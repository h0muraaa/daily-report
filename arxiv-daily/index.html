Towards Improving Speaker Distance Estimation through Generative Impulse Response Augmentation

Anton Ratnarajah, Mehmet Ergezer, Arun Nair 等4人

  • 核心任务： ICASSP 2025的房间声学与说话人距离估计（SDE）挑战赛，旨在探索增强的房间脉冲响应（RIR）数据对SDE模型性能的提升效果。
  • 方法提出： 利用仅受说话人和听众位置约束的开源快速扩散房间脉冲响应生成器（FastRIR），并设计质量滤波器确保生成的RIR与挑战赛RIR对齐。
  • 实验结果： 对于GWA房间，五个位置的平均绝对误差（MAE）从1.66m降至0.6m；对于Treble房间，MAE从2.18m降至0.69m，显著提高了中长距离的估计精度。

LASE: Language-Adversarial Speaker Encoding for Indic Cross-Script Identity Preservation

Venkata Pushpak Teja Menta

  • 问题背景： 多语言语音克隆中的说话人编码器在不同语言（脚本）下未能保持同一说话人身份一致，表现出对口音的依赖性。
  • 方法提出： 提出了LASE（语言对抗说话人编码器），在冻结的WavLM-base-plus上训练一个小型投影头，结合监督对比损失（保持身份）和梯度反转交叉熵（消除语言信息）。
  • 性能表现： LASE在西方和印度口音语料库上消除了跨语言身份差异，并在合成多说话人日记化的跨语言召回率上以极少的训练数据匹配了基线模型。

  • 基准测试： 基于Speech Accessibility Project (SAP) 数据集构建基准，发现当前九个模型未能有效利用诊断或临床描述，有时甚至导致词错误率（WER）恶化。
  • 解决方案： 提出混合上下文依赖微调，结合LoRA适配和临床提示格式，使WER降至0.066（相对冻结基线降低52%），特别是对唐氏综合征和轻度症状说话人效果显著。

Phoneme-Level Deepfake Detection Across Emotional Conditions Using Self-Supervised Embeddings

Vamshi Nallaguntla, Shruti Kshirsagar, Anderson R. Avila

  • 研究痛点： 情感语音转换（EVC）技术的发展引发了音频深度伪造检测的新担忧，现有方法忽视了语音内部语音结构的差异。
  • 方法策略： 提出一个音素级框架，使用基于WavLM的嵌入和音素对齐的TextGrids，在匹配的情感条件下分析真实和EVC生成的合成语音。
  • 研究结论： 发现复杂元音和摩擦音的差异度更高，而分布差异大的音素更容易被检测出，证明了音素级分析是检测情感操控合成语音的有效途径。
