📚科普小课堂：什么是"Loop Engineering"？

🔄 Loop Engineering = 让 AI 自己反复跑，直到跑对

如果你用过 Claude Code 或 Codex，可能已经见过"/loop"这样的指令：你给 AI 一个目标，它会自动重复"执行—检查—修正"的循环，直到达成验收标准。Loop Engineering 就是把这种循环系统化、工程化的一门实践。它不是万能药：适合重复性高、结果能被自动验证的任务（比如跑测试、修 lint、分类 CI 失败）；不适合一次性创意工作或没有自动检查环节的任务。核心提醒：Loop 会烧大量 token，所以先想清楚"有没有东西能自动判定这活干砸了"，再决定要不要搭循环。

🎨 Cowart：给 Codex 加上无限画布

钟二信开源的 Cowart 插件，把 Codex 和本地运行的 tldraw 无限画布结合起来。你可以在画布上圈出图片、写自然语言修改意见，Codex 会自动生成或重绘图片。相比传统"发 prompt—等结果—再发 prompt"的循环，这种"边画边说"的交互更像真实的设计软件，适合快速做图标、示意图、产品配图。
