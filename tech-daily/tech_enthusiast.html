📚 科普小课堂

什么是 AI Agent？为什么最近突然火了？

你可以把 AI Agent 理解成“能自己干活的 AI”。普通的大模型像是学识渊博但只能动嘴的顾问：你问它答。而 Agent 则更像一名能执行任务的助理：你告诉它目标，它会自己拆解步骤、调用工具、查询信息、修改方案，直到把事情做完。

比如你想做一个网站。普通 AI 可能给你一段代码；Agent 则会自己写代码、打开浏览器预览、发现 bug 后修改、再测试，最后把成品跑起来。它需要三个核心能力：推理规划（知道分几步做）、工具调用（会查网页、写文件、运行程序）和记忆（记住之前的进展，不会聊着聊着就忘）。

最近 Agent 火起来，是因为 Claude Fable、OpenAI Codex、GitHub Copilot Agent 等产品让“一句话出成果”成了现实。未来，Agent 可能会像今天的浏览器和搜索引擎一样，成为我们数字生活的基础设施。
