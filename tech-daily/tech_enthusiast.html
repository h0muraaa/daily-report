🎓 科普小课堂

📚 什么是"Source Map"（源码映射文件）？

概念解释： 这次 Claude Code 源码大泄露的罪魁祸首就是一个叫 `.map` 的文件（Source Map）。在现代 Web 开发中，我们写的高级代码（比如 TypeScript）通常会被压缩、转换成机器更容易读懂但人类看不懂的代码。Source Map 就像是一本“翻译字典”，它记录了压缩后的代码和原始代码之间的对应关系。

为什么重要：

  • 方便调试：当线上程序报错时，开发者可以通过这本“字典”，快速定位到是哪一行原始代码出了问题，而不是面对一堆乱码发呆。
  • 安全隐患：正因为它能将压缩代码还原成人类可读的源码，如果一不小心把它发布到了公共环境（就像这次 Anthropic 的失误），任何人都能用它“反编译”出你的全部核心代码。可以说是开发者的好帮手，也是泄密的定时炸弹！
