Claude 推出限时福利：非高峰时段用量翻倍
Anthropic 宣布了一项用户福利：在接下来的两周内，工作日太平洋时间上午5点至11点之外，以及周末全天，用户的 Claude 用量将自动翻倍。这意味着亚洲用户可以在白天享受更多额度，无需额外付费。这一举措被看作是 Claude 在 AI 编程助手竞争中争取用户的策略。
来源：Claude (@claudeai)
Claude 100万上下文窗口全面开放
Claude Opus 4.6 和 Sonnet 4.6 正式支持 100 万 token 的上下文窗口，而且不再收取长文本溢价费用。这意味着你可以一次性上传 600 张图片或 600 页 PDF 进行分析。对于需要处理大量文档的研究人员、律师和程序员来说，这是一个重大利好。
来源：Claude (@claudeai)
Chrome 146 让 AI 助手可以直接操控你的浏览器
最新发布的 Chrome 146 带来了一个革命性功能：只需在 chrome://inspect/#remote-debugging 开启一个开关，AI 助手（如 OpenClaw）就可以直接访问你的真实浏览器会话。无需安装扩展、无需无头浏览器、无需单独登录，AI 可以看到你的标签页、Cookie，并帮你完成操作。这标志着 AI 从"聊天"走向"动手"的重要一步。
来源：Addy Osmani (@addyosmani)

🔥 科技新鲜事

🦞 "养虾"热潮背后的冷思考

最近两周，OpenClaw（昵称"龙虾"）在中国科技圈掀起了一股热潮。从开发者社区到普通用户，从 GitHub 教程到线下装机摊位，"养虾"成了科技爱好者的新潮流。腾讯门口甚至出现公益代装 OpenClaw 的照片刷屏朋友圈。

但热潮背后也有理性的声音：很多人装上后却不知所措——"装上了，然后呢？"一位网友的提问道出了关键：OpenClaw 到底能干什么？这大概是 2026 年最魔幻的场景：一边是全民追捧，一边是装完之后的集体茫然。

事实上，真正的价值不在于"养虾"本身，而在于如何让 AI 真正融入工作流。正如一位开发者所说："200多只龙虾接入一个平台，调研发现只有2只赚过超过1块钱。"技术的新奇感会消退，真正的挑战是如何让 AI 从玩具变成工具。

🤖 AI 编程助手进入"军备竞赛"时代

OpenAI 的 Codex 和 Anthropic 的 Claude Code 正在展开激烈竞争。OpenAI 总裁 Greg Brockman 给全公司下了动员令：到 3 月 31 日，任何技术任务，工程师的第一工具应该是 agent，而不是编辑器或终端。

过去六周，Codex 经历了罕见的产品冲刺：桌面 App 发布、GPT-5.3-Codex 上线、Codex-Spark 实现每秒 1000+ token 的推理速度。与此同时，Claude 也不甘示弱，推出了 100 万上下文窗口。

对于普通开发者来说，这意味着什么？AI 编程助手正在从"辅助工具"变成"主力工具"。未来可能不再需要记住复杂的 API，而是学会如何与 AI 协作，让它帮你完成大部分编码工作。

📚 科普小课堂

什么是 MCP（模型上下文协议）？

MCP（Model Context Protocol）是 Anthropic 在 2024 年 11 月推出的一种协议，旨在让 AI 模型能够更方便地调用外部工具。简单来说，它就像 AI 的"USB 接口"，让不同的 AI 应用可以接入各种服务。

为什么它现在备受争议？
最近，Perplexity 宣布放弃 MCP，转而使用传统的 API 和 CLI。原因是 MCP 存在几个实际问题：全量上下文传输效率低、缺乏自我迭代能力、对于简单任务来说过于复杂。

给普通用户的启示：
技术世界总是在演进。今天的"标准"可能明天就会被更好的方案取代。对于 AI 应用开发者来说，关注用户需求比追逐最新协议更重要。对于普通用户，选择那些真正解决你问题的工具，而不是最"时髦"的工具。

⭐ 产品推荐

🦞 OpenClaw - 你的 AI 助手

OpenClaw 是一个开源的 AI 智能体框架，可以让 AI 直接操控你的电脑完成各种任务。无论是写代码、整理文件、还是自动化日常操作，它都能帮你完成。目前国内外多家云厂商都推出了基于 OpenClaw 的托管服务，入门门槛正在快速降低。

适合人群：想体验 AI 自动化、有一定技术基础的科技爱好者
入门建议：可以先尝试字节跳动的 ArkClaw 或讯飞的 AstronClaw，无需自己部署

🌐 bb-browser - 坏孩子浏览器

这是一个有趣的工具，通过 Chrome 插件 + CDP（Chrome DevTools Protocol）直接操控你的真实浏览器。你可以用命令行或 AI Agent 来控制浏览器：获取网页内容、自动登录、甚至把任何网站变成 CLI 工具。目前已支持 Reddit、Twitter、GitHub、小红书、知乎、B站等 50+ 个网站。

适合人群：喜欢折腾、想提高工作效率的极客
注意事项：使用方式较为"激进"，可能违反某些平台的服务条款

🎯 canirun.ai - 本地 AI 模型适配检测

想知道你的电脑能运行什么本地大模型？这个网站可以帮你。输入你的硬件配置（主要是显卡），它会告诉你最适合运行的模型和参数规模。对于想在本地部署 AI 的用户来说，这是一个非常实用的工具。

适合人群：想在本地运行 AI 模型但不确定硬件是否够用的用户
亮点：提供了各种显卡的适配建议，包括 RTX 4090 的最佳模型推荐
