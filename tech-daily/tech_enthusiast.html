🎓 科普小课堂：什么是 AI Agent？

最近"Agent"这个词在科技圈出现得越来越频繁——从 OpenAI 的 Codex Agent 到 Google 的 Agentic Gemini，再到 Perplexity 的 Computer Agent。那到底什么是 AI Agent？

一句话解释：AI Agent 不是那种"你问一句、它答一句"的聊天机器人，而是能自主设定目标、制定计划、执行任务的 AI 系统。

举个通俗的例子：

普通 AI 就像一位知识渊博的顾问——你问"怎么订去东京的机票？"，它会给你一堆建议和步骤。

AI Agent 则像一位私人助理——你说"帮我安排下周去东京的行程"，它会自己查航班、比价、订酒店、安排日程，甚至根据你的偏好推荐餐厅，整个过程不需要你一步步指导。

为什么 Agent 现在这么火？

因为大语言模型（LLM）的能力已经足够强，可以像"大脑"一样理解复杂指令、调用各种工具（搜索、计算、写代码）、甚至从错误中学习调整策略。而 Agent 就是给这个大脑配上了"手脚"——让它真的能做事，而不只是说话。

2026 年的 Agent 已经能做什么？

Codex 可以连续几天自动写代码和测试；Perplexity Computer 能在沙盒里安全地浏览网页、处理文档；Google 的 Gemini 正在嵌入到每一个 Google 产品中自动帮你完成任务。Agent 时代，正在从"未来"变成"现在"。
