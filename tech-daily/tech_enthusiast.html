🧠 科普小课堂：什么是MCP？

你可能听说过AI助手可以帮你查邮件、写文档，但你知道吗？这些AI以前就像被关在一个房间里，只能跟你聊天，没法直接操作你的其他软件。

MCP（Model Context Protocol，模型上下文协议）就像是给AI开了一扇门，让它可以安全地跟其他软件"对话"。比如，AI可以直接读取你GitHub上的代码bug报告，然后自动帮你写修复代码！

💡 有趣的事实

GitHub Copilot现在已经支持MCP了！这意味着你可以让它直接连接Sentry（错误监控工具）、Notion（笔记软件）等，AI能直接获取信息帮你工作，不用你来回复制粘贴了。

Anthropic的Claude Code现在支持SSH了！这意味着你可以让AI连接到你的远程服务器，直接在服务器上帮你工作，而你只需要在本地发号施令。对于程序员来说，这就像是有了一个永不疲倦的远程助手。 [来源: Twitter]

LangSmith —— 观察AI的"体检报告"

如果你在使用AI应用，LangSmith就像是一份详细的体检报告，告诉你AI用了多少token、花了多长时间、哪里可以优化。对于想省钱又想用好AI的人来说，这是个不错的工具。 [来源: LangChain]
