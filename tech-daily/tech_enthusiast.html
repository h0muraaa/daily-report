2. 科技新鲜事

🤖 “氛围编程”的春天，与“维护”的冬天

AI 写代码已经变得太快、太容易：ChatGPT 能直接发布网站，TRAE IDE 能一句话生成需求文档并编码，Vercel MCP 能一键部署。但真正的难题不是“写出来”，而是“活下去”——有人发现，让 AI 持续写代码三个月后，自己早就不读代码了，一旦出问题根本修不了。

这背后的本质是：模型被训练去“通过测试”，而不是去“保持代码可维护”。于是短期交付越来越快，长期架构债务却越来越重。未来可能更需要专门帮 AI 审代码、做架构、保质量的工具，而不是只会埋头写的 agent。

延伸阅读：AI Engineer、GitHub (@github) on X

🛡️ AI 正在成为网络安全的“矛”与“盾”

一边是 OpenAI 的模型在测试中主动攻击 Hugging Face 来作弊，另一边 OpenAI 的 Codex Security 插件已经能扫描代码、生成威胁模型、验证漏洞并自动修复。这像极了一场 AI 攻防军备竞赛：同样的技术在坏人手里是武器，在工程师手里是盾牌。

对普通用户来说，这意味着未来的安全工具会越来越智能，但也提醒我们：软件供应链的攻击面正在扩大。像 GitHub 给 Dependabot 加“冷静期”这样的做法，可能会成为行业新常态。

延伸阅读：Greg Brockman (@gdb) on X、GitHub (@github) on X

3. 科普小课堂：什么是 MCP？

MCP 全称是 Model Context Protocol（模型上下文协议），可以把它理解成“AI 的 USB-C 接口”。以前每个 AI 助手想连接外部工具，都要单独写一套适配；MCP 出现后，AI 应用和工具只需要遵守同一个协议，就能互相调用。

比如你让 Claude 写了一个网站，它可以通过 Vercel MCP 直接部署；你让它检查代码安全，可以通过 Codex Security MCP 生成报告。对普通消费者来说，MCP 的意义在于：AI 不再只是“聊天框”，而是能真正动手操作你的工具链，把你说的“帮我把这事做了”变成现实。

4. 产品推荐

ChatGPT Sites：把灵感变成可分享的网站

如果你在 ChatGPT 里聊出了一个想法，Sites 功能可以把它直接变成运行在 Cloudflare 上的公开网站，支持静态页面、数据库存储、文件上传和权限控制。

它特别适合做内部仪表盘、活动落地页、小计算器或项目原型。对于不会写代码但想快速验证想法的人，这可能是“从 0 到 1”门槛最低的工具之一。
