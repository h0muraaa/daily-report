Google 发布 Googlebook：为 "AI 优先" 时代而生的全新笔记本品类
Google 在 Android Show 上正式推出了 Googlebook——一款专门为 Gemini Intelligence 设计的笔记本电脑。如果说 15 年前的 Chromebook 是为"云优先"时代而生，那么 Googlebook 就是为"AI 优先"时代量身打造。它融合了 Android 的应用生态和 ChromeOS 的浏览器能力，核心亮点是"Magic Pointer"：你只需晃动鼠标光标，Gemini 就能理解当前屏幕内容并主动给出操作建议——指向邮件里的日期可直接创建会议，选中两张图片能立刻合成搭配效果。此外，用户还能通过自然语言生成自定义桌面小组件，比如"每周推荐食谱"或"只显示风速和降雨的天气组件"。首批 Googlebook 预计今年夏季上市，Gemini Intelligence 也将同步登陆三星 Galaxy 和 Pixel 手机，未来扩展到手表、汽车、XR 眼镜等全生态设备。

8 岁小学生 idea 直接变应用！秒哒 3.0 把 AI 应用开发门槛"打没了"

清华系"小钢炮"再升级：MiniCPM-V 4.6 开源，1.3B 参数就能在手机本地跑多模态 AI
面壁智能联合清华大学正式开源了新一代端侧多模态大模型 MiniCPM-V 4.6。这个模型只有 1.3B（13 亿）参数，却能理解图片、视频、文字，而且只需要 6GB 内存就能在普通手机上流畅运行。实测中，你拍一张"笔放进水杯"的照片问它原因，几秒后手机就会给出"光的折射"的准确解释，全程无需联网、不产生 API 费用。在同尺寸模型中，它的性能全面超越了阿里的 Qwen3.5-0.8B 和谷歌的 Gemma4-E2B-it，token 吞吐量更是达到了 Qwen 的 1.5 倍。项目已在 GitHub 和 ModelScope 开源，还提供 iOS、安卓、鸿蒙的 TestFlight 测试版本，用户可以立即下载体验。这标志着端侧 AI 正在从"能用"走向"好用"。

MiniMax 推出 Mavis：让 AI Agent 学会"团队协作"，不再干一半就停下来问
用过 AI Agent 的人可能都有过这种体验：你让它干个长任务，它跑两步就停下来问"是否继续"，对话框里全是"继续"两个字。MiniMax 将这种现象归结为"上下文焦虑"——模型不敢确定任务何时算完成，每走一步都怕做错。今天发布的 Mavis 模式（MiniMax as a Jarvis 的缩写）试图解决这个问题。它不只是让单个 Agent 变聪明，而是搭建了一套"Agent 团队"基础设施：一个 Agent 当"老板"分配任务，多个 Agent 当"员工"各司其职，它们之间不会"串通"作弊，能持续运行、持续自检。实测中，你可以让 Agent 团队互相"挑刺"、交叉验证结果。这相当于给 AI 配了一个有组织架构的"虚拟公司"，让长程复杂任务的执行可靠性和连贯性大幅提升。

🎓 科普小课堂

什么是"端侧 AI"？为什么它可能是你下一部手机的杀手锏

你可能已经习惯了"问 Siri""喊小爱同学"的体验，但这些语音助手大多需要联网——你的语音先传到云端服务器，AI 处理完再传回来。这个过程虽然只需要一两秒，但存在三个问题：隐私（你的数据离开了手机）、延迟（网络不好时体验直线下降）、费用（每次调用都要算 API 钱）。

端侧 AI（Edge AI） 指的是 AI 模型直接运行在你的手机、平板、手表等本地设备上，不需要联网就能工作。就像今天介绍的 MiniCPM-V 4.6，它只有 1.3B 参数，但能看懂图片、理解视频、回答问题——全部在你的手机上完成。

端侧 AI 的难点在于"小"和"快"的矛盾：模型越小，能力越弱；模型越大，手机越跑不动。所以端侧 AI 的核心技术就是模型压缩（把大模型"瘦身"）、量化（用更少的数字精度表示参数）和高效架构（重新设计模型结构让计算更少）。

对你有什么影响？ 未来 1-2 年，你的手机可能会本地运行一个"私人 AI 助理"，它能看懂你拍的照片、听懂你的方言、记住你的习惯——而且这一切不上传云端、不产生额外费用、网络断了也能用。端侧 AI，就是让你的设备真正"变聪明"的那块拼图。
