Claude Code 新增"电脑操控"功能：写完代码直接帮你点鼠标测试
Anthropic 给 Claude Code 加了一个新能力：直接操控你的 Mac 桌面。写完代码之后，Claude 可以自己编译、启动应用、点击按钮、截图验证，整个流程不用你碰鼠标。这个功能叫 computer use，目前是研究预览阶段，仅限 macOS，需要 Pro 或 Max 订阅。这意味着，你可以让 Claude 写一个 macOS 菜单栏应用，它可以自己写代码、编译、启动、逐个点击界面上的按钮，发现 bug 就修，修完再验证。从开发到 UI 测试，全程无人值守！
AI创新 来源：宝玉(@dotey)
Qwen 3.6 Plus 早期预览版免费上线：提升代码与推理能力
阿里 Qwen 团队宣布，Qwen 3.6 Plus Preview 已经在 OpenRouter 上线，并且在限定时间内免费提供给大家使用。这是 Qwen 旗舰模型的一个早期预览版本，主要升级了代理编程（agentic coding）、前端编程以及通用推理能力。它被设计为 Qwen 3.5-Plus 的更稳定和更强大的继任者。
AI模型 来源：OpenRouter(@OpenRouterAI)
Hermes Agent v0.6.0 发布：加入多实例隔离与各大平台支持
Hermes Agent 推出了 v0.6.0 版本，带来了诸多核心架构升级和生态适配。最重要的是加入了多实例隔离（Profiles），首次支持在同一安装中运行多个完全隔离的 Hermes 实例。此外，它还加入了 MCP Server 模式，可作为 MCP 服务器运行，兼容 Claude Desktop、Cursor 等客户端。针对国内生态，它还完整适配了飞书和企业微信。
产品更新 来源：meng shao(@shao__meng)
世界首个自主 AI 营销师 Helena 登场：帮你全包营销工作
世界首个「自主 AI 营销师」Helena 正式登场。据称，企业在做到第一个 100 万收入前，需要投入大量时间在营销上。Helena 可以接管这些繁琐的工作，比如深夜自动追踪竞品广告、生成 TikTok 幻灯片、UGC 等。它不仅能跨平台（如 GA4、Search Console）实时分析绩效，还能研究趋势并直接在 WordPress 等平台写博客。Helena 拥有独立记忆、定时任务和百余种专属工具。

🎓 科普小课堂

📚 什么是 CLI（命令行界面）？为什么最近 AI 都在拥抱它？

概念解释： CLI 全称是 Command Line Interface，翻译过来就是命令行界面。简单来说，就是你不用鼠标去点击图形按钮（那叫 GUI），而是在一个黑框框（终端）里敲一行文字指令，让电脑去干活。比如你想复制个文件，你不需要右键复制粘贴，而是输入一行像 `cp file1 file2` 这样的命令。

为什么重要：

  • 对于人类来说，点击图形界面更直观；但对于 AI Agent（智能体）来说，CLI 简直是量身定做的。
  • 因为 AI 本身就是处理文本的高手，通过文本命令来控制软件，不仅解析难度低，而且执行速度极快，错误反馈也很明确。
  • 最近像钉钉、飞书甚至企业微信都纷纷推出了自己的 CLI 工具，目的就是为了让各种 AI 能够更方便地直接控制这些协作软件，帮你干活。

有趣事实： 以前如果老板让你一个人包揽前端、后端、运维等所有活儿，那是想“白嫖”你的劳动力。但现在，如果你会使用 AI + CLI 工具，你可能真的能一个人指挥一个“AI 团队”，轻松搞定一整个项目的开发和部署！

🛠️ 值得试试

Claude Code (含 Computer Use)
Anthropic 推出的 AI 编程助手。现在（Pro/Max 用户）新增了直接控制 Mac 桌面的功能，写完代码还能自动帮你点击测试。
cc-connect
一个有趣的开源工具，可以把你本地的 AI Agent（如 Claude Code、Cursor 等）连接到 Slack、Telegram、飞书等聊天软件，让你随时随地在手机上遥控它们写代码。
Pretext
由前 React 核心团队成员开源的纯 TypeScript 文本测量引擎。它能用数学计算提前知道网页上的文字排版，而不需要真的让浏览器去渲染一遍，速度极快！
NotebookLM (Benjamin Franklin)
谷歌 NotebookLM 与合作伙伴推出的全新笔记本体验，让你能互动式地探索本杰明·富兰克林的生平和科学发现。
