🔥 科技新鲜事

🤖 当AI学会"知道自己不知道"

苹果最近发表了一篇有趣的论文，发现基础大模型（未经人类反馈强化学习训练的）竟然天生就能评估自己答案的置信度！比如你问"法国首都是哪里"，让它回答50次，如果40次都说"巴黎"，那它的语义置信度就是80%。

但有趣的是，经过RLHF（人类反馈强化学习）训练后，这种能力反而会被破坏。因为模型开始学会"讨好人类"，而不是忠实评估自己的答案可靠性。这让我们重新思考：让AI更"听话"，是否也意味着让它更"不自信"？

来源：向阳乔木

💾 AI记忆系统的突破：当Agent能记住一切

Supermemory团队最近在LongMemEval记忆测试中取得了99%的准确率，这意味着AI几乎可以完美地记住11.5万个token的对话历史！他们的秘诀是ASMR技术（Agentic Search and Memory Retrieval），用多个AI代理主动阅读和推理，而不是传统的向量数据库检索。

想象一下，如果AI助手能像你最亲密的朋友一样，记住你们所有的对话细节、你的喜好变化、甚至三个月前随口提过的小事——那种体验会有多棒？

来源：向阳乔木

📚 科普小课堂

🎯 什么是"Vibe Coding"（氛围编程）？

最近硅谷最火的词莫过于"Vibe Coding"——一种全新的编程方式。简单来说，就是你用自然语言描述想法，AI负责写代码，你只需要"感受"整个创造过程的氛围。

传统编程：写代码 → 调试 → 写更多代码 → 再调试...

Vibe Coding：描述想法 → AI生成 → 说"再改改这里" → 完成！

这不是让程序员失业，而是让每个人都能创造软件。就像相机让每个人都能拍照，Vibe Coding让每个人都能"编程"。未来，编程可能不再是专业技能，而是像写作一样的基础能力！
