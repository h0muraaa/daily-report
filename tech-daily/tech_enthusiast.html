AI编程Anthropic推出Claude Code Review：AI团队帮你审查代码
Anthropic今天发布了Claude Code的重磅新功能——Code Review。这个功能就像是给你的代码请了一支AI审查团队！当开发者提交代码合并请求（PR）时，系统会自动派出多个AI Agent并行查找bug，然后交叉验证过滤误报，最后按严重程度排序生成审查报告。

据Anthropic内部数据显示，使用前只有16%的PR能收到实质性审查意见，使用后这个比例飙升到了54%。在超过1000行改动的大PR中，84%会被发现问题，平均每个PR能找出7.5个问题。不过这项服务不便宜，每次审查平均花费15-25美元。目前仅向Team和Enterprise用户开放研究预览。

🤖 AI Agent的"技能模式"革命

最近，SkillCraft项目提出了一个极简协议——Skill Mode，用四个动作（save_skill, get_skill, list_skills, execute_skill）构成了技能创建和重复利用的完整生命周期。这听起来很技术，但它解决的其实是每个AI用户都面临的问题：如何让AI记住并复用我们教它的东西？

想象一下，你花了半小时教AI如何处理某种特定类型的数据，但下次使用时它全忘了。Skill Mode就是要解决这个问题——让AI像人类一样，学会一项技能后就能反复使用，甚至分享给其他AI。OpenAI也在他们的Agents SDK中用skills来维护开源仓库，从规划、编码到测试和发布检查都有标准化的技能流程。

这可能预示着AI工具从"一次性对话"向"长期协作伙伴"的转变。

Applied Intuition的CEO Qasar Younis（前Y Combinator COO）最近分享了一个重要观点：未来5-10年，真正的AI革命将发生在物理世界，而不是软件领域。

当所有人都在关注ChatGPT、Claude和编程助手时，自动驾驶汽车、采矿机器人、农业设备正在悄然改变我们的生活。这些技术每年可以拯救超过3万在美国车祸中丧生的人，为残障人士提供出行能力，解决危险行业的劳动力短缺问题。

有趣的是，AI不是在取代卡车司机和农民的工作——而是在填补已经存在的劳动力缺口。美国农民的平均年龄已经接近60岁，长途卡车驾驶岗位空缺不是因为没人能做，而是因为这份工作不再值得做了。AI来得正是时候。

📚 科普小课堂：什么是MCP？

Model Context Protocol（模型上下文协议）

你可能最近经常听到"MCP"这个词。简单来说，MCP是AI领域的"USB接口标准"。

以前，每个AI应用都要单独开发连接各种工具的方式——就像每种电子设备都有自己独特的充电器。MCP改变了这一切，它提供了一个标准化的方式让AI应用安全地连接外部数据源和工具。

最近GitHub和Datadog都发布了MCP服务器，让AI编码助手可以直接访问代码仓库或监控系统。这意味着AI不再只是"聊天"，而是可以真正"操作"你的工具了。未来，支持MCP的工具会像支持USB的设备一样普遍。

🛒 产品推荐

🔥 Firecrawl - 网页数据抓取神器

最近GitHub突破9万星的Firecrawl是一个让AI Agent能够可靠抓取网页数据的工具。如果你正在开发需要读取网页内容的AI应用，这几乎是必备工具。它能把任何网站转换成干净、结构化的数据格式。

🎨 Veeso AI - 设计师的AI设计助手

这是一个用Cursor AI构建的"为设计师、由设计师打造"的工具。它能把你的想法、内容和文档可视化成可编辑的设计图——无需浏览模板、无需写提示词、不再是静态图片。只需要你的想法，就能变成可编辑和分享的结构化视觉内容。

📖 Surreal Slides - PPT转结构化数据

如果你有成堆的PPT需要整理，LlamaIndex团队开源的Surreal Slides可以把PowerPoint文件转换成干净、结构化的Markdown。比Claude Code自带的pptx技能更强大，能更好地理解图表和表格，还能存入数据库方便检索。
