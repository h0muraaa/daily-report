🎓 科普小课堂

💡 什么是 AI Agent（智能代理）？

你可能经常听到"AI Agent"这个词，但它到底是什么？简单说，Agent 就是能自主做事的 AI。

普通聊天机器人（比如最早的 ChatGPT）是你问一句，它答一句——像一位知识渊博但被动的顾问。而 Agent 更像一位能干的助理：你告诉它"帮我订一张下周去北京的机票"，它会自己搜索航班、比价、填信息、甚至帮你付款。

Agent 的核心能力是规划 + 执行 + 工具调用。它会把复杂任务拆解成步骤，使用搜索引擎、代码执行器、数据库等工具，一步一步完成任务，还能在遇到问题时自己调整策略。

现在火热的 Claude Code、Devin、Manus 都是 Agent 的代表。Cursor 的 Composer、GitHub Copilot 的 Agent 模式，也都是把 Agent 能力嵌入了日常工具。可以说，2026 年是 AI Agent 从"概念"走向"日常"的关键一年。
