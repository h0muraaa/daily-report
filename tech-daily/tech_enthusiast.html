什么是 AI Agent？

你可以把 AI Agent 理解为“能自己干活的 AI”。传统 ChatGPT 是你问一句、它答一句；而 Agent 会自己规划步骤、调用工具、检查结果，直到完成一个目标。

  1. 目标理解：你告诉它“帮我订一张下周去北京的机票”，它不再只是给建议，而是会拆解任务。
  2. 工具调用：它可以使用浏览器查航班、调用日历确认时间、甚至调用支付接口。
  3. 循环执行：如果第一步没找到合适航班，它会调整搜索条件再试，直到完成或向你汇报。

简单类比：ChatGPT 像一位知识渊博的顾问，Agent 则像一位能跑腿、能打电话、能自己解决问题的助理。现在的 Agent 还不够完美，但它们正在从“回答问题”走向“办成事情”。
