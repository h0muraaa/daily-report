二、科技新鲜事

🧑‍💼 AI从"聊天工具"升级成"全职助理"：我们还要做什么？

故事：最近，Sam Altman用手机发了一条消息，让ChatGPT安排8人周末旅行，从查历史记录、出三个方案、建投票网站，到最后帮订餐厅、写邮件通知朋友，全部自动完成。另一边，OpenAI的Jason Liu展示了Codex如何当他的"数字幕僚长"：读Slack、看邮件、查Linear，告诉他该优先做什么，还能自动值机发短信。

原理解释：这些能力背后的关键，是AI开始"看见"你的上下文：历史聊天记录、收件箱、任务列表、代码仓库，甚至浏览器。它们通过API和"智能体"框架把多个工具串联起来，像一个人类助理一样，主动推进多步骤任务。

实际应用：你不再需要为每个小任务打开不同App；只要告诉AI目标，它会自己规划、执行、反馈。比如"根据我上周的邮件，准备下周会议材料并发给团队"，或"帮我查航班、值机并把登机牌发到我手机"。

未来展望：当AI代理越来越熟练，人类的核心工作可能变成"判断、审美和纠错"——知道什么是错的，并把它说清楚。Peter Yang总结："唯一剩下的工作，就是理解你不喜欢什么，把它变成语言告诉AI。"

来源：Sam Altman、Peter Yang

✂️ Claude Code 2.0删掉80%系统提示，AI反而更聪明了？

故事：Anthropic在新版Claude Code中移除了约80%的系统提示，但性能没有下降。Jerry Liu等开发者感叹：过去我们写超长提示来覆盖所有边界情况，结果发现这反而限制了AI独立思考和发现"未知的未知"。

原理解释：最新模型（如Claude 5系列）推理能力变强，能在给定完整上下文后自己判断。过多硬性规则反而会让模型只按字面执行，缺少灵活性。更好的做法是把工具接口设计清楚，把判断权交给模型。

实际应用：如果你正在写CLAUDE.md、系统提示或AI技能文件，建议从"详尽规则清单"转向"清晰目标+清晰工具"。让AI自己看代码、自己决定步骤，而不是手把手教每一步。

未来展望：这标志着AI工程从"写死规则"走向"信任模型判断"。未来我们不再堆砌提示，而是设计更好的上下文和工具接口，让AI像资深同事一样自主工作。

来源：AICodeKing、Jerry Liu

三、科普小课堂：什么是"模型量化"？

模型量化就像把一本厚厚的精装书压缩成便携电子书：保留主要内容，但体积大幅缩小。普通AI模型参数通常用32位浮点数存储，而量化可以把每个权重压缩到4位、2位甚至2.9位。这样一来，原本需要几十GB内存的大模型可以装进手机、树莓派或廉价的边缘设备。

代价呢？极低精度可能让模型"变得有点近视"，但Google最新研究显示，把Gemma 2B量化到2.9位后，在树莓派上仍能达到可用速度。未来随着量化技术进步，"大模型"和"小设备"之间的鸿沟会越来越小。

四、产品推荐：MouthPad —— 用舌头控制设备的口腔触摸板

MouthPad是一款定制化的口腔触摸板，放在嘴里，通过舌头动作就能免手操控手机、电脑等设备。它面向厨师、机械师、艺术家等双手被占用的人群，也适合有辅助需求的用户。无需摄像头或手势，也不会被环境光干扰。

为什么推荐？它代表了一种新的"隐形交互"思路：当语音太吵、手势太累、键盘不便时，身体本身也能成为控制器。如果你关注无障碍科技或未来人机交互，MouthPad值得关注。
