🌙 Kimi K3 正式发布：全球首个 2.8 万亿参数开源旗舰模型

🎵 Suno 训练数据遭黑客曝光：从 YouTube Music 抓取了约 38 万小时音频

AI 音乐生成公司 Suno 被一名黑客用蠕虫病毒入侵内部系统，训练数据源码和用户信息外泄。泄露文件显示，Suno 抓取了约 11.4 万小时的 YouTube Music、6.2 万小时的 Pond5 和 1.2 万小时的 Deezer 内容，总计约 38 万小时，甚至还计划下载近 100 万小时的播客。

🧑‍🤝‍🧑 你请了一堆 AI，为什么活还是没变少？

故事引入：想象你雇了三个实习生：一个写文案、一个查资料、一个回邮件。但他们彼此不沟通，所有信息都得你中转。结果是——你更累了。这就是今天很多企业用 AI 的真实写照：买了一堆 AI 工具，却没少干一点活。

为什么重要：单个模型越来越强，但企业 AI 的下一道坎不是“谁更聪明”，而是“能不能协作”。多 Agent 系统的思路是：人做判断和方向，一群 AI Agent 在底下分工执行、互相调用、自己纠错，把重复活干完。

关键细节：Google 的 Managed Agents 加了免费层、预算护栏和 cron 定时触发，就是在降低“Agent 团队”的搭建门槛。OpenMax 等公司也在做多 Agent 产品，展示真实客户案例里一群 Agent 如何像团队一样配合。

未来展望：未来你的工作日可能会变成“指挥一支 AI 小队”：早上自动汇总邮件和新闻，上午让 Agent 写初稿，中午自动审代码，下午让 Agent 跑数据分析。听起来很远，但底层工具今年已经陆续出现了。

科普小课堂：什么是 AI Agent？

最近“AI Agent”这个词越来越火，但它和普通的 ChatGPT 聊天有什么区别？简单来说：普通大模型是“会说话的百科全书”，Agent 是“能动手办事的助手”。

一个 AI Agent 通常有一个核心循环：观察 → 思考 → 行动 → 再观察。它不仅能回答问题，还能调用工具，比如查天气、写代码、发邮件、操作数据库、浏览网页。你可以把 Agent 理解成一个有“手”和“眼睛”的 AI。

举个例子：你跟普通 AI 说“帮我订一张明天去上海的机票”，它只能告诉你步骤；但 Agent 可以真的打开订票网站、查询航班、比价、甚至帮你下单。当然，现在的 Agent 还远没到完全自主，常常需要人在旁边监督，但它正在从“聊天框”走向“工作流”。

🧠 Eva —— macOS 上的开源本地 LLM 大脑

Eva 是一款面向 macOS 的开源工具，主打“本地优先”。它会在你的电脑里维护一份带链接的 Markdown 知识库，AI 不需要每次都去翻原始文件，而是直接基于已经整理好的知识库回答你。

对隐私敏感、不想把文档上传到云端的用户来说，Eva 提供了一种折中方案：既有 AI 的便捷，又保留数据的本地控制权。如果你经常需要读大量 PDF、论文或笔记，又担心隐私，可以试试这个项目。
