02深度分析

「Agent = Model + Harness」：模型厂商正集体下注执行层

DeepSeek Harness 发布页写下的公式值得每位 CTO 反复咀嚼：Agent = Model + Harness——模型负责理解、推理与生成，Harness 则负责上下文、工具、文件系统与执行回放。DeepSeek 以 MIT 协议开源、版本号停留在 0.1.0-rc 的"开发者预览版"，主动把不确定性写在大门口；十字路口文章一针见血：这不是一个产品，而是一套"让所有人共同探索 Harness 的机制"。结合腾讯技术工程对 DSH 的拆解，其"一切皆插件"并非营销话术——模型适配器、系统提示词、会话、存储、沙箱、Agent 循环乃至 Web UI 全部走 Cordis 插件运行时，目的正是让运行时在模型、工具、审批、沙箱、子 Agent 与界面任意替换时仍保持可追踪、可组合、可恢复。

这一动作与同日生态信号互为印证：Vercel 公开其 AI SDK 的"软件工厂"实践，四个月内由 Agent 撰写高达 35% 的合并 PR、关闭 70% 的七月 issue、开放 Bug 下降 25%，人类只负责合并——开发流程本身正在被 Harness 重构。而 Stripe 拟以 100 亿美元收购 OpenRouter（两个月估值 8 倍跳涨）、Cursor 发布基于 60 万条真实请求的模型路由器、Sakana AI 把多 Agent 编排打包成单一模型的 Fugu，全部指向同一结论：编排层与执行层的控制权，正从模型能力中独立出来，成为新的战略高地。对技术决策者而言，这意味着一方面要警惕"模型即一切"的叙事惯性——真正决定交付体验的可能是你如何编排、回放与治理 Agent 的执行轨迹；另一方面，模型厂商亲自下场做 Harness，将把过去三年创业公司在"Agent 框架"上积累的差异化迅速商品化，相关选型需要重新评估。

「智效比」取代「规模竞赛」：后训练 Scaling 与 27B 级模型改写成本曲线

本周模型发布密度堪称史无前例：Grok 4.6、DeepSeek V4 Pro、Gemini 3.7 Flash、GLM-5.3、Qwen3.8 开源权重在 48 小时内密集落地。但真正值得 CTO 关注的不是参数数字，而是两条结构性变化。其一，后训练 Scaling 成为可复制的提智路径。GLM-5.3 与 5.2 共用同一基座，全部提升来自强化学习后训练（长程任务环境数十倍扩展、更长后训练时长），在 Terminal Bench 3.0 等公开基准取得开源第一；爱范儿据此判断"大模型开始卷智效比"。这意味着已部署的基座可以"软件升级"式地获得能力跃迁，模型采购策略应把"后续如何被持续后训练"纳入考量，而不只是看首发基准分。其二，小模型的性能/成本比正在击穿生产门槛。Qwen3.8-27B 在 17GB 内存的笔记本即可运行（Unsloth 实测），SGLang 在单张 RTX 5090 上跑出 206 tok/s 解码，vLLM 单卡支持 1M 上下文、MTP 投机头随权重内置；社区实测其整体表现匹配六个月前"最强且最贵"的 Opus 4.6 Max。配合 Meta 开源 30B 的 Muse Glimmer（Apache 2.0，面向本地 Agent 执行）、Gemini 3.7 Flash 降价 50%，"端侧/私有化部署 + 旗舰云上兜底"的混合架构在经济性上首次变得可信。
