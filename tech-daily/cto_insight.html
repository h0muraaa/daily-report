英伟达换帅余波未平：连跌六周、市值跌破 4 万亿美元，董事会被曝接触 Arm CEO 物色继任者

黄仁勋辞去总裁、CEO 及董事职务后，英伟达的治理真空正被市场持续定价。到本周五收盘，股价一周下跌 12.75%，连跌六周，创 2012 年以来最长跌势，市值跌破 4 万亿美元；此前一个交易日收于每股 162.85 美元、单日跌 2.01%。据英国《金融时报》，董事会已与 Arm CEO Rene Haas 接洽，将其列为继任候选人之一，但不保证最终聘用。公司层面由 CFO Colette Kress 临时接管日常运营，前 Synopsys 掌门人 Harvey Jones 出任 33 年来首任独立董事长，董事会同时启动正式继任遴选。员工侧的「Stand with Jensen」请愿已收集近 6 万个签名，其中自称现员工 3700 余人、前员工 500 余人、股东逾 3 万人，马斯克表示将签名支持。

为什么重要：这已不是单日股价噪音，而是一场「创始人离场 + 继任未定 + 独立董事长就位」的治理结构重置。对把训练或推理押在单一 GPU 供应上的公司，它把供应商集中度从采购条款问题升级为需要董事会签字确认的业务连续性风险。

Agent 评测把「单任务成本」推上台面：Fable 5.2 贵 17 倍却更低分，OpenAI 以 $0.11/任务包揽前二

数据协作平台 Deepnote 发布 Agent Initiative Benchmark：把 12 个前沿模型放进同一家公司的 Slack 群当「AI 同事」，让它们自行判断何时该帮忙、何时该闭嘴。结果 OpenAI 包揽前二——GPT-6 Astra 得 8.97 分居首，GPT-6.1 Sol 得 8.65 分且单任务仅约 0.11 美元；第三名 Anthropic Fable 5.2 得 8.17 分，单任务约 1.87 美元，即贵约 17 倍、分数反而更低。折算成一个 70 人公司每月 Slack 监控账单，Sol 约 281 美元、Fable 5.2 约 4684 美元。同一时间，Reason harness 宣称在 Terminal-Bench 与 DeepSWE 上以「最多低 20 倍的单任务成本」完成前沿任务；AWS 也上线 NeMo Switchyard，指导按「每个解决任务成本 = 总成本 / 通过测试的 run 数」来路由编码 Agent。

为什么重要：Agent 的采购标准正从「跑分」切到「ROI」。常驻循环（安全巡检、客服、PR Review）能不能一直开着，取决于单任务成本而非单 token 价格；只按每百万 token 比价会严重误判真实开销。
来源： 新智元（Agent Initiative Benchmark） · meng shao（Reason 单任务成本） · AWS（按解决任务成本路由）

OpenAI 解散独立机器人团队：通用模型「吃掉」垂直团队，研究者并入 Mark Chen 主研究线

距奥特曼 5 月亲自发帖招人仅五个月，OpenAI 再次解散独立机器人团队。原机器人研究团队并入公司主研究团队、向首席研究官 Mark Chen 汇报，应用机器人与硬件团队并入更大的应用部门、向总裁 Greg Brockman 汇报。触发因素是通用大模型在机器人任务上的跃迁：GPT-6 Astra 未经专门机器人训练，仅凭摄像头画面、机器人自身状态与控制接口，就能自主拆解步骤并下达指令，被认为「通用模型即机器人大脑」。这一转向在本周奥斯汀 CoRL 2026 现场留下注脚——OpenAI 预订的 208 号展位空空荡荡。官方强调机器人仍是长期愿景核心，否认从该领域撤退。

为什么重要：这是一条清晰的组织信号——当基础模型具备通用能力，垂直「专用大脑」团队的存在价值被迅速压缩。CTO 在规划 AI 团队结构时，应把「可被通用模型吸收」的模块与「必须自有数据/场景」的模块分开，避免押注正在被平台化的能力。

Anthropic 给出「常驻 Agent」可照搭架构：收件箱、定时器、记忆、权限、发件箱五原语

Anthropic 工程博客发布《Building always-on agents》，把「24 小时在线助理」拆成五个部件：事件收件箱（有事进来才唤醒一次）、定时器（无人叫也能主动触发）、记忆文件夹（醒来还记得上下文）、权限（拿着账号也不越界）、发件箱（决定何时开口）。其核心判断是：始终在线是一种使用体验，不是让模型一直挂在线上烧 token——大部分时间它在睡觉、不调用模型、也不花钱；并建议「一开始让它安静一点」，把要紧的事留给用户拍板。社区已当天落地：开发者花叔将其复刻进开源 Coding Agent 驾驶舱 FanBox 2.20.0，让终端 Agent 停下时把一句话推到手机（微信/飞书）。

为什么重要：常驻 Agent 的难点从来不是「模型够不够强」，而是事件驱动、并发去重、记忆成本与权限边界这些系统工程。这份架构把「一直在线的体验」和「一直烧钱的后台」解耦，是可以直接映射到队列 + 定时任务 + 权限网关的落地模板。

两个需要重新定价的结构性变量

① 后黄仁勋时代的英伟达：CUDA 护城河仍在，领导真空才是变量

33 年首次管理层更替，把「个人权威」与「平台生态」这两件被长期绑在一起的东西拆开审视。

治理层面的重置已经落地：CFO Colette Kress 临时接管运营，前 Synopsys 掌门人 Harvey Jones 出任 33 年来首任独立董事长，董事会启动正式继任遴选，并被曝与 Arm CEO Rene Haas 接触。市场用连续六周下跌给出定价——本周跌 12.75%，为 2012 年以来最长连跌，市值跌破 4 万亿美元。员工与股东的情绪则反向流动：近 6 万人签署「Stand with Jensen」请愿。传记作者 Stephen Witt 在《纽约时报》给出的批评指向治理本身：过度自信叠加内部「无人敢说不」的缄默文化，创始人绝对权威下的扁平化管理如何演变为危险的单点决策。

真正的悬念不在股价，而在三个结构问题

  • 护城河是生态而非个人：CSDN 与李建忠的拆解指出，英伟达的崛起关键不只是某代 GPU 领先，而是 2006 年押注 CUDA 所形成的软件生态。CUDA 迎来 20 周年之际，真正的威胁来自「AI 自己编写与优化底层算子」、开放互联与国产算力对生态壁垒的合围，而非一次换帅。
  • 「慢一两个节拍」的连锁效应：All-In 的判断是，美国的芯片优势不只在于手里有某一代芯片，而在于英伟达能持续推出更强的新芯片；若因管理层动荡慢上一两个节拍，追赶者（如华为）可能更快缩小差距。这把公司治理直接连到了国家算力竞争力叙事。
  • 供应确定性与合同条款：当继任者、交付节奏与价格策略同时不确定，多年期锁量合同的隐含风险上升。技术高管需要把「治理变更」与「交付中断」写入算力采购的退出条款，而不是只谈单价与交期。
判断：不要把这件事简化成短线股价噪音，也不要简单外推成「英伟达要垮」。未来两个季度，正式 CEO 人选、下一份财报的交付承诺、以及多年期合同的续签条件，是观察其定价权与平台稳定性的三个硬节点；在此之前，任何重押单一 GPU 供应商的架构决策都应加入第二来源与退出机制。
来源： 网易科技（请愿） · 智东西（继任者接触） · AI前线（治理批评） · CSDN（CUDA 与算力格局） · All-In（芯片优势）

② Agent 从「聪明」走向「算得过账」：单任务成本、编排分层与常驻架构

同一天，评测、基础设施与应用架构同时把「成本」推到中心——这是 Agent 从 demo 变成可运营系统的分水岭。

评测侧开始用「美元/任务」而非「分数」说话：Deepnote 的 Agent Initiative Benchmark 显示，OpenAI 两个模型以明显更低的单任务成本拿下前二（Sol 约 $0.11/任务），而 Fable 5.2 以约 17 倍成本换来更低分数；放大到 70 人公司的月度 Slack 监控账单，差距约 16 倍。基础设施侧把成本做成可路由的指标：AWS 的 NeMo Switchyard 明确建议按「每个解决任务成本 = 总成本 ÷ 通过测试的 run 数」在模型间路由，因为编码 Agent 的成本取决于轮数、历史重放与重试——「你为每一次尝试付费，包括那些永远完不成的任务」。新兴 harness（如 Reason）则直接把「最多低 20 倍的单任务成本」当作卖点。编排侧用分档换取效率：Google Antigravity 的 Orchestrator 用前沿模型 Carbon 做规划、快速模型 Hydrogen 执行改码与测试、遇阻再回到 Carbon 修计划，官方称在 Terminal-Bench 4.0 上接近 Carbon 的成功率，同时少用 24% 配额、平均快 19%。架构侧则把「常驻」与「常开」解耦：Anthropic 的五原语架构让 Agent 空闲即睡眠、不烧 token（详见今日要点 04）。

给技术栈的三个直接含义

  • 北极星指标换掉：从「每百万 token 单价」「模型跑分」换成「每个成功任务成本」。要记录重试与失败尝试的成本——失败任务同样收费，但只有成功任务产生价值。
  • 没有 eval 工厂就没有软件工厂：社区反复强调「software factory 必须配一个 eval factory」。没有可靠评测，自动化自我改进循环只是「更多行代码」；评测标准本身才是可复用的护城河。
  • 分档路由是默认架构：用「前沿模型规划 + 廉价模型执行 + 遇阻回升」的分层，配合按解决任务成本的网关，既保成功率又控预算；不要把所有任务都丢给最贵的模型，也不要为了省钱牺牲成功率。
判断：Agent 的竞争已从「谁的模型更聪明」进入「谁能让每个任务更便宜地跑完、并稳定常驻」。下一阶段的赢家，是同时掌握评测标准、成本路由与事件驱动架构的团队——三者缺一，规模化都会卡在账单或可靠性上。

04

CTO 视角：本周行动建议

把信号转成可执行的技术决策
1

重估算力供应商集中度，写进风险台账

为 GPU 供应、模型 API、Agent 平台各指定第二来源与退出条款；多年期算力合同加入「治理变更 / 交付中断」终止权。跟踪三个硬节点：英伟达正式 CEO 人选、下一份财报的交付承诺、算力贷款与交付是否落地。

2

把「每个成功任务成本」设为北极星

停止只按每百万 token 比价；记录轮数、历史重放与重试成本，按「总成本 ÷ 通过测试的 run 数」度量。用成本路由网关做分档（前沿模型规划 + 廉价模型执行 + 遇阻回升），并按季度用新模型重跑基准。

3

先建 eval 工厂，再谈软件工厂

没有可靠评测，自动化自我改进只是更多无人验收的代码。为每个 AI 工作流定义可量化的验收标准与回归集，把「评测标准 + 专有数据」当作核心资产沉淀，而非一次性脚本。

4

采用「常驻 Agent」五原语架构

用事件收件箱 + 定时器 + 记忆 + 权限 + 发件箱搭建 24 小时在线的 Agent，关键是空闲即睡眠、不常开模型。为并发事件做去重与排队，为账号权限设最小范围，重要决策保留人工拍板，初期让 Agent 保持安静。

5

build-vs-buy 再平衡：脚手架买、差异化自建
