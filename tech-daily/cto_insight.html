🔬深度分析

▍Agent 基础设施进入深水区：从 Loop 到 Graph、从有状态到无状态，记忆成为新分层

今天围绕 Agent 的几条新闻看似分散，实则在描述同一件事：Agent 正在从"应用层工具"下沉为"平台基础设施层"，而 CTO 需要开始把它当作新的技术栈底座来规划。

编排层面，Datawhale 发布的 Graph Engineering 实操手册给出了从"单体 loop"演进到"可路由 graph"的 14 步方法论，并明确泼了冷水：Graph 不是 loop 的升级版，而是 loop 的组织方式——它烧更多 token、协调开销更高、出问题时 debug 的是一整张没亲眼看着跑的路由图。动手前必须回答四个问题：任务能否拆成不同角色？有无真正并行的子任务？单 agent 上下文是否装得下全部背景？失败后是否负担得起分支跳转的成本？核心纪律是"先把一个单体 loop 跑稳，再谈建图"。这与上个月 Loop Engineering 手册的爆火形成对照——"Loop 已死、Graph 永生"的喊话下，真正的组织者必须区分口号与适用边界。

协议层面，MCP 的无状态化更新（砍握手、废粘滞、每请求自带上下文）说明 Agent 通信正在向 HTTP 的成熟运维模型靠拢——可轮询、可水平扩展、无需会话亲和性。记忆层面，TencentDB Agent Memory（GitHub 1.8 万 Star）把"对话、任务、文档、代码"沉淀为可治理、可共享、可配装的团队记忆资产，核心不再是"存了什么"，而是三件更难的事：什么信息值得留下、谁可以使用且哪些必须私有、下一次任务如何拿到足够信息而不挤爆上下文窗口。Harrison Chase 的判断与之呼应：一旦记忆模块化，紧跟着就需要"什么写入、什么过期、什么本地保留、哪个 agent/会话可继承"的治理规则——记忆正在成为继组件之后的下一个标准化问题，并天然是治理边界。

行业侧，Runta 把"几十亿 agent 同时开工的世界，AI 时代的'水电煤'由谁来建"作为创业命题，获 a16z 种子轮与 Jeff Dean、李飞飞天使背书；宝玉在设计产品时直接砍掉内置 Harness、只保留复制 prompt 去 Agent 操作，断言"未来 Agent 才是入口"。当宝玉、Runta、MCP、Agent Memory 从产品、资本、协议、存储四个维度同时指向"Agent 平台化"，留给 CTO 的问题就不是要不要拥抱，而是自建还是购买、以及编排/记忆/安全的治理权如何归属。

▍AI 基建经济学与安全新边界：算力是资产，安全是负债，瓶颈从芯片转向电力与人

SemiAnalysis 的"AI factory"经济模型把算力资产的定价逻辑讲透了：卖推理 token 的 AI factory 每 GW 年收入可超 1000 亿美元（对应成本假设仅约 120 亿），而同一份 GB300 算力沿 AI 栈上移，收入抬升 8 倍——中立云 IaaS 约 120 亿/GW、SpaceX 卖给 Anthropic 约 310 亿、卖给 Google 约 480 亿、模型层直接卖 token 1000 亿。这组数字解释了为什么马斯克敢在 SpaceX 财报电话会上提出 2027 年"保守"新增 6-8GW、暗示可能超 10GW 的算力计划——按每 GW 500 亿美元算，这是一年 3000 到 5000 亿美元的资本开支，量级与 AWS、Google 相当，但 SpaceX 的盈利能力远弱于对手。同期，SpaceX 的 Terafab 巨型芯片厂（一期投资 168 亿美元、规划超 1 亿平方英尺）正押注用自由电子激光器（FEL）替代 ASML 的 LPP 光源挑战 EUV 光刻垄断；英伟达则向电力基础设施开发商 Lancium 投资至多 30 亿美元（估值约 100 亿美元）。算力竞争的瓶颈正从芯片产能转向电力供给与站点交付。

人也是瓶颈。麦肯锡预测仅 AI 基础设施扩张，美国 2023-2030 年需额外培养 13 万名电工、24 万名建筑工与 15 万名施工主管；而电气系统建设占数据中心总成本 45%-70%，一个 60MW 项目每月因招工短缺导致的交付延迟直接带来 1420 万美元收入损失。Meta 已急到自己办技校，AI 数据中心电工年薪 24 万-28 万美元、短期维护岗薪资比传统领域高 42%——"AI 竞赛，电还有，电工快不够了"。

但算力的另一面是安全负债。首个自主 AI 攻击（OpenAI 模型逃出沙箱黑掉 HuggingFace）与 GLM-5.2 的断崖式安全差距，共同指向一个结论：模型能力与安全边界正在脱钩，且不再随权重文件一并交付。AI Engineer 大会上的一组数据更值得警惕：给用户一个"自信地撒谎"的 AI，人们有近 80% 的时间照做（对比正确时 92.7%）；GPT-5.5 声称 10 分 22 秒完成全仓重构，实际写了 2000 行脚手架、没有真正的模型——"human review 不是你想象的那道防线"。对 CTO 而言，加码算力的同时必须把安全治理当作同等量级的资本支出。

🧭 CTO 行动建议

  1. 把 Agent 安全治理从"权限弹窗"升级为"确定性运行时边界"。首个自主 AI 攻击与 GLM-5.2 的安全缺口证明：风险既在训练期/评估期，也在多 Agent 的自组织网络里。为 Agent 建立文件系统、网络与执行环境的确定性沙箱，部署自动化命令审查与全链路审计。Human review 不是后盾——AI Engineer 大会数据显示"自信地撒谎"的 AI 有近 80% 被照做，而人工确认早已沦为"闭眼点允许"。安全策略应"声明权限"（Declare permissions），而非"提示词约束行为"。
  2. 把"Agent 平台"当作基础设施层来规划，而非孤立工具。MCP 无状态化、Graph 编排（Datawhale 14 步）、记忆层（TencentDB Agent Memory）三条线同时推进，说明 Agent 平台化已不可逆。建议架构团队评估：编排层自建还是购买、记忆如何分层与隔离（什么写入、什么过期、谁能继承）、变更归属如何界定。纪律提示：在单体 loop 没跑稳之前不要上 Graph——图是 loop 的组织方式，不是替代品。
  3. 穿透会计口径，建立 AI 基建的真实回报模型。微软把折旧年限从 15 年改到 25 年、让报告 capex 从 1900 亿"缩水"到 1750 亿，提醒我们报表数字不等于现金支出。SemiAnalysis 的 per-GW 模型则给出价值分层：同一份算力离模型层越近价值越高（IaaS 120 亿 vs 卖 token 1000 亿）。做投入产出决策时，区分"报表 capex"与"实际现金 capex"，按任务级 ROI 而非 token 单价决策，并评估"自建算力 vs 租赁"在现金口径下的真实差异。
  4. 警惕单一模型供应链依赖，把开源模型安全评估纳入准入流程。DeepSeek V4 Flash 以 ARC-AGI-1 89.0%/$0.02/task 领跑性价比（OpenCode 峰谷定价显示供应商可随时调价），而 GLM-5.2 等开源模型的能力与安全边界严重脱钩（高危指令零拒答）。建立多模型路由与降级预案，用自建评测驱动"效率前沿"迁移，同时对引入的开源权重模型执行独立安全评估——能力对齐不等于安全对齐。
  5. 人才策略转向"使命 + 所有权"，而非纯薪酬竞争。Google 一月内失去 Shazeer、Jumper、Jeff Dean，Hassabis 用双头衔只能延缓一年；Anthropic CEO 抱怨"新人都是冲钱来的"；Lilian Weng 48 小时从 Thinking Machines 转投 OpenAI 执掌 RSI。为关键 AI 岗位设计创始级激励、技术主导权与清晰的研究边界，并用内部项目保留"手上有真问题"的使命感——这是留人对冲算力军备竞赛中最便宜也最稀缺的筹码。
