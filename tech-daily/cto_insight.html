深度 01 · 资本周期

从“叙事溢价”到“成本账”：AI 资本开支进入下半场，CTO 该怎么读这份资产负债表

把今天分散的消息放在一起，会看到同一条主线：AI 基础设施的扩张，已经把未来十年的杠杆加到了极致，而资本市场开始用“成本账”而不是“故事”来给它定价。

同一笔账单，上半场是订单，下半场是风险

上半场的逻辑很清晰：任何千亿美元级的算力长约都会被华尔街视作芯片与云厂商的确定性订单，直接推高科技硬件链条的估值。但当 Anthropic 把约 4475 亿美元的 2030 年前刚性支出、“照付不议”条款与 2138 亿美元可终止合约同时摆到台面上，而二级市场又看到云巨头自由现金流承压、地方公投密集阻击数据中心扩建时，庞大预算反而加剧了投资迟疑。11 月初芯片与算力租赁板块的下跌并非因为需求突然消失，而是市场在强行剥离过去两年的“叙事溢价”。这不是需求崩塌，而是估值的分母变了。

算力约束正在变成能源与政治约束

Anthropic 用 34 亿美元直接采购燃气发电机，说明瓶颈已经从“能不能买到 GPU”延伸到“有没有电、社区让不让建”。Google 一侧的应对是把基础设施做得更“可调度”：GKE dynamic slicing 让 TPU 切片不再绑定固定节点池，启动快 5 倍、恢复快 4.5 倍；Pathways 用单控制器把异构加速器池当作一个整体调度；MaxText 把长上下文训练推到 1400 万 token。这些优化的共同目的，是在供给紧俏的前提下提高“每单位投资的 goodput”。对 CTO 而言，容量规划必须同时回答三个问题：算力单价、刚性承诺敞口、以及能源与审批的可获得性。

给技术高管的提醒：
  • 长约不等于低成本。在价格下行周期里，锁死的长约可能变成负债；需要为“算力单价继续下跌”留出重谈空间与退出条款。
  • 供应商集中度是新的财务风险。DayOne 的 F-1 显示单一客户贡献近 70% 收入，反过来也提醒买方：你的算力供应是否过度依赖少数区域与单一伙伴。
  • 把政治与社区变量写进预案。数据中心的选址、用电与审批，已从运营细节上升为影响交付时间表的战略变量。

对预算与架构的直接含义

  • 容量规划升级为资本规划。把“算力可获得性 + 能源 + 监管”列为一等变量，按季度更新单位成本与刚性承诺敞口，而不是只做需求预测。
  • 多云、多芯从口号变成对冲。AWS 的 TorchNeuron 让既有 PyTorch 代码近乎零改动跑在 Trainium 上，降低了“换芯”的迁移成本，多芯策略第一次具备工程可行性。
  • 自建 vs 采购重新算一遍。当头部厂商用长约锁定稀缺供给、而价格又在快速变化时，混合策略（核心自建 + 峰值外采）往往比单一路线更能穿越周期。

第一层迁移：从模型层到产品与私有上下文

姚顺雨给出的判断——“护城河在产品层，利用专有数据与上下文、并获得用户信任”——与 a16z 对 Computer Use 的观察一致：真正拉开差距的不是跑分，而是那 99% 与 97% 可靠性之间的鸿沟、对 prompt injection 的抵抗，以及 ERP、采购对账这些“没人愿意亲手做的苦差事”。落到企业，企业的差异化本来就不在通用 AI 能力层，而在业务理解层。一份关于企业 AI 落地的复盘把“翻车点”归结为三个写代码之前的决策：先做“雪中送炭”还是“锦上添花”、自研／采购／开源如何选、节奏如何排。通用能力（对话、RAG、OCR、语音）已是商品，自研成本远高于采购且不构成壁垒。

第二层迁移：Agent harness 成为被低估的成本杠杆

Garry Tan 开源的 g-harness-evals 给出了一组反直觉的结果：在同一个前沿模型、同一批办公场景任务下，只替换 agent harness（系统提示、工具、记忆等外围设计），各方案的准确率集中在 71%–79%，20 道题里有 14 道在所有组合下得分完全相同，差距在统计上难以区分；真正拉开差距的是成本与速度——同一个 Opus 5.5 上，OpenClaw 解一题约 0.44 美元、中位耗时约 99 秒，其余方案约 0.19–0.24 美元、耗时约 40–50 秒。这意味着一件事：当模型能力趋同，harness 工程的质量直接决定了单位任务的成本与吞吐。对 CTO 来说，这比“再换一个更强的模型”更可度量、更可优化。

把护城河翻译成可执行的三件事：
  • 数据资产：企业知识库、员工经验蒸馏、专有业务规则——这些是模型拿不到、竞品也复制不了的部分。
  • 工作流嵌入：把 Agent 放进真实流程（报销审核、合同比对、工单分类），用“原成本有多高”而不是“听起来多 AI”来排序场景。
  • 信任与可靠性：评测、可追溯、可回滚，决定了 Agent 能否承担有后果的任务。

产业纵深：一个“非 AI”的正面样本

宁波华翔的案例值得技术高管注意：这家汽车 Tier1 早已完成数字化，2025 年启动集团化 MES 选型，看中的不是某个模型，而是“能灵活适配不同业务单元、云边端协同、以白盒化业务语言生成系统”的能力；合作方用 3 个月交付首批两个工厂，比过去缩短 5–6 个月、提效 3 倍以上，如今三家试点工厂已上线统一制造运营底座。它的启发是：AI 的价值往往落在“系统可复用、TCO 可下降、上线可加速”这些传统 IT 指标上，而不是模型参数上。这与“护城河在业务理解层”的判断互为印证。

CTO 视角

未来一个季度可以落地的五项动作

  1. 把 18 个月容量规划升级为资本规划

    在价格下行周期里，重新测算“长约 vs 按需”的 TCO，把算力单价、刚性承诺敞口、能源与审批可获得性列为一等变量；为长约配置重谈与退出条款，并保留多云、多芯的迁移路径（TorchNeuron 已显著降低换芯成本）。

    衡量口径：每季度更新“单位算力成本 + 刚性承诺敞口”仪表盘

  2. 把模型采购从“单选最强”改为“分层路由 + 单位任务成本”
