01资本周期

科技股单日蒸发 2.3 万亿美元，Anthropic 买方估值一个月内从 2 万亿降到 1.2 万亿

11 月 5 日美股科技股全面暴跌：纳斯达克 100 指数跌 6.4%，单日市值蒸发约 2.3 万亿美元（彭博称按金额计为单日最多），费城半导体指数跌约 12%，芯片股跌幅最深。All-In 的复盘给出的量级是近 4 万亿美元市值被抹去，并围绕“数据中心会不会停建、算力流向哪里”展开争论。政治变量叠加在财务变量之上：中期选举后民主党拿下参众两院，并在得州、佐治亚等数据中心集中的州有所斩获，这些地区居民越来越反对数据中心快速扩张，投资者担心国会接下来会多开听证、多做调查。更直接的重定价发生在 Anthropic 身上：据彭博社报道，其下周启动路演，买方讨论的估值已从 10 月初最高 2 万亿美元、10 月中 1.4—1.5 万亿美元，降到本周的 1.2—1.3 万亿美元，个别人只给 1.1 万亿美元；作为参照，其 5 月私募轮估值为 9650 亿美元，而 OpenAI 本轮融资目标投前 1.25 万亿美元。耐人寻味的是，AI前线周报同时称 Anthropic 仍计划感恩节前启动 IPO、估值最高 1.75 万亿美元、拟募资 800—1000 亿美元——招股区间与买方预期出现明显分歧。对 CTO 的含义是：算力供给的约束已从“能不能买到 GPU”扩展到“社区、监管与资本市场允不允许建”，中长期容量规划必须把资本成本与政治风险列为一等变量。

02平台卡位

DeepSeek 把 Harness 定位为“Agent 时代的操作系统”，日活 154 万并筹备官方插件市场

DeepSeek Harness 团队核心成员田天一对插件作者解释平台边界：官方会提供稳定的基础能力与大多数人需要的通用功能，但设计原则是“一切皆插件”，连内置功能也可以被第三方插件替换，希望社区做出“发明操作系统的人从来没想过的 App”。第三方插件作者披露，Harness 的日活已经突破 154 万；AI前线周报进一步称团队拟建官方插件市场。同一时间，GitHub 正在为 Agent 做一次全栈重建：2.25 亿开发者、一年 343 亿次提交，Microsoft CoreAI 执行副总裁 Jay Parikh 主导的 Copilot Fusion 会把一个任务拆到多个模型上，以同时优化质量、成本与速度，他提出的核心问题也很直接——如何把 token 花费连接到真正交付的工作。基础设施层还出现了新的品类：Entire 推出专为人与编码 Agent 协作设计的 Git forge，其前提是传统 PR 模型不适合 Agent 高速生成、审查与迭代代码的环境。对 CTO 而言，Agent 运行时与 harness 正在成为新的平台入口，自建、采购还是押注某一生态，是一道需要现在就回答的架构题。

03组织形态

Linear 上 Agent 已创造 50% 的新工作，Levi's 用 17 个 Agent 重构整个 SDLC

AI Will 整理的市场地图给出了一个刺眼的比例：在 Linear 上，Agent 创造的新工作占比已从一年前的 3% 升到 50%，95% 的付费工作空间安装了至少一个 Agent；同一张图里，Notion 估值 110 亿美元，Confluence 的 Rovo 覆盖 80% 以上的财富 500 强。企业侧的样板更具体：Levi Strauss 在 GitHub Universe 2026 披露，他们用 17 个专用 Agent 覆盖需求、规格生成、自动化测试、安全扫描、无障碍校验与部署，并通过 MCP 打通 Jira、Confluence 与 New Relic；每个 PR 由 5 到 11 个独立 Agent 审查，自动修复后提交回分支，但仍保留严格的人工审批门。Addy Osmani 的判断是，写代码正在变成“管理”——挑任务、交代背景、委派工作、验收结果，多开几个会话本身意义不大，关键是建立让 Agent 能自验证、带证据交付的工作方式。对 CTO 的含义是：瓶颈正从“产出”转向“评审与判断”，组织设计、职级与 headcount 规划都需要重算。

04可靠性

Claude Code “看起来对”却漏掉 80 万美元，Agent 的可靠性缺口开始有具体价格

AlixPartners 把 Claude Code 指向真实的并购后采购分析：数百家供应商、超过 4 万份合同。第一版答案看起来很完整，但一个总额差了约 80 万美元，一个关键续约截止日迟了一个月；原因包括长合同静默处理失败、修订未关联到母合同、费率表跨页拆分。团队最终用“先结构化数据”的五段流水线，加上内置业务规则的自定义工具，才让每个答案都能追溯到来源。Ramp 展示了另一条路径：在客户上线前做端到端评测，把会计工作拆成对账、差异分析等任务，用带完整账本的合成企业反复回测，发现最新模型仍主要栽在推理上；真正有效的实验包括删掉不必要的技能、跨两个时间段测试记忆、以及定时回归并把问题报进 Slack。研究侧则提醒另一半风险：UndoBench/EvoUndo 发现 Git 覆盖不了外部 API 调用、运行时配置与通知，而且在 478 项让 Agent 变得更强的新变更中，有 197 项（约 42%）同时破坏了它的恢复能力。对 CTO 而言，Agent 的竞争力不在 demo，而在评测、可追溯与可回滚——这三项目前都还没有成为采购清单上的标准项。

05护城河

模型能力加速商品化，护城河正从“模型层”迁移到“私有上下文与产品层”

腾讯首席 AI 科学家姚顺雨在清华被张亚勤追问“用户黏性何在”时给出判断：护城河更多在产品层而不是模型层，核心是两件事——别人没有的私有数据与上下文，以及用户是否信任 AI 了解自己的数据并采取行动；一个更聪明的模型并不了解你是谁。OpenAI Computer Use 产品负责人对 a16z 的说法几乎一致：自 Astra 之后，Computer Use Agent 已能完成人用电脑能做的事情，速度上超过普通人、逼近专家，真正值得看的是 99% 与 97% 可靠性之间那点差别、对 prompt injection 的抵抗，以及 ERP、采购、财务对账这些“没人愿意亲手做的苦差事”；给创业者的提醒是护城河仍在速度、执行节奏与行业纵深。与此同时底座在快速同质化：DeepSeek-V4.1-Flash（7630 亿参数）读取自己最深 7 层的内部激活，在不改权重的前提下把一段 Python 写进推理流程做“读脑自救”，AIME 与 HMMT 2026 准确率提升 7 个百分点；阿里 Qoder 上线匿名模型 Qoduck，Tokenizer 指纹与千问高度吻合、知识测试超过已发布的 Qwen3.8，被广泛猜测是 Qwen4 的预热；Nous Research 在 Qwen3.8-27B 上只用 5280 万 token 做微调就开源了 Arete-27B，把其自建评测里的宣传率从 22% 压到 0.9%，且代码与 Agent 能力没有下降——这说明开源底座上的“对齐层”很浅、很低成本即可改写。对 CTO 而言，不要把战略押在“模型更强”上，要押在数据、上下文、工作流与信任上。

深度 01 · 平台层之争

Agent 时代的平台层：运行时、记忆与协作协议正在同时被重新定义

把今天分散在不同版块的消息放在一起，会看到同一条主线：围绕“Agent 如何运行、如何记忆、如何协作”的基础设施，正在形成新的平台层。这个层不属于任何单一模型，却决定了模型能力能否转化为企业生产力。

运行时正在变成新的操作系统

DeepSeek 对 Harness 的定位值得逐字理解：它不满足于做一个“Agent 工具”，而是要做“Agent 时代的操作系统”。田天一给出的类比是智能手机 OS——官方内置闹钟与计算器满足基本需求，但更希望第三方做出比内置更好、甚至官方从未想过的 App；在“一切皆插件”的架构下，内置功能同样可被替换。配套的数据是 154 万日活与官方插件市场计划。这意味着竞争焦点从“模型跑分”转向“插件生态、API 稳定性与可替换性”，与移动操作系统早期的竞争结构高度相似。对企业而言，选型问题也随之改变：不只是在选一个模型，而是在选一个可能锁定工作流、技能与数据的运行时。

协作协议在被重写

GitHub 的重建给出了平台方的判断：当 2.25 亿开发者一年产生 343 亿次提交、且其中越来越多由 Agent 发起时，代码托管、评审与 CI 的假设都需要重写。Jay Parikh 主导的 Copilot Fusion 把单个任务拆分到多个模型，同时优化质量、成本与速度；他抛出的问题“如何把 token 花费连接到真正交付的工作”，本质上是把平台度量从“调用量”转向“交付量”。Entire 的 Git forge 则更激进：它认为传统 PR 模型不适合 Agent 高速生成、审查、迭代代码的环境，因而从协作原语层面重新设计。两件事指向同一个结论——今天的企业研发基础设施是为“人写代码”设计的，而 Agent 正在成为一等公民。

记忆从功能变成平台能力

Anthropic 11 月 6 日的工程博客给出了目前最完整的智能体记忆设计。难点在于：Claude 必须在当下决定什么值得记，却不知道以后会用到什么。他们的办法是在会话结束后加一个后台步骤“做梦”（dreaming）：回头翻原始对话，改掉记错的笔记，把零散笔记整理成更好找的结构。效果有硬数据支撑：在查数据库答题的测试里，Opus 5 从 0.564 提升到 0.828；用 Stainless 约 35 万个文件、4.2 亿 token 的资料出 25 道题，仅靠 128 轮“做梦”整理出的 wiki 答题，得分从 13% 升到 48%，wiki 与搜索结合后从 54% 升到 61%，每道题还省下约 2 万个 token。最反直觉的是“会挑比记得多更重要”：Sonnet 3.7 在宝可梦任务里写了 413 个记忆文件只拿到 1 枚徽章，而 Fable 5 只写 10 个文件就拿到 4 枚；一条记错的关键笔记会让模型反复走错路，做一次“梦”纠正后才走出月见山。Anthropic 把记忆分成四层——原始会话记录、自写笔记、结构化 wiki、每次开新会话自动注入的上下文——“做梦”负责逐层核对与提炼。这已经不是产品功能，而是平台级的上下文工程。

企业侧的样板已经出现

  • Levi Strauss：17 个 Agent、一条 SDLC。需求、规格、测试、安全扫描、无障碍与部署各有专职 Agent，经 MCP 连接 Jira、Confluence、New Relic；每个 PR 由 5—11 个独立 Agent 审查并自动修复，但人工审批门保留。这说明“多 Agent 流水线”已从演示进入生产，关键在于审批与责任边界的设计。
  • Citadel Securities：给公司建一个“状态估计器”。Joao Wenzel 的团队用 Agent 从 deck、Slack、会议纪要、代码变更与 Agent 轨迹中构建机构记忆，借用机器人学的状态估计思想：随证据更新信念、让事实老化、用实际结果给自己的预测打分、接受人的纠正。它专门识别“外面绿、里面红”的西瓜项目，回测显示被它标记的项目延期概率是其他项目的两倍。检索不够，会老化、会自评的记忆才够。
  • Addy Osmani：工程师正在变成管理者。他给出的顺序很明确：先让 Agent 能检查自己（测试、构建、类型检查、界面截图），再让未参与原对话的新 Agent 独立审查，最后才是人做产品取舍、安全边界与发布判断；并行度上限往往是人的注意力，而不是模型数量。
一句话总结：模型会继续趋同，但运行时、记忆与协作协议不会自动趋同。未来两年，企业 AI 的差异化更可能来自“把私有上下文接进 Agent 运行时”的工程能力，而不是“用到最强模型”的采购能力。

给技术高管的三个判断

  • 把 harness 当作战略资产做 build-vs-buy。如果核心工作流、技能库与记忆都长在第三方运行时上，迁移成本会随时间指数上升；至少要保证提示、工具、评测与记忆数据可导出。
  • 把“记忆质量”纳入架构评审。记忆不是向量库容量问题，而是“写什么、何时改、如何老化、如何验证”的策略问题；错误的记忆比没有记忆更糟。
  • 按“交付”而非“调用”设计度量。GitHub 已经在问 token 花费如何对应真正交付的工作；内部平台也应把 Agent 的产出与评审通过率、回滚率、交付周期挂钩。

深度 02 · 资本与基础设施

资本成本的重定价：AI 基建从“财务决策”变成“政治与信贷决策”

估值与资本开支开始脱钩

Anthropic 的估值路径最能说明问题：10 月初买方合理价位最高 2 万亿美元，10 月中在介绍最新财务数据后降到 1.4—1.5 万亿，本周美股大跌后进一步降到 1.2—1.3 万亿，个别买方只给 1.1 万亿。与此同时，AI前线周报称公司仍计划感恩节前启动 IPO、估值最高 1.75 万亿美元、拟募资 800—1000 亿美元——发行方与买方之间的预期差，本身就是市场重新定价的直接证据。OpenAI 首席财务官则表示，无论选举结果如何，公司都将继续推进美国数据中心扩张计划。一边是估值下修，一边是资本开支不减，这个组合意味着未来一段时间“算力过剩”与“算力紧缺”会同时存在于不同环节：训练集群可能过剩，而电力、并网与先进封装仍然紧缺。

能源与供应链成为硬约束

Anthropic 同意支付 34 亿美元为数据中心采购燃气发电设备，据 FT 报道这是 AI 实验室已知最大的一笔单次发电设备采购——模型公司正在沿产业链向上游走到电力。马斯克则声称软银出现燃气轮机订单违约，但未提供任何佐证；同期软银股价单日暴跌 10.8%，市场对“星际之门”融资能力的担忧被放大。芯片侧同样紧绷：据报道台积电应英伟达要求，开始规划生产 3D DRAM 这类先进存储芯片，因为 AI 硬件需求激增导致存储严重短缺、价格飙升。更远期，马斯克披露的 TerraFab 计划是耗资超过一万亿美元、占地一亿平方英尺、年产 1000 GW（1 太瓦）AI 芯片的单座工厂，约为明年全球 AI 芯片预计年产量的 30 倍；他的论据是全球晶圆制造中真正对晶圆产生物理或化学改变的有效加工时间只有约 20%，以及美国本土产能乐观估计仅为亚洲的 10% 左右。无论这些数字能否兑现，方向是清楚的：算力竞争的下一段瓶颈在电力、存储与制造效率，而不只是 GPU。

需求上升与成本下降同时发生

另一组信号容易被暴跌掩盖：AI 的成本仍在快速下降。Orange AI 引用的数据指出，AI 成本的下降速度快于此前几代变革性技术，其判断是“需求上升是指数级的，成本下降也是指数级的，数据中心按部就班建设即可，无须焦虑与炒作”。这与资本市场的恐慌并不矛盾——需求增长和单位价格下降可以同时成立，而收入增长未必跟得上资本开支。风险叙事也在升温：量子位以《资本正在撤离“世界模型”》为题记录了这一转向；Gary Marcus 引用克鲁格曼的观点称，AI 泡沫破裂几乎必然引发衰退，且复苏可能缓慢、失业率会在数年内保持高位；All-In 的 Chamath 则公开承认“我错了，经济是坏的”。对 CTO 的实用结论不是判断泡沫，而是为两种情形都准备预案。

融资结构本身也在变化

CTO 视角

未来一个季度可以落地的六件事

  1. 为算力与模型合同做“基准 / 下行”两套情景

    估值下修、资本成本上升与电力/并网约束同时出现时，按单一乐观情景签下的长约会把风险全部留在自己一侧。优先争取随公开价下调的条款、按季度重新议价的权利，以及明确的缩容与退出机制；同时把非敏感、非实时负载设计成可跨区域、跨供应商调度的形态。

    衡量指标：单一供应商占推理支出比例 · 单位任务成本（$/任务）

  2. 明确 Agent harness / runtime 的 build-vs-buy

    运行时正在成为新的平台层，DeepSeek Harness 以“Agent 操作系统”定位、GitHub 为 Agent 全栈重建、Entire 重做协作原语，都说明这个层不会自动 commodity 化。现在就评估：核心工作流的技能库、提示、记忆与评测数据是否可导出，迁移成本是否随时间指数上升。

    衡量指标：核心 Agent 工作流的可迁移成本与数据可导出率

  3. 把“证据链 + 回滚”变成 Agent 上线门槛

    Claude Code 漏掉 80 万美元、42% 的能力提升变更破坏恢复能力、Agent 只汇报最终结果——这些都说明“看起来完成”不等于完成。要求每个生产级 Agent 提供可执行的自验证、独立评审、可追溯的中间过程与回滚方案，再谈扩规模。

    衡量指标：回归逃逸率 · 平均回滚时间（MTTR）· 带证据交付率

  4. 用私有上下文与企业记忆构建护城河

    模型层在商品化，护城河迁移到私有数据、上下文与信任。把内部系统通过 MCP 等标准接口接进 Agent，建立会老化、会纠错、会自评的机构记忆，而不是只堆向量库；度量“私有上下文覆盖率”和“一次通过率”，而不是参数规模。

    衡量指标：私有上下文覆盖率 · 任务一次通过率

  5. 重算组织与 headcount：从“写代码”到“定义验收”

    Linear 上 Agent 已创造 50% 的新工作，Levi's 用 17 个 Agent 覆盖整条 SDLC，工程师的日常正在变成挑任务、交代背景、委派与验收。调整职级与招聘画像，减少“纯实现”岗位，增加能设计评测、边界、权限与审批门的人；注意并行度的上限是人的注意力。

    衡量指标：每工程师管理的 Agent 数 · 评审周期 · 返工率

  6. 安全与供应链前移：AI 审计 + 隔离 + 独立验证

    AI 同时加速了攻击与审计。把 AI 代码审计纳入 SDLC 常规环节，坚持“验证者不是发现者”的独立评审原则；对高爆炸半径资产优先做网络分段、运行时隔离与分钟级失效凭证。安全架构基本功比模型能力更值得投入。

    衡量指标：高危资产隔离覆盖率 · 凭证有效期 · 审计发现闭环率
