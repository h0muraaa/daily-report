AI for Science 抵达标志性验证节点，但"验证通过"不等于"被理解"。 数学家 Levent Alpöge 与 Claude 合作完成的黎曼猜想证明，于 11 月 21 日获 Lean FRO 与 Mathlib Initiative 联合声明背书，确认约 1700 万行 Lean 代码所证命题与证明均正确，从公开到认证不到一天。这是 AI 作为"科研协作者"首次在千禧年难题级别获得形式化社区认可。但同期数学家詹妮·洛瑞恩·尼尔森提交《Alpöge 证明无效》论文（约 31 小时内更新 14 版），指出形式化代码可能存在"无论输入都成立"的条件设置漏洞——争议的核心是机器可验证性与数学可理解性之间的落差。 来源：赛博禅心 · Datawhale（反转） · 网易科技
  2. 算力正在被"金融化"。 由 23 岁 MIT 毕业生 Kush Bavaria 创办的 Ornn，获 a16z、Thrive Capital、BoxGroup 投资，试图把 GPU 做成可定价、可融资、可对冲的"大宗商品"。其调研显示，直接向 CoreWeave 下单 H100/B200 的报价已排到 2027 Q4 甚至 2028 Q1，芯片租金比首发时更贵、三年续约期权不再免费——算力稀缺正从"采购问题"升级为"资产管理问题"。 来源：深思圈
  3. Anthropic 上市，重塑 AI 资本格局。 Anthropic 纳斯达克上市首日收涨 17% 至 97.17 美元，融资 1073 亿美元创史上最大 IPO，完全稀释市值约 1.8 万亿美元、跻身全球第七；公司自身入账约 916 亿美元，占当周 AI 已披露融资额的 91.6%。资本正以前所未有的集中度押注基础模型层。 来源：创业邦 · 硅谷科技评论
  4. "企业自训模型"成为独立赛道。 斯坦福教授 Yejin Choi、Carlos Guestrin 创办的 Noeri 融资 1.1 亿美元，主打"用企业自有数据训练、权重归企业所有、可反复重训"的模型；同赛道 Applied Compute 成立不到 18 个月 ARR 已达 1 亿美元，被 Palo Alto Networks 以约 45 亿美元收购。其底层逻辑是：企业租用闭源模型越多，沉淀的 Agent 执行日志就越多，越能反哺自有模型——数据资产正在成为模型护城河。 来源：硅谷科技评论
  5. Agent 安全暴露真实、可量化的风险。 安全公司 Apiiro 发现，Claude Code 的"Don't Ask Again"功能会把密钥明文写入本地 settings.local.json；在 claude/settings.local.json 中识别出 1,122 条密钥，另有 1,160 条散落于 git 历史、共享 settings.json 与仓库内的 Agent 对话记录中。Agent 工具的便利性正以安全边界为代价，企业级治理已刻不容缓。 来源：InfoQ

Deep Dive

算力即新石油：从"排队两年"到"可对冲资产"的价值链重构

基础设施经济学 · 资本格局

Ornn 的切口是算力市场的"价格缺失"：GPU 采购价格不透明、缺乏标准合约、无法对冲，导致企业既买贵又买不确定。Kush Bavaria 的解法颇具"商品化"意味——自己运营芯片以获取真实成交价，再基于此构建 GPU 的指数与期货，并为此拒绝了高估值条款以保留对定价数据的控制权。这背后的信号是：算力正在从 IT 运营支出，转变为需要估值、融资与风险管理的资本科目。

资本与供给两侧同期共振。Anthropic 以 1.8 万亿美元市值完成史上最大 IPO，说明基础模型层的估值锚已被资本接受；企业自训模型公司（Noeri、Remanence、Sqwish）密集融资，加上 Applied Compute 以约 45 亿美元被 Palo Alto Networks 收购，证明"数据资产层"同样在被重估。供给端则被地缘与供应链重塑：分析师郭明錤称谷歌已下调博通 TPU 8i 系列 2027 年出货约 100 万颗（约 20%），同时上调联发科设计的 TPU；腾讯管理层 11 月 18 日亦表态，新收紧的先进算力限制将影响所有中国参与者。

更深一层的判断来自"中国 AI 大迁徙"：算力是重工业——需要电、怕热、挑线路、取决于机柜里的芯片归属。文章将它类比三线建设的地理迁移，提醒我们风平浪静时"软件无重量"是错觉，一旦封锁来临，云端就会落回地面。

CTO 含义：把算力纳入资本与风险管理框架——评估长期合约 vs 现货、自建 vs 租用的全周期 TCO，探索 Ornn 类定价/对冲工具，并规划多芯片、多区域、多供应商的供给弹性，而非把"拿得到卡"当作默认前提。

来源：深思圈（Ornn） · 硅谷科技评论 · 创业邦（郭明錤） · 硅星人Pro（中国AI大迁徙）

算力受限下的模型战略取舍：腾讯混元的"务实主义"

研发战略 · 组织取舍

腾讯首席 AI 科学家姚顺雨带队在 r/LocalLLaMA 做了一场两小时 AMA，加上此前在清华的闭门对谈，难得完整呈现了混元的战略取舍。面对"字节、Kimi 都冲 3T/5T，为何混元停在 700B"的尖锐提问，团队的回答是：Hy3/Hy4 已证明"扎实的小模型能胜过更大的模型，且成本更低、研发中能学到更多"；但另一处又明确承诺下一代会显著扩容。看似矛盾，实为一套有相互牵制的优先次序。

取舍背后的硬约束很现实：先进算力限制影响所有中国参与者，下一代混元可能需要更长时间才能推出；即便追上一项能力，还要面对一批迅速跟进、愿意以更低价格出售的竞争者。产品侧的解法同样务实——旗舰 Hy4 冲智力上限，Hy4 flash 专治"过度思考"、跑日常高频任务，端侧 Hy4-mini、Flash-Lite 及适配 24GB 显存/M5 Max 的小模型已在路线图上。

这提供了一个典型的"约束下决策"样本：在移动的前沿与不确定的供给之间，真正的问题不是"要不要做大"，而是资源花在哪里、为此接受什么代价、凭什么维持下一轮竞争。对 CTO 而言，盲目"更大即更好"是危险的默认值，分层模型策略（旗舰冲顶 + 轻量治高频 + 端侧降本）才是可持续的工程答案。

CTO 含义：建立"旗舰/主力/端侧"的分层模型组合，用轻量模型承接 80% 高频任务以降本提速；把"过度思考"当作后训练与推理调度的显性指标来治理；在算力受限时，优先投资于"单位算力产出"而非参数规模。

来源：硅星人Pro（姚顺雨在混元的取舍） · AI产品黄叔（AMA 实测） · 创业邦（小模型路线图）

Agent 运行时安全参考架构

Google Agent Compute Engine 用隔离 microVM 运行 Agent，支持 checkpoint 挂起/恢复，并把凭证、API key、OAuth 刷新令牌外置，由 Agent Gateway 鉴权后注入。这几乎给出了"Agent 不接触密钥"的标准架构模板。

Serverless GPU 的成本新模型

Agent 工具链工程化：Code Mode

Claude Code 实验性推出 Code Mode：把多步工具调用写成一段 JavaScript 由模型执行，命令可并行、输出可先过滤，工具返回大段内容时只把筛选后部分放进上下文。这是降低 Agent 上下文成本、提升工具编排效率的一个务实方向。

CTO 视角 · 行动建议

Action Items
  • 把算力当资本项来管理。建立长期合约 / 现货 / 自建 vs 租用的全周期 TCO 模型，评估 Ornn 类定价与对冲工具；提前规划多芯片、多区域、多供应商的供给弹性，别把"拿得到卡"当默认前提。
  • 制定分层的"模型主权"策略。界定哪些能力必须自训或私有化（数据敏感、可沉淀壁垒），哪些用闭源 API；同时开始把 Agent 执行日志当作训练资产治理——脱敏、留存、回流，为"企业自有模型"预留数据底座。
  • Agent 平台先建"三件套"再谈规模化。隔离沙箱（microVM）+ 凭证外置（Gateway 注入）+ 预算与权限治理（参考 GitHub 默认 10 美元 / 只读起步）。并立即审计开发团队 Claude Code 类工具的本地 settings 与 git 历史密钥泄露。
  • 守住"人能解释系统"的工程底线。不要让"问 AI"替代对故障链路的第一性理解；用可机器验证的思路（借鉴 Lean 形式化范式）提升关键路径的确定性，让评审与验证建立在可复核的事实之上。
  • 组织与人才要面向"AI + 行业 + 产品"的复合能力。AI 时代 PM 角色增长最快，Atlassian 反而加大 junior 招聘从 0 培养；建立分层梯队（旗舰专家 + 高潜新人）与内部 AI 工程文化培训，避免能力单点依赖少数"会问 AI 的人"。
  • 对"AI 单干"叙事保持理性。黎曼猜想案例的关键变量是人类数学家的数月指导与形式化社区的多工具交叉核验；把"独立检查器 + 多工具比对"的验证范式引入工程评审，对颠覆性叙事保持审慎押注。
