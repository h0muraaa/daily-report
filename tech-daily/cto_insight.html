深度 · 基建经济学

需求爆炸 vs 卖卡坍塌：AI 基础设施的价值正在“再分配”

同一天出现两个看似矛盾的信号——算力越缺越贵，卖算力的人却越跌越惨。矛盾背后是一次价值锚点的转移。

先看需求端：推理需求彻底引爆，谷歌模型 API 每分钟 Token 量达一年前的四倍多，连三年前的老 GPU 都在涨价。再看供给端：Neocloud 的营收同比仍在数倍增长，但股价腰斩再腰斩——因为它们的商业模式建立在“算力稀缺 + 大厂送订单 + 英伟达帮融资”的三重红利上。一旦大厂自建算力投产、供给缺口收窄，纯“转租 GPU”的中间层缺乏定价权，最后真正稀缺的只剩土地与电力。

价值正在向两个方向迁移：其一，向“单位任务成本”迁移。谁能把同样的投入做出更高的有效吞吐，谁就握有议价权。国内海光信息与清程极智联合发布的 PD 分离异构混推方案就是典型——把推理拆成 Prefill 与 Decode 两段，用国产海光深算 3 号吃算力的 Prefill、把有限高端卡留给吃带宽的 Decode，实测同等投入性能达高端同构方案的 3 倍以上，且一张高端卡都不多买。其二，向“端侧/本地”迁移：无界方舟以 50 人团队跑出超 2 亿元 ARR，并发布能在笔记本上运行的千亿模型，说明把推理成本从云端搬到端侧本身就是一门生意。 新智元 十字路口

对 CTO 的含义：算力决策的关键变量已从“有没有卡”变成“单位任务成本 + 供给弹性”。自建 vs 租用不再是非此即彼，而应按负载分层：Prefill 重活放性价比算力、Decode 放带宽算力、可下沉的推理放端侧。把预算从“囤算力”挪向“异构调度 + KV 缓存压缩 + 端云协同”，回报率更高。

Agent 治理缺口：企业 AI 最大的风险不在模型，而在“执行权的边界”

当模型从“回答问题”变成“替人办事”，架构的重心从 Prompt 转向身份、授权与责任链。

微软 Ignite 把 Copilot 抬到“工作操作系统”的位置，并在 Azure、Foundry、Entra、Defender 全线补齐 Agent 身份、治理与成本控制；阿里把“负责任的 AI”落成一套治理原则，牵头起草的 DTR（Deferred Token Response）规范草案已被 OAuth 工作组采纳，正面回答五个问题：谁发起、代表谁、被允许做什么、权限何时失效、跨 Agent/工具授权如何传递与还原。这不是学术洁癖——当 Agent 能跨工具调用、自主拆解目标，一个失控的授权就可能让“A 任务的权限去干 B 任务”。

风险也不只来自模型。Anthropic 对 58 家美国企业、66 次深访的报告揭示了“Claude 手榴弹”现象：少数重度用户随手把 7 页 AI 生成指令丢给 IT 或全公司，收件人要花十几分钟才搞清对方在说什么；有 CFO 拿到建立在过时假设上的 AI 财务预测；一位高管直言“一个平庸的工程师配上 AI，简直是社会公害”。效率暴增并没有均匀分布，而是把协作成本转移给了下游。治理要解决的不只是安全，还有“AI 产能如何被组织吸收”的问题。 阿里技术 爱范儿 创业邦

对 CTO 的含义：把“Agent 治理”前置进平台架构，而不是事后打补丁——统一身份与最小授权、跨工具调用的令牌传递与失效、全链路审计与责任还原、按 Agent/任务的成本护栏。同时为“AI 产能”设计吸收机制（结构化交付物、评审门禁、可观测指标），否则产能会以协作噪声的形式反噬团队。

CTO 视角

面向技术高管的五条行动建议
1

重算算力 TCO，按负载分层而非“囤卡”

把“自建 / 云租 / 端侧”当成一个分层调度问题：Prefill 走性价比算力、Decode 走带宽算力、可下沉推理走端侧。把预算向异构调度、KV 缓存压缩、PD 分离等“提效杠杆”倾斜，而不是单纯扩容量——在供给弹性下降的周期里，单位任务成本比拥有多少卡更决定竞争力。

2

把 Agent 治理前置进平台架构

建立统一的 Agent 身份、最小授权与令牌失效机制，支持跨工具调用的授权传递与全链路审计，做到“出错能还原责任链”。同步上线按 Agent/任务的成本护栏。别等出事后补丁——身份与授权是 Agent 生态的信任底座，也是企业敢把关键流程交给 AI 的前提。

3

重建研发质量护栏，而非死守逐行评审

逐行 Code Review 正在失效，把评审重心从“找缺陷”转向“知识共享 + 风险门禁”。用测试覆盖、可观测、自动化回滚、CI 门禁承接 AI 的吞吐，明确 RC/发布阶段的变更规模红线（别让 4 万行 AI 代码在 RC 期涌入）。产能不是问题，吸收产能的机制才是。

4

多模型策略，规避半年一代的锁定风险

模型商品化 + 半年一换代，意味着“绑定单一供应商”是战略级风险。用抽象层把模型能力解耦，按任务做成本/质量路由，持续跑评测以随时切换。价格战与能力追赶会持续，保留可迁移性是议价权的一部分。

5

组织为“结果”负责，重配人才与资源

当执行趋于免费，人的价值集中在选方向与配资源（判断力与品味），以及为结果负责——只为中间环节负责的岗位最脆弱。核心工程能力（如 Claude Code 班底被挖角所示）高度集中于少数人，需要靠文档化、平台化把个人能力沉淀为组织能力，并提前布局关键人才保留。
