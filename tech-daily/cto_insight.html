办公 Agent 三国演义：大厂赛马收拢背后的组织逻辑与选型窗口

晚点披露的细节值得技术高管细读：阿里 QTeam 原本计划与腾讯 WorkBuddy"正面竞争"，却在 7 月初突然接到整合通知——QoderWork 连人带代码划出，与钉钉孵化的悟空、阿里云内部创业的 MuleRun 一周内完成物理合并，由钉钉新任 CEO 陈宇森统一操盘，一个月后公测。字节的动作更激进：飞书产品团队整体并入豆包，销售、市场、客服并入火山引擎，飞书负责人谢欣承认"调整来得很仓促"——尽管 2025 年飞书收入仍在增长而钉钉已出现下滑。背后的判断是一致的：在 Agent 范式下，上一代协作套件（IM + 文档 + 审批）的护城河正在失效，先完成组织整合的一方才能集中弹药。

从产品形态看，千问办公把本地电脑操作、云端长任务、企业协作收进同一入口，支持钉钉/飞书/微信多 IM 接入，强调"可授权、可管理、可共享、可追踪"的企业级 Agent 工作台，直指 MIT 报告中"个人提效无法汇入组织"的痛点。市场数据也印证了战况：今年 6 月 17 款桌面办公 Agent 合计访问量突破 6000 万次，腾讯系占一半以上。对 CTO 而言，未来 6-12 个月是企业 Agent 选型的最佳谈判窗口——三家都在抢标杆客户，价格、定制化与数据主权条款都有空间。但选型标准应从"Demo 效果"转向：权限与审计体系、跨系统集成深度、任务失败的兜底机制，以及供应商自身的组织稳定性（本轮整合中被边缘化的团队与客户支持连续性，都是需要尽调的风险点）。

Token 经济学 · 成本治理

从"席位费"到"计量费"：Agent 时代的成本模型重构与 AI FinOps

本周两组数据放在一起看特别有张力：一端是 DeepSeek V4 Flash 把百万 Token 打到 1 元、单次 Agent 任务低至 0.0005 美元，Qwen3.8-Max 以 Opus 5 四成的价格提供相近档位智能；另一端是 JetBrains 自曝 AI 开支半年涨 10 倍且"不知如何系统控制"，Karpathy 用 Opus 5 做一个 3D 游戏 Demo 就烧掉 100 万 Token 预算（约 10 美元），一句提示词跑出 6.9 亿 Token、费用近 3000 元的案例也不再罕见。原因相同：Agent 工作方式把"一次问答"变成了"读文件、改代码、跑程序、自查、重试"的长循环，单次任务的 Token 消耗可翻几十到几百倍。

这意味着两件事。第一，模型选型逻辑变了：衡量单位从"单次回答多聪明"变成"完成一项长任务花多少钱、失败几次"。便宜模型 + 多次重试在数学上常常优于昂贵模型一次做对，DeepSeek 的"斩杀线"正是斩在这个拐点上——被压抑的 Agent 需求会因低价瞬间释放（OpenCode 上线 V4 Flash 后使用量单日涨 30%）。第二，成本治理必须工程化：JetBrains 的教训是"员工自选 3-5 款工具 + 无计量"必然失控。建议 CTO 尽快建立三道闸门：统一模型网关（带 BYOK、fallback、成本归因到团队/任务）、Agent 任务的预算与熔断机制（单次任务 Token 上限、夜间批量任务调度）、以及按"任务完成成本"而非"Token 单价"核算的 ROI 仪表盘。AI FinOps 将和当年的云成本治理一样，从可选项变成财务纪律。

MiniMax H3 开源：视频生成的"DeepSeek 时刻"，商用内容生产链面临重估

MiniMax 正式开源通用多模态生成模型 H3（33B）：支持 2K 分辨率、原生立体声、最长 15 秒视频，全模态输入（最多 9 图 + 3 视频 + 3 音频联合参考），复杂文字渲染与影视后期场景表现打平甚至局部超过同期发布的字节 Seedance 2.5。价格是真正的杀器——2K 分辨率下每秒约 8 毛钱，为竞品的三分之一；华为、摩尔线程、沐曦、英特尔等十几家厂商同日发布 Day 0 适配，消费级 RTX 5090/6000 已验证可本地运行。

组织变革 · 人才结构

Anthropic 内部 90% 代码由 Claude Code 编写，团队分化为五种新角色

Anthropic 的 Boris 披露：公司内部平均 90% 的代码已由 Claude Code 编写，他本人自去年 11 月起为 100%。更值得关注的是组织侧判断——"前端/后端/产品/设计"的传统分工已经过时，团队实际分化为五种角色：原型师（快速试错）、构建者（把原型做成产品）、维护者（守住规模化系统）、扩展者（把跑通的产品放大 10-100 倍，目前在 Anthropic 最抢手）、收尾人（打磨细节）。与此同时，DevOps 之父 Patrick Debois 在 InfoQ 访谈中强调：员工用不好 Agent 是公司的锅——"不要再去修 Agent 产出的代码，要去修那个产出代码的系统"，AI 转型不是发几个 Claude Code 账号，而是围绕 Agent 重新组织团队、平台与协作方式。

腾讯研究院的文章提供了冷思考的另一半：2025 年美国直接归因于 AI 的裁员超 5.5 万人，亚马逊两轮裁 3 万且集中在 L5-L7 中层，Block 在盈利状态裁掉 46%——但 AI 并不自动带来超级组织，它也可能只是管理层为旧问题换的体面说辞。对 CTO 的启示：招聘画像（极致用 AI + 扎实工程功底 + 愿意分享）、中层管理者的新职责（修系统而非修代码）、以及"哪些功能允许完全自治"的风险分级，都需要在组织图上明确回答，而不是停留在口号。

Databricks 完成收购 Panther：数据平台正式吞噬安全分析赛道

Databricks 宣布正式完成对云原生 SIEM 厂商 Panther 的收购，加速"安全 Lakehouse"战略。传统 SIEM 市场（Splunk、Sentinel 等）长期受困于数据孤岛与按量计费的高成本，而 Lakehouse 架构天然适合安全数据的统一存储与 AI 驱动的威胁检测。同期 Databricks 还 GA 了 Variant 半结构化数据类型，进一步强化数据摄取能力。

工程边界 · 可靠性

AI 用 Rust 重写 Postgres：通过 4.6 万条官方测试，却被模糊测试一下午击垮

两名工程师用 AI 在几个月内以 Rust 重写了完整的 PostgreSQL 引擎（解析器、规划器、执行器、存储、事务与并发控制），成本约十万美元，且磁盘格式与 Postgres 完全兼容。它通过了超过 4.6 万条官方回归测试与隔离测试——随后在同一批用于 Postgres 内部挖洞的工具下，模糊测试运行一下午就崩溃了。对照组是 Postgres 四十年的工程投入：补丁层层累积、生产灾难换来的修复、成千上万贡献者。

这个案例是当前 AI 编码能力最诚实的标尺：测试套件证明"符合规范"，模糊测试暴露"未经岁月"。对 CTO 而言，它印证了 DevOps 之父本周的忠告——AI 生成代码的验证体系必须超越"测试通过"，覆盖模糊测试、故障注入与长周期浸泡测试。在核心基础设施层，AI 生成代码的采纳应与风险分级挂钩：前端与内部工具可以激进，数据层与支付层必须保守。

CTO 视角 · 行动建议

  • 启动企业 Agent 选型谈判，但尽调供应商组织稳定性：三巨头办公 Agent 刚完成整合、正抢标杆客户，未来 6-12 个月是价格与定制条款的最佳窗口。评估重点是权限审计体系、跨系统集成深度、失败兜底机制；同时关注供应商团队动荡对客户支持连续性的影响。
  • 把 AI FinOps 列为 Q3 必修课：参考 JetBrains 的教训，立即盘点全员 AI 工具使用与开支，统一模型网关并落实成本归因到团队/任务；以"任务完成成本"（含重试与失败率）而非 Token 单价评估模型选型，低价开源模型 + 多次重试在多数场景已具备经济性。
  • 建立模型宣传的独立验证机制：Astra 之争表明头部厂商 PR 与科学之间距离不小。任何影响架构决策的能力声明（数学、自主编程天数、榜单排名），都应要求可复现的第三方评测或内部 Eval 集验证，避免基于营销叙事做技术押注。
  • 按风险分级采纳 AI 生成代码：pgrust 案例证明"测试通过 ≠ 生产就绪"。制定明确的分级策略：前端、内部工具、原型可以激进；数据层、支付、合规相关系统必须叠加模糊测试、故障注入与人工评审。同时回答组织问题：哪些功能允许 Agent 完全自治，哪些保留"微光"。
