Anthropic 创下商业史三大纪录，AI-native 组织形态浮出水面

Anthropic 年化收入从 100 亿美元飙升至 400 亿美元（4 月数据），预计年底突破 1000 亿。全公司仅 3000 人，人均产值超 1000 万美元。更值得关注的是其组织形态：内部 agent 通过 Slack 实时协作，员工不再手写 SQL 和业务代码。Claude Code 负责人 Boris Cherny 透露，前六个月几乎无人使用，Opus 4 上线才是真正的转折点。这意味着模型能力阈值是 AI-native 组织落地的先决条件，而非工具本身。

Perplexity 开源 Agent Skill 设计手册，重新定义"技能"本质

Perplexity 公开了内部构建 agent skill 的完整方法论，核心反直觉：写 Skill 不是写代码，而是为模型构建上下文。Skill 是目录（SKILL.md + scripts/ + references/ + config.json），是格式，是隐式模式匹配 + 渐进披露。这与传统软件工程的"简单优于复杂"完全相反——Skill 的复杂性本身就是特性。对 CTO 的启示：AI 时代的工程范式正在从"写代码"转向"写上下文"，团队技能栈需要重新评估。

来源：Perplexity Research、meng shao

美国五大 AI 实验室全部纳入联邦安全审查体系

NIST 下属的 AI 标准与创新中心（CAISI）与 Google DeepMind、微软、xAI 签署新协议，加上此前已签约的 Anthropic 和 OpenAI，美国五大 AI 实验室全部纳入联邦政府的"模型上线前安全审查"体系。这实际上用"国家安全"名义将评测从自愿变为事实强制，并以更高标准的联邦规则架空了加州等地的州级监管。对全球化布局的技术公司而言，合规成本将显著上升，安全评测能力本身也可能成为新的竞争壁垒。

OpenAI 翁家翌提出"手搓策略"新范式：不更新参数也能强化学习

OpenAI 后训练工程师翁家翌公开了一组实验：让 Codex 反复编写策略代码、运行环境、读取日志、定位失败、修改代码、补充测试，多轮迭代后"养出"纯 Python 程序化策略，在 Atari Breakout 中打到理论满分 864 分。核心洞察：在明确目标、可运行环境和反馈闭环中，AI 可以通过"自主改代码"而非"训练模型参数"变强。这为强化学习的工程化落地提供了全新路径——不需要昂贵的梯度更新，只需要高质量的代码-执行-反馈循环。

来源：腾讯科技、量子位

中国 AI 生态观察：缺算力是共识，协同而非敌对

组织变革

AI-native 组织的到来：从 Anthropic 看技术团队的范式转移

Anthropic 内部已经实现了 AI-native 协作：所有员工通过 Slack 与各自的 Claude agent 实时协作，agent 之间互相沟通协调，无人手写 SQL 和业务代码。负责人 Boris Cherny 揭示了一个被忽视的关键事实——Claude Code 前六个月几乎无人使用，Opus 4 上线才是真正的转折点。

这揭示了一个重要的 CTO 决策逻辑：AI 工具的普及不取决于工具本身，而取决于底层模型能力是否跨过可用性阈值。 当模型能力足够强时，组织形态会自然发生蜕变。TypeScript + React 因训练数据最丰富而率先被"解决"，冷门技术栈只需等待模型能力的泛化。

更深层的战略含义是：大公司在流程重塑和文化转型中受困，而初创公司从第一天就能以 AI-native 构建，起点即是大公司五年后的终点。玉伯（Frank Wang）的论断"AI 应用的终局是 SaaS"值得 CTO 们深思——只要运行时在云端，SaaS 模式就依然成立，哪怕本地 Agent 存在，它背后的那根线仍然通向云端。

对技术高管的行动建议： 评估团队当前工作流中哪些环节已经达到"模型可替代"阈值，优先在这些领域推动 AI-native 改造；同时关注 TypeScript/JavaScript 生态中的 AI 工具成熟度，这是当前投资回报最高的技术栈。

竞争格局

中国 AI 的第二增长曲线：工程效率 vs. 算力瓶颈

百度 ERNIE 5.1 的发布展示了中国模型厂商在效率优化上的极致追求：总参数压缩到原来的约 1/3，激活参数约 1/2，预训练成本仅为同规模模型的约 6%，却在 τ3-bench、SpreadsheetBench-Verified 上超越 DeepSeek-V4-Pro，Arena Search 全球第 4、中国第 1。蚂蚁集团也推出了旗舰级思考模型 Ring-2.6-1T，主打复杂任务执行与生产环境应用。

与此同时，Nathan Lambert 的实地走访揭示了一个关键结构性约束：中国 AI 实验室普遍面临算力短缺。应对策略是"极度努力工作 + 更早更快推进产品化"。这意味着中国 AI 的竞争逻辑正在从"大力出奇迹"转向"效率优先"——在受限的资源约束下，通过工程优化和组织效率来缩小与前沿的差距。

腾讯 Hy3 在 OpenRouter 免费试用期间取得了总 token 使用量、编程和工具调用三项第一，15.4% 的市场份额。这表明中国模型在开发者工具链中的渗透率正在快速提升。阶跃星辰的 StepAudio 2.5 TTS 也跻身 Artificial Analysis 全球前三、中国第一。

对技术高管的行动建议： 如果团队在使用海外模型 API，建议评估中国模型的性价比方案（如 ERNIE 5.1、Hy3、Ring-2.6-1T），在合规允许的前提下进行 A/B 测试；同时关注 Token 成本控制的新趋势，参数效率正在成为模型选型的核心指标之一。

Token 经济基础设施化

中国移动发布 Token 运营体系，试图建立 AI 时代的"银联"——统一计费、统一结算、统一鉴权，推动跨模型、跨生态的 Token 统一换算。这标志着 Token 正在从模型内部的技术概念演变为行业级的经济基础设施。未来企业的 AI 成本核算将需要适配这种标准化体系。

语音 Agent 的"Her 时刻"尚未到来，但基础设施已就绪

ElevenLabs 的 Voice Engine、Mistral 的开源 TTS 模型、阶跃的 StepAudio 2.5 系列，以及 GPT-Realtime-2 的实时翻译能力，共同推动语音 Agent 从 demo 走向生产。但 Gradium AI CEO Neil Zeghidour 的坦诚分析指出：级联系统的工具调用延迟可达 500ms-4 秒，而人类总响应时间约 200ms。端到端语音模型是方向，但半双工问题（只能听或说，不能同时进行）仍是瓶颈。

★CTO视角 · 行动建议

本周值得推进的三件事

  • 评估团队 AI-native 就绪度： 识别当前工作流中已经达到"模型可替代"阈值的环节（如 SQL 查询、数据报表、代码审查），制定 30 天试点计划。优先选择 TypeScript/JavaScript 技术栈，这是当前模型能力最强的领域。
  • 重新审视模型供应商策略： 在 OpenRouter 等路由平台上测试中国模型（ERNIE 5.1、Hy3）与主流模型（Claude、GPT-4o）在真实业务场景中的性价比差异。将"参数效率"纳入模型选型评估矩阵。
  • 建立团队 Skill/上下文资产库： 参考 Perplexity 的 Skill 设计方法论，将团队的核心领域知识、工作流程和决策逻辑从"人脑+文档"迁移为"模型可消费的上下文格式"。这不是一次性项目，而是持续复利的技术资产。

值得关注的三个信号

  • 监管合规提前布局： 美国联邦安全审查体系已覆盖五大实验室，中国相关政策也在加速跟进。如果业务涉及模型训练或部署，建议提前建立内部安全评测能力，避免政策突变时的被动应对。
  • 算力成本结构变化： 百度 ERNIE 5.1 以 6% 的预训练成本实现同级性能，预示着模型训练的成本曲线可能比预期更陡峭。关注 MoE、参数压缩、异步 RL 等技术的成熟度，它们可能在未来 12 个月内改变算力采购策略。
  • Agent 工作流的基础设施缺口： Cloudflare Dynamic Workflows、Trigger.dev（YC 孵化）等产品正在填补"长期运行、可恢复、可观测的 Agent 执行引擎"这一基础设施缺口。如果团队在构建 Agent 产品，避免重复造轮子，优先评估现有方案。
