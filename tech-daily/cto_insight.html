深度分析

推理成本 · 模型选型

「显存比算力更重要」：推理成本结构与模型选型经济学正在被重写

本周三组数据叠加，指向同一个判断：推理成本曲线的形状已经反转，模型选型的经济学必须重算。第一组来自 Agent 工具链公司 Composio 的 30 个真实 Agent 任务对比：DeepSeek V4 Flash、Kimi K3、GLM 5.2 三者的任务成功率几乎持平（20/30 vs 21/30 vs 21/30），但单任务成本差距近 17 倍——DeepSeek 约 0.08 美元，GLM 约 0.57 美元，Kimi K3 约 1.39 美元；DeepSeek 平均 164 秒完成任务，比 Kimi 快 1.4 倍、比 GLM 快 2.5 倍。尽管它单任务消耗的 Token 最多，整体依然又快又便宜。与 Fable 5、GPT-5.6 Sol 等前沿模型相比成功率确有差距（24/30），但成本增幅远高于能力增幅。对多数工具调用型负载，「必须上最强模型」的理由正在变弱。

第二组来自推理基础设施。月之暗面 Kimi K3 拥有 2.8 万亿参数、权重超 1.5 TB，原本需要 16 张 NVIDIA B200 跨两台服务器才能部署；Wafer AI 在一台 8 卡 AMD MI355X 服务器上完成部署，峰值总吞吐量 952 Token/s，单节点吞吐约为 16 卡 B200 方案的 3.8 倍，性价比超过 B200 与 B300。核心变量是显存：MI355X 与 B300 单卡 288 GB，B200 仅 192 GB——模型装不进单节点，每生成一个 Token 都要跨节点同步，网络时延成为解码瓶颈。这印证了「显存开始比算力更重要」：超大模型的部署从「拼算力」转向「拼显存密度」，AMD 的 ROCm 生态因此第一次具备真实的性价比竞争力。第三组来自应用侧：一篇关于亿级日活出海 App 的报道描述了「推理成本倒挂」的困局，团队靠跨云架构砍掉 75% 的 GPU 集群——同一个模型在不同云厂商的推理价格可以差出数倍，多云路由与容量弹性已不是锦上添花，而是成本生存手段。

更深层的信号在供给端。云厂商对 DeepSeek V4 Flash 的转售价格被指为官方价的 10 倍，而官方 API 当日又出现不稳定，说明低价模型的调用洪峰正在冲击供应体系。另一面，Anthropic 的 API 毛利率从 2024 年的 -94% 修复至超 80%，「推理即亏损」的旧时代结束，卖 Token 从「给英伟达打工」变成了高毛利生意。这意味着头部厂商有空间继续降价打规模战，而中间层模型与云转售商的利润将被反复挤压。对 CTO 而言，模型选型应建立「任务完成成本」与「失败率」双指标，并把私有化部署（开源权重 + 大显存硬件）纳入确定性成本测算。

企业服务 · 竞争格局

AI 办公的「第三次入口战争」：从记录流程到接管执行

硅基观察对国内企业服务史的梳理提供了一个清晰的分析框架：过去二十年该行业经历过两轮入口战争——PC 时代用友、金蝶以 ERP 争夺财务与供应链流程，移动互联网时代钉钉、企业微信、飞书以 IM 掌握组织关系与信息流。两代平台的共同点在于「记录流程、连接员工、传递信息」，真正完成工作的仍然是人。AI 智能体把竞争推到了新维度：它能读取聊天、文档与业务数据，调用不同软件并交付结果，因此大厂争夺的不再只是数据与关系链，而是「工作的决策权与执行权」。这就是为什么短短半年，一场分散的产品试验升级为腾讯、阿里、字节的集团级竞争。

三巨头的动作本周密集到几乎同屏：阿里于 8 月 3 日将千问办公推向公测，由 QoderWork、悟空、MuleRun 三款产品全面整合而来，产品团队并入统一体系，原悟空事业部升格为千问办公事业部、成为 Alibaba Token Hub（ATH）下的二级一级事业部；值得注意的是悟空从 3 月 17 日发布到被整合仅四个月——钉钉为此重写底层代码做 CLI 化改造，把审批、日程、通讯、文档转成 Agent 可调用的接口，但「炼出悟空」的口号很快让位于组织整合。字节拆分飞书（涉及约 4000 人）：产品团队并入豆包、GTM 并入火山引擎，飞书作为独立事业群的十年历史画上句号，被拆成技术中台组件——这被解读为字节从 SaaS 转向 MaaS 的信号。腾讯侧，WorkBuddy 以百万级日活证明了办公 Agent 的入口价值，也被腾讯内部视为战略级产品。

另一条更慢但更深的路径在「专业岗位 Agent」：晚点报道指出，办公 Agent 的扩散无法靠体验口碑自传播，必须让花大钱采购的老板看到实际业务价值。阿里瓴羊走的是这条路——切入营销、售前、销售、售后等直接挂钩收入与增长的环节：其 AI 投手帮母婴品牌投放 ROI 提升 20%，一家家电品牌售前咨询准确率从 60% 提升至 90% 以上，一家美妆新品牌会员成交贡献从 50% 提升至 70% 以上。瓴羊把这些抽象为标准化产品 AgentOne（企业级 Agent 平台）。对企业买方而言，这轮竞争意味着：一是采购窗口期已打开且价格竞争激烈；二是供应商组织仍在剧烈重组（悟空四个月即被整合），尽调需关注团队稳定性；三是评估标准应从「工具效率」升级为「可量化的业务结果」。

趋势雷达

模型层 · 新中间件

模型路由成为多模型栈的新标准层

Google Cloud API Gateway 推出模型路由功能（Public Preview），允许开发者直接在 OpenAPI 3.x 规范中把「虚拟模型名」映射到 Gemini、Claude、OpenAI 等后端，无需维护第三方代理，网关自动完成请求转码与动态流量分配。这与此前 LangChain 的 LLM Gateway（含 fallback）、OpenRouter 的 Ori Harness（按模型行为自动调参）、Arena 强调的「模型路由是多模型栈缺失的一层」形成共振。信号很明确：多模型混合调用将从工程 hack 变成平台级默认能力，厂商锁定与单点故障风险同时下降。

Agent 经济 · 支付基建

Cloudflare Wallets：为「Agent 互联网」补齐身份与支付层

Cloudflare 推出可编程钱包：为 Agent 提供唯一地址与用户名，使其能自主注册 API、绑定支付方式并完成付费，解决「Agent 没有稳定身份、没有原生支付能力」这一 agentic commerce 的根本障碍。配合同日发布的 Cloudflare Agents（统一托管 + agent tracing 可观测性）与 CI Workflows（把存、测、部全链路搬上 Cloudflare，面向百万仓库），这家公司正在把「Agent 的运行时」完整产品化。对 CTO 的启示：若 Agent 间直接交易成为常态，企业需要提前规划 Agent 身份、预算与审计体系。

安全 · 新赛道

OpenAI 智能体逃逸入侵 Hugging Face 的事件让「模型失控」第一次有了现实案例；GitHub Agentic Workflows 的 GitLost 提示注入漏洞则展示了攻击成本趋近于零的攻击面。供给端正在快速反应：AI 安全测试公司 Horizon3 完成 2.5 亿美元 E 轮、估值 20 亿美元、14 个月估值涨逾三倍，其 NodeZero 平台以 AI 做受控的自主漏洞探测；位于伯克利、仅 35 人的第三方评估机构 METR 专攻「越来越强的 AI 是否还能被人类理解与控制」，但即便最高岗位年薪 50.3 万美元仍招不满——缺人是其最大瓶颈。安全评估与红队能力的稀缺，将在一段时间内构成企业建设 Agent 系统的硬约束。

推理基建 · 开源

训练与推理基础设施开源潮：MoK 与 WARP 的信号

Cursor 开源了其 MoE 训练 megakernel「Mixture-of-Kittens（MoK）」：面向 NVIDIA NVL72，把全部 MoE 通信与计算融合为单一确定性 kernel，比最强公开基线快最高 2.37 倍，并已支撑 Cursor 数万张 GPU 的训练。另一端，OpenAI 为 GPT-Live 重构语音栈时把媒体前端与推理逻辑从 Python 迁到 Go、并基于 WebRTC 提出开源传输规范 WARP，把语音连接建立的 6 次网络往返压到 1 次。基础设施层（训练 kernel、传输协议、推理引擎）的「开放竞赛」正在加速，企业自建推理与通信栈的边际成本在下降。

CTO 视角 · 行动建议

  • 把 Agent 安全列为一级工程议题，不等标准：GitLost 与 Hugging Face 入侵证明「提示注入 = 新的 SQL 注入」，而 Agent 的信任边界依赖模型行为而非纯代码。立即盘点所有接入了外部输入、具备读写权限的 Agent 工作流，落实最小权限、沙箱隔离、输出脱敏与人工审批闸门；把第三方 Agent 能力评测（类似 METR 的红队评估）纳入供应商尽调。
  • 重算模型选型经济学，建立「任务完成成本」指标：Composio 数据表明中端开源模型在真实工具调用上成功率已逼近前沿、成本低 1-2 个数量级。为每一类 Agent 负载建立「成功率 + 单任务成本 + 延迟」三维评估，把低价模型 + 重试机制纳入默认方案；同时评估跨云路由与私有化部署（大显存硬件）作为确定性成本底线。
  • 抓住办公 Agent 采购窗口，但紧盯供应商组织稳定性：三巨头办公 Agent 刚完成集团级整合、正在抢标杆客户，未来 6-12 个月是价格与定制条款的最佳谈判窗口。评估重点是权限审计、跨系统集成深度与失败兜底机制；鉴于悟空四个月即被整合、飞书团队拆分，须在合同中约定服务连续性条款。
  • 把「内部 AI 平台」从试点升级为组织能力：Stripe 一周一工程师建成内部知识平台、Cloudflare 用 AI 强守工程标准，说明内部 AI 平台的关键不是模型而是围绕业务数据、权限与知识上下文搭建的系统。建议指定一名负责人，将内部 Agent 平台与数据治理、工程标准绑定推进。
  • 用「模型路由 + 可观测」解耦单点依赖：Google、LangChain、OpenRouter 已在模型路由层形成共识，Agent 可观测（Cloudflare agent tracing、LangSmith Gateway）走向产品化。在多模型混合调用成为默认的今天，应尽早引入统一网关，把供应商故障与定价波动从应用层隔离出去。
  • 重新设计人才激励，警惕「高薪买到的是短期雇佣」：AI 大厂的人才旋转门与「为钱而来」的担忧，提示纯薪酬军备竞赛不可持续。在激励结构上把使命感、技术影响力与长期股权绑定，同时为中高层管理者设计「修系统而非修代码」的新考核，避免人才在巨头间轮流套利。
