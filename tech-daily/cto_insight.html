2 个重要话题

① Harness 层竞争：模型差距收窄，执行层成为新的技术制高点

今天的核心信号是：前沿模型的"智商差距"正在快速抹平——V4 Pro 距 Fable 5 仅 0.1 分、Grok 4.6 与 GPT-5.6 Sol 持平，开源与闭源的性能鸿沟被压缩到个位数百分点。当模型本身不再构成绝对壁垒，竞争制高点就从"模型能力"移向"Agent 执行层（Harness）工程"。DeepSeek 直接开源 Harness，把执行层产品化；晚点专访华为前大模型负责人王云鹤，其创业方向正是 Agentic Routing（逐轮为任务挑选模型的 OpenSquilla），核心判断是"顶尖模型会吞噬一切"的质疑下，路由与编排仍有长期空间。

量化证据：坏的 Skill 会拖垮 Agent，好的执行层能省一个数量级

微软与同行的一篇新论文把 307 个 Agent 失败归因到具体加载的 Skill——125 个功能失败、182 个效率回退，且成本回退并非来自提示词长度，最大来源是过度校验（67 例）与重型实现流水线（30 例）。OpenAI 的企业数据同样指向执行层：Top 10% 企业使用插件的频率是普通企业的 2 倍、使用 skills 的频率是 6 倍。InfoQ 对 Claude Code 团队的拆解则点明，2026 年的核心转变是"从把信息输入模型，转向把信息从模型输出给用户"，定制化即知识，钩子是唯一真正可扩展的插件抽象。判断：未来一年，Harness 的工程能力（上下文压缩、缓存命中、技能治理、权限审批）将比模型选型更直接地决定你的 Agent 化改造是省成本还是烧钱。

Agent 负载正在重写推理的成本结构。Z Potentials 的深度报道指出，NVIDIA 在 GPU 显存与通用共享存储之间划出编号 G3.5 的专属存储层（由 BlueField-4 与 NVMe 闪存承载，配套 CMX 平台），专门存放可复用的推理上下文——这是存储第一次在 AI 架构定义中拥有独立层级，原因是 Agent 一次任务要跨越数十次模型调用，KV Cache、向量索引、MoE 专家权重被反复交替动态访问，GPU 在等数据已成为最大的算力浪费。与此呼应，SemiAnalysis 援引 SpaceX 首次财报电话会称其 2027 年仅数据中心就要新增 6-8GW 容量、甚至可能超过 10GW，并有一条通往 3000 亿美元 ARR 的路径；而经纬创投转载的分析则提出警示：AI 基础设施正依赖越来越像房地产开发模式的债务结构，GPU 折旧快、债务扩张跑得比现金流更快，"AI 盛世下的暗雷"指向下一次级债危机。

判断：定价开始分层，成本治理从"选模型"变成"调系统"

三大信号同时出现：DeepSeek 预告 8 月 17 日峰谷定价（缓存命中输入涨约 12 倍、输出涨约 4.5 倍），Gemini 3.7 Flash 直接半价，OpenAI 则用 Cerebras 提速 14 倍卖"速度档"。傅盛的评价很有代表性——V4 Pro"性能接近顶流、价格只有 Fable 5 的 1/57"，性价比斩杀线被再次拉高。对技术决策者而言，推理成本已经不是"选哪个模型"的单选题，而是"缓存命中率 + 峰谷调度 + 速度档位 + 存储路径"共同决定的系统级优化。单卡价格持续攀升的背景下，任何数据未就绪导致的计算中断都是实打实的浪费，企业需要把推理链路当作与数据库同等重要的基础设施来治理。

CTO 视角

行动建议

给技术高管的五条行动建议

  1. 重算推理成本曲线，把"缓存命中率 + 峰谷定价"纳入预算模型。 DeepSeek 8 月 17 日起缓存命中输入价上调约 12 倍、输出上调约 4.5 倍，说明"地板价"不可长期依赖。为生产链路预留多供应商路由与降级策略，别把关键路径绑定在单一低价供应商上。
  2. 在 Agent 执行层（Harness）建立评估与治理基线。 DeepSeek Harness 开源让选择变多，但 0.1 仍是开发者预览；微软技能库论文证明"坏 Skill 会拖垮 Agent"。技能与插件的引入必须有评估、回收与版本管理机制，别让无治理的 Agent 在裸环境中扩张。
  3. 办公 Agent 进入生产前，先定权限、审计与数据边界。 WorkBuddy 等产品已把 Agent 放进 Word/Excel/审批流程，模型与工具可以快速接入，但账号权限、数据隔离、操作留痕必须先行，否则一次越权调用就是一次合规事故。
  4. 把"推理数据路径"纳入基础设施规划。 NVIDIA G3.5/CMX 把可复用推理上下文做成独立存储层，Agent 负载对 KV Cache、向量索引、记忆的访问模式将决定推理延迟与成本。与云厂商核对缓存与存储架构，评估是否需要为高复用上下文单独做缓存层。
  5. 重新评估推理链的安全边界。 思维链可被注入重放复现、沙盒逃逸与隐藏指令攻击并存。敏感提示词与内部代码一旦进入推理 token 即视为可泄露，需在 LLM 网关层增加推理轨迹审计、敏感信息剥离与密钥轮换，并复核供应商 API 的加密推理实现。
