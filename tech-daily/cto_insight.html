过去 24 小时的主线不是“又一个更强的模型”，而是 竞争坐标轴的切换：从“谁的模型最聪明”转向“完成一个真实任务要花多少钱”。OpenAI 用 GPT‑5.6 三档分层 + ChatGPT Work + Codex 合体打出一套企业 Agent 组合拳；xAI 的 Grok 4.5 与 Perplexity 的编排模型则把“接近前沿、价格打骨折”变成了正面进攻。与此同时，harness / sandbox / eval 这一层正在取代模型本身，成为新的护城河与新的战场。

01今日要点

① “每任务成本”成为新的竞技场，模型价格战正式开打
OpenAI 把 GPT‑5.6 拆成 Sol / Terra / Luna 三档（旗舰、平衡、低成本），Sam Altman 明言“5.6 是 dollars‑per‑task 的一大步”；同一天 xAI 发布 Grok 4.5，主打“接近 Opus 级、成本降低约 90%”；Perplexity 则放出基于 GLM 5.2 后训练的编排模型，号称 0.344× Opus 成本达到近前沿水平。Benchmark 的 Peter Fenton 在 CNBC 抛出一个判断：未来 18–24 个月，90%+ 的 token 可能来自开放权重模型，前沿模型毛利承压。
② OpenAI 把“超级 App”重写为 Agent 工作台：ChatGPT Work + Codex 合体
ChatGPT Work（由 Codex 与 GPT‑5.6 驱动）可跨应用/文件执行长达数小时的任务；Codex 并入新版 ChatGPT 桌面端（macOS/Windows），新增 inline 编辑、侧栏 PR review、多 repo；外加 Hosted Sites 与全双工语音模型 GPT‑Live。生态当日接入：GitHub Copilot、Cursor、Devin、Windsurf、Lovable、Figma Make、Notion、Vercel、OpenRouter。这是 OpenAI 对 Anthropic Cowork/Claude Code 的正面回应，也是把“超级 App 1.0”升级为“超级 App 2.0”的押注。
③ Meta 重新入场：Muse Spark 1.1 + Meta Model API，竞争回到“五极”
扎克伯格三年来首次回到 X 发推，亲自带货 Muse Spark 1.1：强 agentic/编码、低价、1M 上下文、计算机使用、可编排多 Agent 优化端到端延迟，并开放 Meta Model API 公测。多位从业者评价“接近 GPT‑5.5 / Opus‑4.8”。Peter Yang 的判断代表共识：从 2 家竞争变成 5 家竞争（OpenAI / Anthropic / Google / xAI / Meta），订阅价格与创新节奏都会因此更健康。
④ Agent 工程化栈成为真正的产品：harness、outer loop、eval、sandbox
翁荔详解 Harness Engineering、Addy Osmani 提出 “Own the Outer Loop”（工程师必须守住 Agent 的边界与后果）、业界流行 Executor‑Advisor 模式（贵模型当顾问、便宜模型执行）；与此同时 SWE‑Bench Pro 被曝约 30% 任务存在致命缺陷、OpenAI 撤回推荐，eval 可靠性亮红灯。基础设施侧，Google Cloud Run sandboxes 公测、Modal 提出 Agent‑Native Cloud（DX→AX）、AWS 增强 SageMaker HyperPod 可观测性——“给 Agent 一个安全、可观测、可弹性的运行环境”正在产品化。
⑤ 资本与组织的同步重估：Ollama 65M、Prime Intellect 1.3 亿；NVIDIA 两月蒸发万亿
Ollama 完成 $65M B 轮（仅 14 人、890 万开发者、85% 财富 500 强在用）；全栈 Agent 平台 Prime Intellect 融资 $1.3 亿、估值 $10 亿、ARR 破 $1 亿。另一端，邦早报援引睿兽数据：英伟达市值不到两月蒸发 1 万亿美元、估值回到 AI 热潮前水平；中国部分大模型比美国便宜 90%。硬件/存储进入超级周期，Mac 与 Xbox 被迫涨价、Pixel 取消 128GB。组织侧，Instagram 的“4–6 个通才工程师 + product staff”正在成为 2026 产品团队新模板。

02深度分析 · 一：定价权迁移——从“智商税”到“每任务成本”

本周最锋利的信号不是某个模型刷榜，而是三家同时把叙事从“能力上限”切到“单位经济”。这是企业采购语言，意味着大模型开始真正进入可核算、可比较、可被 CFO 问住的阶段。

战略OpenAI：用分层定价把“ frontier 智能”商品化

GPT‑5.6 不是一个模型，而是一组价格/延迟/能力的梯度：Sol（旗舰，长程编码与 agentic、网络安全、科学）、Terra（≈GPT‑5.5 水平、约一半成本）、Luna（高吞吐低延迟、成本不到一半）。Altman 与 Brockman 反复强调同一句话——“在任意目标性能上提供最优价格，同时把性能天花板推到最高”。配套数据点：前沿级智能低至 $1/百万输入 token、$6/百万输出 token、750 tok/s，约 10 秒产出一个真实 PR；模型发布节奏从 15 个月压缩到约 6 周。

Perplexity 在 Computer 中放出研究预览版 orchestrator 模型：基于 GLM 5.2 后训练，专为 harness 内执行优化，0.344× Opus 成本达到近前沿表现；内置 advisor 工具，必要时才升级到前沿贵模型。Arav Srinivas 给出长期判断——“正确的做法是后训练开源/前沿模型，使其学会在已部署到数百万用户的 harness 内按需升级；Perplexity 独特地处于解决这个问题的位置”。他们在美国 B200 上自托管，并计划后训练 Nemotron 3 Ultra，把同等能力搬到“美国开源模型”上。

CTO 读法：三股力量同时把“token 价格”压成竞争主轴——闭源分层（OpenAI）、低价进攻（xAI）、开源编排（Perplexity/Ollama/Fireworks）。再叠加 Benchmark“18–24 个月 90% token 来自开放权重”的判断，前沿模型的定价权正在下沉。对你的含义：不要把模型采购当成“押一个最强者”，而要建成可在多档/多供应商间路由的成本‑能力路由层，并把“每任务成本（cost‑per‑resolved‑task）”作为一等指标纳入 FinOps。

03深度分析 · 二：真正的产品不是模型，是 Agent 工程栈

当模型趋同且价格下行，差异化上移到 harness（编排外壳）、outer loop（边界与问责）、eval（评测）、sandbox（安全运行） 这一层。本周这一层从“圈内黑话”变成了成体系的产品与方法论。

工程范式Harness Engineering 与“Own the Outer Loop”

翁荔系统拆解了 Harness Engineering——AI 自我改进的新路径，核心是把模型放进一个由工具、记忆、验证器、循环构成的外壳里持续迭代；Addy Osmani 的 “Own the Outer Loop” 则强调：Agent 带来杠杆，杠杆带来问责——必须有人能说清楚“改了什么、为什么安全、错了会怎样”，否则组织根本不会采纳。社区已成型的 Executor‑Advisor 模式（贵模型如 Fable 5 当顾问/裁判，便宜模型如 GPT‑5.5 当执行器）正是这种思路的工程化：用“规划—派发—审查”循环替代“一次让 AI 搞个大的”。

来源：AINLP · 翁荔详解 Harness Engineering ｜ Elevate / Addy Osmani · Own the Outer Loop ｜ AI Will · Fable5 顾问/Sonnet5 执行模式

风险Eval 可靠性亮红灯：SWE‑Bench Pro 约 30% 任务存在致命缺陷

OpenAI 评测团队重新审查后，撤回对 SWE‑Bench Pro 的推荐——约 30% 任务存在致命缺陷；这意味着多个厂商“刷榜即接近前沿”的结论需要打折，后继评测正向 FrontierCode 等迁移。与此同时，可观测性成为刚需：LangChain 推出 Claude Code → LangSmith 追踪插件（三条命令、一个 JSON，捕获每条消息/工具调用/子 Agent），并出现“用 Terraform 配 eval”的 IaC 化实践；LlamaIndex 强调“日/月处理数百万文档需要稳健的可观测层”。

基础设施Agent 的运行时：sandbox、弹性推理、AX（Agent Experience）

Google Cloud Run sandboxes 进入公测：毫秒级启动、原生隔离，专为执行“AI 生成/不可信代码与 Agent 工作负载”设计；AWS SageMaker HyperPod 新增沿推理路径多点数据捕获、Hugging Face 直拉权重、gated 访问与 revision pinning，强化可观测与审计。Modal CTO Akshat Bubna 把论点说得更绝——“你的 AI 应用不该跑在 K8s 上”，Agent 时代的云要从 DX（开发者体验）转向 AX（Agent Experience）：sandbox、弹性推理、一次 10 万次 rollout。Google 还把算法发现代理 AlphaEvolve 推为 GA（芯片/物流/训练架构优化），AlloyDB 发布 AI proxy 模型，用本地小模型蒸馏 LLM 输出、吞吐提升 2400×、达 10 万行/秒。

CTO 读法：“模型是发动机，harness 是整车”。当发动机趋同，胜负取决于底盘、刹车与仪表盘。投资优先级应上移：可观测的 Agent 运行时 + 可重复的 eval 体系 + 清晰的 outer‑loop 问责，这三者决定你能否把便宜的模型安全地放进生产，也决定你能否吃到价格战的红利而不被质量与合规反噬。

07CTO 视角：本周可执行的行动建议

  • 把“每任务成本”立为一等指标，建模型路由层

    不要在 OpenAI/Anthropic/xAI/Meta/开源之间押单点。按“规划用贵模型、执行用便宜模型、裁判独立”的 Executor‑Advisor 思路，落地一个可在 Sol/Terra/Luna、Grok、Muse、开源权重间路由的层；以 cost‑per‑resolved‑task 而非 token 单价考核。本周的价差（Grok $2/$6 vs GPT‑5.6 $5/$30）足以改变架构选择。

  • 把 eval 与可观测性当成生产前置条件，而非事后补票

    SWE‑Bench Pro 30% 缺陷、OpenAI 撤榜是警示：外部榜单不可靠，必须建业务对齐的内部 eval + 全链路 trace（参考 Claude Code→LangSmith、Terraform 配 eval）。对“写权限 Agent 触达生产数据”的场景，先承认它是未解难题，用沙箱+人工 outer loop 兜底。

  • 为 Agent 单独规划运行时：沙箱、弹性、隔离

    评估 Cloud Run sandboxes / Modal 这类 Agent‑native 运行时，把“AI 生成代码”的执行与可信系统物理隔离；审视 K8s 是否还是 Agent 工作负载的默认答案。同步把后量子密码（ML‑KEM/ML‑DSA）从研究项升级进基础设施路线图。
