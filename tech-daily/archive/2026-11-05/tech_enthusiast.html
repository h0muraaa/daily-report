🍎 今日最炸 01

等了两年，国行 Apple 智能终于开测：Siri 牵手千问

11 月 4 日凌晨，苹果随 iOS 27.3 开发者 Beta 向中国用户开放首批 Apple 智能功能测试，并计划在 12 月随正式版推送。首批支持 iPhone 15 Pro / 15 Pro Max、iPhone 16 及后续机型、iPhone Air 和 iPhone Duo；更新包约 12GB，需要开发者账号，装完还要再等系统处理一段时间。

这次能用的功能不少：信息、FaceTime 和电话里的实时翻译，AirPods 的面对面对话翻译，写作工具的改写、校对和摘要，视觉智能，照片消除、自然语言搜索和回忆影片，智绘表情，通知摘要，备忘录和通话转录摘要等。基础功能在手机本地跑，复杂任务则通过 Siri、写作工具和视觉智能调用阿里千问的云端能力。要注意的是，这一版不包含 WWDC 2026 公布的下一代 Siri AI。

首批实测的口碑比较一致：功能齐了，但更像「补课」。Siri 遇到复杂请求会弹出调用千问的对话框，速度快、内容偏简单；写作工具已经能在微信、钉钉、飞书里直接用；整体体验被形容为「梦回 2024」，和国产手机已经玩出花的 AI 功能相比少一点惊喜。想尝鲜可以，但别拿唯一的主力机升开发者 Beta。

🎨 生图升级 02

ChatGPT 生图升到 2.6：能导出 SVG，会做 GIF，速度还快一半

OpenAI 在 11 月 4 日发布 Images 2.6，ChatGPT 和 Codex 的所有档位都能在网页、桌面和手机端使用。最实用的变化在开发者侧：生成的图可以导出成 SVG 矢量图。以前 AI 图是「色点拼成的位图」，放大会糊，想做 Logo、App 图标或印刷品还得设计师重画；SVG 记录的是线条和形状，放大多少倍都清晰，还能单独改某根线的颜色和粗细。

新版本还能用一句话、一张照片或一张手绘草图生成循环播放的 GIF 动图，比如让吉祥物动起来、把商品图做成循环小动画；改图时能更准确地只改指定区域，出图速度比上一版快 50%。开发者可以通过 API 使用 GPT-Image-2.6 Flare 和 Sunburst 两个新模型。OpenAI 透露，全球用户每周在 ChatGPT、Codex 和 API 上生成 40 亿张图，平均每天超过 5 亿张。

📎 来源：宝玉 · OpenAI · OpenAI

🖨️ 硬核玩具 03

拓竹 H3C 塞进 9 个打印头：3.4 秒换头，彩色打印不再堆废料

3D 打印玩家最头疼的「废料山」，被拓竹用最直接的办法解决了：第三代旗舰 H3C 在机身里装了 9 个可自动切换的独立打印头。每个打印头都有自己的进料通道、加热器和硬化钢喷嘴，换头时把当前打印头放回挂架、换下一个继续打，机械切换只要 3.4 秒，最快 6 秒就能换到下一种材料。

更关键的是，9 个头可以分工：一次打印里同时使用不同粗细、不同软硬度甚至不同精度的耗材，支持超软 TPU 和软硬材料混打，做出拿起来就能用的「产品」，而不只是塑料模型。机器还会在当前打印头工作时提前给下一个打印头预热，减少等待。对爱折腾的玩家来说，这是把「多色」从折磨变成了玩法。

📎 来源：爱范儿 · 爱范儿

🤖 国产模型 04

腾讯 Hy4 正式版：会看图、会操作电脑，还能复刻《王者荣耀》

腾讯混元 Hy4 从预览版转正，首次加入视觉理解和 Computer Use 能力：你可以直接上传一段录屏，让它从视频里学习并复刻界面和元素；它生成的结果也能持续截图，靠自己「看」效果再自我修正。官方称它在多个基准上进入最强开源模型之列，并超过了 DeepSeek V4.1 等对手。

爱范儿在 WorkBuddy 里实测，用一句提示词让它做「极其逼真的鹈鹕骑自行车可交互 3D 动画」，画面观感已经能和 Opus 5.5、GPT-6 一桌；它还尝试复刻《王者荣耀》这类复杂界面。不过 Arena 的 Agent 评测显示，目前上场的 Hy4 仍是专有版本，开源权重还在路上——「最强开源」这句话，还得等权重真正放出来才算数。

📎 来源：爱范儿 · Tencent HY · Arena.ai

🌍 开源卷王 05

Kimi K3.1 Pro 开源：2.8 万亿参数，登顶开源 Agent 榜

月之暗面放出 Kimi K3.1 Pro 的开放权重，总参数 2.8 万亿、每个 token 只激活 1040 亿，采用 896 个专家、每 token 选 16 个的稀疏结构，支持 100 万 token 上下文。它与 K3 一起，是 Hugging Face 上迄今最大的真实模型发布，体量超过 Qwen3.8-2.4T 和 DeepSeek-V4-Pro（1.6T）。

在 Agent Arena 里，Kimi K3.1 Pro（Max）跑了 1.75 万多个真实长任务会话，净提升 +5.1%，在 Work、Code、Chat 三个分类里都是开源第一，总榜第 13；相比上一代 K3 提升 4.2 个百分点。Bash 命令可靠性、用户好评度和「听得进纠正」三项也都是开源第一。对普通人来说，这意味着免费或便宜的开源助手，正在逼近付费闭源模型。

📎 来源：Arena.ai · Thomas Wolf · ollama

🚕 未来出行 06

百度 ApolloWorld：无人车「跑一天」，顶真实路测三年

百度 Apollo 发布 ApolloWorld，自称首个面向物理 AI 的 Agent 驱动全模态世界模型。它把整座城市的路网、多模态传感器和车流博弈搬进云端，支持毫秒级实时交互和连续几十分钟的完整接单推演，不再像以前的世界模型只能模拟几十秒的孤立片段、播放单向「录像」。

在这个虚拟考场里，无人车平均每天能跑 10 万公里；跑一天相当于一辆配安全员的真车连续测试约 3 年，效率提升数百倍。靠着云端 24 小时陪练，萝卜快跑的 L4 级全无人端到端大模型已经正式上车，上百辆无安全员真车每天上街接单。新智元在深圳夜间实测，遇到突然占道的行人、乱窜的电动车和外卖骑手，车辆能提前预判、平顺让行。目前全球做到这一步的，只有百度和特斯拉两家。

📎 来源：新智元 · 爱范儿

📞 生活黑科技 07

Grok Bot 学会打电话：替你排队、按语音菜单、跟客服周旋

xAI 的 Grok Bot 上线了打电话功能：你批准后，它可以替你拨打商家电话，在线等待、按自动语音菜单、跟接电话的人对话，你可以在旁边看实时转写，挂断后收到一份通话摘要。官方演示的用途包括预约、取消订阅、和同事协调时间。目前仅限美国，华盛顿州和伊利诺伊州被排除在外。

这项功能让 Grok Bot 更像一支「个人 Agent 团队」：有负责研究的、写东西的、管日程的，可以同时干活，也能拉进同一个群交接任务。硅星人 Pro 报道，Grok Bot 测试版上线两个月，付费周用户达到 80 万，10 月环比增长超过一倍，马斯克称「从没见过增长这么快」。不过它并没有什么独占的新技术——真正的胜负手，是把已有能力包装成普通人愿意天天用的产品。

🔬 科学趣闻 08

Claude 帮科学家看清「穹窿体」：细菌里也藏着神秘桶状结构

Anthropic 的生物研究团队用 Claude 解析出细菌生命中一种「穹窿体」（vault particle）的首个 3D 结构。穹窿体是细胞里最大的蛋白质结构之一，形状像一只桶，1986 年就被发现，但近 40 年来没人知道它到底干什么。

过去人们只在动物、植物等复杂生物的细胞里见过穹窿体；这次团队证明，细菌以及感染细菌的病毒里也有类似蛋白，能组装出同样的桶状结构。在更简单的生命形式里研究它，可能比直接研究人体细胞更容易揭开功能之谜。这不一定马上变成药，但它展示了 AI 在基础科学里越来越像一台「结构显微镜」。

📎 来源：Anthropic · Anthropic

深度 ①｜国行 Apple 智能到底能干嘛？一份「该不该升」的冷静指南 功能齐了，但更像补课；开发者 Beta 先别上主力机

这次更新最值得注意的，不是「苹果终于有 AI 了」，而是它选择了怎样的合作方式。苹果自研模型负责照片消除、基础润色这类端侧任务；一旦任务变复杂，Siri、写作工具和视觉智能就会去调用阿里千问的云端能力。对用户来说，好处是中文理解和本地服务更接地气；代价是体验被切成「端侧」和「云端」两段，能力边界取决于千问。

实测里最顺手的是写作工具：选中文字就能改写、校对、摘要，而且已经能在微信、钉钉、飞书等第三方 App 里用。实时翻译覆盖信息、FaceTime 和电话，AirPods 也支持面对面对话翻译；照片消除、自然语言搜索、通知摘要、通话转录这些「日常小忙」也都在。最受期待的新 Siri 反而最保守：唤醒后有环绕式跑马灯光效，可以语音 / 打字切换，但复杂请求会跳转到千问对话框，回答速度快、内容偏简单。

深度 ②｜个人 Agent 走进现实：会打电话、会记事，但还不会替你生活 一边是 80 万付费用户，一边是 Uber 一周只成交 4 单打车

今天 Personal Agent 赛道最热闹的两条消息，恰好构成一组对照。Grok Bot 宣布能替用户打电话，官方数据显示上线两个月付费周用户达到 80 万；而另一组被疯转的数据是：Uber 在万圣节周处理了 3.2 亿次订单，其中通过 Agent 完成的只有 500 个外卖订单和 4 次打车。推特上的 Agent 很火，现实里的 Agent 还很冷。

差距不在「能不能」，而在「值不值得」。打电话、订票、取消订阅这类任务边界清楚、结果可验证，Agent 容易做出价值；但一旦要理解你的偏好、跨 App 操作、处理意外，可靠性就迅速下降。Comma 给出的解法是「长期记忆」：整个工作区只保留一条主会话，用一个快速决策模型维护所有 Agent 共享的事实清单，让 Agent 自己写监控程序，并根据人工验收和实际花费调整任务分配。这样换个对话、换个子 Agent，它还记得你上次说「订票要靠窗、优先上午」。

所以更准确的说法是：Agent 正在从「演示」变成「工具」，但还没变成「管家」。对普通用户，最值得先用的不是「全自动生活助理」，而是那些你本来就要做、又很烦的单项任务——比如让 AI 帮你等客服、整理会议纪要、把散落的灵感收进笔记。把边界划清楚，Agent 才真的省时间。

🎓科普小课堂

今天只学一个概念
SCIENCE 101

什么是「世界模型」？为什么它能让无人车一天跑完三年路测？

今天新闻里，「世界模型」出现了好几次：百度用它训练无人车，LiberAI 用它让机器人做奶茶，天数智芯甚至把机器鸭的训练搬到了本地。听起来玄，其实可以把它想成一个「会预测下一秒」的模拟器。

普通视频模型的任务是「生成看起来像真的画面」；世界模型的任务是「如果我这样做，世界接下来会怎样」。它不仅要知道红灯长什么样，还要知道前车刹车后自己该减速、行人突然横穿时会发生什么。对自动驾驶和机器人来说，这等于一个可以无限重来、不会撞坏真车的飞行模拟器。

视频模型 = 拍电影 只要画面好看、前后连贯，观众不出戏就行；它不必真的遵守物理规律。
世界模型 = 开模拟器 你踩油门，它要算出车速、轮胎抓地、前车距离；你打方向盘，它要给出合理的下一个画面。
闭环训练 = 无限陪练 Agent 在虚拟世界里做动作、看结果、改策略，一天跑 10 万公里，错误只发生在云端。

这也是为什么百度敢说「一天顶三年」：真实路测要油费、安全员、天气和路况，还要碰运气遇到罕见场景；世界模型可以把暴雨、夜间、突然窜出的行人这些「长尾」场景批量制造出来，让模型反复练。Liber-0 则是另一个方向：用 220 万小时人类经验，让机器人没见过的任务也能上手，甚至完成一杯奶茶的全流程。蚂蚁灵波的机器人已经在乌镇峰会和上海药店「上岗抓药」，背后同样是视觉、深度感知、世界模型和动作决策的组合。

💡 记住这个比喻：世界模型就是给 AI 用的飞行模拟器——不是为了拍好看的视频，而是为了让它在真正上路之前，先在虚拟世界里把该犯的错都犯完。
