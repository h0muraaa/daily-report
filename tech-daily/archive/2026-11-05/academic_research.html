AI for ScienceAnthropic 与 Claude 解析细菌 vault 颗粒首个三维结构

Anthropic 的生物研究团队公开了与 Claude 合作完成的一项结构生物学工作：首次解析出来自细菌生命的 vault 颗粒三维结构。Vault 是细胞内最大的蛋白组装体之一，1986 年由 Leonard Rome 与 Nancy Kedersha 发现，但其生理功能至今未明；此前 vault 只在动物、植物等复杂真核细胞中被确认存在。该工作表明，细菌及其感染病毒的相似蛋白也能自组装为 vault，这为研究其功能提供了一个更简单、可遗传操作的模式系统。相关预印本已在 Anthropic 的 CDN 公开，但尚未见到完整的同行评议版本，结构解析中 Claude 的具体贡献边界（数据处理、模型构建还是假设生成）仍需按原文核对。

开放权重Kimi K3.1 Pro 架构细节：2.8T 稀疏 MoE、104B 激活、1M 上下文

Moonshot AI 开放了 Kimi K3.1 Pro 的模型权重。Hugging Face 的 Thomas Wolf 总结了其关键规格：总参数约 2.8 万亿，每 token 仅激活 1040 亿；共 896 个专家，每 token 路由至其中 16 个；93 层中大多数采用线性注意力（KDA），每第 4 层使用 DeepSeek 式稀疏注意力、只关注 top-2048 token，从而支持 100 万 token 上下文。模型还使用自定义激活 SiTU-GLU，并配有 4.01 亿参数的 MoonViT-V2 视觉编码器，因此支持文本与图像输入。Arena 的社区评测称其在 17.5K+ 真实长程会话上取得 +5.1% 净提升，位列开放模型第一、总榜第 13，但这是竞技场众包分数而非受控评测，引用时需要与官方技术报告交叉验证。

评测方法Google 与 Mercor 发布 PLE：工程 Agent 的“可行域瓶颈”

Google 与 Mercor 发布 Physical-Engineering's Last Exam（PLE），用 85 项机械、电气、土木与结构工程任务衡量 Agent 的工程交付能力。在 56 项隐藏测试中，Claude Opus 5.5 搭配 Claude Code 得分 48.3%；而在人机共同创作任务中，模型平均满足 91% 的单项约束，却只有 41.3% 的交付设计项满足全部硬性安全与可行性要求。作者指出，剩余约 9% 的失败往往无法靠继续提升单点计算能力解决，因为工程约束彼此耦合——例如电缆桥架与消防管线争夺同一净空，会使几十页正确的计算书整体失去交付价值。该基准的方法论价值大于单次榜单，详见第 2 节。

上下文工程NVIDIA 论文：高频上下文压缩几乎不损失长程准确率

研究者推荐了一篇来自 NVIDIA 的论文，讨论“是否应激进压缩上下文”这一长期争论。结果显示，在广泛的长程与长输入任务上，频繁压缩几乎不损失前沿模型准确率，同时能把上下文保持在很短的水平：在 SWE-bench Verified 上，Claude Opus 4.5 采用“每个上下文只保留一个动作”的策略得 70.2，完整历史为 70.0，中位峰值上下文从 32K 降到 8K token。更有意思的是，在对话结束时做简单压缩反而优于保留完整历史，Opus 从 70.0 提升到 74.8。这一结果对评测设计有直接影响：长程 Agent 的论文应同时报告峰值上下文、压缩策略与 token 位置，否则“准确率”不可比；不过该结论来自二手转述，具体任务分布与统计显著性需回到论文原文。

缩放律Stanford：Hinted Scaling Laws 与“每焦耳经济价值”

Stanford AI Lab 介绍了两项与评测经济学相关的工作。其一是 Hinted Scaling Laws：把一个基准改造成一系列更简单的“带提示版本”，联合建模算力规模 C 与提示等级 H，从而在模型于原基准上得分为零时仍能外推其未来表现；作者称可在少用 5600 倍算力的条件下，把 GSM8K 准确率（H=0）预测误差控制在 3 个百分点以内。其二是 Joules-to-GDP（J2G）框架，衡量 AI 把能源转化为经济价值的效率；在 GDPval 覆盖的金融、工程、法律、行政等 44 个职业上，作者发现“单项经济价值最高的任务”并不等于“每焦耳价值最高的任务”——CAD 设计单任务收入比建站高约 10%，但建站每焦耳价值反而高约 27%。两项工作共同提示：缩放律与效率评估都需要把任务结构与资源约束显式建模。

Agent 自进化ReTerm：让终端 Agent 从自己的失败中做递归自我改进

复旦大学、香港中文大学 MMLab 与上海交通大学的研究者提出 ReTerm，把终端智能体自己造成的失败转化为训练信号，探索失败驱动的递归自我改进（RSI）路径。方法的关键是把“遇到问题 → 尝试恢复 → 根据成败更新参数”接入同一个训练闭环：模型改变后产生的新失败，又成为下一轮学习的起点。论文用 PyStan 案例说明差异：标准 GRPO 模型在 `import pystan` 反复失败后不断卸载重装，而 ReTerm-GRPO 会检查安装路径、发现模块实际位于 `stan` 目录，从而改用 `import stan`。论文编号 arXiv:2610.18484，代码、模型与数据已在 GitHub 与 Hugging Face Papers 公开，是本期最值得复现的训练方法之一。

2.1 OpenAI 自主漏洞发现—利用—修补流水线：把安全加固变成可度量的 Agent 能力

研究背景

软件漏洞的发现与修补长期受限于安全研究人力：一个本地提权漏洞从发现、构造 PoC、验证可利用性到产出补丁，通常需要专家数天到数周。前沿模型能否把这条链路端到端自动化，是“Agent 能否承担真实科研/工程劳动”的一个高价值试金石，同时也涉及大规模漏洞披露的伦理与治理问题。

核心方法

OpenAI 安全研究团队构建了一条自主网络漏洞发现、利用与修补流水线，在单次运行中使用一个尚未发布的“cyber model”，对 Linux 内核的本地提权（LPE）漏洞执行全流程：定位可疑代码、构造并验证利用、生成补丁，再由流水线做验证。团队称正与 Linux 维护者及 Patch the Planet 合作提交报告与补丁。

实验结果

  • 单次运行中验证并为 948 个 Linux 内核本地提权漏洞生成补丁；
  • 总 API 成本约 120 万美元，折合每个漏洞约 1000 美元（Greg Brockman 口径）；
  • Agent 在过程中发现并使用了至少 10 种此前未见诸公开记录的 Linux 利用技术——这一“新颖性”判断基于团队咨询的专家共识，尚待独立安全社区复核；
  • 成果形式是“已验证的补丁”，并不等于已合并进上游内核，二者之间仍有维护者审查与回归测试的距离。

学术意义与限定

这项工作的贡献不只是数字，而是给出了一个单位经济模型：当每个漏洞的边际成本降到约 1000 美元，漏洞发现就从“专家稀缺资源”变成“可批量采购的计算资源”，这对开源基础设施的安全经济学是结构性变化。方法上，它把“发现—利用—修补—验证”做成闭环，天然适合作为 Agent 长程规划、工具使用与环境反馈的复合基准。限定同样明显：任务仅覆盖 Linux 内核 LPE 这一类漏洞，模型未公开，补丁质量与误报率缺乏第三方统计，且大规模自动化漏洞挖掘本身具有双重用途风险。后续研究应关注三个可检验问题：补丁的上游接受率、引入回归的比例，以及“新颖利用技术”能否被独立复现。

2.2 PLE：当 91% 的单项正确不等于可交付——工程 Agent 的约束耦合评测

研究背景

现有 Agent 评测多采用“逐项累加”的计分方式：完成的要求越多，分数越高。这在知识问答与单点执行上有效，却会掩盖工程设计中的一类关键失败——模型可能满足绝大多数要求，但剩下一条恰好决定方案能否投入使用。工程约束彼此耦合，一处修改会让此前核验过的结果失效，因此“平均正确率”与“可交付性”之间存在系统性落差。

基准设计

Google 与 Mercor 发布的 PLE（Physical-Engineering's Last Exam）包含 85 项机械、电气、土木与结构工程任务，其中 56 项为隐藏测试，另有 41 项人机共同创作任务，37 项采用约束评分。评分机制把“单项检查通过比例”与“整体约束耦合/交付可行性”拆开：在统一评分下，约 40% 的评分空间取决于单项检查通过比例，其余部分用于衡量方案在约束网络中的整体成立程度。这一设计使“局部正确但整体不可行”无法被高平均分掩盖。

实验结果

  • Claude Opus 5.5 + Claude Code 在 56 项隐藏测试上得分 48.3%；
  • 在共同创作任务中，模型平均满足 91% 的单项约束，但只有 41.3% 的交付设计项同时满足全部硬性安全与可行性要求；
  • 作者用一个具体案例说明失败机制：电缆桥架在机房顶部穿过消防管线，载流量、电压降与设备选型都算对了，但三维空间中几套系统争夺同一净空，方案只能退回；
  • 剩余约 9% 的失败往往无法靠继续提升模型单点计算能力解决，因为解决一个约束会生成新的约束。

学术意义与限定

PLE 的核心贡献是把“可行域”变成一等评测对象：它提示工程 Agent 的瓶颈正在从“局部能力不足”转向“约束传播与全局一致性”，这与本期 NVIDIA 的上下文压缩研究、ReTerm 的失败驱动训练形成呼应——三者都在说，Agent 的能力瓶颈更多位于 harness、记忆与约束管理，而非单纯模型分数。需要谨慎的是：48.3% 是在隐藏集上的单点结果，任务总数 85 项、覆盖面有限；基准由 Google 与 Mercor 主导，后续需要第三方复现与跨模型横向评测。对论文作者而言，更可迁移的启示是评测报告应同时给出“单项约束满足率”“全约束通过率”与“失败传播路径”，而不是一个聚合分数。

趋势提示“开放权重”正在分层：完全开放 vs 受控共享

本期 Cognition 发布 SWE-2 Flash，称其在主要评测上超过所有美国开放权重模型、包括大 3 倍的模型，但为平衡透明度与网络风险，权重只通过合作伙伴与研究者计划受控共享，而非公开下载。这与 Kimi、Hydrogen-1.0 的完全开放形成对照，提示“open-weight”一词在论文与政策讨论中需要更精确的限定：是权重可下载、可商用，还是仅可申请访问。做开放模型经济与可复现性研究时，建议把许可与访问门槛作为独立变量记录。

4趋势观察

趋势一：评测正从“平均正确率”转向“可行域、长程成本与失败传播”

PLE 的 91% 对 41.3% 是本期最清晰的信号：当模型在单项能力上已经足够强，评测的区分度就转移到约束耦合与整体可交付性。与此同时，Arena 的 Agent Arena 用真实长程会话给出成本刻度——完成一小时任务的中位成本，Gemini 4 Carbon 约 10.51 美元、Claude Opus 5.5 约 21.13 美元、GPT-6 Astra 约 31.08 美元，模型选择最多可削减 66% 成本。研究者若继续只报告单点准确率，将越来越难回答“这个 Agent 能否被部署”。可操作的建议是：论文至少同时报告单项约束满足率、全约束通过率、峰值上下文、每任务成本与失败传播案例。

趋势二：Harness 与上下文管理成为一等研究对象

“同一个模型、不同 harness、不同结果”已从工程经验变成可发表的研究命题。NVIDIA 的压缩实验表明，记忆策略可以把峰值上下文从 32K 降到 8K 而几乎不损准确率；ReTerm 表明，训练循环本身可以围绕“失败恢复”重构；本期还有实测 28 种 Agent 组合的工作指出，面对 5000 词需求文档，Claude 也只能交付约 14%。“智能体脚手架”不再只是产品实现细节，而是影响能力上限、成本与可复现性的核心变量。对学术写作的直接含义是：论文必须把 harness 规格（工具集、上下文策略、重试与终止条件）当作方法的一部分完整披露，否则结果不可复现。

延伸阅读：1991 年 March 的探索—利用框架，为何在今天重新变得相关

本期一条阅读笔记重新讨论了 James March 1991 年的经典论文 Exploration and Exploitation in Organizational Learning：组织需要在“改进已有做法”和“尝试新东西”之间分配资源；论文中的“组织代码”会向知识更多的个体学习（多样化），个体也会向组织代码学习（社会化），而过快的社会化会在组织尚未来得及从个体学习之前就消灭多样性。作者把这一结构类比为今天的人与 AI：当人们习惯先让 AI 思考、自己只负责点头，个体的认知结构与表达风格可能被“快速社会化”抹平。这一类比并非严格映射，但它为“AI 辅助科研是否在压缩认知多样性”提供了一个可操作的经典理论框架，值得在组会中作为方法论讨论材料。
