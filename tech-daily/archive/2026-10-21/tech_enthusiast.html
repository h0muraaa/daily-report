今天最值得聊的 8 件事

🧬AI 用 64 小时“造”出解药候选：Claude 自主设计蛋白质，17 个真能锁住蝎毒

Anthropic 公布了一项相当硬核的研究：一个研究版 Claude 在 64 小时内自主生成了 318,484 个蛋白质设计方案，自己完成超过 55 万次结构预测和筛选，最终交出 211 个候选，直接送进两家真实生物实验室做实验。结果是 17 个设计真的结合上了蝎子的神经毒素，达到严格的结合标准。人类团队全程只给了初始提示词和四次追问，其余几乎由 AI 推进。

为什么盯上蝎毒？全球每年超过 120 万人被蝎子蜇伤、死亡超过 3250 人，多数是医疗条件有限地区的儿童。传统抗毒血清要靠抓蝎子、挤毒、注射进马体内再抽血提纯，贵、慢、覆盖面还窄。更关键的是，Anthropic 把全部 211 个设计方案和实验数据都开源了。

为什么值得关注：这不是“AI 写篇论文”，而是 AI 提出方案、真实实验验证、数据公开的完整闭环。AI for Science 第一次这么具体地走到实验台前。
来源：AI寒武纪 来源：夕小瑶科技说

📱手机上多了一个“AI 管家”：Anthropic 推出 Claude Duet

Anthropic 的新个人智能体 Claude Duet 住进了手机，可以继承你在 Claude 里装过的插件和连接器，目标用户是小生意主和忙碌的上班族。体验者把它丢进邮箱、Slack、销售流程、做销售演示文稿、甚至给孩子找球票等一堆任务里，评价它是“完成度最高的 Agent 发布”：引导流程细致、任务清单清晰、还做了类似 Slack 的频道。

但评测也泼了冷水：它有点慢；而且目前更像“一个人的 Agent”，团队想共享同一个智能体还做不到。Personal Agent 的竞争，已经从“谁更会聊天”变成“谁能真的替你把事办完”。

为什么值得关注：如果 Agent 真能接管你的邮箱和日程，未来手机里最常用的 App 可能不再是聊天框，而是一个会主动干活的“人”。

🤖Meta Muse 上线 40 天下载破 1000 万，留存还比 ChatGPT 高

Sensor Tower 数据显示，Meta 的 AI 助手 Muse 自 9 月推出以来累计下载 1090 万次，其中美国地区 1020 万次。历史上只有另外 11 款应用在发布后这么快达到这个量级，上一款还是 2023 年 7 月的 Threads。更值得注意的是，Muse 的用户留存表现优于 ChatGPT、Claude、Grok 等竞品。

这可能是 Personal Agent 第一次真正摸到“大众产品”的门槛：不是极客玩具，而是普通人下载后会继续用的东西。

为什么值得关注：下载量可以靠营销，留存骗不了人。Muse 的数据说明，个人 AI 助手可能已经跨过了“尝鲜期”。
来源：极客公园

💻为了 AI，硅谷开始重新设计电脑：19 岁创业者的 AI 硬件三天售罄

Personal Agent 火到什么程度？Instinct 在 9 月完成 10 亿美元 C 轮融资，估值一个月内从 25 亿美元飙到 100 亿美元；a16z 领投了 19 岁创业者 Zain Javaid 的 AI 硬件项目 Ghost，种子轮就有 1100 万美元；YC 一支 00 后团队做的“AI 电脑”三天售罄。红杉在年度文章里判断，2026–2027 年将是长周期自主 Agent 的转折点。

逻辑也说得通：如果 Agent 要 24 小时在线、主动处理事情，那它需要的可能不是“一个 App”，而是一台为它重新设计的个人计算机。

为什么值得关注：上一轮硬件创新是“把互联网装进口袋”，这一轮可能是“把 AI 助手装进一台专属设备”。
来源：Z Potentials

🎞️ChatGPT 会做 PPT 了，还能给聊天“上锁”

OpenAI 在 10 月 20 日上线 ChatGPT Slides：可以根据对话内容、上传的文件或大纲生成演示文稿，支持团队实时协作、根据反馈自动调整，还能导出 PDF 或 PowerPoint，目前面向 Pro、Business 和 Enterprise 用户。同一天上线的还有 Locked Chats（锁定聊天）：用四位 PIN 或 Face ID / Touch ID 解锁，锁定的对话会移入单独区域，不出现在历史记录、置顶和搜索结果里，还有独立记忆。

需要提醒的是，官方明确表示“上锁不等于端到端加密”，也不会改变对话保留时长和模型训练设置；重置 PIN 会永久删除所有已锁定对话。

为什么值得关注：一边帮你生产力拉满，一边给你隐私安全感——AI 助手正在补齐“能放心用”的最后几块拼图。
来源：少数派

🫀在浏览器里拆解一颗跳动的心脏：Gemini 4 Argon 生成可交互 3D 人体解剖

Google DeepMind 展示了 Gemini 4 Argon 的新玩法：把三个开源数据集组合起来，生成一个可交互的 3D 人体解剖可视化。你可以分层切换、单独显示肌肉、甚至放大看一颗跳动的心脏。这不是一张渲染图，而是一个能在浏览器里转、能拆开看的“数字标本”。

它展示的不只是模型“会生成内容”，而是把多源数据组织成可探索工具的能力——以后生物课可能真的不需要塑料人体模型了。

为什么值得关注：当 AI 从“回答问题”走向“搭建可交互世界”，教育、医疗和科普的呈现方式都会被改写。
来源：Google DeepMind 来源：Matt Wolfe

🧪 科技新鲜事

两个话题，聊透一点

① 为什么所有大厂突然都在做 “Personal Agent”？从“你问它答”到“它自己找事做”，这才是今年最大的变化

如果你最近总觉得 AI 产品名字越来越多——Muse、Duet、Grok Bot、Today AI、Dots、白艾莉——别怀疑自己落伍了，它们其实都在做同一件事：Personal Agent（个人智能体）。区别只在于各家的产品形态和性格。

过去两年我们用 AI，基本是“我提问、它回答”。而 Personal Agent 的目标是反过来：它记住你的上下文，主动发现该做的事，然后替你执行。一位产品经理分享过一个很直观的例子：中秋假期，他发现公司某个未上线产品的资源消耗突然飙升，和同事在群里讨论到一半就去吃午饭了。结果饭后打开手机，Today AI 已经主动推来一条消息，标出了主要消耗项和计算口径——他根本没给这个 AI 布置过任务，它只是从群聊记录和账单里“看懂”了最近在排查什么。

  • 能力变了：从对话窗口走进工作流，能预订、安排行程、管理日程，甚至完成支付与交易。
  • 形态变了：有的做成手机 App（Claude Duet），有的做成电话/语音助手（Meta Muse），有的甚至开始重新设计电脑硬件。
  • 性格也变了：“白艾莉”干脆把 Agent 做成了养成系游戏——动漫少女有自己的人设、会饿会困、会给你写信，还能在你连续工作两小时后提醒你起来走走、喝口水。

当然，问题也很明显：Duet 被吐槽“慢”，团队共享一个 Agent 还做不到，而且“主动提醒”一旦做不好，就会变成新的通知骚扰。Personal Agent 真正的门槛，可能不是模型能力，而是分寸感。

💡 一句话总结：AI 正在从“工具”变成“搭子”。但一个好搭子，首先要学会什么时候别打扰你。
来源：AI产品阿颖 来源：向阳乔木推荐看 来源：How I AI

② 64 小时 vs 几个月：AI 到底是怎么“设计蛋白质”的？把“找钥匙”变成“批量造锁”，再交给实验室验货

“AI 设计蛋白质”听起来很玄，其实可以拆成三步。蝎毒里的神经毒素像一把“坏钥匙”，会插进人体神经细胞膜上的钠离子通道，让神经疯狂放电。Anthropic 想让 Claude 设计的是一种叫“结合剂”的小蛋白，使命只有一个：死死贴住坏钥匙的齿面，把它封住。

  • 第一步，海量出方案：Claude 调用 12 种蛋白质设计工具，生成了 31.8 万个候选结构。人类不可能一个个想，但 AI 可以。
  • 第二步，自己筛：模型完成超过 55 万次结构预测，判断哪些候选“长得像能贴上去”。这一步相当于在草稿堆里做初筛。
  • 第三步，实验室验货：最终 211 个设计被送进两家独立实验室做湿实验，17 个真的结合成功。注意这个命中率——AI 很能“出主意”，但最终还是要靠真实实验说了算。

为什么这件事重要？因为传统抗毒血清的生产方式太原始了：抓成千上万只蝎子、人工挤毒、注射进马体内、再抽血提纯，周期几个月，而且一种血清往往只能对付少数几种毒素。商业利润低，药企不愿投，这成了“被忽视的热带病”。AI 的价值不是替代实验，而是把“提出候选”的成本打到足够低，让这类不赚钱但救命的项目重新变得可行。

🔬 冷静一下：17/211 的成功率说明这仍是研究级成果，离“AI 自动制药”还有很长的路。但方向已经很清楚了。

Token 到底是什么？为什么 DeepSeek 一天跑 155 万亿个还能赚钱？

今天 DeepSeek 公开了内部推理框架 DeepInfer，并披露了一组很夸张的数字：单个集群每天处理 155 万亿个 Token，整体收入约每卡每小时 38 美元；有分析据此估算，这套集群每天收入约 2200 万美元、利润率接近 80%，约 81 天就能回本。

先别被“万亿”吓到。你可以把 Token 理解成 AI 读写文字时的“最小积木”：一个汉字可能是一个 Token，也可能被拆成两个；英文里 “unbelievable” 可能被切成好几块。你每问一句话、AI 每答一句，背后都是 Token 在进出。

🍜 打个比方：Token 就像面馆里的“一碗面”。模型是厨房，GPU 是灶台。DeepSeek 说自己厉害的地方，不是面更便宜，而是同一个灶台一天能多翻好几倍台——靠的是把请求排队、缓存常用结果、把计算和存储拆开调度，让 GPU 尽量不闲着。

为什么“推理”能赚钱？训练大模型像建厨房，一次性投入巨大；推理是每天卖面，只要翻台率够高、成本控制够好，就能产生稳定现金流。DeepSeek 这次开源的 DeepInfer，核心就是一套把翻台率做到极致的调度系统，还支持最长 72 小时的提示缓存——同样的上下文不用反复算，直接复用。

155 万亿 Token / 天 / 单集群
~80% 估算利润率
81 天 估算回本周期
72 小时 最长提示缓存

⚠️ 说明：80% 利润率和 81 天回本来自行业分析机构的估算，并非 DeepSeek 官方财报口径，看个量级就好。
