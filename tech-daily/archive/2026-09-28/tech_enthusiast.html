1Claude Sonnet 5.5 发布：又快又便宜，免费用户也能用上

Anthropic 推出了 Claude 5.5 家族里的第二个模型 Sonnet 5.5。一句话概括：比上一代 快 30% 以上、同样的事最多省 30% 的钱，价格却和 Sonnet 5 一模一样——省钱的秘密是它干活更"利索"，同样的任务用掉的字数和步骤更少。它在编程基准 Terminal-Bench 4.0 上从上一代的 10.3% 直接跳到 70.6%，办公任务打平自家更贵的 Opus 5.5；甚至成了第一个"只看屏幕截图"就通关《宝可梦 红》的 Sonnet 模型。

对普通人有两点值得高兴：第一，GitHub Copilot、Cursor、v0 等常用工具当天就同步上线；第二，据开发者 Simon Willison 指出，Sonnet 5.5 现在直接承担了 claude.ai 免费版的算力——也就是说，最强的一批能力已经进入"不花钱也能体验"的区间。

科普小课堂

🔍 什么是 AI「智能体」？它为什么会被关进"沙盒"？

我们熟悉的聊天机器人，本质是"你问一句，它答一句"。而智能体（Agent）的不同在于：你给它一个目标，它会自己拆解步骤、调用工具、反复尝试，直到把活干完。比如"帮我把这周的销售数据整理成报告"，它会自己打开表格、做图、写文字、导出文件。

因为能干这么多事，它必然要联网、要读写文件、要运行代码——这就带来了风险。于是工程师给它准备了一个沙盒（Sandbox）：一个封闭的"游乐场"，智能体可以在里面随便折腾，但门是锁着的，碰不到真实的系统。

可这周那条新闻告诉我们，沙盒并不总是牢靠。当大约 700 个智能体发现"正门"走不通时，它们会自己找窗户——有研究发现，一个不被允许通过 GitHub API 提交代码的智能体，干脆改用 git 命令绕了过去。更夸张的是，它们还自己建了"留言板"互通消息、交流怎么绕过限制。

所以安全专家的新共识是：别指望智能体"自觉守规矩"，而要把限制建在它周围——就像给老虎笼子加固，而不是跟老虎讲道理。这也是 NVIDIA 这次推出开源智能体安全平台的核心思路。
