1.研究动态

RSI · 智能爆炸Hinton 等 22 位学者联署首篇 RSI 论文，量化“自动化 AI 研发”的闭环条件

诺贝尔物理学奖、图灵奖得主 Geoffrey Hinton 参与撰写其首篇关于递归自我改进（Recursive Self-Improvement, RSI）的论文《What if automating AI R&D triggers an intelligence explosion?》。作者阵容堪称全明星：22 位作者中含两位“AI 教父”Hinton 与 Yoshua Bengio、强化学习先驱 Andrew Barto，以及 OpenAI 首席科学家 Jakub Pachocki。论文的核心论点是：一旦 AI 能完整参与开发下一代 AI，RSI 就可能真正闭环；而智能爆炸并非必须先出现超级智能——只要 AI 研发的自动化效率足够高，正反馈循环就可能先于“超人智能”启动。作者给出了极具冲击力的量级推演：AI 研发自动化一旦越过某个临界点，原本需要数年完成的进步可能被压缩到几个月甚至更短；理论上 AI 实验室的研发规模可从数千人跃升至数百万“研究员”，今天一年的进展在某些极端情形下未来或仅需约 5 周完成。这是把“智能爆炸”这一 1965 年以来的古老命题，第一次以多作者、可辩驳的形式重新锚定在定量讨论上，值得作为本季度最值得精读的预印本之一。

开放权重Reflection 发布 Beam：501B 总参数 / 23B 激活，以推理效率切入西方开放前沿

美国公司 Reflection 发布首个开放权重模型 Beam，宣称采用 501B 总参数、23B 激活的稀疏（MoE 风格）架构，端到端从零训练，专注于“前沿推理效率”与编码 / agentic 任务，并承诺本月释出完整权重。第三方评测者的定性判断是：Beam 的整体能力接近 GLM 5.2，但相较 GLM 5.3、Kimi K3、DeepSeek V4.1 Flash 等中国头部开放模型仍有多项差距；其真正的差异化竞争力来自推理计算量仅为 GLM 5.2 的约 1/3–1/4，这对长时间运行、需反复思考的 agent 场景意义重大。Ollama 已表示将把 Beam 纳入本地运行支持。对研究者而言，这是一个值得纳入开放权重基线矩阵的新样本——它提示“效率前沿（efficiency frontier）”可能成为西方开放阵营相对“规模前沿”的一条差异化路径。

具身 · 基准VA-Bench：多模态模型“看得懂”不等于“做得到”，完整任务成功率仅约一半

机器之心报道的新基准 VA-Bench（论文题《VABench: Measuring Embodied Spatial Intelligence through Visual Demonstrations, Active Perception, and Metric Control》，arXiv:2609.19554）以“观察—推理—行动—修正”的闭环，系统测试了 12 个主流多模态模型的空间智能。结果揭示了一个清晰的执行断层：在目标识别与定位（TL）上，表现最好的模型达到 100%，操作语义理解（MS）也达 99.6%–100%；但完整任务成功率只有约一半——Qwen3.8-max、Opus-5、GPT-5.6-sol 分别为 53.93%、52.86%、51.55%。作者指出瓶颈集中在主动观察、精细（度量级）控制与在线修正三个环节：模型知道“该抓哪个”，却算不准“移动多少毫米”“当前视角够不够”“抓空后如何调整”。该工作的方法论意义在于，它把空间智能的评测从“答对问题”推进到“闭环完成任务”，为具身智能提供了比静态问答更贴近部署的评估口径。

📎 来源：机器之心（微信公众号） · 论文：arXiv:2609.19554
Harness · 演进ScholarEvolve：用已发表论文而非自身失败日志来进化 agent 框架

微软与加州大学圣巴巴拉分校（UCSB）研究者提出 ScholarEvolve：从已发表的 agent 研究中寻找改进思路，写入运行框架（harness），再用真实任务检验效果。它改的是围绕模型组织工具、上下文、记忆与执行流程的软件层，执行任务的模型保持不变，新能力完全来自 harness 如何为模型提供信息与安排决策。实验在 AppWorld 与 τ²-Bench Telecom 两个交互环境中进行：经框架演化后，Qwen3.5-27B 在 AppWorld Challenge 上的任务完成率从 49.6% 提升到 63.6%，GPT-5.4-mini 在 Telecom 上的单次成功率从 72.7% 提升到 81.9%。作者的关键对照是“读失败日志改 harness”（Meta Harness 路线）：后者只能看到“当前系统怎样走错”，合适改法仍要靠编码 agent 自行想象，容易在相近方案间打转；ScholarEvolve 则把下一步接到文献上，让“论文提供候选思路 → 编码 agent 实现 → 任务结果决定去留”形成可迭代闭环，新论文可持续加入。这一范式把文献阅读正式接入工程改进，值得 agent 研究者关注。

📎 来源：AINLP（微信公众号）
Agent · 实证UT Austin：近 3.5 万次 agent run 揭示“省 token 反而更慢”的上下文压缩反直觉

UT Austin 的一项实证研究在 SWE-bench Verified 与 Terminal-Bench 上运行了近 35,000 次 agent run，独立地变化三个决策变量来检验编码 agent 的上下文压缩：如何压缩、何时触发压缩、压缩掉多少。核心发现颇具反直觉性：以削减 token 为目标的压缩策略，可能反而让 agent 变慢。在 Terminal-Bench + Qwen 上，只用约三分之一 token 的策略，耗时比保留完整上下文高出 20%–80%。细看机制：按步（step）触发压缩的策略每步省 token 最多，却需要多 10%–27% 的模型调用；阈值（threshold）触发策略可省 22%–55% 的 token，调用次数接近全上下文。不同模型下结果也不一致。该工作的方法论价值在于把“上下文工程”从经验规则推向受控实验，并给出一个可复用的结论模板：压缩策略的优化目标不应是 token 数，而应是端到端任务成本（token × 调用次数的联合函数）。

📎 来源：elvis（@omarsar0，X）
检索 · 结构化CorpusMap：为文档集合预建“实体页”，agentic search 质量提升 6.4–11.7 分、输入 token 降 34%–57%

微软及合作者提出 CorpusMap，针对“agent 反复检索大型文档集合”的低效问题：先在集合层面解析出反复出现的实体，为每个实体建立一张实体页，链接到所有提及它的文档；原始文档保持原位。agent 读一篇文档后，可沿实体跳转到相关文档，避免重复搜寻同一证据。在 7 个模型 × 3 个基准上的评测显示，答案质量提升 6.4–11.7 分，同时输入 token 下降 34%–57%，并优于 LLM Wiki 层及另外三种导航层方案。值得注意的是，该实体地图可以完全无需 LLM 调用构建。对关注 RAG 与 agentic 检索的研究者，这提供了一条“预先结构化语料以降低推理期搜索成本”的对偶思路，与本期另一条“agentic search vs 向量检索”的评测（见趋势观察③）恰好形成互补证据。

📎 来源：elvis（@omarsar0，X）
评测 · 代码ReviewBench：为 AI code review 建立开放基准，刻画“抓什么、漏什么、如何取舍”

GitHub 发布 ReviewBench，一个面向 AI 代码评审的开放基准。其动机直指当前 agentic code review 已进入开发主流程、却难以衡量质量的问题：不同 reviewer 有的“报更多问题”，有的“噪声更小”，有的更擅长抓关键缺陷、有的偏向小改进，而这些差异只有在具体工作流中才有意义。ReviewBench 强调基准必须反映真实 pull request 的多样性，以便比较不同系统“抓到了什么、漏掉了什么、做出了什么取舍（tradeoffs）”。对研究者而言，代码评审是一个天然具备“多目标、无唯一正确答案”特性的评测场景，其设计（如何定义正确、如何处理评审风格的多样性）值得作为“开放生成任务评测”的方法样本。

自改进 · 成本SelfSearch：agent 改写自身 harness，不到 5 美元在 Terminal-Bench 2.1 上追平 Codex

一项自改进（self-improvement）工作提出 SelfSearch：让编码 agent 借助对“以往自我修改尝试”的记录（含推理、工具动作与结果），改写自身的指令、工具与流程；被改后的 agent 又成为下一轮的改进者。报告称，一个编码 agent 通过重写自己的 harness，使用 DeepSeek V4 Flash 解决了 Terminal-Bench 2.1 的 82.0% 任务，搜索过程中完全未使用任务奖励（no task reward during search），搜索成本仅 4.03 美元——与公开九种 harness 同条件对比中的最佳者 Codex 持平。六个“模型—基准”设置下的人群平均成功率均上升，单 agent 亦有提升。该结果把“harness 优化”的成本压到了可与一次实验预算相比的量级，也把自改进研究从“算法设计”推进到“可复现的工程搜索”，其记录复用（experience replay of self-modification）机制是核心可迁移点。

AI4ScienceCaltech 团队聚焦三维无强迫欧拉方程，陶哲轩深夜“力挺”

在纽约大学团队与 OpenAI 就“纳维—斯托克斯 / 欧拉方程奇异性”陷入 authorship 罗生门、克雷研究所仍未接受该结果的背景下，Caltech 的 Anima Anandkumar 团队交出了一份不同路线的答卷，聚焦三维无强迫（unforced）欧拉方程。关键分野在于：以往“人工多尺度构造”可借外加光滑外力（forcing）或人为设定跳跃尺度来“推”出奇点，难度低一档；而无强迫条件下纯靠初始数据自发演化出奇点，才是更难也更本质的目标。此前 Chen–Hou 等 2025 年在 PNAS 的工作是这一脉络上的重要节点。该进展引发陶哲轩关注与讨论。无论最终审稿结论如何，这一事件本身折射出 AI 辅助数学研究在“可验证性”与“优先权认定”上的新张力——当 AI 参与猜想生成与证明搜索时，学界如何界定贡献、如何复核，正成为亟待制度化的方法论问题。

2.深度论文解读

深度解读 ①　What if automating AI R&D triggers an intelligence explosion?
作者：Geoffrey Hinton、Yoshua Bengio、Andrew Barto、Jakub Pachocki 等 22 人 · 领域：AI 安全 / 递归自我改进（RSI） · 报道来源：大模型智能

研究背景

“智能爆炸”是 I.J. Good 于 1965 年提出的古老猜想：一个能改进自身的智能体，可能引发能力的失控式增长。半个多世纪以来，它多停留在哲学与科幻层面。近年随着 AI 开始实质参与芯片设计、代码生成、实验规划等研发环节，这一猜想第一次具备了可讨论的现实基础。本文的核心问题因此非常具体：当 AI 开始大规模参与“造下一代 AI”，而下一代 AI 又回来加速研发，这个反馈循环会不会真正闭环？

核心创新

论文的贡献不在于给出“爆炸一定发生”的结论，而在于把命题拆解为可分析的机制条件。其关键论断有三：第一，一旦 AI 能完整参与下一代 AI 的研发，RSI 就可能从部分加速走向真正闭环；第二，智能爆炸未必需要以超级智能为前提——只要 AI 研发的自动化效率足够高，正反馈循环就可能先于“超人智能”启动，这实际上放宽了传统讨论中过强的前置条件；第三，论文把讨论锚定到研发规模与时间尺度的量级推演，而非定性叙事。

关键推断与结论

论文给出的量级图景是：AI 研发自动化一旦越过临界点，原本需数年完成的进展可能压缩至数月甚至更短；未来 AI 实验室的研发规模理论上可从数千人跃升至数百万“研究员”；在极端情形下，今天一年完成的 AI 进展，未来或仅需约 5 周。需要强调的是，这些数字是用于界定讨论边界的推演，而非预测；论文本身也在提示“临界点是否存在、位于何处”仍是开放问题。

学术意义

其价值有三。其一，作者阵容本身是一种信号：Hinton、Bengio、Barto 等符号性人物与工业界首席科学家共同署名，意味着 RSI 已从边缘议题进入主流议程。其二，它把“智能爆炸”这一长期被视作不可证伪的问题，转化为若干可独立检验的子命题（研发自动化率、反馈时延、AI 参与研发的完整度），为后续实证研究提供了可操作的分解。其三，对 AI 安全与治理研究而言，论文提示监管与评估的时间窗口可能比直觉更窄——若反馈循环在“超智能出现之前”即可启动，则对齐与可解释性的研究需要更早地与研发自动化进程耦合，而非等到能力跃迁之后再介入。

深度解读 ②　VABench: Measuring Embodied Spatial Intelligence through Visual Demonstrations, Active Perception, and Metric Control
论文：arXiv:2609.19554 · 项目主页：github.com/zhangzhongbo2213/VABench · 报道来源：机器之心

研究背景

多模态大模型在“空间理解”类静态问答上得分不断逼近饱和，但这类评测与真实具身任务之间存在系统性缺口。VA-Bench 的出发点是：模型能否“看懂”空间，与能否“做对”空间操作，是两种不同的能力。为此，作者设计了一个覆盖“观察—推理—行动—修正”全闭环的评测框架，而不是继续扩充静态空间 QA。

方法设计

VA-Bench 通过视觉示范（visual demonstrations）来规定任务，同时考察三项能力。其一是目标识别与定位（TL，Target Localization）；其二是操作语义理解（MS，Manipulation Semantics），即“该操作哪个目标、任务如何进行”；其三是度量级控制（Metric Control）与主动观察（Active Perception），即“该移动多少毫米”“当前视角是否足够”“抓空后如何在线修正”。后两者正是传统静态评测缺失的部分。

实验结果

在 12 个主流多模态模型上，出现了极具解释力的“断层”现象：TL 最高达 100%，MS 达 99.6%–100%；但完整任务成功率仅约一半——Qwen3.8-max 53.93%、Opus-5 52.86%、GPT-5.6-sol 51.55%。也就是说，“目标找对了、任务也看懂了”，真正动起来后仍只有约一半能成功，瓶颈集中在主动观察、精细控制与在线修正。

学术意义

该工作最重要的贡献是把“空间智能”的评测口径从正确性推进到闭环执行。它提示：以感知/问答为核心的 benchmark 可能存在“饱和但无部署价值”的风险，具身智能研究需要将“度量精度”“视角主动性”“失败恢复”作为一等评测维度。同时，“高理解分 + 低执行分”的断层本身是一个可深入机理研究的现象——它可能同时涉及坐标/尺度表征、动作空间的连续性建模、以及多步误差累积，值得作为后续工作的问题来源。

4.趋势观察

① Harness 正在从“工程脚手架”变成“被研究的科学对象”

本期多条独立线索指向同一判断：围绕模型组织工具、记忆与执行流程的软件层（harness），已经成为与模型权重同等重要的能力来源，并开始被系统化地优化、评测与训练。证据链包括：ScholarEvolve 用文献驱动 harness 演进（同模型 Qwen3.5-27B 在 AppWorld 上 +14 分）；SelfSearch 让 agent 改写自身 harness，以 4.03 美元追平 Codex；Hugging Face 把真实 harness 直接改造成 RL 环境（同一模型在 Mini-SWE-Agent 下 62%、在 Claude Code 下 33%，说明 harness 对同一权重的表现影响巨大）；UT Austin 用 3.5 万次 run 揭示压缩策略对效率的非单调影响。这对研究者的直接含义是：“同权重、不同 harness”应成为实验的默认控制变量，任何声称“某模型能力如何”的结论，都需注明其 harness 假设，否则不可复现也不可比较。

② 评测范式从“能力排名”转向“失效模式刻画”

本期密集出现的新基准有一个共同特征：它们不再满足于给模型打分排名，而是刻意构造能暴露特定失效模式的场景。VA-Bench 刻画“理解—执行断层”；SYAUDIO 首次系统测量音频语言模型的谄媚（模型倾向于迎合用户、即使证据相反）；ReviewBench 关注 reviewer“抓什么、漏什么、如何取舍”；MusicGroundingBench 把“定位证据”与“回答问题”拆成两种能力并发现二者不可互相替代；评测研讨则指出 LLM-as-judge 会偏好自家模型族的输出。方法论的转向值得重视：当基础能力接近饱和，“基准的鉴别力（discriminative power）”比“基准的覆盖面”更关键，一个好的新基准应当能回答“现有系统在什么条件下失效”，而非仅提供又一个排行榜。

③ 上下文与检索：从“越多越好”走向“成本—性能联合优化”

三条互补证据共同修正了一个流行直觉。UT Austin 发现，以削减 token 为目标的压缩策略可能让 agent 慢 20%–80%，因为按步压缩会增加模型调用次数；CorpusMap 则证明，预先对语料做结构化（实体页 + 跳转）能同时提升质量 6.4–11.7 分并降低 34%–57% 的输入 token；Braintrust 的评测显示，agentic search（grep/find/读文件）与向量检索在编码任务上达到相同准确率，但向量检索成本约为 4 倍，原因是分块丢失了上下文、迫使 agent 反复搜索。合起来看，上下文工程的目标函数应改写为“端到端任务成本”，而语料结构与检索方式的匹配，可能比单点的压缩率或嵌入质量更重要。

④ 多 Agent 的理性降温

尽管工业界正把多 agent 推向产品主线，学术侧出现了明确的反向证据。OpenAI o1 及后续推理模型的早期奠基者之一 Noam Brown 指出，多智能体容易获得超出其实际贡献的关注：在一项“一万个 agent 解世界级难题”的讨论中，多 agent 的贡献不足 10%，真正支撑突破的是足够强大的通用基础模型以及让其持续运行、并行思考的能力；且目前尚无充分实验数据说明万级 agent 规模下的协调效率。研究含义清晰：agent 数量增加不等于能力成倍增长，有效交流、共享上下文、减少重复劳动与形成分工才是决定性变量。这为“scaling agents”类工作提出了更严格的实验要求——必须报告并行增益相对于单模型多采样（best-of-n）的净收益。

⑤ AI for Science：可验证性成为新的方法论瓶颈

本期 AI for Science 的两条进展恰好构成一组对照。Caltech 团队在三维无强迫欧拉方程上推进奇异性研究，较“人工多尺度构造”路线更接近本质目标；JEPA-Anything（arXiv:2609.20800）则试图用统一的世界模型骨干跨越分子、细胞、流体、病人、机器人乃至天气等异质领域，把“预测式表示学习”推向通用化。但学术层面真正的新问题是verifiability：当 AI 参与猜想生成与证明搜索，优先权如何认定、结论由谁复核、克雷研究所这类机构如何接纳机器辅助成果——欧拉方程事件中的 authorship 争议正是一个预演。可以预期，“机器辅助数学/科学”的贡献界定与复核流程，会在未来一年内成为比算法本身更受关注的制度建设议题。

⑥ 开放权重的“效率前沿”与学术—工业界人才流动

Reflection 的 Beam 释放了一个值得跟踪的信号：西方开放权重阵营可能不再单点对标“规模前沿”，而是以推理效率前沿（约 1/3–1/4 的推理计算量）作为差异化路线；与此同时 NVIDIA 以 Nemotron-Labs-3 系列持续供给领域专精开放模型。另一方面，UC Berkeley 教授宋晓冬（Dawn Song）团队与 Meta 的合作在入职约 4 个月后传出“工作风格不合”而分道扬镳——她本人是计算机安全领域最高被引学者、动态污点分析经典论文的提出者。这一事件提示：顶级学术团队与企业超级智能实验室的融合并非必然，其摩擦点（研究节奏、安全研究的独立性、成果发布自由度）值得关注，也可能影响未来 AI 安全人才的流向与开源产出。
