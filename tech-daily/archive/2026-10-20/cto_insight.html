设计正在成为新的护城河：Figma 在 Claude Design 冲击下仍增长 48%

Figma 创始人兼 CEO Dylan Field 在 All-In 播客中给出一个反直觉判断：“人们很容易把模型的进步误认为产品的进步。”尽管 Anthropic 以 Claude Design 正面进入设计工具市场，Figma 仍交出了营收同比增长 48% 的成绩单。他的逻辑是：当代码生成成本趋近于零、应用供给指数级爆炸时，用户每天真正使用的应用数量几乎不变，真正稀缺的是审美、品牌调性、产品判断和情感共鸣。

为什么重要这对 CTO 的直接含义是：把工程资源继续押在“把功能做出来”上的边际收益正在下降。技术壁垒正从实现能力转向“定义什么值得被实现”的能力，工程组织需要更靠近设计与用户研究，而不是只做需求承接。

企业级编码 Agent 的 ROI 已被量化：Monzo 内部 Agent 贡献 10% 以上合并 PR

Monzo 的自研编码 Agent 最初只是 Slack 里的一个表情反应，如今每天运行超过 1,800 个任务，撰写全公司技术团队 10% 以上的已合并 PR，并进一步承担事故处理、on-call 数据质量检查和非工程师的需求。Monzo 团队把成功归因于已有的“许多小乘数”：连接内部工具与知识的 MCP 网关、为受监管银行设计的沙箱化 Agent 编排系统，以及把 Agent 本身变成可复用构建块的平台。

为什么重要这提供了一个可复制的企业 AI 落地范式：价值不来自单点模型能力，而来自内部平台、权限体系和数据通路的组合。对于正在做 AI 试点的公司，问题不是“选哪个模型”，而是“有没有把 Agent 接入真实工作流的基础设施”。

“卖 Token”不是一门好生意：需求暴涨与利润承压同时发生

国家数据局数据显示，中国日均 Token 调用量已从 2024 年初的约 1,000 亿增长到 2026 年 3 月的 140 万亿，两年多增长超过 1,000 倍。但供给侧并不好过：九章云极 2025 年收入 10.98 亿元，九成以上仍来自智算基础设施解决方案；硅基流动 2025 年收入增长超 6 倍，毛利率却跌至 -24%。Tech Fund 的估算则显示，中国以外市场年底 AI 年化收入约 4,140 亿美元，而过去 3.5 年 9,310 亿美元资本开支按 6 年设备寿命计算，整体内部收益率约 12%。

深度分析

两个需要进入季度经营会议的议题

算力经济的拐点：资本开支、单位成本与价值转移

需求仍然强劲，但“卖算力”的商业模型正在被价格通缩和资本周期同时挤压。真正的问题不是 AI 有没有需求，而是价值最终留在哪一层。

需求侧：Agent 把 Token 消耗推上一个新量级

Cisco 总裁兼 CPO Jeetu Patel 给出了一个关键数据：Agent 在 2026 年 2 月超过人类成为 Token 消费主体，到 8 月消费量增长 14 倍，目前达到人类的 5 倍。他认为当前只有不到 2% 的人是 Agent 的重度用户，而 15 个月内这一比例会升至 30% 到 40%。中国市场的日均 Token 调用量也在两年多内增长超过 1,000 倍，达到 140 万亿。需求侧的增长是真实的，且远未见顶。

价格侧：单位成本正在快速坍塌

DeepSeek V4.1 Flash 在 Code Arena WebDev 榜单以 1670 分成为排名最高的开源模型，仅落后 GPT-6 Sol 12 分，单项任务平均费用较上一版本下降约六成。其高峰时段每百万 Token 输入价格 2 元、输出 8 元，空闲时段分别为 1 元和 4 元，缓存命中时输入价格低至 0.04 元。OpenAI 则推出 12 小时 prompt caching，让长驻 Agent 可以跨小时复用上下文并按缓存输入价计费。模型能力在追赶，价格却在持续下探，这是典型的供给过剩早期特征。

资本侧：高投入与低回报的张力

Tech Fund 估算，中国以外市场年底 AI 年化收入约 4,140 亿美元，其中 Anthropic 与 OpenAI 合计 1,870 亿美元，Meta 与 Google 的 AI 广告增量 1,080 亿美元，云厂商 660 亿美元，AI 原生应用与 SaaS 330 亿美元，其他 200 亿美元。按 6 年设备寿命计算，过去 3.5 年 9,310 亿美元 AI 资本开支的整体 IRR 约为 12%。这不是一个糟糕的数字，但远不足以支撑所有参与者同时获得高回报。市场已经开始重新定价：费城半导体指数 8 连跌，存储芯片指数单段跌幅 17.6%，SK 海力士与三星单周分别下跌 24.3% 和 17.8%。有分析甚至预言 80% 的 AI 云厂商活不过四年。

结构侧：从“卖 GPU 小时”到“可编程的数据中心”

SF Compute 正在把软件定义网络的历史复制到 GPU：过去自建超算集群需要 5,000 万到 1 亿美元的前期投入，如今可以按小时买卖 GPU 算力，并程序化控制整个栈。Tenstorrent 则以 62 亿美元估值完成 15 亿美元 E 轮融资，估值较 2024 年的 26 亿美元翻倍以上，说明资本市场仍在押注英伟达之外的替代算力。与此同时，英伟达自己正在向软件授权、云收入分成和太空算力延伸。这些动作指向同一个结论：单纯卖算力的利润率会被压缩，价值向调度、软件、数据和应用层迁移。

CTO 判断：未来 12 到 18 个月，算力采购的核心能力不是“拿到更多卡”，而是“以更低的机会成本获得可迁移的算力”。建议把多云、多芯片、短周期合约和开放推理栈作为默认架构，对 3 到 5 年的长期承诺做压力测试，并把利用率和折旧纳入 AI 项目的单位经济模型，而不是只看调用量。

企业 AI 的瓶颈正从模型转向组织

Monzo、Cisco、Webflow、Miro、Capital One 的案例共同说明：Agent 放大的是既有平台和组织能力，而不是替代它们。没有打通的工作流，模型再强也无法产生 ROI。

成功案例的共同点：先有“小乘数”，再有 Agent

Monzo 的编码 Agent 之所以能贡献 10% 以上的合并 PR，是因为它背后有 MCP 网关连接内部工具与知识、有面向受监管银行的沙箱编排系统、有把 Agent 变成构建块的内部平台。Cisco 把 AI 部署进五家大型银行，靠的不是等待 12 个月的合规周期，而是用 Agent 修复 CVE、验证备份与恢复、检查 LLM 评审中的 PII 泄漏，把合规问题转化为工程问题。Eon 则用统一的 MCP 网关替代了每工具独立凭证和本地 MCP 进程，让跨 AWS、GCP、Azure 的 Agent 访问成为可能。

真正的阻力：隐性知识难以被流程化

a16z 发布的 Steven Sinofsky 观点切中要害：大多数工作依赖“know-how”，而把这种 know-how 转成 Agent 可执行的逐步指令极其困难。他说，让任何一个岗位的人画出自己工作的流程图，大多数人都会失败；一个 50 人的市场团队里，可能只有一个人真正理解并记录得清楚。这意味着企业 AI 的瓶颈不是模型智商，而是组织把隐性知识显性化的能力。Agent 实际上是在逼迫企业开发“下一层抽象”，这本身就是一项组织工程。

SDLC 正在被重写：先发布，再定义需求

Webflow CPO Ben Haefele 描述了 AI 原生开发的新顺序：想法 → 已部署的代码 → 测试 → 设计 → 需求。文档不再是起点，而是你确认要发布的那个版本之后的产物。Miro CPTO Jeff Chow 在一年内与 200 多家客户交流后观察到，多数企业已经解决了“执行”，却淹没在无法转化为业务影响的产出中。Capital One 首席软件工程师 Max Kanat-Alexander 则提出“可抛弃软件”概念：代码质量是否重要，取决于这段软件准备活多久、坏掉会伤到谁、有多少系统依赖它，以及重写是否真的便宜。

合规与数据主权成为产品能力

Cisco 在银行场景中发现，零泄漏和数据主权“从来不是免费的”；LLM 评审本身也可能泄漏 PII。Google 则把 Gemini 企业搜索和开放权重模型部署到 GDC 的气隙环境中，服务国防、情报和关键基础设施客户。美国国土安全部要求联邦民事部门停止采购并清除 DeepSeek 相关产品的消息（目前来自社交媒体，需进一步核实）进一步说明：模型选择已经不只是技术决策，而是地缘政治和供应链风险管理的一部分。

CTO 判断：不要再把 AI 预算主要投向“模型试点”。更高回报的投入顺序是：统一 MCP 网关与身份权限 → 沙箱化 Agent 运行时 → 数据与知识通路 → 评估与可观测性 → 最后才是模型选型。衡量指标也应从“做了多少个试点”改为“AI 生成 PR 占比、每日 Agent 任务数、单任务成本、事故恢复时间”。

04

CTO 视角

未来一个季度可以立即推进的六件事

把“模型无关”和“多芯片”写进架构原则

建立统一推理网关，集中处理模型路由、缓存、批处理、限流和成本核算。优先评估 vLLM、SGLang、llm-d 等开源推理栈，避免把关键业务绑定到单一云厂商的托管端点。对长驻 Agent 使用 12 小时 prompt caching 等机制降低上下文成本。

用三个指标管理 AI 投入，而不是试点数量

建议跟踪：AI 生成代码占已合并 PR 的比例、每日 Agent 完成任务数、单任务全成本（含模型、算力、人工复核）。这三个指标能直接反映 Agent 是否进入真实生产流程，也能避免“演示很成功、上线没效果”的常见陷阱。

先建 Agent 基础设施，再谈规模化

优先级依次是：MCP 网关统一内部工具与知识接入、沙箱化 Agent 运行时、身份与最小权限、全链路审计、数据边界与脱敏。Monzo 与 Eon 的案例说明，这些“小乘数”决定了 Agent 能否从演示走向每天数千次的任务执行。

算力采购做“反脆弱”组合

采用多云、多芯片、短周期合约，保留迁移权和数据导出权。对 3 到 5 年的长期承诺做压力测试：如果 Token 价格再降 50%、如果新一代芯片提前上市、如果供应商被地缘政治限制，合同是否仍然合理。把利用率和折旧纳入项目 IRR 测算。

重写 SDLC，并给代码分“保质期”
