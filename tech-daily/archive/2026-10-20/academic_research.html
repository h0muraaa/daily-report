后训练强化学习arXiv 2609.35954

ROSS：让模型重新学习自己“过期”的 rollout[1][27]

在 RL 与 on-policy 蒸馏中，参数更新前的自生成轨迹通常被当作“过期数据”丢弃。小红书 AllSpark 团队的 ROSS 认为，历史轨迹对后续策略仍可能兼具兼容性与互补性：它包含当前策略已不再稳定复现、但曾经探索成功的有效行为。方法保留完整历史轨迹作为上下文，用结果验证器筛出正例，再以分阶段 LLM 评审标注决定哪些模型生成的 token 参与损失，只对选中的片段做监督，而不是整条轨迹照单全收。实验覆盖领域 RL、多教师 on-policy 蒸馏（MOPD）与 Agentic RL：Qwen3.6-35B-A3B 的六基准平均从 58.40% 提升到 62.20%，SWE-bench Verified 从 64.20% 提升到 68.40%；在相同保留样本下去掉 token 级掩码后平均降至 58.49%，说明片段级选择而非仅按结果过滤才是增益来源。该工作把历史轨迹从一次性消耗品变成了可离线复用的训练资产，也为“持续学习”提供了一个不依赖新采样的低成本入口。

关键数据：MOPD 六基准 58.40→62.20 · SWE-bench Verified 64.20→68.40 · 无需新 rollout 来源：小红书技术REDtech（原文）

Agent 记忆多模态评测arXiv 2605.29341

WorldMemArena：把多模态 Agent 记忆拆成“写—维护—检索—用”[2][28]

现有记忆评测多以长对话问答正确率收尾，无法区分失败究竟发生在没写入、没更新、没检索到，还是检索到却没有用上。UCSB、斯坦福、ETH、约翰斯·霍普金斯、CMU 与 J.P. Morgan 的研究者提出 WorldMemArena，把记忆定义为写入、维护、检索、使用四阶段生命周期，构建 400 个多会话多模态任务，分为“终身演化”与“Agent 执行”两种设定，并为记忆点、更新、干扰项与证据链提供标注。论文的主要结论是：更好的写入与存储并不保证更好的任务表现，关键在于回答时是否正确使用记忆；多模态记忆仍是瓶颈，系统在跨域与真实执行任务上表现不稳定；手工设计的记忆系统更结构化但适应性差，harness 型记忆 Agent 更灵活却成本高、可靠性高度依赖 harness 设计。对做记忆系统的研究者，这意味着消融实验应报告阶段级指标，而非只报告端到端准确率。

关键数据：400 个多会话任务 · 2 种设定 · 4 阶段诊断 · 代码与数据集开源 来源：机器之心（原文）

记忆架构基础模型arXiv 2610.26825

MemT-1.0：把长期记忆写进模型内部状态[3][29]

记忆张量发布的 MemT-1.0 不再把历史信息作为外挂文本反复塞入上下文，而是在主干注意力之外并行一个原生记忆块，用 Gated DeltaNet-2 完成 token 级的擦除、写入与遗忘，并以 Mixture-of-Storage 扩展记忆容量。Flash 版为 288B 总参数、17B 激活、336M 动态记忆，Nano 版为 36B/3B/10M，基于 34B token 的两阶段继续预训练与后训练。SWE-bench Verified 上，Nano 的平均成功率从无经验基线 66.07% 提升到执行中注入经验的 69.73%；三次运行全部成功的比例从 54.00% 提升到 61.6%（执行中为 62.8%）。在 128K 历史长度下，报告约 1.86 倍端到端推理加速与 66 倍持久存储压缩，且权重、代码已在 GitHub、Hugging Face 与 ModelScope 开源。这项工作把“记忆”从上下文工程问题改写为架构与训练目标问题，其代价与收益需要在中立基准上继续复核。

关键数据：288B/17B · 336M 动态记忆 · SWE-bench 66.07→69.73 来源：机器之心（原文）

世界模型手术仿真Hugging Face

Cosmos3-H-Dreams：从台面缝合走向临床手术的实时世界模型[4]

NVIDIA 在 16B 的 Cosmos3-H-Embodied-Nano 基础上，以约 22.3 万条具身样本预训练，再用胆囊切除临床录像与 CMR Versius 器械运动学适配出 Cosmos3-H-Dreams。模型接收初始手术画面与 28 维动作（双臂位姿、夹爪、能量控制、摇杆轴与按键），自回归生成未来视频；训练先在 24 帧、再扩展到 72 帧（10 Hz 下 7.2 秒）的双向教师上适配，随后以 causal teacher forcing 与 Self-Forcing 蒸馏为 4 步/2 步因果学生，并用 FadeMem 压缩持续增长的 KV 缓存。系统可在单张 RTX PRO 6000 上实时交互，定性 rollout 展示了器械跟随与组织形变的一致性。需要强调，官方将其定位为研究模拟器而非临床验证系统，且未报告定量基准；视觉真实感并不等于生物力学正确性，这恰是审稿时应追问的核心问题。

Agent 记忆提示学习Hugging Face

ALTK-Evolve：不改权重，用“学到的操作手册”登上 τ²-bench 榜首[5]

IBM Research 的 ALTK-Evolve 让智能体在训练任务上运行，由同一 LLM 分析成功与失败轨迹，提炼带支持度计数的行为准则，再在推理时把准则块追加到系统提示之后；模型权重、工具、策略与 ReAct 脚手架均保持不变。在 τ²-bench 上，零售域基线平均准确率 78.1%、Pass^4 57.5%，完整准则集（292 条）提升到 82.5% 与 67.5%，以 Pass^4 计位列第一，并超过在合成零售数据上微调的 RAFT-30B-A3B（61.4%）6.1 个百分点；航空域使用 GPT-5.5 达到 82.0%。代价是输入 token 成本上升（零售 +65%），但准则块固定、可被 prompt caching 大部分抵消，且匹配任务上的对话轮数略有下降。值得注意的是，最优准则数量依领域而变：零售受益于完整集合，航空域最可靠的配置反而是仅 31 条的高置信核心，说明“记忆规模”并非单调增益。

关键数据：零售 Pass^4 57.5→67.5 · τ²-bench #1 · 零权重更新 来源：Hugging Face - Blog（原文）

递归自我改进科学发现arXiv 2610.23839

DiscoveryRSI：用递归自我改进搜索可验证的科学假设[6][30]

DiscoveryRSI 把递归自我改进（RSI）用到生命科学假设生成：以多 Agent 进化搜索扩展假设树，把选中的研究计划编译为可执行的 Harbor 任务，再通过假设信用分配、harness 重放与再发现三种机制递归学习；同时提出 DFM-Bench，从假设质量、修订路径、发展路径与完整研究运行四个层面评估。开源模型 DiscoveryRSI-27B 在四个生命科学领域的自动假设质量从基座 4.86 提升到两轮自我改进后的 5.39，可证伪性与数据可解析性同步提高。最受关注的指标是与训练截止后发表研究的相关率：27B 模型为 6.3%，高于 GPT-6 的 2.5% 与 Claude Opus 5 的 2.3%。该结果来自社交媒体转述与作者自评，相关率不等于正确率；在引用前应阅读全文，确认时间切分、检索协议与人工评审规模。

Jiuwen Symbiosis：让物理智能体接管湿实验[7]

华为 openJiuwen 团队联合算力平台公共事业中队，以电催化场景为例，把大模型生成的实验方案下发到真实物理设备执行。难点不在生成步骤，而在物理世界的可行性判断与状态约束：移液前瓶盖是否打开、加热工位是否空闲，异构设备并发、异常扰动，以及每个样品与设备状态变更的可追溯性；湿实验没有“撤销键”。Jiuwen Symbiosis 以“感知—规划—执行”的闭环承担这层底座，并与 ScienceDiscovery 的树搜索探索预算分配配合，形成从假设到实验的持续流程。该案例的价值在于把“AI 科研”的评测对象从文本任务推进到可审计的物理操作序列，也暴露了该方向的核心瓶颈：验证成本与安全约束远高于数字环境。

Agent 评测基准方法学NeurIPS 2026 Workshop

编码智能体基准与真实任务流存在系统偏差[8]

JetBrains Research 分析了 IDE 中 4,782 个真实智能体会话，并与三个公开 Agent 对话集比较，指出 SWE-Bench Pro 等基准通常把任务表示为单条用户消息、几乎总是新功能或修 bug，而真实开发者的前五条消息呈现修复、解释、重构、测试等交替分布。论文《Coding-Agent Benchmarks Should Match Their Users’ Task Flows》被 NeurIPS 2026 的 Evaluation of Interactive Agents workshop 接收，主张基准应匹配用户任务流的类型分布与会话结构，否则高分未必对应真实生产力。对做 Agent 评测的研究者，这是一条可直接操作的建议：报告任务分布与交互轮次，而不只报告单轮通过率；对做训练的研究者，则意味着训练数据的会话形态也值得与部署分布对齐。

关键数据：4,782 个真实会话 · 3 个公开对话集 · NeurIPS 2026 workshop 来源：The JetBrains Blog（原文）

PAPER 01 · VISUAL HARNESS · ARC-AGI-3

VISTA：不训练模型，用无损视觉记忆把交互式推理推到人类动作效率[9][25]

技术报告 · MIT · Qiushi Han, Keya Hu, Linlu Qiu, Cathy Wu, Kaiming He · arXiv:2610.02200 · 开源实现

研究背景

ARC-AGI-3 这类交互式视觉推理任务不提供显式规则与目标，智能体必须通过观察与行动自行发现玩法。主流系统通常把屏幕抽象为文本、代码或数值网格，再交给语言模型推理；这种抽象会丢失对象外观、空间关系与动画中间帧，且在长程任务中，有限上下文窗口使历史经验难以持续参与决策。问题因此不只是“模型会不会推理”，而是“模型能否在正确的时刻取回正确的视觉证据”。

核心创新

VISTA 不改动基座模型权重，而是把原始截图作为无损视觉记忆保存在模型上下文之外，按回合与帧索引。模型可以主动回看任意历史帧、放大矩形区域、跨时间比较状态、重放动作展开过程，并读取精确像素值；同时维护 GUIDE.md（跨关卡理解）与 WORKING.md（当前关卡草稿）两份持久笔记。上下文将满时，Agent 写入交接摘要并在新上下文中恢复，记忆、笔记与动作历史得以延续。Harness 只机械执行工具调用并返回图像或像素值，不做程序合成，也不内置手工世界模型——这与依赖代码化环境建模的同期系统形成鲜明对比。

实验结果

搭配 Claude Opus 5.0，VISTA 通关全部 25 个公开 ARC-AGI-3 游戏，相对人类动作效率（RHAE）达到 100.00，而同一模型的官方实现为 40.68；总动作数 7,302 次，比首次游玩的人类基线 17,135 次少 57.4%。GPT-5.6 Sol 同样全通关，RHAE 为 99。开源 GLM-5.3 Flash 320B 加 VISTA 达到 66.93（官方基线 1.89，去掉视觉 harness 为 13.27）；在 3D 渲染设定中达到 84.12，BabyVision 准确率从 41.0% 提升到 63.2%。消融显示图像与文本网格性能接近，但每局 token 消耗为 30.7M 对 71.9M；200K 上下文最优，4 倍图像缩放节省约 75% 的图像 token。

学术意义

这项工作把“模型能力”和“测试时脚手架”明确解耦：同一组权重仅因记忆与检查接口不同，就从远低于人类提升到人类水平动作效率。它提供了一条不依赖程序合成的多模态长程推理路线，并把 harness 本身变成可复现、可消融的研究对象。对领域的影响可能超过单个基准成绩：如果视觉记忆可以替代文本化环境抽象，那么许多“必须把世界转成代码”的假设都需要重新检验。

局限与追问

评测集中在游戏与合成视觉任务，虽然迁移到 3D 与 BabyVision，但真实机器人、开放世界与噪声视觉尚未验证；RHAE 以人类动作效率为参照，不能直接代表任务理解深度。无损记忆与频繁工具调用带来显著推理成本，论文自己的 token 数据也表明上下文策略是关键变量。此外，“模型主动检查”依赖工具调用的可靠性，错误回看或过度回看可能引入新的失败模式，值得后续做细粒度误差分析。

PAPER 02 · FAIRNESS EVALUATION · PROCESS SYMMETRY

FairStress：公平不只看最终选择，还看模型是否同样容易被说服[10][26]

Ai2 · benchmark + 技术报告 + 代码 · 300 个场景 / 29 个领域 / 超过 1,300 万测试用例 · 15 个模型

研究背景

公平性评测常以最终选择为准：交换候选人的姓名或身份标签，看模型是否仍选同一人。但“选对人”可能掩盖更深的不对称——模型可能更容易被说服改变决定、给出不同措辞的解释，或在内部表征中编码不同的群体信息。若只用结果指标，这些差异不可见，去偏方法也可能被高估。

方法设计

FairStress 构建 300 个双候选场景，覆盖招聘、医疗、信贷、教育、住房、刑事司法等 29 个领域；部分场景有明确更优候选，部分刻意模糊。身份信息以四种条件变化：无信息、人口统计编码姓名、暗示身份、显式标签。每个场景再配成对的对抗性前缀（权威、社会共识、证据、法律、历史劣势等），分别偏向两位候选，组合后超过 1,300 万测试用例；FairStress-Core 用项目反应理论选出 5 万条子集以降低评测成本。指标不仅包括是否改变决定，还包括解释用词与内部激活。其公平定义是“对称性”：无论哪一方受益，模型都应以同等标准判断、以同等强度抵抗说服。

主要发现

无身份信息时，模型行为相近；身份越显式，行为越不对称，出现“反刻板印象过度矫正”：为了偏向少数族裔编码候选而放弃正确选择的平均差距，在暗示身份时为 6.9 个百分点、显式标签时为 9.3 个百分点（15 个模型）。在模糊场景中，Claude Opus 5、GPT-5.5 等前沿模型约 60–65% 选择少数族裔编码候选；匹配对抗前缀下，向少数族裔候选切换比向多数族裔切换高 8.8–42.4 个百分点（12 个模型与模式组合）。即使选对，解释也不同：少数族裔选择更多使用 resilience、diversity、barriers 等词，多数族裔选择更多使用 evidence、criteria、detailed 等程序性词汇。内部激活预测选择方向的准确率约 73%（Gemma-3-12B、Qwen2.5-7B），文本描述为 57–59%（随机基线 50%）；移除姓名使激活准确率下降约 18 个百分点。

干预与数据审计

9 种去偏干预大多不能可靠降低不对称。激活引导虽减少了偏向，却使 Qwen2.5-7B 在明确场景的准确率从 98% 降到 47%；反事实思维链最接近对称稳健，且在较大程度上保持准确率，但模糊场景仍偏向少数族裔编码候选。对 Olmo 3 训练数据的审计发现约 9.9 万条拒绝训练样本、2.8 万主题簇，其中只有 9 个与择优决策相关且全部为拒绝样本，不同群体的框架也不均衡——这为“偏差从何而来”提供了数据侧线索。

意义与局限

FairStress 把公平性从“结果均等”推进到“过程对称”，让评测能够区分决定稳定性、解释一致性与内部表征差异，也为去偏方法的比较提供了更严格的压力测试。局限同样明确：它采用的平等主义公平观不覆盖其他规范理论；激活分析仅覆盖两个模型；测量结果会受聊天模板、措辞与打分方式影响（与 BBQ 的对比甚至出现方向差异）；场景为合成构造，外部效度仍需领域专家复核。引用其结论时，应同时报告评测配置，否则“公平/不公平”的判断可能只是配置产物。

§ 4

趋势观察

Trends & Outlook

  1. 记忆正从“外挂文本”变成“内生机制”，评测单位从结果转向阶段

    MemT-1.0 把记忆写进参数化状态[3][29]，ALTK-Evolve 把经验压缩成提示级 playbook[5]，VISTA 把原始视觉帧保存在模型外部并按需调回[9][25]，WorldMemArena 则把记忆拆成写入、维护、检索、使用四个可诊断阶段[2][28]。四条路线指向同一个判断：记忆的瓶颈往往不在“存不下”，而在“该更新时没更新、该用时没用上”。对论文写作的直接含义是，记忆系统需要报告阶段级消融、上下文与 token 成本、以及随时间漂移的稳定性，端到端准确率已不足以支撑结论。

  2. Harness 与测试时策略成为与权重同等重要的自变量

    VISTA 在完全不改权重的情况下，把同一 Claude Opus 5.0 的 RHAE 从 40.68 推到 100[9][25]；ROSS 证明旧 rollout 在离线阶段仍可提取有效监督[1][27]；DiscoveryRSI 通过重放研究 harness 做信用分配[6][30]。这也与业界关于 RSI 与持续学习的讨论相互印证[23]。这些结果共同说明，模型能力不是权重的单值函数，上下文组织、工具接口与重放策略同样决定上限。未来 benchmark 论文若不报告 harness 细节、token 预算与上下文策略，跨系统比较将失去意义；反过来，harness 本身也值得作为独立贡献来设计和消融。

  3. AI for science 的重心从“提出假设”移向“可验证闭环”

    DiscoveryRSI 用 DFM-Bench 评估假设与完整研究运行[6][30]，Jiuwen Symbiosis 把方案下发到电催化湿实验设备[7]，ScienceDiscovery 用树搜索分配探索预算[31]，浙大“求是引擎”把 72 小时自主科研过程公开直播[21]，港科大 Fourth Institute 则尝试为人类与 Agent 社群搭建持续协作的科研平台[22]。共同瓶颈已从生成想法转为验证：数字环境需要可判定的 verifiable reward，物理环境需要状态可追溯与安全约束，长程研究还需要把功劳正确分配给中间假设。谁能降低验证成本，谁就更可能定义下一阶段的科研 Agent 范式。

  4. 评测方法学成为独立贡献，且开始正面处理分布偏移与过程公平

    FairStress 证明“最终选择相同”可能掩盖抗说服能力、解释方式与内部表征的不对称[10][26]；WorldMemArena 指出存储质量与使用质量是两件事[2][28]；JetBrains 则用 4,782 个真实会话说明基准任务流与开发者真实分布存在系统偏差[8]。与此同时，陶哲轩对工业界数学发布中“炸鱼式做题”和正负号错误的批评[20]，提醒社区：规模与公关速度不能替代形式化验证与可复现性。可以预期，NeurIPS/ICML 的评测类工作会更强调协议透明度、对抗压力测试与外部效度，而非再刷一个单一榜单。

  5. 开源基础设施降低跨硬件复现门槛，但 artifact 规范仍滞后

    TorchTPU 开源[11]、vLLM/SGLang 的 TPU 引擎[12]、llm-d 1.0[13] 与 TorchTitan 集成[14]，以及 PyTorch 2.15 的 MPS 改进[19]，正在把“只能在特定加速器上复现”的实验变成跨硬件可迁移的工程。MemT[3][29]、DiscoveryRSI[6][30]、Index-Translate[17]、Xing4.0[16]、Ming-3.0[15]、AnyLanguageModel[18] 与 VAST EdenLive[24] 等模型也同步释放权重或代码。但本期多数条目仍未同时提供训练数据配方、评测脚本与失败案例；对学术复现而言，权重只是起点。建议以“权重 + 数据/标注 + 评测代码 + 计算预算”作为 artifact 的最低标准，并在论文中显式报告未开源部分。
