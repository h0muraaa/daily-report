深度解读 · 商业模式

Neocloud 的“业绩狂飙、股价腰斩”：算力租赁的护城河还剩什么？

这是本周最反直觉的一组数据：CoreWeave 三季度营收同比 +168%、营业利润接近去年同期 4 倍，IREN 的 AI 云收入增至去年近 19 倍，Boost Run 营收同比 +496%——从财报看是“史诗级景气”；但同期股价较年内高点分别下跌 69%、72%、91%，小的玩家跌幅更极端。业绩与股价的背离，本质是市场在给“这门生意能持续多久”重新定价，而不是怀疑当期增长。硅基观察 Pro 的判断切中要害：过去几年 Neocloud 的日子太好过，英伟达帮忙解决资金、微软谷歌忙着送订单，几乎不愁算力租不出去；但一旦 AI 资本开支增速放缓、大型云厂商自建算力陆续投产，“算力不再稀缺”就是悬在头顶的达摩克利斯之剑。

护城河的拆解是关键。Neocloud 的核心资产是“GPU + 土地 + 电力 + 与英伟达的关系”，前者（GPU）会折旧、会过时，后三者（土地、电力、长约客户）才是真正稀缺、难复制的要素。市场担心的正是：当微软、亚马逊、谷歌的自建产能上线，Neocloud 在“算力转售”环节的议价权会被迅速抹平，剩下的价值也许只有手里的土地与电力——这更接近“重资产 REITs 或公用事业”的估值，而非“高成长科技股”。因此，股价的暴跌不是业绩证伪，而是估值范式的切换：从按“营收增速 × 高倍数”定价，转向按“折旧后现金流 + 资产残值”定价。

但反方观点同样成立：H100 一年期租金不降反升 60%、OpenAI 与 Anthropic 2027 年将吃掉全球约 30% 的新增算力，说明“算力短缺”在可预见的未来并未缓解。只要供需缺口存在，Neocloud 的现金流就有支撑；真正的分水岭在于“长约比例”与“客户集中度”——签了多年期大单的玩家，能把周期风险转嫁给下游；而靠现货短租、客户高度集中的玩家，则会在算力宽松时被率先出清。

📌 投资人启示：评估 Neocloud 时，别只看营收增速与 GPU 数量，要盯三个硬指标——① 长约占比与剩余合同期（对冲算力价格下行）、② 客户集中度（单一超大客户的风险）、③ 单位算力的电力/土地成本（真正的长期壁垒）。对二级市场而言，“业绩越好、股价越跌”往往是估值范式切换的早期信号，而非抄底理由；对一级市场而言，纯“算力转售”模式的估值溢价应显著低于“算力 + 能源 + 长约”一体化玩家。
📎 来源： 硅基观察Pro· 爱范儿（SemiAnalysis）
深度解读 · 估值与 Token 经济

Anthropic 的万亿估值：造富神话背后，是“Token 计价”的现金流折现

把 Anthropic 的造富故事拆开，会发现它是一道典型的“一级估值 + 期权杠杆”算术题。阮一峰周刊的数据显示，2024 年授予的期权每股仅 1.30 美元、上市后一度 80 余美元，半年内 60 倍量级的回报，让 5300 名员工里诞生约 600 位亿万富翁。这种财富效应的燃料，来自一级市场对“万亿级 AI 平台”的想象：1.17 万亿（一度冲 1.4 万亿）美元的市值，对应的是“AI 将重构软件与知识工作”的长期叙事。但叙事进入二级市场就要接受现金流检验——AI 前线报道其股价上市不足一周即跌破发行价，正是“私募高估值”与“公开市场即时定价”之间的时滞被一次性抹平。

更深层的变化在“计费范式”。本周多条新闻共同指向同一趋势：OpenAI 从 12 月起让 ChatGPT 的 Plus/Pro/Business 高级推理、Work Agent 与 Codex 任务共享同一份额度；同时承认此前“少计费”，修正后同类工作会更快耗尽额度——ChatGPT 正被改造成按 Token 消耗计价的“WorkGPT”。Anthropic 自身的护城河也在被“开源 + 低价”侵蚀：Sand.ai 以 0.5 元/秒、约 1/6 的价格切入视频生成，复刻文本模型“开源追平 → API 价格崩塌”的路径。当模型能力被快速拉平、计费与用量强绑定，万亿估值就必须回答一个尖锐问题：它的现金流，究竟来自“模型领先的定价权”，还是“规模化的单位算力效率”？

这也解释了 Dario 为何在上市一周内急着发长文——既要回应“AI 安全/控制权”的舆论，也在为商业化策略辩护。对投资人的含义是：模型层公司的估值，正在从“参数/榜单叙事”转向“单位 token 成本 + 付费转化 + 留存”的经营指标。造富神话证明了一级市场的定价能力，破发则提醒了二级市场的兑现纪律，两者共同构成 AI 模型赛道“高成长 + 高不确定”的完整定价画像。

📌 投资人启示：模型层标的宜用“期权 + 情景”框架而非单一倍数：① 看单位 token 的毛利与成本曲线（开源压低价格时，谁的成本更低谁活得久）；② 看计费与额度设计是否把收入绑定到真实用量（订阅 → 按量迁移是毛利重估信号）；③ 把“上市即破发”当作一级退出窗口的定价风险提示——最后一轮的估值溢价，可能正是 IPO 投资人的亏损起点。
📎 来源： 阮一峰的网络日志· AI前线· 爱范儿
