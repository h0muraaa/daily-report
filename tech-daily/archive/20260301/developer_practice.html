Context Mode：高效压缩AI工具输出，守护上下文窗口 工具
@mksglu开发的开源解决方案Context Mode作为MCP服务器，可将Claude Code中的工具输出消耗减少98%。典型场景下将315KB原始数据压缩至仅5.4KB，有效会话时长从约30分钟延长至约3小时。核心技术包括沙箱隔离执行（支持10种语言，仅返回stdout）和精确知识库检索（Markdown按标题分块存入SQLite FTS5，使用BM25+词干+模糊匹配）。这是解决大模型上下文窗口瓶颈的实用方案。

Agent Harness：智能体运行框架解析
Agent Harness是围绕LLM的编排层，负责管理提示词构建、工具执行、策略检查和循环控制。核心职责包括：指令分层（组装system prompt、harness指令、AGENTS.md、工具定义）、行动中介（验证工具调用schema）、循环控制（管理轮次边界和停止条件）、策略执行（权限边界和确认规则）、记忆策略（上下文压缩和子Agent管理）。

Prompt Caching深度优化指南
提示缓存的核心原理是在服务器端持久化KV Cache。关键特性：基于精确前缀匹配（一个字符差异都会导致失效）、存储的是KV矩阵而非原始文本、默认5分钟TTL。最佳实践包括：将System Prompt和Tools放在请求开头确保缓存命中、使用1小时长TTL选项、监控缓存命中率。Bedrock Claude API的计费：缓存读取仅为常规输入的10%（$0.30 vs $3.00/百万tokens）。

On-Policy Distillation深度解读
On-Policy/Self-Distillation(OPSD)使用Policy本身作为Teacher模型。核心优势：相较于GRPO提示性能同时避免过多Aha Moment、缓解灾难性遗忘、天然适合与GRPO结合提供token-level密集奖励。实现难点是获取Teacher模型，Self-Distillation被验证为可行方案。技术实现兼容RL框架，便于开发。
