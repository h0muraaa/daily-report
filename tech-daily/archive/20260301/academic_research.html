研究动态

GPT之父Alec Radford新作：Token级数据过滤可从模型"大脑"深处切除危险知识
这项由Anthropic、斯坦福与Alec Radford联合发布的研究挑战了大模型安全领域的核心假设。研究提出在预训练阶段通过Token级别的数据过滤直接"切除"危险知识，而非依赖发布后的RLHF微调。实验发现，对于18亿参数的模型，Token级过滤能导致目标领域的学习效率下降7000倍，且模型越大，过滤效果越好。这意味着攻击者想要恢复被删除的能力，将付出难以承受的算力代价。该方法为AI安全提供了一种更本质的解决路径。
论文 来源: 机器之心 原文: arXiv:2601.21571
JavisDiT++：统一建模与优化的联合音视频生成框架
HuggingFace上发布的一篇重要论文，提出了JavisDiT++框架，实现了联合音视频生成的统一建模和优化。该研究解决了视频与音频同步生成的关键技术难题，在生成质量和时序一致性方面取得突破。多模态生成是当前AI研究的前沿热点，该工作为构建更自然的人机交互系统提供了重要的技术基础，有望在虚拟内容创作、教育视频生成等场景发挥重要作用。
论文 来源: AK(@_akhaliq) 原文: HuggingFace Papers
On-Policy/Self-Distillation深度解读：使用策略本身作为教师模型
本文深入介绍了On-Policy/Self-Distillation (OPSD)技术，即使用策略模型本身作为教师模型进行蒸馏。相比GRPO，On-Policy Distillation在提示性能的同时避免了过多的Aha Moment，并能缓解灾难性遗忘。该技术天然适合与GRPO结合，提供token-level的密集奖励信号。OPSD的核心是最小化学生策略与教师策略在学生策略自身生成轨迹分布上的KL散度，可以使用Reverse KL或Forward KL。这为强化学习中的知识蒸馏提供了新的研究视角。
技术解读 来源: 大模型智能
GenericAgent：具备自组织、自学习、自进化能力的通用智能体
复旦大学肖仰华教授团队研发的GenericAgent实现了重要突破。该智能体不再是安装繁复、上限受限、难以迁移的传统智能体，而是下一代能在用户使用调教下快速学习与成长的数字生命。其核心特性包括：自组织记忆（记忆分层组织、持续精炼）、自适应学习（在交互中记住合理步骤和策略）、自主成长进步（通过Fork模式尝试多样策略并用更好的策略更新自己）。该系统已于2026年1月11日开源，代表了通用智能体研究的重要进展。
开源模型 来源: 机器之心 GitHub: pc-agent-loop
Context Mode：将AI工具输出压缩98%的上下文优化方案
开发者@mksglu发布的开源解决方案Context Mode解决了AI Agent工具交互中的核心痛点——上下文窗口被大量原始工具输出快速消耗。作为MCP服务器，它可将Claude Code中的工具输出消耗减少98%，典型场景下将315KB原始数据压缩至仅5.4KB，有效会话时长从约30分钟延长至约3小时。核心技术包括沙箱执行（工具在独立子进程运行，仅返回必要stdout）和精确知识库（Markdown按标题分块存入SQLite FTS5，使用BM25+词干+模糊匹配检索）。
开源工具 来源: meng shao(@shao__meng) 项目: claude-context-mode

📊 AI编程的实证研究：开发者如何编写AI上下文文件

首个关于开发者在开源项目中实际编写AI上下文文件的实证研究扫描了10,000个代码仓库，发现仅有466个（5%）采用了AGENTS.md、CLAUDE.md或Copilot instructions等AI配置文件。

研究发现，在155个AGENTS.md文件中，50%在初始提交后从未修改，仅6%有10次以上修订。最常见的文件内容包括编码规范、贡献指南和架构概览，但缺乏标准结构，团队间差异巨大。

学术价值：该研究揭示了AI辅助编程中一个新兴但尚未规范化的文档类型，为后续的标准化研究提供了数据基础。

来源: elvis(@omarsar0) 论文: arXiv:2510.21413

🎯 Agent Harness：智能体运行框架的系统性架构

Agent Harness作为围绕LLM的编排层，负责管理提示词构建、工具执行、策略检查和循环控制，使模型能够表现出自主的智能体行为。其架构包含五个核心职责：

1. 指令分层：组装系统提示词、harness指令、AGENTS.md文件及MCP工具定义
2. 行动中介：验证工具调用的schema合规性，执行工具，标准化返回结果
3. 循环控制：管理轮次边界、重试行为和停止条件
4. 策略执行：施加权限边界和确认规则以降低提示词注入风险
5. 记忆策略：控制上下文窗口内容，实现摘要压缩

来源: meng shao(@shao__meng) 详解: latentpatterns.com

开源资源

Open Cowork：开源版桌面虚拟同事
Open Cowork是Claude Cowork理念的开源增强实现，提供Windows与macOS的一键安装包。其核心是一个"沙箱化工作区"，模型被授权在指定Workspace内读写文件、调用工具，并通过内置Skills系统将数据加工成专业交付物。该工具支持PPT/Word/Excel/PDF等专业成果生成，也能通过GUI直接操作电脑完成复杂跨应用流程，是AI Agent从对话走向执行的重要开源实践。
开源工具 来源: 机器之心 GitHub: OpenCoworkAI/open-cowork
CoPaw：阿里开源桌面Agent工具
阿里桌面Agent工具CoPaw正式开源，用户可基于CoPaw进行二次开发，自由接入本地模型、编写Skills和接入专属消息应用。CoPaw原生支持钉钉、飞书、QQ、Discord、iMessage等聊天软件和平台，内置多种Skills，支持一键本地部署或通过阿里云计算巢和魔搭社区创空间一键云端部署，可调用千问系列等主流模型，是业界部署门槛最低的Agent工具之一。
开源工具 来源: 创业邦
Vercel Skills包管理器：find-skills
Vercel官方发布的find-skills是一个Skills包管理器，通过npx skills命令即可使用。核心功能包括：npx skills find [关键词]搜索Skills（支持交互式搜索）、npx skills add <包名>安装Skill、npx skills check检查更新、npx skills update一键更新所有已安装Skills。官方还提供了在线Skills搜索网站skills.sh，可浏览所有Skills。该工具为AI Agent的能力扩展提供了标准化的分发和安装机制。
开发工具 来源: 逛逛GitHub GitHub: vercel-labs/skills
Scrapling：自适应爬虫工具
Scrapling是一个新型爬虫工具，具备自适应解析能力——网站改版时选择器无需修改，它会自动通过相似度算法找到原来的元素。该工具反检测能力强，自带Cloudflare Turnstile自动过，解析器性能据称吊打BeautifulSoup。对AI特别友好，提供MCP server，可输出markdown格式。该工具为AI Agent获取网络数据提供了更可靠的技术方案。
开源工具 来源: Viking(@vikingmute) GitHub: D4Vinci/Scrapling

趋势观察

AI编程的三个阶段演进
Cursor工程师发文阐述了AI编程的三个发展阶段：第一阶段是代码自动补全（Tab、早期Copilot）；第二阶段是同步Agent，AI在编辑器中实时处理更复杂任务，但仍局限于本地环境、单次交互、即时响应模式；第三阶段是云端长期运行Agent（cloud/background/long-running agents），AI代理可在云端自主运行数小时甚至数天，支持并行多个代理（agent teams）、24/7不间断地构建、测试、迭代整个项目。第三个阶段已经加速来临，token就是燃料。
趋势 来源: Viking(@vikingmute) 原文: Michael Truell
"SDLC已死"——AI原生开发范式的兴起
Boris Tane提出，AI智能体并不是让软件开发生命周期变得更快，而是直接终结了它。传统SDLC（软件开发生命周期）的每个阶段都有对应工具和流程，但AI原生工程师并不了解SDLC、DevOps或SRE——他们从未做过敏捷规划，从未估算过故事点，也从未为等待PR审核而苦等三天。他们只管说出需求，智能体编写代码，查看、迭代、发布，所有环节同步推进。这代表了软件开发方法论的根本性范式转变。
趋势 来源: InfoQ
AI编程工具的开发者采纳实证研究
研究人员对开发者实际使用AI上下文文件的情况进行了首个实证研究。扫描10,000个仓库发现仅5%采用了AI配置文件，且大部分文件在初始提交后缺乏维护。这揭示了AI编程工具在真实开发场景中的采纳现状：虽然概念验证和Demo演示层出不穷，但真正在生产环境中系统化使用AI辅助编程的团队仍是少数。这一发现对AI编程工具的设计者和推广者具有重要参考价值。
