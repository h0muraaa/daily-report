今日要点 Key Takeaways

模型层继续「通缩」：MiniMax 成本降 70%，DeepSeek 以约 27% 价格拿到 37% 的前沿提升

MiniMax 发布 M3.1 Flash，官方称推理速度提升近 3 倍、使用成本降低 70%，在 DeepSWE v1.1 拿到 73.7%、OSWorld V2 拿到 61.7 分（国产模型第一）；其匿名版本 Space Bunny 此前已处理超过 200T Token。同一天，DeepSeek-V4.1-Flash-20261017 登顶 Agent Arena 开源模型第一、总榜第 11，中位任务成本仅 0.20 美元，用约为 GPT-6.1 Sol 27% 的成本取得了后者约 37% 的净提升。

这不是单点降价，而是采购结构的改变：前沿模型溢价正在变成「按任务购买的期权」，而不是默认配置。CTO 需要把模型路由、缓存命中率和任务级 eval 当成基础设施，而不是临时优化。

Anthropic 披露 90% 代码由 Claude 编写：瓶颈已从「写」转向「验证」与「基础设施」

Claude Code 约 90% 的代码由 Claude 自己编写，6 月至 9 月合并 PR 数量翻倍以上，回滚率反而下降超过 40%。其审查体系改为分层验证：PR 前由独立上下文的 subagent 审 diff、CI 强制阻塞、多个 AI 审查员并行找 bug 并由「验证者」投票过滤误报，内部 PR 获得实质性审查评论的比例从 16% 升到 54%；风险分级由分类器判定，低风险零人工、中风险一人、高风险两人，AI 审批不计入人工名额。

更底层的变化是基础设施跟不上：Anthropic 每天合并量从 5 月的约 2,500 次涨到 9 月的 3 万次以上，Monorepo 历史接近 100GB，最终由 7 名工程师用 5 个月重写版本控制系统 Scion，CPU 与内存占用降至原 Git 镜像方案的约 1/200。

Meta Prometheus 一期建成：目标约 100 万 GPU，训练竞争变成系统工程与能源竞争

Meta 在俄亥俄州 New Albany 的千兆瓦级超算 Prometheus 一期已完成，正在向约 100 万 GPU 规模扩展，并采用闭环液冷。Muse 系列基础模型即在此训练：预训练 goodput 达到 85% 以上、强化学习超过 90%，训练期间平均约 4.7 万 GPU 小时才发生一次中断。

当单集群进入数十万乃至百万 GPU 量级，决定模型进度的不再只是算法，而是供电、冷却、网络、故障恢复和调度效率。对多数企业而言，这意味着自建超大训练集群的门槛进一步抬高，外购算力时的「有效算力/有效工时」条款会变得比名义 GPU 小时更重要。

基础设施供应商风险被重新定价：VMware 涨价 400% 与微软退出 Nscale 交易

博通收购 VMware 后，Topgolf 面临的 VMware 使用成本预计上涨 400%，公司已将 1.2 万台虚拟机迁移到 VergeIO 的 VergeOS，累计节省基础设施总成本超过 1,130 万美元（约 7,560 万元人民币）；Gartner 预测到 2029 年将有 55% 的企业启动弃用 VMware 的概念验证。另一边，微软退出了与英国数据中心企业 Nscale 在埃塞克斯的合作，而 Nscale 正推进最高 350 亿美元的上市计划，失去锚定租户使其融资叙事受挫。

两件事指向同一个判断：在 AI 资本开支高企的周期里，供应商的定价权与履约稳定性都在变化。关键基础设施合同需要按「三年 TCO + 退出成本 + 替代路径」重新审视，而不是只看当前单价。

深度分析 Deep Dive

深度分析 01 · 工程组织

当 90% 的代码由 AI 生成，工程管理的最小单位从「人天」变成「变更」

Anthropic 公开的这组数字值得所有技术负责人认真对待：Claude Code 约 90% 的代码由 Claude 编写，6 月到 9 月合并 PR 翻倍，回滚率下降超过 40%。这打破了一个常见假设——AI 生成代码越多，质量越不可控。真正的变化不是「AI 会不会写代码」，而是代码供给量突然放大后，原来的评审、合并、发布和故障定位体系是否还成立。

Addy Osmani 对这套流程的拆解显示，Anthropic 把审查从「合并前的终点关卡」改成了「分层、快速、确定性的反馈系统」：

  • PR 之前：Claude 必须运行测试、构建和 linter，并展示真实输出；另有一个全新上下文的 subagent 独立审查 diff，避免「自己批自己」。
  • PR 之上：必需 CI 阻塞合并，多个 AI 审查 Agent 并行找 bug，由验证者投票过滤误报；内部 PR 获得实质性审查评论的比例从 16% 提升到 54%。
  • 风险分级：由分类器判定风险等级，低风险（文档、flag 后的增量改动）零人工，中风险一人，高风险（计费、自动更新等敏感路径）两人；AI 审批永远不能占用人工名额。
  • 合并之后：flag 灰度内部先行，出问题可不部署直接关闭；每周 on-call 复盘追问「哪一层本应拦住它」，并把历史事故 PR 转成每日 eval 集。
瓶颈迁移的三组硬数据：Anthropic 日合并量 5 月约 2,500 次 → 9 月 3 万次以上（12 倍）；Monorepo 历史接近 100GB、工作副本超 25GB，CI 每天约 2,500 万次代码检出，朴素 Git 拉取每天可能产生 600PB 传输；Cloudflare 的 AI 代码审查单次成本从 1.19 美元涨到 2.46 美元后，通过 token 优化降到 0.77 美元，降幅 68%。

基础设施层面的信号同样明确。Anthropic 最终不是继续堆 Git 镜像服务器，而是由 7 人团队用 5 个月重写了版本控制系统 Scion，把 CPU 与内存占用降到原方案的约 1/200；Meta 则用 1,300 行代码的「薄编排器」把 20 多个工作流路由给 14 个专业 Agent，编排层本身不做任何领域推理，以可靠性换取复杂度下降。Cloudflare 的案例说明，即使架构不变，Agent 工作流也会让 token 成本自然膨胀，必须像对待数据库慢查询一样持续做成本归因。

对 CTO 的直接含义是：考核指标要从「token 用量」「AI 使用率」转向「每次合并成本」「从提交到可验证的时长」「回滚率」「高风险变更的人工覆盖率」。组织上，需要把平台工程、CI/eval、可观测性和安全团队放在 AI 生产力的关键路径上；否则代码产能提升 2 倍，瓶颈只会以更贵的方式出现在合并队列、CI 队列和事故复盘里。Gergely Orosz 提到的「把 token 用量设成 KPI」正是反面教材——它奖励消耗，而不是奖励可验证的产出。

深度分析 02 · 资本与单位经济

便宜的 Token，昂贵的算力：AI 资本周期的「双层定价」正在形成

a16z 引用的一组预测显示，Alphabet、亚马逊、Meta、微软和甲骨文今年的资本开支合计正奔向 7,770 亿美元。这笔钱从广告、电商、软件和云服务的利润中流出，再进入芯片、内存、机房、电力设备、冷却系统和工程建设——科技行业正在做越来越像重工业的事。更关键的是，价值捕获在每一层并不相同：芯片厂商拿到订单即可确认收入，云厂商要把机器租出去，软件公司要证明客户愿意为 AI 多付钱，终端企业则要算清楚到底省了多少人、赚了多少钱。

与重资产扩张同时发生的，是模型层价格的快速下探。MiniMax M3.1 Flash 把使用成本降低 70%、推理速度提升近 3 倍；DeepSeek-V4.1-Flash 在 Agent Arena 的中位任务成本只有 0.20 美元；DeepSeek 的 Search / Fetch API 按每 1,000 次成功请求 5 元人民币计费，空结果不收费。需求端却在反向放大：网易 LobsterAI 的报告显示，9 月用户单次任务平均消耗 20.2 万 Token，是 3 月 6.3 万的 3.2 倍，9 月日活环比增长 83.1%；同一份报告还指出，缓存命中与否会让同样的任务成本相差七倍以上。

这就是「双层定价」：单位 token 越来越便宜，但每个任务消耗的 token 越来越多，最终决定账单的是任务规模、上下文管理和缓存策略，而不是模型标价。与此同时，算力层的稀缺性并未缓解——Meta 的 Prometheus 目标约 100 万 GPU，微软退出 Nscale 的埃塞克斯数据中心交易，都说明电力、机房和长期算力承诺正在成为新的约束条件。

收入侧的两极信号：2026 年至今已有 44 家公司宣布收入突破 1 亿美元，其中企业服务类 21 家、平均「破亿」用时超过 6 年；而 AI 基础设施、模型、搜索、代码、机器人五类合计 19 家，最快的只用了 1–2 年。AI 原生产品的杠杆也在放大：Greptile 以不到 50 人服务数千个工程团队、每天审查 GitHub 上超过 1% 的 PR，并完成 5,000 万美元 B 轮。头部实验室则在为长期资本结构做准备：Anthropic 拟将 5% 股份注入公益基金，并筹备可能创纪录的 IPO。

对 CTO 而言，战略结论不是「等 token 更便宜再投入」，而是建立一个能持续吃到降价红利的采购与架构体系：按任务分层路由，保留 2–3 家可切换供应商，把 prompt 缓存、上下文压缩、批处理和评测集纳入平台能力；对高风险、高价值任务保留前沿模型，对长尾任务主动下探性价比模型。在资本层面，要警惕两类风险：一是把长期算力承诺锁死在单一供应商身上，二是把业务逻辑深度绑定到某家模型 API，导致降价时无法迁移、涨价时无法议价。模型会继续商品化，算力会继续重资产化，企业真正能控制的是「路由权」和「退出权」。

CTO 视角 Action Items

  1. 把模型采购重做成「路由 + 评测 + 缓存」三件套，而不是年度框架合同。 MiniMax M3.1 Flash 成本降 70%、DeepSeek V4.1 Flash 以 0.20 美元中位成本登顶开源 Agent 榜，说明前沿智能的采购价仍在快速下探。为每个关键任务建立 eval 集和成本基线，按质量/时延/价格动态路由，保留 2–3 家可切换供应商；把缓存命中率纳入平台指标——LobsterAI 数据显示同一任务因缓存差异可产生 7 倍成本差。
  2. 把工程度量从「token 用量」改为「每次合并成本 / 验证时长 / 回滚率」。 Anthropic 90% 代码由 AI 编写后，PR 翻倍而回滚率下降 40%+，关键不在写得更多，而在分层验证和风险分级审批。优先投资 CI 并发、merge queue、变更级可观测性、独立 subagent 审查和事故转 eval；否则代码产能提升只会把瓶颈推给合并队列和 on-call。
  3. 把 Agent 纳入身份、权限与审计体系，把模型当作内部风险。 微软 Project Perception 的做法是让安全控制位于模型之外，持续评估 Agent 风险、动态调整权限并隔离威胁；OpenAI 已把 25% 生产工程师转岗安全。给 Agent 独立身份、短期凭证、最小权限、金额与调用预算、完整审计链；对第三方 Agent、插件和 MCP 服务做供应链审查，并用红队方式让 AI 攻击自己的系统。
  4. 对关键基础设施做「三年 TCO + 退出成本」压力测试。 Topgolf 在 VMware 涨价 400% 后迁移 1.2 万台虚拟机、节省 1,130 万美元，Gartner 预计 2029 年 55% 企业将启动弃用 VMware 的 POC；微软退出 Nscale 交易也说明长期算力承诺并非无风险。对虚拟化、数据库、云和模型供应商同时评估替代路径，合同里明确数据可迁移性、价格上限和断供条款。
  5. 重新设计初级工程师与平台的协作方式，而不是简单缩减招聘。 当 AI 承担大部分编码，人的价值转向问题定义、系统设计、验证与结果所有权。把初级工程师放到「定义验收标准、构建 eval、审查高风险变更」的路径上，用 AI 杠杆率和交付质量评估团队，而不是用 token 消耗或代码行数。Anthropic 将 5% 股份注入公共利益基金（可用于缓解就业冲击）、Gergely 对「拒绝学习 AI」的直白判断，都说明组织契约正在被重新谈判；提前做岗位重构和再培训，比事后被动调整便宜得多。
