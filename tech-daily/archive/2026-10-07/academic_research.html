数学 · 神经符号

OpenAI 公开 722 篇内部模型数学手稿，覆盖 372 个成果族与 17 个分支

OpenAI 将内部一个尚未发布的前沿模型产出的数学成果整体上传至 github.com/openai/math：722 篇手稿归入 372 个「成果族」，涉及约 4000 道研究问题，覆盖数论、代数几何、理论计算机科学、组合数学、数学物理等 17 个方向（理论 CS 40 族、组合 37 族、代数与复几何 36 族、数论 31 族）。据其说明，绝大多数结果走同一套固定流程，平均每个结果消耗约相当于 3 小时 ChatGPT Pro 思考的算力。

标题中最受关注的是第 003 号结果「准黎曼假设」（主张 ζ 函数在实部大于 7/8 的区域无零点），此外还包括有理数域上的希尔伯特第十问题（004）、卡塔兰常数无理性（005）、π 的无理性指数为 2（017）以及 Barnette 猜想（第 180 题）。关键的可信度锚点：约 160 篇的主要结论附带 Lean 形式化证明，其余尚未形式化，OpenAI 承认可能存在错误并承诺保留修订历史；同时附有 10 份模型推理过程摘要。发布流程参考了其在普林斯顿高等研究院支持下成立的独立「数学与人工智能顾问组」（成员含 Timothy Gowers、Edward Witten、Martin Hairer 等）的公开建议。

Agent · RL 环境

NVIDIA 研究：VERA 把 benchmark 轨迹变成 9000+ 可重启沙箱，协同演化模型与 harness

NVIDIA 研究团队提出的 VERA 试图回答一个当前 RL 训练的核心难题：如何构造「可验证的环境」。其做法是把 benchmark 轨迹转换为 9000 多个可重启的沙箱，并为每个环境配上 rubric 打分，只保留能实际运行、且能由可观测证据评分的环境。系统随后同时更新模型权重与 harness：一条 harness 编辑只有在通过自检、并在开发集上至少带来 5 分提升时才会被保留；一个模型 checkpoint 若分数下降超过 20% 则被拒绝。

结论颇具方法论意味：在 9B 规模上，协同演化后的 agent 击败了最强的「单轴」基线。这为「harness 与模型共同演化（co-evolution）是拥有智能栈的关键部分」这一判断提供了可复现的实验支持。

📎 来源：elvis（@omarsar0） · NVIDIA AI（PivotOPD）
Agent · 训练基础设施

Microsoft Research Asia 发布 Agent Lightning v1.0：约 3500 行的轻量 agentic RL 框架

该工作提出「Harnessed Agentic RL」范式——让部署时使用的同一套 agent harness 直接参与强化学习，从而免去把 agent 在训练框架内重新实现的工程负担。框架以约 3500 行代码提供完整的 agent RL 控制平面，原生支持 Kubernetes（可在自管集群、云 K8s 或本地基础设施上把 agent 作为标准 K8s Job 运行，不依赖付费的商业沙箱服务）。

数据效率方面给出了一个可引用的结果：一条端到端编码 agent 流水线在仅约 6000 条训练样本的条件下，把 Qwen3.5-9B 在 SWE-bench Verified 上的 Pass@1 从 41.8% 提升到 56.4%，即 14.6 个百分点的增益。

开源模型 · 端侧

Google DeepMind 开源 EmbeddingGemma 2：740M 原生多模态嵌入，统一 768 维空间

面向端侧搜索与本地 RAG 的嵌入模型，把文本、代码、图像、视频、音频映射进同一个 768 维向量空间，基于 Gemma 4 架构、Apache 2.0 协议开源。其设计核心是按模态按需加载：文本主干 270M（130M transformer + 140M embedder，比一代的 300M 更小），视觉编码器（可选）170M，音频编码器（可选）300M。纯文本量化后在 Pixel 11 Pro 上活跃内存约 191MB，加载全部模态约 567MB。

能力上，8K token 上下文（一代的 4 倍）、支持 100+ 语言；官方给出 768 维下 MTEB Code (NDCG@10) 78.68（相对一代约 14% 提升），MTEB 多语言 v2 为 61.36（与一代持平略升）。研究者需要留意的口径：多语言文本只是持平而非大幅进步，真正的增量在代码检索。第三方（Qdrant）复现显示，配合短向量＋量化＋重排可将向量内存压缩约 77×，同时保留 94.5% 的基线检索质量。

📎 来源：meng shao（@shao__meng） · 宝玉 · Qdrant
arXiv cs.SD · 长上下文

WavePrune：把 RoPE 每个通道限制在首个旋转周期，HELMET 分数 35.7 → 40.0

RoPE 通过按通道频率旋转 query/key 的二维通道来编码位置，但旋转是周期性的，会导致「位置混叠」——相隔整整一个旋转周期的相对位置难以区分。WavePrune 直接限制每个通道只使用其第一个旋转周期，从而消除注意力图中由混叠带来的干扰。作者报告在测试的 5 个模型中的 4 个上无需任何额外调优即提升了 HELMET 分数（例如 35.7 → 40.0）。这是一篇「最小改动、明确收益」的位置编码分析工作。

📎 来源：arXiv:2610.06963（cs.SD）
arXiv · 语音表征

自监督语音模型中发现「音系向量算术」：跨 96 种语言，[b] = [d] − [t] + [p]

该工作系统分析了自监督语音模型（S3M）表征空间的结构，覆盖 96 种语言。核心发现是：表示空间内存在与音系特征对应的线性方向，且这些音系向量的尺度与该特征在声学上被实现的程度连续相关。经典例子是清浊（voicing）：[d] 与 [t] 之差构成一个 voicing 向量，将其加到 [p] 上得到 [b]，即 [b] = [d] − [t] + [p]。这为此前关于 S3M 是否隐式学到了音系结构的争论提供了直接的线性可解释证据。

📎 来源：arXiv:2602.18899（eess.AS，v4）
arXiv cs.SD · 基准

Logbook：首个小时级音频事件理解基准，录音跨度从 10 分钟到 6 天

现有音频基准几乎都建立在短的、预先切分好的片段上，限制了模型设计的输入长度与词表规模。Logbook 把任务定义为：给定一段连续录音和一个事件标签词表，系统需输出无间隙的切分，并为每段给出事件标签与文字描述。作者比较了 52 个系统（端到端与级联两类），并消融了微调、上下文长度与推理预算。

结论有三点值得记录：任务本身可行，但最好的系统仍低于人类参考；过切分（over-segmentation）现象普遍，微调可部分缓解；端到端系统往往优于级联系统。

📎 来源：arXiv:2610.07338（cs.SD / eess.AS）
arXiv · 评测方法

FAD 的「任务诱导编码器偏置」：音频生成评测的分辨率被系统性污染

Fréchet Audio Distance（FAD）已是文本到音频生成的默认评测指标，但其分数依赖于底层编码器的嵌入空间——编码器的训练任务决定了哪些声学特征被保留或丢弃，FAD 因此继承系统性偏置。该工作把评测分解为 Recall、Precision 与 Alignment（进一步拆为语义与结构两个维度），并用对数尺度归一化以支持跨编码器比较。在 6 个编码器、2 个数据集上的受控实验揭示了一个四轴权衡：基于重建的 AudioMAE 主导精度敏感性；ASR 训练的 Whisper 在结构检测上占优但对信号退化不敏感；分类训练的 VGGish 则各有短板。对任何使用 FAD 做模型选择的研究者，这是一篇必读的方法论批评。

解读一：OpenAI 的 722 篇数学手稿——神经符号验证的一次大规模公开实验，还是一次无法通过同行评议的发布？

Technical report + public repository · github.com/openai/math · 2026-10-07

研究背景

前沿模型在既有数学基准上的表现已趋饱和，评测的「天花板效应」迫使团队转向未解决的真实研究问题。OpenAI 的做法是：把评估分布从"已解问题"移到"开放问题"，并一次性公开结果，而非逐篇发表。这既是一次能力展示，也是一次关于「AI 研究如何发布」的流程实验。

核心方法

  • 规模：模型被投喂约 4000 个研究问题，输出按相关性归并为 372 个「成果族」、722 篇手稿；平均每结果约等于 3 小时 ChatGPT Pro 的推理算力。
  • 验证路线：约 160 篇的主要结论附带 Lean 形式化证明——Lean 能逐步机检证明，因此可在很大程度上排除逻辑漏洞。其余手稿尚未形式化。
  • 透明性设计：附 10 份模型推理过程摘要；手稿文件夹以日期结尾，显示产出高度集中在 9 月下旬。
  • 治理框架：在普林斯顿高等研究院支持下成立独立「数学与人工智能顾问组」（Timothy Gowers、Edward Witten、Martin Hairer 等），发布方式参考其公开建议。

证据与局限

成果清单本身极具分量——准黎曼假设、有理数域希尔伯特第十问题、卡塔兰常数无理性、π 的无理性指数、特殊情形 CM 阿贝尔簇的霍奇猜想、四维挂谷猜想等，多为悬置数十年乃至半个世纪以上的问题。但 Gary Marcus 与 Simon Willison 转引的社区批评同样值得研究者严肃对待，其要点可归纳为四点：

方法论质疑：(1) 报告未披露模型的架构、具体流程（证明是一次性生成还是迭代式？）、失败率、训练/后训练/数据增广细节，按作者原话「这在同行评议中不可能通过」；(2) 因此无法评估结果在数学之外的可泛化性；(3) 结果依赖符号系统（Lean 等）与 LLM 的组合，属于神经符号方法——这与 Marcus 多年主张一致，但不构成 AGI 的证据；(4) 结果「处于不同验证阶段」，未形式化部分可能存在错误。

一个值得注意的元观察：此次发布的瓶颈已经从「生成」转移到「验证与理解」。社区讨论中反复出现"读不过来"（量子位援引三位菲尔兹奖得主表示"不代表认可"）以及经济学家式的算力成本换算——这本身就是一份关于规模化数学研究的经验数据。

学术意义

无论最终有多少结论经得起独立验证，这篇「发布物」都确立了三个可被后续工作复用的范式：(1) 形式化证明作为可信度分级——以是否通过 Lean 机检作为结果的置信标签，是一条可操作的中立标准；(2) 机检+人工审阅的双轨流程——160/722 的比例本身就量化了当前自动形式化的覆盖率；(3) 独立顾问式治理——为高风险能力发布提供了一种机构化的披露模板。对研究者的直接启示是：在评估"AI 做研究"时，应把可验证性预算（formalization budget）与算力预算并列考量。

解读二：VERA（NVIDIA）——把「可验证环境」本身当作可训练对象

Research paper · research.nvidia.com/labs/lpr · 2026-10

研究背景

Agentic RL 的核心困境在于环境：真实工具链难以复现，人工设计的沙箱很快被模型"奖励黑客"（reward hacking）攻破。主流做法是不断加固环境，但环境与模型是解耦迭代的——模型变强后，昨天的环境就失效了。VERA 的出发点是把环境构造与 harness 设计都纳入优化循环。

核心方法

  • 环境生成：将 benchmark 轨迹转换为 9000+ 可重启（restartable）沙箱，每个沙箱配有 rubric 打分器；只保留能实际运行、且能从可观测证据（observable evidence）评分的环境——把"可验证性"作为环境的一等筛选条件。
  • 双轴更新：同时更新模型权重与 harness。harness 编辑的接受条件为「通过自检 且 开发集上至少 +5 分」；模型 checkpoint 的拒绝条件为「分数下降超过 20%」。
  • 协同演化：两个轴互相提供选择压力，模型不会在静态环境中过拟合，harness 则随模型能力提升而同步加难。

结果与方法论价值

在 9B 规模上，协同演化的 agent 击败了最强的单轴基线。这一结果的意义超出分数本身：它说明harness 的编辑空间可以被形式化为一个带阈值的接受/拒绝规则，从而把此前依赖人工经验的 agent 工程，转成可自动化的优化过程。与之呼应的是同期 NVIDIA 的 PivotOPD——用教师模型演示"更好的动作"以及"如何在之后几步回到正轨"，专门针对 agent 早期犯错后持续跑偏的失败模式；两者共同构成了「环境—行为—纠错」的完整训练闭环。

局限与待验证点

接受的抽象层面，仍有两个问题开放：一是 rubric 打分器的构造本身需要人工设计，其质量上限决定了整条流水线的上限；二是"可观测证据"的定义在不同任务域差异极大，从数学（Lean）到代码（自检脚本）到开放式研究任务（无 ground truth）的迁移性尚不清楚。后者恰是当日 OpenAI 数学发布所要面对的同一问题——当"验证"比"生成"更贵时，可验证环境的外推边界在哪里。

04趋势观察

基于当日信号对研究方向与方法论演进的判断，属编者观点，供讨论。

  1. 「可验证性」正在从评测手段升格为训练目标。 当日三条主线在这一点上收敛：OpenAI 用 Lean 机检为数学结果分级；NVIDIA VERA 把「能运行、能从可观测证据打分」作为环境的准入条件；微软 Agent Lightning 让部署期 harness 直接进入 RL 循环。三者共同指向一个判断——当生成能力不再是瓶颈，验证器的构造能力成为决定研究上限的变量。可预见的工作方向包括：验证器的可迁移性（数学 → 代码 → 开放科学问题）、验证预算的形式化、以及验证器自身的对抗鲁棒性。Gary Marcus 提出的"符号验证无法在开放世界泛化"是一个尚未被任何实验直接驳倒的强反驳。
  2. RL 后训练的抽象层正在上移，从「策略」到「harness」。 此前 agentic RL 主要在 token 策略层优化；VERA 与 Agent Lightning 都把 harness（工具调度、上下文管理、错误恢复）纳入了优化对象。这意味着今后比较 agent 能力时，「模型 + harness」应被视为一个联合单元，单纯报告基座模型分数会系统性地低估或高估实际部署表现。评测基准设计需要相应调整。
  3. 开源权重的竞争重心从「谁的模型更强」转向「谁的单位算力智能更高」。 当日两个信号：Mistral Large 4 以约 3800 张加速卡训练、在部分定位任务上接近 GPT-6 Astra（Dense200 边界框 42.0% vs 41.5%），社区据此讨论"intelligence per GPU"；Reflection AI 发布首个开放权重模型 Beam。与此同时，Hugging Face 过去一年中国模型占下载量约 41%，Vercel AI Gateway 的开放权重模型 token 占比从去年 12 月不足 10% 升至今年 8 月的 56%。对研究者而言，这意味着开放权重已具备作为可复现基线的统计显著性，而非"小样本替代品"。
  4. 音频/语音是当前表征分析最活跃的实验场。 当日 arXiv 的 64 篇中，语音音频方向贡献了多篇高质量"表征可解释性"工作：S3M 中的音系向量算术（96 语言）、跨物种迁移的受控分析（15 个冻结编码器、4 物种）、RAVE 解码器的逐层聚类分析、FAD 的任务诱导编码器偏置。与视觉/文本相比，音频信号具有更清晰的物理与语言学结构，因而更适合做"表征里到底编码了什么"的受控实验。这是一个方法论溢出效应：音频圈的表征分析工具很可能先于其他模态形成标准。
  5. 评测方法论批评本身正在成为一类研究成果。 VoxReason 指出"计划准确率不等于依据来源"；量化评测工作（arXiv:2609.26823）证明"文本输出分数不能确立词汇非诊断任务上的性能"；FAD 的偏置分解工作同理。这些工作的共同结构是：揭示某个被广泛使用的指标与其宣称测量的构念之间存在系统性偏差，并给出替代分解。对写论文的研究者，这提示在方法章节中应对所用指标的这一类批评有明确回应。
  6. 发布的「验证瓶颈」将成为跨学科的共性问题。 数学圈当日最强烈的情绪不是"AI 太强"，而是"读不过来"——三位菲尔兹奖得主表示结果不代表认可，Jake Boggan 关于 Barnette 猜想的感慨更直接呈现了这一代研究者面对"自己终生问题被机器宣布解决"时的复杂处境。当生成速度远超人类评审速度，学术共同体需要新的分诊机制：机检优先、置信分级、以及对"未验证结论"的引用规范。这可能是未来一两年内方法论研究之外，影响最深远的一类基础设施问题。
