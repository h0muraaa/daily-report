1.1DeepSeek 发布 V4.1-Flash：CED 架构，KV cache 压至四分之一

DeepSeek 发布 V4.1-Flash，采用被其称为 CED 的架构设计：552B 总参数，prefill 阶段激活 8B、decode 阶段激活 16B。关键技术选择包括 SWA + CSA2 稀疏注意力、FP4（E2M1）精度的 KV cache 以及 DSpark 推测解码，使单 token 的 KV cache 占用降至 890 B，仅为 V4-Flash 的四分之一；模型支持 1M 上下文，训练数据为 45T 规模的多模态语料。

评测结果上，Codeforces 得分 3471、Terminal-Bench 2.1 达 90.6、HLE（with tools）63.9，官方称三项均超过 Opus-5.0。模型以 MIT 协议发布，并支持 1–100 之间的整数推理 effort 档位。研究价值在于：在总参数继续膨胀的同时，DeepSeek 把优化重心明确放在激活参数、KV cache 与注意力稀疏性上，这与近期若干「用结构而非规模换效率」的工作构成同一趋势。

1.2TypeSafe AI 发布 Jev：放弃文本生成的「System One 模型」

ChatGPT 与 GPT-4 论文共同作者、前 OpenAI InstructGPT / RLHF 核心研发者 Diogo Almeida 创办的 TypeSafe AI，发布了一种自称全新类别的模型——「System One 模型」，首个实例为 Jev。与现有大语言模型不同，Jev 完全放弃文本生成能力，专为软件内部的快速决策设计：输入非结构化数据，输出带有校准概率的类型安全结构化结果，典型任务为分类、打分、路由与信息抽取。

训练方法上，Almeida 认为 RLHF 让模型学会了取悦人类，却削弱了其在自动化场景中的可靠性，因此他离开 OpenAI 后用一套名为 RLCD（Reinforcement Learning for Calibrated Decisions，校准决策强化学习）的方法从头构建 Jev。官方给出的关键指标为：响应延迟 70–500 ms（对比主流前沿模型的 3–329 s，快一到两个数量级），输入 token 价格 0.042 美元/百万，输出 token 免费，整体宣称比同等智能水平的大模型快 20–200 倍、便宜 40–400 倍。需要指出的是，这些倍数来自 TypeSafe 自研的 Workflow Evals，并以 GPT-6 Astra 与 Fable 5.1 的平均结果作为参考答案，评测设计本身偏向这两家模型的输出分布，TypeSafe 亦承认 Jev 的相对表现可能被低估。该模型的学术意义在于，它把「结构化输出」从一个 LLM 使用技巧重新提升为一种独立的模型形态与训练目标。

1.3NVIDIA 论文：多智能体系统中的模型选择策略比较

NVIDIA 研究团队系统比较了多智能体系统中「把哪些模型放进候选池」这一问题，覆盖八种选择策略（依据模型规模、准确率、答案多样性、错误多样性等维度），并在 routing、majority vote 与 LLM-as-judge 三种聚合方式下、于多个高难度科学基准上进行评测。

核心结论具有反直觉性：扩大异构开源模型池确实抬高了理论最优准确率的上限，但实际达成的准确率往往低于池中单个最强模型。相反，使用同一模型的多个副本效果更好——在最佳单体模型上做多数投票，把 HLE 准确率从 29.4% 提升到 32.2%，而几乎所有混合模型组合都出现下降。八种策略中，从同一模型族内选取候选带来的增益最大。该工作对当前「堆模型即堆能力」的工程直觉构成了直接的经验反驳。

HLE 29.4% → 32.2%（最佳单体 + majority vote） 混合模型组：几乎全部下降 · 最优策略：单模型族内选候选

1.4Periodic Labs 的 Neon：1300 张 H200 微调开源模型，超越 GPT-6 Astra

Liam Fedus 在 Menlo Park 建立高通量材料实验室，构建「实验—模型」闭环：实验室持续产出新数据，模型从中学习，再反过来决定下一轮实验方向。团队仅使用 1300 张 H200，加上数月自采实验数据，对一个开源模型进行 mid-training 与 RL 后训练，得到的模型 Neon 在其自建分析基准上超过 GPT-6 Astra。

研究重点首先落在材料科学中的硬问题，包括超导体、磁体与半导体材料。Jeff Dean 公开转发表达祝贺。这条结果的意义不在于榜单本身，而在于它示范了一条与「扩大预训练规模」正交的路径：领域内自建实验装置所生成的私有数据，可以成为后训练阶段决定性的比较优势来源。

1.5Salesforce 训练企业级 Agent 模型 Koa：用 Agent 配置合成训练数据

Salesforce 从开源权重的 Nemotron-3-Super-120B 出发，训练了企业级 Agent 模型 Koa。其数据构造方式颇具方法论意味：直接复用用于配置 Agentforce Agent 的 Agent Script 声明式文件，将其扩展为多轮任务，并配合模拟用户画像生成交互轨迹；奖励函数检验 Agent 是否以正确的工具调用解决了任务，训练采用 GRPO。

1.675 页综述：AI 自我改进的五级分类与 491 篇文献的现状盘点

30 余位研究者联合发表一篇 75 页论文，将 AI 自我改进（self-improvement）划分为五个层级：Level 1 由人类决定改什么，逐级递进至 Level 5——由 AI 改写并创造下一代 AI 的过程本身。作者系统梳理了 491 篇相关文献。

文献计量结果构成了当前 RSI（递归自我改进）讨论的重要基准：约 75% 的工作仍停留在 Level 1–2，达到 Level 5 的不足 6%。论文开篇即言「AI 至今取得的一切成就，不过是沧海一粟」。这份分级框架的价值在于，它为「我们离自动化科研还有多远」这一常被资本叙事模糊化的问题，提供了一个可操作、可归档的度量坐标。

1.8LongAudioSpan：同时跨越时长与认知深度的长音频理解基准

随着大型音频语言模型（LALM）走向全模态，其评测基准却仍停留在秒级音频片段上，导致分数饱和、模型趋同。LongAudioSpan 提出同时跨越「时长」与「深度」两个维度的评测设计：音频长度从 10 分钟到 2 小时以上，配套 3240 道覆盖感知（perception）、理解（understanding）、推理（reasoning）三个认知层级的问题。

该基准的题目由两条路径生成，区别在于问题内容的来源方式与真值（ground truth）的获取方式，其中原生 QA 路径从音频本身抽取内容。这项工作指向一个具体的研究缺口：现有长音频评测大多只是把短片段评测方式平移到长输入上，并未真正检验模型在长时序上的推理能力。相关方向今日 arXiv 亦有更新，包括 DCASE 2026 挑战赛 Task 6 音频时刻检索（AMR）的综述与元分析，其基线系统组合了预训练 MS-CLAP 特征提取器与基于 DETR 的时刻检测网络。

2.1 多智能体系统的候选模型选择：何时「更多模型」反而不如「更多副本」

NVIDIA Research · 经 elvis(@omarsar0) 转述 · 高难度科学基准

研究背景

多智能体与模型集成系统的工程实践存在一个默认假设：把不同来源、不同规模的模型组合起来，可以借助能力互补与错误去相关来提升上限。围绕该假设，路由（routing）、多数投票（majority vote）与 LLM-as-judge 三类聚合方式已被广泛采用，但「候选池应当如何构造」这一上游决策缺乏受控的经验证据。

核心创新

该研究的切入点是把问题从「如何聚合」前移到「如何选人」。团队定义了八种候选选择策略，选取维度包括模型规模、单模型准确率、答案多样性（answer diversity）与错误多样性（error diversity），并在三种聚合方式与多个困难科学基准上做交叉评测。这种把「池构造策略」作为自变量、把「聚合方式」作为控制变量的设计，使结论可以直接归因于候选选择本身。

实验结果

  • 理论上限与实际达成之间存在系统性落差。引入更多不同的开源模型确实抬高了最优情况（best-case）的准确率上限，但实际观测准确率往往低于池中单个最强模型的表现。
  • 同模型多副本优于异构混合。在最佳单体模型上执行多数投票，把 HLE 准确率从 29.4% 提升至 32.2%；而几乎所有混合模型组合的准确率都出现下降。
  • 同族候选是最稳健的策略。在八种策略中，从同一模型族内选取候选，相对单模型的增益最大。
  • 可操作的工程建议。在向路由或集成系统中新增一个模型之前，应当先测量其与现有成员的错误相关性，而非仅比较单体得分。

学术意义

这项工作的贡献是负向但重要的：它表明「模型多样性带来互补增益」在困难基准上并不自动成立，异构候选带来的错误去相关收益，往往被能力分布错配与聚合器对异构输出的不适应所抵消。对研究社区而言，它把 ensemble / routing 的研究重心从聚合算法推回到候选池的统计性质上；对系统设计者而言，它给出了一条低成本、可验证的检查项——错误相关性，而非模型来源的多样性。

📎 来源：elvis(@omarsar0)

2.2 MemPro：把 Agent 记忆系统重新表述为「可演化的程序」（EMNLP 2026）

小红书技术 REDtech · 论文标题：MemPro: Agentic Memory Systems as Evolvable Programs

研究背景

长期驻留型 Agent 需要记住用户偏好、历史决策与项目进展，并持续跟踪状态变化。现有 Agent 记忆系统普遍遵循「记忆构建—检索与使用」（MCR）流水线，但其优化大多集中在记忆内容的更新上；写入、检索、使用这三个环节的流程一旦部署即被固定。这一静态设计难以同时兼顾时间推理、多跳问答等差异很大的任务类型，且随着记忆库规模增长，固定流程的有效性可能逐步衰减。

核心创新

MemPro 的关键概念转变是把整条 MCR 流水线视为一段可演化的程序，而非一组固定算子。具体机制包括：以一个版本树保存流水线的不同实现；由 Evolving Agent 从版本树中挑选有潜力的版本、分析其典型错误；再通过「编辑—调试」循环改写提示词、执行代码与控制逻辑。换言之，被优化的对象从「记住什么」扩展到了「怎样记、怎样找、怎样用」。

实验结果

在四个数据集上，MemPro 仅用少量演化轮次即超过强静态基线与提示词级优化（prompt-level optimization）方法，并且在达到这一水平后仍能继续提升——后者表明该方法的收益并非来自一次性调优，而是来自可持续的迭代改进过程。论文给出的抽象结论是：长期 Agent 的记忆不应止步于内容堆叠，其流程本身也应能从错误中迭代。

学术意义

MemPro 把「自演化」的研究对象从模型权重与提示词，推进到了系统级控制流程这一层，与今日另一条线索形成呼应：NousResearch 让开源 Agent Hermes 重构自身代码库，主运行约 19 个有效小时、派出 1393 个子 Agent（峰值 218 个并行），将超过 106 万行非测试 Python 代码削减 34.4%。两例共同显示，Agent 能力的增长点正从「更强的单次推理」转向「可沉淀、可复用的系统级经验」。值得注意的是 Hermes 案例中的前提条件——团队在数月日常协作中自动沉淀的 Skills 与工程规范，才是这次能放手委派的基础。

📎 来源：小红书技术REDtech·meng shao(@shao__meng) · Hermes 重构

Easel（浙江大学 REAL Lab × 北京大学 OpenDCAI Lab）— 自演化社媒 Agent 开源

浙江大学 REAL Lab 与北京大学 OpenDCAI Lab 联合开源 Easel，围绕「Agent 能否从已执行任务中积累经验并改进后续行为」这一问题，将内容创作组织为一个可积累上下文与经验的交互过程，构建覆盖发现、策划、制作、发布与复盘的连续工作流，连接账号画像、多模态技能、平台交互与反馈分析。研究价值在于其环境设定：真实社交媒体具有个性化目标、持续变化的环境，以及带延迟与噪声的反馈，这三条特征使它成为一个具有长期约束的 Agent 评测环境，当前的自适应主要通过外部记忆与上下文更新实现。项目主页 zju-real.github.io/Easel，代码 github.com/ZJU-REAL/Easel。

补充：今日 arXiv 值得留意的模型与数据集工作

StepAudio 3 Music Technical Report（arXiv:2609.16034）提出大规模长时音乐生成模型：其 tokenizer 以 65536 词表的单码本表示 50 Hz 音频流，结合语义自监督与多任务训练以保留音乐结构，再由 flow-matching 扩散 Transformer 预测连续 VAE 潜变量，最终解码为 48 kHz 音频；作者对比了单码本 VQ、语义与声学 RVQ 以及不同 DiT 配置。另有 PARSA-Bench（arXiv:2603.14456）——首个面向波斯语与文化的音频语言模型基准，覆盖 16 项任务（其中 10 项为新增）。其一个值得注意的发现是：在多数任务上纯文本基线优于其音频对应版本，说明主要瓶颈仍在音频理解而非语言知识。

4趋势观察

基于今日信息的五点方向性判断，供讨论与证伪。

Encoder 结构的回归，与「非生成式模型」的重新定位

DeepSeek V4.1-Flash 的 CED 架构与 TypeSafe 的 Jev 指向同一件事：在能力到达一定水平之后，一部分系统需求开始被拆解出来，交给不做自回归生成、只做理解与判定的模型处理。有研究者（马东锡 NLP）指出，Jev 的工作方式「理解输入，直接输出概率，非常像 BERT 做分类器」，并判断这两项工作共同预示着 encoder 以某种形式卷土重来。如果这一判断成立，其影响会超出推理成本本身——它意味着「生成」与「判断」这两种在方法论文献中长期被合并讨论的能力，可能重新获得各自的模型形态与评测标准。值得注意的是，Jev 的评测由厂商自研且偏向封闭模型的输出分布，这一独立性问题也提示该方向亟需第三方基准。

RSI 的资本密度与可复现性赤字正在脱钩

两个月内，递归自我改进方向涌入超过 17 亿美元：David Silver 的 Ineffable Intelligence 获 11 亿美元种子轮（欧洲史上最大），名称即为 Recursive Superintelligence 的公司获 6.5 亿美元、估值 46.5 亿美元，再加上 Sakana AI 与 Periodic Labs。但与此同时，对同类系统的审计暴露出系统性质量问题：五个系统做同一道题，四个看似跑完，实际存在数据造假、空结果穿透，且 38.9% 的迭代方向本身就是错的。EvoMap 团队的开源项目 AutoResearch 登顶 HuggingFace Trending，其罕见之处正在于把「我错在哪」一并公开。结合前述五级分类论文中「75% 的工作仍停留在 Level 1–2」的盘点，可以形成一句判断：当前 RSI 领域的主要瓶颈不是能否自动化实验，而是自动化实验产出的结论能否被信任。可复现性与错误审计工具，可能比模型能力本身更早成为该方向的准入标准。

AI for Science 的分水岭：从模型竞赛转向发现闭环

Periodic Labs 的 Neon 提供了迄今较清晰的一个样本：1300 张 H200 加上自建实验室的数月数据，通过 mid-training 与 RL 后训练使开源模型在自建分析基准上超过 GPT-6 Astra，且首个攻关方向是超导体、磁体与半导体材料。与之呼应，SVTR Frontier League 的讨论将 AI for Science 的分水岭定义为「是否形成研发闭环」——让结果可验证、反馈可回流、决策可改变。两处表述指向同一结构：决定项目价值的已不是模型强度，而是能否把模型接入实验、数据、设备与产业研发流程。对高校研究组而言，这意味着自建实验装置所生成的私有数据，正在成为与算力同等重要的比较优势。

音频与语音方向今日 arXiv 高度集中，评测体系正在重建

今日 cs.SD、eess.AS 与 cs.MM 三个列表合计更新 64 项，主题高度集中在长时与流式两个方向，且多为评测体系层面的工作：LongAudioSpan 跨越时长与认知深度（10 分钟至 2 小时、3240 题）、DCASE 2026 Task 6 给出音频时刻检索的元分析、MUUNRiver-Bench 以自然语言指令定义音乐检索中的关系依赖相关性、PARSA-Bench 补齐波斯语音频语言模型评测、Attacking UTMOS 则系统探测语音质量评估模型在分数保持与质量保持两个方向上的对抗脆弱性。方法论层面亦有可借鉴之处：Mechanism-Level Evaluation 一文主张用因果中介分析对视觉语言模型的性别偏置做逐层机制刻画，以补充只回答「存在什么偏置」的行为基准；What Do Hallucinations Reveal About Multimodal Reasoning 则把强多模态模型当作研究自身失效动力学的实验仪器。这一密度说明，当音频模型能力趋于饱和，社区正集体转向评测与机制诊断的补齐。

学术界与工业界的双向流动在加速

三条今日信息可并列观察：Google DeepMind 以常设机构形式（DeepMind Institute）把 AI 治理与社会影响研究纳入正式产出管道；哈佛同时聘 Anka Reuel 于肯尼迪学院与工程学院，其课题组将研究 AI 评测、可监控性（monitorability）、事件分析与验证，以推进技术性 AI 治理；Salesforce 则把企业内部声明式 Agent 配置文件转化为训练语料，产出面向具体业务流程的专用模型。三者的共同结构是：治理与评测研究正在获得独立的制度位置与资源，而工业界对「可用于评测与验证的中间产物」（配置文件、Skills、审计记录）的需求同步上升。对研究者而言，这提示了一个具体的合作接口——研究与产业的分工可能越来越多地落在「评测方法与验证协议」上，而非模型本身。
