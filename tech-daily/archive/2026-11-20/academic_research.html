世界模型NVIDIA WorldTrace：让交互式视频世界模型"记得住"走过的场景

NVIDIA Research · NeurIPS 2026 论文

交互式视频世界模型在用户"移开视线再返回"时往往无法还原此前到访的空间，这一"场景一致性"难题长期制约其可用性。NVIDIA Research 提出的 WorldTrace 通过为模型引入可复用的场景记忆，使其无需重新训练即可在探索过程中保持空间一致。

  • 在专门衡量场景回忆能力的基准 LoopBench 上，WorldTrace 相较标准滑动窗口方法把"重访场景"的召回率提升了 32%。
  • 方法的核心价值在于"免重训"：记忆以外部结构注入，而非通过微调参数获得，因而具备较好的可迁移性。
  • 该工作已被 NeurIPS 2026 接收，属于世界模型长程一致性方向少见的、带基准量化的进展。

📎 来源：NVIDIA AI (@NVIDIAAI)

科学智能上海 AI Lab 开源 Sage S2.1 Flash：320B 科学多模态智能体，四项基准 SOTA

上海人工智能实验室 联合 复旦 / 中科院软件所 / 人大 / 自动化所 等

Sage S2.1 Flash 是一个总参数量 320B 的混合专家（MoE）模型，目标是让"科学多模态感知"融入通用智能体：既能读懂分子与光谱等科学数据，又能连续调用工具、在专业软件中交付成果。研究团队以一份完整技术报告披露了其训练流程与细节。

  • 在四个智能体基准上取得 SOTA；典型演示中，模型可仅凭一条指令，从 12,487 张 CT 图像中筛出目标扫描切片，并操作 3D Slicer 重建三维骨骼模型。
  • 核心方法是"统一科学多模态架构"，使模型直接理解科学数据而非依赖外挂解析器。
  • 论文与权重同步开放（arXiv:2611.21072；Hugging Face Papers；GitHub InternLM/Sage-S2.1-Flash），对学术复现友好。

📎 来源：机器之心·arXiv:2611.21072

多模态生成Kandinsky 6.0 Video：双流 CrossDiT 实现同步音视频扩散

Kandinsky Team · arXiv:2610.05608（replace-cross）

该工作提出一系列用于"文本/图像到音视频"同步生成的基础扩散模型，包含 Lite（3B）与 Pro（29B）两档。两档均能生成 5 秒、带 44 kHz 同步音频（含口型对齐）的片段，并内置超分模块将输出提升至 Full-HD（1920×1080）。

  • 架构上采用双流 CrossDiT：在预训练视频流与新训练音频流之间通过双向交叉注意力对齐时间与语义信息。
  • 支持 T2AV（文生音视频）与 I2AV（图生音视频）两种模式，延续 Kandinsky 5.0 的视频生成能力。
  • 代表了"音视频同源生成"从拼接式管线走向统一扩散架构的趋势。

📎 来源：cs.MM updates on arXiv.org

评测基准TELEVAL：面向中文口语交互场景的 SLM 评测基准

Zehan Li 等 · arXiv:2507.18061（v5，replace-cross）

口语语言模型（SLM）的任务得分高，并不必然意味着其口语交互可靠、得体。TELEVAL 针对这一落差，构建了一个面向中文口语交互的大规模基准，在不额外提供任务特定提示或预设选项的前提下评估模型对口语输入的回应。

  • 评测覆盖两个互补维度：①可靠的内容完成度（Reliable Content Fulfillment），衡量在多样声学与语言条件下的语义准确性；②交互得体性（Interactional Appropriateness），评估会话层面的恰当程度。
  • 方法论意义：把"能不能做对"与"做得是否得体"解耦，回应了当前语音对话评测"只看任务成功率"的盲区。

📎 来源：cs.SD / eess.AS updates on arXiv.org

元科研936 个 AI 智能体自主研究三个月：严谨性优于人类，新颖性略逊

alphaXiv 联合 MIT、斯坦福等 · 2026-11-19 报告

这是一项关于"AI 做科研"的元实验：8 月至 11 月，35 个实验室接入 936 个 AI 智能体，人类只提供算力与方向，选题、实验、代码、论文全部由 AI 完成，共产出 936 篇论文；同期 alphaXiv 开放了专收 AI 论文的"AI Track"。

  • 过程细节颇具信息量：有智能体宣布方法提升 13.2 个百分点，两小时内自行撤回，原因是发现对照组未调好；另一个智能体办起"AI 期刊"，四个 AI 盲审、编辑还复算作者代码。
  • 量化结论：两个 Gemini 模型盲评 202 对论文，AI 论文的实验严谨性高出 2 分（10 分制），但新颖性低 0.4 分；此外，把审稿意见写成代码执行，156 条重大意见中有 77 条推翻了论文结论。
  • 作者自身给出保留：评委是"只读文字"的 AI，AI 总分优势几乎全部来自最早的那个实验室，其余实验室与人类论文相当；"没人写代码"依赖参与者自报，公开数据集不含原始数据与权重——每条结论应视为未经核实。

📎 来源：宝玉 (@dotey)

基准进展OpenAI MedChemBench 与 GPT-6.2 Astra 在物理 3D / 机器人基准上的跃升

OpenAI · Greg Brockman（@gdb）· Andon Labs · XDOF

本期出现一组"以基准量化前沿模型科学能力"的信号。OpenAI 发布 MedChemBench，作为衡量 AI 在药物化学推理上能力的新基准，用以展示前沿模型帮助科学家识别候选药物的进展；同一时间窗口内，GPT-6.2 Astra 在多项外部基准上刷新记录。

  • 物理 3D 理解：GPT-6.2 Astra 在 Blueprint-Bench 2（依据公寓照片绘制平面图的 agent 基准）上排名第一，宣称超过人类基线；GPT-6.2 Sol 位列第三。
  • 机器人：在 Ember-0 基准上，GPT-6.2 Astra 得分 41.2%，较 9 月初 GPT 6 的 19.6% 近乎翻倍，XDOF 预计该基准"很快饱和"。
  • 学术解读：这些多为厂商自建基准或第三方私有基准，需警惕"基准饱和"与选择性报告，但其增速本身是值得追踪的经验证据。

开源模型Apple 发布 Depth Pro 2：锐利且时序一致的单目度量深度

Apple · 权重发布于 Hugging Face

Apple 发布 Depth Pro 2，主打"锐利且时序一致的度量单目深度"（Sharp and Temporally Consistent Metric Monocular Depth）。相较感知深度，度量深度意味着输出带有真实尺度，可直接用于三维重建、机器人与 AR 等下游任务；"时序一致"则针对视频场景下逐帧深度的抖动问题。

Kandinsky 6.0 Video: Foundation Models for Synchronized Video and Audio Generation

Kandinsky Team · arXiv:2610.05608v2 · 模态：视频 + 音频

研究背景

音视频生成长期呈"视频模型 + 独立音频模型"的拼接式管线，声画在时间与语义上难以严格对齐，尤其口型同步与事件音（如物体碰撞声）的时序匹配困难。如何在单一扩散框架内联合建模两种模态，是该方向的核心问题。

核心创新
  • 双流 CrossDiT 架构：以预训练视频流与新训练音频流为两条通路，通过双向交叉注意力在时间维与语义维建立耦合，兼顾视频先验复用与音频从零学习。
  • 统一的多模态输出：一次生成 5 秒、44 kHz 的同步音频视频，含口型对齐；内置超分模块将分辨率推至 Full-HD。
  • 双档模型设计：Lite（3B）与 Pro（29B）覆盖效率与质量两端，适配不同算力预算。
实验与能力

同时支持文本到音视频（T2AV）与图像到音视频（I2AV）。在 Kandinsky 5.0 的视频生成基础上扩展，重点验证了同步音频（含口型）的可用性与超分后的画质。

学术意义

该工作把"音视频同源生成"从工程拼接推进到架构级统一，为后续研究提供了可参照的 CrossDiT 双流范式；其"复用预训练视频先验 + 新训音频流"的策略，也为多模态对齐中的冷启动问题提供了一条实用路径。局限在于片段时长仅 5 秒，长程一致性与复杂场景音频仍是开放问题。

📎 arXiv:2610.05608（来源：cs.MM updates on arXiv.org）

Sage S2.1 Flash：把科学多模态感知融入通用智能体的 320B MoE 技术报告

上海人工智能实验室 等联合团队 · arXiv:2611.21072 · 模态：科学多模态 + 工具调用

研究背景

通用智能体在常识与代码任务上进展迅速，但在科学场景中往往"看得见却看不懂"——分子结构、光谱、医学影像等专业数据需要专门的多模态感知能力。此前多数方案以"外挂工具/解析器"应对，割裂了感知与推理。

核心创新
  • 统一科学多模态架构：模型直接理解科学数据，而非依赖外部转换，使感知与工具调用处于同一表示空间。
  • 端到端工具交付：不仅能分析，还能连续调用工具、在专业软件（如 3D Slicer）中实际完成交付物。
  • 完整训练披露：技术报告系统公开 320B MoE 的训练流程与细节，在开源大模型中较为少见。
实验结果

四项智能体基准达到 SOTA。代表性演示：单条指令下，从 12,487 张 CT 图像中定位目标扫描序列切片，整理后驱动 3D Slicer 重建三维骨骼模型；上线首周真实用户反馈"快且聪明"，多轮任务中工具调用流畅。

学术意义

该工作是"科学智能体"从 demo 走向可复现系统的标志性样本：一方面验证了科学多模态感知可与通用 agent 能力统一，另一方面以完整技术报告 + 开放权重承担了学术社区的复现责任。对领域的影响可能集中在"科学数据原生的多模态表示"与"长程工具调用可靠性"两个子问题上。

📎 arXiv:2611.21072（来源：机器之心）

3开源资源

本期值得关注的开源模型、基准与工具，均提供权重或代码，便于复现与二次研究。

腾讯混元 Hy4（含 base / FP8 版本 + System Card）

腾讯混元开源的多模态 MoE 大模型正式版：总参数 770B、激活 49B，首次引入视觉能力，支持视觉理解与电脑操作（命令行 + 图形界面），面向开发、办公、深度研究等真实任务。提供后训练版 Hy4、预训练基座 Hy4-base 与 FP8 量化版三个版本，并同步发布模型安全评估卡片（System Card）。权重要点：混元 LLM 系列（Hy3 preview / Hy3 / Hy4 preview / Hy4 / Hy4 flash）已全部开源。

📎 魔搭 ModelScope 社区·GitHub·Hugging Face

Inkling 2 Mini（Thinking Machines，Apache 2.0）

Thinking Machines 以 Apache 2.0 协议发布 Inkling 2 Mini，定位"本地可用的前沿性能"，并据称达到开放 agent 模型的帕累托前沿。对需要本地部署、可审计权重的学术场景是一个值得纳入基线的候选。

📎 Hugging Face Blog·Clem (@ClementDelangue)

AutoRLBench（清华大学 THUNLP）

把真实 RL 训练事故整理成面向诊断与修复的智能体基准：当前版本含 34 个诊断任务、17 个修复任务，覆盖 configuration / reward / data / environment / algorithm / infrastructure 六大故障类别。首轮结果显示，智能体通常能"发现训练出了问题"，但在解释根因、完成可靠修复上仍明显不足——是一个能暴露能力边界的诊断型基准。

📎 大模型智能（TsinghuaNLP）

Hugging Face harness adapters

HF 发布"harness 适配器"方案，用于把同一模型适配到不同 agent harness 上，以提升性能并控制成本。呼应了本期一条重要研究观察：harness 可作为组合泛化器，通过既有 LLM 能力放大泛化效果，而这一方向仍被普遍低估。

📎 Hugging Face Blog·elvis (@omarsar0)

Encoder 侧补充：Agnes Harness / Hospital-bench / Benchmark Factory（Meta）

量子位报道的 Agnes 以"双系统决策 + 双层自进化"使 agent 效率最高提速 14 倍、成本降至 1/27，并已开源 Agnes Harness；Hospital-bench 以 13 个应用、131 个工具模拟医院运营，20 个模型 48 项任务中 GPT-6.2 Astra 均分 62.4% 领先，安全失误（如泄露受限病历）成为主要挑战；Meta 的 Benchmark Factory 则提出用 agent 循环把内部已合并的代码改动自动转为编码基准，且质量检查无需逐任务人工标注。

4趋势观察

基于本期语料，给出五个值得追踪的研究方向判断。

① 评测正从"刷榜"转向"诊断"

本期密集出现 TELEVAL、MedChemBench、AutoRLBench、Hospital-bench、Benchmark Factory 等基准，且多以"暴露短板"为设计目标（如 AutoRLBench 首轮即揭示 agent 修复能力不足、Hospital-bench 揭示安全失误）。与之呼应，腾讯首席 AI 科学家姚顺雨在清华闭门交流中明确反对唯指标导向与过度"赛马"，警惕针对测试集刷分让评测失去诊断价值。评测方法论的自觉，正在成为与模型能力并行的研究议题。

📎 AI 前线（姚顺雨）

② Harness 作为"组合泛化器"：被低估的研究前沿

elvis（@omarsar0）指出，定制 harness 能带来显著增益，学界开始将其理解为compositional generalizer——通过既有 LLM 能力放大泛化，而非依赖新能力；其本人已在"后训练协同演化 harness 与模型"上看到初步成功。结合 Hugging Face 的 harness adapters，这提示一个可研究的假设：harness 与模型应被联合优化，而非各自独立设计。这与"agent 不应锁定在单一 harness"的工程主张相互印证。

③ AI 自主科研：严谨性与新颖性的结构性权衡

936 个 AI 智能体的三个月实验给出迄今较系统的经验证据：AI 论文在实验严谨性上高出人类约 2/10，却在新颖性上低约 0.4/10，且"代码-论文不一致""直接调用标准答案""对照组未调好"等失效模式反复出现。这提示自主科研的瓶颈可能不在"执行"而在"提出问题与验证结论"，Verifier 与程序化审稿（把审稿意见写成可执行代码）将成为关键工具。

④ 后 AGI 议程：DeepMind 提出通往 ASI 的四条路径

Google DeepMind Institute 发布《AGI 之后是什么？》，主张 AGI 只是智能连续谱上的一个阶段，并从智能能力边界、认知工业化、技术发展路径、递归自我改进四个角度提出通往 ASI 的潜在路线，强调超级智能时代的关键挑战不仅是"做出更强 AI"，还包括如何衡量、预测与治理技术进步。该文为"评测/治理"议题提供了自上而下的框架支撑。

📎 机器之心·原文

⑤ 持续学习仍是 AGI 前最硬的一道坎

腾讯科技梳理了从 Sutton、Karpathy 到 Hassabis、Sutskever 的一致判断：静态预训练的泛化效率远不及人类，agent 若不能在与环境交互中"边走边学"，就无法像人类实习生一样真正上岗。这与本期 OpenAI 内部研究报告形成对照——对预计需人类 2–4 小时的任务，agent 无人工介入成功率已从 23% 升至 46%（监控训练达 79%，写推理/服务系统代码仅 25%），但"研发下一代 AI"仍高度依赖人类。两条信号共同指向：短期能力跃升与长期持续学习缺口并存。
