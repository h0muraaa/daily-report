深度分析 Deep Dive

深度分析 01 · 工程组织

AI 编程正在倒逼工程基础设施与组织模型重写

今天最值得技术高管重视的数字，不是某个模型的跑分，而是 Anthropic 的代码合并曲线：日均合并量从 5 月的约 2500 次升至 9 月的 3 万次以上，四个月增长 12 倍。增长的主要来源是 Claude 自主修改代码、执行测试和反复优化，而原本服务于人类工程师的开发基础设施开始系统性失灵。

关键数字：monorepo 主分支历史接近 100GB · 压缩工作副本超 25GB · CI 每天约 2500 万次代码检出 · 朴素 Git 获取折算每天超 600PB 传输 · 最终由 7 人、5 个月重写版本控制系统。

这不是 Anthropic 独有的问题，而是所有认真使用 Coding Agent 的团队终将遇到的容量曲线。当 Agent 把「写」的成本压到接近于零，系统的约束会依次转移到代码托管、CI 并发、评审带宽、环境一致性和质量验证上。

三个同时发生的变化

  • 协作层从「人协调人」变成「程序协调 Agent」。Anthropic 的 Dynamic Workflows 让 Claude 生成编排程序来启动子 Agent、衔接阶段并汇总结果，主 Agent 从持续协调中解放出来。Google Research 同期开源的 Harness² 更进一步：用 Propose–Probe–Compose 的递归框架，在没有 ground-truth 验证器的开放任务上持续改进 Agent harness，试图解决递归自我改进「换任务就失效」的问题。编排与验收正在成为独立的技术栈。
  • 人类的工作重心从「写代码」转向「定义骨架与验收标准」。InfoQ 采访的首席架构师 Carlos Kelkboom 给出五条反常识原则，核心是：亲自搭建代码骨架、提前确定目录与关键函数签名；禁止主 Agent 直接改代码和文件；生成的代码如果看不懂，宁可扔掉重来。换句话说，人类保留架构决策和结果责任，Agent 获得执行空间。
  • 人才模型被重新定价。马东锡引述 Anthropic 报告称，其内部 AI Agent 的工时已是人类工时的 6 倍；Anthropic 越来越看重自主推进、模糊问题下的判断力、AI 工具熟练度和结果所有权四项特质。「2027 年停止招聘 Junior 工程师」是原帖博流量的表达，不必照单全收，但初级工程师的生存空间确实在被剧烈压缩。单纯会写代码已不再构成竞争优势，能把真实业务问题拆成任务并交付上线才是。

CTO 应该得出的判断

AI 编程的竞争焦点已经从「谁让 Agent 写得快」转为「谁能让 Agent 的产出可验证、可合并、可回滚」。这意味着预算结构要变：减少对「席位数量」的关注，增加对 CI 并发、远端缓存、merge queue、堆叠 PR、按需预览环境、变更级可观测性和 eval harness 的投入。组织上，应明确「人类负责骨架与验收、Agent 负责执行」的分工，并用每次合并成本、从提交到可验证时长、变更失败率、缺陷逃逸率四个指标来衡量体系是否真的变快，而不是只统计生成了多少行代码。

深度分析 02 · 资本与单位经济

一边是模型价格断崖，一边是算力资产重估——AI 资本周期进入「双向定价」

今天的新闻呈现出一种看似矛盾、实则同源的结构：模型侧的性价比在快速改善，算力资产侧却在被重新估值。DeepSeek V4.1 Flash 1017 在长程浏览器任务上追平 Opus 5.5，单任务成本从 2.35 美元降到 0.22 美元；同一天，英伟达在 9 个交易日内蒸发约 6000 亿美元市值，全球前 20 大 AI 与半导体企业在四个交易日内合计缩水约 1 万亿美元。前者说明推理成本还在陡峭下降，后者说明资本市场开始追问：如此庞大的资本开支，最终由谁来付账。

三层价格正在同时重估

  • 模型层：性能—成本帕累托前沿持续外移。DeepSeek 官方称新版本通过自反馈强化学习提升了从零构建完整项目的能力，并缩短了任务时间和输出长度；Ollama 以零数据保留的美国托管版本承接企业负载，国际版限时免费至 10 月 31 日。Browser Use 的实测显示，在长程 Agent 任务上，低价模型已经可以进入「够用」区间。这意味着按任务分层路由模型、而不是全量使用最贵模型，已经具备可操作的性价比基础。
  • 算力层：中间商被资本重新定价。Modal 以 157.5 亿美元估值完成 7.5 亿美元 D 轮，5 个月估值涨到 3.4 倍；无问芯穹完成 23 亿元 C 轮，累计融资 43 亿元；中国电信领投清程极智。美国按收入给算力中间层定价，中国则在为国产芯片的可用性定价。对企业的含义是：算力供给的竞争会压低单位价格，但供应商的稳定性和锁定风险需要单独评估。
  • 叙事层：预测越来越大胆，验证越来越稀缺。Anthropic 联合创始人 Jack Clark 在 IMF 讲座上提出「奇点已至」，并预测 AI 可能把美国 GDP 在 2030 年推上 44 万亿美元；Gary Marcus 则公开质疑这一预测「几乎没有实现可能」。无论谁对，技术负责人都不应把供应商的宏观叙事直接当作自己的投资假设，而应回到自己的任务级成本、吞吐和收入数据。

一个必须正视的反面案例

Character.AI 于 10 月 12 日正式申请破产保护。破产法庭文件显示，其 2024 年下半年月均算力开支高达 1380 万美元，2025 年仍维持在月均约 1000 万美元，而 2026 年 8 月月度总收入仅约 530 万美元，破产前每月亏损 800–900 万美元。这个案例说明：用户愿意和 AI 聊多久，与企业能从聊天中赚多少钱，是两回事；推理成本不会因为产品「有温度」而自动下降。与之对照，Supabase 以 100 亿美元估值成为 AI 编程工具的默认数据库，每周新增 100 万以上数据库、约 70% 由 AI 工具创建，但它的默认入口曾因 v0 切换竞品而受冲击——渠道默认位同样不是永久护城河。

CTO 应该得出的判断

把「任务级单位经济」变成产品与架构评审的固定项：每个 AI 功能都要能回答单次任务成本、毛利率、模型替换成本和失败重试成本。采购上保持两家以上可切换的模型与算力供应商，对多年期算力承诺保持谨慎；架构上建立统一的模型网关与成本遥测，让路由、缓存和降级策略可以被度量。Every 提出的「AI 产品路线图每三个月就会过期」并非夸张——当底层能力与价格每个季度都在变，路线图的假设也需要同步刷新。

CTO 视角 Action Items

  1. 按任务重跑模型选型与经济性模型。 用 2–4 周建立任务级 eval 与成本遥测，区分高峰值任务和长尾任务：成本敏感的长程任务引入 DeepSeek 等高性价比模型，高风险任务保留前沿模型；每季度重跑一次。DeepSeek 与 Opus 在长程浏览器任务上已同分，而单任务成本相差约 19 倍，这种价差不会等人。
  2. 提前为 10 倍代码吞吐扩容工程基础设施。 预算优先给 CI 并发、远端缓存、merge queue、堆叠 PR、按需预览环境和变更级可观测性；用「每次合并成本」和「从提交到可验证时长」作为核心指标，而不是代码行数。Anthropic 四个月 12 倍合并量、每天 2500 万次检出的曲线，就是 12–18 个月后的你。
  3. 为 Agent 建立「使命 + 预算 + 审批边界」的治理模型。 不要只用 rate limit：给 Agent 独立身份与短期凭证，对高风险动作要求人工审批，设置调用次数、金额和时间预算，保留完整审计链；第三方 API Key 纳入轮换与最小权限。Resy 的 200 次调用封号与 OpenCode 的密钥泄露，说明「善意但无边界」的 Agent 同样会造成事故。
  4. 重写工程人才标准与评审流程。 招聘与晋升标准加入自主推进、判断力、AI 工具熟练度和结果所有权；架构骨架与验收责任保留在人类；让初级工程师从「写代码」转向「定义问题 + 验证结果」。Anthropic 内部 Agent 工时已是人类的 6 倍，单纯编码能力不再是稀缺项。
  5. 建立双轨供应商与数据主权策略。 模型层至少保留两家可切换供应商，关键负载准备跨云或主权云部署方案，合同中明确数据保留、训练使用与断网可用性条款；算力中间层保持 2–3 家候选并半年比价。英伟达的估值回调与 AWS 的主权云演练都在提醒：供应链和合规假设需要定期压力测试。
