二、深度投资分析

今日两条主线：a16z 对 AI 时代风险投资底层逻辑的重估，以及国产 AI 算力产业链资本化的收官与检验。

深度一：a16z 重写 AI 投资逻辑——幂律极端化、任务经济价值与「1997 而非 2000」

事实与数据

在 a16z 的一期播客中，Jen Kha、David George 与 Accolade Partners 的 Aram Verdiyan 系统讨论了 AI 时代 VC 逻辑的变化，核心数据与判断有四点：

  • 幂律被显著极端化。 研究覆盖美国 3000 家风险投资机构过去 20 年数据，只有 20 家持续实现 3 倍净回报——不到整体的 1%。David George 认为当前幂律比过去 10—20 年更极端，原因是首次出现「资金可直接复利放大公司竞争优势」的情形：过去给初创公司砸过多的钱往往因协调成本与管理层级膨胀而反噬，资金与增长甚至可能负相关；而在 AI 时代，钱可以直接转化为算力、数据与人才壁垒。
  • TAM 的重新定义。 a16z 认为 AI 攻打的不是软件市场，而是「任务的经济价值」本身，这一口径下的市场规模是传统 SaaS 的十倍以上。这意味着用既有 SaaS TAM 模型去估算 AI 公司天花板，会系统性低估头部标的。
  • 周期定位：更像 1997 年。 其判断当前并未处于 2000 年泡沫前夜，而是更接近 1997 年——基础设施刚成型、应用渗透刚开始放量。
  • 渗透率仍极低。 a16z 的 David George 表示「实体经济几乎没有开始采用 AI」：美国中位数公司每员工每月在 AI 上花费约 12 美元，而其观测数据集中前 1% 的公司已达每员工每月 7,000 美元；最前沿的银行在 AI 工具上的支出大约只占人力成本的 1%。

投资含义

把这几条拼起来，得到的是一幅「高集中度 + 长坡厚雪」的图景。一方面，退出数据（2026 年至今 2.18 万亿美元，单笔 SpaceXAI IPO 超过此前五年之和）与 20/3000 的持续回报率说明：AI 时代的超额收益正高度集中于极少数头部公司，传统「广撒网」策略的 alpha 被压缩，中部基金的处境尤为尴尬。另一方面，12 美元与 7,000 美元之间近 583 倍的渗透率差距，意味着需求侧的空间远未释放——这正是 a16z 称「极其看多」的论据来源。

对配置方的实操建议是分两层：在退出端，应重新评估组合对超大额晚期标的的暴露度，因为能否上车头部直接决定组合回报的量级；在进入端，渗透率数据支持继续押注「AI 向非科技行业扩散」的中期主题（金融、医疗、工业等仍是低渗透区），而非仅停留在 coding 这一已相对拥挤的场景。

关键分歧点：「1997 而非 2000」的判断意味着当前估值仍有基本面支撑，但这依赖两个前提——渗透率确实按 S 曲线向上，且资金向头部的复利效应不会因监管或算力约束中断。若推理成本下行速度不及预期、或头部公司收入兑现节奏低于估值隐含预期，幂律极端化的另一面（集中度风险）会同步放大。

深度二：国产 AI 算力资本化收官——从「讲故事」到「业绩兑现」的分水岭

事实与数据

过去 24 小时，国产 AI 产业链集中释放了一批资本化与经营数据：

  • 燧原科技上市首日 +188.37%，市值 1764 亿元。 随着燧原挂牌，「国产 GPU 四小龙」全部完成资本化。公司采用 DSA 架构、Fabless 模式，三年研发投入 36.76 亿元，本次募资主要投向第五、六代芯片。
  • 长鑫存储 Q2 息税前利润率 82%，反超三星与 SK 海力士，显示国产存储在涨价周期中的盈利弹性。
  • 月之暗面 ARR 冲击 20 亿美元，Kimi K2.8 全量上线并冲刺港股 IPO；智谱启动约 50 亿美元再融资（股权配售 + 可转债）。
  • 宇树科技总市值跌破 2000 亿元，与此前高位形成对比，是当日具身智能板块少见的估值回调信号。

投资含义

这批事件共同指向一个转折：国产 AI 资产的定价依据，正在从「叙事与国产替代预期」切换到「公开市场的收入与利润兑现」。燧原的高开说明一级市场积累的预期在二级市场得到了兑现，但 1764 亿元的市值也意味着市场已提前计入了多代产品的成功——后续每一代芯片的流片、量产与客户导入都将直接对应估值波动。长鑫 82% 的息税前利润率是硬指标，但其强周期性决定了这是盈利高点区间的读数，不宜线性外推。

更值得关注的是估值分化已经出现：月之暗面以 ARR 与 IPO 进程支撑估值，智谱以 50 亿美元级混合融资锁定长期资金，而宇树科技的市值回调则说明「具身智能叙事」在二级市场也开始接受现金流检验。对一级投资人的操作含义是，在国产算力与模型这两条最拥挤的赛道上，尽调重心应从「技术路线与团队背景」进一步前移到「订单可见度与单位经济模型」，因为退出通道打开的同时，检验标准也随之提高。

需要跟踪的变量：① 燧原上市后的首个季度财报能否支撑当前市值隐含的增长预期；② 长鑫的利润率能否在存储价格周期回落时保持韧性；③ 月之暗面与智谱的 ARR / 融资节奏，将共同构成国产大模型的估值锚点；④ 宇树科技的回调是孤立事件还是具身智能板块估值重估的起点。

三、赛道雷达

四个值得持续跟踪的细分方向及其商业化信号。

Agent 基础设施Harness 即服务：OpenAI 把 Codex「拆开卖」

OpenAI 同日发布 Agents API、GPT-Live-1 API、Data Agent 及 ChatGPT for Financial Services 四条产品线，其中最重要的是 Agents API——把原本藏在 Codex 背后、负责持续工作、调用工具、管理上下文与多 Agent 协同的能力抽出来，打包成云端 API 对外开放，按 Agent = Model + Harness 的范式做平台化。同期 OpenAI Codex 团队与 Anthropic Claude Code 团队给出相反判断：前者认为模型变强后 Harness 会越来越轻，后者认为 Harness 会越来越重、成为「承重墙」。这一分歧直接决定 Agent 中间层公司的价值归属——若 Harness 做厚，中间层有独立商业空间；若做薄，价值将回流模型厂商。这是当前 Agent 赛道最值得下注判断的结构性问题。

推理成本模型商品化加速：DeepSeek 用价格重划竞争线

DeepSeek V4.1 Flash 在 OpenRouter 上 24 小时消耗 1 万亿 tokens，按当前节奏 48 小时将达约 2.8 万亿，成为付费模型发布中规模最大的一次；其中 90% 为缓存读取，市场定价约 $0.006/M tokens，比 GLM-5.3 Flash 等同类模型便宜约 5 倍。该模型采用 763B 总参数 / P8B / D16B 的因果编码器—解码器新架构并支持视觉。推理价格的持续下探对投资含义明确：模型层本身的差异化在收窄，利润将更多向「能压低单位推理成本的基础设施」和「能锁定工作流的应用层」转移。

应用层自研「AI Costco」开始卖自有品牌：Genspark 的垂直后训练路径

Genspark 发布 PPT 专用模型 Gen-1 Slides，以开源基座 MiniMax M3 为底、Fireworks AI 参与训练，用约 2000 个内部 Slides 任务做强化学习。在 200 个真实 PPT 任务中综合得分 0.821，略高于 Claude Opus 5 的 0.810；而完成一份 PPT 的平均模型调用成本分别为 0.44 美元 与 4.16 美元——约 1/9.5 的成本。这是「应用公司基于开源基座做垂直后训练」的清晰样本：模型能力可对齐头部闭源模型，成本却低一个数量级。其投资含义在于，应用层的护城河正从「模型接入」转向「任务数据 + 后训练工程能力」，具备场景数据的一方有机会把推理成本优势转化为毛利优势。
