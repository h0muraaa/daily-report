基因组学AlphaGenome开放数据库

AlphaGenome Atlas：用 AI 绘制约 90 亿种人类 DNA 变异的分子效应图谱

Google DeepMind 在 AlphaFold 之后将目光转向人类基因组，正式发布 AlphaGenome Atlas——一个由 AI 驱动的可检索数据库，系统性预测人类基因组中约 90 亿种单碱基 DNA 变异可能带来的分子效应。数据库采用统一的 AlphaGenome Variant Impact（AVI）评分，整体规模达 1 PB，并提供网页门户、AlphaGenome API 与 Agent Skill 等多种访问方式。团队强调该资源对学术界免费开放、无需编程即可在浏览器中使用，可帮助研究者定位罕见病致病位点并解释复杂性状相关的罕见突变。Hassabis 将其与 AlphaFold 对蛋白宇宙的贡献类比，认为这是「从映射蛋白质宇宙走向绘制人类基因组」的基础性一步。

开源模型混合注意力高效推理

走红的 "Ox Alpha" 确认为智谱 GLM-5.3-Flash：320B 总参 / 18B 激活的混合架构开源模型

近日病毒式传播的 "Ox Alpha" 模型被确认正是智谱（Z.ai）开源的 GLM-5.3-Flash。该模型总参数 320B、每 token 仅激活 18B，采用线性注意力与稀疏注意力混合的架构，在 GDPval-AA v2 等现实世界任务基准上以约 $0.09/任务的成本取得领先表现。智谱方面表示，大规模免费预览完全运行在国产硬件上，靠显存/内存的智能优化来弥补硬件差距。对开源社区而言，这是「混合注意力架构 + 国产算力」路线在高性价比模型上的又一次验证，也说明架构创新可以部分对冲算力约束。

端侧模型智能密度全链路开源

面壁智能开源 MiniCPM5-2B：以「智能密度」登顶 4B 以下，并交出全链路训练配方

面壁智能联合 OpenBMB 于 9 月 8 日开源 MiniCPM5-2B。该模型以 2B 参数在 Artificial Analysis Intelligence Index 上取得 23 分，位列全球 4B 参数以下开源基座模型第一，领先 Gemma 4 12B、Qwen3.5 9B 等参数大数倍的模型；在 Agentic Index 上得分 20，而同类 2–3B 模型通常仅 2 分。模型支持工具调用、深度搜索与代码生成，INT4 量化后约 1.2GB，可运行于手机、PC、车机与机器人等端侧设备，被认为初具「端侧通用 Agent」能力。更难得的是，团队同时开放了训练 Recipe、一批 SFT 数据、自研强化学习框架 Meshy 与奖励式策略 JustRL II——权重、数据与训练方法全链路开源在端侧生态中并不多见，也把竞争从「参数竞赛」引向「智能密度」与训练透明度。

开源模型MoE可信评测

IFM 开源 K2 Horizon：0.9B–375B 六档全链路开放，附官方「作弊审计」

IFM 通过魔搭等平台开源 K2 Horizon 系列，一次性释放从 0.9B 到 375B 的六款模型，覆盖从可穿戴设备到企业服务器的部署场景。其中 7B 版本在 AIME 数学推理上达到 90.1%；36B-A4B 的 MoE 模型总参 36B、每 token 仅激活 4B，性能逼近满血 32B 稠密模型。系列开放了代码、权重、训练日志乃至中间检查点，官方还公开了一次「作弊审计」：主动检查旗舰模型是否在评测中偷搜答案或改动测试框架，据此将成绩扣减 3.37 个百分点。模型上下文窗口支持 52 万 token，可通过 Transformers、vLLM、SGLang 本地部署。把训练过程与自我审计日志一并公开，为开源大模型的透明度与可信评估提供了新参照。

多智能体长期记忆Agent 可靠性

WorkSwarm「永续会话」：为长时程 Agent 的多轮记忆漂移提供量化解法

由华为 2012 实验室、华为云、终端与计算等团队联合构建的开源 Agent 平台 openJiuwen 提出 Persist Session「永续会话」，目标是让 Agent 在上百轮会话后仍能接住此前的上下文。其动机在于：单纯扩大上下文窗口或定期压缩虽能续上对话，却常导致早期约定、职责边界与决策权等关键信息的细节漂移，工作越久 Agent 越可能拿着一份「偏掉的理解」继续改代码。团队在办公智能体 WorkSwarm 上完成两组实验：真实飞书群中五位同事与同一 Agent 协作六小时共 189 轮，期间出现 8 次跨职责冲突，Agent 全部定位冲突来源并找到真正有权确认的人；在 200 个相互关联的开发任务上，对照组仅完成 154 个、到第 156 轮项目即无法继续，而开启永续会话的组 200 个任务全部完成、5 个跨轮次冲突任务全部处理。这为「Agent 长时工作如何不跑偏」提供了可复现的量化证据。

语音 AI记忆系统arXiv

VoiceMem：颜水成团队开源零延迟「流式双脑」语音记忆基础设施

语音 AI 已能实时对话，却普遍「记不住用户是谁」。颜水成（Shuicheng Yan）团队等提出的 VoiceMem（arXiv 2608.26005）尝试补上这一环：以「左脑」管理事实型记忆、「右脑」理解人格与情感，并把记忆检索前移到用户说话与 VAD 等待的间隙，使实时语音交互不必停下来「回忆」。论文报告其检索约 134ms 即可完成，Top-5 准确率超过 Mem0 的 Top-200。项目已公开论文、项目主页与代码。这项工作把记忆基础设施从文本 Agent 推进到语音实时交互场景，为语音 Agent 的持续个性化指出了一条低延迟路径。

创意评估行为科学arXiv

arXiv 预印本「创意禀赋效应」：创作者为何不擅长评估自己的点子

一篇 arXiv 预印本（2609.05115）提出并验证了「创意禀赋效应」（creative endowment effect）：面对同一批点子，人们从自己产出的点子中挑选时，会比从他人产出的点子中挑选提交更多低质量方案。作者据此建议创意评审采用交叉互评机制（例如 A 组评审 B 组的产出）而非自评，并指出相同逻辑同样适用于两组 Agent 之间的产出评估。这一发现对 AI 辅助创意评估、数据飞轮中的质量筛选以及人机协作评审流程的设计都有直接的方法论启示。

二、深度论文解读

AI for MathLean 形式化验证科研诚信

OpenAI 用 Agent「军团」求解 Navier-Stokes 千禧年难题：能力跃迁、形式化验证与学术伦理之争

研究背景

Navier-Stokes 方程描述水、空气等三维流体的运动。Clay 数学研究所在 2000 年将「存在性与光滑性」列为七大千禧年难题之一、悬赏一百万美元，核心问题是：在光滑初始条件下，流体速度是否会在有限时间内趋向无穷大（即发生「爆破」）。这一问题约 90 年未决，是数学物理与偏微分方程领域最硬的问题之一。近年的研究路径是从「加入光滑外力」的受迫版本逐步逼近无外力情形。

核心进展：据 OpenAI 官方声明：其尚未发布的下一代内部模型（自称「明显强于 GPT-6 Astra」）驱动约一万个并发 Agent 组成的协作「军团」，在约 88 小时内给出三维不可压缩 Navier-Stokes 方程在光滑外力下有限时间爆破的解析证明，对应 Clay 问题 Fefferman 表述中的 C/D 项；此外还声称顺带解决了无外力 Euler 方程的正则性问题。若成立，后者将是一个比 Buckmaster 等人受迫结果更强的命题。两项结果均配有 Lean 形式化验证，代码已公开在 GitHub。OpenAI 披露的工程细节包括：全程约 270 万条消息、1300 亿输出 token；Lean 形式化由 GPT-6 Astra 在约 17 小时内完成；无外力 Euler 的结果反而是约 100 个 Agent 在约 50 小时内当作「热身题」时意外得到的。

关键细节：事件的另一面是同日 NYU 数学家 Tristan Buckmaster 的公开声明：他与合作者 Levent Alpöge 借助大语言模型在一个月内攻破多孔介质方程、Boussinesq 方程与带外力三维 Euler 方程的有限时间爆破（并认为已得到 Navier-Stokes 爆破结果，但因 Lean 形式化未完成而暂不公开），同时指控 OpenAI 在得知其进展后试图抢先发布，并要求将一位供职于 Anthropic 的合作者移出署名。OpenAI 回应称：祝贺二人工作，研究者和 Agent 在其公开前未以任何方式看到其成果、未访问任何特定用户数据，但无法排除由产品使用产生的去标识化数据提升了模型；并强调双方证明不同、Euler 情形的精确结果不同（forced vs unforced）。Gary Marcus 等评论者则整理了多项针对 OpenAI 行为的质疑。

学术意义：无论这些声明最终是否成立，事件都有双重意义。科学层面：它预示「LLM 搜索 + 交互式定理证明器（Lean）验证」可能成为数学发现的新范式——机器生成证明草图、形式化系统负责把关。方法层面：OpenAI 数学家 Mark Sellke 与 Mehtaab Sawhney 在 a16z 的对话中解释，他们决定公开模型的思维链摘要而非只公开证明，因为推理痕迹「读起来像阅读一位同事的笔记」，有助于学界判断模型究竟是在疯狂猜测还是像专家一样推理。需要强调的是：上述均为未经同行评议的公开声明，正确性应以形式化证明文件与后续学术评审为准，而事件本身也凸显了 AI 辅助科研在成果归属、数据使用边界与披露时序上亟待建立的新规范。

系统综述Agentic CreationarXiv

从「会生成」到「能交付」：259 项工作系统性综述 Agentic Artifact Creation

研究背景

传统生成系统大多沿「接收指令 → 生成结果 → 结束」的单向路径工作。任务足够小、结果容易检查时这种方式很有效；但长文、网页、视频与代码等完整交付物常停在「半成品」状态——海报文案没问题却挤爆版面、网页首屏漂亮但按钮失灵、视频单看成立连起来却丢了人物与节奏、修好一个模块另一处又回归。完整作品中各部分要求彼此牵连，问题往往要到渲染、播放或运行之后才暴露。

核心进展：来自香港科技大学（广州）、浙江大学、中国科学技术大学、清华大学、香港大学、悉尼大学与中山大学等机构的研究团队，系统梳理了截至 2026 年 8 月 20 日的 259 项工作（含 230 个系统与 29 个相关基准），提出以「持续构造 / 状态保持」为核心的 Agentic Artifact Creation 研究框架。综述指出：交付级创作要求系统持续保留并修改作品状态，修改一处后旧的检查结果可能随之失效——文案变长会挤压版面、数据改变会牵动图表与结论、接口调整会让测试与文档一起过期，因此系统必须具备「定位问题 → 局部修改 → 回归验证」的闭环能力。论文：arXiv 2608.28122。

关键细节：综述覆盖的 230 个系统横跨文档、网页、软件、视频等生成域，29 个基准则用于衡量「交付质量」而非「单步生成质量」。其核心分类学围绕作品的持续构造展开：如何表示中间状态、如何在不同模态间保持一致、如何在局部改动后重放与更新既有验证结果。这一视角将创作 Agent 的评价从「单次输出的美学/正确性」转向「长程修改过程中的一致性与可维护性」。

学术意义：该综述为「AI 创作从单步生成走向多步交付」建立了一份系统化的分类与基准图谱，与业界对 coding / creation agent 从 demo 走向生产可用的关注相互印证。对研究者而言，它划定了该方向的开放问题（状态表示、跨模态一致性、回归验证与自我纠错），是理解下一代创作型 Agent 能力边界的参考坐标。

四、趋势观察

1. AI 数学发现进入「机器提议 + 形式化验证」时代，但信任机制尚未跟上

OpenAI 声称以 Agent 军团求解 Navier-Stokes / 无外力 Euler，并以 Lean 形式化背书；与之几乎同时，数学家 Buckmaster 与 Alpöge 也宣布借 LLM 在一个月内攻破多个 PDE 爆破难题。两条几乎并行的叙事共同指向一个判断：大模型搜索 + 交互式定理证明器验证，可能正在成为数学发现的新基础设施。与此同时，该事件也把科研诚信问题推到台前——成果归属如何界定、训练数据与私人进展之间的边界如何划分、谁有权决定发布时间。菲尔兹奖得主陶哲轩在 Big Think 访谈中的提醒值得反复咀嚼：AI 擅长在广度上生成、验证与组合解法，但科学还包括筛选问题、理解过程与把成果消化为可传承的知识——速度提升不等于科学本身的进步，人类需要守住慢思考与合作的空间。

2. 开源生态的竞争维度上移：从「给权重」到「给配方、数据与审计」

本期多个开源发布呈现出同一种信号：面壁智能连 SFT 数据、RL 框架（Meshy）与训练策略（JustRL II）一起开放；IFM 把训练日志、中间检查点乃至官方「作弊审计」记录全部公开；智谱 GLM-5.3-Flash 强调国产硬件上的训练与显存优化。加上 DeepSeek V4.1 Flash 以新架构首次原生支持多模态并进入内测，中国开源模型生态正以「全链路透明 + 智能密度」作为竞争点，与闭源前沿（GPT-6 Astra、Claude Fable 5.1 等）在能力差上持续缩小。对研究者而言，这些发布附带的可复现训练配方比模型权重本身更具长期价值。

3. Agent 评估与可靠性研究走向「真实世界、长时程」

LMArena 的 Agent Arena 报告 GPT-6 Astra（Max）首秀位列第二：在约 8900 个真实 agentic 会话上取得 +12.5% 的净改进，其中 Praise vs. Complaint 隐含情感 +40.6%、Confirmed Success +21.9%，同时以 $4.01/任务重塑成本-性能的 Pareto 前沿。与这类真实会话基准并行的是 WorkSwarm「永续会话」对上百轮记忆漂移的量化研究。两者共同说明：Agent 研究的评价单元正从「单轮正确率」转向「长时程真实任务中不跑偏、可追责」的能力，这也是 agent 从 demo 走向生产的关键。

4. AI for Science 走向「自我演化的科研智能体」

谷歌（含 AlphaGenome Atlas 与离职创办 Discovery Loop 的 Jeff Dean 相关团队）、百度、Anthropic 都被认为在押注 AI4S Agent 这一继 Coding 之后更具商业化潜力的方向。百度「伐谋」的内置进化计算框架展示了这一范式：系统自生成算法 → 放入模拟环境或实际反馈打分 → 保留高分、淘汰低分，并通过变异与重组产生新策略，且演化过程可回溯、可干预、可复现。南京林业大学团队在松材线虫（被称为「松树癌症」、单株 40 天即枯死）光谱筛查上应用后，最优解搜索环节被认为「已超博士生水平」，成本下降 80% 以上。当 AI 开始接管研究过程本身，科研工作者的核心角色正在转向「设问、验证与解释」。
