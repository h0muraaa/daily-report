今日要点

四条最值得用户体验从业者关注的核心洞察。

1交互模型正在「三明治化」：软件要为「人 + Agent」两个用户而设计

增长研究者 Peter Yang 的一条高传播观察，把当下最根本的交互变迁压缩成一张图：为人类而建的软件，正在快速沦为「面向 Agent 的基础设施」；交互模型从两端直连的「人 ↔ 软件」，演化为三段式的「人 ↔ Agent ↔ 软件」。他的判断是——大多数公司还没有为这一转变做好准备。放在体验语境里，这意味着软件的服务对象从一个「终端用户」扩展成了两个：既要被坐在屏幕前的人看懂，也要被中间层的 Agent 读懂、调用与代理操作。

对 UX 研究者的启示是结构性的：当「用户」不再只是人，可读性、权限边界、结构化接口、内容被正确传达给 Agent 的能力，都会成为体验设计的新科目；传统的「以人为中心」需要扩展出「以人机协作为中心」的研究方法——比如去研究 Agent 会怎么「误读」你的界面、又会把哪些人的选择权悄悄接管。

设计启示　把 Agent 当成产品的「第二用户」来设计：先问「它看得懂我的界面与数据吗」，再问「人看了会不会信任它的代办」——新的体验漏斗要从这里重新画起。
📎 来源: Peter Yang(@petergyang)

2AI 开始「互发微信」：当对话的两端都由 Agent 把持，A2A 重塑的是「在场感」

爱范儿「AI 器物志」第 24 篇把镜头对准了 A2A（Agent 间对话）这个正在发生的趋势：据报道，微信正在内测「小微 AI 社交」——你想知道朋友动向，可以喊内置 Agent「小微」去找对方的小微、让它直接给你答案，你「不必亲自问」，对方也「不必亲自答」。栏目由此点出一个更深的判断：手机从设计之初就是为「人盯着它」而生的，全部逻辑止于屏幕；而 AI 恰恰相反，它需要持续感知物理世界、随时在场，迟早要从屏幕里「破壳而出」。

趋势在办公侧落地得更快：企业微信官宣升级，Workbuddy、DeepSeek Harness 等 Agent 可以通过企微接口读写文档、表格与日程。报道强调，这最直接的意义不是「AI 帮我们做更多事」，而是一种产品思路的转变——软件开始主动考虑「自己要怎样才能被 Agent 看懂和使用」。当沟通两端都开始由 AI 把持，「社交活人感」从一个浪漫概念变成了需要被认真测量的体验稀缺品。

设计启示　A2A 时代，界面设计师的交付物不再止于「给人看的 UI」，还包括「给 Agent 读的接口、权限与结构化语义」；而对用户研究者来说，「人缺席的对话」会催生全新的信任与期待管理问题。
📎 来源: 爱范儿

3Today AI：一款「记得你、替你做、盯着变化」的 Personal AI，主动到让人觉得「烦」

几乎被 Codex「统治」的 Agent 赛道来了个新玩家：由 Teambition 创始人、前豆包 PC 端负责人齐俊元创办的 Today AI 正式开启公测。硅星人Pro 团队深度体验一周后的判断是，在频繁切换 Codex、Claude Code、Workbuddy 等 Agent 的背景下它仍然值得一用——因为它可能是这一波 Agent 里最重视用户记忆、也最主动的一个：先把邮件、日历、关系、偏好和未完成事项组织成一个围绕用户运转的「任务世界」，再用 Memory 驱动 Proactive，在变化发生时主动提醒，或把没做完的事接着往下做。

这种主动程度，有时甚至会让用户觉得「烦」，但也恰恰构成 Today 与大多数 Agent 最直观的区隔：通用 Agent 等人带着任务来，Today 则介入你的生活。文章抛出的核心命题值得所有 AI 产品研究者记下——「Context 多了，Agent 却不一定更懂你了」：Context 只是 AI 某一刻能看到的原始材料，Context 多不等于 Memory 好，更不等于用户体验好；反过来，这个围绕用户沉淀的任务世界越「厚」越灵活，就越能证明独立 Agent 应用仍有机会在模型之外建立自己的价值。

设计启示　「记忆」与「主动」是一把双刃剑：AI 产品从「被动响应」走向「主动介入」时，打扰的边界、可解释的时机与撤回控制会成为最需要被研究的体验问题——不是所有记得都叫贴心。

4AI 进家这一年：把「智能」排在最后的屋子，让一位老人说出了「舒服」

晚点特写了一个真实可感的「智能住宅」样本：今年夏天最热的两个月，朱女士和老伴住进儿子沈亚楠在北京打造的度假屋。一周下来，她最深的感受是「家怎么可能完全不用开窗」——不开窗空气仍然新鲜，几乎听不见噪音，走到哪都感觉不到明显的空调直吹，像住在 24 度的恒温室里；打开厨房龙头就有 90 多度的热水，连每周给家具擦灰的工夫都省了。睡前她说一句「小七小七，我要睡觉了」，所有灯就自动关了。有意思的是排序：作为创造者的儿子把设计关键词定为「健康、舒适、智能」——智能被刻意放在最后；而母亲向外人总结这屋子时，只说「住着很舒服」。

文章同时给出了反面样本：空气净化器的 AI 实时监测、猫脸识别自动喂食器、动态调温的智能床垫……单点智能一件件装进家里，家反而变得越来越复杂，智能设备成了需要人花心思管理的东西——收纳十几个遥控器、在一堆 App 里找开关。对做适老化和环境智能的团队来说，这是一个浓缩的对照实验：真正的智能感来自「被服务的周到」而不是「被管理的复杂度」，当交互退到幕后、无需学习，用户（尤其是老年用户）才会给出「舒服」这种最高评价。

设计启示　适老化与智能家居的体验目标其实同一件事：让用户忘掉「设备」的存在。用「需要几步操作」衡量智能是错的，应该用「有多少次你根本不需要操作」来衡量。

设计趋势洞察

两个关于「AI 时代设计师差异竞争力」的趋势观察。

趋势一 · AI 做不出来的「复杂组件」：中国 UI 的独立路线，是创作而非临摹

公众号「超人的电话亭」（酸梅干超人）在 2026-09-08 的这篇教学里，点破一个常被忽视的现实：尽管 AI 绘图能力持续增强，它生成的界面始终只能满足「洋人」市场的默认审美，而中国 UI 视觉已经走出了一条独立路线——不仅当前的 AI 做不好，国外 UI 设计师直接上手也做不来。文章把组件分成两类：一类已成为界面基建、有固定命名与样式，比如瓷片区、提示弹窗、动态卡片、用户列表、底部导航栏；另一类则是没有固定命名、没有固定样式的「临时工」，比如专题模块、横向列表、会员卡片、排行榜。

作者的判断很犀利：设计第一类组件只是重新「临摹」一遍，设计第二类才是真正的「创作」——因为没有现成参照，设计师必须自己完成判断与构思，而这正是国内 UI 初学者最大的进阶挑战。他给出的提升路径也相当实操：大量收集组件案例并按类整理进花瓣或 Eagle、掌握组件框架的设计方法、掌握更丰富视觉细节的设计思路。

设计启示　AI 擅长复述「有标准答案的基建」，而真正值钱的是「没有标准答案的创作型组件」。数据训练以海外语料为主，导致 AI 对中国本土设计语言天然盲区——这既是设计师的护城河，也是本地化设计语料的空白市场。
📎 来源: 超人的电话亭

趋势二 · 对抗 AI 同质化的两条路：系统级「零点击」手势，与拟物质感的回摆

当「生成」本身变得廉价，体验设计师的差异来自哪里？今天有两个互补的早期信号值得放在一起看。

路向 A：Tangerine——把操作融进系统级手势，省掉整个中间界面

开发者 thameem 发布的 Mac 应用 Tangerine 主打「零点击」文件转换：不用打开任何界面，按住 Shift 把文件拖出去，即可完成视频/图片格式转换、裁剪等操作（官网 tangerineformac.com）。用户体验博主向阳乔木的评价很有代表性：一次性买断约 15 美元，支持的文件种类与操作还不够丰富，但「交互设计好有意思、想法创意不错」，已下单支持。这是「界面向后退、手势向前走」的一类设计——效率工具的价值从「功能多」转向「步骤少」。

路向 B：拟物主义「文艺复兴」——在 AI 味的扁平里找回真实质感

设计师社区里，Ding(@dingyi) 分享的视频引来了「文艺复兴了，现在人们又开始回归拟物风格了」的感叹。在 AI 生成界面高度趋同、默认卡片套卡片的节点，带真实材质、光影与手工温度的拟物设计，正在重新成为一种情绪价值——它对抗的不是功能，而是那种「一眼 AI」的廉价感。

设计启示　AI 时代的设计差异来自「约束与质感」：一条路是做减法（用系统级手势与默认值消灭中间步骤），另一条路是做加法的手艺感（用真实材质与文化细节重新定价 craft）。两条路指向同一结论——能被模板化的都不再是竞争力。
📎 来源: 向阳乔木(@vista8) · Ding(@dingyi)

产品体验点评

两个 AI 产品的用户体验案例分析。

Grok Bot 一个月从 0 到「同事化」：亲手 onboarding 前 300 个用户的冷启动样本

Lenny's Podcast 与 Roman Ugarte（SpaceXAI 旗下知识工作 Agent「Grok Bot」的产品负责人，此前在 Cursor 负责增长、亲历公司从 15 人增长到 1000+ 直至被 SpaceX 收购）的对谈，拆解了一个极速冷启动案例：一个小而隔离的团队用 4 周把 Grok Bot 从第一行代码做到可用的内部产品，又用 3 周完成了一次「大获成功」的公开上线。访谈里最有研究价值的是两个早期决策——为什么选择从零新建而不是把它加进 Cursor；以及团队为什么亲自为前 300 名早期用户逐一做了手动 onboarding。

这两条决策背后，是他们明确的「同事化（colleague-pilled）」产品哲学：把 Grok Bot 设计成团队里的「同事」而非「工具」。对 Agent 产品的研究者来说，这是一个难得的一手样本——在投放与增长漏斗之前，高接触的「人肉 onboarding」本质上是产品最早期的用户研究：前 300 个用户教会团队「人愿意把什么托付给 Agent、在什么协作模式下最信任它」，这些洞察再沉淀为后续的产品决策与增长杠杆。

点评　Agent 产品的冷启动瓶颈不在流量，在信任。「第一批用户值得手动服务」——那 300 次对话就是最昂贵也最有效的可用性测试与信任研究。
📎 来源: Lenny's Podcast

Codex 开始帮你整理聊天历史：当「记忆的信息架构」也交给 Agent

资深 AI 产品观察者歸藏(@op7418) 演示了 Codex 的一个新能力：让 Agent 查看并整理左侧的聊天记录——不只可以按项目划分、把不用的归档，还能按你的要求重新分组。他的实例是：原本左侧只有一个项目，Codex 帮他分成了「持续迭代」「待跟进」「最近」三类，原项目里的内容被清空；用户只需要告诉它分组逻辑，甚至可以在分组文案前加上 emoji，让展示更清晰。这条推文在 X 上获得了约 2.9 万浏览，说明「对话历史越来越乱」是许多深度用户共同的痛点。

体验上的意义在于：对话记录作为 AI 产品的「长期记忆」，其信息架构（IA）第一次可以由 Agent 主动代劳、而非用户手工维护。这解放了用户，却也抛出新的体验问题——当整理权被让渡，用户如何理解 Agent 的分组逻辑？它会不会把重要的上下文归进「待跟进」而再也想不起来？可解释性与用户控制感，正在成为「AI 帮你管记忆」类功能的下一道体验考题。

点评　信息架构正从「设计师为用户设计」演变为「Agent 按指令为用户整理」；分组的依据、错误的代价与用户的纠错路径，是这类功能最值得被跟踪研究的体验层。
📎 来源: 歸藏(guizang.ai)(@op7418)

研究方法论

值得借鉴的用户研究新方法、新文献与新数据。

259 项工作系统综述：AI 创作从「会生成」到「能交付」，卡在「持续构造」

来自香港科技大学（广州）、浙江大学、中国科学技术大学、清华大学、香港大学、悉尼大学与中山大学等团队的系统综述，梳理了截至 2026-08-20 的 259 项工作（含 230 个系统与 29 个基准），提出了一个切中 AI 创作体验要害的问题：从「会生成」到「能交付」之间到底缺什么？它归纳的「半成品」现象几乎每个用过 AI 创作的人都有体感——海报文案没写错却挤出了版面；网站首屏很漂亮、按钮点下去毫无反应；长视频单看镜头都成立、连起来却丢了人物和节奏；程序刚修好一个模块、另一处又回归。完整作品里的要求彼此牵连，而问题往往要到渲染、播放或运行之后才暴露。

综述的核心论断是：传统生成系统沿着「指令 → 生成 → 结束」的单向路径工作，这只适合足够小、容易检查的任务；完整交付物要求系统持续保留并修改作品状态——修改一处，旧的检查结果可能随之失效，文案变长挤压版面、数据改变牵动图表与结论、接口调整让测试和文档一起过期。这类工作被概括为 Agentic Artifact Creation（Agent 化作品持续构造）。对做 AI 创作工具体验与评估的研究者而言，这是一份很好的文献地图：它提示我们把研究焦点从「单次生成质量」转向「多轮持续构造中的状态保持、回归与可修复性」。

📎 来源: 新智元

「创意禀赋效应」：评自己的点子会手下留情，创意评审要交叉、别自评

AI 产品研究者 Yangyi(@Yangyixxxx) 分享了一篇有意思的 arXiv 论文（2609.05115）：实验发现，面对同一批点子，从「自己想出来的」里面挑选时，人们会比从「别人想出来的」里面挑选时提交更多低质量点子——研究者称之为「创意禀赋效应」（creative endowment effect）。原因是创作者把自己对创意的所有权偏见带进了评估：自己的点子再普通，也更容易被高看一眼。论文给出的实操建议是：创意评审最好不要让写的人自己评价，可以让 A 组挑 B 组的稿，交叉互选反而效果更好。

作者还指出，相同的逻辑同样适用于两组 Agent 的互评。这条发现对用户研究的方法论价值很直接：无论是产品团队内部的概念筛选、用研中的创意测试，还是越来越常见的「AI 生成物评估」，评审流程的设计都要主动防「自评偏差」——通过盲评、交叉评审、第三方打分等结构手段，把「作者身份」与「质量判断」剥离开，才能拿到更接近真实用户偏好的结论。

📎 来源: Yangyi(@Yangyixxxx)
