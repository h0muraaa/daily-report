用户研究版科技日报

以用户为中心的科技产品洞察

2026年3月19日 星期四

主编寄语

今天的设计领域正在经历一场静默的革命。从Google的"Vibe Design"到AI Agent工具设计的思维转换，我们看到设计范式正在从"为人类设计界面"转向"为AI设计界面"。作为UX从业者，我们需要重新思考：当Agent成为新的"用户"，我们的设计方法论将如何演进？

✦ 今日要点：核心用户体验洞察

1 AI设计

Google推出"Vibe Design"：AI原生设计平台Stitch重塑UI创作流程

Google Labs发布的Stitch平台标志着设计工具进入AI原生时代。与传统设计工具不同，Stitch允许任何人通过自然语言创建、迭代和协作高保真UI原型。这一转变的核心洞察是：降低设计门槛的同时保持专业输出质量。对于UX团队而言，这意味着设计师的角色将从"执行者"转向"策展人"和"策略制定者"。值得关注的是，Stitch强调的"vibe design"理念——通过氛围和感觉而非精确参数来驱动设计——可能预示着设计思维的根本性转变。

来源：The Keyword (Google)

2 工具设计

Agent工具设计的思维转换：从API思维到UI思维

字节跳动技术团队分享的MCP工具设计技巧揭示了一个关键洞察：为AI Agent设计工具时，需要用"UI思维"替代传统的"API思维"。Agent只能通过工具名称、描述和参数schema来"理解"工具能力，它不会主动查阅文档，试错成本极高。这意味着工具命名、描述文案和参数设计的可用性变得至关重要。优秀的Agent工具设计应该像设计人类用户界面一样精心打磨——清晰的标签、直观的结构、明确的反馈机制。这一洞察对正在构建AI产品的团队具有重要指导意义。

来源：字节跳动技术团队

3 社交产品

Facebook Reels"好友气泡"功能：社交发现体验的机器学习优化

Meta推出的Friend Bubbles功能展示了如何通过机器学习优化社交发现体验。该功能通过估算关系强度并排序好友互动内容，创造更有意义的参与和连接机会。从UX角度看，这一设计的精妙之处在于将"社交信号"与"兴趣信号"相结合——不仅推荐内容，更创造社交契机。用户可以通过点击气泡与任何互动过该内容的好友开始一对一对话。这种设计思路值得借鉴：在内容消费产品中，如何创造社交连接的机会比单纯的内容推荐更有价值。

来源：Engineering at Meta

4 AI教育

豆包爱学：从"给答案"到"教方法"的AI教育体验升级

豆包App的"豆包爱学"功能代表了AI教育产品的重要进化。与传统搜题App直接给出答案不同，它模拟真人教师的引导式教学——理解问题、定位知识点、梳理讲解逻辑，并主动询问学生是否理解。这种设计体现了教育产品设计的核心原则：学习发生在思考过程中，而非获得答案时。产品允许学生随时打断提问，AI会根据反馈重新引导讲解。这种"适应性教学"体验展示了AI在教育领域的真正潜力：无限耐心的个性化辅导。

来源：十字路口Crossing

5 人机交互

CODE27融资千万美元：AI桌面伴侣探索沉浸式交互新方向

AI虚拟角色交互团队CODE27获得超千万美元融资，其定位"新一代AI桌面伴侣"值得关注。核心洞察在于：当前AI陪伴产品虽然角色供给近乎无限，但真正让用户愿意长期停留的"关系感"仍然稀缺。CODE27由DJI与EcoFlow硬件核心团队组成，强调硬件与AI的深度融合。这提示我们：下一代人机交互可能不再是纯软件对话，而是具有物理存在感的产品形态。对于UX设计师而言，这意味着需要开始思考"具身AI"的体验设计范式。

来源：暗涌Waves

◈ 设计趋势洞察

趋势一：产品角色的Agent化重构

知名投资人Andrew Chen提出，在Agent时代，产品经理的角色将分裂为两个方向：一是组织人类（利益相关者、设计师、工程师），二是组织Agent（prompts、evals、工作流）。这一洞察揭示了产品管理范式的根本转变。

传统的PRD、OKR、站会、产品评审等仪式需要找到Agent时代的等价物。例如，"站会"可能变成Agent基于运行日志和异常标记向我们汇报——系统已经完成了数千件事，问题在哪里出错、哪里令人惊讶、哪里变得更好。产品团队需要学会从模式、趋势和边缘案例中发现洞察，而非依赖人工状态更新。

来源：Andrew Chen (@andrewchen)

趋势二：Server-Driven UI的大规模应用

Nubank在QCon London分享的Server-Driven UI实践展示了移动端架构的重要演进。通过Catalyst框架，他们从静态移动二进制文件转向动态脚本化框架，使用Flutter实现树遍历解释器来渲染JSON payload中的动态布局和逻辑。

从UX角度看，Server-Driven UI的优势在于：产品团队可以在不发布新版本的情况下快速迭代界面，实现真正的"持续交付"。这意味着设计师和PM可以更灵活地进行A/B测试和渐进式功能发布，用户体验的优化周期从"周"缩短到"小时"。

来源：InfoQ

◉ 产品体验点评

硬件设计

MacBook Neo的可维修性设计：欧盟新规下的用户体验权衡

iFixit对MacBook Neo的拆解揭示了苹果在可维修性设计上的重大转变。这是14年来最好拆修的MacBook——使用螺丝刀卸下五角螺丝即可徒手卸下后盖，电池用18颗螺丝固定而非胶水粘合。这种设计变化源于欧盟新规：2027年起所有在欧盟销售的便携式产品必须配备用户可更换的电池。

UX洞察：可维修性设计与用户体验并非零和博弈。MacBook Neo在保持"圆润可爱、无刘海"的讨喜设计的同时，实现了更好的可维修性。触控板采用机械结构而非压感，确保整块触控板有一致的扎实手感。这种"用户可维护"的设计理念将逐渐成为消费电子产品的标配，UX团队需要开始考虑"维修体验"作为整体用户体验的一部分。

来源：爱范儿

AI工具

LibTV：首个同时为人类和Agent设计的AI视频创作平台

LibTV代表了AI工具设计的新范式——同时服务人类创作者和AI Agent。产品采用节点式工作流设计，在无限画布上可以自由放置文本、图片、视频、音频和脚本节点，通过连线理清创作思路。更重要的是，它提供API让Agent自动生成视频，实现"人可以做，Agent也可以学"的无缝协作。

UX洞察：LibTV的设计体现了"人机协作"的核心理念。对于专业创作者，节点式工作流提供了灵活的控制；对于Agent用户，API调用实现了从剧本、分镜、生成到剪辑的全流程自动化。这种"双模态"设计可能是未来AI产品的标准范式——既保留人类的专业控制，又支持Agent的自主执行。

来源：数字生命卡兹克、 阿真Irene

◎ 研究方法论

评估方法

AI Agent生产环境评估：从确定性测试到概率性评估

AWS分享的Strands Evals实践指南提出了AI Agent评估的核心挑战：传统软件测试依赖确定性输出（相同输入产生相同预期输出），但AI Agent生成自然语言、做出上下文相关决策，即使相同输入也会产生多样化输出。如何将非确定性系统系统化评估？

方法论要点：（1）多轮模拟能力：评估需要覆盖完整的对话流程，而非单轮交互；（2）内置评估器：使用预定义的评估维度（如准确性、相关性、安全性）进行量化评分；（3）边缘案例挖掘：主动发现系统表现异常的边界条件。对于UX研究团队，这意味着需要建立新的评估框架——不再追求"一致性"，而是追求"可预期的质量分布"。

来源：AWS Machine Learning Blog

A/B测试

AI驱动的A/B测试：从随机分配到智能匹配

Amazon Bedrock的AI驱动A/B测试引擎展示了用户体验优化的进化方向。传统A/B测试随机分配用户，需要数周流量才能达到统计显著性。而AI驱动的方案通过分析用户上下文做出更智能的变体分配决策，帮助减少噪音、更早识别行为模式、更快确定优胜方案。

UX研究启示：这种"上下文感知"的测试方法意味着我们可以更精细地理解"谁适合什么体验"。不再是寻找"对所有用户都更好"的方案，而是发现"对不同用户群体最优"的个性化体验。这要求UX研究者建立更丰富的用户画像和情境变量体系。

来源：AWS Machine Learning Blog

设计系统

Claude Code Skills设计：可复用的AI能力模块化方法

Anthropic分享的Skills设计方法论揭示了AI产品设计的系统化思路。Skills不仅是Markdown文件，而是一个包含脚本、资源文件、数据甚至钩子函数的完整文件夹。Anthropic将内部Skills归纳为九种类型：库与API参考、产品验证、代码审查、文档生成、测试辅助、部署流程、安全合规、性能优化、故障排查。

设计系统启示：这种分类方法为AI产品的能力设计提供了参考框架。每个Skill都是围绕特定用户任务场景设计的"能力包"，包含示例、边界情况和常见陷阱。对于构建AI产品的团队，建立清晰的"能力分类体系"和"设计模式库"将大幅提升产品的可维护性和可扩展性。

来源：歸藏(guizang.ai)

◐ UX雷达：值得关注的早期设计信号

触觉反馈设计复兴

BeatBox盖板设计大赛显示，实体触感与数字内容的融合正在兴起。透明盖板成为"连接数字音乐与实体触感的桥梁"，设计不再局限于屏幕内。

AI员工而非AI工具

Junior等产品将AI定位为"同事"而非"工具"，场景由工作流自动提供，使用频率由协作关系驱动。这种定位转变可能改变企业软件的设计范式。

设计工具民主化

AI图片放大转SVG工具（如SVG Converter）让非设计师也能获得专业级输出。设计能力的边界正在模糊，"专业工具平民化"趋势加速。

可穿戴设备质感升级

OPPO Watch X3的钛合金机身、蓝宝石水晶表面、金属竹节表带设计显示，智能手表正从"科技产品"向"时尚配饰"体验进化。

前端AI编程实践

大淘宝技术的AI Coding复盘显示，AI在生成样板代码、单元测试、UI组件搭建等标准化场景效率显著，但在复杂业务逻辑理解上仍需人工审查。

代码审查体验优化

Vercel v0的diff view功能展示了开发者工具体验的细节打磨——文件级变更展示、行级增删统计，让代码审查更直观高效。
