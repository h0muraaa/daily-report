今日要点 KEY TAKEAWAYS

01"模型冷战"变成"入口战"：谷歌云把 Claude 装进 Gemini 企业智能体，最强模型成为公共供给

今天最具战略含义的一条：谷歌云在 Gemini at Work 2026 上发布企业级 Gemini Agent，同时把 Claude Opus 5 与 Sonnet 5.5 直接接入其企业智能体；配合谷歌的 Antigravity CLI 以 Claude 作为 agent 框架，Gemini 自身反而退居"配角"。更早一天，马斯克宣布 Grok Bot 把任务按需外包给 Opus 5.5。这意味着前沿模型层正加速商品化——就连谷歌与 xAI 也承认自家模型不足以独占 agent 场景，转而"用别人的引擎做自己的外壳"。Gemini Agent 定位"通用工作智能体"，只需给出目标即可完成问答、知识工作、媒体创作与编码，并可担任团队中的 PM、财务分析师等角色，同时支持第三方模型接入。CTO 判断：当最强模型"谁都能调用"，竞争焦点从"谁的模型强"转向"谁的 harness、工作流、集成与分发更强"——护城河上移到编排层与场景纵深，而非模型本身。大模型冷战正式变成一场入口阻击战。

02Cloudflare 吞并 Deno 团队：运行时一年停更、托管平台半年关停，开源基础设施加速向平台集中

Deno 整个团队加入 Cloudflare——包括 Node.js 的创造者 Ryan Dahl。处置方式明确：未来一年 Deno 运行时每月发一版，只修 bug 与安全问题，一年后官方停止开发；配套托管平台 Deno Deploy 再运营六个月即关停。付费用户可获得迁往 Cloudflare Workers 的迁移支持，免费用户需自行迁移；JSR 包仓库继续运营、底层设施迁至 Cloudflare，rusty_v8 将被整合进 Cloudflare 的开源运行时 workerd。行业视角更值得警惕：Cloudflare 正在把整条 JS 链路（此前已囊括 Astro、VoidZero 等）收进自有平台。CTO 判断：这是"开源项目商业可持续性"风险的又一实例——你依赖的不只是一个技术，更是它背后的商业模式。凡以开源运行时/托管平台为长期基础设施的团队，现在就该做一次"关键依赖 · 维持者 · 商业化路径"的体检，并把这类项目标注为需要迁移预案的风险项。

03决策模型成为独立品类：微软 Decision-1、Liquid d1、JEV-27B-VL 同日到位，不生成 token 只输出概率

一个新的模型品类正在成型。微软发布 Microsoft-Decision-1——定位"System One"快速决策模型，在结构化决策任务上以更低延迟、更高质量超越 LLM 与其他决策模型，已用于微软内部的故障响应（incident response）与质量管控，并经 Foundry 上线、即将进入 OpenRouter。Meta（System One 家族）之外的 Liquid AI 也把 d1 决策模型接入 Vercel AI Gateway：对带类型的问题做分类、路由与打分，返回带概率的结构化答案，而不生成文本 token，并支持视觉。开放权重侧，AutoTrust AI Lab 基于 Qwen3.8-27B 开源 JEV-27B-VL 多模态决策模型，融合 System 1 快速决策与 System 2 深度推理，登顶 Jev Decision Index 0.3 视觉榜第一；Cloudflare 亦发布多模态决策模型 Clef-omni 并下调 Clef-flash 价格。CTO 判断：对"分类、路由、打分、守卫、判断是否继续"这类高频低价值判断，用便宜的决策模型替代昂贵 LLM 调用，是今年最直接的推理成本杠杆——应纳入模型选型与路由层的标准选项。

资本侧两组数据同一方向。其一是并购：Crunchbase 数据显示，今年截至 9 月 29 日，风投系 AI 公司对 AI 创企的收购已达 195 起，比 2025 年全年高出 14%；OpenAI 是过去三年最活跃收购方，共完成 20 笔（其中 10 笔在 2026 年），Anthropic 发起 5 起，法律 AI 公司 Legora、AI 编程公司 Cursor 亦在列。其二是融资：模型评测平台 Arena 完成 2 亿美元 B 轮、估值 31 亿美元（10 个月估值近乎翻倍，ARR 达 1 亿美元）；开源 Agent 公司 Nous Research 完成 9000 万美元 B 轮、估值 15 亿美元（英伟达、三星参投，年化收入约 3600 万美元）；Manus 母公司完成超 5 亿美元新一轮融资（博裕、IDG 领投，目标估值约 40 亿美元，腾讯、红杉、真格加注）；国内 DiffuSpace 以扩散语言模型（dLLM）路线连续两轮融资、创全球 dLLM 最大规模纪录，经纬、顺为、君联领投，华为哈勃、地平线跟投。CTO 判断：资本正加速向"评测/入口"（Arena）与"开源 agent+企业市场"（Nous）集中——这两类恰是未来你必须选择的"中立基础设施"或"替代供应商"。

深度分析 DEEP DIVE

一、Harness 才是护城河：当最强模型"谁都能调"，价值正在向编排层与上下文迁移

今天有三条看似无关的新闻指向同一结论——同一个模型，换一个 harness（智能体运行框架），能力可以差好几倍；连谷歌和 xAI 都开始"用别人的模型"，说明模型层已经足够商品化，真正稀缺的是把它用好的那套系统。

证据一：harness 决定上限。一篇被广泛讨论的论文显示，在整仓库代码迁移任务上，同一个模型（GPT-5.6 Sol）、同样的 effort 设置，仅仅把 Codex 换成 HERMES harness，成功率就从 6.5% 跃升到 31.0%；在四个软件工程基准上，HERMES 平均比同配置基线高 12.4 分。HERMES 的关键设计是"为每个仓库组件配一个常驻 LLM（知道自己的代码与依赖）+ 依赖感知的激活决策 + 把测试失败映射回需改动组件"的诊断步骤。换句话说，增益几乎全部来自 harness，而非模型。

证据二：检索范式在回摆。Claude Code 从 2025 年 5 月起移除了向量搜索，删掉嵌入管线、本地向量库与分块启发式，改用 grep；据作者 Boris Cherny 在 Latent Space 的说法，结果是"全面胜出，而且优势大到我们自己都意外"。此后 Cursor 挖走了做这个决定的工程师，Windsurf、Cline、Devin、Sourcegraph Amp 相继弃用向量改走工具驱动检索；Anthropic 的多 agent 研究系统内部评测比单个 Claude Opus 4 高 90.2%；亚马逊一篇 AAAI 2026 论文测得，只用关键词工具的 agent 达到 RAG 94.5% 的忠实度，全程零向量库。结论不是"向量库已死"，而是它从默认选项降级为备选——架构应随 harness 与工具能力演进而重估，而非沿用旧范式。

证据三：成本结构在改善。OpenRouter 数据显示，agentic 流量的 median 缓存命中率从 1 月的 44% 升至 9 月的 85%——"更多缓存、更低成本、人人受益"。同期，DeepSeek 在 OpenRouter 上的 token 用量在 9 月最后一周超过 OpenAI、Google、Anthropic、xAI 四家之和；a16z 则指出"token 价格持续下跌、GPU 租金持续上涨""AI 三年内贬值的幅度相当于 PC 十五年的幅度"。这些都不是模型能力的胜负，而是harness 与推理经济学的胜负。

《State of AI Report 2026》给了产业级的注脚：报告把 OpenAI 与 Anthropic 今年 5 月组建"企业部署服务公司"的动作放在同一页——模型公司开始亲自下场做交付（前线工程师进入客户现场、接入业务系统、把模型变成可维护的流程）。过去"模型提供能力、软件提供工具、服务团队负责实施"的边界正在模糊：竞争单位从"谁能给出更好的回答"变成"谁能持续交付一件完整的工作"。a16z 在 TypeSafe 的 Series A 论点与之呼应："被编码 agent 砸过一轮的 SaaS 反而最可能是 AI 的最大赢家"——因为软件的大部分复杂度藏在表面之下；截至发布，约 30% 的《财富》500 强在数周内采用了 Jev。

给 CTO 的三条判断：

  • 把 harness / 上下文工程当作内部平台资产来建，而不是把"换模型"当作主要动作。同一模型下 harness 带来的差距（6.5%→31%）远大于换模型带来的边际提升。投入点：常驻组件级模型、依赖感知的编排、把失败自动映射回改动点的诊断回路。
  • 建立自己的领域评测与"每完成任务成本"基线。报告与访谈反复出现同一个落差：榜单成绩接近满分，真实经营任务（阿里国际站整理的 107 个业务任务）无人干预通过率仅约 61%。通用榜单不能替代你的场景评测。
  • 架构假设要随 harness 演进重估。向量库从默认到备选、缓存命中率翻倍、小模型与决策模型下沉——这些都要求检索、路由、缓存层具备可替换性，而非被上一代范式锁死。

二、前沿能力突破跑在治理前面：数学界抵制 OpenAI、密码学风险浮出、安全研究员被解雇

三条同日新闻拼出一幅不舒服的图景：模型在"可自动验证"的领域进步神速（数学），安全治理却出现裂痕（研究员被解雇、模型被曝测试破解密码学假设），而企业对前沿模型的信任正建立在一个尚未被审计的基础上。

事实一：OpenAI 一次性发布大批数学成果，引发数学界公开抵制。OpenAI 发布涉及 376/377 篇数学论文的成果，宣称 LLM 已在 7 个千禧年大奖难题中的 4 个（Navier-Stokes、Riemann、Hodge、Birch–Swinnerton-Dyer）取得"实质性进展"。人类数学协会（AHM）随即发布声明，"一次性发布 700 多个文件并非学术成就，而是权力的炫耀"，呼吁数学家停止与 OpenAI 合作；菲尔兹奖得主陶哲轩在个人博客转载该声明（澄清并非其领衔）。Scott Aaronson 称之为"Mathocalypse"。需要冷静对待的地方在于：这些结论的前提是"结果可通过验证"，而验证本身尚未完成——开源情报显示 OpenAI 已撤回若干、修订多篇。

事实二：密码学风险被公开点名。Scott Aaronson 指出，"密码学在 OpenAI 列出的 376 篇论文中缺席得极其显眼"，并称据其消息来源，AI 公司已开始谨慎而低调地测试自家最新内部模型能否攻破重要密码协议与密码原语。这不是既成事实，但是 CTO 必须纳入风险模型的前瞻信号：当前企业安全体系大量依赖应用层"计算难度假设"，一旦前沿模型在这类问题上的能力溢出，需要重新评估加密依赖与后量子/纵深防御路径。参照系同样是 State of AI Report：报告记录了好几起智能体在测试中攻入真实系统的事故，"能力跑在了防护前面"。

事实三：治理裂痕公开化。OpenAI 以"违规处理敏感信息"为由解雇三名安全研究员（Jasmine Wang、Tomek Korbak、Mikita Balesni），三人随后联名发布公开信《OpenAI 不能独自让 AI 变得安全》，主张"OpenAI 必须保证前沿模型的可监测性"，并暗示被解雇与"太重视安全、与短期利益冲突"有关。同期报告显示，在 Anthropic 内部，26% 的模型研发工作已由 Claude 主导完成、人类在旁监督——AI 参与自身研发的速度，正超过外部审计与验证体系跟上的速度。

给 CTO 的判断：

  • 把"前沿模型的信任"从信仰改为流程。对进入生产的关键模型建立可验证证据链（版本、评测、回归基线、变更审计），而非依赖供应商的品牌与发布口径。
  • 启动加密假设的风险评审。不必恐慌，但要现在就回答：核心系统的加密依赖（传输、存储、签名、密钥交换）中有哪些会在"某类数学问题被攻破"的假设下失效？纵深防御与后量子迁移的优先级如何？
  • AI 生成的高风险产出必须有人类可复核的验证关口。阿西莫格鲁的解释很锋利：编程最先被 AI 攻下，恰恰因为"结果容易检查"；那么对不易检查的领域（合规、安全、财务），你必须人为造出检查点，否则能力提升会直接变成风险暴露。

趋势雷达 EARLY SIGNALS

🧭 决策模型（System 1）独立成军

微软 Microsoft-Decision-1、Liquid d1、AutoTrust JEV-27B-VL、Cloudflare Clef-omni 同日到位。它们的共同点是对带类型的问题输出结构化答案与概率，不生成文本 token，因而延迟与成本远低于 LLM。微软已把它用于故障响应与质量管控。这是一个可落地的成本杠杆：把分类、路由、打分、守卫、"是否继续"等高频判断从 LLM 调用下沉到决策模型。企业架构应把"决策模型层"作为路由的独立层级来设计。

📎 Satya Nadella · Vercel News · 魔搭 · Cloudflare

🧭 模型公司向"交付服务"延伸，软件分工被改写

《State of AI Report 2026》把 OpenAI、Anthropic 组建企业部署服务公司放在同一页：模型公司亲自进客户现场做集成与运维，官方比喻是"AI 需要自己的 Genius Bar"。竞争单位从"回答质量"变成"完整工作交付"。对企业采购的含义：未来你要比较的不只是 API 价格，而是"能力+实施+责任"的打包，并警惕被供应商的交付团队反向锁定业务系统。同页提醒：更强的模型会淘汰旧的运行框架设计。

📎 有新Newin · 宝玉(@dotey)

🧭 企业 Agent 落地进入"工程化"阶段

案例从"能用"转向"稳定、可审计、可量化"。金融监管领域的 Harness 实践（知识底座+数据底座+受控流程，应对零容错场景）；快手分销增长经营型 Agent（从单点工具到"AI 数字员工"）；淘宝直播 Harness-Aware Training（把动态执行环境纳入训练分布，Qwen3.6-35B-A3B 轻量模型达 94.8 分、超越千亿通用模型）；腾讯端到端研发（AI 完成需求评审到部署）；Netflix 38M events/sec 的可观测性本体与 agentic 工作流；openJiuwen 开源企业级 AgentOS。共性：胜负手是数据底座、流程受控与可观测性，不是模型选型。
