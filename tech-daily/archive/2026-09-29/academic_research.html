ACL 2026 杰出论文：PALU 用「前缀感知局部熵最大化」实现大模型精准遗忘 Maximizing Local Entropy Where It Matters: Prefix-Aware Localized LLM Unlearning

ACL 2026LLM Unlearning中科大 · 新加坡国立

中国科学技术大学与新加坡国立大学团队提出的 PALU（Prefix-Aware Localized Unlearning），获 ACL 2026 杰出论文奖。针对大语言模型遗忘学习中「删干净」与「保能力」难以兼顾的核心矛盾，该工作指出既有方法通病在于对整个回答序列、整个词表做统一干预——这种「全序列、全词表」的负向优化会误伤大量无关知识，导致模型能力退化与算力浪费。PALU 的核心创新是从生成的时间维度与词表维度同时施加局部化约束：只对真正决定敏感内容生成的少量关键前缀位置进行干预，在需要处最大化局部熵。这为遗忘学习提供了一个更具可解释性的干预粒度，是隐私合规与模型安全方向值得复现的基线。

小红书 AllSpark 提出 PACT：为长程 Agent 的信用分配给出唯一性数学刻画 Credit Assignment for Long-Horizon Agents

强化学习Credit AssignmentSWE-bench

面向长程 Agent「最终奖励明确、沿途每一步该分多少信用模糊」的强化学习难题，小红书 AllSpark 团队从信用分配的唯一刻画出发，提出三个正则条件，并证明满足这些条件的信用分配函数存在且唯一。基于该理论框架，团队进一步分析了 OPD、RLOO 与 GAE 中的训练现象，进而提出 PACT，改进 Critic 的回归与策略对齐。实验上，PACT 在 SWE-bench Verified 取得 67.4% Pass Rate，较 GRPO 提升 2.0 个百分点；在四个数学推理基准上平均准确率达 72.87%，较 GRPO 提升 8.80 个百分点。该工作的价值在于把工程调参问题上升为可证明的数学结构，对 Agent RL 训练方法论有直接参考价值。

02深度论文解读

PALU：在关键前缀上最大化局部熵，让大模型精准「失忆」

论文：Maximizing Local Entropy Where It Matters: Prefix-Aware Localized LLM Unlearning
链接：arXiv:2601.03190 | 会议：ACL 2026（杰出论文奖）
作者：Naixin Zhai, Pengyang Shao, Binbin Zheng, Yonghui Yang, Fei Shen, Long Bai 等
机构：中国科学技术大学 · 新加坡国立大学

研究背景

大语言模型在海量语料上训练，不可避免地记住了其中的隐私信息、版权内容与其他敏感知识。当数据所有者要求删除相关信息时，重新收集数据并从头训练模型通常成本高昂，因此「大语言模型遗忘学习（LLM Unlearning）」成为安全与隐私研究中的重要问题。理想方法需同时满足两个目标：一方面模型不再生成与目标数据相关的内容，另一方面原有的语言理解与生成能力尽可能保持不变。

核心创新

论文指出，现有方法多通过对完整回答做负向优化，或在整个词表上提高预测不确定性。这种「全序列、全词表」的干预虽然能削弱目标知识，却会更新大量与敏感信息无关的内容，容易造成模型能力下降和训练资源浪费。PALU（Prefix-Aware Localized Unlearning，前缀感知局部遗忘）从生成过程的时序维度和词表维度同时引入局部化约束，只对真正决定敏感内容生成的少量位置进行干预——即在「需要的地方」最大化局部熵，从而以更小的副作用实现遗忘。

学术意义

该工作把遗忘的干预粒度从「整句、全词表」收敛到「关键前缀位置」，为模型的隐私合规提供了更可控、更可解释的操作界面，也为后续研究给出了一个强基线。其「局部化」思想与当前大模型可控性、可解释性方向高度一致，值得在复现基础上进一步研究其在不同规模模型与多语言场景下的一致性。

来源：大模型智能（原载 专知） · 论文 arXiv:2601.03190

PACT：为长程 Agent 的信用分配建立唯一性理论，并改进 Critic 训练

论文：长程 Agent 如何论功行赏？——信用分配的数学刻画与 PACT
机构：小红书 AllSpark 团队
关键词：Credit Assignment · RL · SWE-bench Verified · 数学推理

研究背景

一个数学 Agent 经长篇推理得出正确答案，一个 Coding Agent 经多次检索、修改、测试才修好程序——最终成败可被验证，但沿途每一步乃至每个 Token 究竟应获多少 Credit，是强化学习中的信用分配（Credit Assignment）问题。对长程 Agent，它直接关系到模型如何从单一最终结果中学习成千上万次决策。既有方法（RLOO、GRPO、GAE 等）处理方式各异，但缺乏统一的理论刻画。

核心创新

团队提出三个正则条件，并证明满足这些条件的信用分配函数存在且唯一。这一唯一性结果为理解现有算法提供了共同坐标系：研究者据此分析了 OPD、RLOO 和 GAE 中的训练现象，指出各自在回归目标与策略对齐上的偏差来源。在此基础上提出 PACT，针对 Critic 的回归与策略对齐进行改进。

实验结果

SWE-bench Verified Pass Rate：67.4%（较 GRPO +2.0 个百分点）
四个数学推理基准平均准确率：72.87%（较 GRPO +8.80 个百分点）

学术意义

该工作把长期停留在「经验技巧」层面的 Agent RL 训练，上升到可证明的数学结构，其价值不限于单一算法改进，而在于给出了一个可被后续工作检验和推广的理论框架。数学推理任务上近 9 个百分点的提升幅度表明，信用分配的结构性修正比单纯增大 rollout 数量更有效——这对算力有限的研究组尤为重要。

来源：小红书技术 REDtech

EverMind 开源 Raven 0.2.0，定位为 "the harness of harnesses"。它站在 Claude Code、Codex 等 Coding Agent 之上：接收复杂任务后生成任务 DAG，明确依赖并并行可并行节点；为每个节点分派最合适的 Agent（内置 Research、Code、Design、Oncall 四个专业 Agent，并可通过 ACP / CLI / OpenAI 兼容 API 接入第三方 Agent，官方预设 13 个，含 Claude Code、Codex、Qwen Code、Kimi Code）；并将流程沉淀为可复用工作流。其特色是面向 RSI——整个 harness 的 prompt、策略代码、playbook 乃至编排层本身都可被 AI 重写。README 称其 Raven-Code 在 DataAgentBench 以 0.8762 Pass@1 居首。开源地址：github.com/EverMind-AI/Raven。

来源：meng shao (@shao__meng) · Ding (@dingyi)

Unsloth 本地部署开源决策模型 Laya：最低 4GB 内存，兼容 Jev API

决策模型端侧部署开源

Unsloth 让开源决策模型 Laya 可在本地部署，最低仅需 4GB 内存，支持 CPU、Mac、Windows、Linux 及 GPU，并可作为 Jev API 的无缝替换。三个版本：Multilingual（678MB / 4GB，100+ 语言，1024 token 上下文）、English（846MB / 5GB，更大 encoder，512 上下文）、Typed Decisions（846MB / 5GB，针对发票、安全事件、客服、agent 轨迹优化）。CPU 上亚秒级响应，GPU 可选且显存不足时自动回落 CPU。文档特别提示工程要点：用 probabilities 做决策阈值而非 confidence，因为 Laya 与 Jev 的 confidence 计算方式不同，直接迁移阈值会踩坑。文档：unsloth.ai/docs/models/decision。

来源：meng shao (@shao__meng) / @UnslothAI

audio.cpp：把 80+ 音频模型装进同一套纯 C++/ggml 推理引擎

推理框架ggml开源

audio.cpp 以 ggml 为底座，为现代音频模型提供纯 C++、跨平台、可复用的原生推理框架，覆盖 TTS、ASR、语音克隆、VAD、说话人分离、音源分离与音乐生成。它解决的核心痛点是：本地音频 AI 的困难不在缺模型，而在每个模型各带 Python 仓库、Conda 环境、CUDA 版本与服务脚本，最终得到十几个互不兼容的环境。README 在 v0.8.0 时宣布已覆盖 80+ 模型家族、120+ 模型变体，并提供 CLI、Server 与 Pipeline 三种使用方式及 Parity 门禁。截至 2026-09-24 最新版本 v0.8.2，约 3000 Star。适合需要统一本地音频流水线的研究者与工程团队。

评测方法开源工具Skills

04趋势观察

1「决策模型」（System 1）成为新的研究品类

TypeSafe Jev 在本窗口持续刷屏：它不聊天、不生成，只做判断、排序与选择，更快更便宜。两周内 OpenRouter 上已聚集 6 个决策模型（含 2 个免费），Unsloth 让 Laya 可 4GB 内存本地部署，上海 AI 实验室推出「书生·明决」，学界也出现 Jev-LDE（1.7B 编辑器，把选 few-shot demo 的 System-2 搜索变成一次 System-1 编辑，平均 1-shot 准确率 81.2→88.1）与 JevRAG（用 Jev 替换 embedding，在 28 个研究任务上报告 59% 更多相关上下文）。值得研究者警惕的是 Latent.Space 的提醒：「不要再造 Jevbench 了」——公开基准很容易被 game，选对任务比刷分更重要。这一路线提示：当服务对象从「人」变为「程序」，模型未必要把思考翻译成人类语言。

2从「把模型做大」转向「把环境做多」：RL 环境生成成为新工程学科

本窗口多条线索交汇：Amazon AGI 的 AutoGym 一体化生成任务、可执行环境与验证器；Google Cloud 的 GKE Agent Sandbox 让 Agentic RL 提速 45 倍；具身智能领域 Real2Sim2Real 闭环成为数据竞争的核心；小红书 PACT 从信用分配理论侧改进长程 Agent 训练；OpenAI 发布《如何保障前沿 RL 训练运行安全》。elvis 的观察颇具概括性：「创建 RL 环境」正在成为一项重要的新型 AI 工程技能，行业出现从模型规模向环境规模迁移的明显转变。

3评测与奖励信号的「可信度危机」被系统性暴露

同日两项独立证据指向同一结论。Arena 对 34,580 条裁决的分析显示 LLM 裁判存在强烈自偏好（自选率 58% vs 人类 34%，GPT-6 Astra 高达 88%）与拒绝判平（96%），AI 之间一致性 79% 对人类的 57%。Meta RL-XAR 进一步指出：直接拿主流 LLM 当裁判做 RLHF/RLAIF，训练出的只会是「更受 LLM 裁判青睐的 slop」，其奖励信号坏得系统化。这提示以 LLM-as-Judge 为基础的研究必须重新校准奖励来源，RL-XAR 的「专家对齐评分标准」与 Anthropic 的评测方法论（信度效度四标准）是两条可行的应对路径。

4AI for Math 跨过分界线：从「证明难题」到「提出议程」

北大团队以约半个月、不到 3 万美元完成庞加莱猜想的 Lean 4 完整形式化（约 320 万行代码，首个双检验版本）；AI Has Taste 累计 453 份手稿，并已找出反例推翻人类论文中的猜想、获原作者确认。两者共同标志：AI 数学研究正从「能不能做出一道难题」转向「证明路线失败后该做什么」——是继续算、换路线、缩小命题，还是提出新的可证伪猜想。换言之，研究范式从 Answer Generation 走向 Research-Agenda Generation，这可能是本窗口最具长期意义的方向。

AMD 以 82 亿美元收购 World Labs，李飞飞任执行副总裁兼首席科学家。她给的理由直接：「要把研究放大，就得离硬件更近」。World Labs 的 Atlas 把生成模型与多视角几何结合，基本解决稀疏重建问题；而 Justin Johnson 坦言「我们基本受限于算力」。同日傅盛指出，世界模型太烧钱，且 GPT-6 已开始把语言、视觉、空间理解揉进同一模型，世界模型路线本身也并非确定。对学界而言，这是双重信号：一方面跨模态空间智能是明确的开放问题，另一方面前沿研究越来越依赖工业级算力与数据，学术界的角色需重新定位（如形式化验证、评测方法、理论刻画等工业界相对薄弱的环节）。

AI 科技评论对 Sonnet 5.5 的拆解指出，模型变强背后其实是「静态依赖分析」与「执行图压缩」能力，使 Agent 成本不能只看 Token——工具等待、状态回填、重新规划、上下文增长、失败恢复共同决定开销（Lovable 测试中 Tool Call 减约三分之一、Shell Run 近乎减半，Base44 应用构建平均迭代从 7.7 次降至 3.6 次）。InfoQ 关于 Agent Sandbox 的讨论、Manus 2.0 的 Cascade harness（Token 消耗 -23.2%、完成时间 -28.2%、成本 -32%）与 Cloud Computer 架构，以及 Firecrawl Alexandria（100+ 数据提供方、1.13 亿索引源，答案质量 +21%）都在说明：模型能力之外，运行时与数据基础设施正成为决定系统上限的关键变量。
