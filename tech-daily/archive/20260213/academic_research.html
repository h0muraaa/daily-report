📚 arXiv 论文速递

PhyCritic: Multimodal Critic Models for Physical AI

arXiv:2602.11xxx cs.CV cs.RO

核心贡献：提出面向物理AI的多模态评判模型，能够评估机器人在物理世界中的行为表现。该模型整合了视觉、语言和物理约束，为具身智能提供了新的评估范式。

技术亮点：通过多模态融合，模型可以理解物理环境中的因果关系，并据此评判机器人决策的合理性。实验表明在物理推理任务上显著优于现有方法。

Step 3.5 Flash: Open Frontier-Level Intelligence with 11B Active Parameters

arXiv:2602.10xxx cs.AI cs.LG

核心贡献：证明了仅需11B活跃参数即可达到前沿水平的大语言模型性能。通过高效的模型架构设计和训练策略优化，实现了参数效率的显著提升。

技术亮点：采用稀疏激活和动态路由机制，在保持高性能的同时大幅降低推理成本。对于资源受限场景下的LLM部署具有重要参考价值。

[论文链接 - Hugging Face Papers] | [Twitter讨论]

Agent Memory Survey: A Survey on Agent Memory Systems

arXiv:2602.06052 cs.AI

核心贡献：首次从三个正交维度对Agent记忆系统进行系统性综述：载体(Substrate)、认知机制(Cognitive mechanism)、主体(Subject)。为Agent记忆研究提供了新的分类框架。

创新框架：

  • 载体维度：记忆存储在哪里（参数记忆 vs 外部存储）
  • 认知机制维度：记忆扮演的角色（情景/语义/程序记忆）
  • 主体维度：记忆为谁服务（用户中心 vs Agent中心）

[arXiv:2602.06052]

🔬 研究动态

GLM-5: 从MoE架构到Agentic Engineering的技术演进

智谱AI发布GLM-5，采用744B总参数/40B活跃参数的MoE架构，预训练数据达28.5T tokens。该模型在SWE-Bench Verified上取得80.2%的成绩，定位从"Vibe Coding"转向"Agentic Engineering"。

技术亮点：

  • 稀疏MoE架构，推理时仅激活40B参数，兼顾性能与效率
  • 长程任务执行能力优化，支持复杂系统工程
  • 完全开源（MIT License），权重可在Hugging Face获取

📎 来源：智谱AI技术博客

Claude API Context Compaction: 服务端上下文压缩机制

Anthropic推出Compaction功能，实现了服务端自动上下文压缩。开发者只需设置token阈值，系统即可自动管理长对话历史。

技术意义：该功能解决了长对话Agent的核心挑战——上下文窗口管理。与客户端压缩相比，服务端实现可以更智能地保留关键信息。

📎 来源：Claude API文档

A2A Protocol: 多Agent通信标准的技术整合

Google主导的Agent2Agent协议获得IBM支持，后者将ACP(Agent Communication Protocol)并入A2A。这标志着多Agent通信标准之争初步尘埃落定。

技术贡献：A2A定义了Agent发现、能力描述和消息交换的标准格式，类似于Web服务的REST API规范。

📎 来源：Andrew Ng课程公告

🔍 深度解读

Simile.ai: 从单一角色到群体模拟的LLM应用新方向

研究背景：传统对话AI通常被设计为具有特定、精心设计的单一角色。然而，预训练LLM的本质是对互联网文本的统计学习，天然包含了多样化人群的表达方式。
核心创新：Simile.ai探索"群体模拟"方向——利用LLM的统计能力模拟多样化的人群分布，而非单一角色。这涉及以下研究问题：
  • 如何构建此类模拟器？
  • 如何管理模拟的熵（多样性）？
  • 模拟的忠实度如何量化？
  • 群体模拟会产生什么涌现特性？
技术方法：该方法可视为对LLM潜在空间的结构化采样，通过控制采样参数生成具有特定人口统计学特征或行为模式的模拟个体。
学术价值：该研究方向填补了"个体级对话AI"和"群体级社会模拟"之间的空白，可能应用于市场研究、政策模拟、社会动力学研究等领域。
开放问题：模拟结果的泛化性、伦理边界、以及如何验证模拟结果与现实世界的一致性仍是待解决的研究挑战。

📎 来源：Andrej Karpathy推文

MiniMax M2.5: 面向Agent任务的系统优化

研究背景：长程Agent任务对模型的工具调用、多步推理、错误恢复能力提出了更高要求。现有模型通常针对单轮对话优化，在复杂Agent场景中表现受限。
核心贡献：M2.5针对Agent任务进行了系统级优化：
评测基准 成绩 含义
SWE-Bench Verified 80.2% 真实软件工程任务解决率
BrowseComp 76.3% 浏览器操作与信息检索
BFCL 76.8% 函数调用与工具使用
效率创新：$1/小时的API定价（100 tps）使得大规模长程Agent部署在经济上可行。这对研究社区的实验可重复性有重要意义。

📎 来源：MiniMax官方公告

📈 研究趋势观察

从模型能力到系统能力：Agent研究的范式转移

近期发布的GLM-5、MiniMax M2.5等模型均强调"Agentic Engineering"能力，显示出研究重点从单纯的模型性能（如MMLU、HumanEval）向系统级能力（长程任务执行、工具使用、错误恢复）的转移。

方法论趋势：

  • 评测基准演进：从静态问答转向动态环境交互（如SWE-Bench、BrowseComp）
  • 架构创新：MoE架构成为大模型主流，兼顾性能与效率
  • 开源生态：头部玩家 increasingly 采用开源策略推动技术普及

Agent记忆：从工程实现到理论框架

Agent Memory Survey（arXiv:2602.06052）的发表标志着Agent记忆研究从碎片化工程实践向系统化理论框架的转变。该综述提出的三维分类法可能成为该领域的标准术语体系。

值得关注的子方向：

  • 记忆压缩与摘要（如Claude Compaction）
  • 长期记忆的外部存储架构
  • 用户记忆与Agent记忆的协同机制
