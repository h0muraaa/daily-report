形式化数学

Claude 证明 VP ≠ VNP：70 页论文 + 7.3 万行 Lean 4 通过机器检查

Anthropic 官方 GitHub 仓库悄然放出一篇 70 页论文《VP ≠ VNP Over Every Field》，核心结论是在特征不为 2 的任意域上，Valiant 提出的代数复杂度类 VP 严格小于 VNP。这相当于攻克了被称为"代数版 P≠NP"的 Valiant 猜想——自 1979 年提出以来已悬置 47 年。论文称核心证明由 Anthropic 内部研究版 Claude 发现并撰写，团队随后与 Claude 一同完善表述，并配套提供约 7.3 万行 Lean 4 形式化代码且通过机器检查。

研究者需注意的关键限定：论文作者一栏仅列 Claude，且截至目前尚无人类数学家独立审阅该证明。形式化通过 ≠ 数学界已接受，机器检查保证了推导在 Lean 逻辑系统内无错，但"定理陈述是否恰当""是否真的回答了数学界所问的问题"仍需同行评议。

形式化数学 · 学术诚信

"25 万页是玩笑"：黎曼猜想证明主导者 Levent Alpöge 公开澄清

围绕 Claude 参与黎曼猜想形式化证明的讨论持续数日后，Anthropic 数学家 Levent Alpöge 在 X 上发长文回应争议。他澄清此前流传的"证明翻译成人类可读文字将超过 25 万页"其实是自己开的玩笑，本意是调侃数字之大，未料被广泛当成事实传播。他明确表示并未否定证明的有效性，承认的错误集中在成果发布时的不当表述以及形式化代码中存在的大量冗余——真正的挑战是那 1737 万行代码。他引用陶哲轩"不要在论文里开玩笑"的建议，坦言终于理解了其中缘由。

这条动态对学术传播极具警示价值：当 AIGC 产出的证明体量超出人类审阅能力时，如何建立可信的发布与复核规范，正在成为形式化数学领域的新议题。

模型架构

智谱 GLM-5.4：首个公开细节的大尺寸 Loop Transformer 旗舰

智谱发布 GLM-5.4，换上全新的 Loop Transformer 架构：不堆参数，而是让同一组网络层循环执行多轮，靠"多算几遍"加深推理。官方披露的技术基本盘包括：沿用约 750B 参数基座（不重训更大模型）、对其中 28 层进行两轮循环计算、通过门控机制解决循环训练稳定性、后训练强化"泛 Coding"（3D 建模、Code-to-Video、游戏开发），并通过 KV Cache 共享与稀疏注意力索引复用控制额外显存与推理成本。官方称效果达到 2T–3T 级模型水平，权重完成安全加固后将开源。这是目前第一个公开技术细节的大尺寸 Loop 模型。

Loop/循环 Transformer 的思想早在 2018 年即被提出，但因从头训练效果不及传统 Transformer 长期停留于论文阶段；GLM-5.4 的"在预训练基座上继续训练"路线，提供了一个值得复现的工程样本。

评测基准

RDQA：让 Agent 自己去"找原始文件"作答，12 个通用 Agent 最高仅 24%

得州大学阿灵顿分校、华东师范大学、佐治亚理工学院在 EMNLP 2026 主会 Oral 提出 RDQA（Raw Data Question Answering，原始数据问答）基准。与传统文档/视频理解基准"直接把源文件交给模型"、或 RAG 基准"默认文档已建索引"不同，RDQA 既不预置检索索引，也不预先提供源文件：每题都要求 Agent 自行找到原始文件、调用解析工具、定位到某一页/某一格/某一秒，再按源文件作答；若答案已以纯文本出现在公开网页上，该题会被改写或删掉。RDQA 共 1,350 道题，分属文档、视频、音频三种模态。结果显示，经参数泄漏率调整后，12 个通用 Agent 的最高准确率仅 24.0%。

02深度论文解读

论文深读 · 计算复杂性

《VP ≠ VNP Over Every Field》：47 年 Valiant 猜想的机器检查证明

核心结论：在特征不为 2 的任意域上，VP ⊊ VNP。
问题定位：Valiant（1979）提出的代数复杂度类分离猜想，与 P vs NP 同构，俗称"代数版 P≠NP"。
证明形式：70 页论文 + 约 73,000 行 Lean 4 形式化代码（通过机器检查）。
主要作者：Anthropic 内部研究版 Claude（论文作者栏仅署名 Claude），研究员协助完善表述。
审阅状态：尚无人类数学家独立核验；经典 P vs NP 仍未解决。

研究背景。在代数复杂性中，行列式（Determinant）与积和式（Permanent）是一对"长相几乎一模一样"的对象：两者公式完全一致，区别仅在于积和式把行列式中的负号全部改成了加号。直觉上"少一个负号应当更简单"，但恰恰相反——正因为没有了正负相消带来的代数捷径，积和式的计算复杂度急剧膨胀。1979 年，图灵奖得主 Leslie Valiant 据此定义了 VP（可由多项式规模算术电路高效计算的多项式族）与 VNP（允许对指数数量 0/1 输入求和、表达更强多项式族的类），并猜想二者之间存在严格差距。

核心创新。该工作的关键贡献不在于提出新算法，而在于给出并形式化了 VP 与 VNP 严格分离的下界证明。据报道，此前公认的"m² log m"型下界长期无法突破，而 Claude 独立发现了核心思路、撰写成 70 页论文，并进一步用 Lean 4 写下约 7.3 万行代码完成形式化验证，使证明的每一步都能被机器逐行核对。

实验/验证方式。对纯数学证明而言，"实验"即形式化验证：Lean 4 的依赖类型检查器充当了独立于证明作者的裁判——只要代码编译通过，推导在底层逻辑系统内即无漏洞。这为"AI 产出的证明可信度"提供了一种不同于同行评议的技术路径。但需清醒认识：形式化只能保证"从公理到结论的推导合法"，无法保证"定理陈述忠实于数学界的原始问题"或"证明的数学思想是否优雅、可推广"。

学术意义与实践提示。①这是 AI 在顶级理论问题上"发现 + 撰写 + 形式化"全链条闭环的一次展示，与三天前的黎曼猜想形式化成果形成连续信号；②配套代码托管于 Anthropic 的 formal-math 仓库，为后续研究者提供了可直接复用的 Lean 工程基底；③但"无人类审阅"是当前最大的不确定性，研究者在下游引用时应明确这一状态，避免将"机器检查通过"等同于"数学界已公认"。

📎 来源：机器之心 · 新智元 · 爱范儿（黎曼猜想澄清）
论文深读 · 具身智能

JEPA4R：把点云世界模型引入 JEPA，纯仿真训练直接部署真机

论文：arXiv:2611.19771　代码：github.com/AIGeeksGroup/JEPA4R　模型：huggingface.co/AIGeeksGroup/JEPA4R
机构：北京大学 · UC Berkeley BAIR · 布朗大学 · 芬兰奥卢大学
任务：基于单台深度相机的三维操作（抓取、推动、灵巧操作）。

研究背景。JEPA（联合嵌入预测架构）世界模型通过预测未来的潜空间表征来学习环境动态，无需在训练时还原未来画面的每个像素，因而在样本效率上具有优势。但对于真实世界的抓取、放置等操作，"物体在哪里""夹爪距目标多远"是控制所必需的具体几何信息。现有具身 JEPA 世界模型大多从 2D 图像输入，难以直接获得这些三维信息——这正是 JEPA4R 的出发点。

核心创新。团队将单台深度相机获取的三维点云引入 JEPA 世界模型，在表征潜空间中学习"动作引起的关键场景因素变化"，再由读取这些表征的策略头完成机器人控制。这一设计使模型在潜空间里"想象"的未来场景可以被直接观察：研究者能把预测的未来表征解码回连续三维点云，验证模型究竟"想"到了什么，提升了世界模型的可解释性。

实验结果。在多项三维操作任务中，JEPA4R 的策略成功率高于图像 JEPA 方法。在 OGBench Cube 仿真测试中，预测可持续到 200 个环境步，平均点误差保持在 1.1 厘米以内。更具工程意义的是：世界模型与动作策略头仅在仿真环境中训练，随后直接部署到真实机械臂，未做真机数据微调，演示了"仿真训练 → 真机零样本"的迁移路径（视频展示平行夹爪抓取胡萝卜、推动积木，灵巧手从固定槽位取出瓶子与香蕉）。

学术意义。该工作为"以几何为中心的具身世界模型"提供了一个清晰的范式：把控制所需的 3D 信息显式纳入 JEPA 潜空间，既保留了像素级重建之外的表征效率，又缓解了 2D 输入在空间推理上的短板；"解码回点云"的可视化手段也为后续世界模型的诊断提供了工具。可复现性较高（论文、代码、权重三件套齐备），适合作为具身智能方向研究者的复现基线。
