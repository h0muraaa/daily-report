1设计经验第一次被"蒸馏"成可调用的资产，而不只是一次性的稿子

淘天 TaoDesign 的探索给出了一个明确方向：把企业内部的设计经验蒸馏成视觉规范、复用结构、静态资源与业务知识四类"可调用资产"，再以"确定性补丁优先、Agent 兜底"的方式编辑源码，并通过 MCP 交付研发、支撑设计验收。它的起点很朴素——同类页面被反复制作、专业判断在不同项目里反复重来，设计师大量时间耗在重复劳动上。TaoDesign 选择把最终控制权留给设计师，让他们聚焦"核心体验决策"，并探索"One Person Team"的协作方式。

为什么重要：这标志着 AI 设计工具的重心，正从"一次性生成"转向"经验的可复用化"。对用户研究员而言，这意味着设计决策背后的用户依据也需要被资产化——否则被复用的只是"长得像"，而不是"为什么这样设计"。

用户行为

2Personal Agent 的 PMF 仍未定论，"主动性"与"个性化"是最难的设计题

海外独角兽一场闭门会整理了 48 条一线笔记，横跨模型公司、大厂、创业公司与数商。一个鲜明信号是 Personal Agent 正在集体落地——上线仅两个多月的 Muse 移动端 DAU 突破 1000 万，Instinct 传出以 300 亿美元估值融资。但行业对几个核心问题尚无共识：PMF 究竟在哪些场景、工作 Agent 与生活 Agent 会融合还是分立、以及如何做好"主动性"与"个性化"。另一边，Lenny 播客里 Muse 的产品负责人透露，他们产品最受欢迎的用例，是团队里没人预料到的那个。

为什么重要："最有价值的用例在意料之外"是用户研究最经典的提醒——真实用户会重新定义你的产品。当设计者还在会议室里推演"该多主动"，最好的答案往往来自对真实使用行为的持续观察，而非想象。

交互范式

3空间计算走出演示厅：手势选择、窗口"留在原地"成了可日常使用的交互

Google 与 XREAL 联手打造的 Android XR 空间计算眼镜 AURA，把《少数派报告》里的操作变成了可上手的功能：戴上 95g 的眼镜本体（外加 265g 分体计算盒），你可以用手选中、拖动、捏合缩放眼前的窗口；浏览器、视频、应用可以同时悬浮在身边，转头再回头，摆好的窗口仍停在原处。爱范儿的体验指出，它和 Vision Pro 的实现路径不同——不是把人放进 VR，而是让窗口真正"留在"你的空间里。

为什么重要：这是一种全新的交互语法：从"点按二维屏幕"转向"在三维空间里摆放与抓取"。随之而来的研究课题也很新——用户如何在空间里建立心理模型、手势的可发现性与误触、长时间佩戴的舒适边界，都还没有成熟的设计规范。

视觉趋势

4"AI 味"正在变成一种审美共识：我们可能正在经历一场审美降级

爱范儿观察到，日本近畿大学把 AI 生成的动态影像直接放上官网首页，选举海报也开始出现 AI 捏造的候选人面孔——连"以美育著称"的日本都在大规模拥抱 AI 生成视觉。作者提出的问题很尖锐：当"够用就好"的生成内容大规模替代人工设计，公众的审美基准会不会被悄悄拉低？视频里出现的文字错误、物理上不合理的细节，也在提示这种"降本"背后的质量代价。

为什么重要：启示是双向的——"AI smell"已经成为用户能感知的体验缺陷（可被识别、可被讨论），而"审美"本身正在成为一个可被测量、被研究的用户感知维度。设计团队需要为 AI 产出建立质量门槛，而不是默认"生成即完成"。

研究方法

5评估 Agent 不能只靠"静态题库"，要用带人格与目标的动态仿真

InfoQ 播客中，周瑜谈到用动态仿真评估 AI Agent 的方法：对于对话式 Agent，其下一步动作取决于上一句回应，加上 LLM 本身的非确定性，静态、基于参考答案的基准并不可靠。更贴近真实的做法，是让 Agent 面对不同的人格、目标与边角场景去跑，观察它在动态交互中是否依然完成任务。

为什么重要：这几乎是把用户研究的"情境化测试"搬进了 AI 评测——真实用户不是一个固定 prompt，而是带着目标、情绪和意外行为的"人格"。把"人格化仿真"引入评测，意味着 UX 可以更系统地回答：这个 Agent 面对"急躁的用户""目标中途改变的用户"时，还靠不靠谱。

设计趋势洞察

深度分析 × 2
趋势一

从"生成工具"到"可复用的设计大脑"：设计经验正在被资产化

TaoDesignContent Studio设计资产MCP 交付

淘天 TaoDesign 的路径值得细读。团队最初以 MasterGo 插件形式生稿，但发现"跨表示层转换"存在损耗，于是转向以浏览器为画板的自建工作台，依托客户端、服务端与云端沙箱三层架构，采用"确定性补丁优先、Agent 兜底"的源码编辑与异步快照回滚。它真正的创新不在生成，而在把设计经验拆成可调用的四类资产：视觉规范、复用结构、静态资源与业务知识，并通过离线评测与在线反馈持续修订。图结构与关联批注则用来承载"多状态与交互上下文"，最终经 MCP 交付研发、支撑设计验收。

几乎同一时间，LangChain 开源了它在 Slack 里运行的"设计 Agent" Content Studio——已产出 3000 多个素材，包括多次重要发布的视觉。它的关键选择同样指向"可复用"：每张图都是一个 HTML 页面、每段视频都是一条动画时间线，因此产物始终可编辑、始终 on-brand；团队把品牌手册喂给它、存进记忆，再让它在三种尺寸上生成发布卡片，甚至把 30 秒发布短片从分镜一路做到最终渲染。

设计洞察：两条路径共同指向一个判断——AI 设计工具的护城河，不在"能不能生成"，而在经验能否被沉淀为可复用、可编辑、可审计的资产。"可编辑"尤其关键：它把控制权还给设计师，避免"生成一次、无法修改"的黑箱。对用户研究员而言，下一步要思考的是：如何把"用户依据"也写进这份资产——让复用的不只是视觉规范，还有"为什么这个交互对这群用户有效"的判断。

趋势二

从"工具"到"认知共生体"：Personal Agent 的主动性悖论

Personal Agent认知共生体主动性信任节奏

牛津大学高级研究员费豪在 arXiv 发表的观点论文，把 Personal Agent 的下一种形态命名为"认知共生体"：它跟随一个具体的人，借助佩戴设备感知世界，长期保存语境，在合适时刻参与思考、必要时替人行动。论文区分了四种人机关系——reactive assistant（被问才答）、autonomous agent（领到目标自己跑完）、personal agent（云端驻留、长期服务一个用户），以及 cognitive symbiont（跟着人走进日常）。关键差异在于 KPI：前三种落在 AI 身上（任务完成率、答案正确率），第四种则必须贴着"人"来衡量。

与之呼应，海外独角兽闭门会的 48 条笔记显示，Personal Agent 的一线实践正卡在几个"没有共识"的问题上：PMF 场景、工作与生活 Agent 是否融合，以及最难的两点——如何做好"主动性"与"个性化"。而 Muse 产品负责人那句"最受欢迎的用例是团队没人预料到的"，恰好从侧面说明：主动性的边界，不能只靠产品团队想象。

设计洞察："认知共生体"的价值，是把评价重心从"AI 做得对不对"转到"人用得放不放心"。这给用户研究提出三个新命题：用户愿意在哪些时刻被"主动打扰"？个性化的边界在哪里（什么时候贴心、什么时候冒犯）？以及信任的节奏——用户如何一步步把判断权交出去，又如何在需要时收回控制。主动性不是越多越好，而是要在"有用"与"越界"之间持续校准。

产品体验点评

案例分析 × 2
案例一

XREAL AURA：当窗口"留在原地"，空间交互需要新的心智模型

XREAL AURA 把消费级 AR 从"随身大屏"推进了一步：过去这类眼镜的核心任务是把手机或电脑画面投到眼前，而 AURA 想让窗口真正"留在"你身边的空间里，并用最自然的方式——手势——去交互。体验中，用户可以用手选中、拖动、捏合调整窗口大小，浏览器、视频与各种应用可同时悬浮，转头再回头，摆好的窗口仍在原位。它运行完整的 Android XR 系统，美国市场限时优惠价 1099 美元起。

与 Vision Pro 相比，两者实现空间计算的方式很不一样——Vision Pro 更接近一台 VR 设备，而 AURA 走的是"把数字内容叠加进真实空间"的路线。这种差异也带来不同的体验课题：窗口"驻留"带来了空间记忆的负担——用户需要记住"我把那个窗口放哪了"；手势则要求系统提供足够的可发现性，否则"看不见的手"会让新手无从下手。

体验点评：空间计算的体验设计，本质上是把二维的"布局"问题升级为三维的"空间记忆 + 手势语法"问题。"窗口留在原地"既是卖点，也是认知成本——好的空间界面需要帮用户建立心理地图，并用微妙的反馈（高亮、吸附、回溯）降低"找东西"的负担。这正是需要用户研究介入、建立新设计规范的地方。

案例二

醒图鸿蒙版：把"AI 对话修图"做成日常语言，而不是参数面板

鸿蒙版醒图的新版本，最值得 UX 团队注意的是它把修图从"调参数"推向"说人话"。更新后，用户可以用"AI 对话修图"直接说出想要的效果——比如"肤色自然一点，背景的暖灯留着""颜色淡一点，留一点胶片感"，醒图会据此调整人像与画面。它还提供"一键变美/一键出片"的智能修图，自动照顾头发、皮肤等细节，以及"相机直闪""温暖测光""富士闪光"等可切换的光影风格；风格模式甚至能在取景时预览滤镜，按下快门前就知道成片大概什么样。

同样有意思的是它的"沟通姿态"：更新日志里一句"不烧心"的俏皮文案，让不少用户跑到评论区打卡，有人说"为了你的更新日志我也要给你点五颗星"。这看似小事，却让一次版本更新变成了一次有温度的对话。

体验点评：这是"自然语言交互"落到消费级工具的一个好样本——把专业参数翻译成用户自己的表达（"暖灯留着""一点胶片感"），降低了修图的心智门槛；"取景即预览"则把"结果不确定性"提前消解。而那句"不烧心"提醒我们：文案与语气也是体验的一部分，它决定了产品在用户心里是"工具"还是"伙伴"。

研究方法论

工具与方法 × 2
方法一

动态仿真 + 人格化：让 Agent 在"有性格的用户"面前接受考验

周瑜在 InfoQ 播客中提出的评估思路，核心是"用仿真替代静态题库"。他指出，对话式 Agent 的动作依赖前序回应，而 LLM 本身是非确定性的，因此"静态、基于参考答案的基准"无法反映真实表现。更可靠的做法，是用动态仿真去跑：为 Agent 构造不同的人格、目标与边角场景，在交互过程中观察它是否仍然完成任务、在哪里出问题。

这背后是一个用户研究式的洞察——真实用户从来不是一个固定的 prompt，而是带着目标、情绪、临时改变主意和意外行为的"人格"。把这种复杂性显式建模进评测，才可能发现"在理想输入下通过、在真实用户面前崩掉"的问题。

为什么有用：可以直接迁移到产品研究——设计一组"人格化测试脚本"（急躁型、犹豫型、中途改需求型、给出模糊指令型），把同一 Agent 放进这些情境里，观察它在被打断、被追问、被要求改方向时的表现。这把"Agent 好不好合作"从主观感受，变成可观察、可复现的研究设计。

方法二

重复暴露 + 纠正反馈：人类识别深度伪造的可训练性

一篇 arXiv 研究（cs.MM）用 110 名参与者做了实验，考察人对音视频深度伪造的识别能力能否通过"重复暴露 + 纠正反馈"提升。参与者在第一阶段评估来自 FakeAVCeleb 与 DFDC 数据集的各 40 段视频，第二阶段在重复观看并给予纠正反馈的条件下重新评估同一批视频。结果显示，FakeAVCeleb 数据集的平均准确率从 63.30% 提升到 67.98%（+4.68 个百分点，p<.001，效应量 d_z=0.54）。

值得注意的是，这种提升是有限但真实的——它说明人类的判断并非固定不变，短时的训练与反馈能改善识别，但远未达到可靠。这为"人机协作识别"提供了实证基础：既然人会漏判，AI 辅助或"人机双签"就有其价值。

为什么有用：这是一个标准的"前测—干预—后测"实验设计，并用统计显著性支撑结论，值得做用户研究的人借鉴其严谨性。它也提示我们：把"人的判断"当成一个可测量、可训练、也会失准的变量，而不是想当然的"最终裁决者"。在 AI 生成内容泛滥的当下，这类"人类感知可靠性"研究会越来越重要。
