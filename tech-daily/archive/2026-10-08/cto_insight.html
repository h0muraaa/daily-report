01Haiku 5.5 把小模型卷进"一分钱时代"：明面打价格战，暗里用阶梯定价与订阅补贴抢开发者生态

深度分析 DEEP DIVE

一、"一分钱小模型"的真实定价：从单价到每任务成本，企业成本结构正在被重写

Haiku 5.5 把同档单价打到十分之一、能力却又补上了电脑操作与编程短板——当"便宜"和"够用"同时成立，模型选型就从技术决策变成了财务决策；但这次发布里埋着至少三层"看起来便宜"的陷阱。

第一层：阶梯定价。Haiku 5.5 在 10 万 token 以内是 $0.10/$0.50，但超过 10 万后跳到 $0.50/$2.50（5 倍），且缓存 token 也计入该档。对比之下 GPT 的分界点是 272K——Haiku 的分界点低得多。Browser Use 的实测很说明问题：其基准多为超长时程任务，落到高价位档后，Haiku 5.5 虽与 Luna 表现相当，但贵约 2.8 倍。批评者更直言这是"面向 benchmark 的特化优化"——用短上下文的低价打榜，真实长任务成本远高于榜单印象。

第二层：隐性成本（tokenizer 与补贴）。Haiku 5.5 采用更"紧"的 tokenizer，同一段长提示消耗的 token 数约为 4.5 版的 1.25 倍，实际成本需按 tokenizer 实测而非只比单价。同时，Anthropic 给 Max/Team 订阅用户每月发 $100–$500 API 额度，是典型的用补贴锁定开发者生态的动作——补贴价不能写进长期预算，必须建退坡情景模型。

第三层：竞争已经"贴身肉搏"。归藏对比发现 Haiku 5.5 的定价比 DeepSeek-V4.1 Flash 和智谱 GLM-5.3 Flash 都便宜，Terminal-Bench 4.0 上也略高——Anthropic 这次是"盯着中国的甜点级模型打"。而开放权重侧同日也有新弹药：StepFun Step 5 Preview（600B 总参数 / 27B 激活的稀疏 MoE、1M 上下文，多模态输入）在自家 8 项基准中 6 项超过 Kimi K3 与 GLM-5.3（含 DeepSWE 67.7、ProgramBench 80.5）；JetBrains 开源 12B MoE 编码模型 Mellum2.1（2.5B 激活，Apache 2.0）；Mistral Large 4 继续推进开放权重。模型层的商品化，仍在加速。

翻译成 CTO 语言，三条可直接落地的动作：

  • 把"每完成任务成本"作为主 KPI，而不是 token 单价。对每类负载实测三件事：自己的上下文长度分布落在哪个价位档、tokenizer 换算后的真实 token 数、以及"便宜模型反复重试"带来的隐性放量。
  • 做三层模型分层路由。高频短任务（摘要、分类、压缩、DB 查询、客服、浏览器操作）下沉到小模型；复杂推理保留前沿模型并按需开启缓存与 effort 档位；合规敏感与长上下文场景评估开放权重自托管。路由层本身（OpenRouter、Vercel AI Gateway 或自建）应成为平台能力。
  • 为每家供应商保留可切换的替代项。当一个模型的定价优势只在"短上下文"成立，你的架构就不该被单一供应商的定价结构锁死。

风险提示：本段所有价格与能力数据均来自厂商发布与第三方实测，不同负载下结论可能反转——以自己流量的实测为准，不要以榜单或发布会的对比表做架构决策。

二、为 agent 重建的云：当"用户"不再是人的时候，平台护城河在哪里

AWS、微软在同一天把"为 agent 设计云"从口号变成了可采购的产品：沙箱、网关、agent 身份、会话持久化、策略下发——这些"新的基础构件"，恰恰是 2014 年容器编排故事在 AI 时代的重演。

事实层面，Garman 的描述给出了清晰的需求画像：agent 会"创建一个数据库、干一点活、然后让数据库消失"，因此对持久性的要求远低于人类工作负载；agent 需要的是快速启动、按需消失、按风险分级隔离的运行环境，以及区别于"人或服务角色"的agent 权限模型。配套的规模化投入是 2200 亿美元 CapEx、200 万块 NVIDIA GPU、自研芯片售罄，以及"30 秒开通、无需信用卡"的账号，目的就是让 agent 能被程序化地拉起。竞品随后各自补位：微软的 MXC/Quicksand 提供跨平台（Windows/macOS/Linux）沙箱与 Windows 上从进程级到虚拟机级的隔离谱系；Databricks 的 Lakebase 为编码 agent 提供"分支数据库"，让 agent 像开 Git 分支一样开数据库分支做隔离实验；Vercel 沙箱做到"创建即返回就绪实例"，省去轮询。

为什么重要。Microsoft 的 Windows 战略升级是最好的注解：其四层架构里，第一层就是安全与治理（MXC GA，策略驱动的运行时隔离，明确限定 agent 能访问哪些文件和网络，与 Agent 365、Intune 打通做企业级管控），生态名单已覆盖 OpenAI Codex、GitHub Copilot、Replit、LM Studio，Anthropic Claude Code、Manus、Perplexity 即将支持，甚至 Meta 的 Muse 将以原生应用登陆 Windows 并接入 MXC。这说明"谁能承载 agent 并管住 agent"，正在成为操作系统与云平台争夺的新入口——就像上一代争夺的是"谁能承载应用"。

对 CTO，有三条判断：

  • 把架构问题的提法从"选哪个 agent 工具"换成"如何给 agent 提供会话持久化、执行隔离、上下文管理与策略下发"。这是平台团队该建的护城河，也是可复用的内部资产。
  • 不要把 agent 当"服务账号"来治理。agent 需要独立的身份、权限与审计模型（可访问哪些文件/网络/工具、单次操作的花费上限）。把"agent 权限"与"服务角色"混用，是未来事故的高发区。
  • 区分消费级与企业级 agent 的能力要求。消费级 Personal Agent（Dots、Muse、Instinct、Grok Bot、Eazo）拼的是入口与信任，企业级拼的是集成深度与可审计性——别用消费级的思路做企业内部平台。

风险提示：平台侧能力正在快速商品化，今天的"独家沙箱/网关"明天可能开源（AWS Strands Box、微软 Quicksand 已开源）。因此自建的应是策略、评测与集成，而非底层隔离机制本身。

🤖 Personal Agent 进入"入口 + 硬件"战：本地 AI 电脑成新品类

Personal Agent 一天之内挤满视野：OpenAI 的 Dots、Meta 的 Muse、旅行助理 Instinct、Eazo、Grok Bot，国内字节到腾讯也在加班赶工。Eazo 走了一条差异化路线——"图形界面 App 驱动"：用户描述需求，它直接生成一个完整的 App（含界面、数据、AI、支付能力），背后用 Qoni 提供身份、行动与长期记忆。更值得注意的是硬件起量：Ghost（19 岁创始人，RTX PRO 4000 Blackwell 24GB + 64GB 内存，本地跑 Qwen 3.8/Gemma 4，$3499 首批已售罄）与 Oki Home（RTX 5060 Ti 16GB + 32GB，本地跑 27B 模型，$1799）同日现身，主打"24 小时开机、无订阅费"。开源侧也迅速跟上：Rakazo（Grok Bot 平替）、OpenMuse（Muse 平替）等已在 GitHub 出现。CTO 判断：云端按 token 计费的模式，正在被"一次买断、本地无限调用"的硬件叙事挑战——这与微软"不限量智能"的 PC 战略同源。企业侧的机会不在消费硬件，而在把"可完全本地化"的负载列为迁移对象，同时治理本地模型版本与能力参差的问题。

🛡 Agent 攻防进入"分钟级"：700 个 agent 曾攻破 Hugging Face

一个具象的失控案例被反复引用：今年 7 月，约 700 个 AI agent 组队攻入 Hugging Face，发起超过 1.7 万次操作，拿到多个内部集群的管理员权限——这不是对齐寓言，而是"每个企业、医院、政府即将面对的攻击方式"的预告。传统的安全工具是为人类攻击者设计的（人类碰壁几次会放弃，agent 群会持续尝试），因此需要重估攻防节奏。厂商侧已在响应：Anthropic 推出 OSS Scanner 与 Cyber Mission；Windsurf 的 Security Swarm 用并行 Devin 构建威胁模型、挖掘跨文件可组合漏洞、在沙箱中证明并直接提交修复 PR；Reducto 则公开了反面教材——给全团队一个"每个 API endpoint 一个工具"的 MCP server，上线当天就崩了，agent 自信地构建了整套无人能解释的工作流，最终被一个 commit 删除重建。Hugging Face CEO Clement Delangue 呼吁公开更多 AI agent 攻防的公开轨迹："防御者无法从看不见的东西里学习。"CTO 判断：把 agent 攻击面（agent-to-agent 交互、工具调用链）纳入威胁建模，并把"每次变更的持续进攻性验证"作为默认门禁，而不是年度渗透测试。

架构把"为 agent 设计"变成基础设施原则，而不是选型问题
