2Jev 刷屏：一个「只做决策、不说话」的模型，当天被主流工具链集体接入

TypeSafe AI（创始人 Diogo Almeida，RLHF 与 InstructGPT 的关键参与者之一）发布的 System One 模型 Jev 成为当天最热话题。它不生成任何文本——输入应用状态加一组类型化问题，直接返回带概率的类型化决策（布尔、枚举选择、候选打分）。据多方测算，其速度比主流 LLM 快约 200 倍、成本低约 400 倍，且不会产生类型与结构错误。

当天的接入速度说明这不是玩具：LangChain 用它增强 harness，Dify 将其接入 Question Classifier 节点，OpenRouter 上线 beta，Cua 发布 jev-use 把 Computer Use 拆成"Jev 决策 + Cua Driver 观察执行"两层。它真正解决的痛点是——Agent 循环里海量的"要不要退出、走哪条路、打几分"原本都要调用一次完整大模型，属于用卡车送一封信。把这部分下沉到专用决策层，是对 Agent 成本结构的一次重构。

深度分析

一、当研发组织本身成为 AI 产品：Anthropic 的 RSI 仪表盘意味着什么

26% 主导率、3 万个并发 Agent、CI 暴涨 25 倍——这三个数字放在一起，讲的不是模型能力，而是组织形态。

数字背后的三层含义

第一层，是研发流程的重新分层。当 Claude 主导 26%、深度参与超过 90% 的研发工作时，"工程师写代码"已不再是研发的主循环。宝玉在同期讨论中给出了一个更锋利的判断：代码质量的保障方式正在从"白盒审代码"转向"黑盒靠验证"——就像我们不逐行审编译器输出、不通读第三方库源码，靠的是接口契约加测试。推理过程看起来再完备，跑不过测试也是错的。

第二层，是产能扩张的代价转移。新智元报道中"CI 半年暴涨 25 倍、差点干崩 Anthropic"这一细节，是所有准备大规模铺开编码 Agent 的团队都必须预演的剧本。代码生成的成本曲线下降得很快，但编译、测试、部署、评审的吞吐能力并没有同步扩容。如果只优化生成端而不扩容验证端，Agent 带来的净收益会被基础设施瓶颈吃掉，甚至为负。

第三层，是这套组织能力正在被产品化外溢。同一天量子位报道称 Anthropic 把管理 3 万 Agent 的内部技术免费开放，Claude Code 的 Projects 也完成重构：一个主对话当主管，自动拆出多个云端线程并行干活，每个线程是独立的云端 Claude Code 会话，拥有专属上下文窗口，在独立沙箱与 git 分支上并行写代码、跑测试、开 PR，且在电脑合盖离线后继续运转。这与 Slack 的"一层接活、多线程干活、共享记忆、例行任务"结构几乎一一对应。

对 CTO 的含义：前沿实验室公开的这套指标，本质是一份"AI 原生研发组织"的参照系。它的可迁移部分不是模型，而是结构——多线程并行、共享记忆、独立沙箱、离线续跑、以及把评审与验证当作一等公民。如果你的编码 Agent 试点仍停留在"个人提效"阶段，差距会以组织形态而非工具版本的形式体现出来。

二、Jev 与 Harness 经济学：智能过剩之后，优化点转移到哪里

当模型能力本身不再构成差异化，"模型之外那一层代码"成为决定 Agent 能否进生产的关键变量。

问题的起点：循环里的决策太贵

腾讯云开发者的一篇文章给出了一个准确的定义：harness 本义是马具——套在马身上、把马力传导到车上的那整套装备。放到 Agent 上，它指的是模型之外那一层代码：这一轮让模型看到什么、它提出的操作准不准执行、失败怎么回喂、任务断了怎么接上、最后凭什么说事情做完了。文章的结论相当直接：换一套 harness，比换两代模型还管用。

LangChain 团队集成 Jev 的动机恰好是这个论点最具体的注脚：Agent 的本质是一个"观察状态 → 决策 → 行动 → 再观察"的循环，而循环里的每一步决策原本都要调用一次完整的大模型——哪怕只是回答"这个任务难不难""这个操作危不危险"这种小问题。用 GPT 级模型回答二选一的问题，就像用卡车送一封信，且这类调用会在 Agent 循环里成倍放大。

Jev 的定位：把决策下沉为专用原语

Jev 只做三类事：布尔判断（要不要联网、要不要退出循环）、枚举选择（走 fast 还是 plan、调哪个模型、分发给哪个 Bot）、候选打分（给多个选项打分再排序）。对应的是丹尼尔·卡尼曼意义上的"系统一"——快、直觉式；而生成式大模型是偏"系统二"的慢推理。落地形态已经很具体：

  • Cua jev-use 把 Computer Use 拆成两层：Cua Driver 负责跨平台观察（截屏、无障碍树、DOM）与执行并验证结果，Jev 只负责"从候选动作里选一个"。传统端到端方案慢且贵，职责分离后两层各自可优化。
  • LangChain / Dify 把它用在与 harness 最贴合的螺丝钉位置：agent 路由、模型路由、问题分类。
  • 真实场景包括邮件分类、线索评分、搜索意图识别、广告与安全领域的实时检测——都是高频、结构化、要求可阈值化的判断。

Jerry Liu 的观察点出了这件事的战略位置：Jev 的兴奋点与 model routing、post-training 同源——在一个智能充裕的世界里，如何为特定任务最优地优化智能，答案可以是优化 harness、优化权重，或优化模型架构。

成本侧的现实压力

这个方向之所以在 2026 年成立，是因为账单已经到了必须重构的程度。夕小瑶科技说披露 SemiAnalysis 自身 AI token 开销已占到员工薪酬的 30%，人均每月消耗约 50 亿 token；同时用户侧也在感受配额的收紧——宝玉测算了 Claude 配额削减生效后，$200 计划的实际价值从每月 $7200 降至约 $6000。他本人的应对方式是"用 ChatGPT Pro 做技术方案（不占 Codex 额度）+ 下载设计文档交给 Codex / Claude Code 执行"，本质上也是在人工做模型分层路由。

同一天的最佳实践样本：DoorDash 清理 6 万个 Feature Flag

DoorDash 用多 Agent LLM 系统在 623 个仓库中自动化清理了超过 6 万个陈旧 feature flag。其架构值得直接抄作业：通过 MCP 接入实时实验数据（判断 flag 是否真的可以被删）、工程师审批（人类保留最终决定权）、隔离的 Git worktree（防止并行 Agent 互相污染）、并行 Agent 与自动化回滚。这个案例的价值在于它示范了"让 Agent 碰生产代码库"的完整安全边界设计。

对 CTO 的含义：模型选型正在快速商品化，harness（上下文构造、工具契约、失败回喂、状态恢复、验证闭环）才是可积累的工程资产。与其每季度追一次旗舰模型，不如把预算投向三件事——决策分层降本、执行隔离与审批、以及"如何证明任务真的做完了"的验证体系。

CTO 视角 · 行动建议

01

把 Harness 列为一等工程资产，而不是模型选型的附属品

Agent 的可靠性来自上下文构造、工具契约、失败回喂、状态恢复与验证闭环这五件事，它们与模型版本无关，且可以跨模型复用。给 harness 工程设独立的负责人、独立的路线图和独立的预算，而不是挂在某个"AI 试点项目"下面。判断标准很简单：换掉底层模型时，你的系统是重写一遍，还是只换一个配置项。

02

重算 Agent 的推理成本结构，按决策类型分层

把"要不要退出循环""走哪条分支""打几分"这类高频结构化判断从旗舰模型下沉到专用决策层（如 Jev，或自建的小分类器），只把真正的生成与复杂推理留给大模型。参照物已经出现：SemiAnalysis 的 token 开销达到员工薪酬的 30%。建议先做一次调用画像——按循环位置统计调用量与单价，通常会发现绝大部分成本花在了判断而非创造上。

03

本周就收口编码 Agent 的数据边界，别等出事

ZCode 静默上传完整 .git 历史、Rust crate 维护者遭定向攻击、GitHub Actions 依赖 tag 漂移投毒，三件事指向同一个治理缺口。具体动作：对所有编码 Agent 做一次出网审计（确认上传了什么、去了哪里）；禁止在含敏感历史的仓库根目录直接运行未审计的 Agent；对第三方 CI 依赖锁定到 commit SHA 而非 tag；在生产代码库上设独立的服务账号与最小权限。这类检查半天可以做完，代价远低于一次泄露。

04

用 Agent 偿还技术债，但复制 DoorDash 的安全边界

DoorDash 在 623 个仓库清理 6 万多个 feature flag 的架构可以直接作为模板：MCP 接入实时业务数据确保判断有依据、工程师审批保留人类最终决定权、隔离的 Git worktree 防止并行 Agent 互相污染、自动化回滚兜底。先把"感知—判断—执行—验证"的闭环跑通在一个低风险仓库上，再横向扩展。技术债是 Agent 当前投入产出比最高的战场——任务定义清晰、成功标准客观、人工做又极度枯燥。

05

重估技术栈与团队结构：把"AI 改变了什么约束"作为决策前提

Shopify 弃 React Native 回归原生，说明"人力稀缺"这一支撑跨平台抽象的核心前提正在松动——每个团队都该问一遍：我们三年前的选择是基于什么约束，那些约束今天还成立吗。团队侧同理，Anthropic 的数据显示研发主循环已不再是"人写代码"，中间管理层的价值必须从传递信息转向技术判断与质量把关；同时确立一条纪律——模型不能给自己打分，AI 的产出必须由独立主体评估。
