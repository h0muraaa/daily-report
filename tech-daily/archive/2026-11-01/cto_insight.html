算力战略

AWS 承诺容量基本售罄至 2027 年，2028 年已被部分锁定

亚马逊 CEO Andy Jassy 表示，AWS 的大宗承诺云容量到 2027 年基本售罄，2028 年的一部分也已完成分配；公司仍在为按需实例、EC2 与 Bedrock 预留余量。但一线从业者反馈，普通 EC2 的按需容量已难以获得，其他云厂商也出现类似约束。这意味着"随时可扩"的默认假设正在失效，容量本身成为需要提前谈判和锁定的战略资源。

对 CTO 的含义：未来 12 个月的上云、迁移和 AI 推理扩容计划，必须从"弹性优先"切换到"合同优先"，并把供应商集中度纳入风险模型。

资本与竞争

Anthropic 公开递交纳斯达克 IPO，上半年净亏损 807 亿美元

据创业邦 AI 周报汇总，Anthropic 已公开递交纳斯达克 IPO 申请，其上半年净亏损达 807 亿美元。同一周还有宇树回应净利润下滑、马斯克警告 200 多家新云企业可能倒闭或被整合等消息。前沿模型公司从私募叙事走向公开市场定价，意味着毛利率、算力采购和客户留存将被逐季审视。

对 CTO 的含义：模型供应商的财务可持续性开始影响采购决策。选择长期模型伙伴时，应把其融资结构、算力合同和上市时间表纳入供应商风险评估。

Agent 架构

DeepSeek 开源 Super-agent 架构，Agent 从"单会话"走向"跨会话常驻"

DeepSeek Harness 团队发布《Super-agent 设计探索》，提出双层架构、事件驱动、异步多信道交互、存算分离与外部 Watchdog，让 Agent 摆脱单次手动会话的绑定，能够跨会话保持上下文并并行推进多个任务。团队同时开源了研究原型 dsh-superagent-prototype，目前以单个 GitHub 仓库为工作对象，可通过 GitHub 评论或飞书消息接任务。其内部实例已在参与问题复现、代码审查响应与 Harness 自身迭代。

对 CTO 的含义：Agent 的竞争焦点正从"模型多强"转向"运行时多稳"。内部平台团队应尽快定义常驻 Agent 的上下文、权限、并发与可观测性标准，而不是继续堆聊天入口。

成本治理

OpenAI 12 月起合并 ChatGPT 与 Codex 额度，统一按 Token 计量

OpenAI 帮助中心文档确认，自 12 月起，Plus、Pro、Business 三档付费计划的用量额度将在 ChatGPT 与 Codex 之间共享，且统一按 Token 而非消息条数计量，仅 Instant 聊天不受影响。官方理由是正在把 ChatGPT Work 的智能体能力并入主体验。对同时用它聊天和写代码的重度团队，这等于把两项支出合并进一个可见、也更容易触顶的池子。

对 CTO 的含义：AI 工具的成本模型正在从"订阅席位"转向"用量计费"。企业需要尽快建立 Token 预算、按团队/项目的分账与超额告警，否则 AI 支出会以不可预测的方式膨胀。

安全风险

币安约 63 亿美元被盗，源头是一名 DevOps 工程师的笔记本失守

币安披露约 63 亿美元加密资产被盗的重大安全事件，攻击者通过入侵一名 DevOps 工程师的笔记本电脑获得访问能力，进入服务容器后提交未经授权的提现交易，整个过程约 20 分钟；目前无证据表明钱包私钥泄露。这是"终端即边界"风险的极端案例：一个有权限的工程终端，足以在极短时间内绕过大量外围防御。

对 CTO 的含义：在 Agent 与自动化大规模接入生产系统前，先补齐身份、终端、短期凭证与提现类高危操作的双人复核，否则攻击面会随自动化程度同步放大。

深度分析

DEEP DIVE
Deep Dive 01 · 基础设施

算力正在从"资源"变成"资产负债表"

今天最值得技术高管重视的，不是某家模型又刷新了榜单，而是算力供需关系正在发生结构性变化。AWS 承诺容量基本售罄至 2027 年、2028 年部分已分配，按需 EC2 出现获取困难，这标志着"云=无限弹性"的时代正在收尾。与之呼应的是，Alphabet、Meta、微软、亚马逊、甲骨文五大巨头已承诺未来数年投入超过 3 万亿美元用于数据中心等领域；腾讯科技则用"一张 GPU 背后的多层交易"点出了 GPU 的金融化——算力不再只是采购项，而是被嵌套进融资、租赁与资本市场叙事里。

三个正在改变决策前提的信号

  • 供应商风险重新上升。AWS 之外的其他云厂商也出现容量约束；马斯克警告 200 多家新云企业可能倒闭或被整合。把关键负载押在缺乏长期算力合同的 NeoCloud 上，风险比过去更高。
  • 国家资本开始给模型公司"压舱"。加拿大政府通过 CDIC（加拿大发展投资公司）向 Cohere 出资最高 16 亿加元，条件是总部留在加拿大、2030 年前新增 1000 个以上技术岗位、同期在加拿大数据中心投入 17 亿加元。Cohere 本轮目标最高 70 亿加元、估值 357 亿加元，德国 Schwarz Group 领投约 6 亿美元。这是主权资本从芯片层延伸到模型层的明确信号。
  • 资本成为物理 AI 的入场券。Figure CEO Brett Adcock 直言，人形机器人后两个阶段（智能规模化、制造规模化）可以靠钱加速，但没有足够资本"连参与竞争的机会都没有"；Figure 已部署 10 万颗 GPU 量级的基础设施，并把数据而非硬件视为真正瓶颈。

把这三点放在一起看，结论并不复杂：算力正在同时被"合同化"和"金融化"。合同化意味着你要更早锁定容量、接受更长的承诺周期；金融化意味着价格会受资本市场情绪、政府产业政策和供应链融资结构影响，而不再只由供需曲线决定。对 CTO 来说，基础设施决策的技术权重在下降，财务与地缘政治权重在上升。

判断：未来 12–24 个月，"多云"将从成本优化手段变成供应安全手段。真正的护城河不是买到最便宜的 GPU，而是拥有可迁移的 workload、可验证的 unit economics，以及至少一条不依赖单一供应商的推理路径。

Deep Dive 02 · 组织与 Agent

Agent 正在成为"组织的一等公民"，而人类退到验收位

DeepSeek 的 Super-agent 架构值得单独看，不是因为它"更聪明"，而是因为它重新定义了 Agent 的运行形态：跨会话保持上下文、同时推进多个互不干扰的任务、用事件驱动和异步多信道替代"人盯着一个聊天框"。这与 Mintlify CTO Hahnbee Lee 披露的数据形成互文——其文档站的 Agent 流量今年从约 10% 涨到约 80%，页面大小与准确性已经比设计更重要；Coinbase 则把整个业务 API 化，x402 支付标准已产生约 1 亿笔链上 Agent 交易，并明确"给 Agent 钱，它才更自主"。

产品、组织、流程同时被改写

  • 产品侧：Compound AI 为 Agent 从零重建了无头 Office 引擎，消耗 1.5 万亿 Token、超过 800 万行代码，支持并行工作、自检格式，并用 Agent 集群处理数据室。这说明"为 Agent 重做一遍软件"正在成为真实的工程预算项。
  • 组织侧：亚马逊 CTO Werner Vogels 明确表示，初级工程师招聘数量与过去一样，没有紧缩；理由是新人的价值在于协作、理解复杂系统、判断哪些 AI 生成代码需要仔细检查。Bending Spoons 则给出另一种样本：Evernote 收购时约 350 人，三年后专属运营团队缩到约 20 人，营收不降反增；公司以约 184 亿美元估值完成 IPO、以约 13 亿美元收购 Airtable、并买下 Miro，伯克希尔追加 3.3 亿美元投资。
  • 流程侧：WorkOS 的 Nick Nisi 用模拟果蝇大脑做代码审查实验，准确率约 88%，核心论点却是"人类审查者已成为瓶颈"。CSDN 蒋涛引用 METR 数据：AI 有 50% 把握独立完成的软件任务时长，从 2019 年的 4 秒、2024 年的 1 小时、2025 年 11 月的 5 小时，增长到 2026 年春天的 17 小时——"AI 还接不下一个岗位，但已经接得下一个工作日的活"。

这三条线指向同一个组织命题：当执行可以由常驻 Agent 承担，人类的价值重心会向"定义问题、设定验收标准、审查风险"迁移。Replit CEO Amjad Masad 的说法更直接：当工程、支持和运营都走向自主，人的角色是知道客户要什么、判断该做什么。这不是"裁员叙事"，而是"岗位内容重写"——尤其对中层技术管理者，过去靠信息汇总和进度跟进来体现的价值会被迅速压缩。

判断：2026 年真正的组织实验，不是"用 AI 提效多少"，而是"能否把 Agent 纳入正式的组织边界"——给它身份、权限、预算、审计和 KPI。做不到这一点的团队，Agent 永远停留在个人玩具阶段。

CTO 视角

ACTION ITEMS
1

把容量与 AI 成本纳入同一张"财务-技术"看板

基于 AWS 承诺容量售罄至 2027 年的信号，重新评估未来 12–24 个月的云合同、预留实例与推理扩容计划；同时因为 OpenAI 开始按 Token 合并计量，把模型调用成本按团队、按场景分账，建立月度 unit economics（每千次请求/每活跃用户的 AI 成本）。

本周动作：拉齐财务与平台团队，输出一页容量与 Token 支出基线
2

为常驻 Agent 定义内部标准，而不是继续做聊天入口

参考 DeepSeek Super-agent 的双层架构、事件驱动与异步多信道设计，明确内部 Agent 平台的几项硬标准：跨会话上下文存储、身份与最小权限、并发隔离、外部 Watchdog、全链路审计。同步决定 API / MCP / CLI 的选型边界，避免每个团队重复造轮子。

本季度动作：发布 Agent 平台架构规范 v1 与两个试点场景
3

把安全预算前移到身份与终端

币安事件说明，一个有权限的工程师终端可以在 20 分钟内造成 63 亿美元损失。优先做三件事：高危操作（提现、删除、生产变更）的双人复核与审批留痕；短期凭证与设备绑定；对 DevOps/平台团队终端做强制加固与异常行为检测。Agent 接入生产系统前，先让它跑在同一套身份与审批体系里。

本月动作：完成高危操作清单与终端加固检查
4

重估人才结构：继续招初级，但重新定义"基本功"

亚马逊 CTO 的做法值得借鉴——初级工程师不减招，但培养重点转向协作、理解复杂系统、判断 AI 生成代码的质量。把 code review 从"流程环节"升级为核心训练科目；同时用高人才密度小团队（参考 Bending Spoons 的运营模型）跑新业务试点，而不是默认按人头扩张。

下个招聘周期：更新初级工程师岗位描述与导师制
5

把供应商集中度与主权风险写进技术战略

算力合同化、GPU 金融化、国家资本入股模型公司，三者叠加意味着"模型/云供应商"已是地缘政治变量。对关键系统至少保留一条可迁移路径；对出海业务，提前评估数据驻留、模型可用性与当地监管；对长期模型伙伴，把其融资与上市节奏纳入年度风险评估。

本季度动作：完成核心供应商风险矩阵与迁移预案
