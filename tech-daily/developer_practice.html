# 深度技术解读

MCP 协议的未来：从集成协议到 AI 基础设施

MCP（Model Context Protocol）发布仅一年就成为最成功的AI集成协议。未来的发展方向包括：渐进式工具发现（解决工具数量爆炸问题）、程序化工具调用（Code Mode）、以及MCP Apps（将MCP作为应用分发机制）。

[来源: AI Engineer / Anthropic]

跨层检索：神经网络架构的新突破

传统深层网络存在"层沉默"问题——深层特征难以有效传递到浅层。新提出的跨层检索机制让每一层可以主动查询其他层的信息，而非被动接收残差。这类似于Transformer中的交叉注意力，但应用于层间通信，有望在视觉和语言模型中同时提升性能。

[来源: Berryxia.AI / 学术论文]

# 工具推荐

10 个开源项目帮你在 Claude Code 里省下 60-90% Token

RTK（Rust Token Killer）CLI代理工具在终端输出塞进上下文前过滤一遍，砍掉60-90% token；Context Mode将原始工具输出存入SQLite沙盒而非直接丢进上下文，减少98%；code-review-graph用Tree-sitter本地建知识图谱，大型单体仓库可减少49倍token；Token Savior MCP服务通过符号而非整个文件导航代码，节省97%。

[来源: Berryxia.AI(@berryxia)]

Firecrawl 重磅开源 web-agent 框架

Firecrawl开源了100%开源的web-agent框架，任意模型都能轻松构建搜索、抓取、交互网页的AI Agent。支持自动爬取、结构化数据提取、JavaScript渲染页面处理，是构建研究型Agent的理想基础组件。

[来源: Berryxia.AI(@berryxia)]

manifest：为个人 AI Agent 提供智能模型路由

manifest是一个开源的智能模型路由层，自动将简单请求路由到便宜模型，复杂请求路由到高级模型，节省高达70%成本。请求先经过23维度评分算法（2ms内完成），自动分配到Simple→Reasoning四档之一。支持300+模型，兼容API key和已有订阅，可Docker一键自托管。
