Claude Code工程化实战：从入门到精通

Cloudflare工程师分享的Claude Code工作流值得每个开发者参考：

1. Research阶段：深入阅读指定代码目录/模块，输出详细的research.md报告

2. Planning阶段：基于research生成详细的plan.md文件

3. Annotation Cycle：在plan.md中直接写评论，让CC更新直到满意

4. 生成Todo List：根据plan生成可执行的任务清单

5. Implement：完整执行实现

6. Feedback & Iterate：用简单指令反馈迭代

MCP架构最佳实践：代码在MCP里 vs MCP在代码里

Armin Ronacher（Sentry创始人、Flask作者）通过实验证明："代码在MCP里"比"MCP在代码里"更有效。

核心观点：AI Agent的最佳实践是提供少数强大、可编程的工具，而不是堆叠几十个特定函数。

Google Workspace MCP设计：只暴露一个execute工具，Agent传入JS/TS代码即可调用完整API。Pi的CodeMode则反向设计效果较差。

实践意义：MCP Server内置代码执行非常有效，让Agent像程序员一样思考和编写代码，MCP只负责提供安全、已认证的运行时环境。

# Google Workspace MCP 工作流 1. 首次运行 → OAuth登录 2. 复用本地token 3. Agent生成JS代码查询日历 4. 返回结构化JSON

文件系统即数据库：AI Agent个人OS架构

@koylanai分享了一种极简的AI Agent持久记忆架构，核心思想：用文件系统本身充当数据库，无需传统数据库的复杂性。

关键设计：

• 文件原生记忆：Markdown知识库 + JSON结构化数据，文件夹层级即本体论组织

• 追加式JSONL日志：事件溯源设计，仅追加不修改，支持流式处理

• 游标即数据库：用文件指针标记已读位置，"cursor本身就是数据库"

• 渐进式披露：按token预算动态加载相关文件

个人OS架构示例： ~/agent-os/ ├── knowledge/ # Markdown知识库 ├── contacts.json # 联系人网络 ├── projects/ # 项目资料 ├── logs/ │ └── events.jsonl # 追加式事件日志 └── profile.json # 个人档案
