Agent Harness 解析：智能体架构深度拆解
AI寒武纪 · 阅读原文 · 架构Agent

这篇文章深入拆解了 Agent Harness 的概念——即包裹 LLM 的完整软件基础设施。核心观点是：模型能力越来越强，但 Harness 不会消失。LangChain 的一个案例证明了这一点：只改了包裹 LLM 的基础设施，模型权重完全没动，在 TerminalBench 2.0 上的排名就从 30 名开外直接跳到第 5。

Local-First AI Inference：面向文档处理的云架构模式
InfoQ · 阅读原文 · 架构模式成本优化

从单节点到 Serverless：流媒体应用后端的架构演进
InfoQ · 阅读原文 · 架构演进AWS

德国流媒体巨头 Joyn 的架构师 Daniele Frasca 分享了从脆弱的单节点架构演进为弹性 Serverless 架构的完整历程。演讲中涵盖了 Hub and Spoke 模式在数据一致性方面的应用、基于 Cell 的隔离策略以缩小故障爆炸半径、以及多区域 active-active 设置的成本优化策略。

特别值得学习的是 Cell-based 架构的实践：将整个系统划分为独立的单元（Cell），每个 Cell 可以独立运行，故障被限制在单个 Cell 内。这种设计在大规模流媒体场景中尤为重要——当用户基数达到千万级时，任何全局故障都可能是灾难性的。文章还分享了如何在多区域部署中控制成本，这对预算敏感但要求高可用的团队有直接参考价值。

逛逛GitHub · 阅读原文 · 开源工具OSINT

Maigret 是一个在 GitHub 上获得 2.4 万 Star 的开源情报（OSINT）工具。输入一个用户名，它会在 3000 多个网站上搜索该用户名是否注册了账号，并汇总所有找到的公开信息生成完整报告。不需要任何 API Key，安装即可使用。

核心特性包括：递归搜索（发现一个关联 ID 后自动继续追踪）、按标签筛选站点（国家/类型）、2026 年 4 月新增的 AI 分析模式（接入 LLM 智能分析搜索结果），以及丰富的报告输出格式（HTML、PDF、XMind、JSON、CSV 和交互式 D3 图谱）。已被 Social Links、Crimewall 等专业调查机构集成到商业化产品中。

JetBrains 2026 方向：AI 与经典工作流在 IDE 中如何共存
The JetBrains Blog · 阅读原文 · IDEAI

JetBrains 阐述了 2026 年的核心产品方向：不强迫开发者选择 AI 或传统编码方式，而是让两者在同一个 IDE 中无阻碍地共存。如果你选择手写代码，IDE 聚焦于纯粹的编码体验，AI 不会干扰核心流程；如果你选择 AI 辅助，IDE 则提供完整的 Agent 协作能力。

CodeGuardian：AI 代码质量分析的 MCP 服务器实践
InfoQ · 阅读原文 · 安全MCP

CodeGuardian 是一个 MCP（Model Context Protocol）服务器，通过十一种专门的工具扩展 AI 助手，用于自动化代码分析和漏洞检测。核心洞察是：现有 AI 编码助手（如 GitHub Copilot）主要基于句法理解运行，未能与 SonarQube、Checkmarx 等专业安全扫描工具深度集成。
