EdgeClaw 2.0 引入多级长期记忆架构系统解析

EdgeClaw 2.0 通过 ClawXMemory 集成了类似 Claude Code 的多级记忆能力。该架构将记忆分为四个层级：L0的原始对话、L1的话题结构化摘要、L2的主题任务长期聚合，以及按周期的时序记忆。这种分级机制兼顾了精细粒度的知识留存与高效的上下文加载，非常值得构建复杂 Agent 时参考借鉴。
