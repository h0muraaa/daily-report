AI_DEV

C++26 标准草案定稿：反射、内存安全、契约与全新异步模型
LANGUAGE
前 ISO C++ 标准委员会主席 Herb Sutter 宣布 C++26 标准草案已完成。新版本引入四大核心特性：编译期反射（Reflection），允许代码在编译期检查和操作自身结构；内存安全增强，在不重写现有代码的前提下提供更严格的安全保证；契约（Contracts）支持前置条件、后置条件和全新的断言语句；以及统一的并发与并行框架，简化异步编程模型。这是 C++ 语言近年来最重大的标准更新之一，标志着 C++ 在现代化演进路上迈出关键一步。
来源: InfoQ
Meta 推出 Just-in-Time 测试：AI 辅助开发场景下 Bug 检出率提升约 4 倍
TESTING
Meta 发布 Just-in-Time（JiT）测试系统，将传统静态测试套件替换为在代码审查阶段动态生成测试的新范式。该系统结合 LLM、变异测试和意图感知工作流（如 Dodgy Diff），在 AI 辅助开发场景中将 Bug 检出率提升了约 4 倍。JiT 测试的核心思想是"变更感知"——不再运行全量回归测试，而是针对当前代码变更的语义和意图，智能生成高价值的针对性测试用例。这代表了软件测试在 Agentic 开发环境下的重要演进方向。

字节跳动 DisCoGC 架构：EB 级分布式存储的 GC 范式革新
INFRA
字节跳动基础设施团队与清华大学合作的论文被 FAST'26（存储领域顶级会议）收录，提出 DisCoGC 算法，一种融合 Discard 和 Compaction 的垃圾回收新范式。在字节跳动自研的分布式 Append-Only 存储系统 ByteStore 中，该系统管理着 EB 级数据和数十万台存储服务器。传统日志结构存储的 GC 面临写放大与空间放大的经典权衡难题，DisCoGC 的创新在于在不移动数据的情况下直接执行 Discard，通过智能识别无效数据块避免不必要的 Compaction，从而大幅降低 GC 过程中的 I/O 开销。这一方案对大规模分布式存储系统的工程师具有重要参考价值。
来源: 字节跳动技术团队

从 Node.js 到 Bun：一次 5 倍吞吐量跃迁的全程实录

Trigger.dev 团队分享了将核心服务 Firestarter 从 Node.js 迁移到 Bun 的完整性能优化历程。Firestarter 是一个热启动连接代理，维持数千个来自空闲运行控制器的长轮询 HTTP 连接。迁移前该服务在 Node.js 上 31% 的时间消耗在一条 SQLite 查询中，每个请求还要经过 Zod 解析和 Object.fromEntries() 转换。

团队通过四轮渐进式优化将吞吐量从 2,099 req/s 提升到 10,700 req/s：1）移除过度设计的 SQLite 查询；2）迁移到 Bun 原生 HTTP 栈；3）精简热路径开销；4）编译为单一二进制文件。文章还记录了迁移过程中踩到的坑——一个 Bun 独有的内存泄漏问题：未 resolve 的 Promise 会悄无声息地吞噬内存。该问题已在文章发布后由 Bun 团队修复。

这个案例的价值在于它展示了"性能优化不是一次大爆炸式的重写，而是一系列有数据支撑的小步改进"。对于正在考虑从 Node.js 迁移到 Bun 的团队，文中详尽的 benchmark 数据和问题排查过程具有很高的参考价值。

来源: 前端早读课 / 原文: Trigger.dev Engineering
Life of a Token：像调试代码一样看懂大模型如何生成 Token

受 Chrome 团队经典文章《Life of a Pixel》启发，本文以 GPT-2 Small 为 trace 对象，完整追踪一个 token 从输入到输出的全链路旅程。文章用 "The capital of France is" 这个 Hello World 级别的输入，展示了模型如何通过矩阵乘法与非线性变换，逐层将 " Paris" 的概率提升至 74.67%。

选择 GPT-2 Small 而非 GPT-4 的原因是"透明"——它的架构与现代 LLM（GPT-4、LLaMA）完全同构，但参数量少到可以在笔记本上秒级复现、逐层打印中间状态。作者将其视为理解 LLM 管线的"最小可运行示例"：理解了 12 层，扩展到 32 层只是数字放大。

对于希望深入理解 Transformer 内部机制的开发者，这篇文章提供了一个极佳的学习路径：从 tokenization 开始，经过 embedding、多头注意力、前馈网络，直到最后的 softmax 输出，每一步都配有可复现的代码和可视化解释。

来源: AI前线
