cs.AI

🔬 研究动态

GLM-5: 744B参数开源模型的Agentic工程突破
智谱AI发布GLM-5，参数规模从355B跃升至744B（40B激活），预训练数据扩展至28.5T tokens。关键技术创新包括：集成DeepSeek稀疏注意力机制、构建"slime"异步强化学习基础设施实现高频细粒度迭代优化。在Vending Bench 2长期规划基准测试中，GLM-5账户余额达4,432美元，开源模型中排名第一，逼近Claude Opus 4.5。模型明确面向复杂系统工程与长周期Agent任务，标志着从"对话AI"向"工作AI"的范式转变。
Code Arena #1 Text Arena #1 (开源) [技术博客] · [模型权重] · [来源: 51CTO技术栈]
MiniMax M2.5: 面向长程Agent任务的开源前沿模型
MiniMax发布M2.5，在SWE-Bench Verified达到80.2%，BrowseComp搜索任务76.3%，BFCL工具调用76.8%。模型针对高效执行优化，复杂任务处理速度提升37%，以100 tokens/second的速度实现每小时1美元的推理成本，使长程Agent的无限扩展在经济上变得可行。这一成本效率突破对于Agent系统的实际部署具有重要意义。

Andrej Karpathy开源micrograd极简实现（200行代码）
Karpathy进一步优化了其著名的micrograd自动微分引擎，代码量从243行精简至200行（缩减18%）。核心改进：通过让各操作仅返回局部梯度，由backward()方法统一处理梯度链式乘法，使每个操作仅需表达前向计算和反向梯度。代码结构清晰分为三列：Dataset/Tokenizer/Autograd、GPT模型、Training/Inference。这一教学级实现展示了深度学习框架的最小核心原理。
200 lines [代码实现] · [来源: @karpathy]
A2A协议课程发布：多智能体系统标准化通信
吴恩达联合Google Cloud与IBM Research发布A2A(Agent2Agent)协议短课程。A2A作为开放协议，标准化不同框架构建的Agent之间的发现与通信机制。自IBM的ACP(Agent Communication Protocol)与A2A合并后，A2A已成为行业标准。课程演示了如何构建医疗多智能体系统，实现Google ADK与LangGraph等不同框架Agent的协作。这一标准化努力对解决当前Agent生态的碎片化问题具有重要价值。
[课程发布] · [来源: @AndrewYNg]
Simile AI: 探索LLM作为群体模拟引擎
Karpathy投资的Simile AI探索LLM的一个被低估维度：不再模拟单一精心设计的个性，而是利用预训练模型在互联网多样化人群文本上学习的统计能力，模拟群体行为。研究问题包括：如何构建此类模拟器？如何管理其熵？模拟的保真度如何？循环中模拟体的涌现特性可能是什么？这一方向对于社会科学建模、多智能体系统研究具有潜在价值。
[投资公告] · [来源: @karpathy]

📖 深度解读

GLM-5的技术创新：从"Vibe Coding"到"Agentic Engineering"

研究背景

当前大语言模型的研究正经历从"对话能力"向"任务执行能力"的范式转移。传统评估聚焦于对话质量与知识问答，而实际应用场景要求模型能够进行长期规划、工具调用和复杂系统构建。GLM-5的定位转变反映了这一研究趋势。

核心贡献

(1) 规模与效率的平衡：744B总参数/40B激活的配置与DeepSeek V3(671B/37B)、Kimi K2(1T/32B)处于同一量级，但采用BF16精度保持计算稳定性；(2) 异步RL基础设施："slime"系统解决了超大模型上强化学习效率低下的问题，实现高频细粒度的后训练优化；(3) 长期规划验证：在Vending Bench 2的年度经营模拟中展现稳定的资源调度与策略执行能力。

学术价值

GLM-5的开源发布（MIT License）为学术界提供了研究超大规模MoE模型与Agent系统的宝贵资源。其技术报告详细披露了训练范式转变的经验，对理解"预训练-后训练"协同优化具有参考价值。在Code Arena和Text Arena的独立评估为模型能力提供了第三方验证。

开放问题

(1) 1.5TB的部署门槛对学术研究的可及性限制；(2) 长程Agent任务的安全性与可控性机制；(3) 异步RL框架的泛化性验证；(4) 与Claude Opus 4.5等闭源模型的能力差距分析。

具身智能导航：从几何路径规划到空间智能的范式跃迁

研究脉络

具身导航正经历从传统"几何路径规划"（关注A到B的避障）向"空间智能"（融合三维视觉、神经渲染与端到端决策）的范式转变。浙江大学彭思达博士与MiMo-Embodied作者郝孝帅博士的讨论揭示了这一领域的关键争议：导航的核心瓶颈在于空间推理/意图理解（"大脑"）还是物理执行/安全反馈（"肢体"）。

技术融合趋势

三维视觉技术（NeRF/3DGS）为机器人提供了更精细的环境表征能力；端到端智驾经验正迁移至通用机器人导航；神经渲染技术实现了从二维感知到三维理解的跨越。这些技术融合推动导航系统从"知道去哪里"向"理解环境语义"演进。

开放挑战

(1) 空间推理与执行控制的协同机制设计；(2) 开放环境中的泛化性与鲁棒性；(3) 仿真到现实的迁移 gap；(4) 安全约束下的实时决策。这些问题需要计算机视觉、机器人学与强化学习领域的深度交叉。

📊 研究趋势观察

  • 从"对话"到"工作"：GLM-5、MiniMax M2.5等模型的定位转变反映了大模型研究从聊天能力向复杂任务执行能力的重心转移，"Agentic Engineering"成为新的技术标杆。
  • 开源模型的能力追赶：GLM-5在多项基准上逼近Claude Opus 4.5，开源与闭源模型的能力差距正在缩小，这为学术界提供了更强的研究工具。
  • 成本效率成为关键指标：MiniMax M2.5以$1/小时的成本实现长程Agent能力，推理成本优化正成为模型部署研究的重要方向。
  • 多智能体通信标准化：A2A协议的推进标志着多智能体系统从研究原型向标准化基础设施演进，这对Agent生态的互操作性具有重要意义。
  • 具身智能的技术融合：三维视觉、神经渲染与端到端决策的交叉融合正在重塑机器人导航与操作的研究范式。
  • Agent记忆的理论框架：三维框架（载体/认知机制/主体）的提出为Agent架构设计提供了更系统化的理论基础。
