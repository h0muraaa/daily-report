§1研究动态

后训练缩放GLM-5.3：同基座、纯后训练，Terminal-Bench 从 4.6 跃升至 28.3，并涌现网络安全能力

智谱于 8 月 14 日发布 GLM-5.3，与 GLM-5.2 共用同一基座，所有能力增量全部来自后训练阶段——官方将其表述为"极致的后训练 Scaling"：数十倍的长程任务环境、更丰富的环境类型与超长的后训练时间。公开基准上，Terminal-Bench 3.0 从 4.6 提升至 28.3，DeepSWE v1.1 从 46.2 提升至 66.9，Agents' Last Exam（CLI）从 23.8 提升至 28.5，内部体感评测较前代提升约 50%；更值得注意的是，在白盒代码审查与漏洞发现任务上，GLM-5.3 表现持平闭源 Mythos 5，官方称其已在 269 个开源项目中挖出 2,436 个真实漏洞。模型提供 1M 上下文与最大 128K 输出，支持连接外部 MCP 工具。对研究者而言，这是"后训练尚未逼近基座智能上界"的最强实证。

模型研究Meta 提出 Wiggle 框架：LLM 裁判在追问下结论翻转率 25%–91%，评估范式遭遇根本性质疑

Meta 新论文（arXiv:2608.12645）指出，LLM-as-judge 通常仅用"对黄金数据的一致性"来验证，但这并不能说明裁判结论在"被质疑"时能否站稳。Wiggle 框架对 9 个前沿模型、14 项裁判任务沿三个维度施压——重新提示下的稳定性、单次质询下的稳定性、持续压力下的稳定性。结果发现"每个模型都会 wiggle"：静态反驳下结论翻转 25%–71%，对抗性说服者面前翻转 62%–91%；且改变裁判结论的压力几乎总是相对 ground truth 产生净污染（net-corrupting）。最稳健的单点预测因子是"基线陪审团多数强度"（baseline jury majority strength）。该工作对奖励模型评测、对齐评估与基准完整性均有直接方法论冲击。

📎 来源：elvis(@omarsar0) · 论文：arXiv:2608.12645

开源模型Qwen3.8 权重放量：27B 稠密小模型追平半年前最强旗舰，2.4T MoE 同步开源

阿里巴巴兑现承诺，开放 Qwen3.8 全系列权重。Qwen3.8-27B 是原生多模态稠密模型，仅 27B 参数却在整体表现上超越 Qwen3.7-Plus，在真实编程与办公工作流上表现突出，原生 262K 上下文、可经 YaRN 扩展至 1M；第三方实测其已能匹配半年前最强最贵的 Opus 4.6 Max，SGLang 在单张 RTX 5090 上实现 206.1 tok/s 解码，Unsloth 使其可在 17GB 内存本地运行。同步开放的旗舰级 Qwen3.8-2.4T-A95B 为 512 专家的稀疏 MoE（2.4T 总参 / 95B 激活），面向 Agent、重编码与长上下文场景，二者均以 Apache 2.0 协议发布。这是"小模型效率曲线逼近前沿"趋势的最强证据。

📎 来源：Qwen(@Alibaba_Qwen) · 量子位

开源框架DeepSeek 开放 V4 Pro 正式版权重与 Harness：以"一切皆插件"重构 Agent 运行时

DeepSeek 于 8 月 13 日开放 V4-Pro-0813 正式版权重，并发布首款 Agent 产品 DeepSeek Harness（MIT 协议）。Harness 的设计原则是"everything is a plugin"——模型接入、工具执行、会话记录、循环本身乃至界面全部走插件机制，Prompt 不再是静态 System Prompt，而是由 Identity/Persona/Tool Guidance/Runtime Context/Tool Schema 动态组装成的"运行时"。Fireworks 等推理商披露，V4 Pro 在 Terminal-Bench 2.1、Cybergym、DeepSWE 等质量基准上以最高 6 倍的成本效率优于 Opus 4.8。Pi 作者 Armin Ronacher 评价这是"第一次让我感到想重新审视自身设计选择"的开源框架，其对 Agent 工程与研究社区的影响值得长期跟踪。

📎 来源：腾讯技术工程 · Fireworks AI(@FireworksAI_HQ)

Agent记忆AML 首期揭榜：Agent 长期记忆迎来"ImageNet 时刻"，MemoraX 58.0 登顶

由牛津大学、清华、北大等海内外近 30 所研究机构联合发起的 Agent Memory Leaderboard（AML，"记忆之巅排行榜"）首期榜单在 Hugging Face Space 发布。官方数据显示 MemoraX 系统以 58.0 分高居榜首，并在文本类记忆全部 7 个能力维度上位列第一；开源方法冠军由 InvMem 以 45.1 分获得。榜单直面一个现实问题：当 Agent 开发者把动辄百万 token 的历史记录全盘塞给模型时，不仅 API 账单指数级爆炸，模型还可能在冗长噪音中严重幻觉——长期记忆由此从工程补丁上升为可量化评估的研究赛道。这是 Agent 记忆领域第一个标准化公开评测，被社区称为该方向的"ImageNet 时刻"。

模型研究Gemini 3.7 Flash：距 3.6 仅三周，Google DeepMind 换帅八天后的首个"工作型"主力模型

Google DeepMind 于 8 月 13 日发布 Gemini 3.7 Flash，距 3.6 Flash 仅三周，官方定义为"迄今最智能的主力模型（workhorse model）"，重点面向编程与 Agent 场景，并被 Cognition、Poe、GitHub Copilot 等生态方迅速接入——Devin 中其 FrontierCode 1.1 已达 Claude Sonnet 5 水平，且价格较 3.6 Flash 低约 50%。发布时点距离 Demis Hassabis 卸任 DeepMind CEO（8 月 5 日）仅八天，恰逢该机构近年最剧烈的权力重组，这一节奏被解读为新管理架构下的算法与反馈加速。对学术观察者而言，其"三周一代 Flash"的迭代密度本身即是研究型组织工程化能力的重要信号。

§2深度论文解读

The Wiggle Framework：LLM-as-Judge 在压力下的稳定性实证研究（arXiv:2608.12645，Meta）

摘要：对 9 个前沿模型在 14 项裁判任务上施压，发现裁判结论在重新提示/单次质询/持续施压三种条件下翻转 25%–91%，且改变结论的压力几乎总是相对 ground truth 净污染。

研究背景

LLM-as-judge 已成为规模化模型评估的事实标准，但其验证方式通常止步于"与黄金标注的一致性准确率"。作者指出，这种验证回答不了一个更基本的问题：当裁判结论被质疑、被施压时，它是否还能站稳？这直接关系到奖励模型评估、对齐评测乃至基准本身的可靠性。

核心创新

Wiggle 提出三维压力测试协议：(i) 稳定性 under re-prompting（重新提示下结论是否一致）；(ii) 稳定性 under a single challenge（单次质询后是否改判）；(iii) 稳定性 under sustained pressure（持续施压下的抗压能力）。该框架首次将"评估者自身的鲁棒性"作为一等公民纳入评估方法论，而非只测评估者的准确率。

实验结果

所有被测模型都会"wiggle"：静态反驳下结论翻转 25%–71%，对抗性说服者面前翻转 62%–91%。更关键的是，导致改判的压力几乎总是把结论推向错误一侧（net-corrupting），即"说服"很难把错的裁判纠正对。作者还发现"基线陪审团多数强度"是预测哪些条目会移动的最佳单点信号——多数一致越弱的判断越易被撬动。

学术意义

这项工作对三个层面有直接冲击：其一，评估报告若只报准确率而不报稳定性，可能严重高估 LLM 裁判的可靠性；其二，奖励模型与对齐评测存在被"提示注入式说服"攻击的薄弱面；其三，"陪审团多数 + 压力测试"可作为下一代评估协议的设计原则。建议引用该工作作为 LLM-as-judge 鲁棒性研究的基线参照。

📎 来源：elvis(@omarsar0) · 论文：arXiv:2608.12645
SraVaani 1.0：面向 65 种印度语言的包容性语音识别（arXiv:2608.08235）

摘要：基于 FastConformer 从头训练的 65 语种多语言 ASR，覆盖大量此前无任何公开 ASR 系统的语言；三阶段训练引入音频—图像表示对齐以强化声学编码。

研究背景

印度语言版图横跨 700 余种语言与数千种方言，而绝大多数 ASR 系统仅覆盖其中极小一部分。作者指出，低资源语言语音技术的不平等是该领域长期未解的结构性问题，SraVaani 以"覆盖 65 种印度语言/方言，其中许多此前没有任何公开或可竞争的 ASR 系统"为目标。

核心创新

模型采用 FastConformer 架构，从头训练，训练流程分三阶段：第一阶段在 VAANI 语料的 31,255 小时无标注语音上进行自监督预训练，使用对比学习目标；第二阶段引入音频—图像表示对齐——利用配对的图像与语音信号对齐表示空间；第三阶段进行监督微调。音频—图像对齐阶段是对标准自监督声学编码的有益补充。

实验与意义

该工作同时提供了大规模多语种语音数据基础设施，为低资源语言 ASR 树立了一个可复现的规模化范式。对语音处理与 AI for Good 方向的研究者而言，它是"以自监督数据规模弥补标注稀缺"路线的又一重要参考点，也呼应了同日 arXiv 上"跨语言迁移中的说话人编码器可解释性"等健康/低资源语音研究热潮。

§4趋势观察

一、后训练缩放（Post-training Scaling）成为新的"智能上界"探针

GLM-5.3 与 GLM-5.2 共用基座、仅靠 RL 后训练把 Terminal-Bench 3.0 提升近 6 倍，这直接挑战"预训练决定模型上限"的直觉。配合 SAO（含 compaction）、IndexShare、新一代 Slime 等后训练框架的密集披露，可以判断：行业正把算力与数据重心从预训练向后训练大规模迁移。对研究者的启示是，基座模型的上界测量、后训练可扩展性（post-training scaling laws）与 RL 环境多样性，将成为比"更大基座"更值得投入的课题。

二、小模型效率曲线持续逼近前沿，评估口径成为关键变量

Qwen3.8-27B 被第三方实测匹配半年前的 Opus 4.6 Max，Hugging Face《State of Open Models》亦指出 Qwen 主导本地推理、小模型主导真实世界用量。但同日多个口径并存——OpenRouter 推出的 Web Search Benchmarks 显示"模型原生搜索未必优于第三方"，提示评估配置本身就会改变结论。效率路线的推进与评估方法论的快速更迭，将让"哪个模型最好"的答案越来越依赖评测协议。

三、Agent 长期记忆从工程补丁升格为正式研究赛道

AML 首期榜单以"ImageNet 时刻"的姿态出现，把长期记忆从"上下文窗口不够用"的权宜之计，抬升为有标准刻度、有独立排行榜的研究领域。MemoraX 在文本记忆 7 个维度全部第一、InvMem 领跑开源方法，暗示记忆的表示、检索与遗忘机制将进入精细化竞争。对于做 Agent 与认知架构研究的团队，这是少数"基准先于成熟方案"的新蓝海。

四、LLM-as-Judge 的稳定性危机，指向评估协议的重构

Wiggle 框架证明"用 LLM 评 LLM"在对抗施压下高度易碎，且改判方向多为净污染。这与近期围绕"推理轨迹安全""加密思维链旁路"的研究共同指向同一结论：模型的自我评价与可验证性，正成为比"分数"更基础的学术问题。下一代评估协议可能将"稳定性压力测试 + 陪审团多数"设为标配。

五、开源权重与安全能力的博弈：从"模型能力"到"能力定向"

GLM-5.3 官方明确以"限制攻击潜力、保留防御价值"为开源前置条件，社区亦出现"闭源负责攻击、开源负责防守"的叙事；DeepSeek 同步开放 V4 Pro 权重与 Harness，Meta 则用 30B 端侧模型推动能力下沉。开源生态的竞争点正从"更大更强"转向"为特定用途定向强化"，而安全评估与加固周期（如 GLM 的两周缓冲）正在成为开源发布流程的标准环节。
