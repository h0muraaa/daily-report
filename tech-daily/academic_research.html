Subquadratic 发布 1200 万 Token 上下文模型，注意力复杂度降至线性

迈阿密初创公司 Subquadratic 推出了首个可处理 1200 万 Token 上下文窗口的模型，并计划近期扩展至 5000 万 Token。该公司由 11 名博士研究员组成，其核心创新在于 Subquadratic Selective Attention（SSA）架构，将注意力的计算和内存复杂度从二次方降至线性。

在 100 万 Token 规模下，SSA 的运行速度比密集注意力快 52 倍；在 1200 万 Token 的"大海捞针"检索任务中准确率表现优异。这一突破直击自 2017 年以来 Transformer 架构的核心瓶颈——注意力成本随上下文长度呈二次增长。若该技术经大规模验证可靠，将根本改变长文档处理、代码库理解、多轮对话等应用场景的技术路径，使 RAG、代理分解等现有折中方案失去必要性。

OSCAR：面向真实 Serving 的 2-bit KV Cache 量化方案，存储压缩 8 倍接近无损

论文《OSCAR: Offline Spectral Covariance-Aware Rotation for 2-bit KV Cache Quantization》提出了一套面向长上下文在线推理的近似 2-bit KV Cache 量化方案，并已接入 SGLang 推理框架可用于真实服务链路。与此前 TurboQuant 等方案不同，OSCAR 保留的是注意力机制真正会读取的方向，而非简单压缩向量。

实验结果显示，在约 2.28 effective bits per KV element 的压缩率下，OSCAR 仍能接近 BF16 精度，并在 Qwen3-4B-Thinking 上相对 3-bit K/V TurboQuant 最高提升 40.1 分。若历史 KV 能稳定压缩至 2-bit，存储开销理论上可缩小约 8 倍。该工作同时解决了"能不能压"和"压完能不能用"两个核心问题，为长上下文模型的经济化部署提供了关键工程基础。

MiniMax M3 基于 GQA 动态块稀疏注意力，百万 Token 预填充速度提升 9.7 倍

MiniMax 即将发布 M3 模型，其核心架构采用基于 GQA（Grouped Query Attention）的动态块稀疏注意力机制。该机制通过一个轻量索引分支快速扫描完整上下文，筛选出最相关的 Token 块，再仅对这些块执行稀疏注意力计算。

在 100 万 Token 上下文上，M3 的预填充（Prefill）速度比 M2 快 9.7 倍，解码速度快 15.6 倍。这意味着百万 Token 级别的 Agent 长程任务从"能跑"迈入"又快又省"的阶段。MiniMax M3 的发布将与 DeepSeek V4 形成竞争格局，为长上下文大模型的工程落地提供又一个高水平选择。值得注意的是，该架构似乎针对中文长文本场景有专门优化，其开源策略也值得关注。

CMU/UMD 联合研究：语言模型也需要"睡眠"，多跳推理准确率提升 52%

卡内基梅隆大学与马里兰大学的研究者在论文《Language Models Need Sleep》中提出了一个颠覆性发现：Transformer 模型在处理超长任务时，注意力机制并非内存容量不足，而是缺乏将上下文转化为可用内部表示的"巩固"过程。他们借用神经科学概念，将多次 forward pass 的离线整理过程称为"睡眠"。

实验基于图灵完备的 Rule 110 任务，发现在清空 KV Cache 前让模型对当前上下文多跑几次 forward pass，将记忆沉淀进 fast weights，预测时仍保持单次 forward 的低延迟。结果在多跳推理任务上准确率提升 52%。这与当前行业狂加上下文窗口、搞 test-time compute 的方向截然不同——"睡眠"是在读取间隙的离线计算，用户无感知但答案更可靠。该研究为理解大模型记忆机制提供了全新视角，也与人类大脑海马体-新皮层的记忆巩固模型形成有趣的对照。

EchoDistill：基于对齐的噪声到干净自蒸馏框架，提升音频大语言模型鲁棒性
arXiv: 2605.23954 | 音频语言模型 · 自蒸馏 · 鲁棒性 · GRPO

研究背景：音频大语言模型（Audio LLMs）在现实噪声环境下表现出严重的语义漂移和幻觉问题。现有鲁棒性方法主要依赖波形级声学增强、答案级监督或噪声表示的内部抑制，但这些方法要么计算代价高，要么在极端噪声条件下失效。

核心创新：EchoDistill 提出了一种对齐驱动的噪声到干净自蒸馏框架。其核心思想是利用一个冻结的干净音频教师模型为推理时的噪声音频学生模型提供语义参考。具体而言，学生模型在噪声条件下采样候选响应以暴露其测试时行为，这些轨迹随后通过群体相对策略优化（GRPO）进行优化，其中教师模型提供干净的语义锚点。这种方法不需要成对的噪声-干净数据，也不修改模型架构，具有极强的实用性和通用性。

学术意义：EchoDistill 将自蒸馏从视觉和 NLP 领域成功迁移到音频模态，展示了跨模态知识迁移的可行性。GRPO 在此场景下的应用也为强化学习在模型鲁棒性增强中的使用开辟了新路径。对于部署在真实声学环境（如智能音箱、车载语音）中的音频 LLM，该框架提供了不增加推理延迟的鲁棒性提升方案。

[来源: cs.SD updates on arXiv.org]
DIVA：利用统一多模态模型中的表示差异实现生成与理解的互增强
arXiv: 2605.25328 | 统一多模态模型 · 表示差异 · 生成-理解互增强 · 归纳偏置

研究背景：统一多模态模型（UMMs）在单一架构下同时实现理解和生成，但研究者发现生成分支偏好高保真、细粒度的表示（用于重建），而理解分支偏好语义判别性的嵌入（对任务无关因素保持不变）。这两种互补但非等价的目标在单一骨干网络中相互干扰，导致"相互损害而非相互增强"。

核心创新：DIVA 首次系统分析了统一骨干网络中这种干扰的根因，并揭示了表示差异中的互补结构。通过 harness 这种差异而非压制它，DIVA 设计了一种互增强机制：让生成和理解分支各自的表示差异成为对方的监督信号，形成正向循环。这使得单一模型在不增加参数量的前提下，在理解和生成两个任务上同时获得性能提升。

学术意义：该研究挑战了"统一模型必然在单项任务上妥协"的隐含假设，证明通过精巧的表示学习设计可以实现真正的"1+1>2"。这对正在向统一架构演进的多模态大模型（如 GPT-4o、Gemini）具有重要的设计启示——理解和生成的矛盾可以通过表示层面的协调来解决，而非简单增加模型容量。

Webwright：微软开源终端原生 Web Agent 框架，核心仅 1000 行代码

微软发布了 Webwright，一个"代码即动作"的终端原生 Web Agent 框架。与传统"观察→预测点击→执行"循环不同，Webwright 让 LLM 直接编写 Playwright 脚本，将网页操作转化为可运行的 Python 程序。工作区即状态，脚本、截图、日志保存在本地，浏览器会话可随时重建。

核心架构极简：Runner（150 行）→ Model Endpoint（550 行）→ Environment（300 行），仅依赖 httpx、pydantic、playwright、typer 四个库，无多智能体系统、无图引擎、无插件层。性能达到 SOTA 水平：Online-Mind2Web 300 任务准确率 86.7%（GPT-5.4），Odysseys 长程任务 60.1%，较此前 SOTA 提升 15.6 个百分点。该框架已集成到 Claude Code 和 OpenAI Codex 插件市场。

Coding Agent 的工业落地：百度 Comate 的反馈闭环与工程范式重构

百度文心快码研发经理在 QCon 2026 北京站分享了 Coding Agent 在百度内部落地的系统性方法论。面对模型能力以周为单位的剧烈迭代，Comate 团队构建了"双层 Loop"Agent 架构：外层是产品反馈闭环，基于线上真实数据持续优化；内层是模型能力适配层，快速接入新模型并评估其适用场景。

AI 辅助编程的认知代价：Anthropic 随机对照实验揭示 17% 技能退化风险

Anthropic 最新发表的随机对照实验（RCT）发现，使用 AI 辅助编程的开发者虽然完成任务略快，但技能掌握程度比手写代码者低 17%。不过，主动向 AI 提问、寻求解释的使用方式能有效缓解这一负面效应。这项研究基于 Claude.ai 数据，是首批严格控制的 AI 编程认知影响实验之一。
