记忆架构OpenAI 发布 ChatGPT "Dreaming" 自动记忆系统

OpenAI 对 ChatGPT 的记忆系统进行了根本性重构，新架构名为 "Dreaming"。与2024年4月上线的人工触发式记忆不同，Dreaming 在后台持续运行，自动从多轮对话中提炼、整合并更新用户画像。关键创新在于时效性处理：系统能自动将"你计划七月去新加坡"更新为"你七月去过新加坡"。

OpenAI 给出了三组纵向评测数据（2024→2025→2026）：事实记忆准确率从41.5%提升至82.8%；偏好遵循率从31.4%提升至71.3%；时效性准确率从9.4%跃升至75.1%，提升幅度最大。用户可在新增的"记忆摘要"页面查看和管理被记忆的内容。该工作对长上下文建模和个性化LLM服务具有重要参考价值。

来源：宝玉(@dotey) | 原始来源：OpenAI
推理模型Microsoft 发布 MAI-Thinking-1 及七款新模型家族

Microsoft 在 Build 2026 上发布了由零构建的模型家族，共七款模型，强调"干净的数据血统"和"极致效率"。核心模型 MAI-Thinking-1 accompanying 一份109页的技术报告，详细披露了训练方法和实验发现。该模型在 SWE-Bench Pro 上达到53%，与 Anthropic Opus 4.6 并列，是目前 toughest coding benchmarks 上的顶尖水平之一。

同批发布的还有：MAI-Transcribe-1.5（43语言SOTA转录）、语音合成模型、图像生成模型等。值得注意的是，Microsoft 强调所有模型均采用零蒸馏（zero distillation）策略训练，这与其他实验室普遍采用的大规模蒸馏路径形成对比。模型已登陆 Microsoft Foundry 和 OpenRouter。

来源：Mustafa Suleyman | 技术报告：microsoft.ai
递归自我改进Anthropic 披露 Claude 内部开发数据：80%+ 代码由 AI 编写

Anthropic 发布了一份关于"递归自我改进"（recursive self-improvement）路径的内部研究报告。数据显示：当前 Anthropic 工程师合并到代码库的代码中，超过80%由 Claude 编写；典型工程师每季度提交的代码量是2021-2025年均值的8倍；在开放式工程任务上，Claude 的成功率从6个月前的约26%跃升至76%。

更引人注目的是研究判断任务：当研究会话偏离轨道时，Claude 提出比人类研究者更优下一步策略的比例从2024年的22%提升至64%（Mythos Preview）。Anthropic 明确表示这并不保证递归自我改进即将到来，Claude 尚不具备"研究判断力"（选择正确问题的能力），但如果趋势持续，AI 系统自主设计并构建其继任者的场景"是合理的"。

来源：Anthropic | 报告：anthropic.com
文本扩散Google DeepMind 展示文本扩散模型：双向注意力实现自我修正

Google DeepMind 的 Brendon Dillon 在 AI Engineer 大会上介绍了 Gemini 文本扩散模型（Text Diffusion）的核心机制与性能特征。与自回归模型不同，文本扩散采用双向注意力，模型能够"看到"未来token并返回修正错误。在一个经典推理测试中，GPT-4o 回答40，Gemini 2.5 Flash 回答42且拒绝修正，而 Gemini Diffusion 模型在第一次前向传播回答60，随后修正为49，最终推理完成后自我纠正为39。

效率方面，24步去噪生成256个token，意味着比自回归生成少约10倍的内存传输次数，延迟可降至每秒2000 token。当前 tradeoff 在于大batch场景下吞吐量较低，规模化 serving 成本仍高。该方向对非自回归文本生成范式具有重要探索价值。

来源：AI Engineer - Text Diffusion
数学推理OpenAI 推理模型推翻 Erdos 80年单位距离猜想

OpenAI 最新一期 Podcast 披露了上个月的一个重要发现：一个通用推理模型帮助推翻了著名数学家 Paul Erdos 提出的80年单位距离猜想（unit distance conjecture）。OpenAI 推理研究员 Alexander Wei、Hongxun Wu 和 Lijie Chen 参与了讨论。

他们回顾了结果开始"看起来真实"的关键时刻、验证证明所需的过程，以及将发现分享给数学界后的反响。该案例的意义在于，它由通用模型而非专门的数学系统完成，提示了通用推理能力在科学发现中的潜在价值。研究团队还探讨了这对数学未来以及研究者如何学习使用 AI 工作的深层含义。

世界模型李飞飞定义世界模型三种形态：视频模型、游戏生成、物理引擎并非一回事

World Labs CEO 李飞飞在最新文章中明确区分了"世界模型"（World Model）这一被严重过度加载的术语。在她和团队看来，当前被混为一谈的三类系统本质不同：视频生成模型（如Sora类）学习的是像素层面的时间连续性；游戏生成系统学习的是可交互规则；物理引擎则是基于第一性原理的确定性模拟。

李飞飞强调"世界不是由词语构成的"（The world is not made of words），语言模型赋予机器的符号能力需要与空间智能（spatial intelligence）结合，才能真正理解和操作物理世界。这一观点在 Stanford、AGI House 等多个场合被重申，对当前世界模型研究的方向选择具有重要指导意义。同期，LeCun 也在该方向下注10亿美元级研究投入。

Agent 评测Agent Arena / Agent Mode：真实世界 Agent 评测方法论突破

dMoE：可学习块专家扩散语言模型

AK（@_akhaliq）分享的一篇新论文提出了 dMoE（dLLMs with Learnable Block Experts），将扩散模型与 Mixture-of-Experts 结合。核心思想是在扩散去噪过程中，让每个时间步或每个块（block）动态选择不同的专家子网络，而非所有层共享相同参数。

该架构的潜在优势在于：扩散模型的多步特性天然适合 MoE 的路由机制，不同去噪阶段可以由专门优化的专家处理；同时保持了扩散模型双向修正的能力。这一方向可能为高效大模型架构提供新的设计空间，值得架构研究者关注。

架构创新统一无编码器多模态架构成为端侧部署关键路径

Gemma 4 12B 的"Unified"架构选择——移除独立的 vision/audio encoder，让多模态输入直接进入统一模型——正在成为一个值得关注的架构趋势。这种设计的优势在于：减少了跨模态对齐的复杂性、降低了端侧部署的内存开销（无需加载多个编码器）、简化了推理管线。代价可能是在某些需要深度模态特定特征的任务上表现稍弱。对于追求"端侧可用"的多模态模型，这可能就是最优 tradeoff。

评测科学多向量检索中的策略选择比模型选择更关键

Milvus 团队分享了一个反直觉的发现：使用相同的多向量模型和相同数据集，仅改变近似检索策略，nDCG@10 可以从0.701骤降至0.109（约6倍差距）。这一发现在多向量检索领域具有警示意义——ColBERT 类模型将文档中每个 token 转为独立向量，文档级 MaxSim 分数不能简单通过标准 ANN 索引高效计算。检索策略的设计空间（如延迟交互 vs 早期交互、不同的索引结构）可能成为未来研究的重要方向。
