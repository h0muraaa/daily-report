一、研究动态

Agent SJTU提出层级认知缓存架构：长程科研智能体的状态管理突破

上海交通大学团队发表了ML-Master 2.0系统，在MLE-Bench基准上运行24小时实现了56.44%的奖牌率，是该基准上最强的成绩之一。该研究的核心创新在于提出"层级认知缓存"（Hierarchical Cognitive Caching）架构，将智能体记忆划分为短期（当前步骤）、中期（跨实验模式）和长期（跨会话 refined knowledge）三个层级。

作者的核心论点是：长程智能体的瓶颈并非推理能力，而是状态管理。缺乏结构化记忆的智能体会重复犯错并在长会话中陷入停滞。这一观点对当前agent研究社区过度关注推理链（Chain-of-Thought）而忽视状态持久化的倾向提出了重要修正。该工作已发布于arXiv。

来源：elvis (@omarsar0) · arXiv: 2601.10402
Arch Apple提出"Attention to Mamba"：Transformer向状态空间模型的跨架构蒸馏

Apple研究团队提出了一种两阶段跨架构蒸馏方案，将训练好的Transformer模型无损迁移至Mamba状态空间模型。直接蒸馏会导致教师模型性能崩塌，其 trick 在于：首先通过核适配将Transformer蒸馏为线性注意力学生模型，再将该学生模型迁移为纯Mamba结构（无注意力块）。

在10B token上训练的1B参数模型实验中，Mamba学生模型达到14.11的困惑度，接近13.86的Pythia-1B教师模型，同时保持了线性时间推理复杂度。如果这一技术路径被验证可扩展，整个开源权重生态系统的长上下文服务成本将大幅下降——这是状态空间模型从"研究玩具"走向"生产替代"的关键一步。

来源：elvis (@omarsar0)
Agent Google CoDaS：面向可穿戴数据的AI协同数据科学家

Google发布了一项将AI智能体应用于生物标志物发现的研究。CoDaS（Co-Data Scientist）系统通过迭代循环将原始可穿戴传感器数据转化为临床相关生物标志物，涵盖假设生成、统计分析、对抗验证和基于文献的推理，并保留人类监督环节。

在9,279例参与者-观测数据中，CoDaS发现了41个心理健康候选生物标志物和25个代谢候选生物标志物，其中包括与抑郁相关的昼夜节律不稳定特征（ρ = 0.252）和与胰岛素抵抗相关的心血管健康指数（ρ = -0.374）。生物标志物发现是医学中最慢、最依赖专家的工作流之一，这项工作展示了agentic系统在封闭科学循环中的实际价值，而非仅限于代码生成或文本处理。

来源：elvis (@omarsar0)
Agent MIA记忆智能体框架：将经验转化为能力的Planner-Executor-Manager架构

上海创智学院与华东师范大学联合团队提出Memory Intelligence Agent（MIA），一个面向深度研究场景的新一代记忆智能体框架。现有智能体大多处于"失忆式工作"模式：每次检索从零开始，推理路径无法沉淀，失败也无法转化为经验。MIA通过Planner-Executor-Manager三元架构解决这一问题。

Planner作为战术大脑，不仅制定研究计划，还能通过测试时持续学习实时调整策略；Executor负责执行并反馈；Manager则管理记忆的积累、检索与更新。该框架针对的是深度研究场景中的持续进化问题，而非单次问答优化。论文与代码均已开源。

来源：机器之心 · arXiv: 2604.04503 · Code: GitHub
Agent Google Aletheia：全自动智能体数学研究的最新进展

Google DeepMind宣布Aletheia系统，该系统基于Gemini 3 Deep Think，在FirstProof挑战中独立解决了10道全新数学问题中的6道，并在IMO-ProofBench上达到约91.9%的准确率。这标志着自动化研究级别证明发现在无需人工干预的情况下取得了实质性突破。

Aletheia的进展需要放在自动定理证明（ATP）的历史脉络中理解：从早期的符号方法到神经指导的搜索，再到如今基于大型语言模型的完整证明生成。91.9%的IMO-ProofBench得分意味着该系统已接近国际数学奥林匹克竞赛金牌选手的证明能力。这一方向的发展可能对未来数学研究的工作流产生结构性影响。

Embodied 高德ABot：全球首个面向AGI的全栈具身技术体系，15项SOTA

高德地图发布了名为"ABot"的全球首个面向AGI的全栈具身技术体系，在亦庄半程马拉松中完成全自主导航与奔跑。该系统在15项基准测试中取得SOTA成绩，构建了从感知、决策到执行的持续进化闭环。其核心亮点在于将大规模导航地图知识迁移至具身智能体，解决了开放环境中长程自主移动的核心难题。

从技术路线看，ABot代表了"地图即模型"（Map-as-Model）的范式：利用高德积累的亿级道路拓扑、动态交通流和三维语义信息，训练具身智能体的空间推理能力。这与特斯拉的纯视觉端到端路线形成有趣对比——一方依赖先验地图知识，另一方强调实时感知。两种路径的学术价值都值得持续关注。

Arch Flash Depth Attention与MoDA：层间通信从残差累积迈向跨层检索

华中科技大学朱亮辉团队提出了一种新的Transformer层间通信机制，从根本上挑战了自2015年ResNet以来"x + F(x)"残差累积的垄断地位。核心思想是将层间信息传递从"累积"升级为"检索"：Query层询问"我需要什么"，Key层回答"我有什么"，每层都能精准"点名"历史信息。

为实现硬件高效训练，团队开发了Flash Depth Attention（FDA）内核，速度提升超过4万倍；进一步提出的MoDA（混合深度注意力）则在单次softmax中同时实现序列级和深度级检索，性能全面超越基线。如果该架构在更大规模上验证有效，可能开启Transformer通信机制的"下一个十年"。项目已开源。

二、深度论文解读

论文一：Attention to Mamba —— 跨架构蒸馏的阶段性突破

研究背景。状态空间模型（SSM）如Mamba系列以线性时间复杂度和恒定内存占用的优势，被广泛视为Transformer在长序列场景下的潜在替代者。然而，SSM面临一个根本性障碍：无法直接利用已经训练好的海量Transformer权重。从零开始训练大型SSM需要数万亿token和数千万美元计算资源，这在开源社区几乎不可行。

核心创新。Apple团队提出的两阶段蒸馏方案巧妙地绕过了这一障碍。第一阶段使用核适配（kernel adaptation）技术，将标准Transformer的softmax注意力蒸馏为线性注意力形式。这一步的关键在于保持注意力权重的语义分布，而非精确数值。第二阶段将线性注意力学生模型进一步迁移为纯Mamba结构，去除所有注意力块。实验结果表明，1B参数模型在10B token训练后，困惑度仅比教师模型高0.25（14.11 vs 13.86）。

学术意义。如果这一方法在7B、70B乃至更大规模上保持有效性，其影响将是深远的：整个开源Transformer生态（Llama、Qwen、DeepSeek等）都可以被"编译"为更高效的SSM变体，而无需重新训练。这相当于为模型架构迁移提供了一种"二进制兼容层"。当然，目前的结果仅在1B规模上验证，更大规模的行为是否一致仍是开放问题。

来源：elvis (@omarsar0)
论文二：ML-Master 2.0 —— 长程智能体的状态管理新范式

研究背景。当前AI智能体研究大多聚焦于单轮或短会话任务（如SWE-bench中的单个bug修复）。然而，真实的科学研究往往是"长程"的：一个机器学习实验可能需要数小时甚至数天的迭代，涉及假设提出、代码实现、结果分析、失败调试和方向调整等多个阶段。如何在如此长的时间跨度中保持 coherent 的状态和积累性学习，是智能体研究尚未解决的核心问题。

核心创新。SJTU团队提出的层级认知缓存（Hierarchical Cognitive Caching）将智能体记忆显式分层：短期缓存保存当前实验步骤的上下文；中期缓存提取跨实验的模式（如"这种数据增强对CNN有效但对Transformer无效"）；长期缓存则沉淀为可跨项目复用的 refined knowledge。在MLE-Bench上运行24小时的实验中，该系统达到56.44%奖牌率。

学术意义。这项工作最重要的贡献是提出了一个可能被广泛忽视的观点：长程agent的瓶颈不是推理，而是状态管理。这与当前社区对"更长CoT"、"更多测试时计算"的痴迷形成对照。如果这一论断成立，未来agent研究的重点可能从"让模型更聪明"转向"让记忆更结构化"——这对架构设计和评估基准都提出了新的要求。

来源：elvis (@omarsar0) · arXiv: 2601.10402

三、开源资源

LiteParse：面向AI智能体的无模型文档解析器

LlamaIndex团队开源了LiteParse，一款无需调用大型视觉语言模型的文档解析工具。它支持50+文件格式，能在约2秒内处理500页文档，且零云依赖。该项目在几周内获得4,300+ GitHub Stars，并已被整合进LlamaIndex生态系统。

从研究角度看，LiteParse的价值在于提供了一个"baseline"选项：当VLM解析存在幻觉风险或成本过高时，研究人员可以使用LiteParse进行快速、确定性的文档预处理。其model-free特性也意味着推理成本的可预测性——这对大规模文档处理实验尤为重要。

来源：Jerry Liu (@jerryjliu0) · GitHub · 官网
MIA：Memory Intelligence Agent框架与代码

上海创智学院与华东师范大学联合开源了MIA框架的完整代码，包括纯净版和可信版两个变体。该框架基于PyTorch实现，提供了Planner、Executor、Manager三个核心模块的参考实现，以及针对深度研究场景的记忆管理API。

对于从事智能体记忆机制、测试时学习（test-time learning）和持续进化（continual improvement）研究的学者，MIA提供了一个可直接扩展的基线系统。其可信版特别增加了对记忆来源的追溯和验证机制，对可解释性研究具有参考价值。

MoDA：混合深度注意力架构开源实现

华中科技大学vision lab开源了MoDA（Mixture of Depth Attention）的完整训练代码和Flash Depth Attention内核。该代码库包含FDA内核的CUDA实现、MoDA层的PyTorch模块，以及基于Hugging Face Transformers的集成示例。

对于研究模型架构效率的学者，FDA内核的"4万倍加速"声明值得复现验证。如果该加速比在长序列和深层模型上依然成立，它可能成为下一代高效Transformer训练的标准组件。

ParseBench：企业文档OCR综合评测基准

Jerry Liu团队发布的ParseBench是一个面向智能体文档理解的综合OCR评测基准，包含167,000条规则，用于衡量数字/单词/句子级别的正确性以及阅读顺序正确性。该基准覆盖了表格、图表、文本和视觉定位四大任务类型。

ParseBench的学术价值在于将"内容忠实度"（Content Faithfulness）量化为可自动评测的指标。当前没有任何解析器在该基准上达到100%，这意味着下游智能体的决策质量普遍受到输入噪声的影响。研究团队已发布完整白皮书和评测平台。

四、趋势观察

评测基准的信任危机：当"满分"成为讽刺

本周，伯克利RDI团队发布了一项令人不安的研究：他们用自动漏洞扫描智能体对8个主流AI评测基准进行渗透测试，结果全部沦陷。在SWE-bench上，仅用一个conftest.py文件和10行Python代码，就实现了500题满分、0个真实bug修复的"完美成绩"。同一周，宾大团队的独立审计报告和Anthropic的Mythos Preview系统卡也指向了相同结论。

这对学术界的警示是深刻的。如果评测基准本身不可信，那么我们过去两年基于这些基准发表的"SOTA"结果，有多少是真实的算法进步，有多少是未被发现的漏洞利用？社区可能需要建立"红队评测"（red-teaming benchmarks）作为标准实践——在发布新基准的同时，必须附带上限攻击（upper-bound attack）的测试结果。

来源：新智元
大模型架构的"下半场"：从Scaling到Communication

本周的多项研究共同指向一个趋势：大模型架构的创新重心正从"如何做得更大"转向"如何通信得更高效"。Flash Depth Attention/MoDA挑战了ResNet时代遗留的层间通信方式；Apple的"Attention to Mamba"探索了跨架构的知识迁移协议；Kimi的KV Cache论文则将上下文管理从工程技巧提升为系统级研究问题。

这一转变的深层原因是：单纯增加模型深度和宽度（wider/deeper）的边际收益正在递减。当GPT-4级模型已能覆盖大多数任务的基本能力后，架构研究的差异化价值在于效率、可扩展性和新能力边界。未来2-3年，我们可能会看到更多关于"结构化稀疏"、"动态计算图"和"跨层信息路由"的研究，而非单纯追逐参数量。

来源：量子位 · Berryxia.AI
Physical AI与具身智能：从"能跑"到"能干活"

高德ABot在亦庄半程马拉松中的表现，以及荣耀"闪电"机器人以50分26秒完成半马，标志着具身智能从实验室Demo走向真实世界压力测试。然而，值得学术界关注的是：这些系统的成功很大程度上依赖于非通用的工程技巧（如高德的地图片段、荣耀的特定步态优化），而非可泛化的学习算法。

NVIDIA VP刘明宇在GTC 2026上提出的Cosmos 3愿景——"为机器人打造黑客帝国"——暗示了另一条路径：通过大规模物理世界模拟生成训练数据，而非在真实世界中昂贵地试错。当"理解"与"生成"在统一模型中融合时，Physical AI可能迎来类似2023年LLM的"ChatGPT时刻"。学术界需要关注的问题是：模拟到现实的迁移间隙（sim-to-real gap）是否能在世界模型时代被系统性缩小？
