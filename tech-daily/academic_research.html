数学推理LLM 在理论计算机科学与交换代数中一次性解决 9 个开放问题

来自 OpenAI 与哥伦比亚大学 Binghui Peng、Runzhou Tao、Steven Wang、Hantao Yu 等研究者的最新工作展示了一个简洁的“证明者—验证者”（prover-verifier）LLM 循环，能够解决 9 个具有挑战性的开放问题。这些问题涵盖理论计算机科学顶级会议 COLT 开放问题列表中的 4 项、FOCS 中的 1 项，以及交换代数领域的 4 项。该研究使用 GPT-5.5 Pro 与 Claude Opus 4.8 作为底层模型，其关键创新在于通过迭代式的证明生成与验证纠错，将大语言模型从“猜测答案”提升为“构造可验证证明”。

这一进展的学术意义在于，它首次以相对统一的流水线在多个子领域同时取得突破，提示 LLM 可能从“辅助计算工具”演进为“数学研究协作者”。不过，该方法的可复现性、证明的可形式化验证范围，以及对问题选择偏差的敏感性，仍是未来需要严格评估的方向。

模型发布美团发布并开源 LongCat-2.0：1.6T 参数 MoE 模型与国产 AI ASIC 训练闭环

美团龙猫团队发布 LongCat-2.0，总参数规模达 1.6 万亿，平均每个 token 激活约 480 亿参数，原生支持 100 万 token 长上下文，面向 Agentic Coding 与长程任务。该模型采用稀疏混合专家（MoE）架构，并针对代码理解、仓库级改写、自动任务执行和多步骤工作流进行了优化，提供 OpenAI API、Anthropic API 以及 Claude Code、Codex 等多种编程工具的接入兼容。

更具研究价值的是其工程路径：LongCat-2.0 的完整训练与部署运行在国产 AI ASIC superpods 上。团队自 2023 年起从千卡规模逐步扩展到五万卡国产算力集群，完成了算子适配、通信优化与分布式稳定性等关键工程问题的闭环。这为“非 NVIDIA 生态下的大规模语言模型训练”提供了一个重要的工业级案例，对研究异构算力上的分布式训练、MoE 路由优化和长上下文效率具有直接参考价值。

机器人学习NVIDIA ASPIRE：首个机器人自动化技能发现系统

NVIDIA GEAR 实验室联合密歇根大学、伯克利与卡内基梅隆大学发布了 ASPIRE，一个面向机器人学的自动化技能发现（automated skill discovery）系统。与传统“逐个任务求解”的范式不同，ASPIRE 能够持续发现、积累并复用可迁移技能，从而实现多任务迁移、仿真到真实（sim-to-real）迁移以及跨本体（cross-embodiment）迁移。该项目已发布项目页面、画廊与白皮书。

从研究角度看，ASPIRE 代表机器人学习从“任务级优化”向“技能库级优化”的重要转向。其核心挑战在于如何在没有显式任务边界的情况下，从交互中提取可复用的原语（primitives）并保证其泛化性。这一方向与终身学习（lifelong learning）、选项框架（options framework）和元强化学习均有深厚联系，值得机器人学与 AI 研究者持续关注。

智能体记忆微软 Memora：在抽象与细节之间取得平衡的 Agent 记忆系统

微软研究院提出 Memora，一个可扩展的智能体记忆系统，通过将“存储内容”与“检索方式”解耦来提升长程任务表现。具体而言，Memora 保留丰富的记忆内容，同时使用轻量级抽象与提示锚点（cue anchors）进行高效检索，从而在抽象性与特异性之间取得平衡。该系统在 LoCoMo 与 LongMemEval 两个长程记忆基准上取得新的最优结果，并在上下文 token 使用量减少最高 98% 的情况下超越了 Mem0、RAG 与全上下文推理基线。

Memora 已被 ICML 接收。其方法对研究 LLM 智能体的长期记忆、外部记忆架构与检索增强生成（RAG）具有重要参考意义，尤其是在如何在压缩记忆表示与保留关键细节之间做权衡这一核心问题上提供了新的设计思路。

智能体优化微软 SkillOpt：将 Agent 技能文件视为可训练参数

SkillOpt 将 AI Agent 的“技能”（skill）——即指导模型行为的文本指令——从一次性提示工程转变为可优化的训练对象。该方法在不更新目标模型权重的前提下，将技能文件作为可训练参数进行迭代优化，并通过边界文本编辑、验证门控、拒绝反馈与慢/元更新机制，保证技能保持紧凑、可审计且避免提示漂移。

实验覆盖 6 个基准、7 个目标模型与 3 种执行模式，SkillOpt 在全部 52 个评估单元中均为最优或并列最优。这项工作为“提示即程序”的研究方向提供了新的优化范式，对自动化提示优化、可解释 Agent 设计以及无需微调即可适配特定任务的方法论具有启发。

多智能体推理Mixture of Debaters：在架构层面学习辩论的多智能体推理框架

现有辩论式多智能体系统通常依赖静态架构，并需要实例化多个模型副本，导致计算开销巨大。本文提出 Mixture of Debaters（MoD），在单一模型内部通过 Mixture-of-Experts（MoE）架构实现动态自辩论。MoD 解决了三个关键挑战：角色分配与流程解耦的双路由机制、基于局部上下文的动量切换以平滑 token 级路由，以及辩论与综合阶段的动态切换。

跨学科研究利用机器学习完整虚拟展开并读取一卷赫库兰尼姆纸莎草

来自牛津、伦敦大学学院、维也纳大学、ESRF 同步辐射中心及 Vesuvius Challenge 等机构的研究团队在 arXiv 发表了关于 PHerc. 1667 的完整虚拟展开与文本读取工作。赫库兰尼姆纸莎草是古典时代唯一大规模保存至今的图书馆遗存，但由于碳化严重，物理展开会造成不可逆破坏，长期无法阅读。研究团队利用欧洲同步辐射光源 BM18 光束线采集的高分辨率相位对比 μCT 数据，结合改进的计算展开算法与机器学习，首次实现了对一整卷密封纸莎草的完整虚拟展开与文字覆盖。

核心方法与创新：研究的关键在于将高分辨率三维成像、几何重建与机器学习相结合。相位对比 μCT 能够捕捉碳化纸莎草薄片内部的细微密度差异；计算展开算法则将这些扭曲、碎裂的层状结构恢复为可读的二维表面；机器学习进一步辅助分割、配准与字符识别。与以往仅能恢复局部片段的研究不同，PHerc. 1667 的“完整”展开意味着方法在覆盖范围与可靠性上取得了质的提升。

学术意义：这项工作是数字人文、计算成像与文化遗产保护交叉领域的里程碑。它证明了机器学习不仅可以处理现代数字数据，还能够在非破坏性考古阅读中发挥决定性作用。对计算机视觉研究者而言，该研究提供了大规模曲面重建、弱监督分割与古文字识别的真实应用场景；对人文学者而言，它开辟了古典文献研究的新范式。未来，随着更多卷宗的数字化，我们有望重新审视古代哲学、文学与科学思想的传承。

机器学习理论当 LLM 遇见理论证明：从 Erdős 到交换代数的开放问题求解

近期 OpenAI 的研究（Erdős 问题上的突破）已经显示大语言模型在数学推理上的潜力，而 Binghui Peng 与合作者的新工作将这一方向推向更系统的理论证明。他们设计的流水线结合 GPT-5.5 Pro 与 Claude Opus 4.8，通过证明者—验证者循环成功解决了 9 个此前未解决的开放问题，覆盖 COLT、FOCS 等理论计算机科学顶级会议的开放问题列表，以及交换代数领域的问题。

方法解析：证明者负责生成候选证明，验证者负责检查其正确性并指出缺陷；两者在循环中迭代，直到获得可接受的证明。这一框架的核心优势在于将 LLM 的“生成能力”与形式化或半形式化的“验证能力”解耦，从而在一定程度上克服了 LLM 容易产生幻觉的弱点。对于需要精确性的数学领域，这种“生成—验证”范式可能比单纯扩大模型规模更具可扩展性。

影响与反思：如果该结果能够在更大范围内复现，它可能改变数学研究的工作方式：研究者将更多精力投入到问题形式化与验证框架设计，而 LLM 承担大量组合搜索与证明构造工作。然而，社区仍需审慎评估这些证明的正确性、可形式化程度以及方法对问题类型的选择性。当前结果更宜被视为“概念验证”而非“通用数学定理证明器”。

该资源填补了低资源语言在语音深度伪造检测研究中的数据空白，对构建更公平、更鲁棒的反欺骗系统具有重要价值。
