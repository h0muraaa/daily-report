DeepSeek-V4-Flash-Vision-Exp 上线：多模态 Agent 能力接近 Opus-4.8
📎 来源：DeepSeek (@deepseek_ai) ｜ DeepSeek 官方公众号

DeepSeek 今日发布实验性多模态模型 DeepSeek-V4-Flash-Vision-Exp。官方披露的关键结论是：在纯文本能力（Agent、推理、世界知识）上它与 V4-Flash 正式版持平，但在需要视觉理解的 Agent 基准上实现了“大幅跃升”，多模态 Agent 能力已接近 Opus-4.8。API 侧同时放开三种接入：图像按 最多 384 tokens/张、沿用 V4-Flash 价格计费，支持 Chat Completions / Messages / Responses 协议，图像可通过 base64、外链或 Files API 传入；同步开放的 Files API 免费使用，图片上传一次后即可用 file_id 反复引用。DeepSeek Harness 0.1.1 也已内置该模型支持。对研究“视觉理解如何转化为 Agent 任务收益”的团队，这是一个可在本地完全复现的实验对象。

T-Rex：触觉反应式灵巧操作——100 小时触觉同步数据集与双时钟 MoT 架构开源
📎 来源：Jim Fan (@DrJimFan) ｜ 项目主页：tactile-reactive-dexterous.github.io

由 Dantong Niu 主导、Jim Fan 团队与 Trevor Darrell 联合顾问的工作 T-Rex 直指机器人触觉模态的长期空白：绝大多数 Vision-Language-Action（VLA）模型要么完全忽略触觉反馈，要么无法对高频接触信号做出反应。工作开源两部分——其一是 100 小时触觉同步灵巧操作数据集，含 7,700+ 条轨迹、22 个电机原语、200+ 日常物体；其二是名为 MoT（Mixture-of-Transformers）的触觉反应式架构，以异步双时钟运行：慢速视动专家负责规划动作，快速触觉专家以“每 1 个视觉 tick 执行 4 个触觉 tick”的频率做实时修正——因为力的变化比帧到达更快。Jim Fan 以“戴厚烤箱手套做近景魔术”比喻无触觉机器人的窘境，主张“学会感受”必须是一次全栈协同设计。对具身智能与多模态学习的交叉研究者，这是触觉进 VLA 的重要开源基线。

商汤开源 SenseNova U1.5 Lite：8B 原生统一多模态，理解+生成+编辑一体化
📎 来源：智东西 ｜ 硅星人Pro

商汤正式开源 SenseNova U1.5 Lite（8B 参数），这是其 4 月发布的 NEO-Unify 原生统一多模态路线的最新落地：在单一模型中贯通视觉理解、推理、生成与编辑，原生支持 3–4k 字符超长复杂指令与 4K 高分辨率输出。商汤公布的基准显示，在图像生成、文字渲染与编辑指标上，U1.5 Lite 优于 Qwen-Image-2.0、Seedream-4.5，部分基准超过 GPT-Image-1.5，但仍与 GPT-Image-2 有差距。轻量、开源、单模型同时覆盖“看懂—生成—改图”的能力组合，正成为实用视觉工作流研究的新选择；模型已通过 GitHub、Hugging Face 与魔搭社区开放。

二、深度论文解读 PAPER DEEP-DIVES

arXiv:2608.19843 · cs.SD / cs.MM

Fourier is Frontier：频域感知自编码器（ear-VAE2）如何修复高压缩率音乐重建的三重失效

研究背景

连续潜在空间音频自编码器是潜在音乐生成模型的骨干。但在高压缩率下，现有波形域解码器普遍暴露三类系统性失效：高频丢失、相位不连贯、立体声图像塌缩。作者指出这三者共享一个结构性根因——波形自编码器缺少显式的频域轴，因而没有任何“逐频带定点修正”的抓手。

核心创新

论文首先在 5 种“预算匹配”的表示中做系统对比，发现 复数 STFT 表示在整带与高频谱距离上均取得最低误差，因为它对每个 bin 都直接暴露幅值与相位。基于此提出 ear-VAE2，一个复数谱自编码器，配以跨通道交互机制以对齐多通道的频谱结构。这一设计把“频带级修正”从不可能变为可直接优化的目标。

实验结果与学术意义

通过在高压缩率设定下检验高频重建、相位一致性与立体声保真度，ear-VAE2 系统性改善了前述三类失效。对音频生成与表征学习研究者，这篇工作的价值在于把“表示选择”重新放回自编码器设计的核心决策位：当目标是最小化感知失真时，显式频域表示可能比继续堆叠波形域模型更有效，也为高保真音乐重建提供了一条可复现的替代基线。

arXiv:2608.11924 · AI for Science

Spark-to-Paper：端到端研究论文生成系统，假结论检出率提升至 92%

研究背景

Coding Agent 正在重塑科研流程，但两条痛点依然突出：其一是工具碎片化——文献阅读、假设提出、代码编写、实验试错、参数调优散落在多个平台，各环节产物难以衔接；其二是科研幻觉——面对复杂、长链条任务，模型在文献引用、实验数字、因果推导上容易出错且难以自查。

核心创新

Spark-to-Paper 以 13 个可组合技能的形式运行在现有编程助手内部，无需单独部署的智能体平台。从一句研究想法出发，系统自动完成文献检索 → 实验设计 → 实验执行 → 论文写作 → 证据驱动的结论修订 → 可编辑论文图生成，直至输出可直接编译的完整 LaTeX 项目。针对科研幻觉，系统引入“证据驱动修订 + 对抗式评审”闭环。

实验结果与学术意义

在 8 个受控研究课题上：引文有效率 99.5%、图形元素可编辑率 96.4%；对 36 条人为注入的假结论，检出率从单遍生成的 14% 提升至 92%，对抗式评审精确率 74%。成本核算为平均每篇 11.9M token / 8.1 美元 / 3.2 小时。论文已被 Hugging Face Papers 标记为当日第一。对“AI 参与科研写作的边界与可信度”这一议题，这是一份把流程、评测与成本数据全部公开的难得实证。

四、趋势观察 RESEARCH TRENDS

AI for Science 走向“端到端工作流”

Spark-to-Paper 把“从想法到可编译论文”压到 3.2 小时 / 8.1 美元；深势科技玻尔·科学空间把文献调研、假设生成与实验执行收进统一桌面端。与微软 Skala 嵌入 CP2K 等“工具链嵌入”不同，这一波的特征是“把完整科研管线编排为一个可对话的工作流”，研究者的角色从操作者转向提问与验收。[来源]

触觉：机器人感知的下一个“被低估模态”

T-Rex 以 100 小时触觉数据与双时钟 MoT 把触觉提升为一等模态；银河通用以“通用小脑”让双足人形完成转笔等精细操作；Generalist AI 的 GEN-1.5 则用一次 3–12 秒演示实现“看一遍秒会”的动作模仿。三者共同指向：当视觉-语言空间被充分开采，触觉反馈与技能获取速度正成为具身智能的下一条研究主线。[来源]

开源多模态进入“理解+生成+编辑”一体化时代

SenseNova U1.5 Lite 以 8B 参数在单模型内贯通视觉理解、推理、生成与编辑并支持 4K 输出；DeepSeek-V4-Flash-Vision-Exp 把多模态 Agent 能力推到接近 Opus-4.8；GLM-5.3（Max）靠后训练改写 WebDev Pareto 前沿。当“能力集成为默认设计”，小模型与大模型的差距正在从“能不能”转向“贵不贵、准不准”。[来源]

基准科学：从“刷分”到“评测可信度”

arXiv 2608.19936 提出量化 ASR 模型“为公共基准而优化”的方法论（参考分歧、掩码数字恢复、拼写切换三类行为探针）；Meta 的 WildArtifactBench 转而用偏好判断的胜率与 Elo 取代严格 ground-truth；Hugging Face 同步发文解读基准优化风险。评测自身正成为被检视的研究对象。[来源]

语音 / 音频研究：安全与感知两条腿并行

深度伪造检测进入“跨代工具对比”阶段——人类对 ElevenLabs 全伪造语音的 F1 已降至约 48%；同时音频-LLM 的韵律因果归因（Represented but Ignored）、低资源语言 ASR（Mizo 语料，形态感知 WER 7.22%）与多语言 TTS 基准（MINT-Bench）同步推进。安全评估与感知建模在音频方向加速交汇。[来源]

Agent 评测范式向“真实任务 + 偏好判断”迁移

从 Arena 的 Code Arena 榜单到 Meta 的 WildArtifactBench，Agent 评测正从“可自动打分”走向“人类 / Agent 化裁判的偏好判断”，以覆盖多格式、长程、真实交付物任务。配合“后训练轨迹数据”研究（Agent 是否真能 post-train 其他 Agent），Agent 的能力度量与可信度问题正在成为独立的研究领域。[来源]
