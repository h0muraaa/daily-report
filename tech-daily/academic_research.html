SWE-1.7：面向软件工程任务的强化学习规模化新进展

AgentRLCode Generation

Cognition 团队发布了 SWE-1.7，并称其是公司迄今为止能力最强的模型。该模型在 Devin harness 中训练，能够在接近前沿闭源模型性能的同时显著降低推理成本，并通过 Cerebras 以 1000 tok/s 的速度提供推理服务。关键训练创新在于让模型在更长时域任务上“自我压缩”（self-compact）：随着训练时长增加，SWE-1.7 在编辑代码前会投入更多时间进行调研与问题重构，表现出 reasoning 深度与代码修改范围同步扩大的趋势。

从研究角度看，SWE-1.7 进一步验证了“RL 在专用代码智能领域尚未触顶”的判断。Cognition 同时披露了支撑该模型的分布式 RL 基础设施：训练集群横跨四大洲四个数据中心，仅训练器需要紧耦合的集合通信，rollout 推理则通过对象存储中的压缩权重差分实现异步同步。这种将训练通信与推理 rollout 解耦的架构，为大规模 RL 工程系统提供了可复用的设计范式。

来源：Cognition (@cognition_labs) on X；Cognition Blog；Fireworks AI on X

Nemotron 3 Ultra 与 LangChain Deep Agents Harness：开放权重模型的“系统级”追赶

Open ModelAgent HarnessCost Optimization

NVIDIA 与 LangChain 联合发布了针对 Nemotron 3 Ultra 调优的 Deep Agents Harness。该工作并非单纯发布模型权重，而是通过“ harness 工程”将开放权重模型与规划、工具使用、记忆和长程任务执行模块深度整合。在公开基准上，该组合以 4.48 美元的总成本取得 0.86 的聚合分数，而性能最接近的闭源模型成本高达 43.48 美元，成本差距约 10 倍。

这一结果对学术界具有方法论意义：它表明在 agent 场景下，模型能力、推理基础设施和 orchestration 策略的联合优化，可能比单纯追求更大的闭源模型更具性价比。NVIDIA 还同步推出了 NemoClaw Deep Agents Blueprint，提供可定制、可治理的开放参考架构，LangChain 则发布了 dcode 与 Nemotron 3 Ultra 的集成教程，展示如何在 Baseten 上部署该模型进行实际编码任务。

来源：LangChain (@LangChainAI) on X；NVIDIA AI on X；LangChain YouTube

NapMem：将长期记忆重构为 Agent 可导航的动作空间

MemoryRLAgent Architecture

现有大多数记忆系统将检索结果直接交给模型，使模型成为“预选证据的被动消费者”。NapMem 提出了一种新范式：将用户历史组织成多粒度金字塔结构——原始对话、类型化记忆记录、主题轨迹和用户画像——并通过溯源关系（provenance relations）将其暴露为工具。模型通过记忆工具强化学习（memory-tool RL）训练，自主决定在进入回答前应该查看哪个粒度层。

该工作在 PersonaMem-v2、LongMemEval 和 LoCoMo 等长期记忆基准上保持竞争力的同时，基本不损害通用推理能力。其核心价值在于把“记忆检索”重新概念化为“记忆导航”，为构建具备终身学习能力的 agent 提供了更结构化的理论框架。

来源：elvis (@omarsar0) on X

COMA：提示词压缩成为大模型 Agent 的新型攻击面

SecurityPrompt CompressionASE 2026

香港科技大学的一项研究（已被 ASE 2026 接收）指出，提示词压缩（Prompt Compression）模块在降低 token 成本的同时，可能重写系统的安全边界。传统攻击假设恶意指令需进入后端 LLM 的有效上下文；但在压缩流水线中，后端模型看到的是经压缩器处理后的 prompt，攻击者可以利用压缩器在预算限制下选择性丢弃系统规则或任务证据，从而在不直接触发 LLM 安全机制的情况下改变系统行为。

研究团队提出了黑盒攻击框架 COMA，用于系统评估这一新型攻击面。该研究对当前面向长上下文的 Agent 系统部署具有重要警示意义：效率优化组件本身也会引入新的安全风险，需在系统架构设计阶段纳入威胁建模。

来源：机器之心；论文：arXiv:2510.22963；代码：GitHub

Flint：面向 AI 时代的可视化声明式语言

VisualizationHuman-AI InteractionMicrosoft Research

Microsoft Research 发布了 Flint，一种开源可视化语言，旨在让 AI agent 能够从简洁、人类可编辑的规范中可靠地生成表现力丰富且视觉精美的图表。Flint 利用语义数据类型指导设计决策，自动管理尺寸、间距、标签和布局，使同一规范可编译为 Vega-Lite、Apache ECharts 或 Chart.js 等多种后端。

从研究视角看，Flint 介于“完全自动化生成”与“精细手工配置”之间，为 agent 辅助的数据可视化提供了一个中间层抽象。其设计哲学强调可解释性与可编辑性，有助于缓解当前 LLM 生成可视化结果不可控、难以迭代的问题。

来源：Microsoft Research Blog

MOTIVE：通过数据影响力筛选提升视频运动生成质量

Video GenerationData CurationICML 2026

NVIDIA Research 在 ICML 2026 上获得 Outstanding Paper Honorable Mention 的 MOTIVE 工作，提出了一种基于数据影响力（data influence）的视频训练数据筛选方法。MOTIVE 重新加权训练信号，使其聚焦于运动区域而非静态背景，并为每个训练片段打分以衡量其对模型运动生成能力的影响。基于筛选出的高影响力子集进行微调后，模型在 VBench 动态指标上显著提升，并在人类偏好评估中以 74.1% 的胜率超过基线模型。

该研究的重要意义在于展示了“数据质量 > 数据数量”在视频生成中的具体实现路径，为后续高质量视频数据集构建提供了可量化的筛选标准。

Audex：在不牺牲文本智能的前提下统一音频智能

MultimodalAudio-Language ModelarXiv
论文信息：Kong et al., Unified Audio Intelligence Without Regressing on Text Intelligence, arXiv:2607.05196.
核心贡献：提出 Nemotron-Labs-Audex-30B-A3B（Audex），一个基于 Nemotron-Cascade-2-30B-A3B 文本 MoE LLM 的统一音频-文本大模型。

当前音频大模型常面临一个两难：引入音频模态后，文本能力出现退化。Audex 采用极简的统一 Transformer 解码器架构：音频输入经编码器投影到文本嵌入空间，文本 token 与量化音频输出 token 在生成过程中被统一处理。这种设计既实现了强音频-文本融合与无缝多模态生成，又兼容标准 LLM 训练与推理基础设施。

训练数据方面，作者精心整理了包含 1574 亿音频 token 的音频-文本数据集。实验表明，Audex 在保持强文本智能的同时，在音频理解、推理和生成任务上取得了统一且优异的表现。该研究为“如何在不牺牲通用语言能力的前提下扩展 LLM 到新模态”提供了一个重要的架构参考。

来源：arXiv:2607.05196 · cs.SD / eess.AS updates on arXiv.org

WebRetriever：面向高效 Web Agent 的大规模综合评测基准

BenchmarkWeb AgentEvaluation
论文信息：Dong et al., WebRetriever: A Large-Scale Comprehensive Benchmark for Efficient Web Agent Evaluation, arXiv:2607.06118.
核心贡献：构建了一个大规模、跨领域、细粒度的 Web Agent 评测基准，重点关注现有基准在规模、领域多样性和评估粒度上的不足。

现有 Web Agent 基准普遍存在三个局限：规模不足且领域单一，难以评估跨域泛化；LLM-as-Judge 方法难以捕捉精细的交互语义，尤其是精确查询表述与过滤操作；过度关注导航成功率而忽略效率、鲁棒性等关键维度。WebRetriever 通过更大规模的数据覆盖、更细粒度的交互标注以及更全面的评估指标，试图为 Web Agent 研究提供更严谨的实验平台。

随着浏览器使用、在线购物、信息检索等 agent 应用日益增多，可靠且可重复的评测基准将成为该领域从“演示”走向“科学”的关键基础设施。WebRetriever 的发布有助于推动 Web Agent 在真实复杂环境下的能力评估标准化。

HeartMuLa：开源音乐基础模型家族

Music AIFoundation ModelOpen Source

HeartMuLa 是一个开源音乐基础模型家族，包含四个核心组件：HeartCLAP（音频-文本对齐模型）、HeartTranscriptor（真实场景歌词识别模型）、HeartCodec（低帧率高保真音乐编解码器 tokenizer）以及 HeartMuLa（基于 LLM 的可控歌曲生成模型）。该框架旨在推进大规模音乐理解与生成在多种任务和模态上的统一研究。

HeartCodec 以 12.5 Hz 的低帧率捕获长程音乐结构，同时保留细粒度声学细节，为自回归音乐生成提供了高效的 token 表示。相关预训练权重已公开，适合从事音乐信息检索、可控生成和多模态音乐理解的研究者复用。

BlueMagpie-TTS：面向台语腔代码切换 speech 的高效 token 化 TTS

TTSLow-Resource LanguageCode-Switching

BlueMagpie-TTS 针对台湾 Mandarin 与英语代码切换场景下的文本到语音合成问题，从文本端进行了自下而上的适配。研究团队提出了 PangolinTokenizer——一种基于字节级 BPE 的分词器，在台湾语境数据上训练，达到了 nine 种对比分词器中最低的 token 率（0.485 tokens/character）和最小词表。

四、趋势观察

从“模型能力”到“系统能力”：开放权重模型的追赶逻辑

今日多条动态指向同一个趋势：开放权重模型正在通过 harness 工程、RL 微调和推理基础设施优化，在特定任务上逼近甚至超越闭源前沿模型。Nemotron 3 Ultra 与 LangChain Deep Agents Harness 的组合、SWE-1.7 在 Devin harness 中的训练，以及 dcode 的模型无关设计，都说明“模型 + 系统”的联合优化正成为新的研究前沿。学术界需关注如何量化 harness 对模型能力的贡献，并建立可比较、可复现的评估框架。

记忆系统从“检索”走向“动作空间”

NapMem 将记忆组织为结构化动作空间，让 agent 自主选择查看哪个粒度层级，代表了长期记忆研究的重要范式转变。与此同时，BYOKG/GraphRAG 在科学领域的应用表明，显式知识图谱在需要严谨性和可解释性的场景中仍具不可替代的价值。未来研究可能会看到“参数化记忆”（模型权重）、“结构化外部记忆”（知识图谱）和“过程记忆”（agent 动作历史）三类范式的进一步融合。

多模态统一与垂直评测并重

Audex 展示了音频-文本统一建模的新进展，而 WebRetriever、Music I Care About 等基准则强调针对特定能力的精细评测。随着多模态模型能力快速扩展，领域专用基准和科学严谨性评估将成为区分“演示效果”与“真实进展”的关键。研究者应在推动模型能力的同时，投入同等精力构建高质量、可扩展的评测基础设施。
