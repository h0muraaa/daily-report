§1研究动态

安全研究防蒸馏机制全面告破：小模型"套出"大模型隐藏思维链，Kimi-K3 重现概率异常

由 MATS 项目研究员 Alexander Panfilov 领衔、马克思·普朗克研究所等参与的团队发布的研究，系统攻破了 Anthropic、OpenAI 等闭源厂商最倚重的"隐藏思维链（Hidden CoT / Reasoning Tokens）"防线——该防线将模型复杂的推理过程加密封装，仅对外部用户输出最终计算结果，试图将大模型的"认知过程"彻底黑盒化。研究显示，小模型可通过概率异常检测"套出"大模型的隐藏推理链，并在 Kimi-K3 上复现了该概率异常。这一工作直接推翻了业界"加密即安全"的假设，对依赖隐藏 CoT 作为护城河的闭源模型构成根本性挑战。

可解释性至知研究院提出大模型可解释性新路线：拆权重，数据成本不到 1%

至知研究院提出一条大模型可解释性的新路线：直接拆解权重以理解模型内部机制，而无需再训练一个替代网络（surrogate）。官方称该方法的数据成本不到 1%，显著低于传统依赖大规模特征工程或探针训练的可解释性方法。在可解释性研究长期受限于"计算成本高、结论难迁移"的背景下，这一"权重级"解释路径为理解大模型内部表征提供了更轻量的分析入口。

后训练缩放GLM-5.3：同基座纯后训练，Terminal-Bench 4.6→28.3，两周发现 2404 个潜在漏洞

智谱于 8 月 14 日发布 GLM-5.3，与 GLM-5.2 共用同一 756B 基座，所有能力增量全部来自后训练 Scaling（更大的长程任务环境、更高的任务多样性、更多的 RL 计算投入）。公开基准上，Terminal-Bench 3.0 从 4.6 跃升至 28.3，DeepSWE v1.1 从 46.2 提升至 66.9，Agents' Last Exam（CLI）从 23.8 提升至 28.5，内部体感评测较前代提升约 50%。更受关注的是其涌现的网络安全能力：发布前两周联合国内安全团队在各大项目上发现 2404 个潜在漏洞（其中 1088 个为中高危），最早的可追溯至 40 多年前，涉及 DNS、邮件与办公系统、通信软件、操作系统等。智谱承诺在发布两周后开放模型权重。

开源模型Qwen3.8-27B 开源：原生多模态稠密，262K 上下文可外推至 1M，超 Qwen3.7-Plus

阿里云正式开源 Qwen3.8 系列，其中 Qwen3.8-27B 是全球社区呼声最高的尺寸：原生多模态稠密模型，27B 参数，原生支持 262K 上下文、经 YaRN 可外推至 1M tokens；较 Qwen3.6-27B 在编程与办公场景性能大幅提升，整体超越 Qwen3.7-Plus。模型新增 reasoning_effort 功能，可根据任务难度控制推理深度。Unsloth 同步放出 Dynamic GGUF 量化版本，17GB 内存即可本地运行，官方 FP8 与 vLLM/SGLang/TokenSpeed 生态兼容。这是"小模型效率曲线逼近前沿"趋势的最新实证。

检索增强Agentic RAG 单卡基准：混合检索 + 晚交互重排，首检命中率 72%→87%

Qdrant 与 Minima 联合发布基于单张 RTX PRO 6000 Blackwell GPU 的 Agentic RAG 案例研究：通过混合检索（hybrid search）与晚交互重排（late-interaction reranking），首次检索命中率从 72% 提升至 87%，中位延迟从 21.3 秒降至 7.7 秒，每 GPU 小时成功完成任务数提升 2.92 倍。该工作为"单卡规模下的检索增强智能体"提供了可量化的工程基准，对评估检索架构与重排策略的实际收益具有参考意义。

§2深度论文解读

DeepSeek Harness 技术拆解：88 页论文背后的"一切皆插件" Agent Runtime 范式

摘要：AINLP 对 DeepSeek Harness 的 88 页技术论文进行逐节拆解；腾讯技术工程实测确认，开源版本本质是一个"能继续造 Agent 的 runtime"——模型、工具、Skills、会话、沙箱、文件系统、Agent Loop 乃至 Web UI 全部以插件形式开放替换。

研究背景

DeepSeek-V4-Pro 正式版上线当天，DeepSeek Harness v0.1 以 Developer Preview 形式开源，GitHub 上线一个多小时破 2 万 star，随后逼近 100k。外界原本期待它是"DeepSeek 版 Codex"，但源码摊开之后，其形态更像一个通用 Agent 运行时：Web coding agent、Headless、Python SDK、ACP 与 JSON-RPC 一应俱全。

核心创新

文章指出 Harness 的灵魂是"一切皆插件"——这与大多数软件"厂商留口子、用户在口子上做有限定制"的逻辑恰好相反：模型接入、工具注册表、会话日志、审批、沙箱、Agent Loop、甚至网页界面全部可替换。其中 Cordis 被作者称为"灵魂"，承载状态机、上下文管理、记忆、Skills & MCP 等概念的落地。用户可像拼装 Arch Linux 一样，把 Harness 捏成任何想要的 Agent。

工程与学术意义

对 Agent 框架的可组合性研究而言，这是一份完整的"插件化 runtime"参照系：它把"运行链路、状态机、上下文管理、记忆、沙箱"从概念文本变成可读、可改、可替换的开源实现。对于研究 Agent 架构与上下文工程的研究者，该论文及其开源实现提供了比闭源系统更易切入的研究载体。

SynthID-Text 式统计水印：从生成机制到 EU AI Act 合规落地

摘要：梳理 Google DeepMind SynthID-Text 水印的采样级机制（keyed watermark probability update），并追踪 Anthropic 为符合欧盟《人工智能法案》而将其应用于 Claude 的实现细节与 FAQ。

研究背景

Anthropic 宣布为 Claude 输出实施文本水印，以符合欧盟《人工智能法案》（EU AI Act）；其他主要模型开发者已签署同一《行为准则》（Code of Practice）并将同步实施。此前创业邦已报道 Claude 将为 AI 生成文字打上"隐形水印"。生成内容溯源由此从研究议题上升为合规刚需。

核心机制

SynthID-Text 的水印嵌入位于采样环节：model forward pass → next-token logits → 温度 / top-k / top-p → keyed watermark probability update → 采样 token。对每一个候选 token，模型都会咨询一个由密钥决定的、上下文相关的"掷硬币"结果来偏置概率分布；持有密钥的一方可通过统计检测该模式，从而判断文本是否由模型生成。这是一种在保持文本质量的前提下叠加可检测统计指纹的方法。

学术意义

Anthropic 官方 FAQ 强调其水印方法对 Claude 输出质量与内容无实际影响，并区分了"可见水印"与"隐形/统计水印"的差异。该路线对机器生成文本检测（AI-generated text detection）与模型审计研究具有直接价值，也为"采样级可控随机性"这一生成模型安全机制提供了标准化案例。

§4趋势观察

一、后训练缩放继续坐实"智能上界"探针地位

GLM-5.3 与 GLM-5.2 共用基座、纯靠后训练把 Terminal-Bench 提升近 6 倍，再次验证"预训练决定上限"的直觉正在被改写。叠加 DeepSeek V4 Flash（304B 参数后训练反超更大模型）等案例，"后训练尚未逼近基座智能上界"正成为行业主流判断。对研究者而言，后训练可扩展性（post-training scaling laws）、RL 环境多样性与任务设计，将比"堆更大的基座"更具研究增量。

二、防蒸馏与推理链安全进入攻防新阶段

隐藏思维链被小模型以概率异常"套出"，宣告"加密即安全"假设失效。这与 Anthropic 诉 DeepSeek/Moonshot"套取推理能力"的指控相互呼应，意味着闭源模型的护城河需从"隐藏推理"转向更根本的机制。推理链可提取性（reasoning-token extractability）有望成为安全与可解释性交叉领域的新研究热点。

三、开源小模型本地化从"demo"走向"生产基线"

Qwen3.8-27B 以 17GB 内存可运行、Apache 2.0 授权、官方 FP8 与社区量化同步到位，把"强模型 + 消费级硬件"同时兑现。当高效量化与生态兼容成为开源发布的标准动作，"同尺寸最强"的竞争将从模型本身延伸到量化、推理引擎与部署成本——这也为资源受限的学术实验室提供了更可行的复现环境。

四、Agent / Harness 范式成为研究主战场

DeepSeek Harness 的"插件化 runtime"与 Cordis 生态，以及 NVIDIA NeMo Switchyard 的模型路由，共同指向 Agent 架构的可组合性研究。与此同时，"上下文 + 评测构建进化 Loop"、Agent 长期记忆与状态机管理等子问题被正式课题化。Agent 框架正从工程拼凑升级为有论文、有开源实现、有基准（如 Agent Arena）的成熟研究领域。

五、生成内容溯源从可选特性变为合规刚需

随欧盟《人工智能法案》落地，Anthropic、Google（SynthID-Text）等主要模型开发者纷纷将统计水印作为标准配置。水印技术从"检测工具"升级为"合规基础设施"，其采样级可控随机性机制也对生成模型的安全审计提出了新的测量需求——"可检测性"与"质量无损"的平衡将成为持续的研究课题。
