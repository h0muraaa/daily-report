ACADEMIC RESEARCH

一、研究动态

ICLR 2026 Best Paper：LLMs 在多轮对话中系统性迷失方向

Microsoft Research 的 Philippe Laban、Jennifer Neville 及其合作者凭借论文《LLMs Get Lost In Multi-Turn Conversation》斩获 ICLR 2026 最佳论文奖。该研究系统性地揭示了大语言模型在多轮交互场景中的性能衰减机制——随着对话轮次增加，模型逐渐偏离用户原始意图，产生"方向性迷失"。

这项工作对真实世界 AI 评估框架具有深远影响：当前主流基准多以单轮问答为主，而该研究表明多轮场景下的模型行为与单轮存在本质差异，呼吁研究社区重新思考对话系统的评估范式，将长程上下文一致性纳入核心评测维度。

[来源: Microsoft Research]

DR-Venus：仅用 10K 开放数据训练边缘级深度研究 Agent

一项名为 DR-Venus 的新研究提出了一种数据高效的前沿深度研究 Agent 训练方案，其核心突破在于仅依赖 10,000 条开放数据即可达到接近前沿水平的 Agent 性能。在数据饥渴的 Agent 研究领域，这一成果显著降低了高性能研究 Agent 的训练门槛。

该方法对学术界的启示在于：Agent 能力的瓶颈未必在于数据规模，而可能在于数据质量、任务分解策略与反馈机制的设计。论文已发布于 Hugging Face Papers。

[来源: AK(@_akhaliq) / Hugging Face Papers]

Near-Future Policy Optimization：强化学习策略优化新框架

一项新的强化学习研究工作提出了 Near-Future Policy Optimization（近未来策略优化）方法，旨在改进传统策略梯度算法在长程决策任务中的样本效率与收敛稳定性。该方法通过对策略未来轨迹的局部近似进行优化，在标准控制基准上取得了提升。

对于从事 RL 理论研究的学者而言，这项工作提供了策略优化目标函数设计的新视角，值得跟进其对策略梯度方差减少的理论分析。

[来源: AK(@_akhaliq) / Hugging Face Papers]

LLaDA2.0-Uni：统一多模态理解与生成的扩散大语言模型

LLaDA2.0-Uni 提出了一个统一的多模态理解与生成框架，基于扩散大语言模型（Diffusion LLM）架构实现了文本、图像等多种模态的联合建模。与自回归模型不同，该框架利用扩散过程进行双向信息交互，在跨模态理解和生成任务上展现了潜力。

这一方向对多模态基础模型研究具有重要意义：扩散语言模型作为自回归范式的替代方案，其在多模态场景下的统一建模能力可能突破现有架构在模态对齐和生成质量上的局限。

[来源: AK(@_akhaliq) / Hugging Face Papers]

多智能体系统中的"多样性崩溃"现象被形式化验证

DAIR.AI 关注的一项新研究对多 Agent 系统中普遍存在的"多样性崩溃"（Diversity Collapse）进行了形式化分析与实证验证。研究发现，多 Agent LLM 系统即使采用不同架构和初始提示，经过多轮交互后输出也会收敛到近乎相同的模式——其根本原因在于结构耦合（structural coupling）：共享上下文、共享任务描述和相互反馈将所有 Agent 拉向同一吸引子。

研究者使用 Vendi Score 等指标进行了量化评估，证实了同质化效应的显著性。这一发现对多 Agent 系统在创意任务（头脑风暴、假设生成、创意构思）中的应用提出了根本性挑战：除非显式地设计反同质化机制（如隔离上下文、引入噪声扰动、设置多样性约束），否则多 Agent 的"多样性优势"可能只是营销话术。

[来源: elvis(@omarsar0) / DAIR.AI]

RaBitQ 向量量化：数学最优性与 Transformer 推理影响

对 RaBitQ 作者团队的访谈揭示了向量量化领域的重要理论进展。RaBitQ 已被数学证明在渐近意义下达到最优，意味着向量量化的理论收益天花板已被触及，后续增益将主要来自工程优化（硬件适配、数据分布特性、延迟优化）而非算法创新。

该研究的技术路径包括三步：Johnson-Lindenstrauss 变换形式的随机旋转、网格构造、量化。值得注意的是，向量量化正在影响 Transformer 推理架构设计——KV Cache 压缩等核心推理优化策略直接受益于量化技术的理论进展。

[来源: Milvus(@milvusio)]

ParseBench：面向 AI Agent 的文档 OCR 基准测试

LlamaIndex 在 Kaggle 上发布了 ParseBench——首个专为 AI Agent 设计的文档 OCR 基准测试。该基准包含 2,000 页企业文档、超过 167,000 条测试规则，从五个维度系统评估下游 Agent 的解析鲁棒性。基准覆盖了 14 种主流解析方法，包括 GPT-5 Mini、Gemini 3、Textract 和 LlamaParse。

对文档理解研究者而言，ParseBench 填补了 Agent 场景下 OCR 评估的空白：传统 OCR 基准关注字符级准确率，而 ParseBench 更关注解析错误如何传播并破坏下游 Agent 任务，这对设计端到端可靠的文档 Agent 具有重要指导价值。

[来源: LlamaIndex / Kaggle]

二、开源资源

腾讯混元 Hy3 Preview 开源：295B MoE 快慢思考融合模型

腾讯混元团队发布了重建后首个模型 Hy3 Preview，总参数 295B、激活参数 21B，支持 256K 上下文长度。该模型采用混合专家（MoE）架构，并引入了"快慢思考融合"（Hybrid fast/slow thinking）机制，可根据任务复杂度动态调节推理深度。

从学术视角看，Hy3 的值得关注之处在于其训练后重建基础设施的系统性方法：能力体系化（避免"偏科"）、评测真实性（跳出公开榜单刷榜陷阱）、性价比追求（协同优化模型架构与推理框架）。在 FrontierScience Olympiad、IMO Answer Bench 等高难度推理基准上表现突出。完整模型权重和在线 Demo 已在 Hugging Face 开放。

[来源: 腾讯混元]  |  [来源: Berryxia.AI]

腾讯开源 Cube Sandbox：Agent 专用轻量级安全沙箱运行时

腾讯开源了 Cube Sandbox——专为 AI Agent 设计的即时并发安全沙箱运行时，基于 RustVMM 和 KVM 构建。核心指标包括：冷启动 sub-60ms（比现有方案快 2.5-50 倍）、单实例内存开销低于 5MB（节省 6 倍内存）、每个沙箱独立内核实现硬件级隔离、单节点支持上千并发沙箱。

该项目的学术价值在于其为 Agent 安全执行环境提供了工程基准：100% 兼容 E2B SDK，可零代码改动切换。对于研究 Agent 安全、隔离执行和沙箱优化的研究者，Cube Sandbox 提供了一个可部署、可研究的工业级参考实现。

[来源: Berryxia.AI / 腾讯]

Generic Agent：上下文信息密度最大化的极简 Agent 框架

Generic Agent（GA）是一个极简、可自我进化的自主 Agent 框架，核心代码仅约 3,000 行，包含 9 个原子工具，Agent Loop 仅 100 余行。其设计哲学是"上下文信息密度最大化"——不追求上下文长度，而追求每个 token 都为当前决策服务。

该项目半个月内获得 5K star 并登上 GitHub Trending 榜首，其核心创新在于将传统 Agent 系统中冗余的系统提示词和工具描述压缩到最小必要信息量，据称可比 Hermes 等方案节省 10 倍 token。Datawhale 团队已发布完整中文教程，对研究 Agent 架构压缩和提示词效率的学者具有参考价值。

[来源: Datawhale]

三、工程与系统研究

CodeAct in Agent Framework：将多步 Agent 调用压缩为单次代码执行

Microsoft 的 Agent Framework 引入了 CodeAct 支持，允许 Agent 将多步工具调用链压缩为单个可执行代码块，从而在典型工作负载中将端到端延迟降低约 50%、token 使用量降低超过 60%。代码在每次调用时运行于独立的 Hyperlight 微 VM 中，兼顾安全性与隔离性。

从系统研究角度，这项工作揭示了 Agent 执行效率的关键瓶颈不在于模型质量，而在于编排开销（orchestration overhead）。CodeAct 的本质是将 LLM 的推理-行动循环从"多轮对话"模式转变为"批处理代码生成"模式，这对设计高效率 Agent 执行引擎具有方法论意义。

[来源: Microsoft for Developers]

Google DeepMind 探索去中心化 AI 训练基础设施

Google DeepMind 发布了一项关于未来 AI 基础设施的研究方向：探索训练过程不受地理位置、容量限制或芯片类型约束的新型基础设施范式。这意味着未来的大规模模型训练可能突破当前数据中心集中化的架构，实现跨地域、跨硬件类型的分布式协同训练。

该方向若取得突破，将从根本上改变大模型训练的拓扑结构和资源调度策略，对分布式系统、网络拓扑优化和异构计算领域的研究具有深远影响。技术细节已发布于 Google Research Blog。

[来源: Google DeepMind]

多模态生物基础模型在医疗与药物发现中的应用

AWS Machine Learning Blog 发布综述，探讨多模态生物基础模型在药物发现与患者护理中的整合应用。传统方法分别分析组学数据、医学影像、临床试验报告和电子病历，而多模态基础模型通过统一表示学习整合这些碎片化数据流，支持从靶点发现到治疗优化的全链条决策。

该方向是 AI for Science 的重要分支，对从事计算生物学、医疗 AI 和跨模态表示学习的研究者具有参考价值，特别是在如何设计能够处理异质生物医学数据的统一架构方面。

[来源: AWS Machine Learning Blog]

四、趋势观察

Agent 评估范式的转向。 从 ParseBench 到 ICLR Best Paper，研究社区正在从"模型能力评估"转向"系统级 Agent 评估"。单一任务的准确率已不足以刻画 Agent 在真实场景中的表现，研究者需要关注错误传播、长程一致性、上下文漂移等系统级指标。这一趋势呼吁新的基准测试方法论和更贴近实际部署环境的评估框架。

扩散语言模型作为自回归的替代范式。 LLaDA2.0-Uni 等工作的出现表明，扩散架构在多模态统一建模上可能具备自回归模型难以比拟的优势——双向信息交互天然更适合模态对齐，且生成质量可能更稳定。若该方向持续取得突破，语言模型的基础架构可能面临范式迁移。

数据效率 Agent 训练的崛起。 DR-Venus 仅用 10K 数据训练边缘级 Agent 的成果，与 Generic Agent 追求"每 token 最大化信息密度"的设计理念相呼应。Agent 研究正从"堆数据、堆算力"的规模竞赛，转向"效率优先"的精密工程。这一转变可能降低学术研究的准入门槛，使更多团队能够在有限资源下探索 Agent 的前沿能力。
