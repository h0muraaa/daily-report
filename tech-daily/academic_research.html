一、研究动态

模型评测

Qwen 3.7-Max 在多项 benchmark 上接近前沿水平

阿里通义千问发布的 Qwen 3.7-Max 在第三方评测机构 Artificial Analysis 的 Intelligence Index 中获得 56.6 分，较上一代 Qwen 3.6-Max 提升近 5 分。评测方评论称这是阿里「离前沿最近的一次」。在 agentic 任务测试中（编写可自我迭代的 Tetris 机器人），Qwen 3.7-Max 的表现超过了 GPT-5.5 和 Opus 4.7，同时价格仅为 Opus 4.7 的 1/9、GPT-5.5 的 1/2。

这一结果表明中国开源/闭源大模型在推理和 agent 能力上正快速逼近国际顶尖水平，同时保持了显著的成本优势。对学术界而言，Qwen 系列作为可广泛获取的高性能模型，为 agent 研究、代码生成和多模态推理实验提供了重要基线。

来源：Paul Couvert (@itsPaulAi) · 花叔
模型发布

Google 发布 Gemini 3.5 Flash 与 Gemini Omni

Google I/O 2026 上发布的 Gemini 3.5 Flash 在多项 vision 评测中超越了 3.1 Pro，同时推理速度提升约 6 倍。Logan Kilpatrick 在 Roboflow 评估中指出，Flash 在 GDPval 等编程 benchmark 上已达到前沿水平。Google 同时发布了 Gemini Omni，一个原生多模态模型，支持文本、图像、音频和视频的联合推理。

值得关注的是，Google 宣布其 AI 系统每月处理超过 3.2 quadrillion（3.2×10¹⁵）个 token，较之前增长 7 倍。这一规模数据对研究 LLM 推理基础设施和分布式训练的学者具有参考价值。

来源：Logan Kilpatrick · GDPval 评测
视觉推理

Meta 与港中文联合发布 ATLAS：用一个离散词统一视觉推理

Meta AI 与香港中文大学联合提出 ATLAS（A Token for Latent Agentic Semantics），这是一种全新的视觉推理范式。不同于传统方法依赖外部工具或显式中间图像生成，ATLAS 仅使用一个离散词（discrete word）即可统一 Agentic Visual Reasoning 和 Latent Visual Reasoning 两种范式，无需视觉监督信号。

该方法的核心创新在于将复杂的视觉推理任务压缩为单一的离散 token 表示，使得模型能够在不依赖昂贵的外部 API 调用的情况下完成多步骤视觉推理。论文已公开，项目页面和代码也已发布。

来源：机器之心 · 论文：arXiv:2605.15198
端侧 AI

Google DeepMind 详解 Gemini Nano 端侧部署架构

在 Google I/O 2026 的 AI on Android 技术对话中，DeepMind 的 Florina Muntenescu 和 Oli Gaymond 详细介绍了 Gemini Nano 的端侧部署策略。Nano 模型权重约 3-4GB，通过 Android 系统的 AI Core 服务以系统级共享方式提供给所有应用，避免每个应用单独打包模型。前台应用获得最高优先级，后台批处理任务在设备充电时夜间排队执行。

这一架构设计对移动设备上的 LLM 推理研究具有启发意义，特别是在模型共享、优先级调度和能耗管理方面的工程实践，可为端侧 AI 的学术探索提供实证参考。

来源：AI Engineer Summit

纽约大学名誉教授 Gary Marcus 在社交媒体上发声，怀念 AI 领域的「科学与透明时代」，批评当前大型 AI 公司在研究透明度方面的倒退。Marcus 指出，随着巨额资金和地缘政治因素的介入，许多本应公开的技术细节和数据被隐瞒。他特别引用了一项关于 OpenAI 的定量研究，质疑当前行业在模型评估和安全性披露方面的不足。

这一观点在学术界引发共鸣，反映了工业界与学术界在 AI 研究透明性上的持续张力。对于依赖公开信息开展独立验证研究的学者而言，模型训练细节、评估方法和安全测试数据的披露程度直接影响研究的可重复性。

开源生态

DeepSeek 宣布 V4-Pro 永久降价，开源模型使用迎来新拐点

DeepSeek 宣布将 V4-Pro API 价格永久调整为原定价的 1/4（此前为限时 2.5 折，后调整为永久 75 折）。Hugging Face 联合创始人 Thomas Wolf 评论称，开源模型使用加速增长的新拐点正在到来。与此同时，a16z 的数据显示 token 价格持续下降的同时，总 token 消耗量创下新高，呈现出典型的 Jevons 效应。

二、arXiv 论文速递

arXiv · 视频理解

MuKV: 面向长视频流问答的多粒度 KV 缓存压缩

本文针对长流媒体视频问答（Long Streaming Video QA）中视觉 token 数量爆炸和 LLM 推理长度受限的问题，提出 MuKV 方法。通过多粒度 KV 缓存压缩技术，在保留关键视觉信息的同时显著降低内存占用，使流式视频理解在资源受限场景下成为可能。

论文：arXiv:2605.22269 · cs.MM
arXiv · 视频生成

Bernini: 面向视频扩散的潜在语义规划

Bernini 将多模态大语言模型（MLLM）的语义推理能力与扩散模型的生成能力相结合，通过潜在语义规划（Latent Semantic Planning）指导视频生成过程。该方法利用 MLLM 在异构多模态输入上的强语义 grounding 能力，为视频扩散模型提供结构化的生成指导。

论文：arXiv:2605.22344 · cs.MM
arXiv · 可解释 AI

SegCompass: 基于稀疏自编码器的可解释推理分割对齐

现有推理分割（Reasoning Segmentation）方法虽然实现了端到端训练，但其推理过程与视觉感知之间的连接是不透明的。SegCompass 利用稀疏自编码器（Sparse Autoencoders, SAE）探索可解释的对齐机制，使 LLM 的组合推理能力能够透明地连接到视觉感知层面，提升了模型决策的可解释性。

论文：arXiv:2605.22658 · cs.MM
arXiv · 语音量化

Whisper-small 量化方案的系统评估

本文对 Whisper-small 模型的后训练量化（Post-Training Quantization, PTQ）进行了跨库统一评估，系统比较了不同量化策略（INT8、INT4、FP16 等）在多种硬件平台上的 ASR 性能表现。研究发现，量化方案的设计选择（如对称 vs 非对称、逐层 vs 逐通道）对最终识别准确率有显著影响，为边缘设备部署语音大模型提供了实用指导。

论文：arXiv:2511.08093 · eess.AS/cs.SD
arXiv · 语音合成

RobustSpeechFlow: 基于增强对比流匹配的鲁棒 TTS

流匹配（Flow Matching）TTS 在零样本说话人相似度和自然度上表现出色，但仍存在内容保真度问题（如跳词、重复）。RobustSpeechFlow 通过增强驱动的对比流匹配（Augmentation-based Contrastive Flow Matching）训练策略，有效缓解了由不对齐引起的错误，在保持语音自然度的同时提升了内容准确性。

论文：arXiv:2605.22083 · cs.SD/eess.AS
arXiv · 多模态情感

多模态政治演讲 Pathos 分析：声学模型与 LLM 的融合

本文探索声学情感识别模型能否作为政治演讲 Pathos 维度分析的代理指标。研究基于 TRUST 多智能体 LLM 流程，利用德国联邦议会演讲语料库，对比了纯声学模型、LLM 和多模态融合方法在情感修辞分析中的表现。结果表明，LLM 与声学模型的融合能够更准确地捕捉演讲中的情感诉求维度。

论文：arXiv:2605.22732 · eess.AS/cs.SD
arXiv · 音乐生成

实时交互式音乐扩散模型的高效微调

本文针对实时流媒体音乐生成场景，提出了一套高效的扩散模型微调和后训练框架。现有 SOTA 模型依赖离散自回归架构，需要工业级算力才能支持实时交互。该工作通过改进的微调策略和推理优化，使扩散模型能够在消费级硬件上实现交互式音乐共创作，为实时生成式音乐研究开辟了新方向。

论文：arXiv:2605.22717 · cs.SD/cs.MM

四、趋势观察

Agent 评估基准成为新的研究焦点

近期多项评测表明，agentic 能力正成为区分前沿模型的关键维度。从 GDPval（编程 agent 评估）到终端操作 benchmark（如 TerminalBench），再到自主长程任务执行测试，agent 评估正在快速分化。值得注意的是，不同模型在不同 agent 任务上呈现出明显的能力分化：Gemini 3.5 Flash 在视觉 agent 任务上表现突出，Qwen 3.7-Max 在代码迭代 agent 任务上超越部分西方前沿模型，而 Claude 在复杂推理 agent 场景中仍保持领先。

学术界需要关注这一趋势：传统的静态 benchmark（如 MMLU、HumanEval）可能已不足以捕捉模型的实际能力边界，动态、交互式的 agent 评估正成为更可靠的能力探针。

KV 缓存压缩：长上下文推理的工程瓶颈

随着上下文窗口从 128K 扩展到 1M+ token，KV 缓存的内存占用已成为长文本推理的主要瓶颈。MuKV、量化感知 KV 压缩、以及近期多项 KV 缓存优化工作表明，这一领域正成为连接算法创新与系统优化的关键交叉点。对学术研究者而言，KV 缓存优化不仅是工程问题，也涉及注意力机制的深层理解——如何在压缩历史信息的同时保持模型的因果推理能力，本身就是一个值得深入探索的理论问题。

端侧大模型：从「能不能跑」到「跑得好」

Google 的 Gemini Nano 部署策略、苹果的设备端 AI 框架、以及越来越多针对移动端优化的模型（如量化后的 Llama、Gemma）表明，端侧 AI 正从概念验证走向规模化部署。学术研究在此领域的贡献点包括：模型压缩与蒸馏、端侧推理引擎优化、隐私保护的联邦学习框架，以及针对资源受限场景的模型架构设计。随着终端设备算力的持续提升，端侧与云端协同的混合推理范式可能成为下一个研究热点。
