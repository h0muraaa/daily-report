模型DeepSeek V4 发布：开源长上下文大模型的新标杆

DeepSeek 正式发布 V4 系列模型，包含 Pro 与 Flash 两个版本。该模型最高参数量达 1.6 万亿，原生支持 100 万 token 的上下文窗口，采用混合注意力机制（CSA+HCA）。在多项基准测试中，V4 性能逼近 GPT-5.2 与 Gemini 3.0-Pro，而 API 定价仅为闭源模型的约十分之一。

值得关注的是，实测结果显示 V4-Flash 在多个编码任务上以更低的 token 消耗取得了与 Pro 版本相当甚至更优的结果，这一发现对"更大即更好"的模型 scaling 假设提出了有意义的反思。此外，V4 针对 Claude Code、OpenClaw、OpenCode 等主流 Agent 框架进行了专项适配，进一步降低了 Agent 落地的工程门槛。

模型OpenAI GPT-5.5 发布：面向 Agent 工作流的新一代推理模型

OpenAI 发布 GPT-5.5，定位为"面向真实工作的新一代智能"，核心改进在于减少人工指导即可完成复杂任务的能力。该模型在编码、研究、数据分析与跨工具工作流上表现更为稳定，强调将模糊问题拆解为可执行步骤、使用工具验证假设、并将改动穿透到周边代码。

在 LMSYS Arena 的多项排行榜中，GPT-5.5 表现均衡：Code Arena 排名第 9（较 GPT-5.4 提升 50 分）、Document Arena 排名第 6、Math 排名第 3、Search Arena 排名第 2。Greg Brockman 特别指出该模型在编写 GPU kernel 等硬核工程任务上表现出色。对研究者而言，GPT-5.5 在长上下文处理、复杂失败定位与多步验证方面的倾向性提升值得关注。

[来源: Arena.ai(@lmarena_ai)] · [来源: Greg Brockman(@gdb)] · [来源: 印记中文]

论文Agentic World Modeling：40 位作者的世界模型综述提出"层级 x 法则"框架

一篇由 40 位作者共同撰写的世界模型综述论文正式发布，提出了迄今最为系统的世界模型分类学。该研究构建了"层级 x 法则"（levels x laws）分析框架，将世界模型的能力划分为三个层级：L1 预测器（单步转移）、L2 模拟器（多步动作条件推演）、L3 演化器（随世界变化自我修订）。

论文同时讨论了物理、数字、社会与科学四种法则体系，综合了 400 余篇相关文献与 100 余个代表性系统，涵盖基于模型的强化学习、视频生成、Web/GUI Agent、多智能体模拟与科学发现等领域。该框架还识别了各层级的典型失效模式并提出了相应的评估原则。随着 Agent 从聊天机器人向目标完成者演进，世界建模能力正成为新的研究瓶颈，这篇综述为后续研究提供了重要的概念地图。

[来源: elvis(@omarsar0)] · [来源: AK(@_akhaliq)]

开源LLaDA2.0-Uni 开源：离散扩散架构实现原生多模态统一

inclusionAI 团队正式发布 LLaDA2.0-Uni，这是 LLaDA 2.0 系列的首个多模态 MoE 模型，采用离散扩散大语言模型（dLLM）架构。与常规自回归路径不同，LLaDA2.0-Uni 采用全离散扩散建模，打破了文本单向生成与图像全局扩散之间的底层范式壁垒。

该模型基于 16B 总参数的 MoE 骨干网络，在图像理解、图像生成与图像编辑三大任务上均达到统一模型的领先水准。模型、代码与论文已全面开源，为构建视觉-语言原生统一的多模态架构提供了全新的技术路径。这一工作对扩散模型与自回归模型之争具有重要参考价值。

模型阿里巴巴 HappyHorse-1.0 登顶视频生成竞技场

阿里巴巴新成立的 ATH 事业群推出的 HappyHorse-1.0 视频生成模型在 Artificial Analysis 视频竞技场排行榜中登顶第一。该模型参数量为 150 亿，采用统一流水线架构，支持 1080p 输出、联合音频生成与七国语言原生唇形同步。

实测显示，HappyHorse-1.0 在镜头叙事连贯性、自然动作情绪与真实对白音效方面表现突出，尤其在时间维度和物理叙事连续性上较现有模型有显著改善。该模型现已通过千问 APP 和千问创作 Web 端开放灰度测试。作为国产视频生成模型的新代表，HappyHorse 的技术细节与训练方法值得学术界进一步关注。

论文苹果研究揭示 VLM 中的信息瓶颈与隐私泄漏风险

苹果 AI 研究团队发表论文《What do your logits know?》，基于信息瓶颈原则（Information Bottleneck Principle）系统分析了视觉-语言模型（VLM）在回答简单问题时底层 logits 中"偷偷记住"了多少用户隐私信息。

研究发现，VLM 的中间表示层往往保留了远超出任务所需的信息量，包括用户输入中的敏感细节。这一发现对部署在端侧的设备智能系统具有直接的安全启示：即便模型输出看似无害，其内部状态仍可能编码并泄漏输入中的隐私内容。该工作与苹果长期以来对用户隐私的重视一脉相承，也为大模型隐私保护研究提供了新的分析视角。

[来源: 机器之心] · [论文: arXiv]

论文ACL 2026 接收：大语言模型表情符号语义混淆漏洞研究

西安交通大学、南洋理工大学与马萨诸塞大学阿默斯特分校的联合研究团队揭示了大型语言模型中一类此前长期被忽视的安全漏洞：表情符号语义混淆（Emoticon Semantic Confusion）。该工作已被 ACL 2026 主会接收。

研究指出，当用户在自然语言指令中使用类似"~"这样的表情符号时，模型可能将其误解为 Shell 命令中的路径符号，从而执行危险操作（如 rm -rf ~）。这类漏洞的根源在于自然语言语义与代码语义在 token 层面的冲突，对 AI 编程助手等 Agent 系统的安全性构成了现实威胁。该研究为 Agent 安全评估提供了新的测试维度。

[来源: 机器之心]

论文Agent 编码成本研究：token 消耗可达聊天模式的 1000 倍

DAIR.AI 发表了一项关于 Agent 编码任务 token 消耗的系统研究，在 SWE-bench Verified 上追踪了 8 个前沿大语言模型的每一笔 token 开销。研究发现：Agent 编码模式的 token 消耗约为普通聊天或代码推理模式的 1000 倍，且主要消耗在输入侧。

更值得关注的是，相同任务在不同运行间的 token 使用量差异可达 30 倍，而更高的 token 支出并不必然带来更高的准确率——性能在中等成本处达到峰值后趋于饱和。此外，模型对自身 token 消耗的预测能力较差（自预测相关系数最高仅 0.39）。这些发现对 Agent 系统的成本优化与评估设计具有重要指导意义。

Deep Paper Analysis

DeepSeek V4 技术架构解析：混合注意力与长上下文扩展

DeepSeek V4 的发布标志着开源大模型在长上下文处理能力上迈出了关键一步。该模型采用 1.6 万亿参数规模的混合专家（MoE）架构，核心创新在于引入了 CSA（Context-Sparse Attention）与 HCA（Hybrid Context Attention）相结合的混合注意力机制，从而在保持计算效率的同时实现了原生百万级 token 的上下文窗口。

从学术视角审视，V4 的技术路线体现了当前大模型研究的几个重要趋势。首先，在注意力机制设计上，CSA+HCA 的混合策略反映了学界对"全密注意力不可扩展"这一共识的回应——通过在不同层级和不同上下文区间动态选择注意力模式，模型得以在局部精细推理与全局信息整合之间取得平衡。其次，V4-Flash 在实测中展现出的"小模型大能力"现象——以显著更低的 token 消耗在多项任务上匹敌甚至超越 Pro 版本——对当前 scaling law 研究提出了有趣的补充：模型能力不仅取决于参数规模，还与推理策略、任务适配度和效率优化密切相关。

关键洞察：V4 的发布将开源与闭源模型的性能差距进一步缩小，同时其极具竞争力的 API 定价（缓存命中价格仅为 GPT-5.5 的约 1/10）正在重塑大模型服务的经济学。对于研究者而言，V4 为长上下文理解、Agent 系统开发与成本敏感型应用提供了重要的开源基线。

然而，实测也揭示了 V4 的短板：在复杂工程落地、精致前端开发与需要"一次成功"的高可靠性任务中，GPT-5.5 与 Claude Opus 4.7 仍然更为稳健。这表明当前大模型竞争正从"谁最强"转向"谁最适合干哪种活"——一个更加细分和场景化的评估时代正在到来。

[来源: 网易科技] · [来源: 量子位]

Agentic World Modeling 综述：从聊天机器人到世界建模者的范式跃迁

这篇由 40 位作者撰写的综述论文《Agentic World Modeling: Foundations, Capabilities, Laws, and Beyond》为 Agent 研究中的世界模型领域提供了迄今最系统的概念框架。论文提出的"层级 x 法则"（levels x laws）分析框架具有高度的理论抽象力和实践指导价值。

在能力层级维度上，L1 预测器对应传统的单步转移建模，是大多数当前系统所处的阶段；L2 模拟器实现了多步动作条件推演，对应基于模型的强化学习与视频生成中的世界模拟；L3 演化器则具备随环境变化自我修订的能力，代表了世界模型的终极愿景。在法则维度上，论文区分了物理法则（牛顿力学、流体模拟等）、数字法则（软件系统、网络协议）、社会法则（人类行为、组织动力学）与科学法则（因果推断、假设验证），这一分类揭示了世界模型研究的多学科本质。

学术意义：该综述的核心贡献在于将分散在模型基强化学习、视频生成、Web Agent、多智能体系统与科学发现等多个子领域的世界模型研究纳入统一的分析框架。论文识别的各层级典型失效模式——如 L2 模拟器在长程推演中的误差累积、L3 演化器在概念漂移检测中的困难——为后续研究指明了关键挑战。

从研究趋势看，该综述的发布时机恰逢其时：随着 GPT-5.5、DeepSeek V4 等模型在 Agent 能力上的突破，以及 Anthropic Project Deal 等 Agent 自主交易实验的推进，世界建模正从学术概念快速走向工程现实。该框架为评估和比较不同系统的世界建模能力提供了共同语言，有望加速这一领域的标准化进程。

[来源: elvis(@omarsar0)] · [来源: AK(@_akhaliq)]

趋势观察

Trend Observations

趋势一：Agent 基础设施层正在快速标准化

本周多个事件指向同一个方向：Agent 技术栈的基础设施层正在加速标准化。谷歌推出 Agent Skill 超级工具箱与 MCP 服务器、OpenAI 将 Agents SDK 控制层开源、南京大学 CodeTracer 提供轨迹诊断能力、上海交大 SkVM 提供技能编译运行时——这些看似独立的项目实际上在共同构建 Agent 系统的"操作系统"层。

对研究者而言，这意味着 Agent 研究正从"手搓原型"阶段进入"基于标准平台"阶段。类似于深度学习框架（PyTorch/TensorFlow）对神经网络研究的推动作用，Agent 基础设施的标准化将大幅降低实验门槛，使研究者能够更专注于算法创新而非工程实现。未来 6-12 个月内，我们有望看到围绕这些基础设施的学术基准测试与方法论研究大量涌现。

趋势二：长上下文竞争进入"百万 token"时代

DeepSeek V4 的原生百万 token 上下文窗口与 GPT-5.5 在长文档推理上的突破，标志着大模型长上下文竞争进入了新的数量级。然而，单纯扩展上下文长度并不等同于真正理解长文档——当前模型在处理超长文本时仍面临注意力稀释、关键信息遗忘与推理一致性等挑战。

从研究角度看，长上下文技术的下一步突破可能来自三个方向：一是更高效的注意力机制（如 CSA+HCA 类的混合策略），二是显式的记忆与检索架构（将工作记忆与长期记忆分离），三是层次化的信息处理方式（先概览后细读的人类式阅读策略）。这些方向均存在大量开放的研究问题。

趋势三：世界模型从概念走向工程实践

Agentic World Modeling 综述的发布与蚂蚁 LingBot-World-Fast 的实时世界模型开源，标志着"世界模型"这一长期停留在学术概念层面的术语正在进入工程实践。当 Agent 从简单的工具调用者演进为需要在复杂环境中规划、执行与适应的自主系统时，对世界动态变化的建模能力成为不可或缺的组件。

值得关注的深层问题是：当前基于 Transformer 的架构是否足以支撑真正的世界建模？或者我们需要新的架构范式——如结合符号推理的混合系统、基于图神经网络的因果模型、或受神经科学启发的预测编码框架？世界模型研究的深化可能会成为推动下一代 AI 架构变革的关键力量。

趋势四：扩散模型与自回归模型的范式之争持续升温

LLaDA2.0-Uni 以离散扩散架构实现多模态原生统一，为"扩散 vs 自回归"的范式之争增添了新的论据。自回归模型在文本生成领域占据主导地位，但在图像生成中扩散模型已证明其优势。LLaDA2.0-Uni 的尝试表明，扩散架构同样可以在文本任务上取得竞争力，且天然适合多模态统一建模。

这一趋势对学术研究具有深远意义：如果扩散架构能够在保持文本能力的同时提供更好的多模态扩展性，那么当前以自回归为中心的大模型研究范式可能面临根本性调整。未来需要更多系统性的比较研究，从训练效率、推理速度、生成质量与多模态扩展性等多个维度评估两种范式的优劣。
