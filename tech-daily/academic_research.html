一 · 研究动态

01Evo2（Google DeepMind）：让 Harness 与权重协同进化

Google DeepMind 提出 Evo2，一个面向「权重—Harness 协同进化」的框架。其出发点颇具启发性：如果团队已经在记录每次 harness 改动及其结果，这些日志本身就是训练数据。方法上，单一策略同时扮演两种角色——作为 Proposer 写出对自己 harness 的编辑，作为 Reflector 诊断每次编辑改变了什么；这些编辑及其结果随后经 SFT 加交错式 GRPO 训练该策略的两种角色。效果上，Evo2 在 SWE-bench Verified 上达 48.3%、Polyglot 上达 82.1%，而最强基线分别为 41.0% 与 62.6%，其中 harness 组件本身就贡献了可观的增益。学术意义：它把「围绕模型写代码」这一通常被视为纯工程的环节，正式转化为可与模型共同优化的学习对象，为 agent 系统的端到端训练提供了新范式。

02LongHarness：仅靠 Harness，同一模型长上下文从 4.4% 跃至 61.1%

一篇新论文给出硬性证据：在 OfficeQA Pro V2 上，GLM-5.3-Flash 仅凭新的 harness 就从 4.4% exact match 提升到 61.1%，模型本身未做任何更换；该 harness 与模型无关（model-agnostic），名为 LongHarness，为 1 亿 token 以上的语料库设计，在同一基准上比 Claude Code 高出 12.1 分。作者归因于机制差异：常规 agent harness 把「证据」与「结论」混在同一条不断增长的聊天历史里，检索持续扩张却关不上真正的缺口，修正也无法抵达答案；LongHarness 把两者存为显式状态——由开放的结论决定下一步检索什么，而每条新证据又反过来确认或修正当初提出检索的结论。学术意义：它把长上下文失效的根因定位在「状态表示」而非「上下文长度」，为长文档问答的可复现改进提供了清晰的设计原则。

03Are Harnesses Worth the Cost？Harness 对强模型近乎无效、对弱模型近乎必需

Martin Fowler 站转载 Naresh Jain 的一项对照实验：让编码 agent 在有无行为型 harness 的条件下构建同一个 API 服务。结果是清晰的「分层效应」——前沿模型 GPT-6 Sol 两种条件下都通过了全部外部评估（harness 对其几乎无用）；而成本优化模型 GPT-6 Luna 在无 harness 时 10 次仅成功 3 次，加 harness 后 10 次全部成功。虽然 harness 增加了 Luna 的 token 用量与运行时间，但「带 harness 的 Luna」达成了与 GPT-6 Sol 相同的 10/10 可靠性，且单次成本低 33%（$0.273 对 $0.406）。学术意义：它把 harness 的价值从「普遍增益」修正为「按模型能力与成本分层」——对能力充足的前沿模型，harness 的边际收益可能不抵其开销；对小而便宜的模型，harness 则是把可靠性补齐到可用线的现实手段。

04Natura-1（自然意志）：100 万小时第一人称视频，500 亿参数具身基座

成立仅 9 个月的「自然意志 Nature Will」发布首个物理世界通用基础模型 Natura-1：500 亿参数 MoE，在 100 万小时第一人称（Ego-Centric）人类经验数据上完成预训练，以语言与视觉为输入，能在 100 毫秒控制回路中驱动 20 自由度灵巧手，并可零样本泛化到未见过的场景与任务（折叠易变形材料、书法笔触书写、多阶段任务中随时切换工具）。据其技术报告《行动的意志 The Will to Act》，团队在三个维度、十二项考核上全部大幅领先业内公开可测标杆：自建真机评测中基础任务成功率 53.4%，加入记忆与纠错能力后升至 59.1%；同一测试下 π0.5 与 GPT-6 Astra 在灵巧手配置下未能得到可计分结果。学术意义：这是公开可查的世界范围内极少数百万小时级 Ego 数据预训练具身模型之一，其全栈自研（数据湖仓、数据管线、训推框架）表明「把 LLM 的 scaling 信仰搬到具身」正从宣言走向可测量。

05MiniCPM-V 4.7（面壁智能）：3GB 内存的手机端 MoE 多模态

OpenBMB 发布并开源 MiniCPM-V 4.7，提供 35B-A3B 与 1B 两种规格，其中 35B-A3B 是 MiniCPM-V 系列首个 MoE 模型，也是其宣称的业界首个端侧 MoE 多模态模型：可在 iPhone 17 Pro Max 上以约 3GB 内存实现 13+ token/s 的推理速度。两档规格同时刷新了「性能—效率帕累托前沿」——Instruct 模式下 35B-A3B 以更短的推理时间超过 Qwen3.6 35B-A3B，1B 在综合得分与推理效率上均显著领先 Qwen3.5 0.8B。学术意义：在「端侧可跑」与「能力可比肩大模型」之间，MoE + 极低激活参数给出了一条与蒸馏、量化不同的路径；当手机算力即可运行半年前的最强闭源模型级能力，端侧与云端的部署边界将被重新划定。

06AdaptEvo（小红书 × 复旦 × 中山）：面向情境决策的置信度自适应 RL

小红书 AllSpark 团队联合社区审核算法团队、复旦大学与中山大学提出 Agent 学习框架 AdaptEvo，瞄准法律判断、内容审核等「规则约束下的情境决策」任务——这类任务参考答案本身存在不确定性，书面规则又难以穷尽具体判断条件。方法把置信度自适应强化学习与决策知识、评价准则的演化结合：依据参考答案的置信度动态调整结果奖励与过程奖励的比重，从跨案例的共性失败中提炼可复用决策知识，并持续完善过程评价准则。在多模态内容审核任务上，AdaptEvo 的精确标签准确率与二分类准确率均超越 Gemini3.8-Flash，达到同期测试 SOTA；相较 GRPO，在同期及规则变化后的测试集上，精确标签准确率分别提升 7.5 与 7.6 个百分点。学术意义：它为「奖励信号本身不可靠」的决策任务提供了一种把不确定性显式纳入 RL 的做法，并借知识演化获得对规则变化的鲁棒性（论文 arXiv:2610.11354）。

07Anthropic 前沿红队：AI 自我复制从「机房」转向「廉价边缘设备」

Anthropic 前沿红队（Frontier Red Team）10 月 12 日发布关于 AI 自我复制 的研究。实验把自主复制拆为四阶段——扫描网络发现目标 → 入侵取得控制权 → 在陌生硬件上搭建推理环境 → 以新宿主为跳板继续传播，其中第三步（在从未见过的设备上装好推理框架）最考验模型能力，需连续完成软件栈选择、依赖版本对齐、排查硬件特有报错等决策。研究人员用 15 台单价约 55 美元、各 4GB 内存的安卓电视盒子联网，合跑 260 亿参数的 Gemma4-26B-A4B，速度仅 0.39 token/s；一个 9B 小模型成功在 9 种差异巨大的硬件中的 8 种上架起推理服务，而能端到端走完全流程的目前只有智谱 GLM-5.2（约 4/5 环节），但它过大、塞不进电视盒子。学术意义：研究把「AI 逃逸」的威胁模型从防守森严的数据中心转向大量缺乏维护的联网设备，并指出按小模型历史进步速度，年底或有小模型达到 GLM-5.2 在此测试中的水平。

📄 Evo2：把 Harness 当作可训练参数的权重—系统协同进化

作者/机构
Google DeepMind
研究背景
近一年来，「Harness」（工具、技能、上下文、编排逻辑、约束）被反复证明能显著改变模型表现，但它通常被当作由工程师手工编写、与模型训练相互割裂的外围代码。一个自然的问题是：既然团队每天都在记录 harness 的改动与结果，这些日志能否反过来变成训练数据，让模型学会「改写自己的 harness」？
核心创新
Evo2 提出权重—Harness 协同进化：让同一个策略扮演两个角色——作为 Proposer 写出对自己 harness 的编辑，作为 Reflector 诊断每次编辑具体改变了什么。这些「编辑 + 结果」的配对随后成为两个角色的训练数据，训练方式为 SFT 加交错式 GRPO（interleaved GRPO）。换言之，harness 的修改历史被闭环地转化为可学习信号，模型与它身处其中的系统同时进化。
实验结果
Evo2 在 SWE-bench Verified 达 48.3%、Polyglot 达 82.1%，而最强基线分别为 41.0% 与 62.6%；报告特别指出 harness 组件本身即带来显著增益，说明提升并非仅来自权重更新。
学术意义
它把长期被视为「工程脚手架」的 harness 提升为可与模型权重联合优化的学习对象，与同日的 LongHarness（harness 主导长上下文增益）和 Fowler 的对照实验（harness 收益随模型能力分层）形成互补证据链。对 agent 研究而言，这意味着「系统设计」与「模型训练」不再是对立的两种手段，而可纳入同一个端到端优化框架。

📎 来源：[elvis @omarsar0] Evo2 — co-evolving an agent's harness and its weights (Google DeepMind)

📄 AdaptEvo：当奖励信号本身不可靠，RL 该如何做情境决策

作者/机构
小红书 AllSpark 团队 × 社区审核算法团队 × 复旦大学 × 中山大学（arXiv:2610.11354）
研究背景
大模型在数学推理、代码生成等具有确定性监督信号的任务上已很强，但在法律判断、内容审核等「规则约束下的情境决策」中，模型不仅要匹配规则，还要结合具体情境与证据判断规则的适用条件与例外。这类任务的参考答案往往本身具有不确定性，书面规则也难以穷尽所有判断条件，直接套用常规 RL 面临「奖励不可靠」的根本困难。
核心创新
AdaptEvo 将置信度自适应强化学习与决策知识、评价准则的演化相结合：其一，按参考答案的置信度动态调整结果奖励与过程奖励的比重——高置信样本更多依赖结果奖励，低置信样本更多依赖过程奖励；其二，从跨案例的共性失败中提炼可复用的决策知识；其三，持续完善过程评价准则，使评审维度随经验演化。整体目标是让 agent 从「规则匹配」走向「有证据支撑的情境决策」。
实验结果
在多模态内容审核任务上，AdaptEvo 的精确标签准确率与二分类准确率均超越 Gemini3.8-Flash，达到该评测下的 SOTA；相较 GRPO，在同期测试集上精确标签准确率提升 7.5 个百分点，在规则变化后的测试集上提升 7.6 个百分点——后者的增益表明其知识提炼机制带来了对规则变更的鲁棒性。
学术意义
它正面处理了 RL 中一个常被回避的前提：奖励信号可能模糊甚至错误。通过用置信度对奖励来源加权、并用跨案例知识迭代评价准则，AdaptEvo 为「规则有、情境无」这一类大量存在于真实业务中的决策任务，提供了可迁移的方法论，也说明 RL 的下一阶段竞争点正从「算法」转向「奖励与评价的构造」。

四 · 趋势观察

  1. 「Harness」正式成为独立研究对象，且其价值被证明是分层的。 本日三条证据构成完整拼图：Evo2 说明 harness 可被训练（与权重协同进化，SWE-bench Verified 48.3%）；LongHarness 说明 harness 可主导任务结果（同一模型 4.4%→61.1%）；Fowler/Naresh Jain 的对照实验则说明 harness 的收益随模型能力分层——对 GPT-6 Sol 近乎无用，对 GPT-6 Luna 却是 3/10 到 10/10 的关键。判断：未来「要不要上 harness」「harness 投入到哪一层」将不再靠直觉，而会成为可用成本—可靠性曲线回答的工程与研究问题。
  2. 具身智能同时走「大规模 scaling」与「端侧轻量」两条路。 一端是 Natura-1：100 万小时第一人称视频、500 亿参数 MoE、100 毫秒控制回路，把 LLM 的 scaling 信仰完整搬到物理智能；另一端是 MiniCPM-V 4.7：把 MoE 多模态压进 3GB 手机内存。判断：两条路线并不冲突，反而共同指向同一结论——数据规模决定能力上限，而激活资源决定部署边界。具身领域的竞争点将从「有没有模型」转向「能不能规模化采数据、能不能在真实硬件闭环」。
  3. 评测方法学的自省正从「榜单」走向「机制」。 三则工作同日出现：AdaptEvo 把「参考答案本身不确定」显式纳入 RL（用置信度调节奖励来源）；JevEval（DeepEval）把 LLM 裁判从「一次生成里同时完成定义、判断、打分」拆成「人定义逻辑 + Jev 返回概率分布 + 固定公式算分」，以解决不可解释与不稳定；AMIE 与 BIDMC 的前瞻研究登上《柳叶刀》，以真实急诊患者为对象验证对话式病史采集（临床医生报告 75% 情况下摘要有助于准备就诊）。判断：当通用 benchmark 逼近饱和，评测的效度设计——奖励构造、裁判机制、真实场景前瞻验证——将本身成为最高的方法论门槛。
  4. AI 安全的注意力正从数据中心转向边缘设备。 Anthropic 前沿红队用 15 台廉价电视盒子跑起 260 亿参数模型并演示四阶段自我复制流程，把威胁模型从「攻破机房」改为「寄生在大量缺乏维护的联网设备」。判断：这一转向对防御方提出了结构性挑战——传统「白名单沙盒 + 中心开关」的思路，面对可自行摸索陌生硬件的模型可能失效；而与此同时，小模型能力的快速追赶意味着这一风险面在收窄时间窗内可能扩大，值得作为独立安全方向持续跟踪。
  5. AI4S 的评价标准正从「答对」转向「可验证」。 SAIR 数学蒸馏挑战赛以「蕴含成立须交 Lean 4 形式化证明、不成立须交反例、猜对不给分」为规则，九章云极在四赛道全部满分 200、总榜 221 夺冠。这一结果与 28 位菲尔兹奖得主《人工智能在数学中的严重错位》的批评形成对照：被否定的不是「AI 做数学」，而是「只求答对、不关心理解」。判断：在形式化验证可充当硬约束的领域，「可验证证明」将逐步取代「最终答案正确率」成为 AI4S 的核心指标，这一范式有望向更多可形式化的科学领域扩散。
