一 · 研究动态

01Context Language Models：让模型自己管理上下文

来自 Meta、MIT 与华盛顿大学的研究者提出 Context Language Models（CLMs），其核心主张是让语言模型自行管理并编辑自身上下文，而不再依赖外部预定义的摘要、压缩与信息检索机制。据其报告，该思路在性能与计算效率两方面均取得显著提升。学术意义在于：长期以来「上下文工程」被视为 harness 层的工程问题，CLM 把它内化为模型自身的一种能力，若可复现，将直接影响长上下文 agent 与记忆系统的架构设计——外部管理器的角色可能从「必须」退化为「可选的加速器」。

02GitSwarm：面向长程 agent 的复合推理（compounding inference）

Meta Superintelligence Labs 的工作提出用持久记忆式的 Git 协作来改造长程多 agent 推理。GitSwarm 让数百个异步 agent 共享同一个 Git 仓库，每一次贡献都是一次 commit，并记录它建立在哪些更早的 commit 之上（可跨分支）；系统没有中央规划器，每个 worker 自行决定是探索、验证、精炼还是组合已有工作。这一设计针对的是「推理时算力大多被浪费在彼此独立的尝试上、忽略部分成果与失败思路」的问题。实验上，使用 GPT-5.5 Codex workers，GitSwarm 在一次运行中解决了 IMOProofBench-Advanced 的全部 30 道题，并在 ProgramBench 上有相应表现。学术意义：把 test-time compute 从「独立重试」变为「可累积的共享状态」，为多 agent 长程推理提供了具体、可复现的机制。

03HugAgent（EMNLP 2026 Main）：数字分身能泛化到新情境吗？

MIT 等机构研究者的 HugAgent 直指一条日益流行的技术路线——先通过访谈、问卷和个人资料了解一个真人，再让大模型扮演他、预测其回答。真正困难的问题不是「AI 学会了你现在怎么想」，而是换一个此前没问过的新情境，它还能否继续答得像你。研究覆盖 54 名参与者、1,742 个评测项，情境涉及全民医疗、公共监控与住房增密等公共议题，并测试了 GPT、Claude、Gemini、DeepSeek、Llama、Qwen 等模型。相关论文入选 EMNLP 2026 Main。学术意义：为虚拟用户、合成受访者与个性化 Agent 的可行性划出了一条可度量的泛化边界——把「像不像」从印象判断转成了可复现的评测任务。

04陶哲轩「Math 2.0」：证明稀缺时代的终结

菲尔兹奖得主陶哲轩在加州理工学院发表题为 Math 2.0 的演讲，判断人类数学研究范式正被 AI 彻底颠覆——数学建立在「证明稀缺」之上，而那个时代已经结束。他给出数学最先被攻陷的三个学科特性：客观可验证（证明对错有绝对共识，可用 Lean 机械检验）、高度可数字化（无需实体装置或实验复核）、以及海量高质量数据（文献绝大多数已数字化），这三点恰好命中现代机器学习的最强项。这一判断的背景是 OpenAI 于 10 月 6 日在 GitHub 上一次性放出 722 篇内部模型生成的数学手稿，覆盖数论、几何、理论计算机科学、数学物理等 17 个领域，部分附带可由机器检查的 Lean 形式化证明。与此同时，陶哲轩转发了关于 Lean 定理证明器可靠性的讨论，并参与联署质疑署名与优先权问题。学术意义：当「证明」不再稀缺，学术评价的锚点将从「能否证明」转向可靠性、可理解性与形式化验证——这也正是紧随其后的一波争议焦点。

05MiniMax M3：稀疏注意力 + 原生多模态的开放权重路线

MiniMax 的 M3 是一款开放权重模型，具备前沿级的编码与 agentic 能力、100 万 token 上下文窗口与原生多模态。其关键设计与多数「先学文本、后拼视觉」的模型不同：M3 从第一步训练就让文本与视觉共同学习，研究团队表示后加视觉会带来不稳定结果。核心的 MSA 稀疏注意力由两路组成——索引分支挑选哪些块重要、稀疏分支只关注这些块——相较全注意力 prefill 约快 9×、decode 约快 15×；报告指出 DeepSeek 的 DSA 等既有设计不适配分组查询注意力（GQA）与 GPU 内存访问模式。学术意义：原生多模态与高效长上下文的组合，为开放权重社区提供了可直接研究的基座，其注意力设计对「高效长上下文」方向具有方法参考价值。

06NVIDIA Data Designer：教 agent「搜索」而非「凭记忆作答」

NVIDIA 的 Data Designer 展示了如何用合成数据流水线教一个模型学会「搜索」这一行为。其原料是一组对 Wikidata 的游走：相互连接的实体被转化为必须经多次搜索才能回答的谜题；从 50,000 条种子经生成与过滤得到约 7,000 条训练记录，搜索能力由 Tavily 经 MCP 提供。三本 notebook 分阶段构建：先以种子主题、难度采样器、prompt 模板、结构化输出与模型评判生成问答对，再引入工具调用。研究团队把「搜索」作为可复用流水线的一个被教的行为范例来呈现。学术意义：这套范式针对的是训练专用模型时最耗人力的环节——ground-truth 的整理，把「定义正确的 eval」留给人类、把数据构造交给流水线，为 agentic 数据构建提供了可迁移的方法论。

07白泽通境 AWM：从「预测世界」到「溯因理解」的世界模型

由中科大相关团队衍生、成立三个月的合肥公司白泽通境，提出溯因式世界模型 AWM（Abductive World Model），思路可概括为「先预测，再溯因」：AWM 先预测世界接下来会变成什么样，再反过来追问是什么导致了这种变化，并把答案拆成三个问题——谁在场（Entity）、怎么动（Dynamic）、会碰到谁（Relation）。系统由三层构成：理解世界的 AWM、把模型压进机器人的端侧推理引擎 BAIZ-RUN，以及承载它们的计算终端，面向产线机械臂在 5 秒内完成移动中抓取与补料的场景。学术意义：当多数世界模型停留在「看着现在、猜下一秒」的预测层，AWM 尝试补上因果归因这一步，指向具身智能从演示视频走向可验收产线任务的关键缺口。

08Anthropic：多 agent 动态工作流把查错率提到九成以上

Anthropic 公布的一组对照测试为 agent 编排提供了少见的量化证据：在 11.6 万行代码中预埋 70 个 Bug，让单 Agent 与动态工作流各跑三次。结果是单 Agent 最好一次只找出 27 个（不足四成），而 Claude 动态工作流三次都查出 66 个（超过九成）。机制上，主 Agent 接到任务后可自己编写分工程序，安排其他 Agent 分阶段完成，最后汇总结果。学术意义：这不仅是一项工程结果，更提示「评估（eval）」本身正在成为 agent 系统的核心组件——当模型开始自行组织协作，如何可追溯地为每一次协作结果打分，将成为与算法同等重要的研究问题。

二 · 深度论文解读

📄 Context Language Models（CLMs）：把上下文管理内化为模型能力

作者/机构
Meta · MIT · University of Washington（联合研究）
研究背景
长上下文与 agent 场景下，上下文管理长期依赖外部机制：摘要、压缩、信息检索各自独立，由 harness 层负责调度。这些机制与模型本身脱节，既增加系统复杂度，也使上下文策略难以随任务自适应。
核心创新
提出让语言模型自行管理并编辑自身上下文，把「何时压缩、何时检索、保留什么」从预定义的外部流程转为模型可学习、可自主执行的能力，从而在统一框架内协调此前分散的多种上下文操作。
实验结果
研究报告在性能与计算效率两方面均取得显著提升——即在效果不降反升的同时降低了算力开销，直指长上下文推理的成本瓶颈。
学术意义
若结论可复现，CLM 将动摇「上下文治理必须外置」的工程共识，对外部 harness、记忆系统与长程 agent 的架构设计产生连锁影响；同时把「上下文工程」从一个纯工程话题推进为一个可被建模学习的科学问题。

📄 HugAgent（EMNLP 2026 Main）：基于访谈的「数字分身」泛化边界

作者/机构
MIT 等机构研究者（论文入选 EMNLP 2026 Main）
研究背景
从虚拟用户、合成受访者到个性化 AI Agent，一条日益流行的路线是：先通过访谈、问卷与个人资料了解一个真人，再让大模型扮演这个人，预测其在未见过问题上的回答。核心疑问在于：模型学会了「你现在怎么想」，是否就能在新的、此前未被问及的情境下继续「像你」。
方法设计
让大模型基于真实参与者的访谈，预测其在全民医疗、公共监控与住房增密等新情境下的回答。评测覆盖 54 名参与者、1,742 个评测项，模型横跨 GPT、Claude、Gemini、DeepSeek、Llama、Qwen 等主流家族，构成一组跨模型、跨情境的可比基准。
学术意义
把「像不像真人」从主观印象转化为可复现的评测任务，为数字分身 / 合成受访者这一技术路线划出可度量的泛化边界；对 HCI、计算社会科学中以 LLM 替代真人被试的研究范式，提供了必要的效度检验方法。

四 · 趋势观察

  1. RSI 从边缘话题走到年度主线。 Air Street Capital 的《State of AI Report 2026》（244 页，第九份）将递归自我改进（RSI）列为研究篇重头戏——让 AI 参与研发更强的 AI，再由更强的 AI 推进下一轮研发。与之呼应的是 OpenRSI Index 的提问：当模型试图改进另一个模型甚至自身时，谁来提供真实有效的环境反馈？该基准从真实开源研究项目出题，让智能体在已有模型、代码、数据与训练方案之上继续改进。判断：RSI 的瓶颈已从「模型能力」转向「反馈信号的可信度与环境设计」，这将是未来一年最具方法论价值的开放问题。
  2. 学术影响力的天平在向开放权重倾斜。 Zeta Alpha 对 arXiv AI 论文中 21 个模型家族提及的分析显示，中国开放权重家族的份额从 2024 年的 9% 升至 2026 年迄今的 31%，美国开放权重家族从 31% 降至 23%，Qwen 的提及份额已超过 Llama。这一指标衡量的是「研究被引用/被作为基线」的程度，比榜单成绩更能反映方法层面的实际采用。对研究者而言，选基座模型时的默认选项正在发生变化。
  3. 世界模型正从「预测」走向「因果理解」。 过去两年具身智能的世界模型多做一句话的事——看着现在猜下一秒；白泽通境 AWM 则尝试补上「为什么」。宇树、智元、松延动力在 8 天内连发 5 个具身模型，关键词也从「跑跳翻跟头」转向世界模型、感知控制、错误恢复与多任务操作。考试科目换了，验收标准就必须从演示视频与参数表，转向任务完成度与泛化。
  4. 「评估」正在成为系统的核心组件。 无论是 Anthropic 用动态工作流把查错率从不足四成提到九成以上，还是 Weights & Biases 强调「每个分数都能追溯到其条件」的评估流水线，亦或 HugAgent 把「像不像」做成 1,742 项可复现任务，都指向同一件事：当模型能力趋于饱和，可验证、可追溯的评测取代榜单分数，成为区分「刷榜」与「有效科研」的分水岭。
  5. 可验证领域是 AI-for-Science 的前沿，也是它的边界。 数学之所以最先被攻陷，是因为它「自带裁判」——一份 Lean 证明对不对，编译器说了算；而一旦问题转向物质世界（某材料能否在液氮温区超导、某合金高温下是否开裂），没有任何形式化系统能替代一次真实实验。这正是 ChatGPT 共同创造者 Liam Fedus 搭建实体实验室的动因：为 AI 科学家补上互联网给不了的那块数据。研究者的机会，可能恰恰在「可验证」与「需实验」之间的那段缝隙。
