Ti-Audio: 首个多方言端到端藏语语音大语言模型
arXiv:2604.11110v2 · cs.SD

语音大语言模型（Speech-LLM）在主流语言上已取得显著进展，但在低资源、多方言环境中的应用仍面临严峻挑战。该研究提出了 Ti-Audio，首个面向藏语三大方言（卫藏、安多、康巴）的端到端 Speech-LLM。核心创新在于 Dynamic Q-Former Adapter，它可从变长语音中提取关键声学特征，在数据极度稀缺的情况下仍能实现稳定的跨模态对齐。

从学术价值来看，这项工作为低资源语言的语音-文本对齐提供了可迁移的技术范式。传统 Speech-LLM 依赖大规模平行语料，而 Ti-Audio 通过自适应特征提取机制降低了对数据量的依赖，对全球约 7,000 种低资源语言具有方法论层面的参考意义。

Co-Director: 层级多智能体框架用于生成式视频叙事
arXiv:2604.24842v1 · cs.MM

扩散模型能生成高保真视频片段，但将其转化为连贯的叙事引擎仍具挑战。现有智能体流水线通过链式模块自动化这一过程，却因独立手工提示导致语义漂移和级联失败。Co-Director 将视频叙事形式化为全局优化问题，引入层级参数化策略：多臂老虎机全局识别有前景的创意方向，而局部多模态自精炼循环缓解身份漂移并确保序列级一致性。

该方法的关键贡献在于将强化学习中的探索-利用权衡引入生成式视频领域，为长时程视觉叙事提供了形式化框架。这对于自动电影生成、广告创意辅助等应用场景具有直接的研究推动作用。

S-SONDO: 面向通用音频基础模型的自监督知识蒸馏
arXiv:2604.24933v1 · cs.SD

通用音频基础模型虽已在多项任务上取得突破，但 SOTA 模型通常包含数亿参数，推理成本高昂且难以在边缘设备部署。知识蒸馏是模型压缩的成熟策略，但现有音频领域工作主要依赖监督设定，要求教师模型输出类别 logits 或中间特征，这排除了仅输出嵌入向量的自监督模型。S-SONDO 是首个面向通用音频基础模型的自监督知识蒸馏框架，无需标签即可实现有效压缩。

这一工作填补了自监督音频模型压缩的理论空白，对移动设备上的音频理解、实时语音识别等部署场景具有实际价值，同时也为其他模态的自监督蒸馏提供了方法论参考。

MarkIt: 无需训练的可视化标记实现精确视频时序定位
arXiv:2604.25886v1 · cs.MM

视频时序定位（VTG）旨在从未修剪视频中定位查询事件的起止时间戳。尽管视频-语言大模型（Vid-LLM）具备强大的开放世界视频理解能力，但输出精确时序信息仍具挑战，原因在于未修剪视频中显式时序线索稀缺，且查询相关实体难以在视频时间轴上持续跟踪。MarkIt 提出了一种无需训练的框架，将输入视频转换为查询条件化的标记视频，从而增强 Vid-LLM 生成可靠时序定位预测的能力。

该方法的核心优势在于零额外训练成本即可提升现有 Vid-LLM 的时序推理能力，这对视频问答、内容审核、自动摘要等下游任务具有直接的工程价值。

[来源: arXiv cs.MM]
音频感知大语言模型中的不确定性估计：首个系统性实证研究
arXiv:2604.25591v1 · cs.SD / eess.AS

近期音频感知大语言模型（ALLM）在各类音频理解与推理任务上展现了强劲能力，但仍频繁产生幻觉或过度自信的输出。尽管不确定性估计在纯文本 LLM 中已被广泛研究，但在 ALLM 中仍属空白——音频条件生成引入了感知歧义、跨模态 grounding 等额外挑战。该研究首次对 ALLM 中的不确定性估计进行了系统性实证研究，在多个模型和数据集上基准测试了预测熵、长度归一化熵、语义熵、离散语义熵和 P(True) 五种代表性方法。

从学术视角看，这是跨模态 LLM 可靠性研究的重要奠基工作。随着多模态模型在关键场景（医疗诊断、自动驾驶）中的应用加深，量化模型不确定性将成为不可或缺的理论课题。

WhisperPipe: 资源高效的流式架构用于实时语音识别
arXiv:2604.25611v1 · cs.SD

实时自动语音识别系统面临转录精度与计算效率之间的根本权衡，尤其在部署 Whisper 等大规模 Transformer 模型时。现有流式方法要么通过激进分块牺牲精度，要么通过无界上下文累积导致内存成本过高。WhisperPipe 通过三项关键创新实现了有界内存消耗与转录质量的兼顾：混合 VAD 流水线（Silero VAD 结合能量过滤，误激活降低 34%）、带重叠上下文窗口的动态缓冲机制，以及自适应注意力跨度管理。

这项工作对边缘计算场景具有直接意义，其架构设计思路——在保持模型能力的前提下通过输入端优化降低资源消耗——可迁移至其他流式 Transformer 应用。

Mitigating Shared-Private Branch Imbalance via Dual-Branch Rebalancing for Multimodal Sentiment Analysis
arXiv:2604.25179v1 · cs.MM

研究背景：多模态情感分析（MSA）要求整合语言、声学和视觉信号，同时保留各模态特有的情感证据。现有方法主要改进共享-私有分解或跨模态交互，但两者最终都依赖于共享与模态特异证据在预测前的组织方式。

核心发现：作者在标准共享-私有流水线中观察到一个被长期忽视的现象——分支失衡（branch imbalance）：主导共享模式在共享分支中不断累积，产生冗余且带有模态偏置的证据；而重复的交互和刚性对齐逐渐将共享信息泄漏到模态特异通道中，削弱了私有证据的判别力。

方法论创新：论文提出了一种双分支再平衡机制，通过动态权重调整抑制共享分支的过度主导，同时增强私有分支的表达能力。这一发现对多模态学习领域具有范式层面的启示：并非所有模态融合都需要更强的交互，有时减少不恰当的信息泄漏比增强交互更为关键。

Praxy Voice: 零商业训练数据成本实现商业级印度语 TTS
arXiv:2604.25441v1 · cs.SD

问题设定：商业 TTS 系统可产出接近母语的印度语音频，但最佳开源基座（Chatterbox、Indic Parler-TTS、IndicF5）在音韵维度上仍有差距。最广泛采用的多语言基座 Chatterbox（23 种语言）甚至无法对泰卢固语或泰米尔语进行分词。研究核心问题：在不训练新声学解码器且零商业 TTS 训练数据的前提下，将非印度语原生基座提升至商业级输出的最小干预是什么？

技术方案：三项关键组件的巧妙组合：(1) BUPS（Brahmic Unified Phoneme Space），将七种印度文字确定性罗马化为 ISO-15919，使 Chatterbox 的拉丁语分词器能够处理；(2) 仅在文本-Token 预测器上的 LoRA 适配器；(3) Voice-Prompt Recovery 机制恢复语音提示质量。

学术意义：这项工作展示了如何通过符号工程（书写系统转换）而非数据工程来解决低资源语言的 TTS 问题，为资源匮乏场景下的语音技术民主化提供了 elegant 的技术路径。其方法论可扩展至其他非拉丁文字系统。

Audio2Tool: 面向语音工具调用的评测数据集

趋势观察

低资源语言技术正从"数据驱动"转向"架构驱动"： Ti-Audio 和 Praxy Voice 的共同启示在于，面对极端数据稀缺场景，巧妙的架构设计和符号工程（如 phoneme 空间统一、动态特征适配）可以部分替代对海量数据的依赖。这暗示着一个更广泛的研究趋势：在低资源设定下，模型设计的创新权重正在上升。

音频-语言模型的不确定性量化将成为下一个研究热点： ALLM 的幻觉问题在文本 LLM 中已有较成熟的解决方案（如语义熵、P(True)），但在音频模态中几乎空白。随着 Speech-LLM 向医疗诊断、紧急呼叫等高风险场景渗透，不确定性估计将从"可选增强"变为"必要组件"。

开源模型竞赛进入"MoE + 长上下文"阶段： 今日发布的 MiMo-V2.5、Ling-2.6 和 Laguna 均采用 MoE 架构并支持 1M+ Token 上下文。MoE 架构在开源社区的快速普及表明，推理效率优化已不再是闭源模型的专利，开源社区正在形成与商业模型相抗衡的工程能力。

多模态学习的隐忧：共享-私有分解的分支失衡： 多模态情感分析中的分支失衡现象可能并非该领域独有。在视觉-语言模型、音频-文本模型等更广泛的跨模态架构中，是否存在类似的模态主导和信息泄漏问题？这值得作为一个跨领域的系统性研究课题加以审视。
