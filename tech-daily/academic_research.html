LLM 辅助数学证明：5 天内解决 6 个开放 Erdős 问题

研究者 Shouqiao Wang 报告称，他使用 OpenAI 的 GPT-5.6 Sol 模型配合 Codex 工作流，在 5 天内解决了 6 个此前悬而未决的 Erdős 问题。该工作流的关键特征在于，它并不依赖深厚的数学先验知识，而是强调模型在形式化推理、模式搜索和验证循环中的自动化能力。Wang 已将每个问题的证明 PDF、LaTeX 源文件、提示词以及部分计算实验的 Python 脚本开源；其中两个问题已完成 Lean 形式化证明，其余仍在推进中。

这一案例对数学研究社区具有重要意义：它不仅展示了当前模型处理组合数学和数论开放问题的潜力，也为"AI 辅助猜想提出—证明生成—形式化验证"的完整研究管线提供了可复制的模板。研究者可以借此评估类似方法在自己领域的可迁移性，并思考形式化验证在降低错误证明风险中的作用。

Meta 开源 Brain2Qwerty v2：非侵入式脑机接口语句解码取得突破

Meta 开源了 Brain2Qwerty v2，一套基于脑电图（EEG）或脑磁图（MEG）信号的非侵入式脑机接口系统，用于将受试者脑中的完整语句解码为键盘输入。系统采用三阶段深度学习模型，根据脑磁信号预测输入字符。在标准评测中，Brain2Qwerty v2 的平均单词识别准确率达到 61%，而此前其他非侵入式方案的基准约为 8%；与 EEGNet 基线相比，字符错误率降低了约 2.5 倍。

研究团队还发现，MEG 信号显著优于 EEG（字符错误率 29% 对 65%），并且解码准确率随数据规模呈对数线性增长。为了推动开放脑科学研究，Meta 已公开模型代码和训练数据。这项工作为脑信号到语言的端到端解码提供了新的实验证据，也为神经科学、神经工程和人机交互领域开辟了可复现的研究基础。

腾讯开源三款具身基座模型并揭示"三层脑"架构

在 WAIC 2026 期间，腾讯 Robotics X 实验室正式开源三款具身基座模型：Hy-Embodied-VLM-1.0（空间与场景理解）、Hy-Embodied-RxBrain-1.0（认知规划与未来状态想象）、Hy-Embodied-VLA-0.5（高层目标到连续动作的转化）。团队指出，通用智能体框架直接移植到机器人上效果不佳，因为机器人面对的世界存在多个时间尺度——高层任务理解可接受秒级延迟，而碰撞、失衡等身体反应需要毫秒级响应。

为此，腾讯设计了原生智能体框架 TairosAgent 和持续在线的具身智能体 Apexio，将上层任务交互的响应时间压缩到 2—3 秒。该"三层脑"架构为具身智能研究提供了一个清晰的系统设计原则：感知、认知与运动控制应在不同频率上协同，而非简单堆叠大模型。这对机器人学习、强化学习和多模态感知研究者均具有参考价值。

新智具身联合复旦发布 3 万小时触觉数据集与系列模型

上海新智具身智能科技有限公司（NeoteAI）与复旦大学可信具身智能研究院联合发布了系列触觉研究报告与模型，核心贡献是构建了一个规模达 3 万小时的统一触觉语料库。该项目首先解决了触觉领域长期存在的数据格式"方言"问题——不同传感器输出的凝胶形变图、电容矩阵、六维力向量等数据难以在同一模型中融合。通过统一表示，团队展示了机器人在煮面、调饮料、收纳整理以及工业装配等精细操作中的能力。

触觉通常被视为视觉之外的辅助模态，但这项研究表明，接触瞬间的力反馈、滑移感知和边缘检测可能是机器人跨越"最后一厘米"的关键。相关数据和模型将进行开源，有望为具身智能、机器人操作和物理仿真社区提供新的评测基准。

EvoX：蜂群式自进化多智能体系统

针对多智能体协同中的"无限智能体死循环"和上下文信噪比下降问题，EvoMap 团队提出了 EvoX。与常见的"主从团队"架构不同，EvoX 采用蜂群式自进化机制：每个 Agent 独立执行任务并持续进化，最终像自然蜂群一样自主汇合。根据报道，该系统在长周期任务完成率上显著提升，同时成本可低至 1.95 美元。

从研究角度看，EvoX 的核心价值在于重新定位了多 Agent 系统的瓶颈：关键不在于增加 Agent 数量，而在于设计有效的角色协作、多轮汇合和组织涌现机制。这与当前学术界对"去中心化协调"和"群体智能"的关注相契合，也为评估多 Agent 系统提供了除准确率之外的成本和鲁棒性维度。

InfraNet：以红外为主导的夜间目标检测新框架 | ECCV'26

北京航空航天大学等机构提出了 InfraNet，一种面向高效红外目标检测的质量感知 RGB 引导框架，已被 ECCV 2026 接收。传统 RGB-IR 多模态检测方法通常假设两种模态始终互补，但在低照度、雾天或强逆光场景下，RGB 图像可能严重退化，反而将噪声引入红外表示。InfraNet 采用 IR-centric 设计，将红外分支作为主路径，RGB 分支仅作为训练阶段可靠性受控的辅助信号，并通过 QualGate 模块自适应抑制不可靠的 RGB 引导。

该方法同时支持 RGB-IR 双模态推理和 IR-only 单模态部署，在 LLVIP、FLIR-Aligned、M3FD 和 DroneVehicle 四个基准上取得了有竞争力的结果。论文提出了一个值得深入研究的模态融合原则：辅助模态的贡献应被显式量化并可控，而不是被默认信任。

MonkeyOCRv2：重建作为文档视觉记忆

研究背景： 文档视觉语言模型通常被理解为"视觉编码器 + 大语言模型"，但视觉编码器的重要性在研究和实践中常被低估。现有工作倾向于复用 CLIP、DINO、SAM 等通用视觉模型作为前端，认为后续的语言模型足以弥补前端表示的不足。

核心创新： MonkeyOCRv2 的核心论点是"重建可以成为文档视觉记忆"。研究团队设计了一种新的视觉-文本基础模型，通过重建任务让视觉编码器保留文档页面的完整证据，而不是仅仅压缩视觉特征。在受控实验中，研究者将语言模型（Qwen3-1.7B）、训练数据、优化设置和解码流程全部固定，唯一变化的是视觉编码器；结果显示，在 8 个文档理解基准上，MonkeyOCRv2-B 取得 57.2 分，领先最强对照 OpenVision-B 达 13.2 分。

实验结果与学术意义： 13.2 分的差距表明，在 LLM 开始理解和推理之前，视觉编码器已经决定了它能拿到多少可靠证据。这一发现对文档 AI、多模态大模型和 OCR 研究均有启示：针对特定领域设计视觉前端可能比单纯扩大语言模型规模带来更高的边际收益。此外，重建任务作为自监督预训练目标在文档领域的有效性也值得进一步探索。

Brain2Qwerty v2：非侵入式神经解码的规模化路径

研究背景： 脑机接口（BCI）长期面临侵入式与非侵入式之间的性能鸿沟。植入式电极能够提供高信噪比的神经信号，但手术风险和成本限制了其应用；非侵入式 EEG/MEG 虽然安全，但解码完整语句的准确率一直停留在较低水平。

核心创新： Brain2Qwerty v2 采用三阶段深度学习模型，将 EEG 或 MEG 信号映射为键盘输入字符。研究设计的一个重要细节是，数据采集时受试者先记住一句话，然后再通过键盘输入，这使得模型能够利用与语言产生和动作准备相关的神经信号。Meta 进一步发现，MEG 的平均字符错误率（29%）显著低于 EEG（65%），说明磁信号在空间分辨率上具有明显优势。

实验结果与学术意义： 平均单词识别准确率达到 61%，是其他非侵入式方案 8% 基线的近 8 倍；并且解码准确率随数据规模呈对数线性增长。这一"数据缩放定律"的发现尤为关键：它意味着非侵入式 BCI 可能不需要依赖传感器技术的革命性突破，仅通过持续扩大数据规模就有可能逼近植入式方案的性能。研究已开源模型代码和训练数据，为神经科学、机器学习和辅助技术研究提供了宝贵的公共资源。

上下文工程正在从"多约束"转向"少即是多"

Anthropic Claude Code 团队近期披露，他们面向 Claude Opus 5 和 Fable 5 删除了超过 80% 的系统提示词，而编码评测未出现可测量的性能损失。这一发现与 Jerry Liu 等研究者的观察一致：过度详细的规则可能限制模型基于上下文做出独立判断的能力。研究者应重新审视 Agent 和工具接口的设计原则——清晰的接口描述和高质量的参考材料可能比厚重的规则手册更有效。

Agent 评测与基准的可信度危机

Gary Marcus 等人指出，训练到特定基准不等于获得通用能力；Kun Chen 也观察到 Opus 5 在公开基准上表现优异，但在实际长程任务中未必优于 GPT-5.6 Sol。这表明，学术界需要更多基于私有数据集和真实任务构建的领域特定评测，而非依赖少数公开排行榜。如何设计能够抵抗"针对性训练"和"数据泄露"的鲁棒评测，将成为 Agent 研究的方法论核心。

"开放权重" debate 背后的研究治理问题

英伟达、微软、Meta 等 25 家科技企业联署公开信支持开放模型，引发了关于蒸馏、开源责任和竞争格局的激烈讨论。Jensen Huang 认为蒸馏本质上是学习，AI 之间相互学习将成为常态；而反对者则质疑企业是否真正愿意开放其核心基础设施。对学术界而言，这一 debate 的实际影响在于：开放权重模型的可用性、可审计性和可复现性将如何塑造未来几年的研究生态。

具身智能从"单一大模型"走向"多时间尺度系统架构"

腾讯的"三层脑"架构和新智具身的触觉数据底座共同指向一个趋势：具身智能研究者正在放弃"用一个端到端大模型解决所有问题"的简单范式，转而构建感知、认知和运动控制分层协同的机器人系统。这一方向与经典机器人学中的层次化控制理论相呼应，也为强化学习、模仿学习和物理仿真研究提供了新的结合点。
