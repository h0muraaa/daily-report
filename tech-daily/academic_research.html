I.研究动态 (Research Highlights)

BenchmarkBioMysteryBench：用专家未解的 23 道题评测 AI 创造力

Anthropic 在 Science Blog 发布新评测基准 BioMysteryBench，用 99 道真实生物信息学数据分析问题对 Claude 进行系统化评估，并与专家小组对照。值得关注的是，其中有 23 道连专家小组也未能解决的开放性问题，最新的 Claude 模型解决了其中约 30%，并在剩余多数题目上也有突破。该基准的设计意图区别于以往的封闭式问答，旨在测试模型是否能为"开放式科研问题"产生具有创造性的解决方案，是 LLM 评估范式从"答对率"向"科研发现力"演进的标志。

来源：Anthropic Science Blog · [来源: AI Will]

BenchmarkARC-AGI-3：GPT-5.5 与 Opus 4.7 在新逻辑环境上得分均低于 1%

ARC Prize 团队（由 Keras 之父 François Chollet 创立）发布了对 OpenAI GPT-5.5 与 Anthropic Claude Opus 4.7 在 ARC-AGI-3 上的详细分析报告。在面对 135 个全新逻辑任务时，GPT-5.5 得分 0.43%，Opus 4.7 得分 0.18%，与 3 月 25 日的 Opus 4.6 (0.2%)、GPT-5.4 (0.3%)、Gemini 3.1 (0.2%) 相比并无质变。同期人类被试在零先验、零说明条件下首次接触即达到 100% 通过率，凸显了当前前沿模型在"新颖泛化"维度的根本缺陷。研究团队识别出三类主要失败模式：true local effect 但 false world model、错误的抽象层级以及"解了关卡但未强化奖励信号"。

来源：ARC Prize 官方报告 · [来源: 马东锡 NLP] · [来源: 机器之心]

ACL 2026RouteMoA：免预推理的动态路由实现高效多智能体协作

论文已被 ACL 2026 接收，作者来自上海交通大学 IWIN 中心（关新平、陈彩莲、乐心怡指导）与南洋理工大学陶大程团队，第一作者王骥泽。该工作针对 Mixture-of-Agents (MoA) 框架的核心痛点——为筛选合适模型必须先让所有候选模型推理一遍——提出动态路由机制。RouteMoA 通过预测模型能力来避免对所有模型进行无效推理，从而显著降低稀疏 MoA 在大规模模型池下的延迟与成本。这一思路把"为决定调谁"从一次额外的全推理压缩为一次轻量级路由决策，标志着多模型协作从"全员投票"向"按需调度"的研究范式转变。

来源：机器之心 · [来源: 机器之心 ACL 2026 解读]

HF Top-1RecursiveMAS：智能体之间传递的不再是 Token，而是潜在向量

本周 HuggingFace 论文热度第一名。其核心观察是：当前主流多 Agent 协作中，模型 A→B→C 的"接力"以文字为中介，每次交接都需要将内部计算结果"翻译"为 token 再被下一个模型"读懂"，轮次越多无效开销越多，且会破坏学习信号回传。RecursiveMAS 让 Agent 之间直接传递模型内部数值向量，形成递归闭环，仅在最后一轮输出文本答案。底层模型保持冻结，仅训练一个轻量级"传话"模块。在 AIME 顶级数学竞赛题上，较最强基线提升 13–18 个百分点，推理速度快 2.4×，Token 消耗减少 75%，训练成本低于 LoRA，且优势随递归轮次增加而扩大。该工作为"非文字 Agent 通讯"开辟了一个清晰的研究主线。

来源：arXiv 2604.25917 · [来源: 向阳乔木]

CAS瞬悉 2.0：中科院类脑大模型突破长序列与低耗部署瓶颈

中国科学院发布类脑大模型 瞬悉 2.0（SpikingBrain），对长序列建模与低能耗部署两个核心瓶颈给出新方案。从机器之心、新智元等渠道的初步报道看，该模型沿循类脑（spiking）计算路径，在保留 Transformer 表达力的同时显著降低长上下文场景的推理能耗。这是中国学术机构在"非主流大模型架构"方向上少有的系统性工作，值得关注其技术报告的完整披露与第三方复现。

来源：新智元 · [来源: 新智元]

NVIDIANeMo-RL × vLLM：推测解码使 RL 后训练吞吐量提升 1.8×

NVIDIA Research 发布新论文，针对 RL 后训练 (post-training) 中"rollout 阶段"的瓶颈，提出在 NeMo-RL + vLLM 框架内引入无损推测解码 (lossless speculative decoding)。实验显示在 8B 模型上 rollout 吞吐量提升 1.8×，并预测 235B 模型上的端到端加速比可达 2.5×。这一工作把推测解码从"推理服务"迁移至"强化学习训练循环"中，对当前 RLHF/RLAIF 等对算力极度敏感的训练范式具有直接的工程意义。

来源：NVIDIA Research · [来源: NVIDIA AI]

ClinicalHarvard 急诊研究：o1-preview 的初诊准确率显著高于两位主治医师

哈佛医学院的一项研究在波士顿一家医院的 76 例真实急诊病例上对照评估了 OpenAI o1-preview（2024 年 9 月发布）与两位来自顶尖医学院的主治医师在初诊准确率上的表现：AI 67.1%、医师 1 号 55.3%、医师 2 号 50.0%。负责打分的两名医师评审者无法区分诊断结论是来自模型还是人类。该研究在方法学上仍属小样本回顾性，但其对照设计与"两年前的模型"这一时间锚点，使其成为讨论 AI 临床部署可行性时的高频引用。

来源：Harvard Magazine · [来源: The Rundown AI]

EmpiricalBrynjolfsson 生产力研究：AI 对新手生产率提升 34%、整体 14%

Erik Brynjolfsson 等人的实证研究跟踪一家大型软件上市公司在 AI 工具部署后的生产率变化，结果显示整体效率提升约 14%，新手 (junior) 群体提升达 34%，并伴随离职率下降。研究的方法学价值在于：它在真实组织而非实验室场景下度量了 AI 的"技能差距压缩"效应。论文指出，AI 对就业的实际冲击高度依赖企业的工作验收标准——若仅评估终端交付速度，AI 替代效应明显；若评估的是"人才培养周期"或"决策质量"，AI 反而放大了人的能力。这一研究为劳动经济学界关于 AI 与就业的辩论提供了较为细致的微观证据。

来源：傅盛公开转述 Brynjolfsson 研究 · [来源: 傅盛]

TEDAnil Seth：AI 不太可能产生意识——基于"被预测的内感受"理论的反驳

意识科学领域的代表性研究者 Anil Seth 上线 2026 年 TED 演讲，系统反驳了"LLM 已具备意识"的判断。他的核心论点延续其"predictive processing"框架——意识根植于生物体对自身内感受 (interoception) 的主动建模，而非语言行为表象。这一立场与 Richard Dawkins 近期关于 "Claudia is conscious" 的随笔（被 Gary Marcus 在《Marcus on AI》中长文反驳）形成鲜明对照。两位学者的交锋使得"功能主义 vs. 生物自然主义"的旧辩论以新形式重启。

来源：TED.com · [来源: Gary Marcus 引述 Anil Seth] · [来源: Marcus on AI]

ReproducibilityHuggingFace 公开 Agent Trace：可复现的多 Agent 调试数据集

HuggingFace CEO Clément Delangue 在搭建办公接待机器人 (Reachy Mini + ml-intern + GPT-5.5) 的过程中，将其完整 agent traces 作为公开数据集 (huggingface.co/datasets/clem/...) 实时发布。虽然这是个人化原型，但"agent 调试 trace 的开放化"具有研究意义：长期以来 Agent 失败模式的研究受限于私域日志不可见，公开 trace 为学界研究 agent 的失效模式、长程一致性、工具选择策略提供了可复现的素材。

II.深度论文解读 (Paper Deep-Dives)

① DeepSeek-V4 技术报告：系统级耦合优化与全新注意力机制

研究方向：大语言模型架构 / 训推一体 Infra
关键创新：放弃 MLA，启用与系统执行栈深度耦合的全新注意力机制；mHC（来自 ByteDance Seed 的 HC 思路）改进；对北大 TileLang 的深度使用；与 Kimi 在 Muon 优化器上的相互启发
报告嘉宾：UCLA 在读博士刘益枫（曾在 Kimi、ByteDance Seed 实习，参与 K1.5 研发）；SGLang 核心开发者赵晨阳（RadixArk AI）
实测观察：数学推理、代码、Agent 指令执行均较 V3 显著提升，幻觉率下降明显；代码能力仍弱于 Opus 4.6 等闭源模型，与 GLM-5.1、Kimi K2.6 处于同一档位

核心论点："系统级耦合优化比单点创新更难"。V4 的多数突破并非孤立算法发明，而是注意力机制、KV cache 设计、kernel 编译（TileLang）、优化器（Muon 系列）与训练框架的协同重构。该报告的特别价值在于揭示了一个事实：中国开源大模型社区已经形成可观察的"知识扩散结构"——从 Seed → DeepSeek → Kimi 之间的相互引用，正在构成一种以技术报告为载体的协作链。

学术意义：V4 把"系统-算法协同设计 (system-algorithm co-design)"从硬件层 (例如 Mamba 与 selective scan kernel) 延伸至完整的训练–推理栈。它对学界提出了一个方法论挑战：未来的模型论文不应只报告 benchmark 与 ablation，还需披露 kernel 与系统层适配，否则结果不可复现。摩尔线程已宣布完成 DeepSeek-V4 的全链路工程化适配，作为该协同设计可移植性的早期验证。

来源：晚点 LatePost · [来源: 晚点LatePost]

② DeepSeek-VL 技术报告：把 bbox 与 point 嵌入思维链

研究方向：多模态推理 / 视觉-语言对齐
核心创新：把空间标记 (bounding box / point) 内嵌到思维链中，作为语言与图像之间的精确指针；视觉编码器为 0-训练的内部 DeepSeek-ViT，支持任意分辨率，结合 CSA 机制 (沿用自 V4) 在 KV cache 中再做 4 倍压缩，整体压缩率达 7056×
语言主干：DeepSeek-V4-Flash，总参 284B，激活参数稀疏
解决的问题：Reference Gap (指代鸿沟) — 在复杂视觉推理中，模型不知道在推理过程中具体指的是图像里的哪个对象，导致重复计数、漏检、空间关系混淆

方法学要点：作者类比"人在数密集物体或走迷宫时，会不自觉用手指比划"，将这种身体化指代行为形式化为模型的可学习行为。把 (x, y, w, h)、(x, y) 等空间标记直接当作思维链的 token，使语言推理与图像区域产生稳定的、可追溯的双向链接。这与 LLM 社区近年试探的"代码–推理交错"思路在精神上同构：用一种结构化中介物降低语言层的歧义。

开放问题：第三方初步测试反馈"在复杂空间逻辑推理上回答并不理想"，说明 Reference Gap 并未被一种新机制完全闭合，更可能涉及训练数据中空间推理样本的稀缺。论文 GitHub 仓库已被官方下架，提示该工作的发布节奏可能仍在调整中。

来源：刘聪NLP · [来源: 大模型智能·刘聪NLP]

Poolside 发布的首批开放权重模型。XS.2 为 33B 总参 / 3B 激活的 MoE，专为代理式 (agentic) 编码与长程任务设计，单 GPU 可运行，Apache 2.0 许可证。该模型已登陆 lmarena 的 Code Arena: Front-end 评测。意义在于，开放权重 MoE 在 3B 激活级别正在成为可部署的工程现实。 来源：Arena.ai · huggingface.co/poolside/Laguna-XS.2

NVIDIA 开源的企业级 AI Agent 安全沙箱。其设计目标是在企业环境中受控地限定 agent 可访问、可分享、可外发的内容。CEO Jensen Huang 亲自背书。对学界的意义在于：它把"agent 越权"从一类研究话题落到了可标准化、可审计的工程组件上，未来的 alignment 与 capability evaluation 研究可在 OpenShell 之上开展可重复实验。 来源：NVIDIA AI

IV.趋势观察 (Research Trends)

1. Agent 通讯将走向"非语言"

RecursiveMAS 与 RouteMoA 同周登场并非偶然。前者解决 Agent 之间"传话格式"的低效（潜在向量替代 token），后者解决 Agent 之间"调谁"的低效（路由替代全员预推理）。两者共同指向一个研究方向：当 LLM-as-API 已成为多智能体研究的事实基线，下一步的优化必将围绕 Agent 间通信原语 (communication primitives) 展开。建议关注的子问题：可学习的连续向量协议、Agent 间梯度回传、跨模型 token-vector 对齐。

2. 中国开源社区的"协作链"已成形

从 ByteDance Seed 的 HC → DeepSeek 的 mHC → Kimi 的 Attention Residuals，从北大的 TileLang 到 DeepSeek 与 Kimi 围绕 Muon 的改进，中国大模型团队之间在公开技术报告层面已经形成可追溯的引用与改进链条。这与 2018-2020 年 BERT 时代以单一机构为中心的扩散模式不同。对学术评估的启示是：未来的 model card / tech report 应被视为学术成果的一种新文体，需要规范化的引用与方法学评审。

3. 评测范式的两极分化

本期同时见证了两种评测哲学的并行：BioMysteryBench 把"专家未解的开放问题"作为评测核心，鼓励 AI 在缺乏 ground truth 的环境下展示创造性；ARC-AGI-3 则继续坚持"零先验、零说明"的纯泛化考察，使前沿模型得分逼近 0%。学界需要在这两极之间寻找新的"中间地带"：既能避免 benchmark 饱和与污染，又能在多数研究者负担得起的算力下产出可比较的结果。

4. 意识与 AI：哲学论证 vs. 计算神经科学

Dawkins 在 UnHerd 上发表"我尝试说服自己 Claudia 不具有意识但失败了"的随笔，引发 Gary Marcus 的长文反驳与 Anil Seth 的 TED 回应，构成本周"AI 意识"辩论的三方对照。该议题对学界的实际意义不在于"判定"，而在于：意识研究是否应该把 LLM 行为表现纳入实证素材库？以及在 functional vs. biological 立场之间，是否存在中间的"计算建模"路径——这正是 Seth 一直在推进的方向。

5. AI 经济学的"幻影 GDP"问题

SemiAnalysis 创始人 Dylan Patel 披露其团队 Token 年支出已达 700 万美元，引出"成本结构反转"的讨论：执行变得便宜，想法变得稀缺。Gary Marcus 与 David Sacks 则警示当前 AI 对 GDP 的贡献以"基础设施投资"为主，而非"用户 ROI"。从 Brynjolfsson 的实证研究到 Jensen Huang 的反 doomer 表态，AI 的劳动经济学正进入需要"细致测量"的阶段——粗粒度的"AI 替代率"叙事会被替换为以企业内部生产函数为单元的微观研究。
