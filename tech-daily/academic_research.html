大模型开源权重

Qwen 3.8：2.4T 参数开放权重模型逼近闭源前沿

阿里巴巴通义千问团队宣布 Qwen 3.8 即将发布并开源，该模型拥有 2.4 万亿参数，官方称其性能仅次于 Claude Fable 5，预览版 Qwen3.8-Max-Preview 已率先上线 Token Plan、Qoder 及 QoderWork。若其实际表现与宣称接近，这将是开源社区首次在万亿参数规模上逼近当前最强闭源模型的门槛，为后续关于模型缩放定律、稀疏架构与开放权重安全性的学术研究提供了重要样本。

第三方早期测试显示，在 AICodeKing 的 KingBench 基准上 Qwen 3.8 Max Preview 获得 65/80 分，位列第二，仅次于 Fable 5；在前端、Three.js、SVG、游戏与数学等任务上表现尤为突出。这一结果若在大规模可复现评测中得到验证，将显著改变开源与闭源大模型之间的能力边界认知。

大模型多模态

Kimi K3：2.8T 参数、百万上下文与原生视觉理解

月之暗面发布新一代大模型 Kimi K3，参数规模达到 2.8 万亿，支持 100 万 token 上下文窗口并原生集成视觉理解能力。该模型将参数规模、长上下文与多模态统一作为核心卖点，为研究长程推理、跨模态信息融合以及长文档理解提供了新的实验对象。

在 Cline 团队的真实 Bug 修复对比中，Kimi K3 与 Claude Fable 5 均能成功修复同一问题，但 K3 耗时 12 分钟、调用 34 次工具，Token 消耗约 120 万，约为 Fable 5 的 1.7 倍；其优势主要在于单价更低。这一结果提示学术界关注：当模型规模持续放大时，推理效率、工具调用策略与成本结构如何与能力同步优化。

具身智能开源模型

面壁智能开源 MiniCPM-Robot 系列具身模型

面壁智能在世界人工智能大会（WAIC）上发布并开源其首个具身智能系列模型 MiniCPM-Robot，包含操作模型 MiniCPM-RobotManip（1.5B）和跟踪导航模型 MiniCPM-RobotTrack（0.9B）。Manip 模型面向通用 VLA（Vision-Language-Action）任务，可直接在端侧部署并根据视觉与语言指令输出机器人动作；Track 模型与南京大学合作，原生适配宇树 Go2 Edu，支持开放环境下的零样本指令跟随。

该系列的一个核心学术动机是解决具身智能中的时序记忆问题：现有模型在缺乏外部工具的情况下难以可靠计数或保持动作历史，导致如"按按钮五次"这类简单任务频繁失败。面壁团队将端侧小模型、推理优化与机器人控制相结合，为低参数具身模型在真实环境中的长程任务执行提供了新的研究基线。

Agent 框架训练方法

上海 AI Lab：让 Harness 自进化的训练框架

上海人工智能实验室提出了一种新的训练范式，使原本用于约束大模型行为的 Harness（控制外壳）自身也能够被搜索、验证和迭代。研究团队在不更换底层模型的前提下，通过优化 Harness 实现了 104% 的效果提升。这一工作的学术意义在于，它将 Agent 系统中"模型能力"与"控制代码"之间的边界进一步模糊化，提示 Harness 本身可能成为可学习、可优化的对象。

随着大模型能力的快速提升，Harness 中编码的"模型做不到什么"的假设可能迅速过期。该研究提供了一种机制，使系统能够根据模型当前能力与任务需求自动调整控制策略，从而减少人工规则维护成本并提升 Agent 在复杂任务中的自适应能力。

同行评审LLM 校准

顶会评审"抽卡"困境：华中科技大学提出 LLM 校准机制

面对 NeurIPS、ICLR 等顶会投稿量逼近两万篇的规模，同行评审中评分尺度不一致的问题愈发突出。华中科技大学李钦宾研究团队在 ICML 2026 Position Paper 中提出了一种基于大语言模型的校准机制，旨在统一审稿打分尺度，减少因审稿人主观差异导致的"审稿抽卡"现象。

语音处理开源模型

OpenMOSS 开源 MOSS-Transcribe-Diarize-0.9B 长音频转写模型

OpenMOSS 团队开源了 MOSS-Transcribe-Diarize-0.9B，一个 0.9B 参数的多人长音频转写模型，支持 128K 上下文，可一次性处理约 90 分钟音频而无需切片拼接。该模型采用 Whisper-Medium 编码器与 Qwen3 风格解码器的端到端架构，将自动语音识别、说话人分离与时间对齐整合为单一自回归任务。

具身智能VLA时序记忆

解读：MiniCPM-Robot 如何用小模型解决具身"数数"问题

具身智能面临的一个基础但长期被忽视的难题是时序记忆。现有视觉-语言-动作（VLA）模型通常缺乏可靠的动作历史跟踪能力，导致在执行"按按钮五次"这类需要计数的长程任务时，要么按一次就停止，要么陷入无限循环。面壁智能在 WAIC 上开源的 MiniCPM-Robot 系列将这一问题作为核心研究目标之一，试图通过端侧小模型与推理优化的结合，在真实机器人上实现稳定的长程操作。

MiniCPM-RobotManip（1.5B）负责操作任务，接收视觉与语言指令后直接输出动作；MiniCPM-RobotTrack（0.9B）负责跟踪导航，与南京大学合作并原生适配宇树 Go2 Edu 机器狗。两者均面向本地部署，体现了"小模型 + 系统优化"的研究路线。面壁智能的学术合伙人姚远指出，机器人和基础模型一样，在不调用外部工具的情况下并不真正具备时序记忆和可靠计数能力，这一观察为后续研究提供了明确的问题定义：如何在参数量受限的端侧模型中嵌入有效的动作历史表征与计数机制。

学术意义： 该系列模型将端侧大模型的研究经验迁移至具身智能领域，为低资源场景下的机器人长程任务执行建立了新的开源基线。研究者可以在此基础上进一步探索记忆增强架构、Sim2Real 迁移以及多模态指令跟随的可解释性。

Agent 基础设施Harness自适应系统

解读：当 Harness 本身成为学习对象

随着大模型能力的快速提升，Agent 系统中外层的控制代码（Harness）逐渐从"弥补模型不足"的补丁演变为决定任务成败的关键组件。上海 AI Lab 的最新工作将 Harness 本身纳入训练与优化范围，提出了一套使其能够自进化的框架。在不更换底层模型的条件下，该方法实现了 104% 的效果提升，说明 Harness 的优化空间可能不亚于模型本身的优化。

这一研究的理论价值在于重新审视了"模型能力"与"系统能力"的边界。传统上，研究者将更多参数、更多数据投入模型训练，而将任务分解、工具调用、错误恢复等能力交给外部工程实现。上海 AI Lab 的工作提示，这些外部工程实现同样可以被视为可学习、可搜索、可验证的对象，从而形成"模型 + Harness"联合演化的研究范式。这与 Anthropic 内部关于"Harness 那层外壳流程正在被拆掉"的观察形成呼应：旧 Harness 假设模型做不到某些事情，而这些假设正在随模型能力提升而过期。

学术意义： 该框架为 Agent 系统的自动结构搜索与元学习开辟了新方向，研究者可以进一步探索 Harness 的表示形式、搜索空间、验证机制以及与不同能力层级模型的适配策略。
