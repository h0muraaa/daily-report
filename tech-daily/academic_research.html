AI4Science1.1 WeatherNext 2 登顶 Nature：AI 台风预报获得"额外一天"提前量

Google DeepMind 在《Nature》发表 WeatherNext 2 的台风预报工作，模型在热带气旋的路径、强度与风场结构预测上达到 SOTA。论文给出一个非常直观的结论：模型的 3 天预报精度与此前方法的 2 天预报相当，等价于把可行动提前量平均拉长 24 小时以上，被官方称作"相当于十年气象学进展"。技术细节上，模型基于近 20 TB 全球大气数据与约 5,000 个历史风暴（IBTraACS）训练，以 28×28 km 分辨率运行（比传统数值模型粗 100 倍），单次 15 天预报在 TPU 上 1 分钟内完成，并可为每个风暴输出 1,000 个概率集合预报（去年为 50 个）。这是"AI 在自然科学关键任务上超越传统数值方法并被顶刊背书"的又一标志性案例。

关键点：Nature 论文 · 路径/强度/风场 SOTA · +24h 提前量 · 1000 集合预报 · 28km 分辨率 · TPU 上 <1min/15 天预报。

Agent评测1.2 "机器科学家"压力测试：48 种 LLM-Agent 配置在真实物理实验室仅 3.3% 免人工可执行

中国科学技术大学把"AI 能否接管实验室"从知识问答推进到真实物理世界：研究团队搭建了包含 45 个模块化自动工作站（覆盖合成、表征与催化性能测试）的机器催化实验室，将设备能力封装为机器可读 skills，供 LLM-Agent 直接调用。随后对 6 种 Agent 框架 × 9 种大模型构成的 48 种配置、32 项专家定义任务共 4,608 次评测，追踪"计划→核验→下发→免人工执行"全链路。结果相当严苛：仅 151 个工作流无需人工修复即可执行（占 3.3%）；最佳组合 Claude Code + Claude Opus 4.7 可达 28.1%，Codex + GPT-5.5 为 19.8%。"会调参数 ≠ 会重新规划研究"——Agent 从真实实验结果中学习、修正研究方案的能力仍是明显短板（论文 arXiv:2607.23045）。

关键点：AI for Science 实证评估 · 真实物理实验闭环 · 48 配置 × 4608 次评测 · 免人工执行率 3.3% · 最佳组合 28.1%。

多模态1.3 Towards Physics of Multimodal Pretraining：首次系统刻画多模态预训练的"物理规律"

这篇文章试图回答一个此前被"工程直觉"主导的问题：多模态统一预训练中，各模态之间的知识到底如何流动、何时协同、何时竞争？作者在合成数据与大规模真实数据上做受控实验，提炼出四个结论——知识流动的不对称性、数据复杂度决定模态协同/竞争、早期统一（而非晚期对齐）更优且能避免"视觉懒惰"（模型依赖语言先验）、以及仅用 5% 算力即可达到强生成性能的高效配方；随后在 13.5B MoE 模型 × 2T tokens 规模上验证了结论的可扩展性。本文为"多模态预训练科学"提供了第一个成体系的经验基础，值得作为该方向的必读基准文献。

关键点：受控实验 · 知识流动/协同/早期统一/配方四大洞见 · 视觉懒惰现象 · 13.5B MoE × 2T tokens 验证。

评测方法1.4 Toward Skill-Native LLMs：Skill Entropy——长程推理评测与训练的新指标

AK 转发的这篇新工作提出以 "Skill Entropy"（技能熵）作为度量与训练长程推理（long-horizon reasoning）能力的指标，研究取向是让 LLM 从"任务执行"转向"技能原生"（skill-native）的能力组织。在 Agent 与推理评测快速演进的当下，这类"过程性/结构性"指标试图补充传统正确率/任务完成率之外的维度——即模型是否真正把长程任务拆解并固化为可复用的技能结构。该工作经由 Hugging Face Papers 传播（2608.05 批次），属于新兴的"评测科学化"脉络（与本期 §4.1 呼应）。

关键点：Skill Entropy 指标 · 长程推理评测与训练 · skill-native LLM 取向 · HF Papers 传播。

Agent基准1.5 MerchantBench：让 Agent 经营网店 365 天，最强模型仅达人类净资产 27.3%

阿里发布的长程电商 Agent 基准 MerchantBench（已上线 Hugging Face）给出一个冷静的结果：模拟卖家全年经营一家网店（365 天模拟、9.8 万+ 真实商品记录、26 个工具覆盖选品/上架/定价/现金流），目标是在年底跑赢真人净资产——而当前最强 LLM 只达到人类平均的 27.3%。相比短任务评测中 Agent 的"表演"，长程一致性（长期目标保持、跨轮状态追踪、延迟反馈与季节波动应对）才是真正的"地狱难度"。它把 Agent 评测从"会不会调工具"推向"能不能扛住经济生命周期"，与 SWE-bench 之后的 Agent 评测趋势一脉相承。

关键点：365 天模拟 · 9.8 万商品 · 26 工具 · 最强 LLM 27.3% 人类净资产 · 长程一致性评测。

视频语言1.7 CLIP-CC-Bench：把视频-语言评测从"单句"推向"段落级长描述"

视频-语言模型的评测长期停留在短视频片段 + 单句指标的设定上。CLIP-CC-Bench 将评测推进到段落级长文描述：从 5 小时电影内容中切出 90 秒片段，逐段配专家撰写的段落级参考，并采用 5 个 SOTA LLM 嵌入模型的集成来缓解单一模型偏差，再以粗/细粒度两级语义匹配方法对比生成描述（arXiv:2608.04302）。这类工作补上了"模型能否生成准确、连贯、忠实于长视频内容的描述"这一评测空白，对视频理解研究的方法学价值大于单点效果提升。

§2 深度论文解读

本期选读：一篇是多模态预训练的"科学化"奠基之作，另一篇揭示了 TTS 评测中的系统性混淆——两篇都值得逐段精读。

2.1 论文精读：Towards Physics of Multimodal Pretraining —— 多模态预训练的经验定律

作者 Junlin Han、Shengbang Tong、David Fan、Minghao Chen、Philip Torr、Filippos Kokkinos、Mike Lewis（arXiv:2608.05000）。论文把"视觉作为基础模型的关键推进轴"这一趋势拆解成可检验的科学问题：统一多模态训练中，各模态如何交互？此前设计空间主要由工程直觉支配，本文用合成数据 + 大规模真实数据的受控实验给出四点经验定律。

（1）知识流动（Knowledge Flow）：分离语言、视觉理解与视觉生成之间的知识迁移方向，揭示显著的不对称性；（2）协同 vs 竞争：数据"复杂度"在很大程度上决定模态间是协同还是竞争；共享注意力 + 带模态专用前馈层的归一化等架构选择能促进协同，且该行为可跨不同的视觉 tokenizer 泛化；（3）早期统一：从极早期统一模态并联合训练，优于晚期对齐或顺序训练；延迟整合会诱发"视觉懒惰"——模型依赖语言先验而忽略视觉信息；（4）配方：仅用 5% 计算预算即可达到强生成性能的高效预训练配方。最终在 13.5B MoE、2T tokens 规模上验证了上述结论。

学术意义。这篇工作的价值不在单一指标提升，而在于为"多模态预训练"建立了一个可复用的因果分析框架：把"是否早期统一""是否共享注意力""数据复杂度如何调制协同"变成可量化、可迁移的经验规律。"视觉懒惰"是一个可被后续工作直接引用的命名现象，对 LLM 接入视觉后"退化为语言先验推理"的一类失败给出了结构性解释。对研究者的启示：① 设计多模态架构前，先用其"知识流动/协同"诊断方法做小规模受控实验；② 13.5B × 2T 的规模验证意味着这些规律在真实训练成本下成立，可直接指导资源分配。该文与 MoE 扩展律、多模态 scaling law 的研究合流，属于"预训练科学"这一新兴子领域的核心文献。

关键点：四大经验定律 · 视觉懒惰现象 · 共享注意力促进协同 · 5% 算力高效配方 · 13.5B MoE × 2T tokens 验证。
📎 原文：arXiv:2608.05000 ｜ 讨论帖：AK(@_akhaliq)

2.2 论文精读：Best-of-N TTS 评测的 ASR 家族混淆——一个必须写进评测报告的坑

Best-of-N（BoN）推理通过用 ASR 验证器从多个候选里挑选最一致的输出，来提升零样本 TTS 的内容一致性，已逐渐成为语音合成的默认推理策略。这篇工作（arXiv:2607.08256）指出的问题具有普遍方法学意义：验证器"看起来有多好"，强烈取决于用它评测的 ASR 家族。

在 LibriSpeech-PC + F5-TTS 上，同一批验证器在 Whisper、wav2vec 2.0、HuBERT 三种评测器下的排序差异显著；同家族（same-family）验证器-评测器组合恢复的 oracle headroom 明显高于跨家族组合，即便两族的表示高度相似——这说明耦合来自"身份/谱系层面"，而非一般性的表示相似性。作者提出两种缓解方案：① Rank Averaging（跨独立 ASR 家族对排名取平均）；② Conjunctive Max-Rank（取各家族中每候选的最差排名，强制跨评测器一致）。在 N=10 时最佳集成相对 F5-TTS 将平均 WER 降低 12%，且不损伤自动相似度与质量指标。

学术意义。这是一篇典型的"评测即研究"工作：它揭示了在 TTS 内部以 ASR 既当验证器又当评测器的循环依赖——如果验证器和评测器同属一族，报告的数字会系统性虚高。其"跨评测器三角互证（cross-evaluator triangulation）应成为 BoN TTS 评测默认规范"的结论，可直接推广到一切"用模型 A 评测模型 B 的训练/选择流程"（如 RAG 检索器用 embedding 评测、代码 Agent 用测试集评测等）。对语音方向研究者，建议把该文与 §1.8 的泄漏审计工作并读：两者共同说明，评测配置本身已成为影响结论的最强变量之一。

关键点：BoN 评测混淆 · ASR 家族谱系耦合 · Rank Averaging / Conjunctive Max-Rank · 12% 相对 WER 改善 · 跨评测器三角互证。
📎 原文：arXiv:2607.08256

§4 趋势观察

对研究方向与范式的观察与预判，供研究者参考。

4.1 "评测科学化"正在成为独立研究主题

本期多条新闻指向同一趋势：评测配置本身成为决定结论的最强变量。Best-of-N TTS 的 ASR 家族混淆（验证器与评测器同族导致数字虚高）、EEG 解码的泄漏审计（控制被试级信息泄漏后证据大幅缩水）、MerchantBench 揭示的"短任务能表演、长程一致性露馅"、OfficeQA 量化的 harness 增益（同模型 +92%）、以及中科大用 4,608 次真实实验给"Agent 接管实验室"泼冷水——都在强调一件事：结论的可辩护性取决于评测设计。对研究者而言，"设计无泄漏、跨族互证、长程覆盖、物理世界验证"的评测将成为论文方法论部分的核心竞争力；审稿人也会越来越严格地质疑评测配置。

4.2 AI for Science 从"预测"走向"预测→实验"闭环

WeatherNext 2 的 Nature 论文代表了 AI 在预测类科学任务上的成熟（顶刊背书 + 实际部署 + 权重开源）；中国科大"机器科学家"实验室则是 AI 进入实验闭环的早期但严酷的实测：规划 → 核验 → 机器人执行 → 从真实结果学习的全链路仍只有个位数百分点的免人工执行率。配合 ACE-Data-0 这类高信息密度具身数据集、以及李飞飞团队 World Labs 收购 SceniX 押注仿真训练场，可以判断：具身数据采集、仿真环境与实验自动化将承接"预测之后"的增量，交叉学科（气象、材料、机器人、生物）会是下一阶段论文高产方向。

4.3 开放权重模型在多模态竞技场登顶，"可复现基座"进一步下沉

MiniMax H3 在 Design Arena 三大视频类别登顶、Kimi K3 进入 GitHub Copilot 与 Databricks——开放权重模型正从"追赶者"变成多个竞技场的榜首。a16z 与 Inferact 的讨论（vLLM 作者 Simon Mo）指出开放权重与闭源在能力上的差距已很小，差距主要在分发与产品化。对学术社区，这意味着默认基座正在转向可自托管、可复现、成本可控的开放模型；相应地，"蒸馏""数据税""许可证"等议题会持续成为学界-工业界互动的焦点（本窗口张一鸣"禁止 Seed 蒸馏"、Anthropic 指控中国实验室蒸馏等事件即是信号）。建议研究者在使用前沿模型做实验时，把"是否可复现"纳入方法学决策。
