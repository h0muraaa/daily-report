ICLR 2026

ICLR 2026 获奖论文揭晓：Transformer 简洁性理论与 Alec Radford 经典 GAN 工作获时间检验奖

ICLR 2026 于巴西里约热内卢举行，今年收到约 19,000 篇有效投稿，总录取率约 28%。获奖论文中，「Transformers are Inherently Succinct」获得杰出论文奖，该工作从理论角度提出以简洁性（succinctness）作为衡量 Transformer 表达能力的指标，证明 Transformer 在编码概念时比有限自动机和线性时序逻辑（LTL）等传统形式语言表示方法更为简洁。评审委员会认为，尽管存在批评意见，但这一鲜明的概念性观点有望推动后续围绕 Transformer 及其他架构在概念表示简洁性方面的理论与实证研究。此外，Alec Radford 等人 2016 年关于生成对抗网络（GAN）在表征学习中的经典论文获得「时间检验奖」（Test of Time Award），这标志着无监督表征学习这一研究方向在过去十年中的深远影响。

CVPR 2026

清华段岳圻团队提出 CFG-Ctrl：将扩散模型引导机制重构为可控动态系统

现有文生图模型在可控性与生成质量之间存在根本性冲突——用户越是强调语义对齐（如指定物体位置、文字内容），画面质量越容易下降。清华大学段岳圻团队提出的《CFG-Ctrl: Control-Based Classifier-Free Diffusion Guidance》从控制理论角度重新设计了扩散模型的引导机制。研究不再将 CFG（Classifier-Free Guidance）视为简单的参数调节手段，而是将整个生成过程建模为一个动态系统，将语义偏差定义为需要被控制的误差信号，并引入控制器来稳定生成轨迹。这一方法论升级的核心价值在于：它将一个经验性的调参问题转化为具有理论保证的控制问题，有望为生成模型的可控性研究提供新的分析框架。

科学发现

SimpleTES：开源模型通过评估驱动缩放实现 21 个科学发现任务的「暴力逆袭」

宽德智能学习实验室（Will）联合斯坦福、清华大学、北京大学发布的研究提出了一项名为 SimpleTES（Simple Test-time Evaluation-driven Scaling）的通用框架。该研究的核心发现是：科学发现的上限不仅取决于模型有多「聪明」，更取决于如何组织试错与评估。SimpleTES 将试错过程拆解为三个可调度的维度——假设生成、实验执行和结果评估，并在此基础上实现测试时扩展（test-time scaling）。实验结果表明，普通开源模型在该框架下能够在 21 个科学发现任务中取得与顶级闭源模型（如 OpenAI o1、DeepSeek-R1）相当甚至更好的表现。这一工作对科研社区的重要启示在于：当算力资源有限时，优化「试错效率」可能比单纯追求模型规模更具成本效益。

长上下文

DeepSeek V4 技术报告：CSA/HCA 混合注意力与 mHC 残差连接的架构创新

DeepSeek 发布 V4 系列模型（Pro 版 1.6T/49B 激活，Flash 版 284B/13B 激活），核心主题是围绕百万 token 长上下文推理效率重构模型架构。技术报告披露了三项关键创新：（1）CSA（Compressed Sparse Attention）+ HCA（Heavily Compressed Attention）混合注意力架构，通过先压缩 KV Cache 再执行稀疏/稠密注意力，在 1M token 场景下单 token 推理 FLOPs 降至约 27%、KV Cache 降至约 10%；（2）mHC（Manifold-Constrained Hyper-Connections）残差连接，增强深层模型训练时的信号传播稳定性；（3）大规模采用 Muon 优化器替代 AdamW，实现更快收敛与更稳定训练。此外，DeepSeek 同时开源了 Base 和 Instruct 版本，为后续研究社区基于该模型进行进一步微调与实验提供了完整基础。

3D视觉

前馈式 3D 场景建模综述：从表示驱动到问题驱动的范式转换

来自浙江大学、南洋理工大学、莫纳什大学、ETH Zurich、图宾根大学等机构的研究者联合发布了前馈式 3D 场景建模（Feed-Forward 3D Scene Modeling）的系统性综述。与已有综述主要按 NeRF、3D Gaussian Splatting、Pointmap 等表示形式分类不同，该工作提出了一种问题驱动（problem-driven）的分析框架，从模型试图解决的核心问题出发重新组织文献。前馈式方法通过一次前向推理直接从输入图像预测三维场景表示，无需逐场景优化，在跨场景泛化能力与实际部署效率方面具有显著优势。该综述同时建立了配套的项目页面与 GitHub 资源列表，为 3D 视觉领域的研究者提供了一个结构化的知识入口。

ICLR 2026 杰出论文：Transformers are Inherently Succinct

作者：Pascal Bergsträßer, Ryan Cotterell, Anthony Widjaja Lin（ETH Zurich）

核心问题：为什么 Transformer 在众多序列建模架构中脱颖而出？该论文提出从「简洁性」这一形式化指标来回答这一问题。

方法论创新：论文将「简洁性」定义为描述某一概念所需的最小表示大小，并严格证明：对于一类重要的形式语言概念，Transformer 能够以指数级更紧凑的方式编码这些概念，而等价的 RNN 或有限自动机表示则需要指数级更大的状态空间。这一结论为 Transformer 在实践中的优越表现提供了理论层面的解释——它不仅「能」表示这些概念，而且表示得「更经济」。

学术意义：该工作属于计算语言学与传统理论计算机科学的交叉领域，其分析框架（以简洁性衡量架构表达能力）有望被推广至其他架构比较场景。评审委员会特别指出，尽管论文存在部分批评意见（如所分析的语言类是否足够代表实际任务），但其概念性观点鲜明，具有开启新研究方向的潜力。对国内研究者而言，这一工作提示了一个值得关注的理论研究方向：架构设计的「表示经济性」可能是除了容量、效率之外的第三个关键优化目标。

DeepSeek V4 技术报告：长上下文效率优化的系统性工程

团队：DeepSeek-AI

核心主题：通过新的架构和工程优化，使大模型更高效地支持百万 token 上下文。

三项关键技术创新：

  • CSA + HCA 混合注意力：CSA（Compressed Sparse Attention）先对 KV Cache 进行压缩再执行稀疏注意力；HCA（Heavily Compressed Attention）则进一步激进压缩 KV Cache 同时保持稠密注意力。两者协同使得在 1M token 上下文下，单 token 推理 FLOPs 仅需约 27%，KV Cache 仅需约 10%。
  • mHC 残差连接：Manifold-Constrained Hyper-Connections 通过引入流形约束增强传统残差连接，改善深层网络（DeepSeek V4 Pro 层数极深）训练时的梯度传播稳定性，同时保留模型的表达能力。
  • Muon 优化器的大规模应用：在大部分模块中替换 AdamW 为 Muon 优化器，实验显示收敛速度更快、训练更稳定。Embedding、prediction head 和 RMSNorm 等模块仍保留 AdamW。

训练策略：采用「领域专家预训练 + on-policy 融合」的两阶段后训练策略，先分别训练数学、代码、Agent、指令跟随等领域的专家模型，再通过 on-policy 方法将其能力融合到统一模型中。

学术价值：DeepSeek V4 的技术报告延续了中国开源模型团队「详实披露」的传统，对长上下文架构优化、高效注意力机制、以及大规模 MoE 训练工程均有重要参考价值。同时发布 Base 和 Instruct 版本的做法，为学术界进行进一步微调实验和安全性研究提供了便利。

四、趋势观察

从「训练驱动」到「评估驱动」的方法论范式转移

2025-2026 年间，一个值得关注的研究方法论趋势正在形成：当模型在标准 benchmark 上的差距日益缩小，「如何设计更好的评估」正在取代「如何训练更强的模型」成为核心创新点。姚顺雨的「AI 下半场」论断、SimpleTES 的测试时评估扩展框架、以及 Hy3 的评估优先发布策略，均指向同一方向。对研究者而言，这意味着评估科学（Evaluation Science）可能成为一个独立且关键的研究子领域——它不仅涉及 benchmark 设计，还包括测试时计算分配、多维度评估融合、以及真实场景下的效用建模。

长上下文：从「功能特性」到「基础设施」

DeepSeek V4 技术报告明确将长上下文定位为「下一代大模型的基础设施」而非可选功能。其背后的逻辑是：复杂的智能体工作流、大规模跨文档分析、多轮科学推理等新兴任务，天然需要模型维持对超长文本序列的全局理解。CSA/HCA 等注意力压缩技术的出现，使得 1M token 上下文在推理成本上首次变得「可承受」。预计 2026 年下半年，长上下文效率优化将成为架构研究的主流方向之一，与 MoE、量化等技术形成互补。

开源模型的「科学发现」能力正在逼近闭源旗舰

SimpleTES 的实验结果表明，通过优化试错流程，开源模型在 21 个科学发现任务中可以达到与 o1、DeepSeek-R1 等顶级闭源模型相当的表现。这一发现对学术研究具有双重意义：一方面，它降低了高水平科学计算研究的准入门槛；另一方面，它提示「智能的组织方式」（orchestration）可能与「智能的内在能力」（capability）同等重要。未来，围绕「如何更好地调用模型能力」的工具链研究（如 Agent 框架、评估协议、工作流优化）可能会获得与模型架构研究相当的关注度。
