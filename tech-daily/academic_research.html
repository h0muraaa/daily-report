摘要 · Abstract

本期聚焦三条学术主线：其一，形式化验证与 AI agents 的深度结合——微软研究院使用 Rust、Lean 与 Aeneas 验证 SymCrypt 密码学代码，展示了 agentic proof automation 在生产级密码算法上的可行性；其二，视觉预训练对文本预训练范式的挑战——arXiv 论文《Scalable Visual Pretraining for Language Intelligence》提出基础模型不必仅以纯文本作为预训练信号；其三，视频生成从离线范式转向实时交互——清华朱军团队 Vidu S1 及其底层 SageAttention、TurboDiffusion 的发布，以及 Wan-Dancer 等长程分层生成工作，共同重塑了 diffusion 模型的时间维度研究议程。

同期，开源生态持续活跃：美团 LongCat-2.0（1.6T 参数）在国产算力上完成推理并全面开源；商汤 SenseNova-Vision 将经典视觉任务原生融入多模态底座；腾讯混元 HyOCR-1.5 实现端到端 OCR 大模型的全栈式开源。

RD · 01

使用 Rust、Lean、Aeneas 与 AI agents 验证 SymCrypt 生产级密码学代码

Formal Verification Cryptography Proof Automation

微软研究院发布技术报告，介绍其在 SymCrypt 密码库上采用 Rust、Aeneas 与 Lean 4 构建形式化验证流水线的方法。该工作针对 SHA-3 与 ML-KEM 等后量子密码算法，证明其 Rust 实现与标准规范之间的功能等价性。Aeneas 作为 Rust 到 Lean 的翻译器，可将 Rust 子集（LLBC）自动转换为 Lean 可证明的纯函数形式，从而在保留 Rust 性能优势的同时获得形式化保证。

方法论的关键创新在于利用 AI agents 进行大规模 proof 自动化——agents 生成的每个证明步骤都可被 Lean 内核独立验证，因此不存在"agent 幻觉导致错误证明"的风险，只有通过内核检查的证明才会被接受。这为"agent-assisted formal methods"提供了可复现的范式，对编译器验证、协议验证等场景具有启发意义。已公开验证代码、规范、性质与证明脚本，首批覆盖 SHA-3 与 ML-KEM。

RD · 02

清华朱军团队 Vidu S1：视频生成从离线走向实时交互

Video Diffusion Real-Time Generation Systems

生数科技创始人、清华大学计算机系教授朱军发布 Vidu S1 实时交互模型，实现 540P、40FPS 实时视频生成与无限时长交互。这是视频生成领域从"离线生成"到"实时交互"的范式转移。其全链路负责人张金涛（朱军教授的 00 后博士生）以推理优化为切入点，构建了 SageAttention（GitHub 星标超 3.5K）、TurboDiffusion（超 3.6K 星标）、TurboServe 等系统级方案，作为 Vidu S1 的底层支撑。

学术意义在于：以往视频扩散模型的加速研究多停留在单点 kernel 或采样器层面，而该工作形成了一套覆盖注意力近似、采样调度、服务编排的全栈系统方法，使得 diffusion 模型首次具备与自回归流式生成相竞争的低延迟特性。朱军团队此前在概率机器学习与生成模型方向的扩散模型高效算法已被 DALL·E 2 等工业系统采用，本人于 2025 年入选 ACM Fellow。

arXiv:2607.09657v1 [cs.MM]

Scalable Visual Pretraining for Language Intelligence

研究背景 · Background

大基础模型的快速进展主要由大规模文本语料上的预训练驱动。然而，人类知识有相当部分通过视觉表征传递——图表、排版公式、页面布局承载着纯文本无法完整捕获的信息。当前主流预训练方法在将文档、网页等视觉丰富源转换为纯文本时丢弃了这些视觉线索，形成"text-only pretraining"这一隐含假设。

核心创新 · Contribution

该工作系统性质疑"语言模型必须以纯文本作为预训练信号"的默认假设，提出 Visual Pretraining 作为可扩展的基础模型智能学习范式。作者通过控制实验对比了相同内容在文本表征与视觉表征下的预训练效果，证明视觉预训练在多个语言智能基准上具备可扩展性（scaling behavior 与文本预训练相当），并在涉及文档理解、公式推理、版面分析等任务上显著优于纯文本基线。

实验结果 · Results

实验覆盖了不同参数规模与训练数据量的组合，确认视觉预训练的 loss 曲线与下游性能随规模呈可预测的幂律改善。在文档问答、数学推理、表格理解等任务上，视觉预训练模型相比文本基线取得一致增益，且增益在更大规模下并未消失。该工作还探讨了视觉与文本预训练的混合策略，发现一定比例的多模态 token 能够提升样本效率。

学术意义 · Significance

该论文若结论稳健，将对基础模型研究产生范式级影响：(1) 数据利用层面——大量已数字化的视觉丰富文档（论文、书籍、报告）可被直接用于预训练，无需信息损失的文本化转换；(2) 方法论层面——为 multimodal foundation model 提供了一条与"先训文本、后接视觉"不同的技术路线；(3) 评测层面——挑战了以纯文本基准为主的模型能力评估体系，呼吁更多视觉中心的语言能力基准。后续研究需关注跨语言泛化、低资源语言下的视觉预训练效率，以及与 OCR-free 文档理解的关系。

arXiv:2607.09134v1 [cs.SD, eess.AS]

ReGen: Hierarchical Multi-Prompt Representation Generation for Efficient Waveform Diffusion Models

研究背景 · Background

表征对齐（Representation Alignment, REPA）已被用于加速扩散训练，但作者观察到，对 Diffusion Transformer（DiT）中间表征的正则化可能隐式纠缠 latents，从而限制生成容量。这一发现挑战了 REPA 类方法的核心假设——即中间表征对齐总是有益于生成质量。

核心创新 · Contribution

该工作提出 ReGen，一种分层多提示词表征生成框架，在单一扩散模型内联合估计表征与数据的多个向量场。同时引入 Generalized Flow Matching (GFM) 以改善 Conditional Flow Matching (CFM) 的泛化能力。GFM 通过放宽 CFM 的条件独立性假设，使得向量场估计对分布外样本更鲁棒。

实验结果 · Results

作者在单阶段波形扩散模型上验证 ReGen，包括神经音频编解码器（neural audio codec）与 Wave-VAE 两类任务。结果显示 ReGen 在波形生成质量上相较基线有显著提升，并在训练效率上优于标准 REPA。这表明分层多提示词的表征生成机制有效缓解了中间表征正则化带来的 latents 纠缠问题。

学术意义 · Significance

理论贡献：(1) 对 REPA 类方法在波形域的适用边界给出了实证分析，指出表征对齐并非普适的免费午餐；(2) 提出的 GFM 框架可视为对 Flow Matching 理论的拓展，可能对其他模态的扩散模型训练产生启发；(3) 在音频生成这一相对小众但应用广泛的领域（音乐生成、语音合成、音频编解码）提供了可复用的高效训练范式。该方法与近期"高效扩散训练"方向的多项工作形成对话，值得在图像、视频等其他模态上验证其普适性。

📎 来源: arXiv:2607.09134 · cs.SD / eess.AS updates on arXiv.org
arXiv:2607.09581v1 [cs.SD]

Wan-Dancer: A Hierarchical Framework for Minute-scale Coherent Music-to-Dance Generation

研究背景 · Background

从音乐直接生成长时长、高清晰度、节奏同步的舞蹈视频仍是重大挑战。现有扩散模型通常在 20 秒后出现时间漂移、身份不一致与动作重复等问题。无论是依赖中间 3D 骨架的间接方法，还是端到端视频合成方法，在长程生成时都难以保持一致性。

核心创新 · Contribution

Wan-Dancer 提出一种新颖的分层框架，将分钟级音乐到舞蹈的生成过程解耦为全局关键帧规划与局部时间细化两阶段。全局阶段利用整段音乐上下文规划关键动作节点，保证长程一致性；局部阶段在关键帧之间进行细节补全，实现帧级连贯。这种"全局-局部"分解使得模型能够突破传统扩散模型的时间瓶颈。

学术意义 · Significance

该工作代表了长程视频生成领域的一个重要方向——通过分层分解而非单一端到端模型解决长程一致性。这一思路与近期视频生成领域的多项工作（如 Vidu S1 的实时交互、Sora 类工作的时空分块）形成互补。对舞蹈编排、动画生成、虚拟人驱动等下游应用具有直接价值，亦为"长程时序生成"这一更一般的学术问题提供了可复用的架构范式。

Reflections on emerging research directions and methodological shifts.

趋势一：形式化验证与 AI Agents 的深度融合

微软研究院 SymCrypt 验证工作代表了"agent-assisted formal methods"的成熟化。关键洞察在于：Lean 等证明助手内核提供了机器可检查的正确性保证，使得 LLM agent 生成的证明可独立验证，无需信任 agent 本身。这一模式可能扩展至编译器验证（CompCert 风格）、协议验证（TLS、共识协议）、乃至数学定理证明（结合 Mathlib）。研究议程包括：如何设计 agent 友好的证明搜索空间、如何将高层证明策略与底层 tactic 调用解耦、以及证明自动化的可扩展性边界。

趋势二：视觉预训练挑战文本中心范式

arXiv 2607.09657 提出的 Visual Pretraining 若结论稳健，将引发对"text-only pretraining"假设的系统性反思。这与近年 OCR-free 文档理解、像素级语言模型（PIXEL、CLIPPO）等方向的工作形成呼应。值得关注的后续问题：视觉预训练在非拉丁文字（中文、阿拉伯文、天城文）上的效率、与文本预训练的最优混合比例、以及视觉 token 化方案对下游推理能力的影响。该方向可能重塑基础模型的数据工程与评测体系。

趋势三：视频生成从离线范式转向实时交互

Vidu S1、Wan-Dancer 等工作共同标志着视频生成研究的时间维度突破。关键技术路径包括：(1) 系统层加速——SageAttention、TurboDiffusion 等底层优化使扩散模型具备实时性；(2) 架构层分层——全局-局部分解解决长程一致性；(3) 交互范式——从"输入-等待-输出"转向"流式-可控-可干预"。研究前沿将聚焦：长程时序的内存高效注意力、用户意图与生成过程的实时耦合、以及生成质量与交互延迟的帕累托前沿。

趋势四：Agentic Benchmark 的方法论成熟

Arena.ai 基于 7.8K 真实 agentic sessions 的 Agent Arena 排行榜显示，GPT-5.6 Sol 与 Claude Fable 5 的差距已收窄至 +1.6% Net Improvement，但在 Steerability（+17.3%）等维度存在显著代际差异。这提示：传统静态基准已难以区分前沿模型能力，基于真实交互的评测方法论（含隐式用户满意度信号如 Praise vs. Complaint）正成为新的学术标准。研究社区需关注：评测数据污染、跨任务泛化、以及 agentic 能力的细粒度分解（规划、工具使用、错误恢复、用户意图理解）。

趋势五：国产算力生态下的大模型协同优化

LongCat-2.0 在五万卡国产集群上的推理，标志着"model-system-hardware co-design"在中国 AI 生态中的成熟。随着国产芯片在显存带宽、互联拓扑上的持续演进，针对特定硬件特性的模型架构创新（稀疏注意力、N-gram Embedding、KV-cache 切分）将成为差异化竞争的关键。学术上，这一方向与 MLSys、ML for Systems 等交叉领域深度相关，值得在异构算力调度、混合精度推理、分布式训练通信优化等子问题上持续投入。
