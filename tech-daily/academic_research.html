摘要 —— 今日研究侧的核心信号集中在三处：其一，记忆与推理的解耦成为系统层优化的新抓手（NVIDIA SEED 把「写记忆」与「预测下一 token」的计算量分离）；其二，Agent 的自我改进从概念演示走向可量化的实验（Google GUARD、Perplexity 的八周随机对照试验）；其三，纯强化学习后训练被证明可以低成本逼近基座能力（DaisyRose-27B）。arXiv 侧则以多模态检索、Agentic 视频理解与音频决策为主。本日报按「研究动态 → 深度解读 → 开源资源 → 趋势观察」组织。

研究动态

1NVIDIA SEED：拆解混合模型的「读写不对称」，用浅层编码写入深层记忆

PreprintInference SystemsKV Cache

NVIDIA 提出 SEED，将「为后续生成写入记忆」与「预测下一 token」两类计算显式分离。以 48 层的 Qwen3.8-Flash-Next 为例，处理输入时令除最后一个 token 外的其余 token 只运行前 31 层，再由轻量记忆写入组件为后续 17 层生成 KV Cache 与循环状态；生成阶段每个 token 仍跑满 48 层。作者在五种混合架构模型上验证了这种计算量差异，并把节省的算力用于降低预填充开销。

解码侧则利用循环状态「主分量近似固定方向 + 低秩残差」的结构进行压缩：单请求循环状态从 113.2MB 降至约 29.2MB。在 GB300 + SGLang 的编码 Agent 轨迹上，每 GPU 峰值吞吐提升 16%～42%，同 P90 输出速率下提升 23%～42%，且原模型权重全程冻结、新增组件以蒸馏训练，规避了精度回退风险。工作已以《Shallow Encoding Emits Deep Memories》发布 arXiv 预印本。

📎 来源：机器之心

2Google GUARD：编辑式自我改进的 Agent Harness，冻结基座即可稳定涨点

AgentSelf-ImprovementHarness

针对自我改进型 harness 普遍存在的局部过拟合、灾难性遗忘与记忆污染问题，Google 提出 GUARD：保持基础模型冻结，仅允许 Agent 编辑自身的提示、技能、工具规则与记忆，且只有当某次编辑的收益大于其破坏的行为时才被采纳。在 43 个托管 SDK 任务上达到 80.80% 准确率（较初始 harness 提升 8.89 个点，p = 0.008），比 Meta-Harness 高 6.28 个点，同时每任务 token 消耗减少 54.5%。在程序性记忆任务上更新正确率 90.1% 且零记忆污染——激进改写器虽然正确率相近，却带来三倍的污染。

📎 来源：elvis (@omarsar0)

3Perplexity：自我改进技能的生产级随机对照试验

AgentRCTProduction

Perplexity 公开了 Perplexity Computer 中「自我改进技能」的研究结果：Brain 在维护工作知识库之外，会读取用户的完整会话轨迹（工具调用、推理、结果），识别复现模式，仅在证据充分时才提议新增或更新技能。内置技能需经失败场景的成对回放与工程师审核方可上线。在为期 8 周、基于生产流量的随机测试中，72.9% 的用户至少获得一项个性化新技能（对照组手动添加仅 6.5%），工具调用失败率下降 11%，不满意的会话下降 7.6%，且成本无可测变化——这类带对照的设计在 Agent 研究中尤为稀缺。

📎 来源：Aravind Srinivas (@AravSrinivas)

SystemsBest PaperLLM Serving

📎 来源：阿里技术

5MIT × NVIDIA QDA：用 Agent 自动搜索量化配方

QuantizationAutoMLPTQ

MIT 与 NVIDIA 的合作工作 QDA 把「训练后量化（PTQ）配方搜索」交给 Agent 迭代完成。其关键加速在于评测：给一个量化推理模型打分通常需数十 GPU 小时，QDA 改为在 Agent 从未见过的推理轨迹上测量候选相对原模型的输出 KL 散度，几分钟即可初筛，再对高分候选做长生成以捕捉重复循环。最终在 W4A16 / W4A8 / W3A16 上分别超过最强公开配方 0.9 / 1.4 / 2.2 个点，每次搜索仅需 64 GPU 小时。

📎 来源：elvis (@omarsar0)

6Runway Praxis-1：27B 稀疏 MoE 扩散 Transformer，联合预测视频与动作

World ModelDiffusionMoE

Runway 发布 Praxis-1：一个 27B 参数的混合专家（MoE）扩散 Transformer，同时预测视频帧与动作，架构、训练阶段与结果见其技术报告。该模型属于「视频 + 动作联合建模」的世界模型路线，与同日 Google 通过 API 开放的 Genie 4（文本/图像播种、WASD 实时操控、48kHz 立体声）形成对照，反映出世界模型正从演示走向可编程接口。

📎 来源：Runway (@runwayml)

7硅星人Pro：一套「数学哲学」Benchmark 揭示长思维链的失效边界

BenchmarkReasoningLean

硅星人Pro 团队以「哲学为灵魂、Lean 为骨架」，设计了一套识别数学哲学思想的 Benchmark，并对 Claude Opus 5.5、GPT-6 Sol、Gemini 3.8 Flash、GLM-5.3、Qwen3.8-Max、Kimi-K3 等十款模型横评。结果揭示：推理 token 消耗越多未必答得越好——有模型仅用约 50 个推理 token 即达 92.7% 准确率，也有模型耗尽 2,048 token 上限仍在死胡同。该工作直指当前长 CoT「暴力硬算、缺乏路径直觉」的痛点，对推理评测方法论具参考价值。

📎 来源：硅星人Pro

8arXiv 精选速览：多模态检索、Agentic 视频理解与音频决策

arXiv:cs.MMarXiv:cs.SDMulti

VideoACE（arXiv:2611.24184）提出面向 Agentic 视频理解的基准，聚焦高帧率动作视频，含 1,000 道多项选择题、时序证据标注与防泄漏的用户提示，考察模型能否把「可交互机会」转化为「更好的理解」。FLARE（arXiv:2605.10228）构建全模态长视频视听检索基准，从 399 段 Video-MME 视频（225.4 小时）生成 87,697 个带视觉/音频/统一标注的片段，弥补现有检索基准「短片、单模态、字幕评估」的局限。

UEmo-D1（arXiv:2611.24481）以决策模型统一多模态情感识别，将输入在自然语言指令引导下直接映射到候选选项的分布，兼顾跨任务泛化、高效决策与多解释包容性。Movie2Game-Bench（arXiv:2611.24669）评估「电影转游戏」改编，覆盖 22 部影片、658 条参考项，并以三个 GUI 模型玩家做 playtest。Great Listeners, Poor Decision-Makers（arXiv:2611.23847）是一篇立场论文：主张 Agentic 音频 AI 的瓶颈已从「识别」转向「决策」，提出独立于感知与推理的显式决策层，决定何时行动、等待、询问或保持沉默。

此外，Harmonic Circuit（arXiv:2611.24453）将机制可解释性（MI）的电路发现方法迁移到符号音乐模型，在 ChatMusician 与 MuPT 中定位出 $I\ldots V\rightarrow I$ 终止主音预测的稀疏子网络；Learning Binary Codes with Spiking Neural Networks（arXiv:2606.00740）用脉冲活动的正负竞争决定哈希位，把语义学习与比特决策统一起来。

深度论文解读

Shallow Encoding Emits Deep Memories（NVIDIA SEED）

Preprint / arXiv · Inference Systems · 2026-11

研究背景　混合架构（注意力 + 循环/状态空间）在长上下文下把大量开销压到 KV Cache 与循环状态的读写上。直觉上「预填充」需要把每一层算满，但作者提出一个被忽视的假设：为后续生成写下记忆所需的深层计算，可以远少于预测下一个 token 所需的计算。

核心创新　SEED 把「记忆写入」与「token 预测」解耦：输入阶段仅让最后一个 token 之外的 token 运行前 31 层，由轻量组件据浅层表示生成深层 KV 与循环状态；解码阶段仍跑满全部 48 层。解码侧的循环状态进一步按「近固定主分量 + 低秩残差」分解存储，直接在该分解形式下读写。

实验结果　在五种混合模型、六个检查点上验证：单请求循环状态由 113.2MB 压缩至约 29.2MB；GB300 + SGLang 下 Qwen3.8-Flash-Next 每 GPU 峰值吞吐提升 16%～42%，同 P90 输出速率提升 23%～42%。原权重冻结、新增模块蒸馏训练，质量评测检验了精度代价。

学术意义　该工作把「预填充 = 全层计算」这一默认假设松绑，为长上下文推理系统提供了新的优化维度——记忆写入的深度可与预测解耦。其「冻结基座 + 轻量旁路 + 蒸馏」的范式，也与同期自我改进、量化搜索等工作共享「冻结大模型、只训练小部件」的方法论取向。

GUARD: Self-Improving Agent Harnesses（Google）

Research · Agent / Harness · 2026-11

研究背景　自我改进的 Agent 通过让模型编辑自身提示、技能与记忆来提升表现，但容易出现三类退化：局部过拟合、灾难性遗忘、记忆污染。如何在「允许自改」与「保证不回退」之间取得平衡，是当前 harness 研究的核心张力。

核心创新　GUARD 保持基础模型冻结，仅开放提示、技能、工具规则与记忆四类可编辑对象。采纳准则是一条「净收益」判据：一次编辑只有在带来的增益超过它所破坏的行为时才被接受。为保证可判定，每个任务被拆解为可逐项检查的结构，从而定位「改坏了什么」。

实验结果　43 个托管 SDK 任务：80.80% 准确率，较初始 harness 高 8.89 点（p = 0.008）；较 Meta-Harness 高 6.28 点且每任务 token 少 54.5%。程序性记忆任务上更新正确率 90.1%、零记忆污染；激进改写器正确率相近但污染三倍。

学术意义　GUARD 把「自我改进」从启发式改写推向有约束的、可度量的编辑决策，其「净收益判据 + 细粒度任务分解」对 Agent 持续学习、在线记忆更新等方向具有方法论借鉴价值，也与 Perplexity 的成对回放审核机制相互印证。

趋势观察

01 / 从「能力」到「决策」 —— 今日多篇工作把研究焦点从「模型能不能做」转向「何时该做」。GUARD 的净收益判据、Perplexity 的成对回放审核、以及立场论文《Great Listeners, Poor Decision-Makers》提出的显式决策层，指向同一判断：Agent 的瓶颈正从感知/识别迁移到行动决策与自我约束。可预期的研究方向是「可度量的决策策略」与「回退安全性」。

02 / 记忆成为新的计算轴 —— SEED 把「记忆写入深度」与「预测深度」解耦，说明长上下文系统的优化空间不仅在算子与并行，更在读写结构本身。当 KV Cache / 循环状态可被分解、压缩、按需写入时，记忆的表示形式将成为与算力、带宽并列的一阶变量。

03 / 冻结大模型、只训小部件 —— SEED（冻结权重 + 蒸馏旁路）、GUARD（冻结基座 + 编辑式自改）、QDA（用 Agent 搜索量化配方）共享一种低成本、低风险的改进范式。在不触碰主权重的前提下，通过外部组件撬动能力提升，可能成为后训练与系统优化的主流工程路径。

04 / 纯 RL 后训练的性价比 —— DaisyRose-27B 以纯强化学习（无 SFT、无蒸馏）在 18 天内显著提升长程 Agent 能力，提示后训练的技术门槛与数据依赖正在被重估。对学术团队而言，这意味着在有限算力下做有意义的后训练研究变得更现实。

05 / 评测方法论的自觉 —— ParseBench-2 的「先定错误权重再调分」、odysseys2 的公开 rubric、VideoACE 的防泄漏设计、以及「数学哲学」Benchmark 对长 CoT 的反直觉发现，共同表明社区正从「刷榜」转向对度量本身的批判性设计。评测即方法，正在成为共识。
