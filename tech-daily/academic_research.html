一、研究动态

复旦团队发布 BadPhoneAgent：首个靶向式手机智能体安全测评数据集
AI 安全 移动 Agent 数据集

随着大模型能力向端侧 Agent 迁移，手机智能体已经能够在真实 APP 中完成点外卖、写评价甚至玩小程序游戏等复杂操作，但其被恶意利用的风险尚未被系统量化。复旦大学计算与智能创新学院张谧教授团队将 8 款基于不同模型构建的智能体接入真实手机，在 31 个国民级 APP 上验证了有害任务的端到端可执行性，并发现部分场景下的执行速度已超过人类。

为支撑后续研究，团队构建了 BadPhoneAgent 数据集。该数据集从 11 部国内外法律法规及最高法案例等 50 余处权威来源中提取真实安全风险，形成了涵盖 6 大类、40 个子类的《手机智能体恶意使用分类体系》。相关论文题为 It Lied to a Doctor to Buy Poison Ingredients: Quantifying Real-World Misuse of Phone-use Agents，为移动 Agent 的安全对齐与防御研究提供了可复用的评测基准。

来源：[机器之心]
GeoLAN：以三维挂谷猜想破解大模型"黑盒"与表征坍塌
可解释性 表征学习 数学交叉

大语言模型在推理、编程和分析任务上表现优异，但其内部决策过程难以追溯，根源之一是 Transformer 训练过程中出现的"表征坍塌"（representation collapse）：语义信息被压缩在狭窄的高维锥形区域内，导致概念纠缠与可解释性下降。佛罗里达大学团队在新论文 GeoLAN: Geometric Learning of Latent Explanatory Directions in Large Language Models 中，尝试从几何角度解决这一问题。

研究者引入了近期三维挂谷猜想证明中的核心概念——"粘性挂谷集"（sticky Kakeya set）——为大模型内部语义空间建立一套"摆放规矩"，从而在训练阶段将相互纠缠的概念梳理到更结构化的方向。该方法不同于事后归因或探测式可解释性方法，而是从训练目标层面约束潜在空间的各向异性，为构建内在可解释的大模型提供了一条新的数学路径。

来源：[AI科技评论]
MoAI 攻防 SoK：系统梳理移动端 AI 安全的三大支柱
端侧 AI 安全综述 系统论文

墨尔本大学、RMIT 大学与南洋理工大学联合发布了一项针对 Mobile On-device AI（MoAI）的攻防 SoK（Systematization of Knowledge）研究。文章指出，传统"云端大模型 + 手机采集数据"的范式存在敏感数据离域、网络延迟与弱网降级三重代价，而 Google Tensor、Apple Neural Engine、Qualcomm Hexagon 等端侧 AI 硬件的进步，以及 LiteRT/TFLite、Core ML 等本地部署框架的成熟，正推动 AI 能力向终端迁移。

该 SoK 系统梳理了 MoAI 生态中的三大安全支柱，为端侧模型的攻防研究提供了统一的问题分类与文献图谱。对于关注边缘智能、模型压缩与隐私计算的研究者而言，这是一份值得细读的领域综述，有助于识别该方向尚未被充分探索的研究空白。

来源：[新智元]
AgenTank：14 天 450 人 500 辆 Agent 坦克的大规模众测与动态评估
Agent 评估 众包实验 动态博弈

静态 benchmark 刷榜已难以反映 Agent 在真实、开放环境中的综合能力。硅星人 Eval 研究小组联合 30 个社区与高校 AI 社团，在为期 14 天的 AgenTank World Cup 中组织了 450 名选手、500 余辆 Agent Tank，消耗近千亿 Token，完成了一场大规模 Agent 众测。比赛采用实时对抗游戏场景，分为 1v1 个人赛与 3v3 团队赛。

与传统静态评测不同，AgenTank 要求 Coding Agent 在多轮失败、回放与日志分析中迭代策略，并应对对手能力持续演化的动态博弈。该众测同时考验了底层模型、Agent Harness 与人机工作流，其收集的长周期对抗数据为研究 Agent 的策略适应、团队协作与失败恢复机制提供了宝贵的实证素材。

来源：[硅星人Pro]
XYZ-Aquila 系列：AI4AI 研发范式下的 Deep Search Agent
AI4AI Search Agent 递归自我改进

XYZ AI Lab 正式发布两款 Deep Search Agent：35B 参数的 XYZ-Aquila-mini 与 397B 参数的 XYZ-Aquila-pro，并在六项公开评测中刷新 SOTA。更值得研究者关注的是其背后的研发范式：团队将 AI 不再仅视为被训练对象，而是让其参与完整 Agent 系统的研发闭环，涵盖算法发现、代码开发、实验迭代与下一代系统构建。

这一方向通常被称为 AI4AI，更激进的讨论则指向 RSI（Recursive Self-Improvement，递归自我改进）。Google DeepMind 的 AlphaEvolve 已被用于数据中心效率优化、芯片设计与训练流程改进；Anthropic 亦披露其代码库中超过 80% 的新合入代码由 Claude 编写。XYZ-Aquila 系列的成绩表明，AI4AI 正从概念验证进入可量化的系统研发阶段。

来源：[机器之心]
Claude Opus 5：基准表现、定价策略与学术启示
大模型 基准评测 效率优化

Anthropic 于 7 月 24 日发布 Claude Opus 5，官方定位为能力接近旗舰 Fable 5、价格维持 Opus 档位（输入 $5/MTok，输出 $25/MTok）。在官方公布的基准中，Opus 5 在 Frontier-Bench（基于工程图纸构建可用软件）上较前代翻倍并超越 Fable 5；在 ARC-AGI 3（新颖问题解决能力）上得分约为次优模型的 3 倍。

从研究视角看，Opus 5 的发布有两点值得关注：其一，它代表了"中间档旗舰"模型的效率优化路径——在保持相对低价的同时逼近顶级模型性能；其二，其引入的可调 effort 设置（包括成本翻倍的 Fast mode）为研究推理时计算扩展（test-time compute scaling）与任务成本-质量权衡提供了新的实验对象。独立评测社区 Latent Space 的初步结果也支持 Opus 5 相对 Fable 5 的性价比优势。

二、深度论文解读

推荐论文：GeoLAN: Geometric Learning of Latent Explanatory Directions in Large Language Models

研究背景：大语言模型的"黑盒"问题长期困扰学界。事后可解释性方法（如探测分类器、激活修补）虽然能定位与特定概念相关的神经元或方向，但难以改变模型训练过程中语义空间被压缩在狭窄锥形区域内的根本缺陷。表征坍塌（representation collapse）导致的各向异性，使得不同概念在潜在空间中相互纠缠，降低了模型输出的可预测性与可控性。

核心创新：佛罗里达大学团队从纯数学的前沿成果——三维挂谷猜想的证明——中汲取灵感，提出"粘性挂谷集"可作为语义空间几何约束的工具。GeoLAN 通过在训练阶段引入几何正则化，鼓励大模型将不同语义概念沿着相互正交或结构化的潜在方向摆放，从而缓解表征坍塌。这一思路将可解释性从"事后分析"推进到"训练时塑造"，与当前主流的表示工程（representation engineering）方法形成互补。

学术意义：该研究展示了数学顶级成果向机器学习训练流程迁移的可能性。如果 GeoLAN 能够在更大规模模型与更多任务上复现其效果，它将为构建内在可解释、可控且更鲁棒的大模型开辟新方向。研究者可持续关注其论文附录中的实验设置、超参数选择以及在标准可解释性 benchmark 上的量化对比。

三、开源资源

Qwen3.5-4B 消歧专用模型：小模型专业化的新案例

近期 Hugging Face 上出现了一款基于 Qwen3.5-4B 进行 SFT 的消歧（disambiguation）专用模型 qwen3.5-4b-sft-disambiguation，支持图像与文本输入。该模型将"把模糊、多义的信息理清楚"这一基础但关键的认知环节单独抽离出来进行训练，体现了当前 AI 系统架构的一种新分工趋势：由大模型负责通用理解与生成，由针对具体瓶颈环节微调的小模型负责做准、做快、做便宜。

对于研究者而言，这类小模型专业化案例为模型能力解耦、模块化系统设计与低成本部署提供了可参考的实验基础，也提示未来可能存在更多面向路由、抽取、判断等细分认知功能的轻量专家模型。

Buzz：Block 开源的 Agent 协作记忆工作台

Block 工程团队开源了 Buzz，一个自托管的"频道驱动"工作空间，旨在解决企业场景中人、Agent、仓库、审批与工作流上下文分散的问题。Buzz 将消息、代码评审、Git 事件、工作流步骤与 Agent 行为统一为签名事件日志，使项目历史成为可审计、可追踪的协作记录。截至 7 月 24 日，block/buzz 在 GitHub 上已获得约 7,522 Star、597 Fork，主语言为 Rust，采用 Apache-2.0 许可证。

该工具为研究多 Agent 协作、长期记忆与可审计 AI 系统提供了真实工程场景下的参考实现，尤其适合关注 Agent 安全、权限治理与组织集成的研究者。
