Meta AIRA₃：约 4000 队 Kaggle 夺金，靠「知识复利」跨域泛化

Meta 于今年 6 月将其下一代自主 AI 研究系统 AIRA₃ 投入一场由 NVIDIA 组织的 Kaggle 实时竞赛：任务是把一个 30B 的 Nemotron 模型微调得「更会推理」，所有参赛队伍共享相同信息、统一在私有测试集上外部评分。最终 AIRA₃ 在约 4000 支队伍中位列第 8 并拿到金牌，超过了可使用同样前沿工具的真人参赛者。参赛采用模型集成：实时提交的夺金组合是 GPT-5.5（配 OpenCode）+ Claude 4.8（配 ClaudeCode）；事后补测中，Muse Spark 1.2（配 MuseCode）同样达到金牌水平，Muse Spark 1.1 与 GLM 5.2（均配 OpenCode）为银牌水平。

架构上，AIRA₃ 不依赖中央控制器：大量「长时程 agent」（模型与编码 harness 成对）在各自隔离环境中长期运行，通过两个共享基板异步协作——一个用于交换假设与发现的「论坛」、一个存放解决方案产物的共享文件系统；个体 agent 互相借鉴、把发现沉淀为可复用资产，用算力换取「知识复利」，搜索策略随每个 agent 的决定动态涌现。团队还给出跨域证据：仅更换任务规格，同一系统在内部基准上把生产 GPU kernel 的延迟降低 27%，并在另一个把 4000 年前阿卡德语泥板译为英文的 Kaggle 竞赛中达到金牌水平。这是迄今来自工业实验室的、少见的「AI 驱动 AI 研究」系统级公开证据；它把递归自我改进从口号变成了可外部评分的工程事实，值得关注其评估协议与事后泛化测试。

NVIDIA 微调 Nemotron：IOI 2026 题目集 535.4/600，越过金牌线并超人类最高分

NVIDIA AI 官方宣布，其研究团队微调的 Nemotron 模型在 IOI 2026 题目集上取得 535.4/600（由 IOI 国际技术委员会评分），高于本届得分最高的人类选手，并超过金牌线。该模型在乌兹别克斯坦与官方竞赛并行、以非正式身份参赛：无互联网访问、与人类选手面对相同的时间限制与提交约束、使用同一平台。配套技术报告已公开在 arXiv（2609.02849）。

生成模型 · ECCV 2026

MIMFlow（ECCV 2026 Long Oral）：把 MIM 塞进 Normalizing Flow 的端到端链路

南京大学团队（经大模型智能/极市平台分享）的 ECCV 2026 Long Oral 工作，直指一个矛盾：Normalizing Flow 擅长精确密度建模，却因严格可逆而把大量容量花在低层细节；Masked Image Modeling（MIM）擅长逼出高层语义，却通常与真正的生成模型分阶段训练。MIMFlow 把两者接进同一条端到端训练链路——Masked ViT Encoder 从被遮挡图像提取全局信息、Learnable Token Bottleneck 用固定数量查询 token 汇聚语义、Latent Normalizing Flow 对该连续 latent 做精确密度估计与反向采样、Generative ViT Decoder 负责像素重建与高频纹理合成。

其要点不是给现有生成模型加一个 MIM 辅助损失，而是重新划分生成职责：传统 Flow 被要求同时建模「对象/轮廓/布局」的全局结构与「毛发/边缘/噪声」的局部细节；MIMFlow 改为 Encoder 提全局语义、Flow 建模语义 latent 的分布、Decoder 合成高频细节。在 ImageNet 256×256 类别条件生成上，MIMFlow-L 的 FID 为 2.50，相比参数规模接近的 SimFlow-L（FID 3.72）下降 32.8%；latent 仅用 128 个 token，低于常见的 256-token 配置。该工作把「表示学习、重建、生成」放进同一目标，代表一类值得跟踪的生成范式收敛方向。

具身导航 · 基准

UrbanGround：把大模型放进真实三维香港，「走两步，就忘了路」

上海交通大学、新加坡国立大学、美团、香港中文大学、上海大学与牛津大学的研究团队，用香港真实三维地理数据搭建了一个城市级沙盒（支持第一人称探索、全局地图、昼夜与天气切换以及行人移动），用来评测大模型的城市导航能力。结果呈现出鲜明的「单帧 vs 长程」反差：10 个模型对街景地标的视觉识别准确率高达 75.0%–93.8%，只看一张图都答得不错；但一旦真正上路，短程导航中表现最好的模型也仅完成 75.0% 的任务，路线拉长后成功率集体跌到 0%–3.8%。

「走两步就忘路」说明当前视觉语言模型缺少把局部判断一路带到终点所需的路径记忆、地标锚定与决策延续能力。UrbanGround 的价值在于把「真实城市三维数据 + 可控交互环境」作为公开评测底座，让导航类 agent 的短板可被量化、可被复现，也提示长程空间推理仍是具身智能的开放问题。

结构化数据 · 基础模型

Xiaomi-TabLDM：把「一次预训练、跨任务使用」带进表格数据

小米技术团队发布通用表格数据基础模型 Xiaomi-TabLDM：以单一预训练模型 + 统一默认配置直接适配不同表格数据集，无需针对每个任务重新训练、调参或后置集成，即可完成分类与回归预测。其动机很实际——金融、医疗、制造、物流等领域大量核心数据以表格存在，而传统表格机器学习几乎都要「每个新数据集重训一次」，存在多版本管理与高昂的生产部署代价。

方法上，团队从大规模合成数据预训练、高效模型 Scaling、Test-Time Scaling 三个方向推进，试图让一个模型充分利用不同数据集间的上下文信息，在控制计算开销的同时扩容量，并用推理期计算持续提升预测。结果方面，在四大公开基准均进入第一梯队：TALENT 二分类第一、OpenML-CTR23 回归第一、BCCO 总体第二、TabArena 回归第二，超过 TabPFN-3、AutoGluon 1.5 extreme、TabPFN-2.6、TabICL-v2 等强基线，并保持较好的性能—效率权衡。对研究社区而言，它把 LLM 的 Scaling 叙事移植到非结构化之外的结构化数据域，可作为表格基础模型方向的参照系。

世界模型 · 具身智能

Phi-WM ActEffect：世界模型只在训练期当「后果检查器」，部署后退场

光象科技与清华大学李升波教授课题组发布第一代「物理原生世界模型」Phi-WM 1.0 ActEffect，思路与常见的「脑内沙盘」相反：常规方法让机器人随身携带世界模型、先预测未来再决定动作，模型想得越多推理链路越长；ActEffect 则让世界模型只在训练阶段工作——检查机器人自己提出的动作会造成什么后果，并把这种「后果检查」变成策略优化的反馈信号。训练完成后，受控世界模型从部署链路中退出，执行时无需在线展开未来或搜索候选动作，即「把『多想一会儿』留给训练，把更短的链路留给执行」。

方法上，策略需要交出三版动作答案（前馈分支的「第一反应」、MIP 动作头的粗提案、粗提案上精修出的最终动作），受控世界模型以「当前视觉状态 + 动作提案」预测场景变化，未来状态放进冻结的 DINOv3 视觉特征空间而非生成逼真画面，再以排序损失要求精提案优于粗提案、粗提案优于前馈提案。结果：LIBERO 平均成功率 98.8%，LIBERO-PLUS（七类分布偏移）80.3%（对比 Fast-WAM 的 51.5%），RoboCasa-GR1 上 67.5%、比第二名高 9.2 个百分点；消融显示去掉后果反馈会让 98.8% 回落到 97.0%。需要注意：这目前以模型发布形式公开、未见 arXiv/会议版本，且夹杂企业商业化信息，结论宜待论文与复现。

AI for Math · 方法学

孪生素数「有界间距」246→186：AI 交出答案，陶哲轩说「令人无语」

OpenAI 宣布 GPT-6 Astra 发布后在孪生素数方向取得新进展：用 Lean 形式化证明把「连续素数间距存在无穷多对不超过某常数」这一上界从 246 推到 186；同期 Anthropic 与 Axiom 也宣布自家 AI 分别把该间距缩到 188 与 212。该问题的既有推进线是：张益唐证明间距不超过 7000 万的素数对无穷多，2022 年菲尔兹奖得主 James Maynard 缩至 600，后续团队进一步缩至 246；牛津数学家 Julia Stadlmann 则在 8 月 31 日凭「平滑模数」新估计把上界先推到 240——恰好赶在 AI 成果集中发布之前。

陶哲轩在 Mastodon 上的回应值得每位做 AI 数学的人细读：他直言「这可真是令人无语的一幕」，并指出问题不在于答案本身——AI 解题太快、过程太黑盒，可能掩盖数学研究里那些宝贵的「失败」与死胡同；若迭代者提前知道最终正确拟设，会抑制对其它路线的探索。他以纳维-斯托克斯方程为例说明：历史上失败的尝试催生了 Leray–Hopf 弱解、Beale–Kato–Majda 爆破判据等一批基础思想。他点名批评一些公司「把通往最终拟设的整个过程几乎完全隔绝在公众视野之外」——即便技术性解决了著名难题，若过程不透明，数学本身几乎没有新增价值，严重时 AI 对数学的影响可能由正转负。他同时给出建设性预言：机器学习驱动模拟 + 严格区间算术 + 形式化证明 + LLM 提拟设 + 人类专家指导的流水线，最终可能真正解决这类难题，而产物之复杂可能让人类无法独立验证，Lean 证明文件或成史上最大形式化证明之一。这条新闻与本期费马大定理解读构成同一枚硬币的两面：机器可验证是「可信度」的解药，而「过程透明与探索空间」仍是未解的方法学问题。

Claude 完成费马大定理首个端到端形式化证明：11 天、1300 万行 Lean、超 Mathlib 五倍

Anthropic 官方 · 形式化数学 · 2026-09-05 报道 | 主导者：Tianyi Peng（清华姚班 / MIT 博士 / 哥大助理教授）

研究背景

费马大定理（FLT）1637 年被费马写在书页空白处：对整数 n > 2，方程 xⁿ + yⁿ = zⁿ 无正整数解。它折磨了人类 350 余年，直到 1994 年 Andrew Wiles 与 Richard Taylor 修补完成证明——该证明依赖大量 20 世纪代数几何工具，写下约 129 页。把这样一座依赖图庞大、抽象度极高的现代数学成果「形式化」进 Lean 证明助手，此前被认为是需要多年社区工程的长期项目：2024 年帝国理工 Kevin Buzzard 等人刚为此启动多年计划（技术蓝图 86 页）。本次，Claude 用 11 天完成首个端到端机器验证证明。

核心创新与关键细节

主导者彭天翼 2017 年毕业于清华姚班、2023 年获 MIT 博士学位，现任哥伦比亚大学助理教授兼 Anthropic 研究员（方向为强化学习、AI Agent 与形式化工具）。他与哥大合作者搭建了 Prove2Me 协作平台：把证明拆成由定理节点组成的 DAG，分离管理「定理陈述」与「证明」，加速 Lean 编译，并为每条定理保留自然语言描述以便 agent 检索与复用。最终方案是 Prove2Me + 基于 Claude Code 的多 agent harness——多个 agent 并行分工：有的补数学定义、有的攻中间引理、有的沿已有成果推进高层定理、有的把整套证明拼装回去。

工程规模惊人：约 1300 万行 Lean 代码、产出 3 万余条中间定理（最终证明采用约 29500 条）、消耗约 60 亿输出 token、体量超过 Lean 核心数学库 Mathlib 自身的 5 倍以上，是迄今写出的最大 Lean 证明；失败的探索代码仅占成品非模板代码约 7%。早期多 agent 协作曾出现项目状态混乱（「组团组到失忆」），换用 Prove2Me 后才扭转。人类数学介入非常有限：彭天翼只偶尔给出高层方向提示，定义、证明、拆分与拼装基本由 Claude 自主完成；内部通用研究模型能力大致相当于 Claude Fable 5.1。可靠性上，完整证明只依赖 Lean 的三个标准公理，并通过程序比对确认 Claude 最终证明的定理陈述与 Mathlib 中 FLT 的陈述完全一致——「裁判是 Lean，不能靠模型自己声称证明完了」。

学术意义与待验证问题

Kevin Buzzard 评价这是「非凡的自动形式化成果」（a remarkable automated formalization achievement）。它的意义不在单条定理，而在于证明：如此规模、如此依赖复杂度的现代数学，可以被 AI 自动搬进形式化系统——过去极度依赖人工、推进缓慢的数学文献形式化，可能首次具备大规模提速条件；同时它把一整片依赖图变成机器可检查的资产。需要保留的谨慎是：目前公开信息主要来自媒体对 Anthropic 口径的转述，完整证明库是否公开、如何复现、1300 万行中多少由模型自动生成而多少经交互修正、60 亿 token 的成本构成，都是社区下一步要检验的问题。将其与本期孪生素数一事对照，形式化既给了 AI 数学「硬通货」，也让「过程是否透明」成为新的方法学争议。

阿里 MeSH（ICLR 2026）与 SpiralFormer（EMNLP 2026）：为「循环 Transformer」治疗计算冗余

arXiv:2510.07739 & arXiv:2602.11698 · 循环架构 · 与 GPT-6 Astra 的 recurrent depth 直接相关

研究背景

GPT-6 Astra 发布后，The Information 爆料其采用了「循环深度」（recurrent depth / looped transformer）：让同一组 Transformer 层对同一段信息反复循环加工，从而在不增加同等参数规模的情况下把计算做得更深，同时会隐藏一部分甚至全部思维链。事实上阿里与合作高校团队比 Astra 早约 11 个月就切入了该方向，聚焦的核心问题是循环架构的「计算冗余」——后续循环的计算增量越来越小、近似空转。

MeSH：解决「每一轮拿什么算」

MeSH（ICLR 2026 接收，2025 年 10 月公开于 arXiv）先给出循环「摸鱼/空转」的三个证据：后续 core loop 的 hidden state 变化幅度急剧缩小；相邻轮次表示高度相似（CKA 分析）；奇异值谱显示表示坍缩进低维空间、表达趋于单一。诊断指向两个病根——「计算无分化」（共享网络缺少轮次信息、难以分工）与「信息过载」（hidden state 同时承载原始输入、历史结果与当前计算）。方案是引入 Memory Buffer（多记忆槽）分流信息，配 Write Router 与 Read Router 决定每轮、每个 token 如何动态读写。在 Pythia-1.4B 级实验中，权重共享减少约 33% 非嵌入参数；加入 MeSH 后零样本下游平均准确率从普通 Transformer 的 49.50% 提升到 50.56%（+1.06 个百分点）；路由器新增参数仅约普通 Transformer 非嵌入参数的 0.005%，额外计算开销约 0.014%。文章亦指出其在计算形式上与 Hyper-Connections、mHC 相似，但 MeSH 把类似的信息调配用在了循环之间。

SpiralFormer：解决「每一轮以什么粒度算」

SpiralFormer（EMNLP 2026 接收）追问：既然不同循环可以处理不同信息，为什么每一轮仍要在完整 token 序列上以固定粒度计算？它把每轮循环的序列长度变成可调，从粗到细——典型方案从原序列 1/8 长度起步，依次扩到 1/4、1/2，最后回到完整序列；相邻 token 通过可学习权重聚合成更粗表示（类似 Coconut 的隐空间思考），写回结果时做右移以避免压缩操作泄露未来信息。在 Pythia-1.4B 级实验中，SpiralFormer-L 与普通 Transformer 参数量基本相同，计算量从 14.08T FLOPs 降到 13.13T，5-shot 下游平均准确率从 51.93% 提高到 54.37%。Attention probing 显示：早期低分辨率循环注意力分布更广（建立全局 pattern），后期高分辨率循环更聚焦局部 token；普通 LoopedFormer 虽有类似趋势但更弱且不稳定——说明「从全局到局部」的分工不会随循环自动出现，多分辨率设计是关键驱动。Scaling 实验只调整循环层占比即形成 U 形曲线，约 30%–40% 时最佳，过度共享参数反而拖累效果，由此打开新的 Scaling 维度（每轮序列压缩尺度）。

学术意义

两篇论文合起来为循环架构提供了一个自洽的设计空间：MeSH 负责「每轮的信息管理」，SpiralFormer 负责「每轮的序列粒度」。放在 GPT-6 Astra 采用 recurrent depth 的背景下，它们是少数已公开、可复现的正面工程化方案，也为研究社区理解「固定参数、加深计算」这条路线的能力边界提供了杠杆。真正的开放问题在于：当推理越来越多地发生在不可见的循环隐状态里，可解释性与思维链监控如何跟上——见本期趋势观察。

PageIndex Flash：完全本地、开源的 PDF 树状索引引擎

PageIndex 发布开源的本地 PDF 树状索引引擎「PageIndex Flash」：直接读取 PDF 自带的排版结构（文字层、标题元数据、嵌套层级）构建目录树，而不是让视觉模型从零推断文档大纲，从而让建树变得快、便宜且可预测。检索采用两阶段：Stage 1 为文档生成含标题、页码范围、摘要与嵌套子节的树；Stage 2 让 LLM 像翻目录一样在树上推理、定位正确页面，给出带页级引用的答案。SDK 将索引模型与对话模型解耦、可独立配置。其主张是「相似 ≠ 相关」：对金融报告、法规、技术手册、教科书这类长专业文档，真正回答问题的段落措辞往往与查询完全不同，按层级树推理比固定 chunk + 向量召回更接近人类阅读方式，也让「推理式 RAG」能在本机、无向量数据库的条件下跑通全流程。

当推理发生在「循环隐状态」里：思维链监控还成立吗？

世界模型路线分岔：Atlas 的「下一视角预测」与 ActEffect 的「训练期退场」

李飞飞与 World Labs 联合创始团队本周在 a16z 对谈中系统解释了为什么押注「新视角预测」（New View Prediction, NVP）：给定场景的若干图像、视频或描述，模型把这些信息放进同一空间上下文，让虚拟相机移动到任意位置、预测将看到什么。其核心判断是——NVP 之于空间智能，可能类似 Next-Token Prediction 之于大语言模型：一个能随模型规模与数据持续 Scaling 的基础任务。Atlas 把长期分开的像素生成与 3D 重建放进同一个模型，每张输入图像都对应明确的 3D 相机位姿（位置、朝向、RGB 与 Depth），让「视角」从 prompt 描述变成模型可直接理解的输入，从而让生成获得空间约束，并把路线从重建延伸到动态世界、机器人与行动规划。这与本期研究动态中的 Phi-WM ActEffect 形成鲜明对照：后者认为世界模型不必参与在线推理——只在训练期检查动作后果、部署即退场，用更短的推理链路换时延与成本。一个押「在线预测未来」、一个押「离线内化因果」，背后其实是「世界模型应该学什么、何时被调用」的根本分歧；腾讯科技援引香港大学席宁的话指出，具身技术路线仍处「百花齐放」阶段，远未收敛——这正是做系统对比研究的好时机。
