一、研究动态

模型发布 Google DeepMind 发布 Gemini 3.5 系列模型

Google DeepMind 在 I/O 2026 大会上正式推出 Gemini 3.5 系列模型，首发型号为 Gemini 3.5 Flash。该模型在编码、Agentic 任务和工具使用方面全面超越前代 Gemini 3.1 Pro，同时保持 Flash 级别的推理速度与成本优势。模型支持 100 万 token 上下文窗口、65K 最大输出长度，并提供四级思考模式（minimal/low/medium/high），其中 medium 为新的默认设置。

从学术视角审视，Gemini 3.5 Flash 的突出意义在于其"智能-速度"权衡曲线的前沿位置：在 Arena.ai 的 Code Arena: Frontend 评测中，该模型以 1507 分位列第 9，较 Gemini 3 Flash 提升 70 分，且在消费者产品、内容创作工具、数据分析等子类别中均超越 3.1 Pro。其 4 倍于其他前沿模型的输出 token 速率（约 800 tokens/sec），使其在实时交互场景中具有独特优势。这一进展表明，模型效率优化与能力扩展并非零和博弈，通过架构改进和训练策略优化，可以在不牺牲速度的前提下实现能力跃升。

[来源: The Keyword]
世界模型 NVIDIA 开源 SANA-WM：2.6B 参数可控世界模型

NVIDIA 研究团队发布了 SANA-WM（Sana World Model），一个仅 2.6B 参数的开源世界模型，支持基于单张图像、文本描述和相机轨迹生成最长 60 秒的可控视频。该模型采用混合线性注意力（Hybrid Linear Attention）、双分支相机控制（Dual-Branch Camera Control）和两阶段生成管线（Two-Stage Generation Pipeline）等创新架构设计，可在单张 GPU 上运行。

世界模型（World Model）作为强化学习和自主智能体研究的核心组件，长期以来受限于计算资源需求和生成质量之间的张力。SANA-WM 的学术价值在于其证明了小规模参数模型（2.6B）在复杂时空建模任务上的可行性，通过架构层面的注意力机制优化和相机控制的显式解耦，实现了动作跟随精度和视觉质量的双重提升。项目已完整开源论文、代码和模型权重，为学术界提供了可复现的研究基线。

[来源: NVIDIA AI Labs]
视频生成 NVIDIA 发布 LongLive 2.0：端到端 4-bit 长视频生成基础设施

NVIDIA 研究员 Yukang Chen 团队开源了 LongLive 2.0，这是首个覆盖训练和推理全流程的 4-bit 长视频生成开源基础设施。该系统基于 NVFP4 量化技术，在 5B 参数模型上实现了 45.7 FPS 的生成速度，支持真实视频训练、少步蒸馏（few-step distillation）、多镜头训练/推理、序列并行加速、NVFP4 KV Cache 及异步 VAE 解码等全套高效训练推理方案。

从研究方法论角度，LongLive 2.0 代表了生成模型系统级优化的重要方向。传统长视频生成研究多聚焦于模型架构本身，而忽视了训练推理基础设施的协同设计。该项目将 FP4 量化、并行计算和内存优化整合为统一框架，将长视频生成的"不可能三角"（质量-速度-长度）向前推进了一步。对于研究社区而言，这一开源基础设施降低了长视频生成研究的准入门槛，使更多学术机构能够在有限算力条件下开展相关研究。

[来源: NVIDIA Labs GitHub]
多模态 Google 发布 Gemini Omni：任意输入到任意输出的统一生成模型

Google DeepMind 推出了 Gemini Omni，一个旨在实现"从任意输入生成任意输出"的统一多模态模型，首发能力聚焦于视频生成与编辑。该模型支持将图像、视频和文本作为输入，通过自然语言对话进行多轮视频编辑，包括环境变换、相机角度调整、风格迁移等操作，并能够利用 Gemini 的世界知识生成高度具体、逼真的物体。

Gemini Omni 的学术意义在于其代表了多模态统一建模范式的进一步演进。与此前专注于单一模态生成（如文本到图像、文本到视频）的研究不同，Omni 尝试构建一个真正的"全模态"（omnimodal）系统，其核心挑战在于不同模态之间的表征对齐和转换一致性。Omni Flash 作为该系列首个可用模型已面向 Google AI 订阅用户推出，后续将扩展至图像和音频输出。这一研究方向与学术界关于"世界模型应支持任意模态交互"的理论构想高度一致。

[来源: The Keyword]
AI for Science Google DeepMind 推出 Gemini for Science 科学工具套件

Google DeepMind 发布了 Gemini for Science，一套面向科学研究者的实验性 AI 工具集，包含三大核心组件：基于 Co-Scientist 的假设生成系统（通过多智能体"创意锦标赛"迭代生成、辩论和评估科学假设）、基于 AlphaEvolve 和实证研究助手的计算发现原型（可并行开发和评分数千种代码变体），以及文献解析工具。

值得注意的是，Co-Scientist 的相关研究已发表于 Nature（s41586-026-10644-y），这标志着 AI 辅助科学发现从概念验证走向实际应用的重要里程碑。在应用案例中，剑桥大学团队结合 AlphaFold、Gemini 和 Co-Scientist 研究抗生素耐药性细菌，Makerere 大学团队利用 AlphaFold 和 AlphaGenome 分析乌干达早发性乳腺癌的遗传靶点。这些跨学科合作案例展示了 AI 工具在加速科学发现周期方面的实际潜力，将原本需要数年的研究过程压缩至数分钟。

[来源: The Keyword]
Agent Skywork 发布 SkyClaw-v1.0：面向工具使用的开源 Agent 模型

Skywork 团队发布了 SkyClaw-v1.0 及其轻量版 SkyClaw-v1.0-lite，两个针对 OpenClaw、Hermes 和 Nanobot 框架优化的 Agent 模型。模型基于自构建的 OpenClaw 环境和高质量工具集进行训练，合成任务来源于真实用户行为模式。在 PinchBench、Claw-Eval 和 Skywork-Claw-Bench 三个评测基准上，v1.0 和 v1.0-lite 均优于 Minimax 2.7、DeepSeek V4 Flash 和 Qwen 3.6 35B A3B/27B 等对比模型。

SkyClaw 的研究贡献在于其系统性的 Agent 训练方法论：通过构建标准化的工具使用环境、基于真实用户模式合成训练数据、并在多维度基准上进行严格评估，为开源社区提供了一个可复现的 Agent 模型开发范式。随着工具使用（Tool Use）成为大语言模型能力评估的核心维度之一，SkyClaw 的开源发布为学术界提供了新的研究基线和对比参照。

[来源: Skywork AI]
基准测试 腾讯开源 Chronicles-OCR：古汉字视觉感知评测基准

腾讯 Hunyuan 团队开源了 Chronicles-OCR，一个专门评测视觉大语言模型（VLLM）对古汉字感知能力的基准数据集。该数据集跨越 3000 年文字演变历史，涵盖从甲骨文到草书的 7 种历史字体，包含 2800 张来自不同材质真实载体的平衡图像。评测任务包括字符定位、细粒度识别、古文字解析和字体分类四个核心维度。

Chronicles-OCR 的学术价值在于其揭示了当前 VLLM 在跨时间分布泛化方面的显著不足：当视觉分布随历史时间漂移时，大多数模型的感知能力急剧下降。这一发现对文化遗产数字化、历史文献自动识别等应用领域具有重要启示。从技术角度看，该基准填补了"古代文字理解"这一特定领域评测的空白，将 VLLM 的评测范围从现代图文理解扩展至需要"穿越时空"才能理解的文化 heritage 场景。数据集和论文已完全开源。

[来源: Tencent Hunyuan GitHub]
Agent 架构 Databricks 提出 MemEx：面向 LLM Agent 的可编程暂存器

Databricks 研究团队提出了 MemEx（Memory Extension），一个面向 LLM Agent 的可编程暂存器框架。该设计灵感源自 1945 年 Vannevar Bush 提出的 Memex 概念——一种桌面大小的机器，用于扩展科学家的记忆和联想能力。MemEx 为 Agent 提供了一个结构化的外部记忆空间，支持复杂的推理链、中间结果缓存和跨会话状态持久化。

在 Agent 系统日益复杂的背景下，记忆管理已成为制约 Agent 长期任务执行能力的关键瓶颈。MemEx 的学术贡献在于其将"记忆"从简单的上下文窗口扩展提升为一种可编程的计算资源，使 Agent 能够主动管理、检索和更新其知识状态。这一方向与当前关于"Agent 认知架构"的研究热潮高度契合，为构建更具自主性和持续学习能力的 Agent 系统提供了新的设计范式。

[来源: Databricks Blog]

二、深度论文解读

Nature Co-Scientist：基于多智能体协作的自动化科学假设生成

Google DeepMind 团队在 Nature 发表了关于 Co-Scientist 的研究论文（s41586-026-10644-y），系统阐述了如何利用多智能体 AI 系统自动化生成、评估和迭代科学假设。该系统的核心创新在于其"创意锦标赛"（Idea Tournament）机制：多个智能体分别扮演假设生成者、批评者和评估者的角色，通过多轮辩论和反馈循环，逐步精炼和筛选出最具潜力的研究方向。

核心方法论：Co-Scientist 采用 Gemini 作为基础模型，通过专门设计的智能体架构实现假设的并行生成与评估。系统包含四个关键角色：(1) 生成智能体——基于领域知识提出新颖假设；(2) 批评智能体——从方法论、可行性和创新性角度挑战假设；(3) 评估智能体——综合多维度评分对假设进行排序；(4) 进化智能体——基于反馈迭代改进高潜力假设。

从研究方法论角度审视，Co-Scientist 代表了"AI 辅助科学发现"范式的成熟化。与早期仅提供文献检索或数据分析辅助的 AI 工具不同，该系统直接介入科学发现的核心环节——假设形成。在多个开放科学挑战的评估中，Co-Scientist 生成的假设获得了领域专家的高度评价，部分假设甚至指向了人类研究者尚未探索的方向。

然而，该研究也引发了关于科学发现"自主性"边界的重要讨论。虽然 Co-Scientist 能够生成高质量假设，但假设的实验验证、理论框架构建和跨领域知识整合仍然需要人类研究者的深度参与。因此，更准确的定位或许是：Co-Scientist 是一种"认知放大器"，它扩展了研究者的假设空间探索能力，而非替代人类的科学直觉和判断力。这一观点与当前 AI 辅助科研领域关于"人类-AI 协作"（Human-AI Collaboration）的主流共识一致。

该论文的发表标志着 AI for Science 从工具辅助阶段向智能协作阶段的演进，为后续研究提供了重要的方法论参考和系统实现基线。

[来源: Nature]
预训练 前沿实验室预训练岗位的技术准备路径

Google DeepMind 研究员 Vlad Feinberg 在其技术博客中系统梳理了申请前沿 AI 实验室预训练（Pretraining）岗位所需的技术准备。该文引用了 DeepMind 去年发布的 Scaling Handbook，并强调了内核优化（kernel work）在 LLM 研究中的核心地位："所有 LLM 工作中最大的瓶颈和最内层的循环，是使抽象的逻辑变更在实际运行中可行的性能优化工作。每个项目都需要有人能够让新的注意力机制、损失函数或数据混合策略在 TPU/GPU 集群上高效运行。"

关键技能栈：(1) 分布式训练框架（JAX/XLA、PyTorch FSDP）的深入理解；(2) CUDA/TPU 内核编程与性能剖析能力；(3) 大规模数据流水线的工程实现；(4) 对 Scaling Laws 和训练动态的理论直觉。Feinberg 特别强调，预训练研究的核心竞争力在于"将理论想法转化为可运行的分布式系统"的能力。

这篇技术笔记的学术价值超越了其职业指导的表层功能。它揭示了当前大模型研究的一个结构性特征：预训练已从单纯的"扩大规模"演进为一门需要深度系统知识和工程能力的精密学科。随着模型规模进入万亿参数级别，训练效率的每一点提升都对应着数百万美元的计算成本节约，这使得"性能工程师"在研究团队中的角色日益重要。对于学术研究者而言，这一趋势意味着跨学科能力（深度学习理论 + 高性能计算）的培养将成为参与前沿研究的前提条件。

[来源: Latent.Space]

Allen Institute for AI 发布了 OlmoEarth v1.1，一个面向效率优化的开源语言模型家族。该版本在保持竞争力的下游任务性能的同时，显著降低了训练和推理的计算开销。OlmoEarth 系列延续了 Allen AI 在完全开源模型（包括训练数据、代码和权重）方面的承诺，为学术研究提供了无商业限制的模型基线。

四、趋势观察

趋势 Agent 基础设施的标准化与生态分化

今日多个发布共同指向一个结构性趋势：Agent 技术栈正在经历快速标准化与生态分化的双重过程。一方面，Google（Antigravity 2.0、Gemini Spark）、Anthropic（Claude Managed Agents with MCP tunnels）、Databricks（MemEx）和 NVIDIA（Nemotron Labs Agent 技能认证）等厂商纷纷推出各自的 Agent 基础设施，试图定义行业标准；另一方面，不同生态之间的互操作性仍然有限，形成了多个相对独立的 Agent 技术阵营。

从学术研究角度观察，这种生态分化对实验可复现性和跨平台基准评测提出了新的挑战。当前 Agent 评测结果往往高度依赖于特定的工具环境和执行框架，使得不同研究之间的直接比较变得困难。社区亟需建立独立于特定厂商生态的开放 Agent 评测标准，类似于 NLP 领域 GLUE/SuperGLUE 所发挥的作用。Skywork 的 SkyClaw 基于 OpenClaw 框架进行评测，以及 OpenRouter 推出统一的 web search 和 web fetch 工具接口，都是朝着这一方向的积极尝试。

[来源: Google Developer Blog]
趋势 模型效率优化进入"系统级创新"阶段

Gemini 3.5 Flash、SANA-WM 和 LongLive 2.0 等今日发布的共同特征是：它们不再单纯依赖模型架构的改进来提升效率，而是将量化技术、并行计算、内存优化和异步执行等系统级技术整合为统一的优化框架。这一趋势表明，大模型效率优化正在从"算法创新"阶段进入"系统工程"阶段。

对于学术研究而言，这意味着未来在模型效率领域的突破将 increasingly 依赖于跨学科的协作——深度学习研究者需要与系统架构师、编译器专家和硬件工程师紧密合作。Google Tensor SDK Beta 对 LiteRT 的集成、NVIDIA 的 NVFP4 量化基础设施，以及各厂商对边缘部署（edge deployment）的持续投入，都印证了这一判断。学术研究社区需要相应调整其技能培养和合作模式，以跟上这一系统级创新的步伐。

[来源: Google Developers Blog]
人事 Andrej Karpathy 加入 Anthropic：顶尖人才流动加剧研究竞争

OpenAI 创始成员、前 Tesla AI 总监 Andrej Karpathy 今日宣布加入 Anthropic，重返一线研发工作。Karpathy 在 AI 教育和普及领域具有广泛影响力，其提出的"vibe coding"概念和关于 Claude Code 的编程心得（被整理为 GitHub 上 22 万+ stars 的 CLAUDE.md 文件）深刻影响了开发者社区的工具使用范式。

这一人事变动的学术意义在于其反映了 AI 研究人才竞争的加剧和研究机构吸引力的动态变化。随着 Anthropic 在企业端付费采用率（34.4%）首次超越 OpenAI（32.3%），顶尖研究人才的流向可能进一步影响各机构的研究方向和技术路线选择。对于学术研究社区而言，这种人才流动既带来了更多的合作机会，也增加了研究生态的不确定性。

[来源: Andrej Karpathy @ X]
