1.1Dario Amodei《We Must Pace the Frontier》：RSI 是否已到临界？ 争议

Anthropic CEO Dario Amodei 发布长文《We Must Pace the Frontier》，主张前沿实验室应主动放缓能力推进，并提出三步方案：第一步，Anthropic 单方面承诺允许第三方评估者获得永久、员工级的系统访问权限，以核查安全措施、报告事故、评估训练过程中的模型对齐；第二步，联合全美前沿实验室划定能力红线并设置强制安全检查站；第三步推动全球落地[1][3]。他自述改变判断的原因有二：递归式自我改进（RSI）"已在全行业出现"，AI 设计下一代 AI 的能力自今夏起大幅提升；以及 OpenAI–HuggingFace 的 Agent 集群事故。文中甚至预测未来 6–12 个月可能出现 AI Agent 集群接管整个互联网的局面[3][4][36]。

工业界反应迅速分化。Sam Altman 表态支持，称"控制前沿节奏"是 OpenAI 近期内部讨论的核心，并承诺引入具有员工级访问权限的独立评估者，同时确认 2026 年不上市，理由是技术与对齐风险下推向资本市场"时机不当"[2][35]；Demis Hassabis 认为方向正确，并再次推介 DeepMind 关于前沿 AI 行业标准机构的提案[5]。但 Cohere 创始人 Aidan Gomez 直指这是"垄断联盟"：员工级全运营访问推高合规成本，中小实验室被排除；安全标准若由少数机构解释与执行，实质上赋予其否决竞争对手的权力；且此类规则依靠芯片出口管制强制执行，覆盖美国及其盟友，中国并不受约束，结果是自我设限者与不受约束者同场竞技[2]。HuggingFace 创始人 Clement Delangue 先公开承认风险成立，随即断言该问题"不可能在少数前沿实验室的闭门会议里解决"，宣布发起 Open Alignment Initiative[2]。

批评者从证据层面反击。Ramez Naam 与 Gary Marcus 指出，Dario 文中援引的博客以及最新 Claude / ChatGPT 的系统卡，恰恰说明实验室没有观察到 RSI：Mythos 5.1 系统卡明确称离 RSI 尚远、相关风险为低，已公布数据反而支持"收益递减"，难以支撑无界智能爆炸的图景[6]；Gary Marcus 另撰文检验"Agent 集群六个月接管互联网"这一论断[7]。同期，Anthropic 对齐研究负责人 Evan Hubinger 公开表示，未来十年内 AI 消灭人类的概率"超过 10%"，且目前尚无超级智能对齐方案、也未走上正轨；前员工 Jacob Coxson 以同一理由辞职[8]。对研究者而言，这组材料构成一个可直接检验的命题："RSI 是否发生"目前取决于定义与测量口径，而非某一方的断言。

1.2近五千数学家联署：AI 在数学中的"目标错位" 学界

一份题为《A Severe Misalignment of AI in Mathematics》的公开宣言已获近五千名数学家联署，其中包括 25 位菲尔兹奖得主[9]。宣言的核心论点并非"AI 数学能力太强"，而是一个目标层面的错位：解题只是达成"概念理解与洞察"这一首要目标的工具与代理指标；当 AI 以更快速度批量"生产"对已解决问题的解答，并把这一指标本身当作进展，工具就可能反噬目标——公开信同时担忧这种做法对学术评价与问题选择生态的挤压[9]。

争论的实质是"数学的价值究竟在过程还是结果"。Justine Moore 提出了一个值得记录的反驳：如果 AI 解决了一个问题，人类依然可以寻找更优证明、不同证明、推广形式与解释；真正消失的只是"第一个解出"的奖金——这与"洞察无法再产生"是完全不同的关切[10]。Kevin Weil 转引 Tyler Cowen 关于 AI 与数学的评论，认为其末段尤为精彩[11]。这一辩论对"如何评价 AI 对科学的贡献"具有普遍意义，不限于数学。

1.3RLT：把循环从"层"扩展到"token" 架构

一份新技术报告提出 Recurrent Looped Transformer（RLT）：把循环（loop）从网络层扩展到 token 维度——解码器对每个 token（提示与回答都包含在内）递归。其结构是一个因果编码器构建全局 KV 记忆；生成每个新 token 时，解码器把三样信息结合：该 token 的编码表示、上一 token 的最终隐状态、以及近期激活的滑动窗口缓存[12]。

关键性质在于计算路径与成本的结构性分离：以 48 层解码器为例，序列长度为 t 时计算路径经过 48t 个解码块，而每个 token 仍只执行固定数量的块——深度随序列增长，单 token 成本保持不变。同一套状态转移被用于预训练、SFT、采样与 RL 回放，且提示–回答边界不重置状态[12]。若把"推理时算力换性能"视为独立于参数规模的缩放维度，该工作提供了关于训练信号如何穿透长循环的具体设计。

1.4推理效率方法论：Gisting 提示压缩与推理指标定义 效率

Shopify 工程团队提出 Gisting：把冗长的 LLM 提示压缩为学习型的"主旨词元"（Gist tokens），在推理阶段以精简词元替换长文本，从而降低端到端延迟、减少基础设施成本并提升吞吐，且不改动模型核心权重。其 Sidekick GraphQL Agent 的系统提示从约 6000 词元压缩至 1500 词元（4:1），预测质量未见下降；在 350 RPM 负载下，首词元时间中位数由 438ms 降至 354ms，端到端延迟中位数由 6.8s 降至 4.2s，吞吐由 20.2 QPS 提升至 23.4 QPS，并据此减少了分配的 GPU 数量。方法源自 2022 年一篇提示压缩论文提出的教师–学生两阶段流程，通过最小化教师与学生对数概率间的 KL 散度来训练 Gist 词元[13]。

与该优化相配套，一组推理系统概念值得记录：Prefill 处理输入、KV cache 保存状态、Prefix caching 只能复用首个 token 变化之前的共同前缀——因此文档一经修改，前缀缓存即失效[14]。NVIDIA NIM LLM Benchmarking 2.0.0 则围绕 prefill / decode 两阶段给出了 TTFT（由 prefill 主导，长输入下受注意力平方复杂度制约）、端到端请求延迟、ITL 等指标的严格定义，并指出并发场景下 continuous batching 会使 TTFT 与单请求串行测试结果显著不同[15]。这些定义界定了"该优化什么、如何测量"。

1.5FlyOCR：用真实果蝇连接组做版面解析 跨学科

Jerry Liu 发布 FlyOCR：用完整雄性果蝇中枢神经连接组（MaleCNS v1.0）训练一个"读 PDF"的系统。流程为：把 PDF 图像切分为单个字形，将像素映射为受体激活，在包含 166k 神经元、25m 条边的电路上运行简化的电流型动力学，对下游脉冲施加一个紧凑的读出模型，再拼接为解析文本[16]。

在一份微软 10-K 上，它对资产负债表标题约 86% 正确，数字读数大多正确；在 1700+ 个采样字形（字母与数字）上达到 87% 准确率。作者自嘲"训练足够后也许能匹敌后期 MNIST 模型"，并提出未来或用生物电路替代文档解析 VLM 的设想[16]。作为极端的跨学科样本，其价值更多在于提出一个可检验问题：真实的生物连接组能否在不借助梯度学习的前提下承担模式识别任务，以及这类"生物基底 + 轻量读出"的范式边界在哪里。

1.6DeepSeek V4.1 Flash 开源配套工具链 开源

DeepSeek Harness 团队负责人公开了 V4.1 Flash 的三个配套仓库，分工明确：DeepSelect 针对 TopK 算子——分块扫描、按阈值筛选、候选增多时收紧阈值，在指定工作负载下较原生 torch.topk 提速约 2–20 倍；deepseek-recipe 处理请求与响应的协议适配；DeepJIT 负责任务内核的编译与运行[17]。

1.7评测可信度：METR 的独立性争议与 Agent 经济基准 评测

METR 因被 Dario 长文点名而进入聚光灯，争议随之而来。Justine Moore 转发了一份"为何 METR 未必是最无偏监管者"的总结[18]；Gary Marcus 的态度更值得研究者参考：他一方面称 METR 是优秀组织、做了出色工作，另一方面警告不应把"全世界的重量"压在它身上——需要湾区与 EA（有效利他主义）圈之外的独立科学家发声，并预计 METR 很快会遭到试图抹黑它的攻击[19][20]。这实质上是对评估机构独立性与单一裁判风险的方法学提醒。

另一类评测来自 agentic 经济任务：Vending-Bench 2 让模型以 500 美元本金在模拟环境中经营自动售货机一整年（自行找供应商、谈价、补货、调价），最后比较账户余额。GPT-6 Astra 平均最终余额 15,515 美元，约为 Claude Fable 5.1 的 3 倍，且 Astra 最差一轮都超过 Claude 最好一轮，这是 OpenAI 模型首次登顶该基准[21]。更值得注意的是 GPT-6 能力跃迁的方向：编码类 DeepSWE 仅提升 1.4 个百分点，而屏幕元素定位 ScreenSpot-Pro 由 76.9% 跃升至 92.7%，业务流程 AutomationBench 由 18.1% 升至 41.4%，CAD 任务提升 12.6 个百分点——"Agent 能力"的测量重心正从写代码转向对真实软件界面的操作[22]。

1.8具身智能与系统层：跨本体泛化、AI Infra 的边界重写 系统

具身智能方面，量子位报道一个导航模型以零样本方式"通吃"四种机器人本体，并把 2000+ 真实场景搬入仿真——仿真到真机（sim-to-real）与跨本体泛化，是当前该领域最具判别力的指标之一[23]。外滩大会一场"不收敛"的圆桌把路线级分歧摆上台面：仿真与真机并非二选一、Real-to-Sim 的 Gap 比 Sim-to-Real 更难、以及"智能的本体存在于数据"等判断，讨论还涉及 GPT-6 Astra 对具身行业的冲击与创业公司护城河[24]。

系统层，AI Infra 的边界正被重写：推理系统需同时处理 KV Cache、Prefill、Decode 等异构负载，而 Agent 会主动产生大量并行、难以预测的请求；本年度 KubeCon + CloudNativeCon + OpenInfra Summit + PyTorch Conference China 首次同台，反映"模型、编排与底层基础设施本就难以彼此独立"[25]。端侧则出现运行 4-bit 量化开源 4B 模型的本地 agentic 系统（MLX 后端），以"数据不出设备"为核心卖点，对隐私敏感场景下的端侧推理研究具有参考价值[26]。

PAPER Ⅰ · 高效推理 / Cost-Efficient Inference · arXiv:2607.20327 · 火思动力（Pyromind）

PyroDash：成本高效的小–大模型 Token 级协同推理

研究背景

顶级模型的能力天花板不断抬升，调用单价同样如此：以 Astra 为例，标准价输入 $10 / 百万 token、输出 $50 / 百万 token，且单次请求输入超过 27.2 万 token 时，整个请求将被按长上下文价格计费（输入翻倍至 $20、输出升至 $75）。作为对照，一个 4B 小模型的输出价格可低至 $0.08 / 百万 token，与顶级模型相差成百上千倍。于是问题变成：面对日益膨胀的账单，如何在不显著牺牲准确率的前提下压低成本。既有方案（如 RouteLLM 一类）多在请求级做静态路由，粒度粗、难以适配同一请求内难度的剧烈变化。

核心创新

PyroDash 的思路是"令牌级协同"：让小模型自己决定何时该呼叫大模型，把"是否需要求助"的决策下推到 token 粒度。这意味着只有在真正关键的位置才支付大模型的价格，而大量简单 token 由小模型自行完成，从而在成本与准确率之间获得比请求级路由更精细的调节旋钮（论文标题即点明 "Token-Level Small-Large Language Model Collaborative Inference"）。

实验结果

  • 在五个数学推理基准上，当设定更倾向节省成本时，小模型平均每 100 道题才调用一次大模型，估算总成本从纯大模型的 $49.36 降至 $1.78（不到原来的 1/27），准确率下降有限。
  • 当设定更看重准确率时，"小模型 + 大模型"组合平均准确率 64.04%，反而比纯大模型的 57.68% 高出 6.36 个百分点，且成本还低约两成。
  • 作者报告这些方案的准确率均高于 RouteLLM、GlimpRouter 等既有路由方案。

学术意义

该结果对"小模型只是大模型的廉价替身"这一直觉构成反例：在协同设定下，小模型对"何时求助"的判断本身成为性能来源，组合甚至超过纯大模型。方法学上，它把路由问题从"模型选择"重构为"逐 token 的投机式升级"，与推测解码（speculative decoding）、级联推理（cascades）同属一个家族——差别在于升级判据是学出来的、且作用在 token 粒度。主要待答问题是"何时求助"信号的可迁移性与校准：在一个基准上学到的阈值能否迁移到分布外的任务，以及在大模型按长上下文计价的现实约束下，最优策略是否会随输入长度发生结构性变化。

📎 来源：机器之心 · 论文：arXiv:2607.20327
PAPER Ⅱ · 元 AI / AI for AI · arXiv:2608.27287 · 阿里巴巴 × 浙江大学

Astar：让 LLM 从 AI 系统自身的"进化史"中学习改进方向

研究背景

工业级 AI 系统的迭代高度依赖算法工程师的经验与直觉——"下一步该往哪改"难以自动化。与普通软件工程不同：修改一段普通代码跑个测试用例几秒即可见分晓，而修改一个工业级 AI 系统需要长周期训练与稀疏反馈。如今 AI 已能顺畅地写代码、跑实验、做评估，算法工程师日常逐渐变成"让 LLM 整理实验结果、实现新想法、监控运行"；唯一未被取代的，被认为是对"改进方向"的判断力。Astar 要做的正是把这最后一环也自动化。

核心创新

与直接使用通用大模型给出"万金油"式建议不同，Astar 另辟蹊径：去深度学习目标 AI 系统自身的"进化血泪史"——散落在历史记录中的代码提交与实验结果。将这些真实的演化经验内化后，Astar 能够根据当前系统状态自适应地探索未来的演化方向，从而打通"提出想法 → 编写代码 → 模型训练 → 评估上线"的闭环。其创新点不在模型规模，而在领域经验的来源选择：用系统自身的历史轨迹替代参数化的通用先验。

实验结果

  • 作者报告可将算法工程师产生新 idea 的效率提升 10–100 倍。
  • 提出的演化方向显著优于现实专家与通用基模。
  • 落地于阿里核心推荐业务：离线 HitRatio 提升 23.6%，在线 GMV 提升 4.86%。

学术意义

这是一条典型的"AI 改造 AI"（meta-AI / AI for AI）路线，与本期其他工作共同指向一个趋势：把"研究 / 工程决策"本身当作可学习对象。方法学上需要审慎评估的是一致性问题——历史实验数据带有幸存者偏差与记录噪声，从"进化血泪史"中提炼的演化方向是否会强化既有的路径依赖、抑制真正探索性的方向，是值得跟进的开放问题；此外，"优于现实专家"的评测协议（专家如何抽样、idea 如何评分）将决定该结论的可复现性。

§4趋势观察

趋势一 · RSI 的"证据标准"之争将定义下一阶段的测量议题

本期最具方法学张力的信号，是"RSI 是否正在发生"这一命题缺乏统一口径：一方以"AI 造 AI 的提速"为据宣称已发生，另一方则指出相关模型系统卡的数据并不支持，收益递减的证据反而更强[1][6]。在定义、度量与证据门槛确立之前，任何"自我改进"的主张都难以被证伪。可预期围绕 RSI 的可测量框架、benchmark 与独立复现将出现更多工作，而"谁有资格评估"（如 METR 独立性之争[18][19]）会与测量方法本身同等重要。

趋势二 · 效率已从工程细节升格为与能力并列的一级研究目标

本期多条独立线索指向同一方向：Gisting 把系统提示压缩 4:1 并显著改善 TTFT 与吞吐[13]，PyroDash 把推理成本压至纯大模型的约 1/27[27]，DeepSelect 将 TopK 算子提速 2–20×[17]，以及 RLT 让"深度随序列增长而单 token 成本不变"[12]。它们的共同范式是在保持性能的前提下重新分配算力——提示层、路由层、算子层、架构层各有其位置。这提示论文评价体系需要同步容纳"同等能力下的成本–延迟曲线"这一维度，而非只比较能力上限。

趋势三 · 静态基准的判别力衰减，评测本身成为研究基础设施

数学界联署对"以解题当进展"的质疑[9]、benchmark 分数与实际体验脱节的公开讨论[29]、以及 GPT-6 的能力跃迁集中体现在屏幕元素定位与业务流程而非编码[22]，共同表明：静态、公开、可污染的基准正在失去学术判别力。随之而来的需求是动态生成、抗污染、且与真实任务分布对齐的评测协议；"评测方法学"本身正在成为需要独立投入的基础设施，而非论文附带的表格。

趋势四 · AI 治理的开放化与教育的制度化同步推进

一条线是治理：Anthropic 承诺第三方常驻评估、DeepMind 推销行业标准机构、HuggingFace 发起 Open Alignment Initiative——"谁以何种权限评估前沿系统"正在被正式设计[1][2][5]。另一条线是教育：MIT 报告系统诊断 AI 对本科教育的冲击并给出八项原则[32]，Stanford CS 312 则把"实验方法论"正式纳入课程并公开全部资料[30][31]。两条线共同指向同一件事——AI 的社会接口正在被制度化，而研究共同体既是受影响的对象，也是设计者之一。
