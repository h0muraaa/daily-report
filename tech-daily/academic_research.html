Abstract · 本期摘要

本期的研究信号集中在三条主线。其一是智能体能力的规模化验证：Anthropic 披露以 1000 个 Claude 智能体在 11 天内形式化费马大定理，产出约 1300 万行 Lean 证明，规模超过 Mathlib 五倍；清华与伯克利则开源 uni-robot-agent，使开放权重模型在具身任务上超过闭源前沿模型。

其二是评测方法的自我修正：南京大学 TestPrism 指出单一参考答案评测将 Coding Agent 的测试能力高估约一倍；Arena 与 CMU 提出 Interaction-as-a-Judge，并开源两个智能体轨迹数据集，把评测从"看输出"推进到"看行为"。

其三是模型形态的分化：Google 发布不生成文本、只回答封闭式选择题的 Gemini Decision 1，System One 决策模型开始成为独立类别；与此同时，NeurIPS 2026 的 Speculative Self-Distillation 与稀疏重连（Sparse Rewiring）分别从训练与参数干预两端回应"如何可控地改变模型"。

一、研究动态Research Highlights

以下条目按学术价值而非热度排序，侧重可复现的方法、可验证的结果与可复用的资源。

1.1千体智能体 11 天形式化费马大定理，产出 1300 万行 Lean 证明

Anthropic 的 RLance Martin 在 AI Engineer Code Summit 上披露，团队调度 1000 个 Claude 智能体，在 11 天内完成了费马大定理的形式化，沿途证明 30,300 个定理，生成约 1300 万行 Lean 代码，规模超过 Mathlib 五倍。[1] 负责协调的 lead agent 在收尾时发出"立即全局冻结 origin/main"的指令，并以"干得漂亮，你们 999 位"结束；Martin 在随后的访谈中强调，长时程智能体的关键在奖励与评测设计，而非提示词。[2]

该工作的价值不止于数学本身：它把长时程多智能体协作、形式化验证与大规模代码库治理压缩进同一个任务，提供了一个罕见的端到端压力测试。1300 万行证明也意味着可观的机器可检查产物，但其正确性仍应以 Lean 内核的独立编译与审计为准，而非以定理数量计。

学术价值：目前公开报道中规模最大的自动形式化（autoformalization）案例之一，为 long-horizon agent 的协作协议、失败恢复与仓库级一致性维护提供了实证样本；同时提示"定理计数"并非合适的科研评价指标，证明的可检查性与可维护性才是。
📎 来源：AI Will(@FinanceYF5)、AI Will(@FinanceYF5)

1.2NeurIPS 2026：Speculative Self-Distillation 让"学生写、老师只在关键处接手"

Stanford AI Lab 推介的 Speculative Self-Distillation（SSD）针对自蒸馏中长期存在的三角权衡——准确率、推理效率与灾难性遗忘。[3] 其设定颇具巧思：学生与老师是同一个模型，区别仅在于老师额外持有新文档信息；二者共同生成 rollout，学生先写，只有当其偏离过远时老师才接管，如同私人导师。

这样做的结果是，训练所用的 rollout 尽可能保持在学生自身的分布上（on-policy），同时由老师在关键分叉处注入新知识。作者称 SSD 将 accuracy–efficiency–forgetting 的前沿整体前推，且无需引入额外的教师模型或外部标注。

学术价值：为"向模型注入新知识而不遗忘旧能力"的持续学习问题提供了轻量方案，也把自蒸馏从"全盘模仿"改造为"按需纠偏"。其关键变量是偏离阈值的设定，这既是方法的核心，也是复现时最需要报告的超参数。
📎 来源：Stanford AI Lab(@StanfordAILab)

1.3南京大学 TestPrism：Coding Agent 的测试生成能力被高估约一倍

现有测试生成基准多采用单一参考答案评测（Single Reference Evaluation）：生成的测试只要在原始代码上失败、在一份标准答案上通过，就被判为成功。问题在于，同一需求往往存在多种正确实现，也存在许多貌似合理却暗含缺陷的实现；单参考评测会奖励那些"只认得标准答案"的测试，从而系统性高估测试质量。

南京大学刘佳恒团队提出 TestPrism，覆盖 17 个来源的 300 个测试任务与 3000 个候选实现，每个任务都配有经验证的正确/错误实现面板；核心指标 Joint Success Function（JSF）要求测试同时满足三个条件：在原代码上失败、接受所有正确实现、拒绝所有错误实现。在 14 种 Coding Agent 上的实验显示，传统指标下的合格率被高估约一倍。[4]

学术价值：直指智能体自我验证与强化学习奖励信号的可靠性。当测试本身有偏，Agent 的"自我检查—修正"闭环会放大误差，而非消除误差；JSF 这类联合指标应成为测试生成研究的默认报告项。
📎 来源：新智元

1.4Arena / CMU：让计算机使用智能体"上手操作"再评判，并开源两个轨迹数据集

Arena 与 CMU 博士生 Wayne Chi 提出 Interaction-as-a-Judge：让 computer-use agent 直接操作游戏与应用，产生交互轨迹，再由 LLM judge 或训练得到的 reward model 依据轨迹评判，而无需访问源代码。[5][7][8] 作为强化学习奖励时，仅用 interaction-only reward 微调 Qwen-3.5-9B，即相对基座提升 6.7 个百分点胜率（约 +50 Arena 分），应用构建成功率从 81.3% 提升至 88.5%，代码膨胀减少 35.7%。[6]

配套开源两个数据集：ArenaWebdevPreferences（6,390 组应用对及人类偏好标签）与 ArenaWebdevCorrectness（189 个游戏版本、362 条人工核验需求），论文见 arXiv:2610.17895。研究还显示该方法可随 computer-use 能力提升而同步扩展，并同时改善推理时扩展与交互式强化学习。

学术价值：把智能体评测从"检查最终输出"推进到"检查行为轨迹"，为交互式 RL 与 trace-based benchmark 提供了可复用基础设施；两个数据集填补了 Web/游戏场景中"人类偏好 + 正确性需求"配对数据的空白。
📎 来源：Arena.ai(@lmarena_ai)、Arena.ai(@lmarena_ai)、Arena.ai(@lmarena_ai)、Arena.ai(@lmarena_ai)

1.5Google 发布 Gemini Decision 1：不生成文本，一次前向回答 1000 道选择题

谷歌上线 Gemini Decisions API，核心是校准的多模态决策模型 Gemini Decision 1。它只处理三类封闭式问题——是/否判断、最多 255 个选项的多选、按序等级打分——单次调用可并行处理最多 1000 个问题，支持 256K 上下文与图像、音频、视频、PDF 输入，端到端延迟约 200ms。[9][10]

定价为每百万输入 token 0.10 美元、输出 token 不计费（官方称约为 Flash-Lite 的 1/5），并宣称在多项基准上取得最低校准误差。此举被视为对 TypeSafe AI 的 Jev 所开启的 System One 路线——非生成式、返回结构化选择/分数/概率——的正面回应；后者在八周内已引来 OpenAI、Cloudflare、Google 相继跟进。[11][12][13][14]

学术价值：决策模型把"可靠的路由与判断"从通用生成模型中解耦，可能催生 System One / System Two 的分层架构。需要审慎的是：校准误差的领先目前仅由厂商基准支持，且模型明确不生成理由，涉及可解释性与责任归属的场景仍需回退到生成式接口。
📎 来源：新智元、meng shao(@shao__meng)、Latent.Space、Latent.Space

1.6清华与伯克利开源 uni-robot-agent：开放权重模型真机零样本超过微调 π0.5

清华大学（丁宁、刘知远、徐梦迪、周伯文等）与 UC Berkeley BAIR（Pieter Abbeel 团队）联合开源统一机器人 Agent harness uni-robot-agent，专为开放权重模型设计，其上产生的交互数据可直接回流继续训练。[15] 此前的机器人使用智能体（RUA）多依赖 GPT-6 Astra 等闭源前沿模型，研究者能调用却拿不到权重，难以用真机经验继续优化。

在不使用任何特权信息的条件下，Qwen3.8-Flash-Next + uni-robot-agent 在 RoboDojo 上取得 31.39 分，超过官方公布的 GPT-6 Astra + RoboProbe 的 28.97 分，单局成本约为后者的 1/20；在 19 项真机桌面操作任务中，Qwen 零样本得分 53.50，高于示教微调的 π0.5（47.75）与零样本 Dream-1（43.50）。论文题为 Democratizing Robot-Use Agents: A Unified Harness with Open...。

学术价值：证明具身智能体的竞争力不必绑定闭源前沿模型，"开放权重 + 统一 harness + 数据回流"可显著降低实验门槛与单局成本，对资源有限的高校实验室尤其重要。
📎 来源：夕小瑶科技说

1.7Sparse Rewiring：只训练 89 个神经元即可复现完整 SFT 的人格行为

研究者 maxsloef 的工作（经 @dongxi_nlp 推荐）指出，常规微调会改动全部权重，即使只学一个简单行为，也难以解释改动究竟发生在哪里。[16] Sparse Rewiring 改为学习神经元的"新触发条件"而非新输出：仅训练 Qwen3-8B 全部 442,368 个神经元中的 89 个，就能得到与完整 SFT 相当的 owl persona。

@dongxi_nlp 评论认为，这与此前的 weight-space programming 思路相近，但再次说明可解释性研究正在回到参数干预的中心——如果能定位到极少量的责任神经元，模型编辑、安全对齐与人格控制的成本都将显著下降。

学术价值：为"可解释的模型编辑"提供了极强的稀疏性证据，把行为改变从"全参数扰动"收缩到"触发器重连"。局限在于目前仍是单一模型、单一行为的案例，跨任务与跨模型的可推广性有待系统验证。
📎 来源：马东锡 NLP(@dongxi_nlp)

1.8DeepMind AlphaGenome 2：在数百万个 DNA 变异中定位罕见病病因

在 Google DeepMind 播客中，Avsec 与 Adam Gayoso 介绍了 AlphaGenome 2 如何帮助科学家批量测试数以百万计的 DNA 改变，从而为罕见病寻找遗传线索。[17] 节目覆盖基因型与表型的关系、Transformer 架构如何用于基因组建模、变异效应映射，以及从真实罕见病案例到未来愿景的完整路径。

这延续了 AlphaFold 所确立的范式，但对象从蛋白质结构转向调控基因组学：模型需要预测非编码变异对表达、剪接等过程的影响，而这类效应往往更微弱、更依赖上下文。

学术价值：AI for Science 的评价重点正在从"单项预测精度"转向"变异效应预测的校准与临床可用性"。对研究者而言，AlphaGenome 2 提供的是假设生成工具，而非直接的致病判定器。
📎 来源：Google DeepMind(@GoogleDeepMind)

Deep Dive · Benchmark & Evaluation

TestPrism：用联合成功函数校正测试生成的"虚高"

论文
TestPrism（测试生成基准）
机构
南京大学 · 刘佳恒团队
任务
Coding Agent 的测试生成质量评估
规模
17 个来源 · 300 个任务 · 3000 个候选实现
核心指标
Joint Success Function（JSF）
被试
14 种 Coding Agent

研究问题

测试在智能体工作流中的角色已经改变：它既是软件质量的保障，又充当 Agent 自我验证的依据、代码评审的证据，甚至强化学习中的奖励信号。因此"测试写得好不好"直接决定了下游环节能否信任 Agent 的判断。然而主流测试生成基准沿用单一参考答案评测，隐含假设是"通过标准答案即正确"。

核心创新

TestPrism 的关键不在于更大的数据量，而在于把需求与实现分离。它为每个任务构建一个"实现面板"：既包含多个经验证的正确实现，也包含多个貌似合理但含缺陷的错误实现。评测时不再问"能否通过某一份答案"，而问测试是否具备区分能力。JSF 将这一能力形式化为三个必须同时满足的条件：

  • 在原始（含缺陷）代码上失败；
  • 接受所有正确实现，而非只接受参考实现；
  • 拒绝所有错误实现，而非只拒绝某一种错误。

关键结果

在 14 种 Coding Agent 上，传统单一参考指标给出的合格率被高估约一倍。这一偏差并非随机噪声，而是方向一致的系统性高估：模型倾向于生成与参考实现细节绑定的测试，把"实现选择"误当作"需求约束"，同时放过那些与参考写法不同但同样有 bug 的实现。

局限与启示

构建多实现面板的成本远高于单参考标注，这限制了基准的规模扩张；此外，正确/错误实现的构造本身依赖专家判断，可能引入新的偏置。但其方法论意义明确：凡是把测试当作奖励信号或验收证据的系统，都应报告"接受正确实现"与"拒绝错误实现"两个维度的联合指标，而非单一通过率。

📎 来源：新智元（2026-11-12）
Deep Dive · Training & Continual Learning

Speculative Self-Distillation：把"老师"限制在关键分叉处

论文
Speculative Self-Distillation（SSD）
机构
Stanford University · Azalia Mirhoseini 组
会议
NeurIPS 2026
作者
Shayan Talaei 等
目标
推进 accuracy–efficiency–forgetting 前沿
场景
向模型注入新文档知识而不遗忘旧能力

研究问题

让模型学会一份新文档，同时不破坏既有能力，是持续学习中的经典难题。传统知识蒸馏由教师全盘生成训练轨迹，学生被动模仿，容易偏离自身分布（off-policy），并放大遗忘；而完全自训练又缺少新知识的注入渠道。SSD 要回答的是：能否让学生保持"自己写"，只在必要时接受教师纠正？

核心创新

SSD 的教师与学生是同一个模型，唯一区别是教师额外持有新文档信息。生成 rollout 时二者协作：学生先写，教师监控其偏离程度，只有当学生"漂移过远"时才接管后续生成。这样训练数据既保持了学生的 on-policy 特性，又在关键分叉点注入了教师所掌握的额外信息。

从方法论看，这相当于把蒸馏的干预粒度从"整条轨迹"细化到"关键 token 段"，用推测式（speculative）的接受/接管机制在效率与知识注入之间取得平衡。

关键结果

作者报告 SSD 将准确率、效率与遗忘三者的前沿整体前推，且无需额外教师模型或外部标注，训练成本低于常规双模型蒸馏。由于原始材料未给出逐项数值，复现时应重点关注偏离阈值、接管比例与遗忘度量三个超参数。

局限与启示

"同一模型 + 额外信息"的设定降低了部署门槛，但也意味着教师的能力上限就是学生本身；当新知识与模型先验冲突较大时，教师可能在关键处仍给出错误引导。后续工作值得检验其在多文档、长文档与多轮增量学习下的稳定性。

📎 来源：Stanford AI Lab(@StanfordAILab)（2026-11-12）

四、趋势观察Trends & Outlook

以下判断基于本期材料，属于研究者的观察与推测，而非既成结论。

01

System One 与 System Two 正在分层，决策模型成为独立类别

Jev 在九月中旬发布后，八周内 OpenAI、Cloudflare、Google 相继跟进判断型小模型，Google 更在大会上当场发布 Gemini Decision 1。[13][11] 其共同特征是：不生成文本，只返回结构化选择、分数或概率，以低延迟、低成本换取可靠性。Jev 作者、RLHF 共同创造者 Diogo Almeida 的判断值得记录——今天的 LLM 为"有人监督的辅助"优化，而非为"无人监督的自动化"优化，"95% 爱因斯坦 + 5% 憨豆先生"对聊天机器人可以接受，对后台决策却是致命的。[14] 这意味着未来的系统架构可能不是"一个更大的模型"，而是"生成模型 + 决策模型 + 确定性检查"的分工。

02

Agent 评测从"单一参考答案"转向"联合成功"与"行为判定"

TestPrism 揭示单一参考评测会把测试能力高估约一倍；Interaction-as-a-Judge 则主张让智能体真正操作应用，用轨迹而非输出来评判。[4][5] 同一转向也出现在工程侧：Vercel 强调 Agent 已成为软件的使用者，评测必须覆盖 Discovery、Selection、Access、Success 全漏斗，而"下单成功"不等于"下对了单"；[29] Plurai 则用数字孪生环境在真实用户之前暴露失败。[30] 评测对象正在从"答案"变为"过程与后果"。

长时程自主智能体的瓶颈在"模型之外"：确定性检查与基础设施

1000 个智能体形式化费马大定理的案例说明，长时程任务的核心已不是单次生成质量，而是奖励、评测与协作协议。[1][2] 工程实践给出同一结论：SpaceX Superintelligence 的 Lauren Tan 带 Agent 上线约 3000 个 PR、回滚率约 0.5%，GrokBot 团队单月 11000 个 PR、回滚率稳定在 0.5%，其共同规则是"每次纠正 Agent，就把它变成一条确定性检查，而不是写进 agents.md"。[24][25] 支撑这一点的还有底层系统进步，例如 TPU Sync 让 KV cache 与权重可以跨 HBM、DRAM、存储与网络迁移。[21]

AI for Science 从结构预测走向基因组、临床与科研流程本身

可解释性研究回到参数干预：稀疏性与因果性是下一阶段的关键词

Sparse Rewiring 用 89 个神经元复现完整 SFT 的行为，SteerDistill 则用闭环教师引导完成 Agent 量化。[16][20] 两者共同指向一个方法论转向：不再只做"事后解释"，而是通过最小干预来验证因果——如果只改动极少量参数就能复现或消除某行为，那么对该行为的机制解释才真正成立。对学术研究而言，这比生成看似合理的自然语言解释更具可检验性。
