AlphaProof Code：AI 首次在代码级形式化验证 Signal 协议安全

形式化验证定理证明安全

Google DeepMind 披露其 AlphaProof Code 框架首次用 AI 在代码层面形式化验证了 Signal 即时通讯协议的密码学实现——该系统每天保护数十亿条私密消息。团队借助 Gemini agent 在 Lean 中生成了逾 600 万行证明，并通过自动审计把人类专家需要复核的范围压缩到最关键的 1%。

这项工作的方法论意义在于：AI 辅助定理证明正从「数学竞赛题」走向「关键基础设施验证」，把专家的注意力从全量审查重新分配到高风险证明片段，为通信、电网等系统的可扩展正确性证明提供了范式。

📎 来源：Google DeepMind (@GoogleDeepMind) · Lean 证明细节

Earlybird：29M 参数流式识别器「抢跑」90ms，为语音 Agent 抢回时延

流式 ASR端侧低时延

传统流式语音识别要等说话人把一个词说完（约 90–400ms）后才输出，对语音 Agent 而言每一毫秒都影响响应。Earlybird 通过将音频在随机位置（包括词中间）截断来训练，要求模型预测截至此刻应出现的全部词，并额外猜测后两个词；其原始 token 概率天然给出逐词置信度，包括仍在发音中的词。

在 LibriSpeech test-clean 上，中位词可在说话人说完前 90ms 被正确预测。模型仅 29M 参数（4-bit 量化下 16.8MB），在精度与体量之间给出了面向实时交互的一条可行折中。

📎 来源：arXiv:2611.14421 · cs.SD / eess.AS

Emilia2：22.9 万小时可控长语音数据集，补齐长时一致性建模语料

数据集长语音生成多说话人

生成高质量长语音要求模型在时间维度上保持内容、说话人身份、轮次切换与表达风格的一致，但多数开源语料只有几十秒短句，长语音基准也至多覆盖两人对话。Emilia2 从真实数据构建短句、单人长语音与多人对话三类形态，保留转写、说话人身份、停顿与声学转场。

该数据集共 22.9 万小时，其中超过 5 分钟的样本占单人长语音时长的 50.0%、对话时长的 66.8%，并提供表达控制标注，直接补上了长时一致性与多说话人可控生成的数据缺口。

📎 来源：arXiv:2611.13614 · cs.SD / eess.AS

Machine Hearing Benchmark：让音频 LLM 感知「人耳之外」

基准音频 LLM感知泛化

多模态 LLM 的感知范围仍以人类可听可见为中心，而物理世界中只有很小一部分波与振动直接可被人耳接收。研究者提出 Machine Hearing Benchmark（MHB），系统评估音频 LLM 能否泛化到人类听觉之外的声音与振动/振荡信号。

MHB 含 6,128 个实例、13 项任务、7 个领域，把「机器听觉」作为一个独立研究方向提出，为超越拟人感知边界的多模态建模提供了统一评测口径。

📎 来源：arXiv:2611.10693 · cs.SD（replace）

压缩之后还剩什么？仅一阶共振峰具备稳健的深度伪造判别力

语音取证鲁棒性可解释特征

在干净实验室录音上表现良好的音频深度伪造检测器，常在电话或平台压缩后失效。该研究在 ASVspoof 2019 上筛查 36 个话语级特征（共振峰、PNCC、LFCC、韵律），并在 ASVspoof 2021 LA 的七种编解码条件下测试：33 个统计显著描述子中，仅 4 个具备大的实际区分度（|r|>0.5，bootstrap 95% CI），且全为一阶共振峰（F1）度量，高度冗余（PC1 解释 79% 方差）。

其收益直接体现为稳定性：36 特征 SVM 在编解码失配下退化 14 个百分点（9.5%→23.5% EER），而 4 特征 RBF-SVM 仅退化 5.9 个百分点。这提示「特征选择」本身即是压缩鲁棒性的来源。

📎 来源：arXiv:2611.13258 · cs.SD

GEAR：把递归自我改进做成「Scikit-learn 式」模块化框架

RSIAgent开源框架

来自 Imperial College London、Duke 等机构的研究者提出开源框架 GEAR，为 LLM Agent 的递归自我改进（Recursive Self-Improvement, RSI）提供通用工具箱。它把采样、候选评测、多样性管理等算法模块，与并行推理等评测设施解耦，使 RSI 算法可以像 Scikit-learn 组件一样被组合、替换与比较，并复用已有的任务执行、评测与版本管理能力。

基于 GEPA（Genetic-Pareto）改进的实验显示，经 GEAR 调优的 Agent 在营销、客服与代码任务上均取得显著提升。论文、项目主页与代码均已公开，把 RSI 从零散技巧推进为可复现的研究基础设施。

📎 来源：机器之心 · 代码 rsi-gear/gear

Swanada：把 12 种文字的端侧 ASR 压进 30MB 以内

端侧 ASR系统工程多文字

面向浏览器与移动运行时的端侧语音识别有四类系统瓶颈：按语言划分的单体 Conformer 每脚本约需 177MiB（12 脚本合计逾 2.1GiB），撑爆缓存配额；静态相对位置编码内嵌 10.2–20.5MB FP32 常量，且 1×1 Conv1d 在 WebAssembly SIMD 上触发缓慢或不支持的 ConvInteger 内核；滑窗 CTC 在边界 token 抖动；44.1/48kHz 采样率失配与 iOS AudioWorklet 静默停滞。

Swanada 以分离编码器、能力路由的 Conformer-CTC，配合上述系统级修复，实现了覆盖 12 种 Indic 与古典文字、单模型 30MB 以下的端侧识别，展示了「模型—运行时」协同设计对边缘部署的决定性作用。

📎 来源：arXiv:2611.13814 · cs.SD

AURA：冻结的通用音频编码器里「藏着」空间线索，但并非线性可得

空间音频统一表征机制分析

空间音频问答要求模型既能识别声源、又能定位声源。现有空间音频-语言模型依赖专用编码器，把空间处理与语义处理分割到不同特征空间。AURA 检验一个未经空间监督训练的通用音频编解码器能否同时承担两者：逐层分析显示，冻结的 codec 确实保留了空间信息，侧向线索主要编码在双耳通道之差中。

但该信息并非线性可得——在双声源场景下，直接在这些特征上训练的模型左右判别仅达到随机水平，其余轴向上也只能给出粗略方向。这为「统一音频表征 + 轻量对齐」的路线提供了机制层面的证据与警示。

📎 来源：arXiv:2611.13687 · cs.SD

AlphaGenome 2: Deciphering how cells read DNA to better understand disease

Google DeepMind · Žiga Avsec、Adam Gayoso 等 · 非商业研究 API / Colab 开放

研究背景
约 98% 的人类 DNA 并不编码蛋白质，而是调控细胞如何工作，也是理解疾病机理、乃至解释「90% 新药临床试验失败」的重要线索来源。同一段 DNA 序列在心、脑、免疫系统中被差异化读取：一个单字母变异为何只在部分细胞中致病、而对其余细胞无影响，是遗传学的核心难题。
核心创新
AlphaGenome 2 把预测粒度从「组织整体」下沉到「单细胞类型」——不再把整块组织当成一张模糊图像，而是逐细胞类型预测同一 DNA 如何被读取。模型在 68 种组织、逾 1 亿条 profile 上训练；更关键的是支持在线适配：研究者只需接入几十个细胞的数据、无需重训练，即可观察 DNA 变化在特定情境下的行为（如疫苗应答中的免疫细胞、驱动肠道炎症的特定细胞、成熟中的造血干细胞）。
实验结果
相比前代模型，AlphaGenome 2 识别出的「开关基因」调控性突变数量接近翻倍；单细胞分辨率的支持使其能解释「同一变异为何只影响某些细胞类型」这一长期悬而未决的问题。
学术意义
该工作把基因组学基础模型从「序列→轨道」的静态预测，推进到「细胞类型条件化 + 少样本在线适配」，为罕见病定位、靶点发现与湿实验设计提供了可交互的研究基础设施。通过 API 与交互式 Colab 向非商业研究开放，也显著降低了实验团队的使用门槛。
📎 来源：Google DeepMind Blog · 官方线程 · DeepMind Podcast

Walrus Technical Report: A Unified 8B Speech-and-Audio Foundation Model

Walrus 团队 · arXiv 预印本 · 骨干由 Gemma 4 初始化

研究背景
语音与音频任务长期各自为战：语音识别、语音翻译、TTS、情感识别、音频描述与通用音频理解分属不同模型与数据管线。如何用统一基座覆盖多任务，同时让性能增益可归因（而非混在架构改动里），既是工程问题也是科学问题。
核心创新
Walrus 的主要贡献不是新架构，而是一套「以数据为中心」的三阶段训练课程：采用标准 decoder-only 骨干并由 Gemma 4 初始化，使增益可追踪到数据。语音生成侧预测低比特率离散语音 token，再由轻量 token-to-waveform 解码器还原高保真音频；课程从广泛多语数据逐步过渡到多说话人、语码转换等更难场景。
实验结果
单一 8B 模型覆盖语音识别（含语码转换与多人对话）、语音到文本与语音到语音翻译、TTS、情感识别、音频描述与通用音频理解，验证了统一 audio foundation model 在多任务上的可行性。
学术意义
当架构趋同、骨干可复用时，训练数据的组织方式成为可复现、可比较的研究变量。该报告把「数据配方」提升为一等公民，对音频基座模型的复现、对比与评测方法学具有直接参考价值。
📎 来源：arXiv:2611.13689 · eess.AS

04趋势观察

从本期样本中提炼的四条方向性判断。

① 从「架构创新」到「数据配方」：语音基座模型的新胜负手

Walrus 明确以数据课程而非新结构作为主贡献，Antalia-2 Mini 用纯合成语音把小模型推到可用，Emilia2 则以数据规模与形态补齐长时一致性。三者指向同一判断：当 decoder-only 骨干与量化工具趋于成熟，可复现、可比较的数据组织方式正成为区分研究质量的关键变量，也为「消融即论文」提供了更严谨的土壤。

② 端侧与效率成为可落地研究的硬约束

Earlybird（29M / 16.8MB@4bit）、Swanada（<30MB、12 文字）、Antalia-2 Mini（7.6M）与 ESDCodec 共同表明，语音研究的评价维度正从单纯的 WER/MOS，扩展到参数量、比特率、时延与运行时兼容性。「模型—运行时」协同设计（WebAssembly SIMD、AudioWorklet、采样率对齐）本身已成为可发表的研究内容。

③ 基因组学基础模型：单细胞分辨率与少样本在线适配

AlphaGenome 2 把条件化粒度从组织下沉到细胞类型，并支持用几十个细胞的数据即插即用，反映出生物基础模型的两条明确走向：更细的条件化维度，以及「免重训练的在线适配」。这与 NLP 中的 in-context / few-shot 思路同构，但面临更严格的湿实验可验证性约束。

④ 感知边界外扩与「研究基础设施」的框架化

Machine Hearing Benchmark 与 AURA 一同把音频研究推向人类感知之外及空间维度，并强调机制可解释性（冻结编码器保留了信息、但非线性可得）；GEAR 则把 RSI 工程化为可组合框架。二者共同提示：本领域正在从「刷榜单」转向「建基础设施 + 讲清机制」，框架与基准的学术价值在上升。这与 Sutton 近期重提《苦涩的教训》、强调可随算力扩展与持续交互学习的方向形成呼应。
