一 · 研究动态

01VISTA：视觉原生 Harness，让多模态模型「按需回看」

何恺明团队提出视觉原生 Harness 框架 VISTA（A Visual Harness for Reasoning in an Interactive World），针对多模态模型在持续交互中难以留存与利用视觉经验的痛点：通过无损视觉记忆与主动检查机制，让模型无需重新训练即可随时回看、放大、对比历史画面。与将环境抽象为文字或代码的常规做法不同，VISTA 保留原始视觉信息，把「过去看过的画面」变为可反复调用的上下文。评测上，搭配 VISTA 后 Claude Opus 5.0 通关 ARC-AGI-3 全部 25 个公开游戏，相对人类动作效率得分达满分 100，动作数比首次游玩的人类基线少 57.4%；GPT-5.6 Sol 同样全部通关并取得 99 分。团队还在浏览器游戏、迷宫与连线题中验证，并将具身任务列为后续方向。学术意义：把「视觉经验」从一次性输入提升为可主动检索的记忆结构，为多模态长程推理提供了与文本 harness 并列的原生范式。

02MiTA（NeurIPS 2026）：注意力也是一种 FFN

北京邮电大学团队提出的 Mixture-of-Top-k Attention（MiTA） 已被 NeurIPS 2026 接收，代码已开源。工作从一个被忽略的等价关系出发：把标准注意力的公式展开，其结构恰好是一个前馈网络（FFN）——查询对应输入，变换后的键值对应两层权重，指数函数对应激活，而隐藏层宽度由固定维度 D 变为序列长度 N。换言之，长上下文的开销不止来自「更多 token」，还来自「一个不断变宽的网络」，区别关键在于权重来源是训练得到的慢权重还是由输入即时生成的快权重（Fast Weights）。团队据此发展出一套五维分类框架，重新组织线性注意力、混合专家注意力、Top-k 注意力等看似不同的路线，并设计出可变形、可复用的 Top-k 专家，兼顾全局信息与按需读取原始细节。学术意义：为高效注意力研究提供了统一的理论坐标，把「路线之争」转化为「如何组织这个随输入生成权重的网络」的设计问题。

03RSI-Anything：把递归自我改进从代码推广到任意领域

PhAI Labs 提出 RSI-Anything，主张 AI 的递归自我改进（RSI）不应局限在代码或数学等单一任务，而应通过统一的「预测—反馈」框架组织差异巨大的任务域。实验证据覆盖四类场景：在代码修复中，不更换写代码的模型、不增加在线测试预算，仅让世界模型参与预测与选择修改方案，成功率即从 26.3% 提升到 31.2%；在 OSWorld 图形界面交互任务上，相对既有方法任务成功率提升约 18.4%；在实验室规划中，一个仅 4B 参数的策略模型经连续五代改进，规划分数从 21.80% 升至 46.01%，略超采用更大模型组合的参考系统；在化学实验中，同样 40 次实验下预测驱动的搜索把平均最佳产率推至 96.15%（贝叶斯优化对照为 82.16%）。学术意义：这些任务的状态形式、行动空间与反馈机制截然不同，却能被组织进同一套改进循环，为 RSI 从「概念叙事」走向「跨域可复现方法」提供了具体证据。

04RoboFoundry：把「系统」本身当作可进化的策略

来自新加坡南洋理工大学、北京航空航天大学、新加坡国立大学、上海交通大学与云蝶科技的研究团队提出 RoboFoundry，定位为首个把智能体系统本身形式化为「自进化的系统即策略（Self-Evolving System-as-Policy）」的具身框架：基座模型保持冻结，进化只发生在模型周围的上下文系统、技能系统与执行接口上，并借助一层共享语义接口在不同机器人之间复用。核心观察是「同一个 GPT-5.5，放进不同系统里表现悬殊」——在 EmbodiedBench 上直接使用 GPT-5.5 的平均成功率为 56.9%，参数一字不改、只让周边系统持续进化后升至 72.7%。实验中 RoboFoundry 使五个基座模型全部获得提升；在长程记忆基准 RoboMemArena 上任务成功率比所有基线至少高 39.0%。学术意义：它把具身研究的优化对象从「模型权重」推进到「模型所在的整套系统」，为「系统级」而非「参数级」的自我改进提供了首个较完整的实验范式。

05DeepSeek-V4 的「周期性盲区」：装饰性符号即可翻转答案

字节跳动 Seed 团队联合普林斯顿大学、斯坦福大学及加州大学伯克利分校的研究者，在测试 DeepSeek-V4 时发现一个可复现的异常：让模型补全其 FP8 推理内核中的一行代码，标准答案为 8，模型却频繁输出 32；更关键的是，不修改任何核心代码，仅在前方无关注释中逐个增加装饰性的 = 符号，答案便在 8 与 32 之间来回翻转，且每隔 4 个 token 重复一轮。多敲一个符号即可颠覆判断，说明这并非随机误差，而是一种结构化的「周期性盲区」。学术意义：它把长上下文检索中的失效从「能力不足」重新定位为「输入扰动下的稳定偏差模式」，对 KV 检索机制的可解释性、评测鲁棒性以及推理内核的工程正确性都提出了新的检验要求。

06LoGRA（NVIDIA）：全权重更新的 RL 显存可低于 LoRA

NVIDIA 的一篇新论文提出 LoGRA，在 RL 后训练中同时更新模型全部权重，却取得比 LoRA 更低的训练显存。机制上，LoGRA 从不显式构建权重矩阵的完整梯度：随着 micro-batch 累积，每个权重梯度被一个每步重抽的 rank-256 随机投影压缩，更新再由两个小矩阵重建；每步之前，方法还会预测策略将变化多少以决定步长。实测在 1.5B 模型上，LoGRA 平均训练显存为 7.2 GiB，而 rank-256 LoRA 需 13.2 GiB；Pass@4 基本持平（81.8% 对 81.4%），Pass@1 低约 2 个点。学术意义：在「全参数微调能力」与「参数高效微调的显存」之间给出了一条新的折衷曲线，对以显存为瓶颈的 RL 扩展实验具有直接的工程价值。

07多 agent + 持久记忆对照实验：收益到底来自哪里？

一篇被评价为「必读」的论文对近期流行的多 agent 系统与持久记忆做了冷静的量化检验。作者构建了一个三层 agent 链，发现把长上下文工作拆分到多个 agent 上，可将单查询峰值 KV cache 从约 35 MiB 降到 14.3 MiB（对照单遍与 RAG 基线），即分工带来的主要是显存效率收益。而「持久记忆—回召」层只增加 0.368 MiB 峰值缓存，对准确率的影响为 +0.015，且置信区间跨越零——即统计上不显著。作者解释了原因：单问题基准给每个样本配备独立证据并单独评分，存储的历史轨迹没有可被有效回召的对象。学术意义：这是对「多 agent + 记忆」热潮的一次方法学纠偏，提醒评测设计本身会决定结论——要证明记忆的价值，必须换用可跨样本累积的评测协议。

08QwenGyre：面向极长程 agent 训练的弹性 RL

阿里 Qwen 团队发布 QwenGyre，针对超长程（XLong）agent 强化学习中的两个瓶颈给出设计。其一是 Elastic Scheduler：在 rollout 与训练之间按需求动态重分配 GPU，且进行中的执行不被中断，相对 Colocate 提速最高 1.85×、相对 Async 为 1.78×。其二是 Trajectory Processor：把分叉的执行（压缩、子 agent、重试）组织为前缀共享的轨迹树，得到有界且去重的训练样本，且超时后的部分进展仍可被计分。在 Qwen3.8-2.4T-A95B 上、每次 rollout 约 70 万 token 的规模下，QwenGyre 在 48 步内把 NL2RepoBench 从 52.5% 提升到 58.5%，端到端训练时间较 Async 缩短约 44%。学术意义：把长程 agent 训练的瓶颈明确为「调度」与「轨迹表示」两个可工程化的问题，为大模型 agent 的 RL 基础设施建设提供了可复现的技术路线（论文 arXiv:2609.33848）。

📄 Mixture-of-Top-k Attention（MiTA）：把注意力放回 FFN 的统一视角

作者/机构
北京邮电大学团队（论文被 NeurIPS 2026 接收，代码已开源）
研究背景
在 Transformer 中，注意力负责 token 间交互，前馈网络（FFN）负责逐 token 非线性变换，二者长期被视为功能互补的两类模块。随之而来的是高效注意力路线的碎片化：线性注意力、混合专家注意力、Top-k 注意力各自成体系，缺乏统一的理论坐标来比较「它们究竟在改什么」。
核心创新
论文指出一个被忽略的等价关系：标准注意力本身就可以写成一个 FFN——查询对应输入，变换后的键与值对应两层权重，指数函数对应激活，偏置为零，隐藏层宽度由固定维度 D 变为序列长度 N。区别只在权重来源：普通 FFN 用训练得到的慢权重，注意力用当前输入即时生成的快权重（Fast Weights）。据此，团队把已有理论扩展为一套五维分类框架，并设计出可变形、可复用的 Top-k 专家，既保留全局信息，又按需读取原始细节。
实验结果
在该框架下构造的 MiTA 兼顾长上下文效率与细节保真；工作已被 NeurIPS 2026 接收，代码在 github.com/QishuaiWen/MiTA 开源，可供复现与对比。
学术意义
此前「长上下文开销高」多被解释为「处理了更多 token」；本文提供一个更本质的解释——我们在运行一个宽度随序列长度增长的网络。这既统一了多条高效注意力路线，也把「如何组织这个由输入生成权重的网络」确立为一个可系统研究的设计空间，对后续长上下文架构工作具有方法论价值。

📎 来源：[新智元] 注意力也是FFN？从快权重出发，重新理解高效注意力 | NeurIPS'26 · 论文：arXiv:2602.01219

📄 RSI-Anything：跨域递归自我改进的「预测—反馈」框架

作者/机构
PhAI Labs
研究背景
递归自我改进（Recursive Self-Improvement, RSI）正成为 AI 研究的重要方向，但既有工作多集中在代码、数学等「自带验证器」的领域。一个值得追问的问题是：AI 的自我进化为何一定要局限在某一类可形式化验证的任务里？不同任务的状态形式、行动空间与反馈机制差异巨大，能否共享同一套改进机制？
核心创新
方法可概括为「让世界模型参与预测与选择，并用真实反馈继续适配预测器」。关键在于改进的对象不是写答案的模型本身，而是外围的世界模型 / 预测器——由它来预测并挑选候选方案，再以环境的真实反馈校准预测，从而在没有额外算力预算的条件下获得稳定增益。
实验结果
跨四个差异巨大的领域验证：代码修复成功率 26.3% → 31.2%（未换模型、未增测试预算）；OSWorld 图形界面交互任务相对提升约 18.4%；实验室规划中 4B 策略模型经五代改进，规划分数 21.80% → 46.01%，略超更大模型组合的参考系统；化学实验中同预算 40 次实验，平均最佳产率 96.15%，高于贝叶斯优化的对照 82.16%。
学术意义
它把 RSI 从「某个特定领域的技巧」提升为「一套可跨域复用的改进循环」，其价值在于证明：即便任务间状态与反馈形式迥异，只要能把问题表述为「预测—验证—反馈」的闭环，改进即可发生。这为 RSI 研究提供了一个不依赖特定验证器的通用落点。

📎 来源：[机器之心] 从预测万物到自我进化：PhAI Labs 提出 RSI-Anything，探索通用 RSI 新路径
