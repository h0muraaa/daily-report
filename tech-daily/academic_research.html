一、研究动态 Research Highlights

Stanford 启动 Marin 535B-A23B 开放训练：18.75T tokens、2.7e24 FLOPs 的 hero run
📎 来源: Stanford AI Lab
开放训练Scaling Law

Percy Liang 宣布斯坦福团队本周正式开训 Marin 535B-A23B，且整个过程完全公开。航行计划为：在 11 台 GB200 NVL72 上以 18.75T tokens 完成预训练（80%）与中期训练（20%），预计耗时约 3 个月、总计算量 2.7e24 FLOPs，随后进入后训练阶段。开训前团队先训练了一组 4 级 scaling ladder（从 1.6B-A61M / 48B tokens 到 27.7B-A1.2B / 926B tokens）以排查问题并预测 hero run 表现，团队自陈"这是迄今最大的一次运行，必然会有意外"。对研究界而言，这一完全开放的超大规模训练流程，连同用 scaling ladder 做训练前预测的方法论，是观察前沿大模型如何规划与验证训练路线的罕见一手资料。

Google DeepMind 单字标题论文 "Recirculation"：推理期循环替代链式思考
📎 来源: elvis
架构创新推理时计算

Google DeepMind 一篇罕见使用单字标题的论文获得 AI 研究者力荐，核心是一种 training-free 的架构演化思路——由模型自身来指导架构修改。论文指出，前馈 Transformer 一次前向传播能更新的内部状态次数受限于层数，面对长生成时 chain-of-thought 只能退化为在文本空间做"临时记事本式"的状态跟踪；而 "Recirculation" 在推理阶段引入循环，让模型在 prefill 期把激活值反馈回自身，使网络在固定参数下像动力系统一样跟踪并修正信念状态，完全无需重训。该方法可能为递归自我改进（RSI）提供更鲁棒的机制基础（详见深度解读）。

RSI 关键实证：Agent 后训练策略在第一步就被"锁定"
📎 来源: elvis
递归自我改进后训练

一篇追踪递归自我改进（RSI）进展的重要论文指出，当前模型尚无法真正做好"让 AI 改进 AI"：障碍从模型创造力不足到陷入局部最优不一而足。研究团队系统分析了一大批公开发布的后训练轨迹，最引人注目的发现是——"agent 的训练策略在最开始就被锁定，剩余的全部预算都花在了该策略内部的局部调整上"。这意味着智能体在第一步就决定了训练策略，随后只是在既定框架内做局部微调，几乎没有策略层面的探索。该发现为理解 RSI 为何多停留在口号层面提供了经验证据，也把后训练自动化的突破点明确指向"策略探索"而非"策略内调参"（详见深度解读）。

NVIDIA 自研编码 harness 在 ARC-AGI-3 达 100%，解出全部 183 关
📎 来源: clem 🤗
AgentARC-AGI

NVIDIA 构建了自己的编码 harness 对 CUDA GPU kernel 进行自动优化，并在 ARC-AGI-3 的 25 个公开游戏上拿到 100% 得分、解出全部 183 关。clem 据此断言，Agent 将把"运行、优化、后训练自己的模型与 kernel"从极少数人的特权变成人人可为的能力，并抛出"何时迎来 100 万 AI builders"之问。这类"用 profiler 与数据集对 X 迭代直到达到 Y"的自优化范式，与 Boris Cherny 描述的"用 Opus 对 CPU/内存/CI 时间/帧率做 hill-climb"同属一个新兴方向：AI 驱动的程序优化正从实验演示走向常规工具。

TRACES：一个"不信任正确答案"的发现式智能基准
📎 来源: 马东锡 NLP
基准测试过程监督

马东锡 NLP 介绍了名为 TRACES 的新基准，定位是"检验结果，审计过程"的发现式智能（discovery intelligence）评测，自我标榜为 "the benchmark that distrusts a correct answer"。与传统只看最终答案是否正确的基准不同，TRACES 强调对智能体得出结论的完整过程进行审计，呼应了学界围绕"过程监督（process supervision）vs 结果监督（outcome supervision）"的争论。对评估推理过程的可信度与可复现性而言，这是方法论层面的一个新尝试。

DRAM 控制器寄存器操纵打破 CPU 内存隔离：开源工具 skitter-creek-bath-salts
📎 来源: InfoQ
硬件安全内存隔离

安全研究员 Christopher Domas 开发了开源硬件安全工具 skitter-creek-bath-salts，通过操纵内存控制器翻译寄存器（translation registers）破坏 CPU 特权边界，使非特权软件得以访问受保护内存区域。该工具揭示了现代处理器架构在内存隔离方面的一处底层漏洞，可能动摇云计算与机密计算（confidential computing）的安全假设。对系统安全研究而言，这是"控制器寄存器操纵"层面的一个新攻击面样本，也再次提醒：硬件层面的隔离机制需要与软件侧的形式化验证一起纳入安全评估。

Anthropic 经济研究：AI 未推高失业率，2024/2025 产出增长超 2000%
📎 来源: 新智元
AI 经济学劳动力实证

Anthropic 经济研究负责人 Peter McCrory 发布长文，结论直白：AI 没有抢走任何人的工作（至少到目前为止）。数据链条是——经质量调整的 AI 产出在 2024 与 2025 年均增长超过 2000%，约五分之一的美国企业已在业务中使用 AI，但 2026 年 6 月美国失业率仍为 4.2%，恰好处于充分就业水平。McCrory 的核心判断是 AI 目前是一种"技能偏向型、劳动力增强型"技术，但他给这一结论标注了 12 个月的有效期。其与 Maxim Massenkoff 的对照分析显示，Claude 高自动化岗位的失业率并未比其他岗位恶化，软件工程类招聘帖自 2025 年 5 月起反弹；唯一值得关注的是年轻劳动者在 AI 高暴露岗位上求职变难，斯坦福数字经济实验室的研究提供了类似证据。

Netflix 公开基于 Triton 与 vLLM 的内部 LLM 推理服务平台经验
📎 来源: AI前线
推理系统生产实践

Netflix 公开了将 LLM 推理纳入内部服务平台的生产经验，涉及支持不同模型规模、硬件需求与快速演进的推理引擎所面临的真实挑战。平台构建在既有 JVM 服务层之上，小模型可在 CPU 进程内运行，大请求则委托给 MSS（model serving service），由 Triton 负责模型加载、批处理、GPU 调度与多框架服务，vLLM 负责实际推理并暴露扩展点。文章特别指出：不匹配的 Triton 与 vLLM 版本会导致部署无法加载，必须一起测试并固定兼容版本；vLLM 对 Hugging Face 的兼容性对部分 Netflix 自研模型不足，需借助 vLLM 扩展点支持自定义架构与解码行为。这一案例为"多引擎共存的 LLM 推理平台"提供了难得的工程细节与运维经验。

二、深度论文解读 Deep Paper Review

《Recirculation》—— Google DeepMind 单字标题论文：推理期循环让前馈模型无需重训即可跟踪信念状态
📎 来源: elvis 推荐 · Google DeepMind

研究背景

前馈 Transformer 一次前向传播能更新的内部状态次数，受限于其层数；面对远超层数的长生成，模型只能通过 chain-of-thought 在文本空间里做"临时记事本式"的状态跟踪，既低效也容易失真。这篇论文从这个观察出发，质疑了"堆层数 / 堆思考文本"之外的第三条路径：能否在固定权重下，用推理时的计算图改造来获得更强的状态跟踪能力？

核心创新

Recirculation 在推理阶段引入循环：模型在 prefill 期间把激活值反馈回自身，使网络在参数完全不变的前提下像动力系统一样迭代演化，从而跟踪并修正信念状态。整个方法属于 training-free 的架构演化——不改变权重，仅改变推理时的数据流，并利用模型自身的行为来指导架构层面的修改。这与当下热门的"测试时扩展"（Test-time Scaling）不同：它扩展的不是采样数量，而是网络内部的状态更新次数。

学术意义

在 RSI（递归自我改进）成为热点、但"改进什么"仍模糊的当下，这篇单字标题论文提供了一个具体且可复现的机制：把"架构演化"放到推理期，让模型自指式地改进自身的计算结构。研究者认为这可能启发更鲁棒的递归自我改进方法。论文将推理时计算与架构搜索两个原本分离的方向桥接起来，其"训练-free"特性也使其易于被社区复现与扩展，是值得关注的架构研究信号。

Agent 后训练轨迹研究：为什么当前模型尚不能真正实现 RSI
📎 来源: elvis 推荐 · 后训练轨迹语料分析

研究背景

递归自我改进（RSI）在 2026 年已演变成一条拥挤的创业赛道，但"AI 能否真正后训练 / 改进 AI"始终缺乏系统的经验证据。常见质疑集中在模型创造力不足、容易陷入局部最优等。本工作试图回答一个更具体的问题：让 Agent 去后训练另一个 Agent，到底会发生什么？

核心创新

研究团队系统分析了一大批公开发布的后训练轨迹，跨任务地考察智能体在后训练过程中的策略演化。最引人注目的发现是："agent 的训练策略在最开始就被锁定，剩余的全部预算都花在了该策略内部的局部调整上"——也就是说，智能体在第一步就决定了训练策略，随后只是在既定策略框架内做局部微调，几乎没有策略层面的探索。这直接把 RSI 的瓶颈定位到了"策略探索"而非"策略内调参"。

学术意义

这一发现为"当前模型尚不能真正实现 RSI"提供了直接的经验证据，也解释了为何多数 RSI 实践停留在自我纠错、持续后训练等局部改进层面，而非范式级的自我升级。对跟踪 RSI 前沿的研究者而言，这是理解该领域真实水位的重要标尺：若要实现真正的自我改进，突破口可能在于打破"开局即锁死策略"的倾向，而不是在既定策略内做得更好。

数据集AI for Science

科学家发布了迄今最大的宇宙二维地图，包含 5.6 万亿像素、近 40 亿个天体，并免费向公众开放，用于暗物质与暗能量研究。这类超大规模天文巡天数据对 AI for Science 中的目标检测、分类与大规模图像检索等方向是高质量的训练与评测资源，也体现了"开放数据 + 基础科研"的结合，为天文交叉研究提供了难得的数据底座。

local.ai：面向本地 AI 模型的硬件基准测试
📎 来源: GitHub
基准测试本地模型

GitHub 推出的 local.ai 面向本地 AI 模型的硬件基准测试：不满足于 tokens/sec 单一指标，而是比较任务质量、端到端任务时间、硬件成本与电费成本。其早期访问版能自动检测用户机器配置并推荐合适的本地模型，帮助用户在购买昂贵 GPU 之前做出更理性的选择。对研究设备选型与推理效率对比而言，这是一个把"效率"落到硬件成本层面的实用工具。

Semantica：让 AI 决策可追溯的开源图谱基础设施
📎 来源: 逛逛GitHub
知识图谱可审计

本周热门开源项目 Semantica 是一套面向 AI Agent 的图谱基础设施：把文档、网页、数据库等零散资料整理为知识图谱，识别人物、公司、事件及其关系，使 Agent 不仅能做相似度检索，还能理解信息之间的连接、来源与冲突。更关键的是，它把 AI 使用的数据与决策过程（包括因果关系与执行过程）保存为可查询的审计记录，并可导出 JSON、CSV 或 RDF。对金融、医疗、法律等重视合规与可追溯性的场景，这是把"AI 决策可审计"落地的开源方案。

Munder Difflin：本地 AI 克隆代理协作的开源多智能体框架
📎 来源: HackerNews 每日摘要
多智能体开源框架

Hacker News 上出现的 Munder Difflin 是一个免费开源的多智能体框架，允许用户创建本地 AI 克隆代理实现团队协作，并支持端到端加密通信。它为多智能体协作、本地化代理与隐私保护的研究与原型验证提供了开箱即用的基础设施，属于"多智能体 + 隐私"交叉方向的稀缺开源资源，对希望快速搭建 Agent 协作实验的研究者具有实用价值。

四、趋势观察 Trends & Perspectives

开源权重 token 占比跨过 62%：Vercel AI Gateway 的分水岭数据
📎 来源: Guillermo Rauch · clem 🤗
开源权重产业趋势

Guillermo Rauch 发布数据：Vercel AI Gateway 上开源权重模型的 token 占比在 8 月 22 日达到创纪录的 62%（闭源 38%），而约两个月前（6 月 24 日）这一比例还只有 28.4%。clem 据此断言"绝大多数 AI workload 最终将基于开源模型"，并指出这才刚刚开始——企业采用仍处于早期，harness、CLI、IDE、SDK 等还需要适配成 model-agnostic。用生产网关的真实 token 分流来度量开源/闭源分野，是比榜单更有说服力的硬指标，值得研究者持续跟踪。

"Ox Alpha" 匿名模型风波：从猜谜游戏到基准完整性质疑
📎 来源: InfoQ · 量子位 · Berryxia.AI
评测完整性匿名模型

OpenRouter 未开发布会、未发布技术报告，仅用一个忍者表情上线了代号 "Ox Alpha"（stealth/ox-alpha）的匿名前沿模型：面向长周期软件工程、复杂推理与结合视觉的 Agent 工作流，拥有超 100 万 token 上下文与 13 万 token 最大输出，参数、训练数据、架构与基准成绩全部保密，预览期免费。该模型上线后迅速演变成一场"猜模型"游戏（Gemini、小米 MiMo V3、腾讯混元、智谱等均被猜测）；量子位报道匿名模型被研究者从 tokenizer、视频编码与 API 报错等细节扒出"智谱血缘"；Berryxia 则记录了社区在 ox-alpha 上跑完整 113 项 DeepSWE 基准的结果——实际通过率 58.4%，与传闻的 80% 相去甚远，几乎等于 Claude Opus 4.8 的 59%。匿名发布、身份猜测与独立复测之间的张力，正在成为评测完整性与可重复性的新议题。

国产 flash 级模型的"过度思考"：十几分钟吐一个字的现象级问题
📎 来源: Orange AI
推理行为后训练

多位从业者交流指出，国产 flash 级模型（ox、DeepSeek Flash 等）存在严重的"疯狂思考"问题：任务越复杂越严重，最极端时可能思考十几分钟才吐出一个字，交互体验很差。有观点怀疑这与过度后训练有关——超出了小参数量模型所能承受的极限。这一现象把"推理时思考开销"与"后训练策略"的关系摆上台面：如何在推理质量、延迟与成本之间取得平衡，已成为小而快模型面临的真实研究问题，也提示后训练强度与模型容量之间的匹配值得系统化实验。

从两遍 RAG 到 harness 评估：文档处理的实证转向
📎 来源: Jerry Liu · Jerry Liu（文档提取实验）
RAGAgent 评估

Jerry Liu 观察到当前 Agent harness（Codex、Cowork）的 RAG 趋势是"两遍处理"：先用免费/开源的轻量文档解析工具对 10–100–1000s 文件做快速低成本扫描，让 Agent 据此检索出相关子集；再对命中页面用 just-in-time 的 VLM 截图解析做精细拆解，从而避免对海量客户文件全量跑 VLM OCR 的昂贵与缓慢。在 schema-guided 复杂文档提取的实验中，其团队比较了 Claude Code、Codex、专用 OCR 工具（含 LlamaParse）与裸 VLM：短文档上专用 OCR 工具成本只有 coding agent 的零头且精度相当，长文档上 coding agent 逐渐贴近成本/精度 Pareto 前沿——因为复杂文档提取本质是推理任务，而 coding agent 就是通用推理 harness。叠加 elvis 关于"用 harness 测模型是彻底坏的、harness 工程正是前沿实验室发力点"的讨论，可以看到：评测与检索方法论本身正成为 Agent 研究的核心战场。
