一、研究动态

Claw-Eval 开源：首个端到端真实任务 AI 智能体评测基准

随着大模型从"回答问题"演进至"执行任务"，Agent 评测正成为能力评估的关键方向。魔搭 ModelScope 社区开源的 Claw-Eval 是业界首个覆盖端到端真实任务的 AI 智能体评测框架，通过 300 个人工验证的真实场景任务，从完成度、安全性与鲁棒性三个维度对 14 个前沿模型进行了系统评估。

该框架的核心设计哲学是"运行层尽量轻量，任务本身足够真实"。与仅关注最终答案的评测方式不同，Claw-Eval 更关注任务是如何被完成的：过程是否可追溯、行为是否合规、异常发生后能否恢复。其执行链路采用 Setup → Execution → Judge 的透明可审计架构，并提供了公开排行榜和数据集。这一工作为 Agent 领域的可复现评测提供了重要基础设施，填补了当前基准测试在"真实任务端到端评估"方面的空白。

[来源: 魔搭ModelScope社区] | GitHub: claw-eval/claw-eval | 排行榜: claw-eval.github.io
SWE Atlas 发布：AI 编程智能体的工程能力首次系统评测

Scale AI 团队近期发布的 SWE Atlas 基准测试，对当前 AI 编程智能体的能力边界提出了深刻质疑。该基准包含 284 道由资深工程师手写的考题，系统评测代码理解、测试编写与重构等核心工程能力，而非仅聚焦于 bug 修复和功能添加。

实验结果显示，前沿模型在 Pass@1 指标上最高仅达 43.49%，做三次能全对的比例骤降 30%~50%。更值得注意的是，模型在代码理解、测试编写、重构等专业工程师日常任务上"几乎全员翻车"。论文揭示了一个被长期忽视的差距：当前最强的 AI 编程智能体是优秀的"补丁工"，却仍然是糟糕的"工程师"。这一发现对 Agent 在软件工程领域的实际落地具有重要警示意义，也指明了未来基准测试和能力优化的方向。

[来源: 新智元]
CNCF 基准测试：RAG 检索并非提升漏洞修复能力的主路径

Brandon Foley 在 CNCF 博客上发布了一项针对 AI 编码智能体的基准测试研究，以 Kubernetes 仓库中的真实拉取请求为基准，测试了三种智能体配置在漏洞修复任务上的表现。三种配置分别采用纯 RAG 检索（KAITO + Qdrant，结合 BM25 与嵌入向量语义搜索）、混合方法（RAG + 本地文件系统）以及纯本地仓库克隆（无检索索引），所有测试均使用 Claude Opus 4.6 模型。

研究发现，AI 编码智能体能够发现并修复孤立漏洞，但通常难以理解系统范围内的影响。在速度方面，纯 RAG 始终最快（平均 76 秒），混合方法最慢（约两分半）。更重要的是，实验结果对"改进代码检索是提升自动化漏洞修复能力的主要途径"这一主流观点提出了挑战，提示研究社区需要重新思考 Agent 的代码理解机制设计。

[来源: InfoQ]
NVIDIA Research 发布 LongLive-2.0：长视频生成的端到端低精度系统

NVIDIA Research 推出了 LongLive-2.0，一套面向长视频生成的端到端 NVFP4 训练与推理系统。该系统解决了低精度部署中训练与推理之间的"精度鸿沟"问题——传统方法依赖训练后量化，导致模型训练方式与实际运行方式不一致。

LongLive-2.0 将 NVFP4 感知训练、知识蒸馏与 W4A4 推理进行了统一对齐，在保持基准质量的同时显著提升了速度和内存效率。这项工作对视频生成模型的实际部署具有重要工程价值，也为低精度训练-推理协同优化提供了新的技术路径参考。

[来源: NVIDIA AI]
Jim Fan 提出具身智能 "Great Parallel"：从 VLA 到 WAM 的范式转变

英伟达 AI 资深研究科学家 Jim Fan 在红杉资本 AI Ascent 活动上的演讲中，系统阐述了具身智能领域的"大平行"（Great Parallel）理论。他将 LLM 的成功路径概括为三步——大规模预训练 → 监督微调对齐 → 强化学习推理，并认为机器人正延续相同路径：用世界模型预训练预测下一个物理状态，用动作微调到仿真空间，用强化学习完成最后一英里。

演讲的核心论点之一是 VLA（视觉语言动作模型）时代的终结。Fan 指出，当前主流 VLA 模型本质上是在 VLM 顶部嫁接动作头，绝大多数参数服务于语言，导致模型"擅长名词却在物理规律和动词执行上严重不足"。WAM（世界动作模型）被认为是新的范式方向。Fan 预测有 95% 的把握在 2040 年达到"机器人终局"——这一时间表为具身智能的研究规划提供了重要参考坐标。

[来源: 十字路口Crossing]

二、开源资源

OpenHuman：带 Memory Tree 的开源桌面 AI Agent

OpenHuman 是一个在 GitHub 上获得 7.2K+ Star 的开源桌面 AI Agent 助手，其核心创新在于解决 Agent 的"冷启动"问题。传统 Agent 安装后对用户一无所知，需要长期交互才能建立理解；OpenHuman 通过 Memory Tree 记忆系统，在安装瞬间即开始构建用户画像。

技术上，系统支持 118+ 个第三方服务的一键 OAuth 连接（Gmail、Notion、GitHub、Slack 等），数据源被标准化为不超过 3K Token 的 Markdown 片段，自动构建层级化摘要树。其 TokenJuice 智能压缩技术可将 HTML 转 Markdown、缩短长 URL、清理非 ASCII 字符，最高减少 80% 的 Token 消耗。系统还生成 Obsidian 兼容的 .md 文件，方便用户直接浏览和编辑 AI 记忆。这一架构为个人 Agent 的长期记忆管理提供了可落地的工程参考。

[来源: 逛逛GitHub]
Harness-as-Interface：不修改模型，只修改运行时接口的 Agent 新范式

一项新的研究工作提出了"代码即 Agent Harness"的核心论点：不要触碰模型本身，而是修改包裹冻结 LLM 的运行时接口，将反复出现的交互失败转化为 Harness 侧的可复用干预策略。实验在 7 个确定性环境、126 个模型-环境配置、18 个骨干模型上取得了平均 88.5% 的相对性能提升。

尤其值得关注的是跨模型泛化能力：从一个模型轨迹学习到的 Harness 可以泛化到另外 17 个骨干模型，这表明 Harness 捕获的是环境结构而非模型特定的模式。这一发现对 Agent 生产部署具有重要启示——Harness 层的投入可能比模型层的调优更具可迁移性和长期价值。

[来源: elvis(@omarsar0)]
DeepSeek 组建 Harness 团队：从零构建代码智能体基础设施

DeepSeek 于 5 月中下旬启动了 Harness 团队的公开招募，目标是从零开始构建对标 Claude Code 的代码智能体产品。官方招聘页面将团队定位表述为一个醒目公式：Model + Harness = Agent——即除模型本身以外的所有工作，都属于 Harness 的范畴。

这一动作反映了中国研究团队对 Agent 基础设施层的高度重视。高级研究员陈德里（Deli Chen，北京大学毕业，2023 年加入 DeepSeek）已成为公司对外沟通的重要代表。Harness 团队的建设方向——包括工具抽象、任务规划、上下文管理、重试机制、安全策略等——与当前国际前沿的 Agent 工程实践高度一致，值得持续关注其开源贡献。

[来源: AI前线]
FinSight：开源 AI 股票研究代理系统，集成 RAG 评估能力

FinSight 是一个开源的 AI 股票研究代理系统，其核心能力在于将公告、财报、研究笔记、市场数据转化为有证据支撑的回答和版本化的研究报告。系统提供了证据溯源报告、工作流编排和 RAG 评估能力，对于研究多 Agent 协作系统、RAG 评估方法论以及金融文本理解的学者具有参考价值。

三、趋势观察

学术界对 AI 能力评估的反思正在加深

本周密集出现的几项基准测试工作（Claw-Eval、SWE Atlas、CNCF 漏洞修复测试）共同指向一个趋势：AI 评测正在从"结果导向"向"过程导向"转变。Claw-Eval 关注 Agent 的完成过程是否可追溯、行为是否合规；SWE Atlas 揭示当前模型在代码理解、测试编写、重构等"工程师日常"上的系统性不足；CNCF 测试则挑战了 RAG 优化作为漏洞修复主路径的假设。

这些工作的共同点是都试图回答一个更根本的问题：AI 系统是否真正"理解"了任务，还是只是在模式匹配？对于研究评估方法论的学者而言，这一方向的探索可能重新定义我们对 AI 能力的测量标准。

"Harness"作为 Agent 工程核心概念的确立

从 DeepSeek 的 "Model + Harness = Agent" 公式，到学术研究中"Adapt the Interface, Not the Model"的实证结果，"Harness"（运行时接口/工程封装层）正在从一个工程术语演变为 Agent 领域的核心研究概念。这一趋势暗示，未来的 Agent 研究可能分化出两条并行路径：模型能力本身的 scaling，以及 Harness 层对模型能力的放大与约束。理解这两条路径的交互关系，对于 Agent 系统的长期设计具有战略意义。

顶级实验室对 AGI 时间表的收敛预测

Anthropic 联合创始人 Jack Clark 和 Google DeepMind CEO Demis Hassabis 本周给出了高度一致的时间表预测：Clark 提出 12 个月内 AI 将与人类合作做出诺奖级发现，18 个月内完全由 AI 运营的公司将创造数百万美元营收，2028 年底 AI 将跨入递归自我改进阶段；Hassabis 则预测通用人工智能将在 2030 年前后降临，冲击力将是工业革命的 100 倍以上。

尽管这些预测本质上属于观点而非可验证的学术结论，但两家风格迥异的顶级实验室在此刻达成共识，本身就构成了一个值得研究的社会-技术现象。对于研究 AI 治理、技术预测方法论以及科学社会学的学者，这一收敛性预测提供了丰富的分析素材。

四、深度论文解读

SWE Atlas：超越补丁的编程智能体能力评测

研究背景：当前 AI 编程领域的基准测试（SWE-Bench、SWE-Bench Pro、TerminalBench 等）几乎都将评测焦点集中在 bug 修复和功能添加两项任务上。然而，真实软件工程的核心能力谱系远比这宽泛——阅读陌生代码库、为新功能编写测试、对历史代码进行重构、回答架构问题、调试仅在生产环境复现的运行时异常等，这些"上游和下游能力"在主流基准中几乎被集体忽略。

核心创新：Scale AI 团队提出的 SWE Atlas 包含 284 道由资深工程师手写的考题，首次系统覆盖了代码理解（Code Comprehension）、测试编写（Test Writing）、重构（Refactoring）和 bug 修复（Bug Fixing）四大能力维度。与自动生成的大规模基准不同，手写考题确保了任务的真实性和对"工程思维"的有效测量。

关键实验结果：前沿模型在 Pass@1 指标上最高仅 43.49%，且做三次能全对的比例比单次骤降 30%~50%。更令人警醒的是，模型在代码理解、测试编写和重构上的得分远低于 bug 修复——这些恰恰是人类工程师日常工作的主要内容。论文因此得出一个尖锐结论：当前最强的 AI 编程智能体是优秀的补丁工，却仍然是糟糕的工程师。

学术意义：这项工作对 AI 编程研究具有范式矫正价值。它提示社区：一味优化 SWE-Bench 分数可能正在制造"能力幻觉"，真正的研究前沿应当转向对"工程能力全谱系"的建模。同时，手写基准 vs 自动生成基准的方法论对比，也为 AI 评估领域的方法论研究提供了新的讨论起点。
