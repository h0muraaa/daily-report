ICML 2026CAMEL：以置信度门控反思重构奖励模型

来自 TikTok 与新加坡国立大学（NUS）的研究团队提出 CAMEL（Confidence-Gated Reflection for Reward Modeling），针对奖励模型（Reward Model, RM）长期存在的"效率—可解释性"两难给出新解。标量判别式 RM 高效但缺乏推理过程，生成式 judge 可解释却需为每个样本生成长思维链；CAMEL 将奖励建模改造为"置信度门控"机制——先以单 token 给出初判，置信度足够高则直接输出，仅当置信度低时才触发 reflection 复核。其关键发现是：两个 verdict token 之间的 log-probability margin 与判断正确性强相关，可作为"样本难度"的零成本信号。实验上，CAMEL 在 RewardBench、RM-Bench、JudgeBench 上取得 82.9% 平均准确率，较此前最佳提升 3.2 个百分点，并以 14B 参数规模超过多个 70B 级奖励模型，建立了更优的准确率—成本 Pareto 前沿。这与 DeepSeek 近期"按置信度分配计算"的推理系统研究方向形成呼应，表明自适应计算分配正成为后训练优化的核心范式。

📎 来源: 机器之心 · 论文: arXiv:2602.20670

机器人学习TouchWorld：面向灵巧操作的触觉基础模型

哈工大（深圳）长聘教授杨朔及其团队（破晓智能 PHANES AI）发表论文《TouchWorld: A Predictive and Reactive Tactile Foundation Model for Dexterous Manipulation》，瞄准机器人操作中"视觉上看做对、物理上未完成"的失败模式。核心论点在于：视觉只能判断动作是否"像"成功，触觉才能确认成功是否真正发生。TouchWorld 让触觉同时承担预测（行动前预测应有的接触状态）与反应（接触后依据真实力反馈快速纠错）双重角色。在浇花、桌面清理、电源插头插入等六项真机任务中，无干扰场景平均成功率 65.0%，加入目标移动与抓握干扰后仍达 57.2%，分别超过最强基线 15.7 和 16.0 个百分点。每项任务仅使用 200 条遥操作轨迹与 100 次真机评测，数据效率值得关注。该工作延续了"将触觉写入机器人基础模型"的研究路线，对具身智能的多模态感知对齐具有方法论意义。

📎 来源: 机器之心 · AI科技评论

多智能体系统GraphPlanner：从"选择模型"到"生成工作流"的 LLM 路由

UIUC 研究者提出 GraphPlanner，将 LLM Routing 从 query 级模型选择推进到多智能体工作流生成。传统 Single-Round Router 只回答"该调用哪个模型"，Multi-Round Router 虽允许多次调用但仍缺乏对协作流程的显式建模；GraphPlanner 在每一步同时决定调用哪个模型以及激活哪个智能体角色，并利用图结构记忆历史交互与当前工作流状态，从而实现任务分解与协作规划。代码已在 GitHub（ulab-uiuc/GraphPlanner）开源。这一方向与本周产业侧"Router 无处不在"的现象（OpenRouter 估值 13 亿美元）形成学术—产业共振：当模型趋于大宗商品化，调度与编排层的理论与算法价值正在凸显。

📎 来源: 新智元 · 论文: arXiv:2604.23626 · 代码: github.com/ulab-uiuc/GraphPlanner

AI 评测方法IRT 测量理论引入 AI 评测：告别 1950 年代的计分方式

Mindmakers 的 Alejandro Vidal 在 AI Engineer 演讲中批评当前 AI 评测仍沿用古典测量理论（Classical Test Theory）——数对题数、等权处理、信任百分比，而心理学界已积累数十年针对"测量不可见且不合作对象"的测量理论。他主张引入项目反应理论（Item Response Theory, IRT，即 SAT/GRE 背后的数学）：将每个测试项目建模在共享能力尺度上并给出真实误差棒，从而识别哪些测试项是纯噪声、哪些最优、能力缺口与意外行为在何处；配合自适应测试（adaptive testing），可用极少题目测量同等能力，支持私有、轮换的评测题库以对抗数据污染。结合 CAMEL 利用 token margin 作难度信号的发现，"评测项目本身的质量建模"正成为评测方法论的显性议题。

📎 来源: AI Engineer

LLM 可靠性"语义盲"：LLM 接入确定性工业系统的架构失配

Phaidra 团队在 AI Engineer 分享了将前沿 LLM 部署于 5 万级传感器工业环境（根因分析、告警分诊、运行决策支持）后的失败案例，提出"语义盲"（Semantic Blindness）这一失效模式：概率性语言模型与具有确定性依赖、热力学约束的物理系统之间存在根本的架构失配——"你不能用下一个 token 预测引擎来解决组合工程问题"。这一经验性结论对 LLM 在安全攸关系统中的应用边界提供了重要的一手证据，也呼应了神经符号（neurosymbolic）方法复兴的合理性。同类地，AWS 的 Elizabeth Fuentes 在同场会议给出抑制智能体幻觉的五种技术（Graph-RAG 减少 73% 虚构统计、语义工具选择降低 89% token 消耗、多智能体验证达 92% 检出率等），可作为结构化缓解方案的参考实现。

二、深度论文解读

论文一：CAMEL — 置信度门控反思的奖励建模

研究背景

奖励模型是 RLHF/RLAIF 对齐管线的核心组件。现有两条路线各有短板：标量判别式 RM 高效稳定但输出仅为分数，难以审计；生成式 judge 能给出判断理由，但每个样本都要生成长思维链，token 与延迟开销在大规模偏好数据标注场景下难以承受。DeepSeek 的 DSpark/DeepSpec 等工作已预示"按置信度分配计算"是推理系统的新焦点，CAMEL 将该思想系统化地引入奖励建模。

核心创新

（1）发现两个 verdict token 的 log-probability margin 与判断正确性强相关，构成零成本的样本难度估计器——这一"白盒置信度"比事后校准更直接；（2）将奖励建模重构为两阶段门控过程：单 token 初判 → 置信度阈值判断 → 仅困难样本进入反思复核，把计算预算花在真正困难的样本上；（3）由此建立准确率—成本的 Pareto 前沿，简单样本成本降至 1 个 token。

实验结果

在 RewardBench、RM-Bench、JudgeBench 三个基准上平均准确率 82.9%，较前 SOTA 提升 3.2%；14B 参数规模超过多个 70B 级 RM，表明方法收益不依赖参数堆叠。

学术意义

CAMEL 的价值不仅在于指标提升，更在于提供了一个可迁移的分析框架：将"模型自身的概率结构"作为难度信号，为自适应推理预算分配提供了原则性依据。该思路可推广至 verifier、过程奖励模型（PRM）乃至通用 judge 系统，是"让模型在不确定时才思考"这一范式在奖励建模上的完整实例化。

论文二：TouchWorld — 预测与反应一体化的触觉基础模型

研究背景

当前视觉—语言—动作（VLA）模型主要依赖视觉监督，但触觉信息缺失导致"看起来做对了、物理上没完成"的失败普遍存在——指尖贴上按钮与真正按下按钮在图像上几乎不可区分。如何让机器人基础模型"摸得懂"真实世界，是灵巧操作走向实用化的关键瓶颈。

核心创新

TouchWorld 将触觉建模为双重角色：预测式（predictive）——行动前预测"应该碰成什么样"，为规划提供触觉想象；反应式（reactive）——接触后依据真实力/触觉反馈快速纠错。这一"预测—反应"闭环与人类操作中的触觉使用方式相符，本质上是在基础模型层面统一了触觉的前馈与反馈通路。

实验结果

六项真机任务（浇花、桌面清理、插头插入、杯子插入、擦锅、抽纸巾），每项仅 200 条遥操作轨迹：无干扰平均成功率 65.0%，人为扰动下 57.2%，分别超最强基线 15.7/16.0 个百分点。数据效率与抗扰动能力均显著优于基线。

学术意义

该工作是"触觉进入基础模型"路线迄今较完整的实证之一，说明触觉不只是附加模态，而是确认动作因果完成的必要信号通道。对具身智能领域，它提示：多模态对齐研究不应止步于视觉—语言，力觉/触觉的表征学习可能是下一个数据与模型瓶颈。结合本周近百家具身数据公司一年融资 44.7 亿元的产业背景，触觉数据的采集与对齐方法具有重要的学术与产业双重价值。
