DeepSeek 提出「以视觉原语思考」框架，用边界框与坐标点作为多模态推理的最小单元
DeepSeek-AI, 北京大学, 清华大学 · arXiv:2604.xxxx · 2026-05-01
当前多模态大语言模型（MLLM）的思维链（CoT）推理几乎完全发生在语言空间，导致在密集计数、拓扑导航、多步空间推演等任务中出现「指代鸿沟」（Reference Gap）——自然语言的模糊性无法为精确空间布局提供可靠锚点。DeepSeek 团队受此启发，将边界框与坐标点提升为「最小思考单元」，使模型在推理时能够直接「指代」图像中的物理坐标，从而将认知轨迹锚定在真实视觉空间中。基于 DeepSeek-V4-Flash 构建的模型在仅使用约 90 个 KV Cache 视觉 token 的情况下，性能即可比肩 GPT-5.4、Claude-Sonnet-4.6 与 Gemini-3-Flash。该工作为 System-2 类多模态智能指明了一条更高效、更可扩展的方向。
来源: [AINLP] · [极客公园] · [51CTO技术栈]
Meta FAIR：将安全、事实性与推理能力「预训练进」LLM，而非仅后训练修复
Meta FAIR · 2026-04
现有大语言模型的安全性、事实性与推理能力大多通过 RLHF 等后训练手段「 bolt-on 」附加，但此时模型的行为模式已经固化。Meta FAIR 的最新工作将这一修复前移至预训练阶段：使用一个强后训练模型同时作为 rewriter 和 judge，对预训练后缀进行高质量、更安全的重写，并通过 RL 驱动预训练过程。策略模型从序列生成而非 next-token prediction 开始学习，奖励函数直接编码质量、安全性和事实性。实验结果显示，相对于标准预训练，事实性相对提升 36.2%，安全性提升 18.5%，生成质量胜率达到 86.3%。该研究为「预训练即对齐」提供了重要的实证支持。
来源: [elvis (@omarsar0) on X]
ReaLM-Retrieve：在推理过程中动态注入证据，解决长推理模型的知识缺口问题
2026-04
传统 RAG 系统在推理开始前仅检索一次，而大型推理模型（如 o1、R1）在推理过程中会生成长达 12k-25k token 的思维链，并在推理中途遭遇知识缺口。ReaLM-Retrieve 是一个推理感知的检索框架，能够在多步推理中动态注入外部证据。其核心创新包括：(1) 在 reasoning-step 粒度（而非 token 或 sentence 级别）检测不确定性；(2) 学习一个策略来判断何时外部证据真正有帮助；(3) 将单次检索开销降低 3.2 倍。在 MuSiQue、HotpotQA 和 2WikiMultiHopQA 上，该方法比标准 RAG 绝对 F1 提升 +10.1%，同时检索调用次数减少 47%。
来源: [elvis (@omarsar0) on X]
递归推理解锁小模型极限：700 万参数模型在 ARC Prize 上超越千倍规模模型
HRMs & TRMs · Y Combinator Decoded · 2026-04
Y Combinator 在最新一期 Decoded 中解析了两篇关于递归 AI 模型的论文——HRM（Hierarchical Recursive Model）与 TRM（Transformer Recursive Model）。研究表明，标准 LLM 在某些推理任务上存在根本性天花板，而推理时的递归机制赋予小模型以计算深度突破这一限制的能力。一个仅 700 万参数的递归模型，在 ARC Prize 等推理基准上超越了比它大一千倍的模型。当递归思想与大规模基础模型结合时，可能产生新的规模-效率帕累托前沿。这一方向对「推理即计算」的范式转换具有重要理论意义。
来源: [Y Combinator - Beyond Bigger Models] · [Y Combinator on X]
Eywa：为语言模型与专用科学基础模型建立「神经连接」
UIUC · arXiv:2604.27351 · 2026-04
科学 AI 面临一个结构性困境：语言模型能「说话」但不懂专业数据，专用模型（如 Chronos 用于时序预测、TabPFN 用于表格数据）懂数据但不能「说话」。UIUC 的 Eywa 框架从《阿凡达》中纳美人的「Tsaheylu」神经键获得灵感，在语言模型与各类专用基础模型之间建立标准化接口。语言模型负责理解任务、调度工具、整合结果，而专用模型各司其职。短期内 MCP（Model Context Protocol）等协议可解决连接问题，但长期而言，语言模型能否在特定领域达到专用模型的精度，仍是一个开放的科学问题。

用不可压缩知识探针估算黑盒 LLM 参数量：GPT-5.5 约 9.7T
Pine AI 首席科学家 李博杰 · 2026-04
该研究提出一种通过事实容量反推黑盒大语言模型参数量的方法。核心假设是：记住一条事实需要占用固定参数空间，模型答对的冷门事实越多，其参数量就不可能越小。作者使用 1400 道冷知识题目，先以 89 个参数量已知的开源模型拟合答题准确率-参数量的映射曲线，再将闭源模型的答题得分投射到该曲线上以读出对应参数量。结果显示：GPT-5.5 约 9.7T（断层第一），Claude Opus 4.6 约 5.3T，GPT-5 约 4.1T，Grok-4 约 3.2T。该方法虽存在量级不确定性（如 9.7T 的实际值可能在 3T-29T 之间），但相对排名仍具参考价值，为闭源模型的规模比较提供了一种独立验证手段。
来源: [Berryxia.AI on X]
AI 图像生成技术综述：数据质量、蒸馏友好性与系统架构的核心洞察
arXiv:2604.28185 · 2026-04
一篇覆盖 2026 年最新 AI 图像生成技术的综述论文提出了四个关键洞察：(1) 最终训练阶段的少量高质量专家数据直接影响用户对 AI 生图能力的感知，数据质量竞争已进入白热化阶段；(2) 训练数据中混入哪怕少量 AI 生成图片，都会严重损害生图质量和后续潜力，数据纯净度成为关键瓶颈；(3) 蒸馏是商业部署的必选项，不考虑蒸馏友好性的架构设计等于训练了一个无法落地的模型；(4) 开源与闭源生图系统的核心差距不在渲染器本身，而在渲染器外的系统架构（数据管线、后处理、质量评估）。这些结论对整个生成式视觉研究领域的方法论和评估标准具有指导意义。

二、深度论文解读

2.1 DeepSeek「视觉原语推理」：从感知鸿沟到指代鸿沟的范式转移

多模态大语言模型（MLLM）在过去两年中通过高分辨率裁剪、动态分块等技术逐步解决了「感知鸿沟」（Perception Gap）——即模型「看不清」的问题。然而，DeepSeek 团队指出，一个更本质的瓶颈被长期忽视：「指代鸿沟」（Reference Gap）。

自然语言天生是模糊、连续的，而视觉空间是精确、离散的。当模型用语言描述「左边第二个红色的物体」时，它实际上已经丢失了精确的空间锚点，导致推理链条与图像实体脱节，最终引发级联幻觉（cascading hallucination）。人类在解决类似问题时，会本能地用手指指向目标，将抽象语义锚定到具体物理坐标上。DeepSeek 的「以视觉原语思考」（Thinking with Visual Primitives）框架正是模拟这一机制。

核心方法：将边界框（bounding boxes）和坐标点（coordinate points）提升为思维链中的「最小思考单元」，使模型在推理时能够直接引用图像中的精确位置，而非依赖自然语言的间接描述。

实验结果显示，基于 DeepSeek-V4-Flash 构建的模型在仅使用约 90 个 KV Cache 视觉 token 的情况下，即可在密集计数、空间推理等挑战性基准上与 GPT-5.4、Claude-Sonnet-4.6 和 Gemini-3-Flash 等前沿模型匹敌。这一结果表明，视觉 token 的效率（而非数量）可能是多模态 System-2 推理的关键。该研究还暗示，未来的 MLLM 架构可能需要重新思考「语言中心」的设计假设，为视觉-语言融合提供了新的理论基础。

2.2 Meta FAIR 预训练阶段对齐：将 RL 从后训练前移至预训练

当前 LLM 的安全性和事实性改进几乎都是在后训练阶段通过 RLHF、DPO 等方法完成的。Meta FAIR 的最新工作提出了一个反直觉的问题：如果我们在预训练阶段就引入对齐信号，会发生什么？

该团队设计了一个「双重角色」机制：一个强后训练模型同时充当 rewriter（重写预训练后缀以提高质量和安全性）和 judge（评估模型输出相对于原始后缀和重写版本的优劣）。策略模型不再学习 next-token prediction，而是学习序列生成，其奖励函数直接编码三个维度：质量、安全性和事实性。

关键结果：事实性相对提升 36.2%，安全性提升 18.5%，生成质量胜率达 86.3%。这些增益来自预训练阶段的早期干预，而非后期的行为修正。

从学术角度看，这项工作对「预训练-后训练」二分法的传统框架提出了挑战。如果安全性和事实性可以通过预训练阶段的奖励设计内化为模型的固有属性，那么后训练对齐可能只是「补救措施」而非「必要步骤」。这一发现对 LLM 训练范式的重构具有深远影响，尤其是在大规模预训练成本持续上升的背景下，预训练阶段的效率优化变得愈发重要。

四、趋势观察

从「更大模型」到「更深推理」的范式迁移正在加速。 递归推理模型（HRM/TRM）和推理时检索（ReaLM-Retrieve）的共同指向是：模型的有效能力不再仅由参数量决定，而由推理时可调用的计算深度和信息获取能力决定。这一趋势与「测试时计算扩展」（test-time compute scaling）的研究方向高度一致，可能重新定义「模型规模」的度量标准。

多模态推理的瓶颈正从「感知」转向「指代」。 DeepSeek 的「视觉原语」工作揭示了一个被忽视的深层问题：即便模型能「看清」图像，也不意味着它能「指对」图像中的对象。这暗示未来的 MLLM 架构需要在视觉-语言接口层面进行根本性重新设计，而非简单增加视觉 token 数量。

预训练阶段对齐的潜力正在被重新发现。 Meta FAIR 的工作表明，预训练阶段引入结构化奖励信号可能比后训练对齐更有效率。如果这一结论在更大规模上得到验证，整个 LLM 训练 pipeline 的流程图可能需要重绘——预训练不再只是「无监督学习」，而是「弱监督对齐」的起点。

科学 AI 的「异构协作」模式正在成形。 Eywa 框架和 Heterogeneous Scientific Foundation Model Collaboration 等工作的出现，标志着学术界开始认真对待「语言模型 + 专用模型」的协作架构。这种模式下，语言模型作为「协调者」而非「全能者」，可能更适合科学发现的真实需求。

闭源模型规模估算正成为独立研究方向。 李博杰的「不可压缩知识探针」研究为黑盒模型比较提供了一种不依赖厂商披露的新方法。随着闭源模型参数量越来越成为商业机密，这类基于能力反推规模的间接测量技术将具有持续的学术价值。
