1.研究动态

斯坦福团队以权重编辑修复机器人指令泛化论文

Jusheng Zhang、Keze Wang 与 Liang Lin 的论文《Can LLMs Debug Robots by Editing Their Weights?》提出一种无需梯度更新、也无需新增机器人示范数据的策略修复方法：仅修改 65 行词嵌入，即可修复 GPT-6 Astra 在「换种说法就失败」上的指令泛化缺陷。在最成功的实验中，335 条包含被改词元的留出指令成功率由 74.3% 提升至 87.5%，另有 430 个回合的成败结果逐一不变，显示出对非目标行为的良好保持性。研究把机器人策略调试转化为对语言—动作接口的定向干预，为具身智能的可解释调试提供了新范式。

📎 来源：机器之心

Salesforce AI Research 提出 JoMoHa：模型与 harness 协同进化arXiv 2611.11499

自改进 harness 研究的一个常见局限是：编写 harness 的编辑器通常是固定的前沿模型。JoMoHa 用同一组任务结果以强化学习同时训练两个策略——一个编写可执行 harness，另一个在 harness 内求解任务。作者发现交替更新模型与 harness 会造成二者失配、性能先升后降，通过为两个策略维护独立的历史与价值估计解决了该问题。在 ALFWorld、WebShop 与 DBBench 上，JoMoHa 平均达到 70.3%，ALFWorld 最高 97.0%，优于仅训练权重或仅训练 harness 的基线。

📎 来源：elvis(@omarsar0)

长程智能体决策模型：用轨迹评估充当 GRPO 教师arXiv 2611.17167

一篇关于长程 agent 强化学习的工作主张：让决策模型评估已完成的轨迹，而把动作选择留给策略；决策模型输出带类型的分布（如每个选项的概率）。实验显示，六种被测模型（三种决策模型、三种通用 LLM）作为 actor 时都会优先选择更容易的子目标，但在看到完整轨迹并判断每一步是否有帮助时，又会为执行时跳过的步骤记功。将其中一个决策模型作为 GRPO 教师后，Qwen2.5-1.5B 策略在 ALFWorld 上由 72.8% 提升至 82.9%，WebShop 由 56.8% 提升至 71.4%，且包括其作为 actor 时很少完成的任务。

📎 来源：elvis(@omarsar0)

NVIDIA 开源 GR00T 2：跨本体机器人 System One 模型开放权重

NVIDIA 发布 GR00T 2，定位为面向机器人研究的最先进开源 System One 模型，可从人类演示中学习技能，并预测其动作将如何改变物理世界。其技能可跨不同机器人本体迁移，从而减少为每台机器人从零教授每个任务的需要；Hugging Face 的 Thomas Wolf 确认 LeRobot 集成正在进行。该发布延续了 NVIDIA 在开放权重模型上的持续投入，为具身智能研究提供了可复现的基座。

📎 来源：Thomas Wolf(@Thom_Wolf)

Google DeepMind 发布 PARDIG 与 SatWeave 基础数据集数据集

DeepMind 开源了 WeatherNext 3 背后的两个基础数据集：PARDIG 每 15 分钟估计一次全球降雨，并将降水检测技能提升 30% 以上；SatWeave 将多颗地球静止卫星合成为每 60 分钟一幅的地球云与风暴实时视图。相关数据已在 Google Cloud Storage 与 Earth Engine 上开放，可用于缺乏地面雷达地区的更准确洪水预警、野火烟雾追踪与太阳能评估等真实问题。这组数据把气象观测的时空分辨率问题转化为可复用的公开资源。

📎 来源：Google DeepMind(@GoogleDeepMind)；数据集发布

Ropedia 发布 Xperience 2 具身环境—行为数据集数据集

面向后 GPT-6 时代的物理智能，Ropedia 发布 Xperience 2：一套将真实场景扫描与人的第一视角活动记录相结合的数据集，在同一度量坐标系中对齐场景几何、录像、轨迹与身体姿态。基于这些数据，人的动作可被转换为机器人轨迹，扫描场景可被转换为可交互仿真环境，目标是建立可复用的「环境—行为一体化」数据金标准。该工作正面回应了物理智能缺乏 Scaling Law 的问题——究竟应扩展何种环境与行为数据、又该如何持续生产与使用。

📎 来源：机器之心

基准方法学进展：ParseBench-2 与 XYBench评测

两个新基准都把「基准设计」本身作为可迁移的贡献。Jerry Liu 团队发布的 ParseBench-2 不只是文档解析基准，更是一套编码人类偏好的框架：使用者可声明「好解析」的标准，并用编码智能体自动优化指标，而非手工构造确定性度量。AllenAI 在 Hugging Face 发布的 XYBench 则聚焦「问题背后的问题」，试图衡量那些难以直接测量的能力维度。二者共同反映出评测正从静态榜单转向可定制、可归因的评估框架，这对学术评价的生态效度与可比性都提出新课题。

📎 来源：Jerry Liu(@jerryjliu0)；Hugging Face Blog

2.深度论文解读

Déjà View：以单个 Transformer 块的循环复用实现高效三维重建

NVIDIA · NeurIPS 2026 Oral Paper（论文与代码已开放，Hugging Face 提供免代码交互 Demo）
研究背景
从不同角度拍摄的照片恢复 3D 几何与相机位姿，是几何视觉的长期问题。近年方法多依赖大参数量模型与高昂计算预算，性能与成本难以兼得，尤其不利于资源受限的研究复现。
核心创新
Déjà View 通过循环复用单个 transformer block 来构建网络，参数量仅 117M，即可把不同视角的照片转换为 3D 几何与相机位置。关键在于循环次数可调：研究者能按自身算力预算在「性能—计算」之间做连续取舍，形成一种参数少、算力自适应的架构范式。
实验结果
官方报告称，该模型在五个基准上匹配甚至超越最多 10 倍大的模型，且使用相当或更少的计算。工作入选 NeurIPS 2026 oral，论文与代码已公开，并在 Hugging Face 上线无需编程的交互式 Demo，便于社区快速验证。
学术意义
该结果说明深度循环与权重共享可在几何视觉任务上以极小参数取得竞争性表现，为「算力自适应」的模型设计提供了可复现案例，也降低了三维视觉研究的算力门槛。其「循环次数即计算旋钮」的思路，可能迁移到其他需要按预算伸缩的感知任务。
📎 来源：马东锡 NLP(@dongxi_nlp)；NVIDIA AI(@NVIDIAAI)

CoACT：面向 Coding Agent 的动作保持型观察压缩

清华大学人工智能学院 · ICSE 2027 直接接收（CCF A 类，Top 5%）
研究背景
Coding Agent 解决软件问题时需要反复查看代码、修改程序、运行测试，每一步返回的文件内容、搜索结果与日志都会留在上下文中，并在下一轮调用时整段重传。统计显示，这些 observation 在 SWE-bench Verified 上占总 token 消耗的 45.7%，在 Terminal-Bench 上最高达 67.8%，任务越难、上下文越长，每步成本越高。
核心创新
直接压缩 observation 的难点在于：删除某段内容时，很难预判它后续是否仍会被用到。CoACT（Action-Preserving Observation Compression）不再以压缩结果与原文的相似度为目标，而是以「压缩之后 Agent 的下一步动作是否改变」为准则，优先保留对后续决策真正有用的信息。
实验结果
在 SWE-bench Verified 的 200 个实例、三个 Agent 模型上，CoACT 平均减少 33.0% 的总 token 消耗，平均 PASS@1 由 69.0% 提升至 71.0%，任务表现与未压缩时相近。该工作被 CCF A 类会议 ICSE 2027 直接接收（Top 5%），表明软件工程与 LLM 智能体的交叉方向正获得顶会认可。
学术意义
CoACT 把上下文压缩的评价标准从「信息保真」转向「行为保真」，为智能体效率研究提供了一个可迁移、可度量的准则；同时也提示，agent 系统的评估指标应更多锚定在下游行为而非表面文本相似度上。
📎 来源：机器之心

4.趋势观察

趋势一：Harness 与模型的协同进化成为智能体研究的显学

JoMoHa 用双策略强化学习联合训练 harness 编写者与任务求解者，DAIR.AI 的 harness engineering 论文合集，以及工业界基于 GEPA 反思搜索的 Skill 自进化实践（大淘宝技术，横向对比 GEPA、SkillOpt、EvoSkill、Trace2Skill 等论文），都指向同一问题：当底层模型能力趋同时，围绕模型的「外壳」——harness、记忆、工具与评估回路——成为新的可优化维度。值得警惕的是，交替优化容易导致模型与 harness 失配，独立历史与价值估计、确定性程序的边界校验是当前较稳健的工程约束。

趋势二：开放权重持续缩小与前沿的差距

Déjà View 以 117M 参数比肩最多 10 倍大的模型，MiniMax H3-Image 成为多图编辑开源第一，Inkling 2 Small 成为美国第一开源 agent 模型，叠加 llama.cpp v1.0.0 的成熟，学术界复现与二次开发的门槛正快速下降。但「开放」仍需在合规层面甄别：H3-Image 的许可证带有地域与营收限制，可能影响跨国合作与商业化研究的使用边界。

趋势三：具身智能的数据与调试范式正在成形

Ropedia Xperience 2 试图统一环境与行为数据的度量坐标系，Stanford 的权重编辑工作把策略失灵定位到语言—动作接口的少数词嵌入，NVIDIA GR00T 2 则强调跨本体的技能迁移。三者分别对应数据、可解释性与泛化三个瓶颈，提示物理智能的「Scaling Law」可能同时取决于数据对齐质量与接口层面的可控性，而不仅是模型规模。

趋势四：评测从静态榜单转向可定制框架

ParseBench-2 与 XYBench 都把「如何定义好的评估」交给使用者，Arena 亦强调以真实使用轨迹而非纯人类偏好作为信号。对学术评价而言，这提升了生态效度，却也带来可比性与可复现性的新挑战——当每个团队都能定制指标时，跨工作的公平比较需要更明确的报告规范与开源评测协议。
