具身智能开源世界模型 / VLA

1.蚂蚁灵波「灵波」系列三件套开源：小时级世界模型、VLA 基模与具身专用视频基模同日放出

蚂蚁灵波在 24 小时内连续开源三款面向具身智能的基础模型，构成一条从"世界建模—动作策略—视频先验"的完整链路。LingBot-World 2.0（Infinity）主打"小时级"实时交互生成，声称解决视频世界模型长期的长时漂移（long-horizon drifting）顽疾，做到 720p/60fps 满血输出且零质量塌陷，并内置 Director Agent 实时驱动世界演化（攻击、施法、召唤风暴等丰富动作与事件），可像游戏一样游玩。LingBot-VLA 2.0 是面向真实机器人的 Vision-Language-Action 基础模型，扩展了动作空间、引入预测动力学建模，以约 60,000 小时预训练强调跨任务、跨具身（cross-embodiment）泛化。LingBot-Video 则被定位为全球首个具身专属的 MoE 视频基模，意在把视频生成先验直接服务于"机器人大脑"。三者权重均已放至 Hugging Face / 魔搭，发布后 LingBot-World 2.0 迅速登上 Reddit 热榜。学术意义在于：具身研究正从单点模型走向"世界模型 + 策略模型 + 生成先验"的系统化开源栈，为可复现的具身泛化研究提供了稀缺基座。

具身智能泛化涌现数据规模

2.原力灵机 DM0.5：15 万小时数据喂出"Zero-Shot 提升 31%"，声称已现泛化涌现

原力灵机发布具身模型 DM0.5，以约 15 万小时数据训练，官方指标突出 Zero-Shot 性能提升 31%，并宣称"已经出现泛化涌现"。与其 Action 2026 大会上提出的"三级火箭"框架相呼应：行业共识是具身落地的瓶颈不在硬件或场景，而在数据碎片化——不同硬件、算法、场景各自为战，数据无法跨任务、跨机型复用，使"从 10 万小时到 100 万小时"的跃迁难以靠单纯数采堆出。该工作把论证主线放在三座大山（基模能力、集成开发、连续作业）与一条核心假设上：要实现开放世界的 Few-/Zero-Shot 涌现，必须同时具备更大数据规模、更先进架构与更强开放世界泛化。值得跟踪的学术问题是：其"涌现"宣称是否有可复现的跨实体评测协议支撑，以及 15 万小时数据的构成分布与跨机型迁移曲线。

arXiv 技术报告开放模型MoE / 多模态

3.Google Gemma 4 技术报告公开：一套模型落入"五个位置"，12B 试水 encoder-free 多模态

Google Gemma 4 技术报告已公开于 arXiv。其新颖之处不在单项能力（Thinking Mode、原生多模态、长上下文在开放模型中已渐成标配），而在于把同一代 Gemma 4 摆进五个清晰位置：端侧/移动的 E2B（有效约 2.3B）与 E4B（有效约 4.5B）；居中的 12B 是结构最特殊的一版——图像与音频减少对独立编码器的依赖，经更轻的投影模块直接进入 LLM 的 embedding space（encoder-free 多模态路线）；26B-A4B 采用 MoE（总 26B、推理激活约 3.8B）压延迟；31B 走 Dense 质量优先路线，承担高质量推理、代码与微调基座。Dense 与 MoE 双线并行、规模从 2.3B 到 31B，辅以 QAT 量化、MTP 解码与长上下文省显存设计，整体服务于"分层部署"而非单一 SOTA。详见下方"深度论文解读"。

arXiv:2606.16821评测 / 安全检索 Agent

4.SearchGEO：13 个主流大模型抗"AI 投毒"能力被系统量化，脆弱程度相差一个数量级

由 KAUST 生成式 AI 卓越中心、吉林大学、浙江大学、瑞士人工智能实验室等机构（含 Jürgen Schmidhuber）组成的团队发布 SearchGEO 评测框架（arXiv:2606.16821，代码已开源）。背景是 2026 年央视 3·15 晚会曝光的 "GEO" 灰色产业链：虚构产品 + 批量软文，两小时后即可让主流大模型把捏造内容当作"标准答案"推荐。SearchGEO 在 13 个主流 LLM 后端 × 5 种攻击模式 × 4 个高风险领域上系统测试，结论远比"谁更安全"复杂：模型脆弱程度相差达一个数量级；没有一种攻击通吃所有模型；两个看似最安全的模型可能朝相反方向失败——Claude 综合表现最佳，但存在"沉默漂移"与误拒风险，GPT 在新场景中则极易被攻击。这是把"检索增强 Agent 的可信度"作为一等研究对象的重要评测工作。

📎 来源：新智元 · 论文 arXiv:2606.16821 · 代码 github.com/Beastlyprime/SearchGEO

评测方法学SWE-Bench Pro数据污染

5.SWE-Bench Pro 被检出约 30% 任务含致命缺陷，OpenAI 撤回推荐

继指出 SWE-bench Verified 存在设计与污染问题后，OpenAI 对曾被其推荐的 SWE-Bench Pro 重新质检并撤回推荐。动机是前沿模型在其公开 731 题上的通过率约 8 个月内从 23.3% 飙升至 80.3%——这种跃升本身就要求追问"进步是能力还是评测噪声"。质检分三层：自动化质检标出约 286 道可疑题；Codex 类 investigator agent 进仓库跑测试、看失败模式并多轮独立审计；每题再由 5 名资深工程师独立审题面、测试与 gold patch。归纳出四类主要失效模式：过严测试（测题面未要求的实现细节）、题面欠指定（隐藏测试要求无法从题面合理推断）、低覆盖测试（残缺修复也能过）、误导性题面（与测试要求矛盾）。人工比 agent 更常判"坏题"（尤其低覆盖测试，人工约 9.4% vs agent 约 4.1%），两者大类一致约 74%。核心启示：开源 PR 本是为人协作而生，描述/代码/单测经多轮协商，并不天然构成干净、自洽的评测单元——这对所有"用历史 PR 造 bench"的范式都是一记警钟。

📎 来源：meng shao（@shao__meng） · AI 寒武纪（OpenAI 废除 SWE-Bench Pro）

AI for Science开源地球系统基础模型

6.微软发布 Aurora 1.5：开源地球系统基础模型扩展 22 个变量，支持小时级与概率集合预报

Microsoft Research 发布 Aurora 1.5，对其 Aurora 地球系统（Earth System）基础模型作重大扩展：新增 22 个与能源、农业、交通、气候风险相关的天气变量，时间分辨率提升至小时级，并加入概率集合预报（probabilistic ensemble forecasting）能力。模型以开源形式发布（GitHub 代码 + Hugging Face 模型检查点），并打通到 Microsoft Weather 服务，把开放研究与数据、基础设施、托管访问和实际业务连接起来。学术价值在于：它是"AI for Science / 地球系统建模"方向少见的、变量覆盖面与时效同时推进、且完全开放的基础模型，为气象—能源—农业的跨学科下游任务提供了可复现、可评估的统一基座。

安全 / 对齐双重用途可移除能力

7.Anthropic × AE Studio 提出 GRAM：把病毒学等"双重用途"能力做成可移除模块

Anthropic 与 AE Studio 合作提出 GRAM，一种训练方法，将既有益又危险的"双重用途"能力（例如病毒学知识——既可用于研发救命疫苗，也可被用于制造致命病原体）封装进可移除模块（removable modules）。其核心思想是把"能力删减"从粗粒度的全模型对齐推进到模块化、可组合的粒度：在不伤及模型通用有益能力的前提下，按场景启用或剥离特定高风险能力。这为"如何保留科学助益、同时降低滥用风险"这一长期张力提供了一条架构层面的安全路径，而非仅依赖后训练拒答。

📎 来源：Anthropic（@AnthropicAI）

arXiv:2607.07148语音对话强化学习

8.DuplexPO：把全双工口语模型的"何时说"与"说什么"解耦，智力—动态权衡并非根本

当日 arXiv 新稿 "Decoupling Conversational Dynamics in Full-Duplex Spoken Models through Reinforcement Learning"（arXiv:2607.07148）直面全双工口语对话模型的一个关键矛盾：低延迟、backchannel、处理打断等"会话动态"的进步，往往以更弱的推理与指令遵循为代价，呈现"智力—动态权衡（intelligence–dynamics trade-off）"。作者论证该权衡并非根本性的——会话动态可以作为独立的实时决策策略，从人类对话数据中单独学习。为此提出 DuplexPO 强化学习框架，将"何时发言（when to speak）"与"说什么（what to say）"解耦，在不牺牲智能的前提下习得动态。这与同日 OpenAI 全双工语音模型 GPT-Live 的产品化形成有趣对照，是该方向从工程共识走向方法学澄清的代表性工作。

📎 来源：arXiv:2607.07148（eess.AS, new）

arXiv 技术报告开放模型架构

深度解读 · 一｜Gemma 4：以"五个位置"重构开放模型家族

Google · Gemma 4 Technical Report（arXiv 公开）｜解读来源：AINLP

研究背景。开放模型的竞争焦点正从"单点 SOTA"转向"全栈部署"：端侧低延迟、移动端、云端高质量推理、MoE 高效推理各有约束，单一架构难以通吃。Gemma 4 的回答是用同一代模型覆盖整条谱系。

核心创新——一套模型，五个位置。

E2B / E4B
端侧与移动设备，有效参数约 2.3B / 4.5B；面向手机、Raspberry Pi、Jetson Orin Nano、Android 与本地低延迟任务。
12B
本报告最特殊的一版：填补尺寸空档的同时换用 encoder-free 多模态路线——图像/音频经由更轻的投影模块直接进入 LLM embedding space，减少对独立编码器的依赖。
26B-A4B
MoE：总参数 26B、推理激活约 3.8B，核心卖点是延迟与效率。
31B
Dense 质量旗舰：本地高质量推理、代码、复杂问答与微调基座。

贯穿性技术。Dense 与 MoE 双线并行；规模 2.3B → 31B；并辅以 QAT 量化、MTP（多 token 预测）解码与长上下文省显存设计——全部服务于"分层部署"目标，而非堆叠单一指标。

学术意义。12B 的 encoder-free 多模态是最值得跟踪的架构信号：它延续了"模态直接进 LLM 嵌入空间、弱化独立编码器"的路线（与近期原生多模态趋势一致），若验证有效，将显著降低多模态开放模型的结构与训练复杂度。其次，"同代模型 + 多部署位"的家族化设计，为研究社区提供了一组规模连续、架构对照清晰（Dense/MoE、encoder-based/encoder-free）的可比实验台。

📎 来源：AINLP（Gemma 4 技术报告解读）

arXiv:2606.16821鲁棒性评测

深度解读 · 二｜SearchGEO：当检索 Agent 上网，攻击者有多容易操纵答案？

KAUST / 吉林大学 / 浙江大学 / 瑞士人工智能实验室 等（含 J. Schmidhuber）· arXiv:2606.16821 · 代码已开源

研究背景。"GEO（生成式引擎优化）投毒"把检索增强系统变成了攻击面：攻击者批量制造软文污染搜索结果，诱导 LLM 把虚假内容综合进答案。3·15 晚会展示了现象，但缺失一个更基础的问题——不同模型面对同种投毒，脆弱程度是否相同？差距多大？

核心创新。SearchGEO 是首个系统量化"检索→综合"链路被操纵难易度的评测框架，覆盖 13 个主流 LLM 后端、5 种攻击模式、4 个高风险领域，把"抗投毒"作为可比较、可复测的评测维度。

关键结果。

  • 13 个模型的脆弱程度相差达一个数量级，安全性差异显著。
  • 不存在"通吃"攻击：没有任何单一攻击模式能稳定击穿所有模型。
  • 两个看似最安全的模型朝相反方向失败：Claude 综合最佳，但有"沉默漂移"与误拒（过度拒绝）风险；GPT 类模型在新场景中极易被攻击。

学术意义。它把评测对象从"模型安全"的笼统叙事，推进到"检索 Agent 在对抗性搜索环境下的可信度"这一可测量问题，并揭示了一个反直觉事实：安全性不是单一标量——最安全的两个系统失效模式相反，意味着防御不能一刀切。配合已开源代码，可成为检索 Agent 鲁棒性研究的标准基准之一。

📎 来源：新智元 · arXiv:2606.16821 · GitHub

基准 · 歌声合成（arXiv:2607.06986, new）

MMGenre：多流派歌声合成（SVS）诊断基准

针对现有 SVS 基准严重偏向流行乐的问题，MMGenre 覆盖 10 大流派 / 26 子流派，并配套自动构建流派对齐乐谱的流水线。对代表性 SVS 模型的评测发现一个负向但重要的结论：合成歌声跨流派的声学特征高度相似、可分离性弱——流派判别能力有限，zero-shot 流派适配仅带来边际提升。为流派感知合成研究提供了诊断工具。

基于本期信号的研究方向判断与待解问题。

→具身智能撞向"百万小时数据墙"，开源栈与"泛化涌现"成为破局赌注

本期具身信号高度集中：蚂蚁灵波三件套开源（VLA 2.0 用 60,000 小时、LingBot-Video 作视频先验）、原力灵机 DM0.5 用 15 万小时并宣称 Zero-Shot +31% 与"涌现"。行业叙事已从"硬件/场景"转向数据碎片化与跨实体复用——核心瓶颈是数据无法跨任务、跨机型复用，"10 万→100 万小时"难以靠堆数采完成。值得审视的学术问题："泛化涌现"的可复现评测协议是什么？跨实体迁移随数据规模的标度律（scaling law）如何？世界模型长时一致性、预测动力学建模、视频生成先验赋能控制，可能是下一阶段具身泛化的三条主战线。

→"评测方法学"本身成为前沿：从 SWE-Bench Pro 到 SearchGEO

SWE-bench Verified 污染、SWE-Bench Pro 约 30% 坏题、SearchGEO 揭示检索鲁棒性跨模型差一个数量级——三条信号指向同一结论：当分数数月内从 23% 飙到 80%，必须追问是能力还是噪声。"用历史 PR 造 bench"的范式被证明存在结构性缺陷（过严/低覆盖测试、欠指定/误导题面），而模型安全性也非单一标量（最安全者失效模式相反）。评测设计、污染审计、人机协同质检，正在从"工程环节"升格为需要方法学创新的研究对象。

→全双工语音与"智力—动态"解耦：从工程共识到方法学澄清

产品侧（OpenAI GPT-Live）已确认全双工"边听边说"成为语音模型共识；研究侧 DuplexPO（arXiv:2607.07148）则给出方法学论断——会话动态可作为独立实时策略单独学习，"智力—动态权衡"并非根本。配合 SpeechKV（arXiv:2607.06827，71K 小时训练、把语音压缩到接近文本粒度同时保性能）等效率工作，语音/音频方向正同时推进"交互自然度"与"长序列解码效率"两条线，且与全模态 OmniLLM 的 token 压缩（如 DASH）形成呼应。

→能力跨域收敛与"迁移"：前沿研究者对模型边界的重新估计

Sergey Brin 在 DeepMind Build Day 的无脚本问答中给出一线观察：过去需分领域训练的模型，如今 Gemini 已能在数学与多类科学问题上同时领先，收敛速度超出预期；且存在明显的技能迁移——代码训练改善数学推理、图像训练提升几何题表现，这些关联并非刻意设计，而是训练中自然涌现。他也坦率承认即便内部团队对模型能力边界的认识仍不完整，并把思维链（CoT）称为"提出时无充分理论依据、但实践反复证明有效"的跃升推手。对"Transformer 能否通向 AGI"，他的回答是"能，但它已经变了"——这为架构演进（而非范式颠覆）的判断提供了来自前沿的佐证。

📎 来源：机器之心（布林谈前沿 AI）

→双重用途与"架构级安全"：从拒答走向可移除能力模块

GRAM（双重用途能力模块化、可按需移除）与 Claude Mythos（首次把"自主发现并武器化漏洞"推到超越人类顶尖专家水平，使漏洞从披露到规模化利用的窗口从月/天压缩到分钟）共同指向一个转向：安全正从"后训练拒答"走向"架构层能力治理"。字节跳动安全团队据此提出防守需从"人类节奏"切换到"机器速度"，并在零信任之上叠加"假设边界终将被穿透"的韧性设计。对研究社区的启示：能力删减的粒度（模块 vs 全模型）、攻防时间常数的变化，将重塑安全评估与红队方法。

📎 来源：Anthropic（GRAM） · 字节跳动技术团队（Mythos 影响分析）

→开源作为"AI 主权"与反集中：治理争论进入关键路口

Andrew Ng 借《Permissionless Innovation》强调"保护开源 AI 是无需事先许可即可创新的关键"；Yann LeCun 重申"AI 最大风险是权力集中于少数闭源助手提供商，AI 主权的唯一解是开源基础模型"；Hugging Face 的 Clement Delangue 则以其美国国会证词论证开放科学与开源 AI 如何分配经济收益、制衡大公司。三者在同一 24 小时内共振，叠加微软/蚂蚁/商汤/Google 的实际开源动作，构成"开放权重"叙事在治理与产业两端的同步强化。

📎 来源：Andrew Ng · Yann LeCun · Clement Delangue（Hugging Face）
