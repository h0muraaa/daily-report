研究动态

LEAP: Lean编译器验证驱动的通用LLM Agent框架，单次解决70% IMO问题
形式化验证 定理证明 Google Research

Google研究团队提出了LEAP框架，将一个通用大语言模型包装在Agentic Scaffold中，使每一步推理都接地于Lean编译器反馈，并针对验证器反馈进行迭代优化。该框架在Lean-IMO-Bench上将单次求解率从不足10%提升至70%，超过了此前专门设计的金牌系统（48%）。更引人注目的是，同一个通用模型在不针对Putnam考试特化训练的情况下，成功解决了2025年Putnam竞赛的全部12道题目。这项工作展示了一种"验证即训练信号"的新范式，对形式化数学和自动定理证明领域具有重要方法论意义。

[来源: elvis(@omarsar0) / arXiv:2606.03303]
Foley-Omni: 从任务级音频合成到完整视频音轨生成的统一多模态模型
多模态生成 音频合成 arXiv:2606.03672

现有统一音频生成模型多聚焦于孤立的任务级合成（如单一声效或音乐片段），而实际视频制作需要为同一视频联合生成多个音频组件。本文提出的Foley-Omni通过共享潜变量生成过程，联合建模语音、声效和音乐，将任务级合成扩展至完整视频音轨生成。研究团队还开发了音视频数据整理流程，并引入V2ST-Bench基准用于整体视频音轨生成评估，为该领域的可复现研究提供了基础设施。

[来源: cs.SD updates on arXiv.org]
联合音视频生成的推理时缩放：首个多模态ITS综合研究
推理时缩放 音视频生成 arXiv:2606.03183

推理时缩放（Inference-Time Scaling, ITS）在单模态领域已被证明是提升生成质量的有效训练无关方法，但将其扩展至多模态领域面临非平凡挑战：需要同时平衡多个异构目标。本文首次对联合音视频生成中的ITS进行了系统研究，证明多验证器框架对于克服单目标优化的局限性至关重要。该研究为如何在多模态场景下设计高效的推理时策略提供了理论依据和实验验证，对降低高质量音视频生成模型的训练成本具有实际指导价值。

[来源: cs.MM updates on arXiv.org]
LiveMoments (ICLR 2026): 参考图引导扩散模型修复Live Photo封面帧画质
ICLR 2026 扩散模型 图像修复 vivo BlueImage Lab / 南开大学

ICLR 2026接收论文（接收率约27.4%）。针对Live Photo用户重选封面时面临的画质降级问题，研究团队利用原始高清封面作为参考，构建了一个包含运动对齐模块的参考引导扩散模型。该方法有效解决了两帧之间因时间偏移产生的运动错位问题，成功将低质重选帧修复至高清水平。这是首个专门针对Live Photo重选封面帧画质修复的解决方案，展示了扩散模型在精确图像对齐与修复任务中的潜力。

[来源: vivo互联网技术 / arXiv:2604.12286]
Stable Hybrid Cross-Attention Fusion: 面向智能城市监控的音视频事件识别新框架
多模态融合 音视频识别 arXiv:2606.03747

本文提出了一种稳定的混合交叉注意力融合框架，用于智能城市环境中的音视频事件识别。架构结合了预训练的VideoMAE和AST表征，采用FiLM-based音频条件化、双向交叉注意力融合、多模态Transformer编码和模态-时序注意力机制。为提升计算效率和训练稳定性，研究采用了冻结预训练骨干网络和缓存特征提取策略。在AVE数据集上的实验验证了该方法的有效性，对多模态城市感知系统的工程实现具有参考价值。

[来源: eess.AS updates on arXiv.org]
TFPARN: 面向ASVspoof 5的高效Transformer反欺骗网络
语音安全 反欺骗 arXiv:2606.02980

针对自动说话人验证系统的反欺骗需求，本文提出了TFPARN（Transformer-based Focal-Pairwise Attentive Ranking Network）。该系统提取log-Mel特征后使用Transformer编码器建模帧级信息，通过注意力池化获得话语级表征，并采用focal分类损失与pairwise排序损失的联合训练。在ASVspoof 5 Track 1封闭条件下，该方法针对标准交叉熵训练对困难样本关注不足、与排名和阈值评估指标不对齐的问题，提供了有效的解决方案。

[来源: cs.SD updates on arXiv.org]
OmniHalluc-L: 长视频全模态幻觉的反事实基准测试与可靠性校准
幻觉检测 基准测试 arXiv:2606.03614

长视频全模态助手常出现的"几乎正确"错误——听到正确的语音、看到正确的事件，却将其绑定到错误的说话人、时刻或模态——难以被标准视频QA检测。本文提出了一种反事实事件绑定协议，从同一音视频证据构建配对的正确/反事实声明，并以严格配对准确率评估。该基准包含3,600条来自638个长视频（平均24.16分钟）的单声明QA项，为长视频多模态幻觉的系统性研究提供了重要的评估基础设施。

[来源: cs.MM updates on arXiv.org]
SVHalluc: 视听大语言模型中语音-视觉幻觉的综合基准
幻觉 视听LLM arXiv:2606.02642

现有视听LLM幻觉基准多聚焦于环境声效（如狗吠）来指示事件发生，而人类语音承载 fundamentally different 的丰富语义和时序结构。本文首次系统研究了语音内容如何诱发视听LLM的幻觉，并推出了SVHalluc——首个专门评估视听LLM中语音-视觉幻觉的综合基准。该工作填补了语音-视觉对齐评估的空白，对提升多模态大模型在真实场景中的可靠性具有重要意义。

[来源: cs.MM updates on arXiv.org]
Efficient ASR Training with Conversations that Never Happened: LLM合成对话数据增强
ASR 数据增强 低资源语言 arXiv:2606.03957

低资源语言和 niche 领域中的对话式ASR受限于领域匹配的多说话人训练数据稀缺。本文提出了一套数据增强流程：生成场景级对话及参与者元数据，将说话人属性映射至TTS声纹，组装为说话人感知的模拟对话。研究评估了五种LLM家族在单生成器、固定预算混合和规模扩展设置下的表现，在匈牙利语BEA-Dialogue基准上验证了方法的有效性。该方法可推广至任意具备各组件资源的语言，为低资源对话ASR提供了实用的数据生成范式。

[来源: eess.AS updates on arXiv.org]
吃透大模型SFT底层机理：从交互机理层面统一解答实践争议
监督微调 理论分析 过拟合 上海交通大学

该研究从底层交互机理出发，系统分析了在大语言模型上进行监督微调（SFT）的适用条件与时间窗口。针对SFT数据高度同源/同质化场景下的争议——SFT究竟是增强能力还是损伤能力——研究团队提出了可验证的解释指标，能够对每个LLM给出严格且精确的适用时间窗与最大后训练样本容量。核心发现：在高度同源数据上SFT的有效时间窗口通常极短，且最优窗口时长可在交互机理层面严格确定。这一理论框架为SFT实践提供了统一的指导原则，有助于规避无效算力投入。

[来源: 机器之心 / 上海交通大学]
TransitLM: 首个大规模端到端公交路线生成数据集与基准
端到端生成 数据集 城市计算 高德地图

传统公交规划依赖完整的地图基础设施（站点拓扑图、实时时刻表等），流程冗长复杂。高德地图研究团队提出了一种无需地图基础设施的端到端公交路线规划方案，通过在1,300万条路线数据上微调4B参数模型，直接生成结构完整、高精度的公交路线。实验显示，六大通用LLM（GPT-5.4、DeepSeek-V4等）的最佳连通率仅75.5%，精确匹配仅40.2%，说明通用LLM缺乏公交网络领域拓扑知识。TransitLM开源了数据集与评测基准，为城市出行AI研究提供了新的基础设施。

[来源: 魔搭ModelScope社区 / 高德地图]

深度论文解读

SkillOpt (Microsoft Research): 将技能文档视为可训练外部状态的Agent优化框架
Agent优化 技能文档学习 Microsoft Research

当前AI工程师手写Agent技能文档并期望其泛化的做法可能并非最优。Microsoft Research提出的SkillOpt将技能文档视为冻结Agent的可训练外部状态，由一个优化器模型对技能文件进行验证门控的编辑（增删改指令），并通过文本学习率控制每轮重写的激进程度。Agent本身保持不变，仅技能文档被优化。

在52个（模型、基准、harness）组合上，SkillOpt全部达到最佳或并列最佳。在GPT-5.5上，相比无技能基线，直接对话提升23.5分，配合Codex提升24.8分，配合Claude Code提升19.1分。该方法击败了人工编写的技能、TextGrad、GEPA和EvoSkill等方法，且具有良好的跨模型迁移能力。

学术意义：SkillOpt提出了一个"元学习技能表示"的新方向——不是微调模型权重，而是学习如何编写更好的指令。这对构建可维护、可迭代的Agent系统具有范式级影响，同时也引发了一个有趣的理论问题：技能文档的优化空间与模型权重空间之间的关系是什么？
[来源: elvis(@omarsar0) / Microsoft Research]
混合法律Agent: 开源模型路由+前沿模型顾问击败单一前沿模型
模型路由 成本优化 领域特化 Harvey / Fireworks AI

Harvey与Fireworks AI合作训练了面向法律领域的开源模型，并设计了"混合Agent"架构：GLM 5.1作为主工作器，在需要时将任务路由至Claude Opus 4.7作为顾问。在Harvey法律Agent基准（LAB）上，该混合方案达到18/100全通过，超过了Opus单独使用的14/100，而成本仅为39%。

Hugging Face CEO Clem Delangue指出，这种路由和后训练开源模型的思路不仅提升了准确性，也显著降低了延迟和成本。"前沿模型在所有领域、所有任务、所有设置下都更好"的观点并不成立，更多是让用户多付费的营销话术。Harvey的LAB基准采用人类式的验证方法——每个任务有50多条通过标准，每条都有独立的评判调用，便于审计但规模执行成本较高。

学术意义：这项工作为"何时使用前沿模型、何时使用领域特化开源模型"提供了实证依据。它验证了模型路由（Model Routing）作为系统级优化策略的有效性，并提出了一个新的研究问题：如何自动学习最优的路由策略，而非依赖人工设计的启发式规则？
[来源: Fireworks AI(@FireworksAI_HQ) / Harvey]

PaddleOCR-VL-1.6: 百度开源超轻量化多模态文档解析模型
OCR 多模态 开源 百度文心大模型

百度开源了PaddleOCR-VL系列最新版本，核心模型仅0.9B参数。通过创新性的"欠优化区域感知优化框架"与渐进式后训练策略，在保持前代零成本平滑迁移能力的同时，显著提升了对表格、古籍、生僻字、印章及图表等复杂场景的识别精度。该模型支持100+种语言的多语种识别，在权威评测集OmniDocBench上表现优异，可高效集成至企业文档系统。代码与模型已开源。

趋势观察

从非形式化AI到形式化证明：Axiom Math与数学推理的新范式
数学推理 形式化方法 Latent.Space

2025年，成立仅七个月的Axiom startup在Putnam竞赛中解决了全部12道题目（限时内得分8/12），超越了顶尖本科生（110/120）和此前最佳的AI系统DeepSeek（103/120）。这一成就与当前Claude Code和Codex引发的Agent编程革命形成了有趣的呼应：AI正在从"非形式化"的直觉推理迈向"形式化"的严格证明。

Latent.Space的深度分析指出，这一转变的核心在于将LLM的生成能力与形式化验证系统（如Lean）相结合，使每一步推理都可被机器验证。这与传统AI在竞技游戏中击败人类的模式不同——数学证明要求100%的正确性，而非统计上的优势。该趋势可能预示着AI研究方法论的根本转变：从"训练更大模型"到"构建更好的验证与反馈循环"。

[来源: Latent.Space]
GitHub的Agent时代：14倍提交量、2亿开发者与信任危机
AI Agent 软件开发 开源生态 GitHub / Latent.Space

GitHub COO Kyle Daigle在Latent.Space播客中分享了AI Agent对代码托管平台的深远影响：Agent使代码提交量增长14倍；Copilot正从自动补全向CLI、桌面、云端Agent和Ambient Workflow演进；GitHub Actions已成为CI/CD和自动化的计算层；预计80%的PR将来自Agent。最值得关注的是，当Agent开始编写、审查和发布代码时，信任成为开源生态的新瓶颈——如何验证AI生成代码的安全性、版权合规性和质量，将成为比技术实现更困难的挑战。

[来源: Latent.Space(@latentspacepod) / GitHub]
Anthropic分析832个恶意账户：AI赋能网络攻击的战术映射
AI安全 威胁情报 Anthropic

Anthropic安全团队 examining 832个恶意账户，将其活动映射到长期使用的威胁行为者战术和技术数据库（MITRE ATT&CK框架）。研究发现，AI正在降低某些类型网络攻击的技术门槛，使低技能攻击者能够执行更复杂的操作。但传统的安全社区技术（如行为分析、威胁狩猎、数字取证）在检测AI赋能攻击方面仍然有效，关键在于及时更新检测规则以识别AI生成的内容特征。该研究为理解AI对网络安全格局的影响提供了首批大规模实证数据。
