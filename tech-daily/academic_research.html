重大突破Stealing Reasoning Traces：116 页论文击穿三大闭源模型的加密思维链

由 MATS program 研究员 Alexander Panfilov 领衔，联合马克斯·普朗克智能系统研究所、图宾根 ELLIS 研究所与安全公司 Snyk 发表的论文（arXiv:2608.09867）披露了 Anthropic、OpenAI、Google 三大前沿厂商 API 中普遍存在的密码学旁路漏洞：攻击者无需破解底层加密算法，只需让同厂商的轻量级模型对加密推理块进行引导，就能以明文形式转录出顶级大模型原本被隐藏的思维链。攻击链路极为简单——先让强模型（如 Claude Opus 4.8）完成昂贵推理并拿到其随响应返回的加密推理块，再将该块交给同厂较弱模型（如 Haiku 4.5）并诱导其转述内容。核心在于这类密文被设计为可在同一家供应商体系内跨会话、跨账号甚至跨模型重放（以便客户端续聊），"信封没有被拆开，换个收件人，同一家邮局仍然认得章"。论文全文 116 页，社交平台阅读量已超 210 万，Nathan Lambert 评价"这很可能成为今年最有影响力的科学论文之一"。

新基准MindTopo：微软研究院为 VLM 的拓扑推理建立新基准

微软研究院发布 MindTopo，一个专门测试多模态模型拓扑推理能力的新基准，评估模型对连通性、包含、顺序、分离、结（knot）等拓扑概念的理解。该基准同时测量"推理"与"规划"两个维度：不仅测试模型能否在静态图像中识别拓扑关系，还要求模型通过一系列动作序列保持并操纵这些关系。核心实证发现是当前多模态模型在静态识别任务上表现远好于交互式任务，提示它们难以随时间维持一致的拓扑理解；失败常发生在规划阶段而非感知阶段——随着场景变化，模型会丢失结构关系，或提出违反拓扑约束的动作。这项工作为空间推理与规划研究提供了标准化测试工具。

新基准ExtractBench 白皮书：企业长文档抽取的"召回崩塌"现象

LlamaIndex 发布 36 页 arXiv 白皮书，完整公开其文档抽取基准 ExtractBench 的构建方法与实验。该基准覆盖 370 份企业文档、4,869 页、67 种文档类型、横跨金融/能源/政府/汽车/供应链/医疗/法律/地产 8 个领域，对 14 个系统（前沿 VLM、编码 Agent、抽取 API）进行完全确定性的评估（无 LLM judge）。最关键的实证发现是"长列表完整性问题"：面对 26,725 行的无人认领财产清单、8,624 条记录的债权人矩阵、3,063 条持仓的 13F 表格，前沿 VLM 并非读错而是"直接放弃"——精度保持高位，召回在最长文档上崩塌至 F1 仅 8.9–35.8%，且"每一行返回结果看起来都正确"，导致抽查通过但大部分文档内容未返回。其迭代式抽取方案 Agentic Plus 在长列表任务上取得 96.1% F1，是唯一随文档变长仍保持水平不降的系统。

§2深度论文解读

解读一 · Stealing Reasoning Traces from Proprietary LLM APIs（arXiv:2608.09867）

摘要：三大闭源模型 API 返回的"加密思维链"因支持跨会话/账号/模型重放而成为密码学旁路；研究者用两次 API 调用让同厂弱模型转述出强模型的隐藏推理明文。

研究背景

"防蒸馏"是闭源模型厂商的核心关切，隐藏思维链（Hidden CoT / Reasoning Tokens）被视为最具价值也最难逾越的护城河：模型内部先推理、再向客户端返回一个不透明的加密推理块与最终答案，下一轮对话时客户端把密文传回，模型即可接着前文状态继续工作。这套设计原本兼顾三件事——用户看不到完整推理、客户端改不了内容、服务商不必为每段会话长期保存状态。其隐含假设是"加密即安全"。

核心创新

论文的关键洞察在于：密文必须可被客户端重放（否则无法续聊），而这一重放能力在供应商体系内并未被严格隔离——加密块可以带到另一个会话、另一个账号甚至另一个模型里继续使用。攻击者无需破解底层加密算法，只需在同一家厂商体系内完成两步：先用强模型产生昂贵的推理，取得加密块；再将其重放给同厂较弱模型，通过提示诱导（jailbreak）让弱模型"转述"出强模型未显示的推理内容。Claude 侧用 Opus 4.8 生成、Haiku 4.5 复述即为代表性实验。

结果与验证

该攻击在 Anthropic、OpenAI、Google 三家厂商的 API 上均被验证有效，研究团队还观察到 Kimi-K3 的重现概率异常。论文篇幅达 116 页，详细记录了从加密块格式逆向、重放边界测绘到弱模型转述的实验全流程。研究者以项目名"Stolen Thoughts"发布，并上线了独立域名供复现。

学术意义与边界

该工作推翻了业界素来笃信的"加密即安全"假设，把问题从"加密是否可破"重新定义为"推理轨迹的可重放性边界在哪里"。对推理隐私、蒸馏防护与 API 安全设计提出了新课题：防蒸馏不应依赖加密晦涩，而应在服务端对推理追踪的归属、跨模型/跨账号隔离进行重构。Nathan Lambert 称之为"今年最有影响力的科学论文之一"，其方法论意义（面向系统边界的攻击思维）超越了单次漏洞披露本身。

📎 来源： AI前线 · AINLP · Simon Willison's Weblog
解读二 · MindTopo：评测多模态模型拓扑推理的新基准（Microsoft Research）

摘要：MindTopo 同时评测推理与规划两个维度，发现当前 VLM 在交互式拓扑任务上系统性弱于静态识别，失败集中于规划阶段而非感知阶段。

研究背景

空间推理是通向可靠具身智能与视觉规划的基础能力，而拓扑关系（连通性、包含、分离、顺序、结等）是空间认知中比物体识别更抽象、更稳定的结构层。既有视觉语言模型基准多聚焦静态物体识别、属性判断或基础空间关系（如上/下/左/右），缺乏对拓扑这种"不随形变改变"的结构性关系进行系统评测——而这恰恰是机器人操作、导航与场景理解中不可或缺的能力。

核心创新

MindTopo 的差异点在于同时测量"推理"与"规划"。推理侧：模型需要在静态图像中识别并推理拓扑关系；规划侧：模型必须在一系列动作中保持并操纵这些关系（如移动、拆解、缠绕）。该设计把测试从"能否看出关系"推进到"能否在变化中维持对结构的稳定理解"，更贴近真实交互场景。

实验结果

当前多模态模型在静态识别上表现显著优于交互式任务，说明它们尚未形成随时间一致的拓扑心智模型。失败往往在规划阶段暴露：当场景变化时模型丢失结构关系，或提出违反拓扑约束的动作——尽管同一模型在静态图中能正确识别相同的拓扑结构。

学术意义

MindTopo 为空间推理与规划提供了标准化测试工具，其"感知—规划鸿沟"的发现对神经符号方法、世界模型与视觉规划等方向有直接启示：模型需要的可能不只是更好的感知，而是能在行动链条中稳定追踪与更新抽象结构的机制。该工作由微软研究院与多家高校合作，与同日发布的机器人/具身研究（Chelsea Finn）形成呼应。

📎 来源： Microsoft Research Blog · Microsoft Research(@MSFTResearch)
