Prompt Optimization微软开源 SkillOpt：将 Agent 技能文档视为可训练参数

微软本周开源了 SkillOpt，一个把 Agent 技能文档当作「可训练参数」的文本空间优化框架。其核心洞察是：既然内部权重可用梯度下降优化，外部自然语言指令也应有一套系统化的训练方法。该框架在 7 个目标模型、6 个基准测试、3 种执行环境（直接对话、Codex、Claude Code）的全部 52 个评测组合中均达到最优或并列最优。

这项工作将 Prompt Engineering 从手工试错提升为可系统优化的训练问题，为 Agent 技能文档的自动优化提供了理论框架和实证基础。论文已发布于 arXiv:2605.23904。

LLM EvaluationRubrics 综述：Agent 时代如何定义「好答案」

中国人民大学高瓴人工智能学院研究团队发布了首篇 Rubrics 综述论文《The Rules of the Game: A Survey of Rubrics for Large Language Models》，全文 40 页，系统梳理了 Rubrics 在大模型中的定义、构造方法、训练应用、评测场景与开放挑战。

Rubrics 将模糊的「好答案」标准拆解为可逐项检查的评价维度（如是否回答用户问题、覆盖关键信息、引用可靠证据、论证是否清晰等），使评审者或 judge model 能给出细粒度反馈并转化为训练信号。这标志着大模型的训练与评测正在从单一正确性信号，转向多维度、可解释的质量标准体系。论文同时维护了持续更新的 GitHub 项目。

Embodied AI复旦系团队推出 STI-WM：首创时空一体架构的机器人世界动作模型

深耕世界动作模型底层技术五年的复旦系科创企业眸深智能，正式推出 STI-WM（Spatiotemporally Integrated World Model）时空一体世界动作模型。当前行业主流的 VLA 视觉语言动作模型、通用世界模型普遍存在空间感知精度不足、物理逻辑约束缺失、长时序规划能力薄弱等痛点。

STI-WM 通过时空一体架构尝试解决上述问题，旨在支撑机器人实现真正的自主感知、自主推理与自主决策。半年内已完成 5 轮融资，是中国原生物理 AI 领域的重要探索。同期，τ0-WM 也发布了号称最大规模预训练的开源具身世界模型，基于 17800 小时真机数据。

Agent Training复旦 × 通义提出全新 CUA 训练范式

复旦大学与通义团队合作，提出了全新的 Computer-Use Agent（CUA）训练范式，旨在解决当前 Agent 在工具选择与使用上的核心瓶颈。研究指出，「别光给 Agent 加 Tool 了，它根本选不明白」——单纯增加工具数量而不改进训练方法，无法提升 Agent 的工具使用能力。

该工作从训练方法层面重新审视了 CUA 的能力边界，为下一代能够自主规划、正确使用外部工具的 Agent 提供了新的技术路线。这反映了学术界对 Agent 研究从「堆工具」向「精训练」转变的共识。

Context ManagementThe Efficiency Frontier：上下文管理策略的最优选择框架

一篇关于上下文管理的学术工作提出了「效率前沿」（Efficiency Frontier）框架，将上下文策略选择建模为单一的成本-性能优化问题。该框架引入了表示额外上下文边际效用递减的对数效用项，以及一个表示预处理在重复查询中摊销的重用参数 N。通过扫描 N 值，可以发现检索与压缩方法的交叉区域，从而在实际部署负载下选择最优策略。

这项工作弥补了现有研究在「真实负载下何时一种方法真正优于另一种」这一问题上的空白，为 Agent 系统的上下文资源管理提供了理论指导。

Spec-Driven Testing for Agents: A Brain the Size of A Planet

Steven Willmott, SafeIntelligence | AI Engineer Summit 2026

研究背景

随着 Agent 系统的能力不断增强，其安全风险也在同步扩大。Steven Willmott 指出了一个被忽视的安全现象：将恶意指令包装成诗歌对大模型是一种有效的越狱手段——大模型能理解诗歌的含义并执行指令，而小模型因为无法理解诗歌而不受影响。这说明「更大 ≠ 更安全」：能力越广泛的模型攻击面也越大，且拥有更多基础设施访问权限可供滥用。

核心框架

  • 显式规则：如「折扣不得超过 10%」，以硬约束限制 Agent 行为边界
  • 领域本体：限定 Agent 的知识范围（如航空公司 Agent 只需知道实际飞往的目的地）
  • 权限与角色：定义不同角色的操作权限，防止越权行为
  • 鲁棒性要求：规定在多少拼写错误或改写后系统应失败，而非持续执行

学术意义

该框架的核心贡献在于将 Agent 验证从「测试数据集」范式提升为「规范驱动」范式——spec 需要独立于模型实现编写，从而使验证具有真正的安全保障意义。这为 AI 安全研究提供了一个可操作的工程框架，也为学术界研究 Agent 的可验证性（verifiability）提供了新的切入点。

SkillOpt: Training Agent Skill Documents as Trainable Parameters

Microsoft Research | arXiv:2605.23904

研究背景

在智能体应用中，程序员花费大量时间手写 CLAUDE.md、Codex skill 文件和各种 Agent system prompt。这种手工试错本质上与手调 prompt 没有本质区别，只是对象从一句话变成了一整份文档。微软研究院提出：Agent 的技能文档就是它的「外部权重」，既然内部权重可以用梯度下降来优化，外部权重也应该有一套系统化的训练方法。

核心方法

  • 文本空间优化：不训练模型权重，只训练指导 Agent 行为的自然语言文档
  • 跨模型泛化：在 7 个目标模型、6 个基准测试、3 种执行环境上验证
  • 全面最优：全部 52 个评测组合中均达到最优或并列最优

学术意义

SkillOpt 标志着 Prompt Engineering 正在从「手工艺术」向「可训练科学」演进。它为技能文档的自动化优化提供了理论基础和实证验证，也为研究「自然语言作为可优化参数空间」的性质开辟了新的研究方向。

Trend 1: Agent 评测方法论从单一指标到多维 Rubrics

随着大模型从简单问答走向深度研究、医疗咨询、多模态生成和长程 Agent 任务，评测方法论正在发生范式转变。Rubrics（评分量规）正在成为连接人类期望、任务要求和模型行为的重要接口，推动评测从单一正确性信号转向多维度、可解释的质量标准。人大高瓴人工智能学院发布的 40 页综述系统梳理了这一方向，预示着未来 Agent 研究将需要更精细的评估基础设施。

Trend 2: 具身智能从世界模型到世界动作模型的演进

本周多条新闻指向具身智能领域的技术路线分化：τ0-WM 强调大规模真机数据预训练（17800 小时），STI-WM 探索时空一体架构，王晓野的工作则推动世界模型向多智能体交互仿真迈进。这些并行进展表明，具身智能正从「预测接下来会发生什么」的世界模型，向「知道应该采取什么动作」的世界动作模型演进。学术界需要关注这一范式的理论基础——如何将物理约束、因果推理与动作规划统一到一个可学习的框架中。

Trend 3: AI 安全研究的政治经济学与评估可信度

本周围绕 Anthropic 的争议——包括被指控「阉割旧模型以推销新版本」、Opus 4.8 的 API 身份识别异常、以及系统卡中政治中立性评估的饱和现象——揭示了一个深层问题：在商业化压力下，模型评测的独立性和可复现性面临挑战。Andy Hall 指出，即使「中立性」直接评估已饱和，更深层的偏见评估仍发现问题。这提示学术界需要开发更 robust、更难被「针对性优化」的评估方法。

Trend 4: Prompt/Skill 工程正在「科学化」

微软 SkillOpt 将技能文档视为可训练参数、中国人民大学发布 Rubrics 评测综述、NVIDIA 开源 SkillSpector 安全扫描器——这些事件共同指向一个趋势：围绕大模型的「外围工程」（prompt 设计、skill 编写、安全验证）正在从经验驱动走向系统化和科学化。这对 AI 工程研究提出了新的理论问题：自然语言指令空间的优化性质是什么？如何定义和度量「好的」system prompt？
