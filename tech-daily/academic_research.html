1. 研究动态

深度学习基础理论出现系统性突破："学习力学"框架试图建立第一性原理级别的科学理论

由 UC Berkeley、哈佛、斯坦福等高校 14 名研究者组成的团队发表了一篇系统性综述论文，将过去十年间散落在各处的深度学习理论碎片拼成了一幅完整的图景，并将其命名为 Learning Mechanics（学习力学）。该框架试图为神经网络的学习过程建立一套第一性原理级别的科学框架，类似于经典力学统一天体运动、统计力学连接微观与宏观的关系。论文指出，过去十五年深度学习的成功几乎完全来自工程直觉和大规模实验，而非理论推导——AlexNet 依赖 GPU 并行计算的偶然发现，ResNet 来自对梯度消失问题的修补，Transformer 的注意力机制最初甚至未被认真对待。这一新框架的提出，标志着学术界开始系统性地回应 LeCun 和 Hinton 等人关于"深度学习理论基础仍是荒原"的批评。

ICLR 2026 录用论文 ReBalance 提出"均衡思考"新范式：推理精度提升 10.0 的同时长度直降 35.4%

哈尔滨工业大学（深圳）等机构的研究者针对大模型推理中的"过度思考"问题提出了 ReBalance 方法，并首次系统性地引入了 Balanced Thinking（均衡思考） 这一新视角。该方法的核心洞见是：高效推理的关键并非盲目压缩推理长度，而是在过度思考与思考不足之间维持动态平衡。ReBalance 利用模型自身的置信度信号，在思考过程中实时调控其内部状态，无需额外训练即可实现推理行为的动态引导。在参数规模从 0.5B 至 32B 的四个主流模型上，以及涵盖数学推理、通用问答和编程任务的九个基准测试中，该方法在精度提升 10.0 的同时将推理长度降低了 35.4%。这一结果为推理效率优化领域提供了新的方法论方向。

长期智能体协同进化新框架：LLM 决策器与动态技能库的双向优化机制

一项新研究针对长期任务执行智能体（long-horizon agents）中决策器分解能力不足和技能库老化两大核心瓶颈，提出了 协同进化框架（co-evolution framework）。在该框架中，LLM 决策智能体与动态技能库通过迭代优化实现相互增强：决策器负责选择和链式调用技能，性能反馈同时更新策略和技能库，新技能则通过泛化成功序列自动生成，而非预先手工编码。这一设计与当前主流做法形成鲜明对比——大多数长期智能体栈将技能优化与决策制定视为独立的优化问题，导致系统性能在达到一定水平后陷入平台期。该框架为自适应规划和可复用行为库的构建提供了新的理论路径，对通用智能体（General Agent）的研究具有方法论意义。

主动式智能体评估新基准 PARE-Bench：143 项任务覆盖通信、生产力、日程与生活方式应用

当前智能体基准测试大多将应用建模为扁平的工具调用 API，忽略了真实用户交互中的状态化、序列化特征。针对这一问题，研究者提出了 PARE 框架，将应用建模为具有状态导航和状态依赖动作空间的有限状态机，从而支持真实的主动用户模拟。在此基础上构建的 PARE-Bench 提供了 143 个多样化任务，横跨通信、生产力、日程安排和生活方式四大类应用，系统性地测试了上下文观察、目标推断、干预时机和多应用编排四个维度的能力。该基准为评估"在用户表达需求前即采取行动"的主动式智能体（proactive agents）提供了首个系统性的实验平台，填补了该领域评估方法论的关键空白。

来源: elvis (@omarsar0) on X
生产级编程智能体架构解剖：Claude Code 代码库仅 1.6% 为 AI 决策逻辑

一项基于 Claude Code 泄露源代码的系统性架构分析（论文 arXiv:2604.14228）揭示了生产级 Coding Agent 的深层设计哲学。核心发现是：Claude Code 整个代码库中仅约 1.6% 为"AI 决策逻辑"（提示词、模型调用、循环），其余 98.4% 为确定性的运行环境（权限管理、上下文构建、工具路由、故障恢复）。这一悬殊比例意味着模型几乎拥有完全自主的决策权（决定在哪里推理、调用什么工具），但模型从不直接接触文件系统、Shell 或网络——工程复杂度的目的不是约束模型，而是为模型提供一个安全且丰富的运行环境。该架构与 LangGraph（状态图约束控制流）和 Devin（显式规划器）走的路线截然相反，体现了"最小脚手架 + 最大化操作型 harness"的设计范式。研究团队进一步提炼了十三条设计原则，并以五种人类价值（人类决策权、安全/隐私、可靠执行、能力放大、情境适配）作为设计权衡的驱动力。

2. 深度论文解读

2.1 There Will Be a Scientific Theory of Deep Learning —— 深度学习的"牛顿定律"是否即将诞生？

摘要： 由 UC Berkeley、哈佛、斯坦福等机构的 14 名研究者系统梳理了过去十年间散落在各处的深度学习理论碎片，提出了 "Learning Mechanics" 框架，试图为神经网络的学习过程建立一套第一性原理级别的科学理论。

研究背景与问题意识。 深度学习在过去十五年间取得了令人眩晕的进展，参数量从百亿冲向万亿。然而，学术界始终未能建立其基本理论——神经网络仍然是个黑盒子。LeCun 在 X 上直言"深度学习的理论基础仍然是一片荒原"，Hinton 多次表示深度学习的成功更像炼金术而非科学：我们知道什么有效，但不知道为什么有效。这种理论滞后于工程实践的局面，已经成为制约领域长期健康发展的根本瓶颈。

核心贡献：Learning Mechanics 框架。 该研究团队将过去十年间各种孤立的理论发现——包括神经正切核（NTK）理论、平均场理论、信息瓶颈理论、彩票假说等——整合为一个统一的理论框架。类比经典力学统一了天体运动与地面落体、统计力学架起了微观粒子与宏观热现象之间的桥梁，"学习力学"试图回答的核心问题是：神经网络在训练过程中究竟"学"到了什么？为什么大规模、过参数化的模型能够泛化？优化的动态过程如何与表示学习相互作用？

学术意义与局限。 这项工作的重要意义在于，它首次以系统性的方式将深度学习理论从"碎片收集"推进到"框架构建"的阶段。然而，该框架目前仍处于早期发展阶段，其预言能力和对实际模型设计的指导价值尚待验证。真正的"牛顿定律"不仅需要解释已知现象，还需要能够预测未知行为——这将是 Learning Mechanics 未来需要面对的核心考验。

2.2 Efficient Reasoning with Balanced Thinking —— 从"过度思考"到"均衡思考"的范式转换

摘要： 哈尔滨工业大学（深圳）等机构的研究者提出了 ReBalance 方法，引入"均衡思考"视角，利用模型自身的置信度信号在推理过程中实时调控思考深度，无需额外训练即可实现推理行为的动态引导。

问题的重新定义。 过去一年中，大模型推理的"过度思考"问题引发了广泛关注。但 ReBalance 团队指出，真正的挑战并非简单地缩短思维链。简单问题的冗余验证和复杂问题的思考不足并存——现有方法往往一刀切地压缩输出，导致模型从"想太多"直接滑向"想太少"。因此，问题的本质是思考失衡，而非单纯的过度思考。

方法创新。 ReBalance 的核心机制是利用模型在推理过程中产生的置信度信号作为内部状态指标，实时判断当前推理是否处于"过度"、"不足"或"恰当"的状态，并动态调整后续推理行为。关键在于，这一过程完全基于推理时的自我监控，无需额外的训练数据或微调，属于即插即用的推理时方法（inference-time method）。

实验结果与影响。 在 0.5B 到 32B 参数规模的四个主流模型（具体模型未在报道中披露）上，ReBalance 在数学推理、通用问答和编程任务共九个基准上实现了精度提升 10.0 和推理长度降低 35.4% 的双重收益。考虑到该方法无需训练成本，其实际应用价值非常高。从学术角度看，这项工作将推理效率优化的研究焦点从"长度最小化"重新定向到"动态平衡"，为后续研究开辟了新的理论空间。

论文: Efficient Reasoning with Balanced Thinking
会议: ICLR 2026
作者机构: 哈尔滨工业大学（深圳）等

NVIDIA 100% 开源 Lyra 2.0：单张 2D 图片生成可探索 3D 世界

NVIDIA 正式发布并完全开源了 Lyra 2.0，该系统能够将单张 2D 图片转换为持久、可探索的 3D 交互世界。技术流程分为三步：图片到视频的初始生成、视频到 3D 高斯泼溅（Gaussian Splatting）和网格的重建，以及最终的持久化 3D 场景渲染。项目已开源模型权重、推理代码和预训练模型，这对于具身 AI（embodied AI）仿真环境的构建具有重大意义——研究者无需再依赖真实世界数据采集即可生成多样化的训练环境。当谷歌将类似技术（Genie 3）保持闭源时，NVIDIA 选择完全开源，这一策略选择本身也值得从学术和产业互动的角度加以关注。

4. 趋势观察

4.1 从"工具调用"到"状态机建模"：智能体评估范式的深层转变

PARE 框架的出现标志着智能体评估方法论的根本性转变。当前主流的 agent 基准（如 SWE-bench、WebArena）本质上将环境建模为工具调用接口——智能体接收观察、输出动作，环境返回新观察。但真实应用是状态化的、有导航结构的、上下文依赖的。PARE 将应用建模为有限状态机，这一形式化选择不仅更贴近真实交互，也为理论分析提供了可操作的数学结构。可以预见，未来的 agent 评估将更多地借鉴形式化方法和程序分析的技术传统，而非单纯的端到端基准测试。

4.2 推理效率研究进入"后长度优化"时代

ReBalance 的"均衡思考"概念揭示了一个重要的范式转换：推理效率优化正在从"越短越好"的单一维度优化，转向对推理质量与成本之间动态权衡的多维度优化。这一转变的理论基础是，思维链（Chain-of-Thought）的推理过程本身具有内在的结构——验证、回溯、假设生成等不同类型的推理步骤对最终答案的贡献度并不均匀。未来的研究方向可能包括：基于信息论的最优停止准则、针对不同问题难度的自适应推理预算分配、以及将推理过程本身作为学习信号的元学习方法。

4.3 生产级 Agent 的架构共识正在形成

Claude Code 架构分析揭示的"1.6% AI 逻辑 + 98.4% 基础设施"比例，以及十三条设计原则的提炼，暗示着生产级 Agent 系统的架构模式正在从零散的工程实践收敛为可传授、可复现的设计知识。这一趋势与早期数据库系统、操作系统的发展轨迹类似：先有大量特化的工程实现，随后逐渐沉淀出通用的架构模式和设计原则。对于学术界而言，这意味着 Agent 系统研究正在从"算法创新"扩展到"系统创新"的新阶段，而后者正是计算机科学传统优势的领域。

4.4 3D 生成技术成为具身智能的关键基础设施

NVIDIA Lyra 2.0 和 Microsoft TRELLIS.2 的相继开源，标志着高质量 3D 资产生成正在从研究原型转变为可用的基础设施。对于具身 AI（embodied AI）和机器人学习社区，这意味着训练数据的获取方式可能发生根本性改变——从昂贵的真实世界采集转向可扩展的生成式仿真。这一转变的影响将类似于 ImageNet 对计算机视觉的推动作用：当数据瓶颈被解除后，算法创新的空间将被大幅拓展。需要关注的是，生成式 3D 环境与真实物理世界之间的域差异（domain gap）问题将成为新的核心研究挑战。
