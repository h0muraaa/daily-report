设计趋势洞察

CLI 是新时代的 GUI：交互界面的全面降级还是跃升？

钉钉、飞书等主流工具密集开放 CLI 支持。随着 Agent 广泛被使用，图形用户界面（GUI）中需要人类大量手动的“点选”显得过于低效。而 CLI 则提供了一个可以直接命令和批量执行的路径。

UX 启示：系统设计不再只是面向“人类用户”，而是面向“人类 + Agent”。我们需要考虑提供对自动化更加友好的接口和输入方式。

GUI 界面在 AI 时代的进化：意图化与响应式

Agent 4 in Replit 的设计中重新思考了跨多种输入输出的协同。从原本的纯文本框迭代为集成了设计画布和实时反馈的界面。这标志着 GUI 虽然面临挑战，但只要将其发展为更好的“人类直觉捕捉器”，依旧具备强大的竞争力。

UX 启示：好的 AI 工具需要将用户的需求（意图）迅速反应并落地成型，不仅要“做对”，还要在交互链路上给用户充分的安全感与即时反馈。

诊断界面的体验升级：降低认知负担

LangSmith 针对“排查 Agent 失败原因”进行的大规模改版表明：当系统越来越复杂、不确定性越来越高时，“如何报错”甚至比“如何成功”更加重要。界面的信息层级需要按照人类排错的直觉进行重组。

UX 启示：可解释性和可见性是 AI 体验设计的重中之重。设计师必须深刻理解“出错的旅程”，并提供结构化的、清晰的上下文。

Claude Code 的 Computer Use 功能

AI 编程助手 / UI 操作

将大模型与本地 GUI 环境打通。Claude 可以直接执行点击、滚动、测试等 UI 操作，进一步打破了文本代码与最终结果之间的壁垒。

虽然目前在复杂、非常规的操作上有时表现不稳定，但这极大地展示了“智能体帮人类做 UI 测试和反馈”的雏形。对开发者来说，这省去了频繁在代码编辑器和浏览器/App之间切换的操作。

体验亮点

  • 直接在终端调用，操作流高度统一
  • 不仅生成代码，还可以即时完成 UI 测试并验证效果
  • 提供直观反馈，大幅减少人类的机械劳动

研究方法论

从“点选用户研究”转向“Agent 轨迹研究”

当我们不再记录用户的鼠标点击（Clickstream），而是记录 Agent 访问知识库、做出决策的过程（Traces），用户研究的对象就发生了根本的转变。研究者需要具备阅读和分析 Agent 日志的能力，并能够通过这些日志反推用户原本的意图，从而去优化产品提供的信息结构和反馈机制。

混合界面的评估体系

随着 GUI 和 CLI、TUI 的深度融合，单一的可用性测试已无法覆盖所有的使用场景。在多模态、跨终端的工具上，应当引入“意图转换率”和“任务交接摩擦”来衡量界面的有效性，不仅考察人类的体验，也要考察 Agent 抓取页面和解析信息的体验。
