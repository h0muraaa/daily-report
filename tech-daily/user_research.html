从"给答案"到"逼思考"：AI 教育产品的交互范式转移

近期一款名为 Koji 的 AI 家教产品引发热议，它由 MIT 和哈佛学习科学专家训练，核心理念是"拒绝当答案打印机"。与传统 AI 辅导不同，Koji 不会直接给出解题步骤，而是通过反问、屏幕批注、临时加小测等方式引导学生自己推导。

产品设计上有三个值得关注的交互创新：首先是"屏幕可见性"——Koji 直接趴在孩子屏幕旁边，知道光标在哪停留、哪一步拖错了，无需用户手动描述问题；其次是"图形化干预"——可以高亮区域、给图加批注、在画布上和学生一起画辅助线，突破了纯文字对话的局限；最后是"主动开口"——每个新页面 Koji 会先抛出一个引导性问题，大幅降低学生求助的心理门槛。

设计洞察：教育类 AI 产品的核心指标不应是"用户满意度"，而是"知识到底有没有进脑子"。Koji 的设计选择揭示了一个反直觉原则：真正好用的 AI 家教，应该让学生"觉得有点烦"——因为适度的认知摩擦才是学习发生的必要条件。这对所有"辅助型"AI 产品都有启发：效率最大化不等于体验最优，有时需要刻意保留"不顺畅"来保障核心目标。

ego lite：为 AI Agent 重新设计的浏览器体验

ego 团队发布了专为 AI agent 设计的浏览器 ego lite，从根本上解决了当前 agent 操作浏览器的体验痛点。传统方案用 CDP 桥接 Chrome，导致窗口乱飞、登录状态随机丢失——这些问题不是 bug，而是"桥接的极限"。

ego lite 从内核层面重建，让 agent 直接继承用户的登录状态，在完全隔离的后台空间中运行。用户和 agent 各自拥有独立 space，互不干扰。据官方数据，相同任务下执行速度比其他方案快 20% 到 245%。产品开场动画也做得很细腻，体现了对 developer experience 的重视。

设计洞察：ego lite 代表了一类产品设计思路：不是给现有工具加 AI 能力，而是围绕 AI 的原生行为重新设计工具。当 agent 成为新的"用户群体"，它们需要的不只是 API 接入，而是符合其运行特征的专属环境。这对设计师的启示是：AI 时代的体验设计对象，已经从"人"扩展到了"人 + agent"的混合系统。

"认知缴械"：AI 时代的人机交互心理学新课题

宾夕法尼亚大学沃顿商学院学者 Steven Shaw 和 Gideon Nave 在 2026 年发表的研究中提出了"认知缴械"（Cognitive Surrender）概念。他们在传统的认知心理学双系统模型（System 1 直觉 / System 2 深度思考）基础上，增加了 System 3——在大脑之外运行的外部人工认知系统。

实验让 1,372 名参与者完成 9,593 次认知反射测试。结果显示，当 AI 随时可用时，参与者更倾向于绕过自己的 System 2，直接依赖 AI 给出答案。犹豫、试错、在死胡同里徘徊后突然连接线索的过程被折叠了——而这些正是深度学习和创造性思维发生的关键环节。

研究启示：这对 UX 设计师和产品经理提出了一个全新的设计伦理问题：我们应该设计"让用户尽可能少费力"的产品，还是保留适度的认知摩擦来保障用户的长期能力发展？Koji 教育产品的"反效率"设计，可能预示着一个新的设计范式——有意识的摩擦设计（intentional friction design）。
[来源: 腾讯科技]

AI 产品经理的核心能力模型：从 PRD 到 Trace

Arize AI 联合创始人 Aparna Dhinakaran 分享了一套 AI 产品经理的实战能力框架。核心观点包括："会用观测和评估看 trace 的产品经理，已经站进前 1%"；"代码越来越便宜后，产品品味成了团队里最稀缺的东西"。

她展示了一条完整链路：从用户反馈（GitHub discussions、Slack、Discord、Gong 通话记录、PostHog、Amplitude 等）中发现痛点 -> 让 agent 生成优先级报告 -> 用 trace 和评估结果判断 agent 有没有"胡来"。AI PM 的第一步要从空白 PRD 前移到反馈现场，把碎片接成可被 agent 使用的上下文图。

方法启示：传统 PM 靠访谈和直觉整理需求，AI 时代的 PM 需要把反馈管道变成系统能力。新的核心技能不是"写更好的 PRD"，而是设计"product taste agent"——一个能每天自动告诉你最大痛点在哪、下一步路线图该排什么的智能系统。
