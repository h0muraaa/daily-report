今日要点

5 条核心洞察
  • 1

    ChatGPT 吞掉 Codex：一次 10 亿用户的“强行迁徙”

    OpenAI 把独立 Codex 应用并入 ChatGPT 桌面端，原 ChatGPT 改名 “Classic”，聊天被缩成右下角一个小浮层，主界面让给 Work/Code 两个 Tab——同时深度研究、Atlas 浏览器也被一并“吃掉”。社区几乎一面倒地吐槽“找不到自己的聊天记录”，Simon Willison 直言被 ChatGPT / Codex / Work / Claude / Code / Cowork 的镜像命名“彻底搞晕”，歸藏更痛批“交互稀烂”“过去几个月的 Codex 认知全白干”。这是一次教科书级的产品形态重组：当增长逻辑从 chatbot 转向 Agent，品牌惯性、信息架构与用户心智同时承压。

  • 2

    “托付半径”：Agent 产品真正的 UX 上限，是你敢把多少活彻底交出去

    爱范儿在百度搭子 AI DAY 上提炼出一个精准概念——托付半径：衡量一个 Agent 上限的，不是 demo 多炫，而是用户敢把多少活“彻底交给它”。同日创业邦 / 定焦的《乱用 AI，打工人被坑惨了》给出反面注脚：AI 会一本正经地编造不存在的竞品、虚构法条、擅改代码模块，而“它给的东西太像真的”反而让人放下戒备、在提案现场被客户当场拆穿。信任不是越高越好，可被校准的信任才是好 UX。 产品的分水岭，正在从“能不能做”转向“敢不敢交、交了如何兜底”。

  • 3

    语音进入“自然界面”蜜月期，但拟人化又一次过界

    GPT-Live 全双工语音被 Brockman 称为“真正的进步，仿佛进入自然交互的新时代，以后会少盯屏幕”，向阳乔木也说“智能调高点，快接近真人”。但过界信号同步出现：Orange AI 吐槽“你笑她也笑，笑得特别大声像疯了”“老婆社恐犯了不敢跟她说话”；发布会上的实时翻译演示“小翻车”。声音的注意力侵入感与文字不同，拟人的分寸比技术指标更难拿捏。 有意思的是，ChatGPT 用可视化卡片（世界杯/股票/天气）补偿“听觉线性、信息难回看”——这是语音 UX 里值得借鉴的范式。

  • 4

    AI 没取代你，却让你“干更多活、拿同样钱、质量还下滑”

    Lenny 的 2026 职场大样本调查颠覆主流叙事： tech 从业者最怕的不是“被 AI 抢走工作”（仅 22% 垫底），而是被要求用同样的薪水做更多事、并看着产出质量下滑——“AI 解锁的速度，被原封不动地灌回了期望值，每一点收益都成了新基线”。人人都是产品经理则记录到 AI 正在撕裂团队：管理者要降本增效，员工怕“亲手革自己的命”，极客做出惊艳 Demo、保守派“看好戏”式找茬。劳动者的真实 UX，是被不断拔高的基线与无处安放的同事情感。

  • 5

    品味成为最后护城河：模型会“先想美学”了，但“丑”仍是共识

    Every 的 Dan Shipper 评测 GPT-5.6 Sol 的设计能力：它真正会在动手前先推理美学概念，相对 5.5 是实质飞跃，虽仍不及 Opus 与 Fable，但差距在快速缩小。与此同时 Orange AI 一针见血：“benchmark 飞升，审美一直停留在原地……怎么能这么丑。”当生成成本趋零、人人一分钟出内容，注意力、判断与品味成为稀缺资源——深思圈在 GTM Summit 的现场结论也是“真正稀缺的从来不是产出，而是别人凭什么多看你一眼”。

设计趋势洞察

2 个深度

趋势一从 Chat 到 Work / Code：超级应用的信息架构之难

今天 OpenAI 把 ChatGPT、Codex、Atlas 浏览器三合一，桌面端只剩一个叫 “ChatGPT” 的超级应用，主界面却几乎全是原 Codex 的壳； Logan Kilpatrick 宣布“我们正式进入超级应用时代”。这背后是一次典型的 IA 难题：当产品从单一模态（聊天）长成多模态工作台，老用户的心智模型被强制改写。 歸藏抓住核心矛盾——“Work 和 Code 根本没必要硬区分，没必要在界面上透出‘我只能 Code’或‘我只能 Work’，用户直接用就行了”，切换时除了左上角 logo 几乎看不出区别；花叔则点破“名义上是 Codex 并入 ChatGPT，实际是 Codex 吞并了 ChatGPT，只因 ChatGPT 品牌更响才留着名字”。

但反方意见同样成立：LlamaIndex 的 Jerry Liu 实测后表示更喜欢 ChatGPT 的 Work/Codex 拆分胜过 Claude 的 Cowork/Code——界面更统一、两模式共享聊天记录、对“知识工作 vs 代码”的差异 Toggle 处理得更用心。真正的风险点在计费与可发现性：小互担心普通 Plus 用户若把 Work 当 Chat 用会“立刻用光额度、认为被割韭菜”，而 OpenAI 恰恰没讲清用量怎么算；Simon Willison 引用官方说明，云 Work 不出现在桌面 Work、桌面线程与本地文件留在本机——“试图（但未成功）解释清楚 ChatGPT Work”。

实践建议：做 mode-splitting 时，先证明“两种模式在心智上真的不同”，否则宁可用统一入口 + 上下文自适应；命名是资产，镜像对手命名（Work↔Cowork、Code↔Code）会让用户跨产品失忆；任何会改变“扣费单位”的整合，都必须把额度规则写在一级入口，而不是文档里。
信息架构超级应用命名即 UX计费透明度

趋势二反即时 · 反上云 · 反通知：“慢 / 笨 / 本地”成了新奢侈

当一切产品都在比谁更快、更即时、更云端，一批反方向的设计正在获得真实增长。美国 App Roost 让消息按“真实鸟类的飞行速度”慢慢飞到对方手里，距离越远耗时越久，刻意违背“便利速达”——结果一条 Threads 帖子带来 3 天 10 倍、近 30 万用户；它戳中的正是“对方正在输入…”带来的即时焦虑。设计师 Karen X. Cheng 把一台 1920 年代的旋转拨号电话接上 AI Agent，用机械显示屏回复，称它是“没有干扰通知的笨手机”——刻意用物理限制换取注意力安宁。

同一脉络还有两层：一是去云化——Susan STEM 写道，去云化不一定源于某个可量化的隐私威胁，而可能只是对“万物默认上云”这套架构的拒绝；二是复古拟物——有人做了 UltraPod 让 iPhone“退回 2001 年”，国产厂商 1:1 复刻 1979 年 Walkman 的机械按键与键程，连“没用”的 HOTLINE 键都原样保留。Nilay Patel 关于 AR 眼镜的提醒则为这股潮流定了边界：真正的 AR 需要“贴着眼、持续录制一切的摄像头”，必然侵犯隐私——所以“少感知、少上传”本身正在成为体验卖点。

实践建议：把“慢 / 离线 / 不打扰”设计成可被感知的功能而非缺陷；在默认即时的产品里提供“延迟送达”“安静时段”“本地优先”的一档；复古拟物要服务于情绪价值（安心、掌控、仪式感），而非单纯堆砌怀旧符号。

产品体验点评

2 个案例

案例一ChatGPT Work / Codex 三合一：Sites 一键发布很香，整合却很疼

是什么：桌面端把 Chat、Work、Codex 合进一个 “ChatGPT” 超级应用；新功能 Sites 可把对话生成的网页直接部署成可分享的链接（个人待办、五人旅行合意器 Travel Roulette 等），并内置可导入密码与 Cookie 的浏览器、100GB 存储、推理强度滑块。为什么重要：它是 OpenAI 把 9 亿周活从“聊天”迁向“办事”的关键一跃，也是对 Claude Cowork/Code 的正面回应。

关键 UX 细节：亮点在闭环——想法 → 网页 → 一键发布分享，宝玉夸 Codex 新的推理强度滑块“做得很酷”；痛点在迁徙成本——卡兹克感慨“原版 ChatGPT 界面也没了，只剩一个小聊天 Tab 证明它存在过”，howie 指出“ChatGPT 的 logo 都变成了 Codex”，小互则盯住计费黑箱。OpenAI 还把 reasoning 拆成 3 模型 × 5 强度 × 2 速度 = 30 种组合，把选择负担直接甩给用户。

设计启示：超级应用不是“功能加法”，而是“心智减法”。迁移老用户时，保留熟悉的锚点（位置、图标、历史）比重做界面更重要；发布即分享（Sites）是降低“从做到给人看”摩擦的好范式；但 30 档模型/强度组合属于把内部复杂度外溢——必须提供“默认推荐 + 一键 Auto”，否则就是变相劝退。
来源： 数字生命卡兹克 · 卡尔的AI沃茨（改名/分区/Sites） · OpenAI Devs（Sites 一键发布） · howie（100GB 存储） · 宝玉@dotey（推理滑块） · ChatGPT（Work 快速导览）

案例二GPT-Live 语音：卡片补齐听觉短板很妙，拟人过界依旧翻车

是什么：OpenAI 全双工语音模型 GPT-Live 进入大众日常使用，支持边听边说、可被打断，并能在对话中弹出世界杯/股票/天气等可视化卡片；Simon Smith 发现它还能把定时新闻简报“边读边答疑、打断后续读”。为什么重要：它把语音从“对讲机”推进到接近真人的交替发言，是语音成为主交互界面的标志性一步；Brockman 据此判断“我们将少盯屏幕，今天的 App 会显得痛苦地不友好”。

关键 UX 细节：可视卡片是语音场景里弥补“听觉线性、信息难回看”的聪明做法；但拟人边界再次被踩穿——Orange AI 记录“你笑她也笑，笑得特别大声像疯了”“老婆社恐犯了不敢跟她说话”，发布会实时翻译也被指“小翻车”。对照产业侧，ElevenLabs 为希腊 Alpha Bank 打造了忠于品牌音色的双语客服语音 Agent，超低延迟语音公司 Gradium 同日融资 1 亿美元。

设计启示：语音产品要把“回应频率 / 可打断性 / 笑的尺度 / 沉默的舒适度”设为可调参数；为信息型回答配可视卡片，弥补听觉不可回看；品牌化语音（音色、语气、语种）是比“更像人”更稳的差异化；实时翻译类演示务必经跨口音、跨语域的真实用户测试，而非只看舞台 demo。
来源： Orange AI（笑得像疯了/社恐） · 歸藏@op7418（语音卡片） · Greg Brockman（新闻简报） · 向阳乔木（接近真人） · ElevenLabs（Alpha Bank 品牌音色） · arXiv（全双工语音 Agent 评判可靠性）

研究方法论

新方法 & 工具

方法dot plot 反 “DAU 谎言”：在有几百用户前，它可以是唯一仪表盘

YC 合伙人 David Lieb 的 dot plot 方法今日被“晚点再听”完整编译成中文：把每个用户每天有没有完成关键动作铺成一张二维表，让你不仅知道“这个月活跃多少人”，还知道“张三昨天到底有没有回来”。核心论点不变——总量图把所有用户混在一起，让你看不见任何一个具体的人；平均数会把用户磨平，新用户进来、老用户离开，总量仍可能“很好看”。

这期中文编译对 PM 与研究员的可操作性更强：它把“看数据”从汇报动作拉回产品动作——哪个用户该被访谈、哪个功能在形成习惯、哪个渠道只带来一次性试用，都能从点阵里读出来。

研究员可落地：在聚合仪表盘之外，固定维护一张个体行为 dot plot；早期产品把“找到 10 个真爱用户的行为轨迹”置于“拉高 DAU”之前；用点阵的颜色去问对的问题、修总量指标不会告诉你的问题。
个体行为反虚荣指标定性+定量
来源： 晚点再听LaterCast（dot plot 中文编译）

工具 ⭐研究/测试智能化三件套：意图驱动 E2E · 改指令而非换工具 · AI 使用元认知

① Slack 意图驱动 E2E 测试：Slack 工程团队用 Agent 按“意图”而非固定脚本跑端到端 UI 测试，运行期随界面与系统变化自适应，降低分布式系统里脆弱用例的数量——可用性回归从“维护脚本”变成“描述目标”。

② GitHub Copilot 的反直觉一课：把 Copilot code review 换成更好维护的共享工具（grep/glob/view）后，评测反而更贵、抓到的 bug 更少；根因不是工具，而是指令——把指令重写成“像评审者真实读 PR 那样：问、收敛、读、定”后，回归翻成 20% 成本下降且质量不变。给 Agent 的工具说明，和 API 文档一样是承重结构。

③ Claude Reflect 使用回顾：像“屏幕时间”一样回看 1/3/6/12 个月里你何时、用 Claude 做了什么、累计多久，并分析“哪些事其实该自己做”，可设安静时段、用久提醒休息，且不纳入无痕与健康内容。把元认知 / 数字健康做成一级功能。

研究员可落地：把 UI 回归写成“意图 + 边界”而非脚本；维护 Agent 时，先审指令再换工具，把“Agent 读世界的方式”当成要被设计的界面；主动给用户/自己配一个“AI 使用回顾”仪表盘，防止沉迷、校准边界。注意：模拟用户擅长覆盖边界与回归，却不擅长发现“意料之外的动机”，不能替代真人。

流程给 Agent 用的“接口”，本身也是一种 UX

BrowserAct Skills 围绕 Agent 的真实工作方式重做浏览器接口：页面状态要让模型低成本理解、点击输入用索引完成、多账号并行不互相污染、遇验证码逐级升级——它回答的不是“怎么打开网页”，而是“Agent 长期并发可恢复地操作真实网页时，浏览器该长什么样”。Dify CLI 则把思维链在 chat / 调试 / CLI 全链路单独透出，并升级 Human Input 表单——把可审计性与人在回路做成默认。

在“让经验跨会话沉淀”上，阿里技术的《意识 × Loop》给出范式：用长短期记忆、用户画像、工作手册，让 Loop 关掉窗口后还能“每天上班自动翻开上次写到的地方”，解决“调好的 evals 下次会话又失忆”的痛点。三者指向同一原则：Agent 能理解的界面 + 能被审计的过程 + 可被复用的经验，才是可托付的工作流。

研究员可落地：当由你定义 Agent 能力时，把“页面/工具的可理解性”当作可用性来设计；把 CoT 与人工确认点暴露成默认 UI；为重复调研建立跨 session 的记忆与用户画像，避免一遍遍重教同一件事。
Agent UX可解释性人在回路跨会话记忆
来源： 山行AI（BrowserAct Skills） · Dify（CLI + CoT 全可见） · 阿里技术（意识 × Loop 跨会话自进化）

值得关注的早期信号
信任校准

“托付半径”与“被 AI 坑惨”同框

百度搭子用“托付半径”定义 Agent 上限；同日《乱用 AI，打工人被坑惨了》记录 AI 编造竞品、虚构法条、擅改代码，用户因“太像真的”放下戒备而被当场拆穿。一正一反，把可校准的信任推成 Agent UX 的核心命题。

来源：爱范儿（托付半径） · 创业邦 / 定焦（乱用 AI）
选择过载

30 种模型 × 强度 × 速度组合：把复杂度甩给用户

GPT-5.6 在 Work/Codex 里摆出 Sol/Terra/Luna × 5 档 effort × 2 档 speed = 30 种搭配，meng shao 直呼“怎么选”，Peter Yang 公开求“默认该用哪档”。与此同时社区实测发现 Terra 意外出圈、最贵 Ultra 反而花钱更多效果更差——选择越多，越需要 Auto 与默认推荐。

设计系统工程化

把 Carbon 设计系统喂给 AI：每个组件回答“何时用 / 何时不用”

AI 的“私人语言”问题：它在写给不在场的人看
