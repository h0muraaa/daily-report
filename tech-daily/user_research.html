◆设计趋势洞察

AI 原生设计

AI 时代的产品管理范式转移：从路线图到每日发布

Anthropic 的 Claude Code 与 Co-work 产品负责人 Cat Wu 在 Lenny's Podcast 中分享了团队如何将产品发布周期从 6 个月压缩到 1 周甚至 1 天。核心转变包括：设立 evergreen "launch room"让工程师直接发布就绪功能、将 PM 角色从"协调多季度路线图"重新定义为"让团队每周出货"、以及通过"研究预览"标签降低发布心理门槛。

这一趋势对 UX 团队意味着：设计评审流程必须同步加速，设计系统需要支持"即插即用"的快速迭代，而设计师的核心竞争力正从"交付完美方案"转向"在不确定性中快速验证假设"。

极简设计

Granola 的"反野心"设计哲学：为混乱状态设计软件

AI 笔记应用 Granola 联合创始人 Sam Stevenson 在播客中分享了产品设计的核心原则：刻意将产品做得"令人惊讶地没野心"，专注服务那些"一个会接一个会"的极端用户。设计灵感来自 Oxo 厨房工具——为极端用户设计，让所有人喜爱。

最关键的设计洞察是"拥抱混乱"：针对用户在会议间隙的"系统一"思维状态（慌乱、碎片化）设计软件，而非要求用户进入深度思考。产品不保存音频、不让机器人加入会议等独特抉择，都是从用户真实隐私焦虑出发的体验设计。

●产品体验点评

产品体验

Claude "降智"事件复盘：当系统改动叠加成用户体验灾难

Anthropic 官方发布复盘报告，承认 Claude Code 在过去一个月出现质量下降，并归因于三个独立但叠加的问题：3月4日将默认思考时长从"长"调为"中"、3月26日缓存优化 bug 导致每轮对话都在清除历史思考记录、4月16日在 system prompt 中添加了字数限制指令。

从 UX 视角看，这一事件的价值远超技术层面：三个变更影响的用户群和时间段各不相同，合起来却造成了"Claude 好像变笨了但说不清楚哪里笨"的模糊负面感知。第二个 bug 甚至被内部实验掩盖，导致定位花了一周多。这深刻说明——在 AI 产品中，用户对"智能感"的感知是脆弱且整体的，任何影响对话连贯性、上下文记忆或表达丰富度的改动，都可能被放大为品牌信任危机。

产品体验

GPT-5.5 vs Opus 4.7："说人话"成为 AI 产品的新战场

用户反馈显示，GPT-5.5 最大的进步是"学会了说人话"，而 Opus 4.7 却因过度优化被吐槽"不会说人话"。这一对比揭示了一个关键洞察：编程能力与对话自然度并不矛盾，AI 产品的 personality 设计正成为差异化核心。

更值得 UX 研究者关注的是 GPT-5.5 在风格一致性上的提升——用户反馈"在原有网站设计风格延伸上非常舒服"，而 GPT-5.4 即使给了设计规范也会"做一大坨"。这说明多模态 AI 的设计理解能力正在跨越"能生成"到"能延续"的关键门槛，对设计系统、品牌一致性管理将产生深远影响。

交互设计

腾讯发布 7 个座舱智能体：从"空间位移"到"时间价值"的体验重构

腾讯智慧出行在北京车展前夕发布 7 个座舱智能体，展示了汽车作为智能空间的全新体验范式。以"随行点单智能体"为例，系统通过语音理解用户意图，结合偏好记忆与实时行程筛选最优门店，根据车辆 ETA 反向推算出餐时间，取餐时订单直接关联车牌实现"送餐到车"。

从用户研究视角，这代表了智能体设计的"无感介入"原则——在合适的时间、以合适的方式介入用户生活，而非频繁打扰。真正有价值的座舱智能体现在一种有分寸的"无感"之中，这与传统语音助手"等待指令"的被动模式形成鲜明对比。

◆研究方法论

用户研究

消费趋势洞察：从"物质拥有"到"精神体验"的用户价值迁移

腾讯研究院 T-ask 调研发布居民服务消费趋势报告，核心发现是消费支出正在从"物质拥有"的实物消费转向"精神体验"的服务消费。这一结构性转变对产品设计具有深远意义：用户不再只为功能付费，而是为情感共鸣、身份认同和独特体验付费。

对 UX 研究者而言，这意味着用户画像需要从"人口统计学标签"升级为"价值观与生活方式分层"，研究方法需要从"可用性测试"扩展到"情感旅程映射"和"意义建构分析"。

AI 辅助研究

北大开源 One-Eval：交互式自动化评测框架

北京大学 DCAI 团队开源 One-Eval，将大模型评测从"写一堆配置然后跑脚本"重构为"从自然语言需求出发、自动规划、自动执行、可中断、可追溯、可生成报告"的完整工作流。用户只需在对话框输入需求，系统自动规划评测方案并生成可分析报告。

这一工具对 UX 研究智能化工作流具有启发意义：研究设计、数据采集、分析报告的自动化闭环正在成为可能，研究者可以将更多精力投入到洞察提炼和策略建议上。

设计系统

Google DESIGN.md：让非设计师也能复刻顶级设计品味

Google 通过 Stitch 项目公开 DESIGN.md 标准，将品牌视觉系统转化为 agent 可执行的设计上下文，包括 token、组件规则、布局规则、图像规则和 Do/Don't。开发者已基于该标准创建开源工具，可将任意网站设计风格复刻为 DESIGN.md。

对设计系统建设而言，这意味着设计规范正在从"人类阅读文档"进化为"机器可执行协议"，设计系统的规模化落地将获得新的技术杠杆。

早期信号

AI 超便携电子纸：手机背面的"注意力入口"

阅星曈开创"超便携电子纸"品类，产品磁吸在手机背面，重量仅 70 克、4.3 寸屏幕、售价不到 300 元。在零推广费用前提下，依靠小红书社区"云股东"共创众筹，一年内完成从产品定义到规模化验证的闭环。

这一产品形态暗示了一个值得关注的 UX 趋势：在智能手机性能过剩、AI 功能同质化内卷的背景下，用户注意力被无限拆解，而"做减法"的极简硬件反而创造了新的专注场景。创始人直言"是用户和我们一起，把这块小屏打磨成了今天的样子"——共创式设计在硬件领域同样有效。

交互式麻将教程：游戏化教育设计的标杆

一个面向外国用户的交互式麻将教程网站（themahjong.guide）因其出色的设计配色、合理的教程安排和简洁的交互性获得广泛好评。整个教程通过几个大块就说明了核心玩法，并融入了简单的交互元素。

早期信号

Cursor 3 原生抗锯齿：细节体验的复利效应

代码编辑器 Cursor 3 引入原生 macOS 字体抗锯齿功能，开发者反馈"small things like this really makes a big difference. very delightful"。这一看似微小的改进在用户端产生了显著的愉悦感。
