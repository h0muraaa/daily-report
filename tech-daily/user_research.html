◆ 产品体验点评
Codex Computer Use：当 AI 通过"辅助功能"操作你的 GUI
📦 meng shao 📅 2026-05-02

OpenAI Codex App 的 Computer Use 功能通过 macOS 的"屏幕录制 + 辅助功能"两项系统权限，让 AI 能够直接"看屏幕、动鼠标键盘"，操作 macOS 上的图形界面应用。适用场景包括：测试 macOS/iOS 模拟器流程、浏览器操作任务、复现 GUI 特有的 bug、修改必须点 UI 才能改的设置、查看没有插件接入的应用数据等。

从 UX 视角看，这是一个值得深思的交互范式转移。Computer Use 本质上是将"辅助功能"（原本为视障/运动障碍用户设计的技术）重新定位为 AI 与图形界面交互的通用桥梁。这带来两个设计洞察：一是无障碍技术的通用价值正在被重新发现——为边缘用户设计的解决方案，往往也能为 AI 这样的"新用户"提供最佳交互路径；二是它揭示了一个长期被忽视的 UX 问题：大量应用的功能仍然被困在 GUI 里，缺乏结构化的 API 接口，AI 不得不"像人一样"点点画画才能完成任务。

权限模型也值得产品设计师关注：Computer Use 存在两层独立权限——macOS 系统层（Screen Recording + Accessibility）决定 AI 能否感知和操作 GUI，Codex 内部层则控制 agent 的行为边界。这种分层权限设计为后续 AI 代理产品的安全与信任框架提供了参考。

📦 Browser Use 📅 2026-05-02

EverMind 长期记忆：AI 个性化体验的底层基础设施
📦 硅星人Pro 📅 2026-05-02

EverMind（盛大集团孵化）定位为所有 AI Agent 的通用"记忆层"（Memory Layer），核心产品 EverOS 是一套开源长期记忆系统。与大多数仅做向量数据库"存起来等人检索"的方案不同，EverMind 让 AI 能像人一样对记忆进行整理、更新，甚至从过去经验中学习和进化。团队在多项记忆评测上 4 个月达到 SOTA。

从用户研究视角看，长期记忆技术是 AI 个性化的底层基础设施。当前大多数 AI 产品的"个性化"停留在会话级别的上下文记忆，用户每次新开对话都要重新建立关系。EverMind 所解决的"infra 层面的记忆缺失"，正是限制 AI 走向真正个性化的最大瓶颈。对用户研究员而言，这意味着两个机会：一是当 AI 具备长期记忆后，用户与 AI 的"关系"将发生质的变化——从"每次重置的陌生人"变成"了解你历史的伙伴"，这种关系演进需要全新的用户研究框架；二是记忆层的设计本身需要用户输入——什么样的记忆应该保留、如何组织、用户如何查看和控制自己的记忆，这些都是尚未被充分探索的 UX 议题。
