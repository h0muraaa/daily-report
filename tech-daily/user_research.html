01「确认疲劳」实锤：93% 的权限请求被用户无条件批准

Anthropic 披露了一个对交互设计极具警示意义的数据：Claude Code 最初采用逐项授权机制——每次写入文件、执行命令或访问网络都弹出确认框，但实际数据显示用户最终批准了约 93% 的权限请求，让「靠人工确认」的安全价值大打折扣。这正是用户体验里经典的 alert fatigue：当弹窗多到一定程度，人会条件反射式地点击「允许」，人审环节名存实亡。

Anthropic 的解法是把安全边界从「每次都问人」改为「用运行环境限制 Agent 能做什么」——为 Claude Code 引入操作系统级沙箱（macOS 用 Seatbelt，Linux 用 bubblewrap）。对所有设计 AI 产品权限/审批交互的团队，这是一堂必修课：确认点要省着用，真正定义行为边界的应该是环境本身，而不是一个被点到失灵的人工按钮。

来源: AI前线

02「1000 个深度用户胜过 10 万泛用户」：AI 时代的用户哲学

深思圈记录了一场关于「AI 时代最底层问题」的对谈（高利明 × Creekstone 创始合伙人李一豪），几个判断与用户研究直接相关：模型是有缺陷的天才、1000 个深度用户胜过 10 万泛用户、死去活来才是这个时代最大的红利。尤其「1000 个深度用户胜过 10 万泛用户」指向一个正在回归的产品观——早期产品该追求的不是下载量级，而是愿意反复使用、深度反馈的核心用户群。

这与「深度定性研究取代大样本问卷」的思路高度同构：当获取用户变得便宜，稀缺的反而成了「真实、深度、有上下文的关系」。对用户研究团队来说，这提示研究预算的重心应从「广度覆盖」向「深度陪伴」迁移——找到能陪你迭代到「死去活来」的那批核心用户，比触达十万个路过的人更有长期价值。

来源: 深思圈

03日均观看 80 分钟：美国直播电商霸主 Whatnot 的用户粘性密码

美国直播电商平台 Whatnot 刚完成 5.45 亿美元 G 轮融资，估值 200 亿美元，已占据欧美直播电商约 60% 份额。对用户研究最值得关注的是行为指标：平台用户日均观看时长超过 80 分钟——在「美国做不了直播电商」的普遍结论下，这组数据说明它的体验设计绕开了中国路径的陷阱。

与国内 4.5 万亿直播电商 GMV 的「全网流量转化」逻辑不同，Whatnot 从收藏品（宝可梦卡牌、球鞋）交易切入，走的是「兴趣人群深度运营」——先聚集一群高兴趣、强社交的藏家，再用稀缺品拍卖把停留时长拉起来。同一个商业模式在不同市场长出了完全不同的用户体验形态，这对研究「直播电商的本地化体验设计」是极佳对照样本。

来源: 极客公园

04当 AI 把原型画完，产品经理的工作才刚开始

一位产品实践者最近 3 个月几乎不再用墨刀/摹客/Axure，全部改用 AI 生成 HTML 原型，几分钟就能得到列表页、详情页和交互流程，「至少像个产品」。但他的核心洞察很冷静：AI 最擅长生成「符合常识的答案」，而一个产品方案是否成立，靠的不是常识，而是对具体业务、具体用户和具体取舍的判断——「页面越完整，我越要仔细 review」。

他提出三层原型评审思路：先问「这是不是用户真正的问题」（用户在什么场景来、现在怎么处理、替他省掉哪一步），再走一遍功能交互流程，最后看边界状态（记录错了怎么改、提交后状态如何变化）。AI 让「先出一版看看」变得几乎零成本，业务决策与用户判断反而成为产品人的核心价值——这是「AI 提速 ≠ AI 决策」的绝佳案例。

来源: 人人都是产品经理

05创作越来越离不开人：模型越强，要控制的细节越多

Orange AI 在测试 Seedance 2.5 和 LibTV 后得出一个反直觉的结论：虽然 Agent 能帮上不少忙，但创作这件事反而越来越离不开人——只要创作出来的内容还是给人看，创作结果就需要人来把关。原因是模型越强，创作过程中要控制的细节就越多，纯靠文字生成视频并不行，「优秀的产品、设计和工程都是模型能力的放大镜」。

这对体验设计的启发是：AI 生成能力的瓶颈不在模型本身，而在「人能否控制细节」。当生成结果可解释、可干预、可微调的「控制力（controllability）」成为创作类产品的核心竞争力，设计上要回答的问题就从「怎么生成」变成「怎么让人把得住方向」——工具感、调参感和评审界面，都是未来体验研究的富矿。

来源: Orange AI(@oran_ge)

01网页回归「人的手感」：手写可视化与纸张涂鸦美学

最近 Claude 的手写可视化在 X 上爆火，但设计观察者 Xian 看到的是更本质的信号：网页终于不再只是规整的卡片和模板，而是重新有了纸张、涂鸦、翻页、拖拽和「人的手感」。他整理了 5 个同方向、真正可以玩的交互作品（如 ponpon-mania.com/chapters），这些作品把手写笔触、纸张质感与拖拽翻页直接做进了界面。

对设计趋势研究而言，这是对过去十年「卡片化、模板化」UI 的一次集体反叛。当 AI 可以批量生成标准界面，「有手感、有笔触、有不确定性」的界面反而成为差异化来源——手写/手绘美学正在成为对抗「AI 平均值」的视觉语言。它提醒研究团队：设计的稀缺资源正从「规整」转向「有温度的不完美」。

设计洞察
当生成式工具让「标准界面」变得廉价，「不标准、有人的痕迹」重新成为稀缺体验。评估 AI 设计工具时，除了生成质量，还要看它能否保留手绘、涂鸦、非对称这类「反模板」的审美能力。

02Flova 的「完全小白化」：AI 视频创作的门槛革命

Seedance 2.5 发布后，一个字节系创业者做的视频 Agent 产品 Flova 把创作门槛又降了一层。它的两个设计选择非常值得研究：一是在模型之上做了一层 Harness，同一个提示词用 Flova 出的短片明显好于模型直出（推测它进一步优化了提示词与工作流）；二是完全小白化——用户直接用自然语言甚至语音输入表达想法，不需要复杂的提示词工程。

文章还点出一个深层差异：视频生产流程比 Coding 复杂得多。代码是结构化语言、结果可验证，而视频包含故事、人物、场景、镜头语言与节奏，很多时候没有明确标准答案、无法直接验证。正因为如此，视频 Agent 的设计难度天然更高——它必须把「审美判断」和「作品架构」拆解成可引导的体验，这是 AI 创作类产品体验设计的前沿命题。

01Cloudflare Precursor：从「一次性挑战」到「持续行为分析」

Cloudflare 推出 Precursor——一个客户端行为分析引擎，通过持续评估会话交互（如鼠标移动轨迹、键盘敲击时序）来检测高级机器人、爬虫与 AI 代理，而不再依赖一次性挑战（如 CAPTCHA）。它的思路是把「身份判断」从单点验证变成连续的行为信号积累。

对用户研究的方法论启发在于：行为特征正在成为比「用户自报」更可靠的信号。同样的技术思路完全可以反向用于真实用户画像——通过鼠标轨迹、停留时长、输入节奏识别用户意图与熟练度，得到的是比问卷更真实的行为数据。这提示研究团队把「行为侧写」纳入方法工具箱，也提醒注意其边界：连续行为采集同样会带来对「被持续注视」的隐私与信任问题。

来源: InfoQ

02微软 Skill Recorder：演示式学习与「边操作边讲解」的研究哲学

微软开源了桌面端工具 Skill Recorder，思路是「演示一次，AI 学会」：记录一次真实的电脑操作（屏幕、应用切换、访问页面、可选语音讲解），分析后生成两种产物——按需调用的 SKILL.md，或按时间/条件触发的多步骤 Automation。作者点出的底层洞察是：写 Skill 本质上是在把一套熟练的工作流程「翻译」给 AI。

更值得注意的是它的方法论选择：相比文字描述，「手把手演示 + 讲解」被证明是最高效的教学方式。这与可用性测试的理念完全同构——与其让用户填问卷描述「你怎么用」，不如让用户在真实任务里边操作边说出思考过程（think aloud）。当 AI 要「学会」人类工作流时，人类最自然的教学方式，恰好也是研究者获取洞察的方式。
