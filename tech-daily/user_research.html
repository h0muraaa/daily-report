🔮设计趋势洞察

趋势一：从 UX 到 AX，界面设计要为"智能体用户"预留接口

Cloudflare CEO Matthew Prince 的判断正在成为共识：未来互联网的主要使用者可能不再是人，而是 Agent。前端早读课的文章进一步把这一趋势提炼为 Agent Experience（AX）——一种新的设计理念。

对 UX 团队的具体启示包括：第一，产品的信息架构需要考虑"机器可读性"，文档、Schema、错误提示都要能被 Agent 解析；第二，权限与鉴权流程要从"人类一次性登录"转向"Agent 最小权限 + 动态授权 + 可追溯审计"；第三，反馈界面要同时服务两类用户：给 Agent 的结构化状态，以及给人类的置信度与行动摘要。

这不是要取代 UX，而是把 UX 的边界从"人机界面"扩展到"机机协作 + 人机确认"的混合系统。未来产品团队可能需要新增"Agent 用例"（Agent Persona）和用户故事并列。

[来源: 前端早读课]

趋势二：AI 生成式 UI 正在压缩"设计 → 原型 → 开发"的切换成本

Skywork 推出的 Skywork Design 让画布上生成的 UI 可以直接变成可点击原型，无需跳转到其他工具。Lovable 则支持用 @ 引用现有项目中的设计系统、UX 流程、组件和资产。Google 也在推进 A2UI v0.9，试图建立跨平台、框架无关的生成式 UI 标准，让 AI Agent 能够声明界面意图并与现有设计系统对齐。

这些信号指向同一个方向：设计工具正在被"意图驱动"的工作流重新定义。设计师的角色可能从"画界面"转向"定义设计系统、约束规则与体验质量阈值"。用户研究员则需要更早介入：当界面由模型生成时，可用性测试、品牌一致性和无障碍合规如何嵌入生成流程，而不是等到发布后才补测。

📱产品体验点评

案例一：AEKE 力量镜 —— 用场景重定位盘活"已死赛道"

健身镜品类曾被认为已经"判死刑"，但深圳团队趣动未来通过融合健身镜与力量训练设备，推出 AEKE K1 和 S1 Pro，在 Kickstarter 上累计筹集超过 700 万美元。其体验策略值得拆解：首先，它没有继续讲"健身镜"的故事，而是把产品重新定位为"力量镜"，锚定海外用户更关注的力量训练需求；其次，用高帧率 AI 摄像头实时捕捉骨骼点，解决力量训练中动作纠正的痛点，用户评价认为体验优于传统传感器方案；最后，从 K1 的女性友好、家庭友好定位，到 S1 Pro 的更高客单价升级，体现出对产品分层和人群细分的持续打磨。

用户研究启示：当一个品类整体低迷时，往往不是"用户不需要"，而是现有产品的价值主张和核心场景没有切中真实痛点。通过使用场景重定位 + 关键技术体验升级，可以重新定义品类边界。

案例二：Rose Diary —— 小体量 App 的需求验证与审美差异化

一位产品经理独立开发的日记 App Rose Diary，目前 434 次下载、10 多位付费用户、18 元定价。作者复盘指出，日记 App 市场看似饱和，但"觉察日记"实体书的畅销和竞品普遍"不够好看"的现状，让他确认了需求存在，并决定用审美差异化切入。产品通过结构化复盘模板降低用户的"写日记"启动成本。

这个案例对 UX 和用研的启发在于：第一，需求验证可以通过跨品类信号（实体书销量）间接完成，而不一定需要从零开始的大规模调研；第二，在红海品类中，审美和情绪价值可以成为核心差异点；第三，早期数据不好看时，结构化复盘模板和轻量付费设计能够帮助快速学习，而不是盲目扩大投放。

🧪研究方法论

方法：把"Agent 使用日志"当作新的定性数据源

Every 团队对 Codex 的深度实践展示了一个值得用户研究借鉴的思路：五位背景不同的成员形成了五种差异化 workflow。非技术成员 Natalia 用 Codex 夜间自动 enrich 数百条 CRM 客户记录；Dan 用长线程和路由线程处理邮件与招聘；Katie 则通过"让模型采访自己"来重建更适合 Agent 的文件系统。

这些 workflow 不是设计出来的，而是在使用过程中生长出来的。研究者可以借鉴以下步骤：

1
采集 Agent 会话日志：不只是看最终输出，更要看用户如何修改 Prompt、何时接管、何时放弃。
2
识别"模式化中断"：当用户反复把任务拆成多步、反复复制粘贴上下文，说明当前界面存在 friction。
3
构建 Agent 用户画像：不同角色（非技术构建者、工程师、运营）使用同一 Agent 的方式差异巨大，需要分别建模。
4
设计"控制感"量表：在自动化与人工干预之间找到用户最舒适的边界，并把它变成可测试的设计原则。
