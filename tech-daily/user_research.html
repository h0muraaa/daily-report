人机交互 / 具身交互

荣耀 Robot Phone：AI 第一次"长出身体"，主动替用户构图

荣耀正式发布全球首款机器人手机 Robot Phone，售价 9999 元起，搭载行业最小的全钛云台架构，四自由度云台可主动跟拍。这不再是单纯的"相机参数"升级，而是一次交互范式的变化：AI 开始控制物理硬件去参与取景、构图这些过去完全属于人的创作判断，用户从"操作工具"变成"与设备协作"。对用户研究员而言，这带来一个值得长期跟踪的研究问题——当系统拥有物理主动性，用户愿意在什么时候把"拍什么、怎么拍"交给设备，又在什么时候想自己说了算？信任、控制权与让渡的边界，正在成为具身交互体验设计的新核心。

📎 来源：量子位 · 爱范儿

会议体验 / Agent 上下文

腾讯会议首页罕见的"录音笔"：把会议里的"原因"变成可搜索的 Context

腾讯会议首页四宫格多年不变，这次却罕见地给"录音笔"留了位置，功能完全免费。这个产品动作背后是一个被 Agent 放大的用户痛点：文档记录的是结论，会议记录的是原因——但过去这些"原因"只存在于参会者的记忆里。当 Agent 要端到端完成任务，它却从未参加过你的会议，你只能把背景一遍遍重新讲给它听。把日常沟通沉淀成一份可搜索的 Memory，让 Agent 也能"参与过讨论"，正在成为会议类产品下一个价值高地，也解释了为什么 Granola、Notion 等公司都在做 AI 会议笔记。

📎 来源：AI产品阿颖

群组协作 / 注意力管理

微软谈群聊里的 Agent：对一个人有帮助的回复，可能打断另外五个人

微软官方博客系统讨论了"Building Agents for Teams"的核心难题：一对一的人与 Agent 对话规则简单，但群组协作里每条消息都在争夺注意力，对某个人有用的回复可能打扰其余五个人。文章指出，有效协作建立在无数细小的社会判断上——何时回应、何时保持安静、说多少合适、用什么体例。这个判断对用户研究团队非常关键：人机群组交互的评测不能只看任务完成度，还要衡量 Agent 是否"懂分寸"；如何把社会礼仪编码进 Agent 行为，将是一个全新的、几乎没有先例的研究方向。

📎 来源：Microsoft for Developers

设计审美 / 微交互

谷歌"庆祝打勾"的微交互 vs 网友吐槽：打磨细节和整体审美，用户先感知哪一个？

Google Design 分享了目标追踪样例 App "Achieve" 的设计：用品牌色圆环扩散淡出的自定义完成动画替代标准 Material ripple，并搭配按压渐变，让"勾掉一个待办"这件事有庆祝感。但这条内容被设计师 Viking 转发吐槽，直言"这大圆角加字体太丑了，AI Slop 看起来都顺眼一百倍"，评论区也成了"高级吐槽大会"。这场争论的启发在于：设计系统把大量精力投入微交互的"精确感"，但用户的第一感知往往是整体视觉调性——细节打磨与整体审美之间的落差，值得每个设计团队自省。

📎 来源：Viking(@vikingmute)

产品哲学 / 克制设计

阅星曈完成近 5000 万融资：AI 硬件都在做加法，它靠一块"减法屏"跑出来

超便携电子纸品牌阅星曈完成近 5000 万元 A 轮追加融资，顺为、经纬、博裕、小红书四家老股东跟投。当 AI 硬件普遍在加麦克风、摄像头和更大的模型，阅星曈的产品却是一块没有应用商店、没有短视频、没有信息流的磁吸电子纸，只让用户在地铁上、排队时、睡前读几页书。更值得注意的是它下一步的设计取舍：公司正测试"云端 + 手机 App + 电子纸"的三端架构，设想让 AI 成为信息抵达屏幕前的一层处理。做减法获得用户之后，怎么在"克制"与"增长"之间做加法，是这个品牌真正值得观察的课题。

📎 来源：白鲸出海（极客公园）

产品进化

从"工具"到"同事"：AI 时代的产品，正在为"人 + AI"双用户重新设计

InfoQ 报道了 QCon 上一场颇具仪式感的演讲：苏杰让 AI 数字分身替自己完成演讲主体、自己只负责翻页（两个月后翻页也自动化了），以此演示"AI 正在折叠时间"。他判断将来产品、技术、设计、运营都会统一成全栈 builder，而"我们的新同事就是 AI"。这个趋势在产品侧已有落点：WorkBuddy 资料库让 HTML、智能 Markdown 这类"AI 原生格式"具备数据存储与多端同步，变成"多人多 Agent 文档"；Claude 在 Chrome 的会话也跨端延续到桌面与移动端。设计含义是清晰的——信息架构要开始面向"人 + AI"的双用户，Agent 能否接得住上一个环节的产出、人类能否看懂 Agent 留下的中间态，会成为比"界面好不好看"更优先的体验问题。

📎 来源：InfoQ · 爱范儿 · Claude(@claudeai)

AI 控制权

"思考强度"成为产品参数：AI 能力的可调化，把选择权交还给用户

DeepSeek V4 Pro 正式版把思考模式分为 low / high / max 三档，官方明确建议"简单任务用 low，日常 Agent 任务用 high，复杂任务用 max"；几乎同时发布的 DeepSeek Harness 也提供 Off / High / Max 三档推理等级。这是把"该让 AI 想多深"这个过去由模型内部决定的选择，显式交到用户手里。对产品设计的意义在于：AI 能力"可调化"正在成为新范式——用户要能按任务复杂度与成本预期，调整 AI 的投入程度。这既是功能设计，也是成本透明度设计：当"思考档位"对应着不同消耗，用户对 AI 的付出与回报就有了可感知的标尺。

📎 来源：DeepSeek · 爱范儿

跨端一致性

WorkBuddy 上线远程控制：国内终于有了"随时随地让 Agent 干活"的丝滑体验

数字生命卡兹克把 WorkBuddy 本次更新称为"刚需中的刚需"：PC、App 和小程序打通，打开手机端，电脑端原有的任务、对话、工作空间和产物实时同步，远程控制体验因国内直连甚至比 Codex 还丝滑。更早之前，WorkBuddy 联合 Peet's、COSTA 等五家咖啡品牌发起"工作交给 WorkBuddy，时间和咖啡留给自己"的活动，把"把重复劳动从人的工作时间中剥离"做成了可感知的品牌体验。从用户研究看，跨端同步的"低摩擦"与随时可委派的"掌控感"，是 Agent 产品体验的两个关键指标——用户要的不只是能干活，而是"无论我在哪，活儿都能继续"的确定性。

📎 来源：数字生命卡兹克 · 十字路口Crossing

定价与信任

豆包开始"两头收费"：AI 对话入口的商业化，用户信任怎么守？

豆包被列为抖音特定成交渠道，通过豆包入口跳转成交的酒店订单开始按独立费率结算（住宿综合费率约 12%），被视为国内首个 AI 对话入口对商家交易明码计费的案例。商业上这是平台必经之路，但用户真正担心的是"推荐客观性"：当 AI 导购背后有商家付费，用户还能信任它的建议吗？对产品设计师而言，这是 AI 商业化时代最棘手的信任设计问题——推荐利益如何披露、AI 身份如何标注、以及"中立感"如何被用户感知，都会直接影响用户对 AI 助手的基本信任。这个案例值得作为"商业变现 × 体验信任"的长期观测样本。

📎 来源：人人都是产品经理（AIX财经）

众包用户建模

腾讯 600 万悬赏背后的"用户理解难题"：两套画像系统为何融不到一起

腾讯在数据挖掘顶会 KDD 上悬赏超 600 万元，求解广告精准推送里的一个老大难：理解用户需要两套判定——一套"管用户此刻想要什么"（基于行为序列），一套"管用户是什么样的人"（标签画像），两套体系各自发展了十多年、数据结构完全不同、一直各跑各的，内部多年没找到满意的融合方案。最终 52 个国家和地区近 1.4 万人参赛，学术赛道冠军独摘超 200 万，创国内企业技术竞赛单项奖金纪录，工业赛道冠军甚至是用 DeepSeek 网页版生成的。对用户研究的启示很直接：当"用户理解"复杂到内部团队无解，把问题开放给社区、用众包竞赛逼近答案，正成为一条值得关注的研究路径。

📎 来源：赛博禅心

大规模职业洞察

扫描 7.43 亿条招聘数据：AI 时代职业的四种命运

上海科技大学的研究扫描了智联招聘全部 7.43 亿条招聘数据，是目前对"AI 与中国职业市场"最大规模的调研。结论很有层次：好消息是职业没有大面积缩减，坏消息是职业正在被重新定义。三类缩影——客服（被 AI 替代后，剩下的人每天处理"被 AI 惹恼的用户"的烂活儿）、工程师（底部 AI 化、顶部精英化，资深工程师收入反而更高）、翻译（内涵从"翻语言"变成"跨文化商务整合"）。这种用全量生态数据刻画群体处境、而非靠问卷抽样的做法，正是大规模用户研究的方法论范本，也提示研究者：AI 对用户的影响从来不是均匀的，"被替代 / 只剩烂活儿 / 顶部提升 / 横向整合"需要被分开观察。

📎 来源：古典古少侠

学习体验研究

DeepTutor：34K Star 的"Agent 学习操作系统"，把学习行为装进统一工作台

山行AI 深度拆解了开源项目 DeepTutor（34K+ Star，Apache-2.0，本地优先）：它把聊天、研究、解题、测验、写作、知识库、外部 Agent 与三层长期记忆放进同一个本地工作台，让一次学习任务能继续变成笔记、报告、题库，甚至一本可交互的书。它给自己的定位是"终身个性化辅导系统"。对用户研究的意义在于其产品假设：学习不是一次性问答，而是需要记忆、可积累、能跨任务延续的过程——把"学习旅程"当作用户体验对象来设计，比单点功能更接近真实用户行为，这是 AI 教育产品值得借鉴的框架。

📎 来源：山行AI

语音体验研究

dots.tts 开源：当"情绪、韵律、停顿"变成可编辑的参数，语音 UX 进入可设计时代

小红书 dots 团队开源 dots.tts——一个 20 亿参数、全连续、端到端的自回归语音合成模型，零样本克隆在 Seed-TTS-Eval 三个子集上取得最佳平均内容准确度与说话人相似度，并配套 dots.tts.edit 支持文本、情绪、韵律、停顿的编辑，1T1A 双流模式让文本流与语音流交错推进，交互场景下首包延迟低至 54 毫秒。对语音交互研究的意义在于：当"情绪、韵律、停顿"成为可编辑、可测试的参数，语音助手的性格与情感表达就进入了可设计、可度量的范畴——语音 UX 有望从"能不能说对"走向"说得像不像一个有性格的人"。

📎 来源：小红书技术REDtech

Pixel 11 的 HiLight 彩色 LED：让"AI 正在想"看得见

Pixel 11 Pro 系列加入 HiLight 彩色 LED 灯，通过不同灯效显示 Gemini 正在聆听、思考或回答。把 AI 的"思考状态"变成可感知的光，是降低 AI 交互不确定性的巧妙设计。

设计 Skill 生态

博主开始系统性整理"审美照片 Skill"：设计能力被封装成可复用模块

Orange AI 整理了一批审美出众的照片 Skill，如 photo-abstract-editorial（从照片提炼构图节奏与色彩关系）、heytea-style（喜茶风格海报）、photo-revival（把废片重画成诗性手绘插画）。当"审美"被沉淀为 Skill，设计能力的可复制性正在改变创作门槛。

📎 来源：Orange AI(@oran_ge)
