🌊设计趋势洞察：Agent 从"被动应答"走向"主动在场"

Vida：一款"在你问之前就已经干完"的主动型 Agent

传统 Agent 的交互范式是"用户给上下文 → 用户下指令 → Agent 执行"。Vida 试图把这个顺序反过来：通过持续读取屏幕、记录用户在电脑上的行为轨迹，它能够在用户开口之前就理解任务背景并主动产出结果。实测中，用户可以用一句极简的指令让 Vida 完成日报整理、进度同步、消息回复等原本需要大量背景说明的工作。

用户研究视角：这种"全程可见"的设计极大降低了用户启动任务时的认知负担，但也把隐私、透明度和控制感推到了体验设计的第一线。用户需要清楚地知道：Agent 看到了什么、记住了什么、什么情况下会主动行动，以及如何随时撤销它的权限。未来的 UX 关键可能不是"让 Agent 更聪明"，而是"让用户对 Agent 的聪明程度有可控的感知"。

Claude Tag：把 AI 变成 Slack 里的"同事"

Anthropic 推出的 Claude Tag 让企业用户可以直接在 Slack 频道里 @Claude 分配任务，Claude 在后台拆解、执行，并在线程中返回结果。Andrej Karpathy 将其视为 LLM 交互的第三次重大重设计：从网页聊天，到桌面 App，再到"嵌入团队工作流的持久存在实体"。

用户研究视角：当 AI 从工具变成"团队成员"时，交互设计的参照系不再是软件功能，而是人际协作规范。用户会自然地用对待同事的期待来要求它：回复是否及时、是否理解上下文、是否越权、犯错后如何补救。Claude Tag 的 Beta 形态虽然简单，但它开启了一个重要研究方向：如何用既有的协作语言（@、线程、频道权限）降低用户学习成本，同时明确人与 Agent 的权责边界。

🎨产品体验点评：创作工具、折叠屏与睡眠硬件的 UX 信号

Agnes Pavo：面向非代码创作者的 AI 工作台

Agnes AI 在免费开放全模态 API 后，又推出了 PC 端创作平台 Pavo，覆盖剧情短片、Agent、图片生成、视频生成四大模块。其核心卖点是"智能路由"：根据视频内容、镜头、风格自动匹配最合适的模型，让用户无需理解底层模型差异就能获得较好的生成效果。平台上线后，AI 短剧创作从"调 API"走向"开箱即用"。

用户研究视角：Pavo 的价值不在于单一模型能力，而在于它缓解了 AI 创作中典型的"平台割裂"痛点——图片在 A 工具、视频在 B 工具、剪辑在 C 工具。对于设计师、短剧导演和新媒体运营者来说，工作流的连续性比单点生成质量更重要。UX 上值得关注的点是：智能路由的决策是否可解释？用户是否能在自动推荐和手动选择之间自由切换？这些将决定工具是"省心"还是"失控"。

DUSQ 睡眠贴片：从"数据报告"到"直接干预"

睡眠硬件 DUSQ 在 Kickstarter 上线首日筹得 70 万美元，最终突破百万美元。与常见的睡眠耳机、助眠灯不同，它采用耳后贴片形态，通过监测皮电反应（EDA）、心率、HRV 等数据，直接刺激神经调节睡眠状态，而不是仅仅提供声音或灯光氛围。

用户研究视角：这款产品的热度揭示了一个被长期忽视的用户痛点：睡眠类硬件多年来把重点放在"记录与报告"上，但用户真正需要的是"解决问题"。DUSQ 的激进之处在于它把产品价值从"让你知道睡得不好"转变为"主动帮你睡好"。对于 UX 人来说，这是一个关于"数据疲劳"的提醒：当用户已经看了足够多的报告，下一步的设计重心应该放在可感知的干预效果、使用安全感和长期依从性上。

🧪研究方法论：多模态交互、信任与团队角色

Voice-In, Visuals-Out：被视为 AI UX 峰值的交互形态

Forestwalk Labs 联合创始人 Allen Pike 在 AI Engineer 大会上分享了"语音输入、视觉输出"的产品实践。他认为，最新模型已经让这种交互形态成为可能，但要真正让用户感到愉悦，关键不在技术可行性，而在低延迟、响应式反馈和恰当的视觉呈现。

用户研究视角：语音交互的失败案例往往不是因为识别不准，而是因为系统反馈的节奏和形式与人类对话直觉不匹配。当 AI 输出从文本扩展到图像、图表、界面时，设计师需要重新思考"对话回合"的定义：什么内容应该即时出现、什么需要等待、什么应该用视觉辅助降低认知负荷。建议关注真实场景下的用户测试：用户是否愿意在公共场合使用语音？他们对视觉输出有哪些预期？

OpenAI Codex 负责人：产品工作最贵的部分变成了"品味"

OpenAI Codex 产品负责人 Andrew Ambrosino 在 Lenny's Podcast 中表示，AI 让实现变得便宜后，产品流程被彻底倒置。过去是先研究、写文档、做原型再开发；现在内部可能同时有 90 个团队各自做出相同功能的原型，最难的是从中挑出"对的那个"。他把这种判断力称为"taste"，并认为它正在成为产品经理和设计师最核心的价值。

用户研究视角：这一观点重新定义了 UX 研究的角色。当原型成本趋近于零，研究的重点不再是"验证一个方案是否可行"，而是"在大量可行方案中识别出最符合用户心智模型和情境需求的那个"。这要求研究者更早介入创意阶段，通过快速情境调研、认知走查和用户隐喻分析，帮助团队建立筛选标准，而不是只在方案定型后做可用性测试。

Claude Code 创始人提出未来产品团队的五种角色原型

Boris Cherny 在 X 上发文，认为工程、产品、设计、数据科学等职能正在融合为五种按"产出方式"划分的新角色：Prototyper（原型师）、Builder（构建者）、Sweeper（打磨者）、Grower（增长者）、Maintainer（维护者）。他强调这些角色与岗位头衔无关，一个人可能同时跨越两到三种角色，而团队健康度取决于角色配比与产品阶段的匹配。

用户研究视角：这个框架对 UX 团队尤其有启发。传统上，设计师被定位为"产出设计方案"的角色；但在 AI 时代，设计师可能同时承担 Prototyper（用 AI 快速生成概念）、Sweeper（打磨 UI 与体验细节）和 Grower（基于反馈持续迭代）的职责。招聘和绩效评估可能需要从"岗位能力模型"转向"角色组合能力"，研究者也需具备与 AI 协作、快速验证假设的复合能力。
