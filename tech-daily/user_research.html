今日要点

  • "AI 贴牌"工具面临淘汰：通用功能正在被彻底取代

    近期的观察显示，仅增加一个 AI 对话框或者微小功能的“套壳”软件正面临危机。聊天、整理等通用功能正在迅速被原生大模型整合（如 ChatGPT 将加入办公场景等）。对于设计师和产品经理而言，这意味着必须挖掘只有基于自身专属数据壁垒才能提供的独特体验，而不能单纯依赖"交互式创新"或轻交互型的工具堆叠。

    来源：人人都是产品经理

  • AI 智能体接管营销与自动化，重塑专业工作流体验

    AI 不再只是充当副驾驶。在很多测试案例中，多名 AI Agent（如通过 Relay 和 OpenClaw 的组合）正在接管营销的全链路任务，实现 7x24 小时的追踪和自动优化。这一转变极大地影响了对营销人员工具体验的认知：从如何更好地手动"管理数据"，变为如何更好地向 AI"下达目标指令并监控过程"。

    来源：人人都是产品经理

  • 国内企业服务产品的全面 CLI 化浪潮来袭

    钉钉和飞书在同一天开放了 CLI 支持，企业微信也紧急增加了 CLI 支持。这种逆 GUI 的"复古"趋势，实则为了接入大模型生态，让 AI 能够极其便捷地执行多步自动化操作。这对原本极度依赖可视化表单填报的企业级 UX 设计带来了本质的冲击：GUI 的易用性不再是企业级产品的核心护城河，Agent 友好度和接口连通性更重要。

    来源：人人都是产品经理

  • Stitch 2.0：从自然语言到高保真原型的 "AI Vibe" 设计体验

    荣登 Product Hunt 榜首的 Stitch 2.0 代表了 AI 原生设计工具的新一阶段。它可以利用多代理架构和自然语言，几秒钟就能生成高保真的界面原型和流畅动效。这意味着交互设计师可以将更多精力用于"探索设计意图"与"定义风格"，而不是花费数小时绘制标准组件的间距与网格。

    来源：Z Potentials

  • AI 溶图与字体渲染的无缝衔接正在普及

    设计师分享了使用 AI 进行产品溶图和字体设计的完整流程。在平面设计、电商等场景，使用 AI 进行场景构建、渲染和融合的效果已足够自然。当设计工具的学习曲线从"熟练操作软件"转变为"如何撰写 Prompt 与审定美感"时，用户的设计心智正在发生根本性变革。

    来源：优设

  • AI 预测平台 Echo 展现出超越人脑决策的潜能

    能通过自主搜索和信息整理来预测公司市值或地缘政治变化的 AI 系统 EchoZ-1.0 横空出世。这种"让 AI 代替人类搜集和判断海量非结构化数据"的应用模式，极大提升了金融和决策从业者的用户体验。这反映出工具的核心价值点正向深层逻辑推理转移，而非简单的信息呈现。

    来源：赛博禅心

  • Physical Intelligence：将 AI 从数字世界拓展到物理互动体验

    专注于物理智能体的初创公司 Physical Intelligence 估值翻倍至 110 亿美元。它尝试构建能执行叠衣服、泡咖啡等日常操作的物理视觉-语言大模型。当用户的交互界面从"屏幕"扩展到真实的"物理空间环境"时，无缝、多模态的人机互动体验将成为全新的研究领域。

    来源：Z Potentials

  • AI 时代下的用户职业与工具杠杆体验

    随着自动化取代基础执行工作，用户对于工具体验的期待也发生了改变。用户不再寻找如何用工具"替代自己执行重复劳动"，而是期望工具能成为放大其决策与意图的"杠杆"。“AI 只能执行你的答案，无法替你定义目标”，这正是下一个时代赋能型产品交互设计的基石。

    来源：傅盛(@FuSheng_0306)

设计趋势洞察

两看相厌：Agent 与传统软件的架构和体验冲突

当 AI Agent 作为主流用户操作底层软件时，冲突随即产生。传统工程师认为 Agent 产生的流程或代码是"屎山"，而 Agent 在尝试调用专为人类设计的复杂 GUI 逻辑时也面临极大的阻力。企业级软件的体验评估对象，已经不可逆转地从"单一的人类使用者"转变为"人与 Agent 的混合使用者"。

UX 启示：产品的设计范式需要升级，既要提供给人直观的体验边界，也要向 Agent 提供结构清晰、易被解析的底层接口。

产品经理的“战略性偷懒”重塑效率逻辑

产品设计的流程和关注点正在迁移。通过大量使用 AI 助手，原本琐碎的竞品分析、文档梳理被机器承担，而真正的价值转移到了如何进行精准的战略判断和业务洞察。这一现象说明，未来的效率类产品设计，应该更加鼓励用户从繁琐的界面微操中解脱出来，提供更多的“宏观控制与审查”体验。

UX 启示：将精力从实现复杂的表单控件中转移出来，思考如何设计出更好的“目标确认与执行监控”界面。

原子级创新（Atoms not Bits）成为新一轮增长点

正如 YC Demo Day 展现的趋势，大量的新产品不仅仅在生成文本或图片（Bits），而是正在向执行物理世界操作或解决复杂的现实业务痛点（Atoms）方向延伸。设计这类产品不仅需要考虑屏幕上的信息排布，还要深刻理解屏幕外用户的物理环境感知及情感预期。

UX 启示：设计师的关注重点必须走出屏幕边框，深入研究服务触达真实物理世界时的用户心理和互动触点。

产品体验点评

🛠️

Stitch 2.0

设计 AI 工具

Google 推出的 Stitch 2.0 是目前“AI 辅助界面设计”方向的领跑者。与其前身不同，它不仅能根据提示生成粗糙线框图，而是能输出带完整细节、组件逻辑乃至微交互动效的高保真原型。

它通过自然语言对话式的界面，将原本繁复且需要系统性学习的 UI 软件操作门槛彻底降低，使产品经理或研究人员能迅速将脑海中的想法通过多轮对话具象为可交互的产品 demo。

体验亮点

  • 降低表达原型的技术门槛，非专业 UI 也能制作高保真输出
  • 多模态支持：可以直接通过语音描绘界面意图
  • 强化了多代理系统对组件风格一致性的把控
🤖

企业微信 & 飞书 CLI

企业协作与效率

传统的企服巨头集体走向 CLI 化，标志着“人机交互”向“机器协同人交互”体验跨越。通过暴露出高度标准化和可用性极强的命令行接口与 MCP (Model Context Protocol)，用户只需通过自己喜欢的 AI 聊天助手，就能横跨多个复杂的国内协作工具（打卡、建群、查文档）。

这种抛弃繁杂层级菜单、转为直接下发指令的模式，是针对重度企服工具用户真正的痛点解决之道。它赋予了每个打工人开发“自己专属企业助手”的超能力。

体验亮点

  • 从复杂树状导航菜单回归到“意图驱动的指令式交互”
  • 极大提高了外部智能体无缝对接并控制这些平台的流畅度
  • 打破了不同 App 间的体验孤岛
📈

Helena 自主营销 Agent

商业数据助手

Helena 展示了自动化商业系统应该具备的流畅体验。不同于早期的营销工具仍然需要人工配置各种活动参数和盯盘数据，Helena 从跨平台数据监测到趋势分析、再到生成 UGC 和网站更新，实现闭环执行。

它代表了“雇佣式软件（Software as an Employee）”的用户体验雏形。作为用户，你不再是在操作一个软件面板，而更像是在和一个不知疲倦、数据敏锐的“全能员工”进行绩效验收和宏观复盘。

体验亮点

  • 把“数据报告阅读”变成了“行动策略批准”
  • 7x24小时自我闭环，极大缓解了用户的精神负载（Mental Load）
  • 多渠道整合体验：融合了内容生成和渠道投放全链路

研究方法论

面对智能涌现，寻找“无可替代”的特异性知识点

在讨论 AI 的理解局限时，有研究人员提出了"Agent 的秋裤困境"：即一些具有极高个人特异性、不常存在于公开数据集且难以被常识逻辑直接推导出的行为（如“今天我需不需要穿秋裤”），往往是 AI 的盲区。在进行用户洞察时，研究人员应敏锐地捕捉这种“个体经验与场景交织”的非显性需求，这是 AI 仅通过通用语料难以洞察的关键体验触点。

基于 Agent 的自动化工作流梳理

在企业服务产品的设计上，传统 UX 设计流程通常是针对用户的角色拆解屏幕触点；而现在我们需要引入全新的方法论——即“智能体视角的触点拆解”。不仅要思考信息流在界面上的流转，更需要梳理系统在开放 API 时能否流畅、精准无误地让第三方 AI Agent 解析到界面的语义（如飞书 CLI 对于干预式执行的评分体系）。

UX 雷达

新动向

CLI 体验在企业软件中的全面复苏

原本已被束之高阁的 CLI 和纯命令式操作，借着大语言模型作为中间人的角色，再次成为企服产品必做的基础体验建设。

早期信号

AI 代行真实世界的物理探索

机器人软件与环境感知大模型的进化，正在把用户体验设计的前沿从二维平面拓宽到物理空间的实际互动操作上（例如 AI 对家居场景的物理交互感知）。

值得关注

面向机器（Machine-facing）的设计规范

传统软件开发与 Agent 调用的冲突加剧，未来或许会诞生类似专门指导“如何让界面背后逻辑对智能体更友好易用”的全新设计规范与架构标准。

趋势加强

雇佣制软件的用户心态

用户购买软件将越来越接近“雇佣一个外包团队”。界面设计的核心将从工具配置面板逐步收敛至“仪表盘”、“审批流”与“任务进度汇报”界面。
