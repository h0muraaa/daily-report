AI设计工具

Claude Design 开放额度共享，AI设计工具进入日常化阶段

Claude Design 已与 Claude AI 网站及 Claude Code 共享额度，降低了使用门槛。实际使用中，Claude Design 的产品设计能力和 UI 设计能力已获得广泛认可。一个重要技巧是：导入成熟的设计系统（如 Adobe Spectrum 2）后再进行设计，风格一致性会显著提升，输出结果也更显专业。

此外，Opus 4.8 在 UI 设计和实现方面相比 GPT-5.5 有明显优势。用户反馈表明，不同模型在不同场景下各有擅长之处——写作、UI设计、系统规划各有所长，组合使用才是最佳策略。

UX洞察：当AI设计工具进入"可复用设计系统"阶段，设计师的核心价值正在从"执行视觉产出"转向"定义和打磨设计系统"。这要求设计师更深入地理解品牌一致性、组件规范和跨平台适配规则。

系统界面设计

iOS 27 液态玻璃界面回调：美观与可读性的设计博弈

苹果在 iOS 27 和 iPadOS 27 中将对"液态玻璃"设计语言进行重要调整。iOS 26 的液态玻璃界面并非苹果内部预期的"完全体"，下一个版本将做出更多调整，试图兼顾透明度和可读性。界面逻辑和布局也将重新回调应用底栏，整体逻辑回到 iOS 18 风格，取消独立的搜索按钮和其他变形标签。

这一调整揭示了一个经典的设计张力：视觉创新（液态玻璃的通透感和未来感）与可用性（文字和控件的可读性、操作的确定性）之间的平衡。苹果在经历一代用户的实际反馈后选择回调，说明过度追求视觉 novelty 可能损害核心体验。

UX洞察：设计语言的大胆创新需要给用户足够的适应周期和反馈通道。iOS 液态玻璃从推出到回调仅用一年，说明在核心操作系统层面，保守渐进的设计演进策略仍是最优解。

成本-体验ROI

Uber 反思 AI 投入：高昂的 Token 成本与用户体验产出尚未建立清晰关联

Uber COO Andrew Macdonald 在播客中坦言：公司在 AI 上的投入越来越高，但落到消费者端真正好用的功能上，并没有相应的产出。他表示"Token 的消耗量确实在激增，但这种高昂的投入与终端用户体验的实质性提升之间，尚未建立起清晰的逻辑关联"。

更早之前，Uber CTO Praveen Neppalli 也表达了类似担忧。这一现象在技术圈引发广泛共鸣：当 AI 成为基础设施层面的投入，如何衡量其对终端用户体验的真实贡献，成为产品决策中的核心难题。

UX洞察：企业需要建立"AI投入-体验产出"的量化评估框架。建议从三个维度衡量：任务完成率变化、用户满意度变化（NPS/CSAT）、以及用户行为路径的简化程度。没有数据支撑的技术投入，终将面临预算削减。

设计工具演进

Figma 推出首届 Config Makeathon，设计智能体 Beta 即将开放

Figma 宣布将于 6 月 4 日举办首届 Config Makeathon，奖金池高达 10 万美元，由 Contra 提供支持。更重要的是，在 6 月 3 日前预注册的用户将获得 Figma 设计智能体（design agent）Beta 版本的访问权限。

这标志着设计工具的 AI 化进入加速期。从辅助性的自动布局、组件推荐，到能够独立执行设计任务的智能体，Figma 正在重新定义设计师与工具的协作关系。

UX洞察：设计智能体的核心价值不在于"替代设计师"，而在于承担重复性、模式化的设计执行任务，让设计师将精力集中在创意策略、用户洞察和设计决策上。关键挑战在于定义"哪些设计任务可以被智能体可靠地接管"。
📎 来源: Figma(@figma) 推文
情感化AI设计

《和平精英》上线 AI 明星队友"小田"：从"搭伙"到"固定搭子"的情感化设计

腾讯游戏《和平精英》正式上线 AI 明星队友"小田"，这是游戏行业首个由策略大模型驱动的明星 AI 伙伴。基于腾讯混元 Hy3 preview 研发，通过混元 GameMate1.0 框架实现了从对话、感知、决策、行动到记忆的全链路智能体升级。

"小田"的核心设计亮点在于长期记忆功能——她能够记住玩家的习惯、喜好和兴趣，在一场场对局中与玩家产生长期的情感牵绊，成为玩家真正熟悉的"固定搭子"，而非单次"搭伙"。这种从"功能性陪伴"到"情感性陪伴"的设计跨越，代表了游戏 AI 角色设计的最新方向。

UX洞察：AI 角色的情感化设计需要三个核心要素：一致的"人格"（行为模式稳定）、长期"记忆"（记住用户偏好和共同经历）、以及"主动性"（主动发起互动而非被动响应）。这些要素的协同才能真正创造"活人感"。

💡设计趋势洞察

趋势分析

趋势一：AI 设计工具从"玩具"到"生产工具"的关键跨越

过去半年，AI 设计工具经历了从"炫技式演示"到"融入真实工作流"的质变。Claude Design 支持导入 Design System、Figma 即将推出设计智能体 Beta、以及 shadcn 推出的 GitHub repo 转设计系统注册表功能——这些信号共同指向一个趋势：AI 设计工具正在从生成单张图片/页面，进化到理解和维护系统级的设计规范。

对设计师而言，这意味着工作重心需要重新定位。当 AI 能够可靠地执行"根据设计系统生成符合规范的界面"这类任务时，设计师的核心竞争力将更多体现在：定义什么样的设计系统最能服务用户、如何确保设计系统在不同场景下的一致性和灵活性、以及如何通过用户研究持续优化设计系统的底层逻辑。

实践建议：

  • 梳理当前团队的设计系统，评估哪些部分可以被 AI 工具接管
  • 建立设计系统的"AI 友好度"标准——清晰的命名规范、完整的组件说明、明确的使用场景
  • 将释放出的设计执行时间重新投入到用户研究和设计策略中

趋势分析

趋势二：多 Agent 工作流中的"上下文断裂"——用户体验的新挑战

随着多 Agent 工作流的普及，一个隐蔽但关键的用户体验问题正在浮现：知识困在各自的"脑壳"里，无法自动同步。当用户使用 OpenClaw 作为个人助理、Codex 写代码、Claude Code 做设计时，每个 Agent 像独立的新脑子——各自记忆、各自对用户的局部画像。

从用户研究的角度来看，这创造了一个前所未有的体验断裂：用户在同一个项目中的需求、偏好和决策历史，需要在不同工具间反复"自我介绍"。这种体验远比"在不同 App 间切换"更深层——它涉及认知负荷的重复投入和"被理解感"的反复建立。

研究方向：

  • 跨 Agent 的"用户画像同步协议"——如何在保护隐私的前提下实现 Agent 间的上下文共享
  • "渐进式认知加载"设计——如何让用户无需重复解释已提供过的信息
  • 多 Agent 工作流中的"一致性体验"度量指标

沉浸式体验

盛唐长安 3D 互动世界：文化内容的沉浸式体验设计范式

一位开发者用两周时间，基于 Three.js 和实时语音 AI，将盛唐长安做成了可走进去对话的 3D 世界。用户可以用 WASD 真正"走进"长安城，而非仅转相机看模型；按住麦克风就能和李白、杜甫等 NPC 进行真实语音对话；还能参与飞花令、对对联、猜谜等唐风小游戏。

这个项目的体验设计有几个值得关注的亮点：

  • 第一人称漫游：从"观察式"到"参与式"的视角转换，显著提升了沉浸感
  • 多模态交互：语音对话+文字游戏+自由探索的组合，满足了不同用户的交互偏好
  • 文化叙事的游戏化：将诗词、历史知识转化为可玩的游戏机制，降低了文化内容的认知门槛

不过，从用户体验角度，这类沉浸式 3D 内容仍面临一些挑战：加载性能对体验的打断、语音交互在嘈杂环境中的可用性、以及新用户首次进入时的引导设计。这些正是用户研究可以深入的方向。

AI vs 人类设计

播客封面设计：当 AI 无法给出满意结果时，人类设计师的价值在哪里？

一位创作者尝试用 AI 为播客"橘座"设计封面——在橙色背景中放置一把舒适的椅子。AI 试了多次都无法达到满意效果，创作者转而翻阅人类设计师的经典作品，最终发现了 Eero Aarnio 设计的 Ball Chair（星球椅）——"这把椅子本身就很像一只被刀切开的橘子"。

这个案例生动地揭示了 AI 设计的当前边界：

  • 隐喻理解：AI 难以将"橘座"这一名称背后的文化隐喻（橙色→橘子→被切开的球体）转化为视觉符号
  • 情感共鸣：人类设计师在创作 Ball Chair 时的个人故事（为新家制作一把大椅子，妻子协助绘制头部动线）赋予了作品情感深度
  • 跨域联想：从"橘子"到"球体"到"Ball Chair"的联想链条，需要对人类文化、设计史和视觉隐喻的深层理解

UX启示：AI 设计工具最适合处理"模式明确、约束清晰"的设计任务，而涉及深层文化隐喻、情感表达和品牌叙事的任务，仍需要人类设计师的创意主导。未来的设计工作流可能是：人类负责"概念和隐喻"，AI 负责"执行和迭代"。

🧪研究方法论

方法创新

快手"液态组织"实践：从"人月神话"到 Agent 驱动的产运研协作

快手磁力引擎风控技术负责人王东旭在 QCon 2026 分享了团队推动组织智能转型的实践。他从"AIGC 已将安全、效率、体验的不可能三角推向极限"这一现实困境出发，提出固态组织必须向"液态组织"转型：

  • Prompt to Product：产品经理用 Prompt 直接交付原型，缩短从需求到可视化的路径
  • 模型教练：运营从配置规则表达式升级为模型教练，通过反馈优化 Agent 行为
  • CLI 模式：研发以命令行模式与 AI 协作，逃离"职业阶梯中空化"困局

从用户研究视角，这一转型对研究者提出了新要求：需要理解 Agent 的行为模式、设计 Agent 与人类协作的评估框架、以及建立"人机协作"体验的研究方法。传统的可用性测试需要扩展为"人机协作效能测试"——不仅测人，也要测 Agent 在协作链路中的表现。

工具推荐

值得关注的设计与研究工具

1. designmd.cc — 一键生成设计系统文档

输入网址即可一键生成 design.md 格式的设计系统文档。对于需要快速整理和归档设计规范的研究团队来说，这是一个降低文档维护成本的有用工具。

2. Graphite — 矢量作图 Web 应用

一个浏览器端的矢量作图工具，适合快速原型和概念图的绘制。对于需要跨设备协作的设计研究团队，浏览器原生工具可以减少环境配置 friction。

3. ElevenLabs 语音交互模型

ElevenLabs 在 Warsaw 峰会上展示了其最具表现力的 AI 语音模型，并演示了语音智能体在客户体验场景中的应用。对于研究语音交互、客服机器人、无障碍设计的团队，这是值得关注的方向。

4. Shopify Liquid 主题系统案例

Shopify Staff Engineer 分享了如何在极端设计灵活性与大规模流量下的低延迟性能之间取得平衡。对于需要构建可扩展设计系统的企业，这一案例提供了关于 DSL（领域特定语言）和开发者工具体系建设的宝贵经验。
