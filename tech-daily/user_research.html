◈设计趋势洞察

趋势一：从"Prompt 工程"到"Loop 工程"——AI 产品交互范式的迁移

"Loop Engineering"概念在创业者和 AI 工具社区中快速升温。它的核心不是让 AI 一次性给出完美答案，而是设计可迭代的反馈环：用户提出意图、AI 执行、用户纠偏、AI 再执行。这种范式把设计焦点从"如何写出更好的提示词"转移到"如何设计更低摩擦的反馈与修正机制"。

对 UX 设计师来说，这意味着界面需要为"半成品"和"迭代中状态"提供清晰的可视化。用户不再期待一步到位，而是希望随时介入、随时调整。Matthew Berman 建立的 Loop Library 正是这种社区化尝试：把常用的 agent 循环流程模板化，降低个体搭建循环的成本。这与传统设计系统中的"组件复用"逻辑类似，只是复用的对象变成了行为流程。

趋势二：AI 辅助设计进入"评注-重设计"闭环

Lovable 近期密集发布的设计功能代表了 AI 设计工具的新方向：用户不仅可以通过自然语言生成界面，还可以直接在设计上圈画、打叉、标注"把这个移到上面""去掉这个"，AI 读取标记后自动重构。这种"视觉评注"的交互方式比纯文本 Prompt 更接近真实设计协作——它允许用户在不掌握设计术语的情况下表达修改意图。

这一趋势提示我们：未来设计工具的竞争点可能不是"生成得多快"，而是"理解用户反馈的能力有多强"。Redesign Skill 让 AI 扮演"设计顾问"角色，先评估现有设计再给出改进方向；Annotate 功能则把用户从"打字描述"解放到"随手圈改"。两者共同指向一个更自然的人机共创界面。

◎产品体验点评

案例一：Claude Code Artifacts——把 AI 会话变成可共享的"活文档"

Claude Code 推出的 Artifacts 功能，允许用户把与 AI 的会话输出为实时更新的网页。这种设计解决了一个长期痛点：当 AI agent 在终端里完成大量工作后，如何让他人快速理解并继续协作。典型场景包括事故排查时间线、PR 走查、系统架构图、依赖审计报告等。

从用户体验角度看，Artifacts 做了三件对的事：第一，它把"过程"变成了"产物"，让 AI 工作的中间状态可视化；第二，它保留了会话上下文，查看者不需要重新复述问题；第三，它通过私有链接和权限控制缓解了企业安全顾虑。Boris Cherny 提到他正在用它做代码可视化解释、系统图、动画预览和团队数据分析仪表盘——这说明 Artifacts 已经跨出了单纯的编程辅助，成为一种通用协作媒介。

UX 洞察

AI 工具的普及不会止步于"单人效率"，下一步是"协作可见性"。设计师在研究 AI 产品时，应关注：用户如何向他人解释 AI 的输出？中间产物如何被分享、审阅和迭代？Artifacts 提供了一个值得借鉴的模式。

案例二：Lyft 封闭式小区接驾方案——用地图智能修复"最后一公里"的用户痛点

网约车场景中，封闭式小区常导致司机被导航到错误入口、乘客与司机反复电话确认、订单取消率上升。Lyft 的解决方案结合了 OpenStreetMap 数据、司机反馈、历史接驾模式来识别小区边界，并为乘客提供"小区内/小区外"的接驾选项，同时引导司机前往可通行出入口。乘客还可以主动分享门禁信息，减少临时沟通。

这个案例展示了如何把"隐性摩擦"变成可度量的设计问题：不是简单优化地图精度，而是重新设计接驾点推荐、路线规划和信息补全的协同流程。对 UX 研究者而言，这类项目的关键在于深入一线场景，理解司机和乘客在物理空间中的真实行为，而不是只看数据指标。

案例三：豆包实时语音模型 3.0——语音 Agent 的 UX 设计重点转移

豆包实时语音模型 3.0 的最大变化不是语音识别准确率，而是"全双工"和"端到端"带来的交互体验升级。它能在用户说话时同时倾听，支持随时插话；能在嘈杂环境中正常工作；还能在实时对话中调用工具完成预定日历、发邮件、总结文档等任务。

这提示语音交互设计进入新阶段：设计师需要考虑"话轮边界"——系统何时该接话、何时该保持沉默；需要考虑"社交礼仪"——在多人对话中如何被临时禁言、又如何被召回；还需要考虑"打断与恢复"——用户插话后如何平滑继续。传统语音助手的设计假设是"用户说完一句，系统回应一句"，而新范式更接近自然人类对话。

✦研究方法论

培养产品直觉：当数据与"第六感"冲突时如何决策

人人都是产品经理上的一篇经验分享指出，产品经理的直觉并非玄学，而是长期经验在大脑中的"离线计算"。作者建议用三条路径培养直觉：第一，大量复盘真实案例，把"感觉"和"结果"对应起来；第二，在关键决策前主动写下自己的预判，再与实际结果对比；第三，当数据验证与直觉冲突时，先假设直觉可能是对的，然后寻找数据没有覆盖到的变量。

对用户研究员来说，这意味着研究方法不能只看量化数据。访谈、情境观察、可用性测试获得的"模糊信号"同样重要。好的研究者需要建立一种"可验证的直觉"——既能敏锐捕捉用户的未言明需求，又能通过小范围实验快速验证。

Apple 设计大奖给我们的评估框架

今年 Apple 设计大奖继续围绕六个维度评选：乐趣横生、多元包容、创新思维、出色互动、社会影响、视觉图像。少数派在现场与入围开发者交流后发现，获奖产品往往不是靠单点技术突破，而是在"手感"上做到极致。例如 (Not Boring) Camera 用三维界面、动态光影、声音和触感反馈还原实体相机操控感；Structured 和 Detail 则在不同场景下展示了如何让复杂功能变得可亲近。

这个框架可以作为 UX 团队评估自家产品的镜子：我们的产品在哪一个维度上有明显优势？是否在"出色互动"上投入了足够的设计细节？是否在"多元包容"上考虑了不同能力用户的体验？
