用户研究版科技日报

2026-07-27 · 聚焦 AI 时代的体验、速度、信任与可解释性

1. 今日要点

速度与响应正在成为 AI 产品新的体验决胜点。 当模型智力差距缩小时，1–5 分钟的等待窗口让用户陷入“无法进入心流、也不能离开屏幕”的尴尬，注意力被切碎成碎片化状态。
“自带 Agent”与模型可替换性正在重塑应用形态。 应用不再需要内置完整 Agent，只需保存状态、渲染 UI、开放接口，让用户把自己信任的 Agent 带进来，这对跨平台一致性和可扩展性是根本性转变。
医疗/心理健康 AI 开始以“评估驱动”取代“感觉驱动”。 SonderMind 的案例显示，Agent 架构、伦理引擎、临床反馈闭环必须同时设计，否则再聪明的对话也会带来真实风险。
研究型工作流正向文件系统与 Markdown 约定回归。 用 AGENTS.md 描述规则、用 research/ 文件夹沉淀知识，这种去 UI 化的做法提示我们：复杂工作流的设计正在从“功能堆砌”回到“清晰的信息架构”。
复古像素/Dither 视觉语言重新流行。 在高度同质化的现代 UI 中，低保真、有纹理的视觉风格正在成为品牌差异化的新信号。

2. 设计趋势洞察：从“Agent 即应用”到“Agent 即基础设施”

Granola 创始人 Chris Pedregal 提出，未来的应用不应试图自建 Agent，而应做好三件事：保存状态、渲染 UI、让用户带来自己信任的 Agent。这一观点与 Qwen AI 平台发布的方向形成呼应——把“选模型、调模型、切换模型”封装成官方 Skill，交给 Agent 自己完成。

从用户体验角度看，这意味着应用的设计重点将从“比拼模型能力”转向“比拼状态可迁移性、接口清晰度与跨 Agent 一致性”。用户不再被锁定在某个产品的 Agent 里，而是可以在不同场景下使用同一个 Agent 驾驶不同应用。这对设计系统提出了新要求：组件不仅要服务人类用户，还要能被外部 Agent 识别、调用和解释。

与此同时，Kaku 终端展示了另一种更“安静”的 AI 体验范式：AI 不常驻前台，只在命令出错、忘记语法或主动唤起时出现。这种“低打扰、按需出现”的交互，或许比当前大量 AI 应用的全屏对话更符合开发者和重度用户的真实工作节奏。

3. 产品体验点评

Claude Code 2.0：从“规则约束”到“上下文信任”

Anthropic 在新一代 Claude Code 中删掉了约 80% 的系统提示词，却并没有损失性能。这说明，当模型推理能力足够强时，过多的防御性规则反而会成为限制。产品建议也从“写更多规则”转向“把工具接口设计清楚，让模型基于上下文自行判断”。

这对设计师和研究员的启示是：AI 产品的可控性设计，正在从“前端写死限制”迁移到“后端提供高质量上下文与可验证工具”。用户体验因此变得更灵活，但也要求产品团队对“工具可理解性”和“失败可解释性”投入更多精力。

Claude Code 2.0: YOU NOW NEED TO CHANGE EVERYTHING!

Anthropic 移除了约 80% 的 Claude Code 系统提示词且性能未下降，建议从僵化规则转向让模型基于周围代码自行判断，并强调工具接口的清晰度。

来源：AICodeKing / YouTube

速度与等待：AI 产品的新痛点

多位用户指出，当前 Kimi 的最大痛点是速度：一个通常 2 分钟的 UI 改动需要 5–7 分钟，单个任务等待 1–5 分钟成为“既无法进入深度工作，又不能离开屏幕”的尴尬区间。结果是用户更容易被社交媒体打断，形成“Agent 让我们更 ADHD”的反馈。

从用户旅程角度看，AI 产品的“等待体验”设计将成为新的研究课题：进度反馈是否足够透明？中间结果是否可预览？用户是否可以并行处理其他任务？这些细节将直接影响工具能否进入专业工作流。

Kimi 的最大痛点就是速度了

有开发者反馈，Kimi 做 agent mode 和 UI 改动的响应速度明显慢于 Claude Code，模型差距缩小后，算力与推理速度正成为决定可用性的关键。

4. 研究方法论：评估驱动开发（Evals-Driven Development）

SonderMind 在构建心理健康 AI Coach 时，把“vibe 驱动”转变为“评估驱动”。他们建立了由人类治疗师洞察转化而来的大规模机器可读评估集，并设计了 Supervisor/Executor/Evaluator 的闭环架构与可随临床指南演化的 Ethics Engine。

这对用户研究方法的启发是：在高风险领域，研究者需要把“人类专家判断”编码成可重复、可度量的评估标准，同时保留人在回路中的监督。研究不再是项目结束后的报告，而是贯穿产品生命周期的实时反馈系统。

此外，Guillermo Rauch 分享的“Agent CLI + 文件系统”研究法也值得关注：通过 AGENTS.md 定义格式与最佳实践，用纯文本文件夹沉淀研究资料，再用 Agent 关联历史会话。它的可扩展性和可共享性，值得用户研究团队思考知识库与洞察沉淀的新形式。

5. UX 雷达：值得关注的早期设计信号

  • 自维护 API（Self-Maintaining APIs）： API 提供方不再只发变更公告，而是主动在客户代码库中找到受影响的使用方式并提交 PR。这种“把变更责任从用户侧移到平台侧”的思路，可能改变开发者工具的可用性标准。 来源：Y Combinator / YouTube Shorts
  • 交互式 3D 体育数据肖像： 将世界杯 1500 多场赛事事件转化为 Three.js 3D 可视化，把枯燥数据变成可探索的“故事空间”，为信息可视化与叙事体验提供了新的参考。 来源：GitHub / YouTube Shorts
  • 教育中的人际关系不可替代： TED 演讲再次强调，AI 可以传递知识，但同伴辅导中的人际连接与共情能力，仍然是人类独特的体验优势。 来源：TED / YouTube
  • Dither / 像素风设计回潮： dither-kit 等工具让低保真像素纹理更容易进入现代网页设计，为同质化 UI 提供差异化视觉表达。 来源：Viking / X
