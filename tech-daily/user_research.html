今日要点

AI设计技能生态爆发：从工具到设计系统的完整链路

当前市场上已出现超过12套成熟的AI设计技能（Design Skills），涵盖从UI审计、无障碍检测到动效设计的完整工作流。Impeccable提供17个设计命令，UI Skills包含15个独立技能模块，Taste Skill则专注于高级视觉质感打造。这标志着AI辅助设计从"尝鲜"走向"生产级"应用，设计师需要重新思考人机协作的边界。

语音交互的UX突破：Claude Code语音模式展现技术术语精准识别

开发者反馈Claude Code的语音模式在捕捉技术术语方面表现出色，虽然对语音作为主要输入方式仍持谨慎态度，但实际使用频率正在增加。这揭示了专业场景下语音交互的新可能——当AI能准确理解领域术语时，语音输入的效率瓶颈正在被打破。

陪伴机器人设计新范式：科沃斯"毛团儿"用多模态感知重构人机互动

科沃斯在AWE展会上展示的机械小狗"毛团儿"，通过柔软的触感、自然的表情反馈和声音互动，创造出类似真实宠物的情感连接。用户不是"操作"它，而是本能地想抚摸、和它说话。这代表了陪伴机器人设计的重要转向：从功能导向到情感导向，从指令交互到自然互动。

生成式UI的实用化探索：从概念到生产力工具

开发者发现生成式UI与AI助理结合的新用法——可视化助理的记忆内容、生成待办清单的交互式勾选界面、以日历形式呈现日程安排。这标志着生成式UI从"炫技"走向"实用"，开始真正解决信息呈现和任务管理的痛点。

智能家居的推理与记忆困境：美的MevoX试图破解的五大难题

美的AI研究院院长指出，智能家居要实现真正的"智能"，必须解决设备能力异构、环境差异、用户输入模糊、体感判断个体差异、响应速度与准确性的平衡等五大挑战。MevoX自进化家居智能体的推出，代表了行业从"联网控制"向"主动服务"的转型尝试。

AI设计

设计技能（Design Skills）的模块化生态正在形成

市场上涌现的设计技能已形成完整的分层体系：基础层包括baseline-ui（Tailwind设计一致性）、fixing-accessibility（无障碍审计）；进阶层涵盖12-principles-of-animation（迪士尼动画原则）、fixing-motion-performance（动画性能优化）；高阶层则有taste-skill（高级视觉质感）、redesign-skill（项目升级重构）。这种模块化趋势让设计师可以像搭积木一样构建自己的工作流，同时也对设计师的"技能选型"能力提出了新要求。值得关注的是，Vercel官方发布的web-design-guidelines包含100+ UI审计规则，Anthropic的frontend-design skill则代表了AI厂商对设计质量的官方定义。

来源：Ding(@dingyi)、Vercel Labs
交互设计

从"意图驱动"到"持续感知"：Agent交互模式的演进

OpenClaw的Heartbeat机制（定时检查新任务）正在被新的"持续感知"（Aware）模式补充。Clawith等项目提出，真正的智能体应该像人类一样持续感知环境变化，而不是被动等待指令。这带来了交互设计的深层思考：当AI从"工具"变成"同事"，界面设计需要从"命令-响应"模式转向"协作-同步"模式。设计师需要考虑如何让用户感知Agent的状态、如何设计多Agent协作的界面、如何处理"AI主动行为"与"用户控制感"之间的平衡。

产品体验

Manus Desktop的"My Computer"功能：本地Agent的体验突破

Manus将AI Agent从云端搬到本地桌面，推出"My Computer"功能，让用户可以组织数千张未分类照片、批量重命名发票、在本地用Swift构建桌面应用。这一设计的用户体验价值在于：数据不用上传云端，消除了隐私顾虑；直接操作本地文件，消除了"云端Agent"与"本地文件"之间的割裂感；无需手动编写代码，降低了使用门槛。然而，玉伯的评价也值得关注——"全是预期中的功能，没了那种出其不意的惊喜"，这提示Agent产品正在进入"体验同质化"的瓶颈期。

来源：Manus(@ManusAI)、Frank Wang 玉伯(@lifesinger)
产品体验

Dify的视频简历功能：招聘流程的人性化创新

Dify在招聘流程中引入3分钟视频简历选项，让候选人可以"充分表达真实的你"。这一设计洞察非常精准：简历只是起点，人才是答案。通过LLM技术对视频内容进行初步分析，帮助团队更快、更准地理解每一位候选人。这代表了AI在HR领域的正确打开方式——不是替代人的判断，而是放大人的感知能力，让招聘从"关键词匹配"走向"真实理解"。

来源：Luyu Zhang(@goocarlos)
产品体验

Notion AI自定义技能：从Prompt到Skill的体验升级

Notion推出自定义技能（Custom Skills）功能，将AI能力从"一次性Prompt"升级为"可复用Skill"。用户可以将任何页面转换为技能，教Notion AI做好一件事——格式化笔记、起草更新等。这一设计的关键洞察是：用户真正需要的不是更强大的AI，而是更容易复用的AI能力。通过将技能视为普通页面，Notion实现了"创建-分享-协作"的完整闭环，降低了团队协作的认知门槛。

来源：Notion(@NotionHQ)

研究方法论

AI时代的用户研究新工具

  • r.jina.ai：将任意网页转换为干净的Markdown格式，完美用于研究、AI Agent或直接向模型提供文档。解决了网页内容噪音多、格式混乱的问题。
  • Chrome DevTools MCP：AI助手可以直接连接浏览器，读取正在浏览的内容并直接操作。这意味着用户研究者可以让AI观察用户的实际操作流程，自动记录交互路径。
  • Claude Code + Obsidian：将多年个人笔记转化为可操作的洞察、项目创意，甚至自定义命令。适合进行纵向的用户行为分析。
研究方法

"监督工程"（Supervisory Engineering）：AI时代的新工作模式研究

Annie Vella对158名专业软件工程师的研究发现，AI工具正在将工程师的工作从"创造导向"转向"验证导向"。但这种验证不同于传统的代码审查和测试，而是一种新的工作形态——"监督工程"：指导AI、评估输出、纠正错误。这对用户研究的方法论有重要启示：当研究对象的工作性质发生根本变化，传统的任务分析、工作流程研究方法是否还适用？研究者需要开发新的框架来理解"人机协作"中的认知负荷、决策模式和效率瓶颈。

UX雷达

早期信号：WebMCP可能重新定义AI与Web的交互方式

Chrome团队推出的WebMCP（Web模型上下文协议）让AI Agent可以直接与Web应用内核对话，绕过前端UI。这意味着未来的网页设计可能需要同时考虑"人类界面"和"AI界面"，设计师需要思考如何用API思维重新设计信息架构。

早期信号：生成式UI的实用化拐点已至

开发者开始将生成式UI用于实际场景：可视化AI助理的记忆内容、生成可交互的待办清单、以图表形式呈现统计数据。这标志着生成式UI从"演示价值"走向"实用价值"。

早期信号：AI产品的"人格化"设计成为差异化关键

Sam Altman评价GPT-5.4时指出，其最显著的特征不是智商，而是"人性"。用户声称想要10倍效率的"自闭症天才程序员"，但真正想要的是有性格的互动伙伴。这提示AI产品的UX竞争正在从"能力"转向"性格"。

早期信号：跨设备Agent同步体验成为新战场

Perplexity Computer推出跨设备同步功能，让用户可以在手机和桌面之间无缝切换任务。随着Agent开始承担更多长期任务，跨设备体验的连贯性将成为用户粘性的关键决定因素。
