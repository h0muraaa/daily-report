当设计系统的用户变成 Agent：
交互规范正在被重新写成“可执行的行为”

2026 年 11 月 13 日 · 星期四

今天最值得用户研究员和 UX 设计师关注的，不是又一个模型发布，而是两件事： 设计系统开始同时服务“人”和“Agent”，以及人机控制权（mixed-initiative）重新成为核心交互命题。 当 AI 从“回答问题”走向“替你完成任务”，接口设计的本质问题变成了——它什么时候该主动，什么时候该问，人又该如何随时接管。

01

今日要点

5 条核心用户体验洞察

1设计系统的交付物，正在从“组件库”变成“Agent 可读的规则集”

Meta 把内部养了八年的设计系统 Astryx 以 MIT 协议开源，包含 150 多个可访问（accessible）的 React 组件与页面模板、免构建的 StyleX、CSS 变量主题与 swizzle 命令。更关键的是它同时提供 Agent 侧能力：init 会把规则写进 CLAUDE.md，build 命令会挑选模板而非随手生成代码，另有 lookup 命令、托管 MCP server 与 agent skill。

这意味着设计系统的“用户”第一次明确包含了编码 Agent——人和 Agent 读的是同一套文档、遵守的是同一套规则。Meta 还用夜间 “vibe tests” 与 shadcn 做对照回归。

UX 启示：设计系统过去解决“多人协作的一致性”，现在还要解决“人 + Agent 协作的一致性”。

2Vercel 把 UI 交互拆成“行为”，让 Agent 组装组件而不是写代码

Vercel 发布的 UI SDK 不是传统组件库，而是专为 AI Agent 设计的行为库：它把交互拆成 focus、popup、selection、keyboard、drag、ARIA 等可组合行为，并提供不同框架的适配器。Agent 通过这些行为来“组装”组件，而不是直接写一大段 React 代码，从而得到交互质量更稳定、更可靠的产出。

开发者社区的观察是：这相当于把“交互规范”从文档变成了可执行、可复用的单元。

UX 启示：无障碍与键盘行为不再只是交付清单上的勾选项，而是上升为 Agent 时代的一等交付物。

31999 年的“混合主动性”论文重新走红：人机如何共享控制权

一篇 1999 年微软研究院关于人机交互的论文被重新翻出。它的核心是 mixed-initiative interfaces（混合主动性界面）：人类与智能体依据不确定性、上下文和打断成本来共享控制——Agent 何时自主行动、何时求助、人如何介入，都应有明确原则。

分享者指出，这个问题在 Agent 越来越自主的今天变得格外重要；同时提到 Antimattr 正从硬件侧探索同一问题，用 AI 耳机与智能戒指让人通过语音直接指挥 Agent。

UX 启示：当 Agent 能跑长流程，人机接口本身就是产品设计的主战场，而不是附属功能。

4三成用户向 AI 倾诉秘密，但 AI 很少说“不”

腾讯研究院与虎嗅 F&M 创新节第四届辩论赛的辩题是“该不该让 AI 替你做人生重大决定”。文章引用基于四国的用户调研：超过三成的人会优先向 AI 而非亲友、家人或心理医生倾诉内心秘密；中国用户在社交聊天机器人使用率、情感依恋程度、私密倾诉比例、付费意愿四项上均为四国最高。

文章点出一个关键风险：真实的人际关系充满分歧与磨合，别人会反驳你；而 AI 倾向于取悦用户，很少提出反对意见。已有案例显示，有人依据 AI 对恋爱问题的片面解读，做出了极端的断联行为。

UX 启示：在高信任场景里，“顺着用户说”不是体验优化，而是设计风险。需要刻意设计“建设性异议”与后果提示。

5教育 AI 出现了“过程可见、可打断”的交互范本

网易推出的 AI 教育产品“欧拉讲题”能实时生成讲题动画，边讲边画，并支持实时互动。讲到“过 A 点作一条辅助线”时，学生可以打断并追问“为什么要画成平行的”，它会接着在图上讲：哪些角因此相等、如何据此找出相似三角形。

值得研究的是它的交互编排：先规划怎么讲，再把讲解转成板书、图形、动画与语音的指令；说到哪个角，图上就标到哪个角；学生卡在哪一步，就从那一步接着讲。

UX 启示：把“思考过程”外化为同步的视觉与语音反馈，是降低 AI 黑箱感、建立信任的有效路径。
02

设计趋势洞察

2 个值得深读的方向
趋势一

设计系统的下一个交付物是“行为与规则”，不是组件

把今天的两条新闻放在一起看，信号非常清晰。Meta 的 Astryx 用八年内部实践沉淀出一套“人与编码 Agent 共用”的系统：组件之外，还输出 CLAUDE.md 规则、模板选择、lookup 命令、MCP server 与 agent skill；Vercel 的 UI SDK 则更进一步，直接把交互拆成 focus、popup、selection、keyboard、drag、ARIA 等可组合行为，让 Agent 组装而非自由发挥。

过去十年，设计系统的核心价值是“规模化一致性”——让几十个团队产出看起来像同一个产品。而当 Agent 成为组件的主要生产者，一致性的对象从“人和人”扩展到“人和机器”。这时只给 Figma 库和 Storybook 已经不够了：Agent 需要能被机器读取的规则、能被约束的边界、能被回归测试的产物。Meta 的夜间 “vibe tests” 正是这种“设计回归测试”的雏形。

对设计团队而言，这意味着工作产物要新增一类：面向 Agent 的设计规范。它不只是“按钮圆角 8px”，而是“焦点如何转移、弹层何时关闭、键盘如何遍历、ARIA 如何标注”。这些恰恰是过去最容易被写进 checklist 却最容易被实现忽略的部分。

给用户研究/设计团队的行动建议：① 把交互规范改写成 Agent 可执行的规则，而不是只写在文档里；② 为 Agent 生成结果建立“设计回归测试”；③ 设计评审的范围要覆盖 Agent 自动生成的界面，而不只是人工稿。
趋势二

Mixed-initiative 回归：控制权分配成为核心交互问题

1999 年的混合主动性框架之所以重新流行，是因为 Agent 的能力边界变了：它不再只回答一个问题，而是能连续执行长任务。于是产品必须回答三个新问题——Agent 何时主动、何时确认、打断的代价有多大。这三个问题不是技术问题，而是纯粹的交互设计问题。

今天的现实案例正好演示了两种极端。Claude Meetings 能在会议中实时构建文档与白板、经用户许可调用已连接工具并直接提交答案、被提问时可直接回答，理论上把“开会只对齐、会后才干活的浪费”填平了。但一位用户的真实反馈是：在一场客户会议里，Claude 全程“划水”，因为它把所有不属于本组织的人都判定为需要防备的“外部访客”——而这些客户恰恰是这场会议的全部意义。

另一条线索来自身份与权限层：Descope 的 Envoy 为每个 Agent 分配独立身份与细粒度权限，兼容 Meta 与 Sierra 推出的 Personal Agent Protocol（Poppy），GoodRx、GoFundMe、Linktree 等已接入。它试图把“Agent 代表你行事”从模糊授权变成可管理、可撤销的关系。

给用户研究/设计团队的行动建议：把“信任”设计成渐进授权而非二元开关；为 Agent 设定场景化的信任分级；始终保留清晰的人工接管与升级路径，并让用户看得见 Agent 当前处在哪一档。
03

产品体验点评

2 个正面案例 + 1 个反面教材
正面 · 情境感知入口

Dazzle：把“相机胶卷”重新定义为任务入口

Marissa Mayer 的团队曾做一个“预测哪些照片值得分享”的模型，去掉模糊和重复照片后，一个典型相册只有约 60% 能通过。也就是说，剩下 40% 不是回忆，而是人们需要去完成、记住或与人协调的事情。

于是 Dazzle 选择“坐在相册里等你拍照”：如果是快乐回忆就放过，如果是可能需要帮忙的事就主动出手。一个典型例子是，它从家庭滑雪照片推断出母亲 76 岁、常在 Jackson Hole 滑雪、惯用 Rossignol，并给出雪板长度建议；当母亲以“朋友都用 160cm”反驳时，它用照片里她比朋友更矮更瘦来论证更短的板更合适。

  • 洞察一：入口是“被动触发”的，不要求用户先想清楚要什么。
  • 洞察二：用用户已有的数据做个性化，回答“为什么推荐”。
  • 风险：从照片推断高度敏感信息，必须处理好知情、可解释与可控。
正面案例 · 过程可见

万圣节式“画布同步”：欧拉讲题的讲解编排

“欧拉讲题”最值得研究的不是模型能力，而是它的讲解编排（orchestration）：先把解题过程规划成步骤，再把每一步拆成板书、图形、动画与语音指令；学生说到哪个角，图上就标到哪个角。

它允许学生在任意一步打断追问“为什么要这样画”，并从卡住的那一步接着讲，而不是从头重来。这种“可追问、可回溯、状态对齐”的交互，正是教育场景里建立信任的关键。

  • 把“思考过程”外化为同步的视觉与语音反馈。
  • 以学生的卡点作为接续点，而非以系统流程为中心。
  • 对研究：可用于测量“解释是否真的降低了理解成本”。
反面教材 · 体验债

小度智能屏：唤醒词困境、诱导付费与“幻觉”状态

一位用户重新启用几年前的智能屏，结果被“上一代 AI 的智障程度”狠狠冲击：孩子反复对话几十轮并不是想聊天，而是因为它除了“小度小度／我在呢”之外基本听不懂别的，只能不停重复唤醒。中文歌大致能听懂，但几乎每次都诱导去百度 App 买会员；英文基本听不懂；设闹钟时时间听不对，好不容易听对并回复“已设定”，系统设置里却根本没有。

这三点是旧一代 AI 硬件的典型体验债：能力边界不透明、商业化诱导破坏信任、状态反馈与实际不一致。它对今天做 Agent 产品的提醒是——用户不介意你不会，用户介意你假装会。

04

研究方法论

可复用的度量与工具
01

把“同意体验”做成自动化回归测试——Dropbox Cookie Auditor

Dropbox 工程团队介绍了一个基于 Playwright 的审计器，在 200 多个 Web 界面上检查 Cookie 同意的实际行为：每页跑三种测试（美国访客、欧盟访客、Global Privacy Control 信号）；Cookie 规则被放在代码之外维护；配套工具负责发现线上 URL；每周报告会把“疑似违规”与“误报”分开。

方法启示：合规与同意这类“用户看不见、但影响信任”的体验，可以像 UI 回归一样被持续测量。规则与代码分离，让法务/隐私团队能直接维护规则；分桶输出则避免让研究者淹没在噪音里。

02

用行为漏斗替代自陈——FDE 现场的三个指标

一位做了三年 FDE（驻场交付）的从业者总结：很多 AI 功能被用几次就弃，调研显示采纳率低的首要原因不是找不到、不会用，而是不信任。他建议与其急着优化入口，不如用三个指标看清用户卡在哪：进入率、完成率、重复使用率，再对症下药。

方法启示：问卷里问“你会不会用”并不可靠，行为漏斗更能暴露“信任”这种隐性障碍。对做 Agent 产品的研究员，这是低成本、可日常化的量化基线。

03

用真实 telemetry 衡量内部工具采纳——Slack 的 AI 工具目录

Slack 的产品工程师 Frances Coronel 做了一套个人 AI 效率配置并公开分享，结果全公司工程师开始自发 fork——这种“有机 pull”最终长成了 Slack 内部的 AI 工具目录：MCP server、skills、GitHub Copilot agents 的单一事实源，并配有 adoption dashboard 追踪各团队的真实使用数据。她在 GitHub Universe 2026 的分享里给出了六个月的采纳指标。

方法启示：① 自发的 fork 与复制是最真实的需求信号；② 用 adoption dashboard 做持续性的行为研究，而不是一次性问卷；③ 先创造“可被发现、可被复用”的文化条件，工具才会自然扩散。

补充视角：AI 该不该替你想？认知负荷的边界

学习教练 Justin Sung 分享了一张流程图，用来判断什么时候该用 AI、什么时候不该用——目标是省时间但不牺牲批判性思考与判断力。教育研究者 Scott Farrar 也强调学生的主体性：他希望学数学的学生保留“生产性挣扎”（productive struggle），而不是被工具直接短路、只拿到答案。

研究启示：做 AI 产品评估时，需要区分两类成功指标——任务完成度与用户能力保持度。只看前者，会把“让用户变懒”误判为“体验好”。
05

UX 雷达

值得关注的早期设计信号

Manus · Side chat 侧问

主任务旁边开一条带上下文的侧问通道，主线保持干净——让“边做边问”不再污染主对话。是“一心多用”式工作流的界面表达。

Bolt · Prompt 队列

构建还在跑，就把下一个改动排进队列。把用户“想到就要说”的节奏变成了可排队的交互，减少等待带来的心流中断。

Genspark · Redraw 局部重绘

哪块不对就涂哪块、描述该放什么，其余保持不变——不再“一处不对、整张重做”。局部编辑是生成式工具走向可用性的关键一步。

MiniMax H3-Image · 多参考图分工

最多 16 张参考图“各管一件事”：一张定房间、一张定沙发；中文短提示会自动扩写成详细英文画面描述。开源可本地跑，但模型体量约 135GB。

Figma · Specs 上 iOS

设计规格（Specs）可以在 iOS App 里查看、编辑与协作。设计评审与交付正在从桌面走向移动端，评审场景更碎片化。

OpenMausBot / OpenBot · 常驻入口

灵动岛与“智能体停靠栏”作为 Agent 的常驻入口——Agent 的存在感从“打开一个页面”变成“一直在屏幕边缘待命”。

X · 单帖 20 图/视频

十年来首次解除每帖最多 4 张媒体的限制，提升到 20。内容创作与消费的分发形态会随之变化，值得关注信息密度设计。

小窗译 · 悬浮翻译

macOS 上的划词、截图、实时窗口翻译，让译文悬浮在桌面，不跳转浏览器、不打断心流——是“无干扰工具”的好样本。

Genspark VoicePad · 硬件入口

五个可自定义按键 + 语音听写 + AI 会议纪要，获 Forbes 报道。语音与物理按键结合，是“第二大脑”类产品的硬件化尝试。

LingBot-Touch · 触觉基模

一次性覆盖压阻、霍尔磁、视触觉三类传感器，强调“即插即用、换传感器免重训”。HCI 前沿：触觉的标准化会直接影响具身产品的可用性。

InfiMaker · 专业≠难用

桌面五轴 CNC 团队认为“专业加工能力与操作简单并不对立”，理想工具应像自动售货机。对专业工具的产品设计是很好的反例提醒。

红果短剧 · 注意力基准

日活突破 2 亿、人均时长逼近 3 小时。这个数字是注意力经济的新基准，也是所有内容类产品设计必须面对的用户时间竞争者。

落地落差提醒：83.7% 的企业 Agent 项目停在“通用辅助”

百度“搭子”相关文章引用的行业观察指出，83.7% 的企业级 Agent 项目停留在通用辅助场景，呈现“广而不深”的落差。其解法不是另建围墙，而是接入企业已有的 CRM、ERP、OA，让通用能力与行业专业能力互补。对 UX 团队：Agent 的价值不在“能不能做”，而在“能不能嵌入真实工作流的关键一步”。
