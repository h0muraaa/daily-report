DeepSeek V4 发布：开源模型以 1/3 成本逼近闭源巨头，AI 推理定价体系面临重构
[来源: 晚点LatePost] | [来源: Matt Wolfe]

DeepSeek V4 于 4 月 26 日正式发布，引发业内对其商业影响的广泛讨论。该模型输入 token 定价低至 $1.74/百万，而 GPT-5.5 和 Claude Opus 4.7 的定价约为 $5/百万，成本差距接近 3 倍。更关键的是，V4 在数学推理、代码能力和 Agent 指令执行方面较 V3 有显著提升，且幻觉率大幅降低。晚点 LatePost 的技术分析指出，V4 的核心突破在于"系统级耦合优化"，而非单点创新——从字节的 HC 到 DeepSeek 的 mHC，再到 Kimi 的 Attention Residuals，中国大模型团队正在形成一套独立的技术演进路径。对投资者而言，这意味着闭源模型的定价权正在被开源社区侵蚀，API 业务的毛利率空间将持续承压。同时，V4 支持百万级上下文窗口，可本地部署，这对企业级客户的吸引力极大，可能加速 AI 应用从"租用 API"向"私有化部署"的迁移。

Anthropic 估值或超 9000 亿美元；一级市场 AI 融资热度持续
[来源: 创业邦]

X 平台 4 月下载量创历史新高，较此前纪录增长 40%
[来源: AI Will(@FinanceYF5) 引用 Nikita Bier]

X 产品负责人 Nikita Bier 透露，4 月将创下 X 平台单月下载量的历史新高，比上次纪录高出 40%。在被唱衰三年后，这一数据具有重要的信号意义。对投资者而言，X 的用户增长恢复可能意味着马斯克对平台的改造（从 Twitter 到 X 的转型、AI 功能整合、支付功能预期）正在产生实际效果。如果 X 能持续证明其用户基础和活跃度，将为其后续的"超级应用"叙事和潜在估值重估提供支撑。不过，需要关注的是，下载量增长是否转化为有效的广告库存和商业化提升，这才是决定估值的关键。

OpenAI Codex 营收 7 天内翻倍；OpenClaw 与 ChatGPT 账号全面打通
[来源: 新智元]

OpenAI 近期产品迭代节奏明显加快。官方数据显示，GPT-5.5 上线一周后，API 增速是以往任何版本的 2 倍以上；Codex 的营收在不到 7 天内实现翻倍。更值得关注的是生态整合：ChatGPT 账号现已可直接登录 OpenClaw（此前 Anthropic 力推的竞品），这意味着 OpenAI 正在用生态锁定策略对抗 Anthropic 的产品优势。同时，Codex 推出"宠物模式"（Pets）、一键迁移、浏览器提速和自主迭代命令等功能，明显对标 Claude Code 的同类产品。从投资视角看，OpenAI 正在经历一场"闪电战"式的产品追赶，其商业化引擎已经启动，但追赶上 Anthropic 在开发者社区的心智份额仍需时间。

Meta 计划 5 月 20 日裁员约 10%，资本支出增加倒逼组织瘦身
[来源: 创业邦] | [来源: a16z]

Meta 计划 5 月 20 日进行约 10% 的裁员，扎克伯格给出的理由是资本支出增加。这是一个值得关注的信号：当 AI 基础设施的资本开支（Capex）飙升时，人力成本成为最先被优化的对象。a16z 的数据也显示，Meta 的日活跃用户（DAU）自 2021 年以来首次出现下滑，同时"滚动浏览行为正在下降"。这两个趋势叠加，意味着 Meta 正面临用户注意力被 AI 工具分流的压力。对投资者而言，这反映了大型科技公司的共同困境：必须在 AI 军备竞赛中保持投入，但传统的广告商业模式可能正在被侵蚀。

OpenAI vs Anthropic：路线之争背后的估值逻辑
[来源: howie.serious] | [来源: AINLP] | [来源: All-In Podcast]

OpenAI 与 Anthropic 的竞争正在从"模型能力比拼"演变为"产品路线与商业模式"的全方位较量。从近期动态来看，两家公司的策略分化愈发明显：

Anthropic 的路线：押注 coding（Claude Code）、本地 agents（OpenClaw）、dense model，不追求极致的 token 低价。这一策略已被市场验证：苹果官方 Support App 更新中意外泄露的 CLAUDE.md 文件证实，苹果内部正在用 Claude Code 构建完整的 AI 系统——这是对 Anthropic 企业级产品能力的最大背书。从投资角度，Anthropic 走的是"高价值客户 + 高客单价"路线，类似早期的 Snowflake 或 Datadog。

OpenAI 的路线：正在拼命从"极致低价"的错误路线往回修正。GPT-5.5 已经让人恢复信心，Codex 的快速增长也验证了"AI 编程助手"这一品类的 PMF。但 All-In Podcast 指出，OpenAI 近期的收入目标并未达成，说明其商业化仍面临压力。OpenAI 的优势在于品牌认知度和生态规模（ChatGPT 的亿级用户），但劣势在于产品线过于分散，从模型到搜索到硬件到社交，战略聚焦度不足。

投资观点

如果 Anthropic 的 9000 亿美元估值坐实，其隐含的估值逻辑是"企业级 AI 基础设施的下一个 Salesforce"。而 OpenAI 的估值逻辑更偏向"AI 时代的 Google"。两条路线都有合理性，但 Anthropic 的差异化更明确，客户粘性（通过 Claude Code 深度嵌入开发工作流）可能更强。建议投资者关注两者在"企业客户 ARR"和"开发者生态活跃度"这两个核心指标上的差距变化。

AI 推理成本崩溃：谁是受益者，谁是受损者？
[来源: 晚点LatePost] | [来源: OpenRouter] | [来源: 宝玉(@dotey)]

DeepSeek V4 的低价策略和 OpenRouter 推出的免费"响应缓存"功能，正在加速 AI 推理成本的下行。OpenRouter 的缓存功能允许开发者将响应缓存 1 秒到 24 小时，缓存命中不消耗 provider 的 rate limit，这对测试和 agent 重试场景的成本节省极为显著。更极端的案例是：一位中国开发者在飞机上用 MacBook Pro M4（64GB 内存）本地运行 Llama 3.3 70B，11 小时无网络环境下完成了完整的客户项目，生成速度达 71 tokens/秒。

受益者：AI 应用层公司（如 Perplexity、Genspark、各类垂直 AI SaaS）。推理成本下降直接扩大其毛利率空间。Perplexity 最新推出的"Equity Research Council Mode"可以对比高盛、摩根大通、摩根士丹利等投行的研究报告，这种高价值功能的成本结构将因推理降价而显著改善。

受损者：纯 API 提供商和闭源模型公司。如果开源模型能以 1/3 成本提供近同等能力，企业客户迁移到私有化部署的动机将大增。OpenRouter 的缓存功能虽然利好生态，但也在加速"去模型商化"的趋势——模型本身越来越 commoditized。

投资建议

在推理成本持续下降的背景下，投资价值向上层应用和"数据/上下文层"转移。LlamaIndex CEO Jerry Liu 的观点值得参考："2023 年大家都在做 picks and shovels，但今天核心 agent 抽象已经固化，真正具有持久护城河的是 agent 的上下文层（context layer）。"建议关注能够将企业私有数据（PDF、合同、财报）转化为 agent 可用上下文的工具型公司。

[来源: Y Combinator]

宏观信号：Berkshire 现金创历史新高，Meta DAU 首降

a16z 发布的图表显示两个值得关注的宏观信号。第一，Berkshire Hathaway 的现金储备达到历史新高，巴菲特的保守姿态可能暗示其对当前市场估值的谨慎态度。第二，Meta 的日活跃用户（DAUs）自 2021 年以来首次下降，同时"滚动浏览行为"（Scrolling）也在下降。这对以广告收入为核心的 Meta 而言是一个值得警惕的信号。尽管 Meta 正在全力投入 AI 和元宇宙，但其核心社交产品的用户时长增长可能已经见顶。与之形成对比的是 X 平台的下载量创新高，社交媒体的竞争格局正在发生结构性变化。

大型科技公司 Capex 激增，财报超预期但隐忧浮现
[来源: All-In Podcast] | [来源: a16z]

All-In Podcast 指出，大型科技公司的最新财报显示" smash earnings"（业绩碾压预期），但资本支出（Capex） explosion（激增）是背后的关键驱动力。a16z 的观点提供了历史视角：AI 并不是第一个由半导体和基础设施驱动早期增长的科技周期——互联网、云计算都经历了类似阶段。历史规律是：基础设施投资先行，应用层价值随后释放。当前阶段，NVIDIA 等"卖铲人"仍然是最大受益者，但投资者需要判断 Capex 增速何时会从"建设期"进入"消化期"。一个警示信号是：Uber 的工程师在 4 个月内烧光了全年 AI 预算（人均数百至数千美元/月），原因是大量使用 Claude Code/Cursor 等工具时的长上下文滥用、并行子代理和质量审查不足。这说明 AI 工具的"隐性成本"正在企业中快速累积。

估值方法论

在 AI 投资中，传统的"收入倍数"估值法可能失效，因为大量价值体现在"效率提升"而非"直接收入"。建议采用"替代价值"（Replacement Value）框架：评估 AI 工具替代的人力成本与其订阅价格的比值。例如，如果 Codex 每月 $20 能替代一名年薪 $15 万的初级工程师 20% 的工作量，其 ROI 是极其清晰的。当前市场可能低估了这种"隐性价值"的可持续性。

ARC-AGI-3 测试：顶尖模型得分低于 1%，AI 能力评估体系需要重构
[来源: 机器之心]

ARC Prize 发布的 ARC-AGI-3 测试结果显示，GPT-5.5 得分 0.43%，Claude Opus 4.7 得分 0.18%，而人类在首次接触时可 100% 解决。这一由 Keras 之父 Francois Chollet 创立的基准测试，旨在评估 AI 在"全新逻辑环境"中的适应能力。对投资者的意义在于：当前大模型在高难度推理任务上的能力可能被高估，这意味着"通用 AI 助手"的商业化天花板可能比市场预期更低。短期内，垂直场景（如代码、文档处理）的 AI 应用比通用助手更具确定性。
