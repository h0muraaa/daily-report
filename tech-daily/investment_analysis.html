xAI解散并入SpaceX，22万张GPU集群租给Anthropic
马斯克宣布旗下AI公司xAI正式解散并整体并入SpaceX，更名为SpaceXAI。此举标志着马斯克科技生态完成AI业务战略重组。Colossus 1数据中心拥有超22万张英伟达GPU（含H100、H200及GB200），300兆瓦容量，已全部租给Anthropic使用。分析师估算年租金约50亿美元。更值得关注的是，双方还签署了"轨道AI算力"合作意向，计划将数据中心送上太空。马斯克对Anthropic的态度也在三个月内发生180度转变——从公开指责其"邪恶""反人类"，到称"没人触发我的邪恶探测器"。

Recursive Superintelligence获5亿美元融资，成立四个月估值40亿美元
由前Salesforce首席科学家Richard Socher创立的Recursive Superintelligence宣布完成5亿美元融资，Google风投GV领投，英伟达跟投。公司成立仅四个月，尚无公开产品，估值已达40亿美元。Socher是斯坦福AI先驱Andrew Ng和NLP权威Christopher Manning的学生，2014年获斯坦福计算机系最佳博士论文奖。该公司宣称要让AI学会自主做研究、自主进化，核心逻辑是"把人从循环里移走"。这一估值水平在2026年的AI融资市场中依然属于顶级定价，反映出顶尖AI科学家+自主研究叙事在当下的稀缺溢价。

Kimi完成20亿美元融资，估值突破200亿美元
月之暗面（Moonshot AI）旗下Kimi完成新一轮20亿美元融资，估值突破200亿美元。这一消息从爱范儿早报中披露。作为国内大模型赛道头部玩家之一，Kimi的估值继续攀升反映了资本市场对中国AI应用层叙事的持续看好，尽管商业化路径和盈利时间表仍不清晰。

总部位于伦敦的AI招聘平台Ethos完成2275万美元A轮融资，由a16z领投，General Catalyst、XTX Markets等参投。Ethos的核心创新在于用语音访谈替代传统的职位标签匹配，通过AI挖掘简历无法呈现的深度专业知识。平台能够回答复杂查询如"帮我寻找曾在顶级VC资助的财务自动化初创公司工作过的人"。a16z合伙人Anish Acharya认为语音是人类沟通的原始形式，Ethos通过精心设计的语音问题捕捉到了传统平台遗漏的细分专业信号。

深度投资分析

主题一：Big Tech的"AI豪赌"——当资本开支吞噬自由现金流

核心数据

Microsoft、Alphabet、Amazon、Meta、Oracle五大巨头合计自由现金流预计在2026年底跌至约1000亿美元，跌幅超70%；同期AI资本开支合计将突破7150亿美元；2026年预计新发债1750亿美元，是AI周期前平均水平的6倍以上。

这是当前科技投资领域最值得警惕的宏观信号。Gary Marcus引用的数据显示，五大科技巨头正在以自由现金流暴跌70%的代价进行AI军备竞赛。这些公司"账面利润创新高，实际现金却在枯竭"，被迫大量发债维持投资强度。

投资逻辑一：这是"新基建"还是"资本黑洞"？

乐观派将此比作云计算早期的重资本投入——AWS亏损多年后才成为利润引擎。悲观派则认为AI目前缺乏明确的商业模式闭环，企业端的AI ROI已被MIT等多项研究证伪。关键在于：当前AI资本开支的"折旧周期"与"回报周期"是否匹配？如果3-5年内无法产生对应收入，当前的资产负债表将承受巨大压力。

投资逻辑二：OpenAI的融资困境是行业缩影

The Information报道，OpenAI与Broadcom宣布合作生产10GW定制AI芯片时"还没有想清楚OpenAI如何为此买单"，数月后双方仍在谈判由Broadcom垫付首批约180亿美元生产费用。类似地，OpenAI与软银的Stargate项目也传出迟疑信号。这说明即便是头部AI公司，也面临"故事先于现金流"的融资压力。如果AI巨头的融资链条断裂，可能引发整个行业估值重估。

投资逻辑三：关注"卖铲人"的盈利能力边界

CoreWeave的案例极具代表性：Q1收入20.8亿美元（同比+112%），未履约订单994亿美元，但调整后经营亏损1.44亿美元，"真实"毛利率仅4.28%，低于上季度的7.2%和市场预期的6%。段永平在此节点建仓约2000万美元。这揭示了一个核心矛盾：AI基础设施需求爆炸式增长，但供应端的定价权和盈利能力正在被过度竞争和资本密集度侵蚀。CoreWeave股价上市后先涨4倍再腰斩的走势，正是市场对这一矛盾的定价摇摆。

主题二：Anthropic正在超越OpenAI——硅谷AI竞争格局重塑

傅盛在深度解读中明确提出：Anthropic将超越OpenAI成为AI创业公司中估值最高的公司，"现在已经被验证了"。其论据包括：Anthropic未上市估值已超万亿美元（注意：此处为口语化表述，实际应为约600-800亿美元区间），年营收10倍暴增，即将登顶全球收入最高AI公司之一。

为什么Anthropic能弯道超车？

核心差异在"组织执行力"而非"模型能力"。拾象投研团队指出，Coding Agent成为科技史上增速最快的新物种，预计2026年ARR突破1000亿美元，而Anthropic凭借Claude Code在这一赛道占据先机。Claude Code之父Boris Cherny在红杉资本AI Ascent 2026上透露：他认为去年10-11月模型已达到"编写100%代码"的临界点，2026年他"还没亲手写过一行代码"，每天能在手机上提交几十个PR。这种"产品-用户-数据"的飞轮一旦启动，会形成强大的网络效应壁垒。

OpenAI的战略失焦代价

拾象团队认为，Anthropic在Coding上的领先、OpenAI和Google前期的战略失焦，"本质上都是组织问题"。当竞赛窗口从6个月压缩到以周为单位时，能够快速调整产品方向、All in正确赛道的组织才能胜出。xAI的失败同样印证了这一点——傅盛指出，马斯克在"核心业务理解上的偏差"导致创始团队人才大量流失，"组织管理一度混乱"。

投资启示

在AI投资中，"模型能力"的差异化正在快速收敛，"产品-market fit"和"组织执行力"的权重在上升。Anthropic的崛起不是因为它有最好的模型，而是因为它最先把模型变成了最有粘性的开发者产品。对于一级市场投资者而言，判断一家AI公司的价值，应该更多关注其产品是否正在形成自增强的飞轮，而非仅仅比较模型benchmark分数。

赛道雷达
Coding Agent 高速增长 $100B+ ARR
赛道热度：极高 | Coding Agent被拾象团队定义为"科技史上增速最快的新物种"，2026年预计ARR突破1000亿美元。Anthropic凭Claude Code有望年中追平OpenAI的ARR。关键变化是：AI开始系统性地加速AI自身——Coding Agent让AI模型的迭代速度大幅提升，形成正反馈循环。投资看点在于：谁能在开发者工作流中建立最深的集成度，谁就掌握了AI时代的"操作系统"入口。需关注Cursor、Windsurf、Claude Code、GitHub Copilot的竞争格局变化。

估值观察
Anthropic估值持续攀升，OpenAI地位受挑战
Anthropic凭借Claude Code的强势表现，正在从估值和营收两个维度逼近甚至超越OpenAI。拾象团队判断其未上市估值已跻身全球AI创业公司最高行列。考虑到Anthropic还租下了xAI的Colossus 1全部算力，其服务容量的扩张将直接转化为收入增长。OpenAI meanwhile面临融资链条的不确定性——与Broadcom的芯片合作、与软银的Stargate项目都传出资金安排未落实的消息。估值视角下，Anthropic的"确定性溢价"正在上升。
xAI从2500亿美元估值到解散：一场估值泡沫的破裂
xAI 2023年7月成立，不到三年估值从0冲到2500亿美元，却在2026年5月6日正式解散并入SpaceX。这不是突发事件：2月完成资本结构并入，3月底创始团队全员清零，5月只是品牌层面的收尾。这一案例深刻说明：在AI赛道，"算力+创始人光环"的估值公式正在失效。没有可持续的产品-市场匹配和组织能力，再高的估值也只是空中楼阁。对投资者而言，xAI的教训是：对于"叙事驱动型"的高估值标的，需要更严格地审视其组织健康度和人才留存率。
AI科学家创业项目估值溢价：Recursive Superintelligence的40亿美元
Recursive Superintelligence成立四个月、无公开产品、估值40亿美元，Google GV和英伟达同时下注。这一定价的逻辑在于：Richard Socher作为前Salesforce首席科学家、斯坦福最佳博士论文获得者，其学术背景和技术愿景在当前的AI人才市场中属于极度稀缺资源。类似地，从DeepMind和OpenAI出走创业的研究员在过去两年形成了明显的创业浪潮。对一级市场投资者而言，这类项目的"人溢价"是否合理，取决于能否在6-12个月内兑现产品里程碑，否则将面临严峻的估值回调压力。
段永平建仓CoreWeave：逆向投资还是价值陷阱？
段永平在CoreWeave股价接近腰斩时买入约2000万美元。CoreWeave的叙事极其矛盾：一边是最"刚需"的GPU算力供应商，手握994亿美元RPO；另一边是毛利率仅4.28%、亏损持续扩大的财务现实。段永平的投资逻辑可能基于"卖铲人"的长期确定性——无论哪家AI公司胜出，算力需求都将持续增长。但风险在于：如果AI资本开支周期见顶回落，或者云厂商自建芯片降低对第三方算力的依赖，CoreWeave的高杠杆模式将面临严峻考验。
