2025年8月 · 聚焦：AI 模型价格战、推理基础设施、Agent 经济与企业落地

1. 市场概览

  • 模型发布Anthropic 推出 Claude Sonnet 5 并开启 aggressively 定价。 新模型在编码、Agent 和长上下文任务上达到接近 Opus 的水平，限时定价为 $2 / M input、$10 / M output，标准价为 $3 / $15。它已上线 AWS Bedrock、Vercel AI Gateway 并成为 Claude 免费/Pro 版默认模型，标志着 Anthropic 正用性价比+多云分发抢占企业市场份额。
    来源：Vercel News；AWS Blog；Claude 官方 X
  • 产品迭代Google Gemini 企业 Agent 平台加入 Nano Banana 2 Lite 与 Gemini Omni Flash。 Nano Banana 2 Lite 主打最快、最省成本的图像生成与编辑，Omni Flash 则进入高质量视频生成与对话式内容预览。Google 正在用多模态+成本效率组合强化企业 Agent 工作流，直接对标广告、社交媒体与创意 SaaS 场景。
    来源：Google Cloud Blog
  • 大额融资Etched 结束隐身模式，融资 $8 亿、手握超 $10 亿客户合同。 公司推出专为 Transformer 推理从头设计的芯片/系统，声称在吞吐量、延迟与能效上达到 SOTA，首批机柜今夏发货。巨额融资与预订单并存，意味着推理 ASIC 赛道正进入商业化冲刺阶段，但交付与模型架构风险仍是核心变量。
    来源：Amjad Masad X

    来源：elvis X；Paul Couvert X

    来源：Aravind Srinivas X
  • 数据库Google 以 AlloyDB Omni 切入金融核心数据库替换市场。 该产品强调部署自由、亚毫秒级交易延迟与合规安全，旨在帮助金融机构摆脱传统商业数据库的授权陷阱与技术债务。全球大型投行往往将 70% 以上 IT 预算用于维护旧数据库，市场空间可观但替换周期长、销售门槛高。
    来源：Google Cloud Blog
  • 方法论Andrew Ng 提出 "Loop Engineering" 成为 Agent 软件开发的关键范式。 Agent 通过循环迭代（编码、测试、修正）完成 0-到-1 产品，被视为提升软件构建效率的新组织方式。该趋势利好 Agent IDE、自动化测试与评估基础设施，但也意味着单纯模型层的差异化正在收窄。
    来源：Andrew Ng X

2. 深度投资分析

2.1 Claude Sonnet 5：定价战下的企业 AI 分发竞赛

Anthropic 将 Sonnet 5 的限时输出价格压至 $10 / M tokens，标准价也仅为 $15 / M，同时把模型能力推到原先需要 Opus 才能完成的任务区间。这一"越级定价"既是对 OpenAI 与 Google 的防御，也反映出 Anthropic 急需扩大企业 ARR 与市场份额。

投资看点： 同步上线 AWS Bedrock、Vercel AI Gateway 与 Claude Platform，显示其"模型即服务"的多云分发策略已成型。对 Vercel 与 AWS 而言，它们成为模型流量的聚合层，议价能力提升；对 Anthropic 而言，渠道分散有助于获客，但毛利承压。

风险： 若输出 token 价格持续下降，API 业务的毛利率将快速收窄。Anthropic 必须依靠企业订阅（Team/Enterprise）和 Claude Platform 高溢价服务来拉高客单价。建议关注其企业客户数、平均合同金额与 AWS Marketplace 分成比例。

2.2 Etched：$8 亿融资与推理 ASIC 的资本豪赌

Etched 以 $10 亿+ 客户合同和首批机柜即将出货亮相，核心卖点是从硅片到模型全栈为 Transformer 推理优化。这与 SemiAnalysis 提出的"软硬件协同设计带来 100x 收益"逻辑一致，也契合当前推理成本每年约 60% 下降的行业预期。

投资看点： 若早期客户测试数据属实，Etched 有望在大型 AI 公司推理集群中切走显著份额，商业模式大概率是整机柜/芯片销售+可能的云服务。$8 亿融资规模意味着估值已进入独角兽后段，需要强劲收入兑现。

风险： 模型架构快速演进（MoE、多模态、非 Transformer 架构）可能削弱专用芯片优势；此外，NVIDIA 生态护城河、台积电产能、客户集中度和交付能力都是关键风险。建议将其视为高贝塔的 AI 基础设施押注，关注合同转化率和毛利率。

3. 赛道雷达

  • Agent 支付与工具市场： x402 + Apify 的 2 万工具目录，让 Agent 可以无摩擦地按需购买服务。赛道尚处早期，但支付协议、工具发现与信任机制是构建 Agent 经济的必要组件。
  • AI 软硬件协同设计： 从 Etched 到 SemiAnalysis 的 InferenceX，行业共识是单纯买卡不如全栈优化。投资机会在编译器/内核、模型压缩、测试基准与异构调度层。
  • 企业 AI 从"团队自动化"转向"个人赋能"： Anthropic 产品负责人强调先让个体员工成为"一人创业公司"。这意味着面向单点效率的 AI 助手、低代码 Agent 和垂直场景插件更易落地。

4. 估值观察

推理成本曲线： 模型能力等价下的推理成本正以每年约 60% 幅度下降，专用推理芯片和大模型厂商的主动降价共同压低行业整体价格中枢。对投资者而言，"单位智能成本"的下降意味着规模效应和效率优势将成为估值核心，而非单纯收入增速。

私募数据民主化： Perplexity 免费集成 Forge 私募数据，降低了非专业用户获取一级市场信息的门槛。传统数据供应商（如 PitchBook、Crunchbase 高级版）可能面临定价压力，而 Perplexity 的差异化则增强。

云厂商模型托管的边际化： AWS managed entitlements 让模型访问更像水电煤，模型层被进一步 commoditize。未来溢价将流向编排层、安全/合规层、行业 workflow 与数据飞轮，而非单纯的 API 转售。
