2深度投资分析

深度一：OpenAI 的 1.2 万亿估值、推迟的 IPO 与一张 1 万亿美元的算力账单

一级市场估值上修 vs 资本开支刚性——超级实验室的"融资—算力"飞轮还能转多久

事件

OpenAI 就新一轮融资与投资者初步接触，估值或达 1.2 万亿美元；同时把原定年底的 IPO 推迟到明年或更晚，理由指向 AI 安全担忧。竞对 Anthropic 的 IPO 预期估值达 1.5 万亿美元以上。

关键数据

  • 上一轮（2026 年 3 月）：1220 亿美元融资，估值 8520 亿美元；本轮传闻估值隐含约 41% 的环比上修。
  • 二级市场：Caplight 追踪显示其估值已破 1 万亿美元，驱动力是 Codex 编程产品人气与 GPT-6 Astra 的模型表现。
  • 算力账单：据 Oguz Erkan 统计，Anthropic 已宣布算力容量超 11.5GW，但实际运行估算仅 1–2GW；全部建成后每年或花费 1150–1200 亿美元。若 OpenAI 按类似规模扩张，两家未来五年算力支出可能合计达 1 万亿美元。

投资视角

这组数字揭示了一个核心矛盾：估值上修的动力来自"产品与模型表现的边际改善"（Codex、GPT-6），而非收入结构的质变；而资本开支却是刚性且前置的。11.5GW 已宣布与 1–2GW 实际运行之间的缺口，意味着大量已签署的算力承诺尚未转化为折旧，一旦转化，利润率修复的窗口会被进一步压缩。IPO 推迟在短期对一级投资人并非坏消息——它把流动性事件后移，避免了在安全舆论高位定价；但对二级市场而言，Anthropic 1.5 万亿美元级别的 IPO 一旦落地，将成为整个 AI 板块的定价锚，届时 OpenAI 的一级估值能否守住 1.2 万亿，取决于其能否在 IPO 前把 Codex 这类"可计费、可复购"的产品收入做成可验证的曲线。

判断：短期看好模型公司的一级估值惯性，但需警惕"估值上修由产品叙事驱动、成本由资本开支驱动"的错配。跟踪指标应锁定两个——实际运行算力/GW 转化率与企业级 API 与订阅收入的季度斜率，而非模型跑分。

深度二：国产 GPU 的估值逻辑崩塌——收入增长 162%，股价却腰斩

"稀缺性溢价"消失与解禁抛压，如何压倒基本面

事件

7 月至今国产 GPU 集体腰斩，沐曦、天数智芯最大回撤 55%/64%，跌后无有效反弹；同期中际旭创、新易盛、胜宏科技及港股 MiniMax 均有 9%–27% 的修复。

关键数据

  • 基本面：2026 上半年四家国产 GPU 合计收入 52.42 亿元，同比增长约 162%；最慢的沐曦增速 44.7%。
  • 供给端：不到一年时间，公开市场从"几乎无纯国产 GPU 标的"变为五家可选，标的稀缺性快速稀释。
  • 筹码端：沐曦网下配售、战略配售及部分首发前股份陆续解禁；天数智芯基石投资者锁定期于今年下半年先后结束。

投资视角

这不是一次"错杀"，而是估值范式的切换。国产 GPU 此前的高估值包含两层溢价：一是标的稀缺性溢价（可投资的纯正标的极少），二是国产替代的确定性与想象空间溢价。前者随供给放量直接被抹平，后者则因"规模不足以摊薄研发、利润跑不出来"而迟迟无法兑现。收入的 162% 增长证明需求真实存在，但需求增长不等于股东回报——在重研发投入、尚未形成规模效应的阶段，收入增长反而可能伴随亏损扩大。解禁节奏则是压垮情绪的最后一根稻草：当锁定期结束遇上估值范式切换，卖方结构与买方叙事同时转向，反弹缺乏承接力量。

判断：国产 GPU 已从"主题成长"切换到"制造业 + 半导体周期"的估值框架，需用 PS、毛利率、研发费用率而非国产替代叙事来定价。真正的买点信号不是股价企稳，而是单季度毛利率环比转正 + 研发费用率见顶回落。短期内规避解禁密集窗口。

3赛道雷达

赛道一：推理专用芯片——Groq、Cerebras 与 OpenAI 的三条路径

硅谷 101 的复盘给出了这个赛道最完整的估值坐标：去年年底英伟达以约 200 亿美元对 Groq 进行"acqui-hire"；做晶圆级大芯片的 Cerebras 于今年 6 月 IPO，市值达 670 亿美元；OpenAI 联手博通推出首款自研推理芯片 Jalapeño，从设计到流片仅用 9 个月；再叠加谷歌 TPU，牌桌上的玩家迅速增多。赛道分化的核心是技术路线取舍——Groq 走 SRAM 加确定性静态编译调度（动态性不足），Cerebras 押注晶圆级大芯片（软肋是良率、成本与系统适配），OpenAI 则用 ASIC 自研绑定自身模型。真正的投资变量是"训练看算力、推理看带宽"这一结构性差异，以及"推理时代 CUDA 是否会被绕过"的长期命题。当 Token 经济成型、推理消耗爆炸式增长，专用推理芯片的性价比曲线若持续逼近通用 GPU，价值链将从英伟达向推理 ASIC 与自研芯片公司分流。

📎 来源：硅谷 101 E251

赛道二：递归自我改进（RSI）——几个月内涌入资本超 17 亿美元

深思圈梳理了这条今年最热的资本赛道：4 月 AlphaGo 之父 David Silver 的新公司 Ineffable Intelligence 拿到 11 亿美元种子轮（欧洲史上最大）；5 月一家名为 Recursive Superintelligence 的公司融资 6.5 亿美元、估值 46.5 亿美元，由 GV 与 Greycroft 领投，团队包含前 Meta FAIR 研究总监田渊栋；再加上 Sakana AI、Periodic Labs，RSI 方向几个月内涌入资本超 17 亿美元。投资逻辑是"让 AI 自己做 AI 研究"带来的指数级复利；但文章指出的核心风险同样致命——AI 交出的实验报告结论能否被信任（数据造假、空结果穿透、约 38.9% 的迭代方向被判错）。这是一个典型的"愿景定价远超可验证产出"的赛道，估值难点在于既无成熟收入、也无公认评测标准，投资人实际上是在赌团队与研究方向，而非可证伪的里程碑。

赛道三：AI 原生企业软件与 FDE 交付模式

两条信号值得并列观察。其一是 a16z 与 Lightfield 的对谈：创始人 Keith Peiris 曾把 Tome 做到 2500 万用户，随后因底层技术无法充分捕捉演示者、受众及其关系上下文而主动放弃该产品，转而切入销售工作流，试图用 "business world model" 统一企业分散且互相冲突的邮件、通话与 CRM 数据——a16z 的判断是下一代企业软件"看起来完全不像 Salesforce"。其二是宝玉总结的 Anthropic 工程师 FDE（前线部署工程师）分享：在上市 SaaS 公司中按平均合同金额排序，Palantir 达 400 万美元，ServiceNow 120 万、Workday 60 万，其余均不超过 50 万；Palantir 靠几千人做到别人几万人做不到的客单价，靠的正是 FDE 模式——在可复用平台上为客户"建出结果"，而非从零写定制代码（那是外包开发）。两条信号指向同一结论：AI 时代企业软件的护城河正从"功能与席位"转向"数据上下文加交付能力"，能同时拿下高客单价与可复用平台的团队，是这一轮一级市场最值得下注的形态。

📎 来源：a16z · 宝玉（X）

赛道四：AI Agent 的"信任基础设施"与保险——AIUC 完成 4000 万美元 A 轮

Latent.Space 披露，AIUC 宣布完成 4000 万美元 A 轮融资，其核心产品 AIUC-1 是一套由真实保险承保的 Agent 标准。创始人 Rune Kvist 曾任 Anthropic 首位产品岗位员工，其判断是：限制 AI 落地的最大约束不是能力，而是信任——当 Cursor、Harvey、Lovable、ElevenLabs 这类公司部署的自主系统出错时，责任归属会随模型变强而愈发难以界定。这条赛道代表了一种新颖的变现结构：不做模型、不做应用，而是做"可被追责（agents you can sue）"的标准与保险层，通过与前沿实验室和下游应用方的双向绑定收取"信任税"。在企业采购日趋合规化的背景下，这类基础设施的位置类似于云时代的审计与合规服务，具备长期复利属性，但短期规模受制于保险精算数据的积累速度。

📎 来源：Latent.Space

赛道五：算力成本下降带来的应用层套利——SeaVerse 基础设施成本降 60%

Google Cloud 博客披露，SeaArt 旗下游戏创业公司 SeaVerse 在采用 GKE 与 GKE Agent Sandbox 后，基础设施成本最高降低 60%。SeaVerse 构建的是"可玩 AI 体验"平台，用户可打开轻量游戏、角色对话、交互应用，或从一句提示词创建自己的体验；其技术难点在于需要运行动态、多租户、强隔离、低延迟且成本弹性的沙箱负载。这个案例的价值不在于单点降本，而在于验证了纳德拉同时期提出的判断——随着模型竞争加剧与 Token 成本下降，应用层（尤其嵌入企业 Workflow、具备 Memory 与 Orchestration 能力的应用）会获得更大的价值空间。对投资人而言，这是一个可量化的"应用层毛利改善"证据：当基础设施成本下降 60%，原本被推理成本吞噬的毛利结构会显著重估。

4估值观察

观察一：价值分配正在从模型层向应用层迁移

微软 CEO 纳德拉在 All-In Summit 2026 给出了一个对创业公司和投资人最直接的判断：模型层不会长期拿走 AI 产品创造的全部经济价值。他指出，本轮 AI 产业的大量价值集中在 Foundation Model、GPU 和云基础设施，但这种结构正在变化——如果一个 AI 产品创造的大部分收入最终都要交给模型层，AI 应用公司很难留下足够毛利；随着开源模型持续提供替代方案、Token 成本下降，Memory、Harness、Orchestration 以及真正嵌入企业 Workflow 的应用将获得更大价值空间。他还判断当前存在明显的 "massive model overhang"：模型能力已经跑在产品和企业落地前面。这一观点对估值方法论的含义是：给"模型公司"的溢价应逐步让渡给"能把模型能力转化为可复购企业收入"的公司，应用层公司的估值倍数存在系统性重估空间。

📎 来源：有新 Newin

观察二：算力资本开支是横在"减速叙事"前的硬约束

针对 Anthropic 等公司呼吁为前沿 AI"踩刹车"的叙事，AI Will 引述 Oguz Erkan 的统计给出了一个会计层面的反驳：Anthropic 已宣布算力容量超 11.5GW，实际运行仅 1–2GW，全部建成后每年或花费 1150–1200 亿美元；若 OpenAI 按类似规模扩张，两家未来五年算力支出可能达 1 万亿美元。这意味着"模型公司想减速"在财务上并非自由选择——已签署的算力承诺会转化为刚性折旧，收入增速一旦跟不上，自由现金流将承受巨大压力。对估值的直接影响是：用"长期利润率"给这些公司定价时，必须把这一量级的资本开支与折旧纳入模型，而非只按软件公司的边际成本假设外推。

📎 来源：AI Will @FinanceYF5（X）

观察三：二级市场的"数据入口"正在发出早期信号

一条容易被忽略但很有意思的指标：OpenRouter 上周出现两年半未见的反转——用户花在 OpenAI 模型上的钱超过了 Anthropic。虽然这只是平台用户支出结构的变化、并非整个 AI 市场的份额变化，但作为一个高频、可观测的"开发者用脚投票"指标，它对模型公司的收入斜率具有领先性。结合 OpenAI 二级市场估值破 1 万亿、GPT-6 Astra 与 Codex 的产品周期，以及同期传闻的 Opus 5.2 与 GPT-6 Sol 同时灰测，可以判断模型层竞争在 9 月进入了新一轮密集发布期。对于持有模型公司敞口的投资人，OpenRouter 这类第三方支出数据比官方跑分更适合作为估值上修的验证依据。

📎 来源：AI Will @FinanceYF5（X） · 硅星人 Pro

观察四：本轮 AI 一级估值的三种定价范式并存

把今日的融资事件放在一起，可以清楚看到三种截然不同的定价逻辑同时存在。第一类是"收入验证型"：Profound（D 轮 1.8 亿美元 / 估值 18 亿美元）、富勒科技（3.5 亿元 B 轮）、信诺维（206 亿元市值），估值与可验证收入或现金流强相关，其中信诺维靠 License-out 的 9.27 亿元授权收入实现扭亏，是 Biotech 估值范式迁移的最佳注脚。第二类是"产品叙事型"：如 Arcee.ai 宣布 Series B、估值超 10 亿美元，加速下一代 Trinity 模型并扩展与 DOE 及国家实验室在 Genesis-Science-1 上的合作，估值主要由模型能力与生态位驱动。第三类是"愿景期权型"：RSI 赛道的 Ineffable Intelligence（11 亿美元种子轮）、Recursive Superintelligence（6.5 亿美元 / 估值 46.5 亿美元），以及世界模型的 World Labs（约 54 亿美元）、Decart（约 40 亿美元），在收入之前即完成定价。投资人的实际任务，是把资金分别配置到这三类不同久期、不同验证标准的资产上，而非用同一套 DCF 或 PS 倍数横向比较。
