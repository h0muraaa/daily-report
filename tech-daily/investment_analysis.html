#01 生物医药/大单授权

英矽智能牵手礼来：27.5亿美元的超级合作

港股明星企业英矽智能（Insilico Medicine）与礼来（Eli Lilly）达成了一项全球药物研发与管线授权合作，交易总价值高达27.5亿美元，其中首付款达1.15亿美元。这是一笔业内少见的超高起点大单，标志着头部跨国药企对AI驱动的新药研发管线的强烈认可，也极大提振了AI制药赛道的估值逻辑。

交易总额27.5亿美元，首付1.15亿美元 | 反映AI制药标的的价值正在兑现
#02 AI应用/独角兽上市

德适生物港股IPO：医学影像大模型第一股

基于AI分析染色体的杭州德适生物科技成功在港交所主板上市，被称为“医学影像大模型第一股”，目前市值约190亿港元。这家由80后交大教授创立的企业，展示了AI在精准医疗领域的商业化潜力，也为国内医疗AI企业提供了一个极具参考价值的退出路径。

医学影像大模型第一股 | 上市市值近190亿港元 | 验证医疗AI的落地与商业化
#03 互联网大厂/AI版图

美团深度布局AI：揭秘50+被投企业版图

极客公园的深度梳理揭示了美团在AI领域的隐秘且庞大的投资版图，覆盖了超过50家科技企业。这表明国内互联网巨头不再仅仅依靠自研大模型，而是通过广撒网的股权投资与生态并购，在底层算力、具身智能到垂直行业应用中建立防线，以防在AI时代的转型中被边缘化。

超50家被投企业 | 覆盖底层算力到垂直应用 | 大厂防御性与扩张性投资并举
#04 SaaS/AI代理平台

首个面向 Agent 的竞价广告平台 Volisphere 亮相

随着 AI Agent 的爆发，专注于连接和推广 Agent 的平台级产品开始出现。Volisphere 致力于建立一个“Agent Economy”（智能体经济），被业内视作具有 AppLovin 潜力的早期产品。它意味着 Agent 赛道正在从“如何制造智能体”向“如何分发和变现智能体”演进。

填补 Agent 商业化分发空白 | “Agent 经济”基础设施雏形初现
#05 通用人工智能战略

昆仑万维确立2026 AGI战略，主打AIGC创作生态

在三大模态模型全部登顶后，昆仑万维正式披露了其2026年AGI战略，核心是构建超级AIGC创作生态。区别于单纯拼大模型参数，昆仑万维利用其在游戏、出海等领域的已有优势，试图通过C端应用的直接变现来反哺模型训练，这种“以战养战”的商业模式在当前烧钱的AI赛道中显得较为务实。

三大SOTA模型加持 | 聚焦超级AIGC创作生态 | C端商业化反哺研发
#06 大模型/行业洗牌

Kimi 面临商业化与技术的双重挤压

评论文章指出 Kimi 目前的尴尬处境：曾在2024年以极高的曝光度、激进的投流和200万字长文本噱头火爆出圈，但后续面临极高的推理成本（实验模型单次调用成本近3位数）和技术商业化的难题。在 DeepSeek 等以超低成本和顶尖性能突围的背景下，缺乏造血能力和技术护城河的初创大模型公司正面临严峻的估值调整压力。

初创大模型面临商业模式考验 | 烧钱投流模式不可持续 | 技术与成本的平衡成为生死线
#07 软件行业洗牌

AI 正在“杀死”哪些传统软件？

行业分析指出，2026年AI正在加速冲击传统软件业。特别是通用功能型软件（容易被AI直接内化为系统功能）和轻交互型工具（将直接被自然语言界面替代）面临最大风险。然而，拥有深厚垂直数据壁垒的专业软件以及社交网络依然具备较强的抗风险能力，这是 SaaS 赛道投资人必须高度关注的赛道重估逻辑。

轻交互工具类软件价值大幅缩水 | 数据壁垒成为软件公司的最后护城河
#08 人才流动/具身智能

前理想智驾端到端负责人夏中谱加入“无界动力”

前理想汽车智能驾驶端到端负责人夏中谱正式出任通用具身智能公司无界动力的联合创始人兼联席CTO。这一人员变动标志着顶级自动驾驶人才正在向具身智能领域溢出。智驾领域跑通的“数据驱动+端到端”商业与技术经验，正被迅速复制到机器人赛道，提高了具身智能初创企业的技术落地确定性。

智驾顶尖人才流向具身智能 | “智驾经验”赋能机器人商业化 | 具身智能团队配置升级

🔍 深度分析

Deep Analysis - 核心事件与商业逻辑

英矽智能与礼来 27.5 亿美元合作 医疗健康/AI制药

事件简述：英矽智能（Insilico Medicine）宣布与全球制药巨头礼来达成总价值达27.5亿美元的合作，其中首付款达1.15亿美元。

投资逻辑与行业影响：
  • 这笔交易验证了生成式AI在突破性药物分子设计中的实际价值，尤其是在难度极高的靶点上。
  • 高额首付款（1.15亿美元）不仅极大改善了初创企业的现金流，也确立了目前 AI 制药授权交易的新基准估值。
  • 反映出传统跨国药企（MNC）不再满足于小打小闹的技术测试，而是愿意为极具潜力的 AI 发现管线支付巨额溢价，以应对专利悬崖。
市场潜力：随着 AI 发现的分子逐渐进入临床中后期甚至获批，AI 制药板块（TechBio）的整体估值中枢有望迎来系统性重估。
风险提示：新药研发风险极高，后续里程碑付款能否兑现完全取决于临床数据；AI 制药公司如果只有技术平台而无成功管线，依然面临变现难题。

Kimi 的商业困局与大模型赛道大洗牌 AI大模型/软件与SaaS

事件简述：市场声音开始重新评估 Kimi 等国内明星大模型创业公司的估值逻辑，认为其高成本的增长策略难以持续，且面临技术路线被颠覆的风险。

投资逻辑与行业影响：
  • 以“长文本”、“营销投流”驱动用户增长的模式已被证明是不经济的。实验性模型的高昂推理成本严重拖累了公司的现金流与商业化进程。
  • DeepSeek 的低成本、高性能路径（如 V3/R1）直接摧毁了“大力出奇迹”的护城河，资本对无节制烧钱算力的容忍度降至冰点。
  • 大模型创业公司必须迅速转向应用层变现（To C 订阅或 To B 垂直解决方案），否则将面临严重的流动性危机与 Down-round 风险。
市场潜力：基础大模型正在加速成为“水电煤”一样的廉价基础设施。能在此基础上构建高价值工作流和Agent的企业将捕获最大商业价值。
风险提示：基础模型公司估值可能出现大规模泡沫破裂；缺乏自有场景的模型企业生存率极低。

Agent 经济的基础设施：Volisphere SaaS与商业服务/AI Agent

事件简述：出现首个面向 AI Agent 的竞价广告与分发平台 Volisphere，预示着 Agent 的商业化网络正在成型。

投资逻辑与行业影响：
  • 当 Agent 成为新的交互端点时，旧的流量分发逻辑（如应用商店、搜索引擎）将失效。Volisphere 试图成为“机器与机器交互”时代的流量入口。
  • 这标志着 AI 应用的投资主题从“如何打造更好的 Agent（生产工具）”转移到了“Agent 如何发现彼此并进行价值交换（商业网络）”。
  • 如果该模式跑通，将诞生 AI 时代的 AppLovin 或 Google Ads，这是极其稀缺的平台级投资机会。
市场潜力：自主 Agent 之间的交易和流量分发是一个全新的空白市场，有望催生百亿美元级别的广告和网络中间件巨头。
风险提示：过早进入可能成为先烈；高度依赖底层大模型平台（如 OpenAI, Anthropic）的生态开放程度。

💡 估值观察与明日看点

估值观察：SaaS 赛道面临“AI侵蚀折价”

随着 AI 的内化能力增强，那些仅仅依靠简单工作流拼接和轻量级交互起家的 SaaS 工具，其在一级市场的估值模型正在失效。投资人目前倾向于给予这类企业显著的“AI侵蚀折价”。相反，拥有独家行业数据、深厚合规壁垒（如医疗、金融垂直领域）的软件公司，将获得防守性溢价。

赛道转移：从“大模型”到“具身智能”

夏中谱等顶级自动驾驶专家的流向明确指出了资金和人才的新去处——具身智能。自动驾驶本质上是轮式机器人的具身智能，这一领域积累的端到端数据驱动经验，正在被套利到更广泛的机器人赛道中。预计 2026 年具身智能初创公司的首轮估值将水涨船高。
