根据睿兽分析监测，本周国内一级市场共披露 115 起融资事件，其中已披露金额的 55 起总融资规模为 640.81 亿元人民币，平均单起 11.65 亿元；人工智能赛道以 30 起事件、约 583.71 亿元融资规模遥遥领先，而 DeepSeek 一家即占据近 510 亿元。

作为幻方量化孵化的前沿大模型公司，DeepSeek 自 2025 年初发布 DeepSeek-R1 以来，以“低成本、高性能、开源权重”的策略迅速打开全球市场。这笔 A 轮不仅刷新了近期一级市场的单笔记录，也意味着资本对“开源模型+算力效率”路径的押注正在升温。对投资者而言，需要关注其后续估值、收入转化能力，以及在美国出口管制背景下的算力可持续性。

Anthropic Fable 5 / Mythos 5 在 AWS Bedrock 要求共享推理数据，出口管制再添变数

InfoQ 报道，在 Amazon Bedrock 上使用 Claude Fable 5 或 Mythos 5 需选择 provider_data_share，即 Anthropic 可保留用户 prompt 与输出 30 天并可能进行人工审核；这与此前 Bedrock 模型数据不出 AWS 边界的做法形成鲜明对比。更早前，Anthropic 以美国出口管制为由，要求 AWS 撤销对这两款模型的访问权限。

估值观察

资本开支周期与回报焦虑：高盛 5.3 万亿美元的 hyperscaler 资本开支预测，意味着 AI 基础设施投资已进入前所未有的重资产阶段。若 AI 应用收入无法在未来 3–5 年内产生足够现金流，资本回报率（ROIC）将显著下降，相关数据中心、电力、网络设备公司的估值需从“成长溢价”切换至“周期股”逻辑。

开源模型对闭源 API 估值的挤压：DeepSeek、GLM 5.2 等开源/开放权重模型以更低成本逼近闭源模型性能，将压缩纯模型 API 的定价权与毛利率。投资者应为闭源模型公司设置更严苛的盈利路径假设，同时关注在推理优化、私有化部署、垂直微调上具备差异化能力的厂商。

商业化信号与组织风险并存：Anthropic Cowork 翻倍、Skywork 3.0 收入三倍增长、Waniwani 800 万美元种子轮，均显示 AI 应用层开始出现正向商业信号；但 Meta 的工程文化危机提示，“AI 优先”若以牺牲组织健康为代价，可能反噬估值。建议在模型能力、收入质量、组织执行力三个维度上综合估值。
