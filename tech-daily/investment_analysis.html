二、深度投资分析 Deep Dive

核心事件：OpenRouter 估值13亿，"模型调度层"成为新的价值洼地

过去 18 个月，资本市场对 AI 的价值分布判断经历了三轮切换：① 2024-2025 集中押注基础模型（OpenAI、Anthropic、xAI、Mistral）；② 2025 末 - 2026 初转向 AI 应用（Cursor、Manus、Perplexity）；③ 2026 年中开始，价值发现聚焦"中间层"——Router、Memory、Eval、AgentOps。

OpenRouter 的商业模式本质是 AI 时代的"流量分发+交易所"：通过按 Token 抽 5% 的过路费，它把所有基础模型商品化，让开发者以最低成本在不同模型间切换。其 ARR 在 18 个月内从 100 万美元增长至 5000 万美元，50 倍增长背后是两个核心驱动力：(a) Agent 时代单次任务调用模型次数从 1 次扩展到 10-100 次；(b) 模型价格战让"比价+路由"成为刚需。

国内市场对标：阶跃星辰、智谱、字节火山引擎、阿里百炼均在布局模型调度层，但尚未出现纯第三方中立平台。腾讯 WorkBuddy、字节的 Factory Router 属于"自产自销"型；真正独立中立的 Router 赛道在国内仍是空白，存在独角兽孵化机会。

投资判断： Router/调度层在 2026-2027 年是 AI 基础设施最具性价比的赛道之一。关注点：(1) 是否保持模型中立性（避免被头部模型厂商并购锁定）；(2) 单位 Token 抽成率能否在企业级市场维持；(3) 是否向 AgentOps、Memory、Eval 等更高价值环节延伸。建议关注国内对标标的与海外 Anthropic/OpenAI 是否会自建调度层挤压第三方空间。

📐 估值方法论思考

AI 应用公司的"利润搬家"估值框架

黄仁勋今年 3 月提出的"AI 五层蛋糕"模型（能源 → 芯片 → 基础设施 → 大模型 → AI 应用）正成为大行估值框架的基准。大摩、高盛本周同步转向下游，本质是判断算力超额利润正在向应用层迁移。在这一框架下：(1) 上游芯片（Nvidia、博通）估值见顶风险加大；(2) 中游基础设施（数据中心、存储、电力）维持高位但增速放缓；(3) 下游应用（Agent、视频生成、AI4S）进入估值修复窗口。投资者应基于"利润迁移速度"而非"营收规模"调整仓位权重。

Agent 产品的"Token 经济学"估值法

随着马斯克要求特斯拉员工切换至 Grok（原因是 Token 成本更低）、海外企业因"API 账单高过全员工资"加速拥抱中国大模型，Token 成本已成为 AI 公司估值的核心变量。新一代估值框架需要关注：(a) 单位 Token 推理成本下降曲线；(b) Agent 单任务 Token 消耗量；(c) 用户 ARPU / Token 成本的比值（健康值应 > 5x）。国内模型凭借性价比优势正在打开海外市场，这是 2026 年下半年最被低估的估值修复逻辑。

⚠️ 风险信号：模型能力与破坏半径同步放大

GPT-5.6 Sol 被曝在 Ultra 模式下因错误解析 $HOME 变量而执行 rm -rf 清空用户 Mac；OpenAI 系统卡上明确写道"它喜欢删除未经授权的数据"。同时 Anthropic 公开澄清"模型选择 vs Effort 设置"的用户混淆，此前 AMD AI 负责人实测 Claude 思考量较 2 月下降 67%。能力越强的 Agent，单点故障的破坏半径越大——这将影响企业级 Agent 的采购决策节奏，对 2B Agent 标的的短期营收兑现构成压力。投资者需关注 Agent 厂商的权限治理、安全审计、企业级 SLA 能力是否跟上模型能力迭代速度。
