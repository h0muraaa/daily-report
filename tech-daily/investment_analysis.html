DeepSeek 启动第二轮融资：估值 710 亿美元，最快今年底申报 IPO

IPO 筹备

据彭博社与金融时报报道，DeepSeek 本周开始与投资者初步接触，洽谈以约 710 亿美元（约 4806 亿元人民币）投前估值再融资 15 亿美元，较 6 月初首轮 520 亿美元估值单月上涨 37%。同时公司已启动 IPO 筹备，规划在内地上市，最快今年底提交申请，2027 年完成挂牌；目前正与会计师事务所合作，目标 12 月底前完成财务报告。IPO 前还计划在私募市场至少再融资 100 亿元人民币，最终规模可能数倍于此。

首轮 70 亿美元融资结构堪称"国家队+产业资本"组合：梁文锋个人出资 200 亿元（最大单一股东）、腾讯 100 亿元、宁德时代 50 亿元、京东/网易/IDG 各 30 亿元，国家人工智能产业投资基金出资 10 亿元且不受股权锁定期约束并享有投票权——这一条款在国产 AI 公司融资中较为罕见，凸显其战略地位。

梁文锋个人净资产随之升至 360 亿美元，超越 Anthropic CEO Dario Amodei（约 155 亿美元）与 OpenAI 总裁 Greg Brockman（约 280 亿美元），成为全球 AI 模型创始人首富，并跻身中国第八大富豪。本轮募资主要投向自有数据中心建设、AI 芯片采购、研究团队扩充及 Agent 产品开发。

Emergent Labs 完成 1.3 亿美元 C 轮，估值 15 亿美元，ARR 4 个月 +70%

Series C

YC 孵化的 AI 全栈开发平台 Emergent Labs 宣布完成 $130M Series C，估值 $1.5B。核心数据：平台累计构建应用超 1200 万个，付费客户突破 20 万，年化收入（ARR）达 $1.2 亿，过去 4 个月增长 70%。创始人 Mukund Jha 与 Madhav Jha 兄弟将其定位为"商业操作系统"——让非技术背景的业务方把"工作方式"直接转化为软件。

典型案例：一位餐饮备餐创始人用 Emergent 自建了库存与运营平台，传统外包成本约 $200K 的产品以约 $10K 落地。投资逻辑：vibe coding 赛道正从"工具"演化为"业务入口"，Emergent 的客户结构（中小企业主而非开发者）与 Lovable、Replit 形成差异化，ARR 增速显著快于同阶段 SaaS 基准，但需警惕 OpenAI/Anthropic 自研 Agent 编码产品对长尾场景的下探挤压。

Granola 完成 $125M C 轮，估值 $1.5B：会议记录是入口，工作流才是终局

Series C

AI 会议记录工具 Granola 宣布完成 $125M Series C，估值 $1.5B。创始人 Chris Pedregal 在访谈中明确表示：会议记录只是入口，真正的竞争在于"AI 原生时代的工作界面"。面对 Notion、OpenAI、Zoom 相继推出同类功能，Granola 选择纵向扩展至会前准备、会后执行与跨会议上下文管理。

投资视角：单点 AI 工具在基础模型能力普惠化后迅速贬值， Granola 的护城河取决于能否把"会议上下文"沉淀为跨应用的私有数据资产。$1.5B 估值对应 ARR 倍数估计在 30-50x 区间，处于 AI 应用层合理偏上水平，关键在于 12 个月内能否把"记录工具"重塑为"工作流平台"。

Series B

Meta 追加 $40B 扩建路易斯安那园区，算力规模翻倍至 5GW

Capex 扩张

Meta 周一宣布再投资 $40B，将路易斯安那州数据中心的规划算力从 2024 年最初宣布的 2GW 提升至 5GW（约为传统数据中心功耗的 100 倍）。该园区累计投入已超 $50B，成为 Meta 最大计算设施，项目从 Blue Owl Capital 等机构获得外部融资，配套 Entergy Louisiana 将建设七座天然气电厂供电。

扎克伯格此前承诺未来几年为 AI 基础设施投入"数千亿美元"。投资视角：超大厂 Capex 军备竞赛仍在加速，5GW 单一园区已接近中型城市级别的电力负载。对上游 ASML/台积电/SK 海力士、中游 Lambda/Crusoe 等 GPU 云、下游能源基建（燃气、核电、电网）均构成持续利好；但需警惕 2027 年若 AI 应用端 ARR 增速跟不上 Capex 折旧，可能出现类似 2000 年光纤泡沫的局部回调。

02深度投资分析

深度一：DeepSeek 的 $71B 估值与"国产 OpenAI"的资本范式

核心判断：DeepSeek 的估值跃升不是单一公司的胜利，而是中国 AI 资产定价范式从"折价追赶者"切换到"平价竞争者"的标志性事件。一级市场愿意为其付出 37% 的月度涨幅，本质是对"中国模型进入全球第一梯队"这一事实的追认。

▎事件复盘

从 4 月首次传出融资时约 $10B 估值，到 6 月初首轮交割的 $52B，再到当前谈判中的 $71B，DeepSeek 的估值在 90 天内上涨 7 倍。同期对照：Anthropic 最近一轮 $61.5B（2025 年 3 月）、xAI $80B（2025 年 3 月，X 合并口径）、OpenAI $300B（2025 年 3 月）。DeepSeek 已跻身全球 AI 模型公司估值第二梯队头部。

▎估值锚定：为什么 710 亿美元不算贵

  • 对标 OpenAI 的效率比：OpenAI 2025 年 Capex 超 $80B，DeepSeek 以显著更小的资本消耗达成同级模型能力，"单位智能成本"远低。若市场认可 OpenAI $300B 估值，给 DeepSeek $71B 意味着 23.7% 的"效率折价"——考虑到中国市场规模与监管折价，这一比例并不算激进。
  • 商业化已现轮廓：Vercel AI Gateway 6 月处理的数万亿 token 中，DeepSeek 系列模型占据重要份额；Agent 产品 V4 即将推出，订阅+API 双线变现路径清晰。
  • 战略稀缺性：国家 AI 产业基金出资且享有投票权的条款，意味着 DeepSeek 已被定位为"国家 AI 战略资产"，这一身份本身即构成估值底仓。

▎股权结构看点

梁文锋个人 200 亿元（约 $28 亿）加注成为最大单一出资方，这是中国 AI 创业史上罕见的"创始人反向加注"案例。梁的净资产从 $16.7B 升至 $36B，一年内身家翻倍，超过 Dario Amodei 与 Greg Brockman 的总和。这一结构既向市场传递创始人长期投入信号，也使 DeepSeek 在 IPO 前保持相对干净的股权结构，避免传统 VC 多轮跟投带来的治理复杂度。

▎IPO 路径研判

内地 IPO 对 DeepSeek 而言有三重意义：（1）避免港股同股不同权架构的复杂谈判；（2）匹配国家 AI 基金等国资股东的退出需求；（3）以科创板为跳板获得 A 股 AI 稀缺标的溢价。但挑战同样明显：首次公开财报将直面市场检验，DeepSeek 长期不披露营收数据，其研发开支、芯片采购成本、模型训练折旧将成为估值再定价的关键变量。

▲ 看多逻辑：中国 AI 资产定价权重构 + 国家级战略卡位 + 高效率模型路线 + 强 IPO 预期。$71B 估值若兑现，对应 2027 年 IPO 时 $100B+ 的目标市值存在合理性。
▼ 风险点：（1）首次财报若营收/亏损数据不及市场预期，可能引发估值修正；（2）AI 芯片获取受地缘政治影响存在不确定性；（3）模型能力能否持续追赶 GPT-5.x/Claude 4.x 前沿尚存变量；（4）一年内估值 +610%，新进入者的安全边际有限。

深度二：Cognition 收购 Windsurf 一周年——AI Coding 赛道最成功的并购整合样本

核心判断：Cognition 用 72 小时签约完成的 Windsurf 并购，是 AI Coding 赛道迄今最成功的"能力互补型"整合案例。一年间 ARR 从 $73M 增至 $500M+（~7x），验证了"云端 Agent + 本地 IDE"双栈策略的商业价值，也为 Cursor 的独立路径敲响警钟。

▎交易复盘：为什么是"72 小时"

2025 年 7 月，Windsurf 创始团队部分核心成员加入 Google（Antigravity 项目）后，Cognition 果断启动收购——从周五晚首次通话到周一晨签约仅 72 小时。本质逻辑是"能力互补拼图"：

  • Cognition 缺 GTM 与本地开发入口，Windsurf 缺工程组织与云端 Agent 能力；
  • Cognition 主打 Devin 云端 Agent，Windsurf 拥有百万级用户的 IDE 产品，产品零重叠；
  • 一次并购补齐"市场 + 本地入口"两块短板，把分散的 AI 编程能力收拢为完整栈。

▎战略升级：从"AI 工程师"到"自动驾驶式软件开发"

Devin 产品定位同步升级：从"初级工程师"演进为可调度其他 Devin 的"中高级工程师"。这一定位变化意义重大——AI Coding 赛道正在从"辅助人"转向"替代部分人力编制"，定价逻辑也从"席位订阅"转向"按产出计费"。Scott Wu 明确说，未来竞争对手不是 Cursor 或 GitHub Copilot，而是传统 IT 外包与咨询行业（全球市场规模 $1.5T+）。

▎对赛道的启示

  • Cursor 被传寻求出售： Cognition 整合成功使独立 IDE 厂商面临被"云 + 端"双向挤压，Anysphere 近期频频传出并购/融资传闻，顶级人才正在加入 Cursor（被坊间戏称"等下一波 SpaceX 式造富"）。
  • 估值参考点：Cognition 最新一轮估值 $10B+，对应 ARR $500M 约 20x P/S，处于 AI Coding 板块合理区间；若按 Devin Desktop 平台化逻辑演进，2027 年冲击 $2B ARR 与 $30B 估值具有可见性。
  • 对 Microsoft/GitHub 的警示：Copilot 用户增长已被 Devin/Cursor 分流，微软若不在 Agent 编码上做出更大动作，可能失去开发者入口。
▲ 看多逻辑：ARR 增速、产品整合、行业破圈三线共振。Devin Desktop 有机会成为 AI 时代的 Visual Studio——开发者操作系统的入口级资产。
▼ 风险点：（1）OpenAI Codex 与 Anthropic Claude Code 自带模型优势，可能从底层侵蚀；（2）整合团队的文化融合仍是长期变量；（3）"自动驾驶式软件开发"叙事若被证伪（如 RL 自进化达不到预期），估值弹性会快速收缩。

04估值观察 · 趋势与方法论

▎Token 经济学：AI 应用估值的新锚

Gary Marcus 引用的观点"一次 80% 的降价就能终结 OpenAI 和 Anthropic"虽有夸张，但方向正确：AI 模型的长期竞争优势不属于拥有最多算力的玩家，而属于能从每瓦电力中提取最多智能的玩家。这意味着 AI 应用公司的估值方法正在从"GMV/用户数"切换到"Token 效率（Revenue per Token / Intelligence per Watt）"。

对于一级市场，我们建议用三层指标评估 AI 应用：

  • Token 杠杆率：每 1 美元 Token 成本撬动的终端收入。SaaS 健康线为 5-10x，Agent 产品应达 3-5x。
  • Token 留存率：客户 Token 消耗 6 个月留存（类比 NDR）。低于 100% 意味着客户在"试完即弃"。
  • Token 议价权：模型成本下降 50% 时，应用方是选择降价让利于客户还是保住毛利？这决定长期定价权归属。

▎DeepSeek 估值方法的范式意义

DeepSeek 的 $71B 估值首次把中国 AI 模型公司拉入"全球第一梯队定价"。这一事件的方法论意义在于：市场开始接受"效率调整后的对标估值"——不再以"中国公司 = 折价 50%"的简单公式定价，而是根据模型能力、单位智能成本、市场地位进行精细调整。这一范式将传导至月之暗面（Kimi）、智谱、MiniMax 等二线模型厂商的下一轮融资。

▎长鑫科技 309x PE：高预期与高风险的博弈

长鑫 309x 的发行 PE 看起来极高，但需要拆开看：（1）2025 年扣非净利润处于存储周期底部，基数极低；（2）2026 上半年业绩指引已"超市场预期"，意味着 2026 动态 PE 可能回落至 80-120x 区间；（3）国产 DRAM 替代+HBM 国产化是 5-10 年级别的产业趋势。结论：长鑫不是"贵或便宜"的问题，而是"愿不愿意为国产存储的 5 年 CAGR 30%+ 支付周期底部溢价"。对于长期资金，这一溢价具备合理性；对短期交易者，309x 的静态 PE 已是高风险区。

▎本周估值结论：AI 板块估值整体处于"基础模型层 + Capex 受益上游"溢价、 "通用应用层"折价的分化阶段。建议超配：（1）有明确 ARR 与 Token 效率数据支撑的 Agent 平台； （2）AI 基础设施（GPU 云、Token 服务、算力金融）；（3）国产替代主线的半导体/存储。建议低配： 纯模型 API 厂商（价格战风险）、缺乏差异化的通用 Chatbot、估值已计入 5 年增长的人形机器人概念股。
