二、深度投资分析

分析一：AI 大模型估值格局变天——Anthropic 凭什么超越 OpenAI？

Anthropic 在私募二级市场的估值突破 1 万亿美元，超过 OpenAI 的 8520 亿美元，这是一个标志性事件。传统观点认为 OpenAI 凭借先发优势和 ChatGPT 的用户规模理应在估值上领先，但市场给出的信号是：投资人对 Anthropic 的技术路线、安全理念和长期商业化潜力给出了更高溢价。

关键观察点：

  • Anthropic 的产品开发周期从 6 个月缩短到 1 周，得益于 Mythos 等最新模型的内部优先使用权
  • Claude Code 已建立开发者心智，形成与 OpenAI 的差异化竞争
  • OpenAI 的频繁领导层动荡和战略摇摆可能影响了二级市场信心
  • 私募市场的估值更多由"稀缺性"驱动——Anthropic 的二级股票供给更少

投资启示：大模型赛道的估值逻辑正从"用户规模"转向"技术差异化 + 开发者生态 + 执行效率"。对于一级市场投资者，需要关注被投企业是否有清晰的差异化定位，而非盲目追逐最大玩家。

分析二：具身智能——从概念验证到千亿赛道的投资节奏

2026 年 Q1 具身智能融资规模超 300 亿元，接近 2025 年全年六成。它石智航 4.55 亿美元 Pre-A 轮创下行业纪录，互联网大厂从"用钱投票"到"亲自下场"——阿里、百度、小米、美团、腾讯 2025 年合计投资机器人企业 62 次。

赛道分化与投资判断：

  • 本体路线（宇树为代表）：硬件自研能力强，但面临同质化竞争和商业化路径不清晰的风险
  • 物理世界模型路线（它石智航为代表）：以 AI 原生为主，软件定义机器人，可能获得更高估值倍数
  • 大厂入局：意味着行业从"概念验证"走向"场景落地"，初创公司的窗口期正在缩小

投资建议：具身智能正处于从"技术驱动"向"商业落地"过渡的关键节点。投资重心应从"谁能做出最酷的机器人"转向"谁能在具体场景中产生可量化的 ROI"。制造业、物流、安防等 B 端场景可能是率先产生规模化收入的领域。

四、估值观察

DeepSeek 开源策略的估值冲击： DeepSeek 全面开源 V4 系列的举动，正在迫使市场重新评估 AI 模型的估值方法论。如果最先进的模型权重是公开的，"模型即产品"的公司的防御性将大幅下降，估值会面临压缩压力。相反，计算资源（谁能部署最多 tokens/秒）、数据飞轮和工程驾驭层（Harness）的价值可能被重估。
Token 效率成为新的能力信号： 如 Taranjeet 所观察，模型评估的维度正在从"能不能完成任务"转向"用多少 token 完成"。GPT-5.5 的核心卖点之一就是"更聪明、更省"——同样的 Codex 任务消耗 token 显著更少。在规模化部署中，token 效率直接转化为成本优势，这将成为影响企业客户选择和模型估值的重要因素。
半导体产业链的景气度分化： SK 海力士利润暴涨五倍，三星芯片部门员工集会要求分享 AI 热潮利润（要求 15% 营业利润分配，约 270 亿美元），美光/闪迪股价持续大涨。AI 算力需求持续推升存储芯片景气度，但也要注意地缘政治风险（伊朗战争导致油价突破 100 美元/桶）对供应链的潜在冲击。
