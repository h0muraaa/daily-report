市场概览：一级市场核心动态

Anthropic 私募二级市场估值破1万亿美元，历史首次反超 OpenAI 估值重构
[来源: 智东西] · [来源: 新智元]
根据 Business Insider 报道及 Forge Global 平台数据，Anthropic 在私募二级市场的估值已突破 1万亿美元（约合人民币6.865万亿元），超过 OpenAI 3月31日最新一轮融资的8520亿美元估值。Forge Global CEO 凯利·罗德里克斯透露，Anthropic 在该平台估值徘徊在1万亿美元左右，而 OpenAI 约为8800亿美元。更极端的报价来自 Saints Capital 联合创始人肯·索耶，称近期有股东愿以 1.15万亿美元 估值抛售股份。Anthropic 2月16日刚完成由 GIC 和 Coatue 领投的融资，彼时估值仅3800亿美元——意味着 不到两个月估值涨幅超过160%。驱动因素包括迅猛的营收增长、Claude Code 的产品势能，以及 AI 编程助手赛道的资本狂热。二级市场供需失衡（早期股东惜售、买方竞价）是推高估值的直接推手。
SpaceX 与 Cursor 达成深度绑定：600亿美元收购选择权或100亿美元年度合作 mega deal
[来源: 硅星人Pro] · [来源: 傅盛@X] · [来源: Founder Park]
SpaceX 获得在2026年晚些时候以 600亿美元 收购 Cursor 的选择权，或支付100亿美元用于双方深度合作。600亿美元是 Cursor 此前290亿美元估值的两倍多。这笔交易对双方都有战略必要性：Cursor 面临 Claude Code 和 Codex 的直接竞争，供应商变竞争对手的压力迫使它需要背靠 xAI 算力自建模型能力；而马斯克即将推动 SpaceX 以 1.75万亿美元 估值IPO（有望创史上最大IPO纪录），"手握AI时代开发者日常工作台"是支撑这一估值的关键叙事。此前 Sam Altman 曾两次求购 Cursor 均被拒。对投资者而言，这笔交易意味着 AI 编程工具赛道进入"站队"阶段，独立中立性的窗口正在关闭。
AI 存储公司 Vast Data 融资10亿美元，估值跃升至300亿美元 估值3倍跃升
[来源: Z Potentials]
由 NVIDIA 支持的 Vast Data 宣布完成约 10亿美元 融资，估值从2023年的91亿美元跃升至 300亿美元，增幅超过3倍。本轮由 Drive Capital 和 Access Industries 共同领投，NVIDIA、Fidelity、NEA 等老股东跟投。资金分为一级和二级资本，允许员工和早期投资者变现。Vast Data 在运营层面已实现盈利，十年累计产生 40亿美元预订额，其中大部分来自过去一年。核心客户包括摩根大通、xAI、CoreWeave 等。公司表示正在考虑用新资金进行收购和 AI 生态投资，并正在推进 IPO 计划。AI 基础设施层（存储、算力、网络）的资本密度持续提升，Vast Data 代表了数据存储软件在 AI 训练/推理场景中的价值重估。
阿里、腾讯等巨头洽谈投资 DeepSeek，估值目标超200亿美元 首次外部融资
[来源: 创业邦] · [来源: 极客公园]
腾讯控股与阿里巴巴正在洽谈投资 DeepSeek，这是该公司成立以来的 首次外部融资。估值目标已从最初传闻的100亿美元上调至超过 200亿美元（约合人民币1365亿元）。DeepSeek 由量化对冲基金幻方量化于2023年创立，以低成本、开源模型路线迅速崛起，但至今未产生可观收入，模型全部开源且聊天机器人免费。对腾讯和阿里而言，投资 DeepSeek 具有双重对冲价值：一方面分散自身 AI 研发的单一风险，另一方面为未来深度技术合作打开通道。受此消息影响，阿里巴巴美股盘前股价一度直线拉升超2%。不过三方均未正式回应。DeepSeek 的特殊性在于，它是极少数在未进行任何商业化变现的情况下即获得200亿美元级别估值的 AI 公司，估值完全建立在技术声誉和生态影响力之上。
黑湖科技完成近10亿元D轮融资，工业 AI 已全面盈利 全面盈利
[来源: 真格基金]
工业 AI 公司黑湖科技宣布完成近 10亿元D轮融资，本轮资金将用于加速工业 AI 应用落地和全球扩张。公司已实现 全面盈利，营收年增速超60%。黑湖科技自2016年创立，从生产管理数字化起步，逐步建立起轻量、可复制的产品体系，覆盖食品饮料、汽车零部件、装备制造等30多个行业。2023年以来持续投入多场景工业智能体（AI Agent）研发，已实现规模化落地，覆盖设计、排程、生产、质检等核心场景。其"拆单 Agent"可将原本2-3小时的人工拆单缩短至分钟级，准确率超95%；"报价 Agent"将报价时效从6小时压缩至秒级，询盘响应率提升70%。工业 AI Agent 从"辅助决策"到"自主决策"的升级，标志着该赛道正从概念验证进入规模化商业变现阶段。
Meshy 年经常性收入达4000万美元，3D AI 赛道跑出首个盈利样本 ARR 4000万
[来源: 硅星人Pro]
由清华姚班出身、MIT博士胡渊鸣创立的 3D AI 公司 Meshy 披露，其年经常性收入（ARR）已达 4000万美元，月度收入增速长期保持在20%-30%，毛利率85%，LTV/CAC 大于4，一半以上增长来自自然流量。3月17日，拓竹科技将 Meshy 6 接入 MakerWorld 平台，用户上传照片两分钟即可获得可直接3D打印的 3MF 文件。与图像生成、视频生成领域头部公司普遍"烧钱换增长"不同，Meshy 的毛利、自然流量占比和付费意愿更像一家成熟生意。本轮 AI 应用浪潮中，能在细分垂直场景（3D打印/制造）跑通单位经济的案例仍然稀缺，Meshy 为投资者提供了一个验证"AI 工具能否独立盈利"的关键样本。
NeoCognition 完成4000万美元种子轮，打造自学习通用 Agent 种子轮
[来源: Z Potentials]
俄亥俄州立大学教授 Yu Su 创立的 NeoCognition 从隐身模式现身，完成 4000万美元种子轮融资，由 Cambium Capital 和 Walden Catalyst Ventures 共同领投，Intel CEO Lip-Bu Tan、Databricks 联合创始人 Ion Stoica 等参投。公司致力于开发能够"自学成为任何领域专家"的 Agent 系统。Yu Su 指出，当前 Agent（无论 Claude、OpenClaw 还是 Perplexity）完成预期任务的成功率仅约50%，可靠性不足是制约其成为独立工作者的核心瓶颈。NeoCognition 的差异化在于模拟人类学习方式的自学习机制，而非依赖预训练知识的通才模式。4000万美元种子轮在当前市场环境下属于超大规模，反映出资本对"下一代 Agent 架构"的押注意愿仍然强烈。
中国大模型市场高度集中：智谱、MiniMax 上市，"六小虎"缩减为"四小强" 赛道洗牌
[来源: 创业邦]
2026年开年中国大模型赛道呈现显著的马太效应。阿里、腾讯、字节、华为等巨头形成难以撼动的第一梯队；智谱AI和MiniMax先后登陆港交所，市值双双突破 3000亿港元；阶跃星辰完成超50亿元B+轮融资，刷新近一年赛道纪录；月之暗面最新估值飙升至约 180亿美元，正与投行接触推进港股IPO。昔日"AI六小虎"中的百川智能和零一万物已陷入公开融资静默期，赛道从六家缩减为"四小强"。在这种背景下，澜舟科技等企业选择避开参数竞赛，专攻企业级智能体市场，发布自研"企业智能体OS"LangClaw。对投资者而言，中国大模型赛道的投资窗口正在从"广撒网"转向"押注已验证的头部"，未上市标的的稀缺性正在快速消失。

深度投资分析

一、Anthropic 估值反超 OpenAI：二级市场定价权的转移

Anthropic 在不到两个月内从3800亿美元飙升至1万亿美元，涨幅超过160%，这是 AI 一级市场历史上最陡峭的估值曲线之一。理解这一现象需要拆解三个层次：

核心论点： 这不是简单的"更好模型"叙事，而是资本市场对"AI 平台入口"的重新定价。Claude Code 在开发者群体中的渗透率、企业级订阅的续约率、以及编程助手这一垂直场景的商业化确定性，共同构成了 Anthropic 估值溢价的底层逻辑。

供给端收缩效应：Anthropic 早期股东（尤其是创始团队和前员工持股）的惜售情绪极强，二级市场上可流通股份极度稀缺。Forge Global 和 Saints Capital 等平台的数据显示，买方竞价已出现"有价无市"的局面——1.15万亿美元的卖方报价未必能成交，但它确实锚定了市场心理预期。

OpenAI 的相对劣势：OpenAI 8520亿美元的融资估值发生在3月31日，但其产品矩阵（ChatGPT 消费端增长放缓、企业端面临微软 Copilot 的直接竞争、API 价格战压力）让投资者对其"估值天花板"产生疑虑。更关键的是，OpenAI 向营利性实体转型的法律不确定性，以及 Elon Musk 的诉讼干扰，都在削弱其股权的流动性溢价。

风险提示：1万亿美元估值尚未经过一级市场融资轮次的正式确认，二级市场的报价存在显著流动性折价/溢价噪音。Anthropic 的年化营收能否支撑这一估值倍数（假设10-20倍 P/S，对应年收入需达500-1000亿美元）仍是最大未知数。当前估值更多反映的是"稀缺性溢价"而非"基本面验证"。

二、SpaceX 1.75万亿 IPO 与 Cursor 600亿选择权的资本逻辑

马斯克即将推动 SpaceX 以 1.75万亿美元 估值进行 IPO，这将是有史以来最大规模的首次公开募股。两个月前，xAI 与 SpaceX 的合并交易估值为1.25万亿美元。 Cursor 的600亿美元收购选择权/100亿美元合作费用，本质上是为这一 IPO 叙事添砖加瓦。

为什么 Cursor 值600亿？ 从财务数据看，Cursor 14个月内 ARR 从1亿美元涨到20亿美元，150人团队人均产出是谷歌的9倍。但更核心的价值在于其"开发者入口"地位——100万日活开发者每天在此编写代码，这是 AI 时代最稀缺的注意力资产之一。对 SpaceX/xAI 而言，收购 Cursor 意味着直接获得一个与开发者日常工作流深度绑定的分发渠道，而不需要从零建设。

选择权结构的投资含义：SpaceX 获得的是"可选择的收购权"而非立即执行的并购。这给了马斯克灵活性：既可以先通过算力合作测试双方契合度，又保留最终决策权。但对 Cursor 而言，这种深度绑定实际上构成了"排他性锁定期"——在选择权有效期内，Cursor 很难接受其他买家（如微软、谷歌）的收购要约。对 Cursor 现有投资者而言，600亿美元是明确的退出价格锚，但时间不确定性和交易执行风险需要纳入 IRR 计算。

估值方法论观察

当前 AI 一级市场的估值逻辑正在经历从"用户/收入倍数"向"战略资产定价"的迁移。Anthropic 和 Cursor 的案例表明，当标的具备"平台入口"或"开发者注意力垄断"属性时，传统 SaaS 估值倍数（10-20倍 ARR）已无法解释其定价——资本市场更愿意参照"基础设施级资产"的估值框架（如英伟达、微软的历史 P/S 区间）。

与此同时，中国 AI 公司的估值逻辑仍更贴近"收入验证"标准。黑湖科技的10亿元D轮、Meshy 的4000万美元 ARR，其估值倍数相对克制，反映出中美两个市场在资本充裕度和风险偏好上的结构性差异。对跨市场投资者而言，中国 AI 应用的"估值性价比"可能更高，但需承担地缘政治和流动性的额外折价。
