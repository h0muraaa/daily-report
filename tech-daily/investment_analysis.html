宇树科技申请科创板IPO，拟募资42亿元——"人形机器人第一股"正式冲刺上市

3月20日，上海证券交易所正式受理宇树科技股份有限公司科创板上市申请，拟募集资金42.02亿元人民币。本次募资将重点投入智能机器人模型研发、本体研发、新产品开发及制造基地建设四大方向，根据招股问询函披露，公司2025年实现营业收入约17.08亿元。

这是当前全球机器人赛道最具代表性的IPO事件。宇树在四足及人形机器人领域具备技术先发优势，其B2/H1系列产品已规模商用。42亿元的募资规模意味着极高的上市前估值溢价预期；若参照人形机器人行业20-40x ARR估值区间，宇树当前估值或已在200-300亿元人民币区间。对一级市场而言，此次IPO定价将为该赛道整体估值体系提供重要锚点。

投资关注点：宇树能否在上市后维持高增速、与国际竞手（Figure AI、Boston Dynamics）的差距是否可持续缩小，以及国内政策对人形机器人量产补贴的力度，将成为二级市场给予溢价的核心变量。

Dify完成3000万美元Pre-A融资，开源AI工作流平台加速商业化扩张

AI应用构建平台Dify宣布完成3000万美元Pre-A轮融资，并随即启动新一轮招聘。Dify基于开源框架构建，提供AI工作流编排、LLM应用开发等能力，已积累大量开发者生态。在Agent热潮推动下，该公司正快速从开源工具向商业SaaS产品转型。

OpenAI计划合并ChatGPT、Codex及浏览器为"桌面超级应用"——消费端护城河深化战略

据《华尔街日报》报道，OpenAI正计划将旗下ChatGPT、Codex编程工具及AI浏览器整合为单一桌面"超级应用（Superapp）"，以简化用户体验并提高产品粘性。此举是OpenAI在消费端强化生态闭环的重大战略动作。

从商业模式角度分析，超级应用策略将有效降低用户流失率，提升LTV（用户生命周期价值）。Codex已面向美国和加拿大高校生提供100美元代金券，是典型的"年轻用户圈地"打法——与Claude for OSS（开源开发者免费6个月Max订阅）的策略形成呼应，两家公司均在布局开发者流量入口的长期价值。对标微信/支付宝的超级应用逻辑，若OpenAI能在桌面端建立统一入口，则在AI订阅市场的定价权将进一步提升，支撑其在$157亿年收入预期下的持续高估值。

此举同样释放了信号：OpenAI正在由纯API/模型公司向终端消费品公司演进，投资人应重新审视其商业模式的边界扩展速度。

美国白宫发布全国AI统一监管框架——"一本规则书"终结50州分散立法混乱局面

特朗普政府AI政策负责人David Sacks宣布，白宫正式发布基于去年12月总统行政令要求的全国AI监管统一框架。该框架旨在取代此前50个州各自为政的碎片化监管态势，重点涵盖：儿童在线安全保护、能源成本防护、第一修正案（言论自由）保障以及AI内容审查防护。Marc Andreessen（a16z创始人）公开表达支持，称其"理性、保护性且鼓励建设者"。

对投资人而言，这是利好信号。统一联邦框架意味着AI公司可降低合规成本，消除各州法规冲突带来的运营不确定性，利好头部AI公司（OpenAI、Anthropic、Google DeepMind）及其B2B企业服务渗透。尤其是涉及国防、政府合同的AI公司（如Palantir），将在稳定监管环境下加速政府采购落地。

需警惕的是：框架的具体实施细则和执法力度尚待明确，在政治更迭风险下长期政策稳定性存疑。

Apple封锁AI"氛围编程"应用更新——$90亿估值Replit遭App Store审查风暴

深度投资分析

— 重点事件解读

【事件一】Cursor×Kimi"许可证门"：开源生态商业化的制度性风险与机遇

本周AI开发工具领域最具爆炸性的事件，是Cursor新发布的Composer 2模型被开发者通过API返回值"扒出"其底层基座为Moonshot AI（月之暗面）的Kimi K2.5。相关时间线如下：

事件时间线

暴露：开发者Fynn在调试Cursor API时，发现模型ID为 kimi-k2p5-rl-0317-s515-fast，明确指向Kimi K2.5，Moonshot员工公开质疑并引发舆论风暴。

回应：Cursor VP Lee Robinson承认Composer 2基于开源基座，约1/4算力来自基座，其余为Cursor自研强化学习（4x规模RL）。联合创始人Aman Sanger确认Kimi K2.5"在困惑度评测中表现最强"。

收场：Moonshot AI官方确认Cursor通过Fireworks托管推理平台的授权商业合作获取Kimi K2.5，事件由"许可证纠纷"降级为"沟通滞后"。

投资视角：中国开源模型正在重塑全球AI应用层竞争格局

Kimi K2.5作为基座模型被$9B估值的Cursor选中，是中国AI开源生态全球影响力的强力佐证。Hugging Face CEO Clement Delangue同期发推："开源正成为最大的竞争使能器，另一个验证了中国开源已成为塑造全球AI堆栈的最强力量——前沿不再只关乎谁从头训练，而是谁能最快地适配、微调和产品化。"

对于中国AI基础模型公司（Moonshot、DeepSeek、Qwen等）的投资逻辑，此次事件强化了以下判断：在模型层面的商业化可借助"开源+商业授权"双轨路径实现，API使用费 + RL合作服务费将成为重要收入来源。全球头部AI应用公司（Cursor、Windsurf等已被证实）将持续采用中国高性价比开源基底，形成稳定的B2B收入流。

许可证合规风险：一个被系统性低估的价值毁损因子

Kimi K2.5采用修改版MIT许可证，核心条款为：月收入超过2000万美元的商业产品须在用户界面显著展示"Kimi K2.5"标识。Cursor月收入约1.67亿美元（8倍触发门槛），但Composer 2界面从未展示任何Kimi标识。

分析认为，Cursor通过Fireworks"推理合作伙伴条款"来满足许可证义务的法律逻辑存疑——基础设施合规与产品层合规是两个不同的法律维度。这一潜在风险目前被市场忽视，但若许可证纠纷演变为正式法律诉讼，将对Cursor融资（上一轮估值约$100亿）产生实质影响。AI应用公司在尽职调查阶段应将开源许可证合规列为重点审查项。

投资结论：此事件对Moonshot AI（及中国开源基础模型赛道）是利好，确认了其全球B2B商业化路径；对Cursor是中性偏负面（许可证合规问题悬而未决）；对整个AI应用层赛道是提示性信号——开源基座的许可证条款将越来越被纳入投资尽职调查清单。

【事件二】Dreamer出柜：前Stripe CTO与Google高管联合打造"Agent操作系统"平台

由前Stripe CTO David Singleton与Hugo Barra（前小米国际副总裁、前Meta VR负责人）联合创立的隐身初创公司/dev/agents，本周正式以"Dreamer"品牌公开亮相。核心产品定位是以个人"Sidekick"（助理AI）为中心，构建发现、构建和使用AI Agent的完整堆栈。

商业模式解析

Dreamer的核心逻辑是：下一个主流计算平台不是聊天机器人，而是Agent的操作系统。Sidekick是一个"构建Agent的Agent"，用自然语言帮助用户定制个人化工作流，并从Dreamer的Agent应用商店中发现、安装和运行第三方Agents。商业模式预期与App Store高度相似——平台抽佣 + 订阅服务。

David Singleton此前主导了Android生态系统的大规模平台化，以及Stripe作为支付基础设施的全球扩展。Hugo Barra在消费硬件和VR平台拥有罕见的产品化经验。这一组合具备打造平台级产品的稀缺执行能力。

市场机遇与竞争格局

Dreamer当前处于"等待列表"阶段，面向Latent Space社区开放早期访问并提供$10,000建设奖金。竞争对手包括：Perplexity Computer（已宣布个人AI电脑形态，已接入Pitchbook/Statista/CB Insights等数据源）、Anthropic Cowork（VM虚拟机加持的Claude Code桌面Agent）、腾讯QClaw（微信遥控本地Agent）。市场教育曲线仍较陡，但头部玩家的融资能力决定了用户规模竞赛的持续时间。

投资关注：Dreamer尚未公开融资信息，但创始团队背景（前Stripe CTO + 前Google VP）意味着其A轮估值将会相当激进。若能验证Agent App Store的PMF，中期GMV模型预期较强。建议关注Q2融资动态。

赛道雷达

— 值得关注的细分机会
AI Coding Agent平台化

Cursor×Kimi验证开源基座+RL微调可快速推出前沿级代码模型。Devin推出"可自我调度"的任务自动化功能（所有用户可用），Replit Agent 4发布后用户增长显著。GitHub Copilot达成6000万次PR Review里程碑。此赛道正从工具演进为平台，下一个竞争焦点是任务自动化（Schedule+Autonomous）而非补全。

人形机器人商业化

宇树科技IPO申请落地，拟募42亿元；Jensen Huang宣称AI机器人是50万亿美元产业。Waymo170M英里安全数据强化了"机器人可替代人类执行物理任务"的论据。Fei-Fei Li团队Dream2Flow研究显示：生成视频+3D物体流可解决机器人泛化问题。国内政策端对人形机器人量产的补贴预期持续升温。

AI Agent基础设施（记忆&工具）

Perplexity Computer接入Pitchbook/Statista/CB Insights，转型为知识工作者"AI工作站"；Devin推出任务调度功能；Claude Cowork新增Dispatch（手机远程指挥本地Agent）；LlamaIndex推出LiteParse + 40+Agent技能集成；mem0发布AI GitHub commits排行榜。记忆层（mem0）、工具调度（LlamaIndex）、任务管理等Agent基础组件正快速产品化。

中国AI出海 & 数字服务贸易

白鲸出海数据：2026年1-2月中国出口同比增长21.8%，集成电路出口飙升72.6%；数字服务出口规模已超实物跨境电商，AI/游戏/短剧成出海新主角。中国AI模型（Kimi、DeepSeek、Qwen、GLM）已实质性渗透全球AI应用层。腾讯QClaw正式全量开放（基于OpenClaw封装），国产AI Agent进入消费级普及阶段。

AI原生SaaS转型（"SaaSocalypse"应对）

Palantir CTO Shyam Sankar在a16z对话中提出"SaaSpocalypse"概念——AI正在颠覆传统SaaS商业模式。其核心论点：能提供"Alpha软件"（主动定义未来、具有壁垒）而非"Beta软件"（被动跟随需求）的公司才能存活。Notion AI会议记录后台持续运行、接入AI+Connector后被重新激活的案例，印证了现有SaaS通过AI增值功能实现NRR扩张的路径。

AI合规与安全基础设施

Lovable公开声明与Delve（"伪造合规即服务"公司）无关，并展示其SOC 2 Type II + ISO 27001合规证书。Sonatype推出针对AI代码生成的实时依赖安全护栏Guide。Databricks发布DASF v3.0（AI安全框架），聚焦Agentic AI新型攻击向量。随着AI生成代码和自主Agent大量进入生产环境，安全合规工具市场将快速扩张，是B2B投资机遇所在。

估值观察

— 估值信号与方法论
