# 科技日报生成器

## Overview

从JSON格式的新闻数据中提取关键信息，生成**指定角色**视角的科技日报，输出为HTML格式。

## 输入参数

本Skill接受以下参数格式：
- `<JSON文件路径>` — 必需，新闻数据JSON文件
- `--role <角色名>` — 必需，指定要生成的角色，可选值：
  - `cto_insight` — CTO洞察版
  - `developer_practice` — 开发者实践版
  - `tech_enthusiast` — 科技爱好者版
  - `investment_analysis` — 投资分析版
  - `academic_research` — 学术研究员版
  - `user_research` — 用户研究版
- `--output <目录>` — 可选，输出目录，默认为 `./tech-daily/`
- `--timeout <时长>` — 可选，如 `15m`

## 执行流程

1. 读取并解析输入JSON文件
2. 读取指定角色的人设prompt
3. 基于角色视角筛选新闻并生成HTML日报
4. 保存文件到输出目录

## 角色设定

| 角色标识 | 角色名称 | 目标读者 | 核心关注点 | prompt文件 |
|----------|----------|----------|------------|------------|
| `cto_insight` | **CTO洞察版** | 技术高管、CTO、VP | 战略价值、商业影响、竞争格局 | `prompts/cto_insight.md` |
| `developer_practice` | **开发者实践版** | 程序员、工程师 | 技术细节、工具更新、最佳实践 | `prompts/developer_practice.md` |
| `tech_enthusiast` | **科技爱好者版** | 普通大众、爱好者 | 通俗科普、生活影响、趣味性 | `prompts/tech_enthusiast.md` |
| `investment_analysis` | **投资分析版** | 投资者、分析师 | 市场机会、估值逻辑、风险评估 | `prompts/investment_analysis.md` |
| `academic_research` | **学术研究员版** | 研究人员、高校师生 | 理论基础、研究创新、学术价值 | `prompts/academic_research.md` |
| `user_research` | **用户研究版** | UX设计师、产品经理、用户研究员 | 用户体验、设计趋势、用户洞察 | `prompts/user_research.md` |

## 生成要求

执行时请遵循以下要求：

1. **自主筛选**：从所有新闻中筛选出对指定角色最有价值的内容
   - 不要简单按关键词匹配，要理解内容本质
   - 关注有信息增量、有具体事实/数据的内容
   - 排除纯情绪表达，保留"情绪+信息"的内容
   - 不唯来源论，社交媒体的第一手信息也有价值
2. **内容要求**：
   - **每条新闻必须有总结**：禁止只列出标题或一句话带过
   - 每条内容必须是完整的总结段落（至少2-3句话）
   - 说明这条新闻是什么、为什么重要、关键细节是什么
   - 从原文中提取有价值的信息点，用自己的话重新组织
   - **禁止**：只写标题、只贴链接、只写"XX发布了YY"、直接输出未经处理的原文
3. 严格遵循人设中的输出格式
4. 从筛选后的新闻中提取最相关的信息
5. **必须标注每条新闻的信息来源**（使用JSON中的 `link` 和 `feed_title` 字段）
6. 在日报底部添加对应角色的信息来源汇总区块
7. 生成完整HTML文档（含CSS样式）
8. 保存到指定路径：`<输出目录>/{role}.html`

## 输出文件

输出到指定目录（默认 `./tech-daily/`）：
- `{role}.html` — 指定角色的日报文件，如 `cto_insight.html`

## 信息来源标注规范

1. **每条新闻必须标注来源**
   - 使用 `feed_title` 字段显示来源名称
   - 使用 `link` 字段生成可点击的原文链接
   - 格式：`[来源: 网站名]` 或 `📎 来源: [标题](链接)`

2. **HTML 链接格式**
   ```html
   <a href="https://original-link.com" target="_blank" rel="noopener">[来源: Google Blog]</a>
   ```
   所有链接必须可点击，`target="_blank"`，`rel="noopener"`。

3. **底部来源汇总区块**
   - CTO版：`信息来源汇总`
   - 开发者版：`参考链接汇总`
   - 爱好者版：`延伸阅读`
   - 投资版：`数据来源声明`
   - 学术版：`参考文献`
   - 用户研究版：`参考来源`

## 样式指南

- **CTO版**: 简洁商务风格，蓝灰色调
- **开发者版**: 深色代码主题，等宽字体
- **爱好者版**: 活泼配色，emoji点缀
- **投资版**: 专业金融报表风格
- **学术版**: 学术简洁风格，蓝白/灰白配色，LaTeX风格排版
- **用户研究版**: 温暖人本风格，橙/紫渐变配色，注重可读性与视觉层次
